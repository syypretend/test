4. 小米 MiMo-V2.6 发布：从三个维度扩展强化学习算力，走向模型自我改进

8 月 8 日，小米 LLM-Core 团队发布技术报告 MiMo-V2.6（arXiv:2610.11959），这是一系列全模态（omni-modal）模型，核心贡献在于系统性地把强化学习（RL）作为主要训练范式进行规模化扩展，让模型"边用边学、自我改进"。

技术要点：

  • 三路并行扩展 RL 算力：①更大的批次与吞吐（异步训练，每步消费 1,568 个样本与 27-37 亿 tokens，上下文最长 1M）；②更多样化的环境（代码、通用、视觉、网络四域，混合多种 agent harness）；③更多的评分算力（分组式 agentic grading，为长程任务提供更准确的奖励信号，并引导模型输出更短、更节省 token 的解法）
  • 稳定性设计：冻结 MoE 路由器；建立多层 reward-hacking（奖励钻空子）防御
  • 基础设施：为混合任务 agentic RL 构建了统一轨迹表示、高并发多框架 rollout、控制面/数据面分离、训练-推理一致性等工程能力
  • 前置环节：RL 前先做多模态语料中期训练（mid-training），为 RL 提供充分的探索空间，基于混合 SWA 架构的预训练底座展开

开源与验证：

团队开源了训练动力学、RL 环境与 RL 框架以支持复现。该工作与 DeepSeek-R1、OpenAI o 系列等"推理模型通过 RL 提升"的路线一脉相承，但把 RL 从"单一数学/代码场景"扩展到"全模态 + agent 场景"，并公开了防 reward hacking 与冻结路由等工程细节，值得社区复现验证。

6. NeurIPS 2026：Thinking Inertia 揭示 LLM 的"思维惯性"——告诉它别思考，它还在思考

10 月 8 日上线的论文《Thinking Inertia: LLMs Keep Thinking When Told Not To》（已被 NeurIPS 2026 接收）首次系统量化了 LLM 的"不思考"行为：禁用思考模式或明确要求模型不要推理，模型依然会输出显式推理过程，作者称之为"思维惯性"（Thinking Inertia）。

技术要点：

  • 重新定义"无思考"的度量：把每个响应规范化为"作答前追踪（pre-answer trace）+ 最终答案"两部分，从三个层次评估——①空思考率（Empty-Thinking Rate，严格只输出答案的合规率）；②问题与作答前内容的指令感知相关性；③LLM-as-judge 显式推理率（可见的显式推理）
  • 实验规模：6 种提示干预 × 6 个 LLM × 3 类问题（布尔题、多选题、开放式问题）
  • 关键发现：显式"不要思考"控制无法可靠消除显式推理；答案空间越开放，思维惯性越明显；布尔与多选题上准确率基本不变，而开放式问题存在"只答答案的合规性"与"任务准确率"之间的权衡
  • 补充实验：把同一问题改写进不同的答案空间（如提供候选答案）后，"只答答案"更容易达成

影响分析：

该研究把"no-thinking"定义为一个与推理能力并列、需要系统性评测的非平凡能力。对实际工程的影响：①提示词"别思考直接答"不可靠，想要纯答案输出需在产品层做解析而非依赖模型自觉；②"思考模式"开关可能徒有其表，禁用后推理 token 仍会隐性产生，计费与延迟设计不能按开关状态假设；③ 为"是否需要思考"自适应路由提供了新评测基线。
