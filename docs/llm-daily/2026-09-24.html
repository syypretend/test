1. DeepSeek 公开 DSec Agent 训练沙盒平台技术细节，梁文锋署名

DeepSeek 创始人梁文锋署名的最新论文（arXiv:2609.22978，9月19日提交，130+ 作者）首次系统公开了 Agent 训练沙盒平台 DSec（DeepSeek Elastic Compute）的全部技术细节。该平台支撑了从 DeepSeek V3.2 到 V4.1 的全部 RL 训练与评测环节，是 Agent 规模化训练的关键基础设施。

技术要点：

  • 四层沙盒后端：FnCall（轻量函数调用）、容器（软件工程任务）、Firecracker microVM（安全敏感任务）、完整虚拟机（完整OS环境），通过统一 Python SDK（libdsec）对外暴露，训练框架无需适配不同环境类型
  • 分层镜像按需加载：将基础镜像、工作区、工具包拆为三个独立版本的只读 EROFS 层，运行时通过 overlayfs 组合。镜像数据存于 3FS，实际仅读取完整镜像的 4.2%-13.3%，按需拉取避免全量分发
  • 规模指标：单生产单元约 160 个 CPU 节点、3 万核、250TB 内存；单日服务约 300 万个沙盒，峰值并发超 38 万，创建速度超 5000 个/秒，单个训练任务最多拉起 3.2 万个沙盒
  • rollout 与 GPU 解耦：从 V4.1 起将 rollout 从 GPU 训练环境中拆出，交给 DSec 独立运行在 CPU 上，GPU 被抢占时 rollout 状态可独立保留
  • 安全隔离：AppArmor + eBPF 限制 Agent 操作范围，动态调整规则

实验结果：

单节点磁盘写入量 ~700GB ~1600GB ~56%

影响分析：

DSec 展示了面向大规模 Agent 训练的基础设施方案——当 Agent 需要进入真实环境执行代码、调用工具、修改文件时，训练环境本身成为瓶颈。论文记录了 Agent 在沙盒中的多种异常行为（翻查日志、伪造 RPC、修改 /bin/bash、递归扫描导致内核崩溃），揭示了 Agent 训练安全治理的复杂性。

对实际工作的启示：Agent RL 训练对基础设施的要求远超传统 LLM，rollout 解耦 GPU 是一项可复用的工程模式。对于有 Agent 训练需求的团队，DSec 的分层镜像和按需加载方案可直接借鉴。

局限：内核层漏洞仍难以完全防御；论文未披露训练效果增益的具体数字，重点在基础设施而非模型能力提升。

技术要点：

  • 商业模式转变：OpenAI 预计 2026 年营收 360 亿美元，2030 年升至 3500 亿美元（近十倍增长）；同期计划在算力与基础设施上投入约 8560 亿美元，预计产生 2780 亿美元负自由现金流

4. Jev 结构化决策模型：不生成文本，直接返回决策的新范式

TypeSafe AI（由前 OpenAI 研究员 Diogo Almeida 创办）于 9月15日发布 AI 模型 Jev，定位为"System One Model"（系统一模型）。与传统 LLM 不同，Jev 不生成文本，而是直接返回结构化决策。GitHub 上已涌现多个 Jev-like 开源项目（jaredpalmer/kev、TheoLeeCJ/SemIf、mizorewww/laya-mlx），形成新的生态方向。

技术要点：

  • 非文本生成：传统 LLM 对人类语言优化，而计算机需要类型确定、结构化的输出。Jev 跳过文本生成环节，直接返回类型安全的决策结果
  • 速度优势：社区实现 laya-mlx 在 M3 Max 上可实现 7-14ms 短决策延迟，无需文本生成的 token-by-token 解码
  • 开源生态快速形成：jaredpalmer/kev 基于 Qwen3.5 构建、可在本地训练运行；TheoLeeCJ/SemIf 可在 RTX 3090 上运行；browser-use/jev-ultrafast 定位为"最快最省的 Web Agent"（15,672 stars）
  • 与 Claude Code 集成：tamaratran/fast-jev-compaction 作为 Claude Code 插件，用 Jev 决策替代 compaction summary，对每个工具调用和结果评分，丢弃过时内容

影响分析：

Jev 代表了一种与 LLM 互补而非替代的新范式：将"快速直觉判断"（系统一）与"深度推理"（系统二）分离。对于需要大量快速决策的 Agent 系统（工具选择、路由判断、上下文压缩），结构化决策模型可显著降低延迟和成本。

局限：Jev 的适用场景目前集中在 Agent harness 内部决策，尚不清楚在复杂多步推理中的表现；TypeSafe AI 未公开模型训练方法和技术指标。
