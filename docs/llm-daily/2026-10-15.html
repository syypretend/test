1. Meta 发布 Muse Wonder 系列：首款前沿模型，距离 Opus 5.5 仅差 2 分

10 月 13 日，Meta 超级智能实验室（Superintelligence Labs）正式发布其首个前沿模型系列 Muse Wonder，包括 Muse Wonder 与 Muse Wonder Full 两款模型，代号"Watermelon"。这标志着 Meta 在 Llama 4 失利、落后前沿竞争近一年后，正式杀回第一梯队。

一句话概要：Meta 首次推出瞄准"个人超级智能"的前沿模型系列，在多项 Agent 与编程基准上追平行业头部，结束长期"追赶者"定位。

技术要点：Muse Wonder 定位轻量级、低延迟，直接面向 API 与开发者开放；Muse Wonder Full 是完整版，仅通过 Muse Code 订阅提供，不走按需付费 API。系列重点强化三条能力线——个人/专业级 Agent 任务、长期记忆与编程。相比 6 周前发布的 Muse Spark（AI Index 最高 48 分），Wonder 与 Wonder Full 在 Artificial Analysis Intelligence Index v4.3 最高推理档位分别拿到 52 分与 56 分，跃升显著。

实验结果：在第三方基准榜单上，Muse Wonder 系列综合排名第三，超过 OpenAI 当前最新旗舰，距离榜首 Claude Opus 5.5 仅差 2 分。扎克伯格称"Meta 已在 AI 前沿领域追上竞争对手"，并承诺继续大规模资本投入挑战 OpenAI 与 Anthropic。

影响分析：对开发者而言，这意味着 API 市场重新出现一个"记忆强、Agent 任务强"的第三极；对 Meta 而言，Muse 系列与其 30 亿级用户分发网络结合，个人 AI 助手（Personal Agent）商业化路径比纯 API 厂商更宽。花旗研报已将其视为 Meta 第二增长曲线。

来源：ZAKER 报道 · 智东西报道 · IT之家报道

4. 何恺明团队发布 VISTA：无损视觉记忆让 AI "过目不忘"，ARC-AGI-3 满分通关

何恺明（MIT）团队发布新论文《VISTA: A Visual Harness for Reasoning in an Interactive World》，给 AI Agent 装上"视觉记忆系统"，在不修改模型参数的前提下，在交互式视觉推理基准 ARC-AGI-3 上拿到满分 100 分。

一句话概要：瓶颈不在模型智力，而在记忆组织方式——用无损帧存储 + 主动视觉回看取代"画面转文字/一次性编码"，Agent 即可质变。

技术要点：VISTA 不做任何"翻译"（不把画面转成网格或文字），而是把环境返回的每一帧原始画面无损保存（按回合+帧编号归档），模型可随时按空间（任意区域放大、像素级 RGB 读取）与时间（跨回合对比）两个维度"回头看"。相比官方文本网格方案 4,000 token/帧 的开销，512×512 图像仅需约 308 token，信息更全、开销更小。

实验结果：ARC-AGI-3 上 VISTA+Claude 拿到 RHAE 100.00 满分通关（7,302 步），文本网格基线仅 13.33 分；VISTA+GPT-5.6 达 99.00 分；比首次游玩的人类少用 57.4% 的动作。该基准不告知规则与目标，全靠自行摸索。

影响分析：这是何恺明（ResNet/MAE 作者）首次进入 Agent 领域，其洞察"更强的模型 ≠ 更好的 Agent，记忆的组织方式才是瓶颈"，对 Agent 产品（客服、游戏、具身）的记忆设计具有直接启示。

来源：https://arxiv.org/abs/2610.02200 · CSDN 深度解读

5. 微软研究院 Fork-and-Flush：清空聊天记录，智能体性能暴涨 66%

微软研究院论文《Fork-and-Flush: Escaping Idea Basins in Autoresearch Agents》（arXiv:2610.07447）发现：AI 智能体在长时间运行后会被早期对话中的错误假设与冗余信息"困住"（作者称之为 Idea Basin / 思维盆地），而"定期清空聊天记录、只带走工作成果"这一朴素操作，能让同等算力下的性能提升 66%。

一句话概要：对 AI 智能体而言，"遗忘"有时比"记忆"更有价值——上下文污染是长程 Agent 性能的关键杀手。

技术要点：Fork-and-Flush 的流程是：正常对话积累到一定轮数后，分叉（Fork）出多个新会话，仅携带代码/文件/实验结果等真实工作成果，清空全部对话历史，各副本并行探索不同方向后再择优推进。它揭示了"上下文越长未必越好"的反直觉事实。

实验结果：传统持续对话方式平均得分 0.52；Best-of-4（跑 4 次选最优，4 倍算力）仅 0.58；而 Fork-and-Flush 在相同算力下达到平均 0.78、最高 0.86，相对传统方法提升 66%，相对 Best-of-4 提升 44.4%。

影响分析：对 Agent 工程是即时可用的低成本优化：当你发现 Agent"卡住兜圈子"，开新对话只带关键信息往往比继续追问更有效；这也对大上下文窗口的价值叙事提出了挑战，为"上下文压缩/重置"类研究开辟了方向。

来源：https://arxiv.org/abs/2610.07447 · CSDN 深度解读

6. UNITAS：1.7B 参数的 3D 原生世界模型，在机器人操控上碾压 6B/8B 大模型

跨维智能（DexForce）团队发布 UNITAS（arXiv:2610.12099，代码同步开源）：一个仅 1.7B 参数的"3D 原生世界动作模型"，直接在三维空间理解与推理，彻底绕开"摄像头 2D 图像→猜测 3D 结构"的翻译路线。

一句话概要：正确的表示方式比堆参数更有效——机器人直接用 3D 点云"思考"，小模型也能全面压过参数数倍的大模型。

技术要点：UNITAS 把观察、动作、环境变化全部统一到三维物理空间表达（点云 + 轨迹），同时建模物体随时间的变化轨迹，并将"世界模型（预测世界会怎样变）"与"动作模型（决定自己怎么动）"合并为同一个模型。相比主流 2D 图像 + 文本描述的路线，避免了深度靠猜、遮挡失效、信息逐层损失等问题。

实验结果：LIBERO 平均 99.8%（Fast-WAM 6B 为 96.5%、π0.5 为 97.2%）；LIBERO-Plus 89.1%；RoboTwin Clean/Random 分别 92.94%/93.04%；真实机器人实测成功率约 85%。1.7B 参数在几乎全部基准上高出 6B-8B 模型 3~6 个百分点。

影响分析：这是"表示学习 > 规模 Scaling"的一个强信号，对具身智能与 VLA（视觉-语言-动作）方向的选型有直接影响：参数不是越多越好，3D 原生表示可以在极低算力门槛下（端侧部署）取得更好效果。

来源：https://arxiv.org/abs/2610.12099 · CSDN 深度解读
