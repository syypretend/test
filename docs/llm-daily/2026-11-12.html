1. Anthropic 发布 Claude Fable 5.2 与 Mythos 5.2：基准登顶 + API 降价 20%，千 Agent 协作 30 小时形式化费马大定理

一句话概要： Anthropic 同时发布通用旗舰 Fable 5.2 与安全专精的 Mythos 5.2，在编码、知识工作、网络安全三类基准上刷新纪录，同时把 API 价格从 $10/$50 降到 $8/$40（每百万 token 输入/输出），并首次公开"约 1000 个 Agent 协作完成 Lean 形式化证明"的实验。

技术要点：

  • 双模型同源、护栏不同。 Fable 5.2（模型 ID claude-fable-5-2）面向通用与编码场景全面开放；Mythos 5.2 使用同一底座但配置更强安全护栏，仅通过 Project Glasswing 向经过审核的网络安全与生命科学用户开放。这一点很关键：能力相同、准入不同，等于把"谁能用"做成产品分层。
  • 推理预算（effort）成为一等参数。 官方把 Medium / High / Xhigh / Max 做成可选档位，同一模型在不同档位下分数与单任务成本差异巨大。FrontierCode 2.0 上 Fable 的得分从 Medium 的 37.6% 升到 High 的 45.3%、Xhigh 的 49.1%，对应单任务均价 $2.48 / $6.72 / $14.19。这意味着"模型选型"正在变成"模型 × 预算档位"的二维选型。
  • 成本下降来自定价与 token 效率两条线。 标准价下调 20%，缓存读取降至 $0.20/百万 token；官方同时称部分难题在 Medium 档即可完成且消耗 token 少于 5.1，因此实际账单降幅可能超过 20%。Batch API 再半价（$4/$20），Fast 模式则以 2 倍价格换最高 2.5 倍生成速度。
  • 安全侧的可量化指标。 Mythos 5.2 在自家漏洞评估中重新发现 89.6% 的已知漏洞（5.1 为 78.3%）；在"沙箱外放置凭据/文件"的越界测试中，越界使用比例为 3.1%（5.1 曾高达 21%，Opus 5.5 为 3.3%）。

实验结果：

影响分析：

  1. "贵模型"的用法正在改变。 官方自己建议多数编码与知识工作仍用 Opus 5.5，Fable 只在"跨陌生代码库迁移、多轮诊断仍失败的疑难 bug"这类高价值任务上接管，或作为便宜模型的"顾问"（advisor）被按需调用。这对企业落地很实际：不是全员换旗舰，而是把旗舰放在失败成本最高的环节。
  2. 安全能力开始按行业定价。 Mythos 的白名单机制说明前沿模型正在分化出"受监管版本"，与纽约州 AI 安全法生效、Anthropic IPO 披露同周出现，合规不再是附加项而是产品结构的一部分。
  3. 多 Agent 协作从演示走向工程验证。 约 1000 个 Agent 在 30 小时内完成费马大定理现有证明的 Lean 形式化，Opus 团队同期只完成约 27%；另一组生物实验用 Mythos 配合两个蛋白折叠工具，在 34 个衣壳结构中正确预测 28 个。关键不是"Agent 数量"，而是任务本身可被 Lean 逐步校验——可验证的中间信号才是大规模协作的前提。

2. 腾讯混元 Hy4 正式发布：770B 总参 / 49B 激活、1M 上下文，首次原生视觉 + 电脑操作（CUA）

一句话概要： 腾讯在世界互联网大会乌镇峰会交出混元 Hy4 正式版：MoE 架构 770B 总参数、49B 激活参数，上下文突破 1M，首次引入原生视觉理解与计算机使用（CUA）能力，模型权重将于近期开源，官方定位"跻身全球开放权重第一梯队"。

技术要点：

  • 参数与上下文。 总参 770B、激活 49B，属于"大知识、小计算"的稀疏 MoE 路线；1M 上下文使其可吞下完整代码仓库或长文档集，Terminal Bench 2.1 得分 85.4（官方口径）。
  • 原生视觉而非外挂编码器。 视觉能力直接进入主模型，实测可在 28 亿像素航拍图中定位约 2 米的屋顶构件；在"照着一张设计截图复刻网页"的任务中，能读取配色、字体、布局甚至侧栏像素宽度，裁切工具偏差时改用像素分析定位线条与颜色。
  • CUA（Computer Use）落地。 模型可看屏幕、找工具、选颜色并控制鼠标，演示中在 Chrome 的 JS Paint 里临摹表情包并录屏；同时可操作 Blender、CAD 等专业软件。
  • 训练侧专项。 前端优化细化到复杂交互、业务逻辑、状态管理与前后端联动；办公场景专项优化时效检索、多源整合与事实一致性校验；金融方向用真实场景构建数千工作空间、上万任务，并由 213 位专家（七成来自外部头部金融机构、五年以上经验）参与众测。

实验结果：

  • 幻觉与推测错误显著下降：内部测试中幻觉率由 preview 版 12.95% 降至 7.2%，推测类错误率由 23.1% 降至 5.6%。
  • 金融任务：579 个真实金融任务综合表现居开源模型第一。
  • 长程科研任务：面对含 699 万个单细胞、84 张无时空标记的小鼠胚胎二维切片（含镜像翻转噪声），在离线、无专用配准工具、无细胞类型标注条件下，1.5 小时零人工干预完成空间对齐与三维网格重构，对齐精度超过专业配准工具默认配置。
  • 数学研究：与北大数学团队合作中找到 Méndez–Pinto–Villarreal 猜想的反例，提出新条件完善猜想并完成 Lean 形式化验证。
  • Agent 交付自检：网页播放器任务首轮 51 项测试过 48 项，自主定位到"列表播完最后一首再点下一首"的边界 bug 并修复，最终 59 项全通过、控制台零报错。

影响分析：

  1. 开源权重的"能力上限"被再次抬高。 此前开源阵营在长程 Agent 与 CUA 上普遍落后闭源，Hy4 把"边做边自检、失败重试"的交付模式做进模型本体，意味着企业自建 Agent 的起点不再是"能调工具"，而是"能验收"。
  2. 视觉原生 + CUA 的组合有明确业务价值。 从设计稿还原页面、按平面图生成可交互 3D 场景、批量处理图片工具，都对应真实外包与内部工具需求；对电信类企业，类似的"看截图操作老系统"正是大量存量流程自动化的入口。
  3. "自检—回归—交付"是可复用的工程范式。 拉起无头浏览器、逐按钮点击、截图做视觉 diff、失败后改代码重跑，这套流程不依赖模型厂商，任何 Agent 平台都可以照搬为自己的验收基线。

3. NeurIPS 2026｜DGP：打通全部 ViT 与 LLM 层，让每个语言层按需"翻阅"视觉层级

一句话概要： 西北工业大学与香港科技大学提出动态门控路径 DGP（Dynamic Gated Pathways），把"用哪个 ViT 层"的老问题改写成"ViT 的哪一层应该连接到 LLM 的哪一层"，让每个语言层根据当前图像—问题上下文，对全部视觉层动态分配融合权重。

技术要点：

  • 问题定位。 主流多模态模型只取 ViT 最后一层或倒数第二层，投影后一次性注入 LLM，之后所有语言层共享同一份固定视觉表示。但读菜单价格依赖局部纹理与文字细节，理解画作历史意义依赖高层语义，而 ViT 浅层保留边缘/颜色/纹理、中层表达物体结构、深层偏向抽象概念——用一层应付所有问题本身就是信息瓶颈。
  • 路由机制三步走。 ① 在图像与问题之后、首个答案 token 之前插入可学习 glimpse token，用各 LLM 层中该 token 的隐藏状态作为查询（表达"这一层现在想找什么"）；② 取各 ViT 层 [CLS] 表示映射到 LLM 隐空间作为键/值，经共享多头交叉注意力 + 每层独立路由 MLP + Softmax，得到覆盖全部 ViT 层的权重；③ 在相同 patch 位置加权求和，经该层专属投影器与可学习标量门控，以残差写回视觉 token。
  • 熵正则防塌缩。 预训练阶段对每个 LLM 层在一个 batch 上的平均路由分布做熵最大化（系数 0.01），鼓励探索各视觉层；指令微调阶段关闭，让路由专门化到任务所需粒度。约束的是 batch 平均分布，单个样本仍可形成明确偏好。
  • 不是"更多层简单平均"。 全层均匀平均会明显掉点，这是论文最有说服力的消融。

实验结果：

  • LLaVA-1.5-7B 上 11 项指标全部超过基线：SQA-I 66.8 → 71.0（+4.2）、MM-Vet 30.5 → 33.8（+3.3）、VizWiz 50.0 → 53.1（+3.1）、LLaVA-Wild 63.4 → 66.5（+3.1）；13B 配置 11 项中 10 项提升（VizWiz +3.8、MMBench +2.4、GQA +2.2）。
  • 跨架构复现：Qwen3-VL-2B 的 SQA-I 85.3 → 86.9；LLaVA-NeXT 的 SQA-I 69.5 → 72.3、MMBench 66.5 → 68.7。
  • 消融（7B）：均匀平均 24 层使 MM-Vet 30.5 → 25.3、MMBench 64.3 → 57.6、LLaVA-Wild 63.4 → 56.3；加入动态门控回升到 32.4 / 65.6；再加熵正则达 33.8 / 66.7，SQA-I 70.5 → 71.0。
  • 开销：7B 增加 5.29% 参数、4.07% FLOPs，峰值显存基本不变；13B 参数 +4.27%、显存 +4.13%。
  • 路由可视化：中间 ViT 层整体更常被激活，但浅层/深层会被特定语言层选中；同一张图只换问题，权重会从浅层（颜色、小区域细节）移向中深层（画作身份、动作语义）。

影响分析：

  1. 多模态瓶颈可能不在"看得更多"，而在"接线方式"。 过去两年大量工作堆视觉编码器、分辨率与数据，DGP 提示另一条性价比更高的路径：不改编码器，只改跨模态连接拓扑，就能在 OCR、细粒度感知、幻觉类基准上同时涨点。
  2. 工程上可渐进落地。 模块只增加约 5% 参数，适合在现有 VLM 上做增量微调而非重训；对需要"读小字 + 理解整图"的票据、工单截图、设备铭牌识别场景，收益方向明确。
  3. 边界要讲清楚。 验证集中在 7B/13B 与 LLaVA-1.5 / Qwen3-VL-2B / LLaVA-NeXT，30B 以上、更大分辨率与更大语料尚未系统验证；全层动态连接的计算随层数与分辨率增长的扩展效率仍是开放问题。

来源：机器之心（新浪转载） ｜ 论文 arXiv:2611.06844 ｜ 代码

4. SwarmEvolve：数百 Agent 在隐空间"心灵感应"，8B 小模型 3–8 分钟达到别人 60 分钟的成绩

一句话概要： 布朗大学团队提出 SwarmEvolve，让数百个低成本 Agent 组成"蜂群"，不生成自然语言思考链，而是在隐空间直接推理、通过传递 KV Cache 共享想法，用 8B 级模型在数学发现与科学计算任务上追平甚至超过前沿大模型驱动的 AlphaEvolve。

技术要点：

  • 把"说话"从进化搜索里删掉。 传统 LLM 进化搜索每轮都要生成大段 Chain-of-Thought 再让另一个 Agent 阅读理解，延迟与 token 成本高；SwarmEvolve 让 Agent 在隐空间形成方案，直接把内部状态（KV Cache）传给同伴，省去"想—写—读—再想"的翻译损耗。
  • 新颖性过滤器。 用隐向量的距离直接度量想法差异，只保留最有创意的个体，替代"重复采样多次以维持种群多样性"的笨办法。
  • 隐空间交叉（Latent Crossover）。 把多个蜂群成员的 KV Cache 合并，交给一个"总结者 Agent"完成思想融合，交叉操作不再经过语言层。
  • 成本结构改变。 并行的是大量小模型而非单个大模型，单轮迭代成本低，靠"宽度"换"深度"。

实验结果：

  • 21 个数学发现与科学计算问题（含二维对流扩散方程数值求解）上平均得分最高。
  • 中位数 3–8 分钟达到其他 SOTA 框架约 60 分钟的成绩，约一个数量级加速。
  • 使用 Qwen3 8B 即可超过 AlphaEvolve 用前沿大模型首次发现的解。

影响分析：

  1. "隐空间通信"可能是多 Agent 系统的下一个效率拐点。 当前主流 Agent 协作靠自然语言消息总线，信息密度低、延迟高；KV Cache 级别的共享在工程上受限于模型同源与显存带宽，但在"同一基座模型 + 同构 Agent"的集群里是可实现的。
  2. 小模型 + 大种群 vs 大模型 + 单链推理，是一条值得下注的分支。 对算力有限、又需要搜索式优化的团队（排产、参数调优、算子自动生成），这条路比"买更多旗舰 token"更现实。
  3. 可验证性仍是前提。 论文任务都有明确的数值或形式化目标函数，蜂群才能判断优劣；开放域创意任务上"隐空间交叉"是否同样有效，尚未验证。

来源：arXiv:2611.08483 ｜ 中文深度解读

5. Scientist World：把 1000 篇论文变成 1000 个可运行环境，前沿 AI 科学家 74% 情况下超越原作者

一句话概要： 论文提出 Scientist World，用全自动流水线把每篇论文转成"可运行的实验环境"（提取开放问题、复现基线、搭建评测），让 AI 科学家与人类原作者在同一环境中同场竞技；首批 1000 个环境上，前沿 AI 在 74% 的情况下超过原作者。

技术要点：

  • 解决"可读但不可运行"。 此前 AI 科学家能读论文、看代码，却缺少可动手实验的世界；该工作把论文从"文本"变成"环境"，让想法可以被执行和比较。
  • 三重身份。 考场（评测 AI 科研能力）、档案馆（记录 6400 小时研究轨迹：每个想法、每次实验、每次失败）、训练场（用成功经验训练更小的模型）。
  • 全自动流水线。 研究问题抽取 → 基线方法复现 → 评测环境搭建，三段串成闭环，规模化的瓶颈从"人工搭环境"变成"论文可复现性"。

实验结果：

  • 前沿 AI 科学家在 74% 的环境里超越人类原作者。
  • 记录 6400 小时研究痕迹，形成目前规模最大的"AI 如何做科研"轨迹集。
  • 用这些轨迹训练小模型，研究创意能力提升 158%。

影响分析：

  1. 科研 Agent 的评测标准从"答题"转向"做实验"。 benchmark 分数高不代表能提出可验证的新假设；用原作者作为基线是更硬的对照。
  2. 6400 小时轨迹可能比榜单更有价值。 它提供了"失败—修正"的中间过程，是训练科研 Agent 的稀缺数据，也可用于分析 AI 在哪些环节系统性犯错。
  3. 局限同样明显。 环境质量取决于论文可复现性，偏实验科学、偏计算的工作更易被覆盖；"74% 超越"是特定任务集上的结论，不宜外推为"AI 已能替代科研人员"。

来源：arXiv:2611.08478 ｜ 中文深度解读

6. 面壁 MiniCPM-V 4.7：35B-A3B 多模态模型装进手机，3GB 内存跑出 30+ token/s

一句话概要： 面壁智能展示 MiniCPM-V 4.7 的 35B-A3B 版本：总参 350 亿、每 token 仅激活 320 个专家（占 3.1%），通过专家权重存闪存 + 前瞻专家调度（LES），在 iPhone 18 Pro Max 上以约 3GB 运行内存实现 20.51 token/s，LES 2.0 已超过 30 token/s。

技术要点：

  • MoE 稀疏化是端侧扩容的关键。 32.2B 专家权重、10240 个专家，占全部参数 93.6%；每 token 只用 320 个，大量暂不使用的专家权重放在手机闪存中按需加载，内存占用压到原来的 1/15。
  • LES（前瞻专家调度）解决闪存带宽瓶颈。 按需读取方案原本只有 2–3 token/s；LES 提前预测下一层可能调用的专家，在当前计算未结束时就预加载，配合存储布局、分层量化与解码优化，速度从 3.38 token/s 提升到 20.51 token/s。
  • 视觉侧同步优化。 LLaVA-UHD v4 把压缩过程前移到视觉编码器内部，减少 55.8% 的视觉编码计算量，同时维持或改善评测表现。
  • 双尺寸策略。 35B-A3B 提升能力上限，1B 版本覆盖千元级机型（4.6 的 1B 已在部分千元机流畅运行）。

实验结果：

  • iPhone 18 Pro Max：约 3GB 内存、20.51 token/s 解码，LES 2.0 超 30 token/s。
  • 飞行模式下可识别家庭用电表格、估算各电器月耗电并对比节电方案；面对估算与实际账单差额，能指出信息不足而非编造原因。
  • 功耗目前大致相当于一款大型手游，目标是降到接近长时间听歌的水平，以便常驻运行。
  • 开源项目累计 GitHub 星标超 17 万，模型下载超 7000 万次。

影响分析：

  1. "端侧只能跑小模型"的判断正在失效。 35B 级 MoE 在手机上可用，意味着隐私敏感（通话录音、家庭对话、车内摄像头）与弱网场景（隧道、地下车库）可以本地闭环，云端只兜底复杂推理。
  2. 端云分工将按"任务复杂度 × 隐私等级"重划。 高频、实时、敏感的任务下沉，复杂逻辑上云；这对客服、装维等一线场景的离线辅助很有参考价值。
  3. 速度标准已被明确。 8 token/s 不卡、15 token/s 流畅是团队给出的用户感知阈值，30 token/s 已超出阅读速度，后续竞争点转向功耗与首字延迟。
