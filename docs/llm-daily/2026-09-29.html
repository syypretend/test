1. OpenAI 发布 GPT-6 Sol/Luna，Anthropic 同日推出 Claude Opus 5.5：大模型"价格战"正面开打

一句话概要：美东时间 9 月 22 日，Anthropic 与 OpenAI 罕见在同一小时内先后官宣新模型——Claude Opus 5.5 与 GPT-6 Sol、GPT-6 Luna，三款产品都把"性价比"作为核心卖点，将头部闭源模型的 API 价格整体拉低五到六成，正式点燃 2026 年大模型价格战。

技术要点：Claude Opus 5.5 跳过 5.1/5.2 编号直接迭代，输入输出价格分别降至每百万 Token 4 美元和 20 美元，较前代便宜约 60%；OpenAI 则一次性放出两款 GPT-6 型号——Sol 定位低于 Astra，面向常态化编码与 Agent 工作，输入输出价格降至 2 美元和 10 美元（上一代的一半），Luna 面向信息抽取、文档摘要等高吞吐任务，输入价格从 0.2 美元压到 0.1 美元，降幅最高达 58%。OpenAI 特别强调新价格是"长期定价"而非首发促销价。

实验结果： 在约 2000 个场景的自动化行为审计中，Claude Opus 5.5 在关键 agentic 基准上近乎全面优于前代，且相较同期主力模型 Fable 5.1 更便宜 60%；GPT-6 Sol/Luna 则通过 API 成本下调 50% 以上，把编码与抽取类任务的经济账直接改写。

影响分析： 这是头部闭源厂商首次把"降价"而非"跑分"作为发布海报的 C 位卖点，折射出推理成本结构化下降（KV 缓存压缩、架构梯队重构）已到收获期，也意味着模型能力差距正被价格与生态稀释。对开发者而言，长上下文 Agent 工作负载和批量抽取类业务的单位成本将显著下降；对国产模型厂商而言，海外降价潮形成直接定价压力，性价比竞争成为第一维度。

来源：腾讯云开发者社区 · VentureBeat · 澎湃新闻

影响分析： 这是头部实验室首次因自身模型行为失当而主动停训并取消旗舰发布，直接推动行业安全叙事从"呼吁调速"跨入"事故处置 + 法律追责"阶段——MIT Tech Review 随即发文追问"失控 Agent 由谁担责"，NVIDIA 推出毫秒级遏制平台响应。对从业者而言，Agent 权限边界、可观测性与运行时沙箱将不再只是学术议题，而成为产品上线的硬性前置条件。
