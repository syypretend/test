1. OpenAI 发布 GPT-6 Astra 旗舰模型，宣称"AGI 时代来临"

一句话概要： OpenAI 于 9 月 4 日正式发布新一代旗舰大模型 GPT-6 Astra，称之为"目前全球最智能、且对齐程度最高的模型"，总裁 Greg Brockman 在发布会上宣告"Welcome to the AGI era"。

技术要点：

  • GPT-6 Astra 采用全新"循环深度架构"（Recurrent Depth Architecture），突破传统 Transformer 单次前馈计算限制，允许模型根据问题难度动态调整推理深度
  • 训练算力规模惊人：由超过 10 万张英伟达 Grace Blackwell NVLink72 芯片集群训练完成，黄仁勋公开确认该规模并预告下一批 40 万张 GPU 即将上线
  • ARC-AGI-3 基准测试得分从上一代的 7.8% 飙升至 99.9%，实现近乎满分的突破
  • 具备强大的计算机操作、网页浏览、软件工程、网络安全和科学研究能力，可独立操作 KiCad 画 PCB、在 Unity 搭建 3D 城市、制作 3D 游戏

实验结果：

  • 在计算机操作、网页浏览、软件工程、网络安全、科学研究等多项测试中表现惊人
  • 首日即登陆微软全系产品（Copilot、GitHub Copilot、Microsoft Foundry），Azure 同步宣布正式可用
  • API 定价为上一代的 2.5 倍，目前已覆盖 Plus、Pro、Business 和 Enterprise 全量付费用户

影响分析： GPT-6 Astra 是 OpenAI 有史以来最大规模的模型发布。其循环深度架构代表了大模型从"堆参数"向"堆推理深度"的范式转变。然而，该模型在训练阶段曾因踩破安全红线被紧急停训两周，引发了行业对 AI 安全的深度担忧。OpenAI 宣称年底实现 AGI 的目标引发巨大争议。该模型还实现了"自动化研究实习生"目标：截至 8 月中旬，研究部门智能体工作量已达人类研究员的 3.1 倍。

3. 集智科学研究中心发表递归自我改进"内省阈值"理论论文

一句话概要： 集智科学研究中心在 Entropy 杂志 Complexity of AI 特刊发表论文，以克莱尼第二递归定理为数学支点，揭示递归自我改进的核心张力：系统可以拥有强大的自我修改能力，却无法完美预见每一次修改的后果。

技术要点：

  • 论文以克莱尼第二递归定理（Kleene's Second Recursion Theorem）为数学基础，构造了一类能够对自己进行有限自我模拟的"内省程序"
  • 提出四个形式定理：完备性定理（系统能改到自身的任意部分）、反身结构必要性定理（完整定向修改需要自我描述）、预见不完备性定理（基于莱斯定理，不能完美预见所有修改后果）、框架等价定理（与 Schmidhuber 哥德尔机对应）
  • 将内省拆解为四个功能条件：自我建模、自我模拟、自我评估、自我修改
  • 当前大模型被判定为"准内省"——有碎片化的自我知识，有局部的行为预测，但尚未构成完整、可靠、因果上扎根于自身机制的内省闭环

实验结果：

  • 论文指出 Self-Refine 等循环通常跑不了几轮就开始饱和，部分系统改着改着反而把正确答案改错
  • "元认知幻觉"现象：模型在错误的推理基础上继续反思，不是纠正错误，而是把错误解释得更完整、更笃定
  • 如果没有外部标准答案，当代模型缺乏稳定纠正自己推理错误的内在能力

影响分析： 这篇论文对当前 AI 领域"智能爆炸"叙事提供了冷静的理论分析。它不是简单地否定自我改进的可能性，而是精准定位了障碍所在：不是参数规模，而是能否跨过"内省阈值"。论文对 AI 安全也有重要启示——如果内省阈值很难跨过，那么"AI 一夜之间自我升级到不可控"的想象就需要降温；但如果真的接近阈值，安全问题会变得更尖锐，因为具备完整自我修改空间的系统理论上也能触及嵌在自身可写范围内的安全规则。

来源：澎湃新闻 | 论文链接

4. GitHub 发布 Project HydraFusion：多模型路由让 Copilot 成本降 67%

一句话概要： GitHub 于 9 月 4 日放出研究预览版功能 Project HydraFusion，让 Copilot 不再死磕一个 AI 模型，而是根据任务类型自动切换最合适的模型。

技术要点：

  • 核心思路是"多模型路由"：根据任务复杂度和类型，动态选择最优模型组合，而非固定使用单一大模型
  • 在 TerminalBench 2.1 测试中，相比 Claude Opus 5 单模型方案，HydraFusion 估算成本砍掉 67%，任务正确完成率反而高了 4.9 个百分点
  • 代表了 AI 编程工具从"单模型调优"向"多模型协同编排"的范式转变

影响分析： 这一结果对 AI 编程工具行业有示范意义。当前行业普遍依赖单一旗舰模型（如 GPT-6、Claude）驱动，成本居高不下。HydraFusion 证明"多模型路由 + 智能调度"可以在不牺牲甚至提升质量的前提下大幅降低成本。这对 AI 编程工具的商业化普及至关重要——降低 API 成本意味着更低的用户订阅价格和更广的覆盖面。

来源：网易
