1. 腾讯混元开源 Hy4 preview：770B 总参数、1M 上下文，稳居开源第一梯队

8 月 28 日，腾讯混元发布并开源新一代旗舰大模型 Hy4 preview。这是姚顺雨带队重建地基后交出的首份答卷，直接以"大身体、小开销"的 MoE 架构搅动国产开源模型格局。

技术要点：

  • 总参数 770B、激活参数仅 49B 的稀疏 MoE 架构，单次推理只激活约 6.4% 参数，兼顾能力上限与推理成本
  • 上下文长度突破 1M（100 万 token），配合缓存命中 0.3 元/百万 token 的低价策略，显著降低长文档场景门槛
  • 与 CodeBuddy、WorkBuddy 等腾讯内部生产力产品深度协同，用软件工程、游戏、金融、安全等领域的高质量共建数据做预训练与后训练
  • 权重已在 HuggingFace、GitHub、ModelScope 与 GitCode 等多个平台同步开源

实验结果（据官方公告与媒体报道）：

维度 Hy4 preview 说明
总参数 770B 国产开源第一梯队
激活参数 49B 单 token 推理开销可控
上下文 1M 突破百万 token
缓存命中价 0.3 元/百万 token 长上下文场景成本优势

影响分析：

腾讯混元此前一直以"全尺寸开源"策略推进，Hy4 preview 的发布使其首次进入 700B 级开源俱乐部，与阿里 Qwen3.8-Max、DeepSeek V4 系列正面竞争。对开发者而言，49B 激活参数意味着单卡或多卡消费级硬件上部署大模型成为可能，1M 上下文则为代码库级理解、长文档分析提供了实用窗口。

值得注意，Hy4 preview 只是 preview 版本，正式版性能与稳定性仍待验证；其"参与造了自己"（模型辅助数据生产）的自我优化路线，也提示开源模型迭代将越来越依赖模型自身参与训练数据生产。

2. 智谱 GLM-5.3-Flash：首个原生多模态 GLM-5 模型，稀疏+线性注意力混合架构开源

8 月 26 日晚，智谱 AI 上线并开源 GLM-5.3-Flash（320B-A18B），这是 GLM-5 系列的首个原生多模态模型，也是智谱在"大基座+极致效率"路线上的关键一步。

技术要点：

  • 总参数 320B、激活参数仅 18B（A18B），MoE 架构；官方宣称能力全面超越参数量高出一倍的 GLM-5.2
  • 首个开源"稀疏注意力 + 线性注意力"混合架构模型，注意力计算量相比 GLM-5.3 降低 3 倍，显著压缩显存与带宽压力
  • 原生多模态：视觉编码 + Coding 能力一体，1M 上下文
  • MIT License 开源，权重与推理实现同步放量，并与壁仞、商汤等国产芯片/算力平台完成适配验证

实验结果（据官方公告与媒体报道）：

指标 GLM-5.3-Flash 对照
AA 综合智能指数 57 分 与 Claude Opus 4.8 持平
总参数/激活参数 320B / 18B 推理成本大幅低于同级
上下文 1M 长文档场景友好

影响分析： GLM-5.3-Flash 的混合注意力架构是国产模型首次以"稀疏+线性"混合注意力公开开源，直接把注意力计算量压缩 3 倍，为国产算力（壁仞、商汤等）的推理适配提供了标准范式。对于开发者，18B 激活参数 + MIT 开源意味着低门槛、低成本的多模态 Agent 落地；其"AA 指数 57 分与 Claude Opus 4.8 持平"的第三方测评结果，也表明国产开源模型已进入全球前沿能力区间。

局限在于：混合注意力架构的稀疏/线性部分在极长上下文上的长尾稳定性仍需社区复现验证；AA 指数侧重综合智能，具体业务场景的差异仍需实测。

4. Anthropic 发布模型硬件标准 MHS，首次公开进军物理 AI 领域

8 月 27 日，Anthropic 以研究预览形式发布 Model Hardware Standard（MHS），被视为继 MCP（2024 年底的"AI 界 USB-C"）之后，Anthropic 第二次发布全行业统一协议——这次把 Agent 从软件世界延伸到物理世界。

技术要点：

  • MHS 是一套面向物理设备的 AI Agent 接口标准，让 Agent 能安全地发现、连接和操作显微镜、液体处理器、机械臂等科研与先进制造设备
  • 首批应用面向科研实验室与先进制造场景：设备可并行接入，Agent 任务从常规药物发现实验延伸到量子计算机激光校准
  • 与 MCP 一脉相承：MCP 统一了 Agent 调用外部工具/数据源/API 的方式，MHS 把同样的逻辑延伸到物理设备
  • 研究预览形式发布，意味着协议仍在演进期，Anthropic 将收集产业反馈迭代

影响分析： Anthropic 从 MCP 到 MHS 的路径，表明头部厂商正在争夺"Agent 与物理世界交互"的协议制高点。对工业界而言，MHS 若成为事实标准，将大幅降低物理设备接入 AI Agent 的集成成本（从"每个设备定制驱动"变成"一套标准接口"），加速具身智能、机器人、自动化实验室的落地。对开发者来说，可提前研究 MHS 规范，为后续物理 AI 应用做技术储备。局限在于：研究预览阶段的安全性评估、设备生态覆盖度仍需时间验证。
