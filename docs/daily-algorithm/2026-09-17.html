树状数组（Binary Indexed Tree / Fenwick Tree）

类别：数据结构 | 难度：中等

算法简介

树状数组（Binary Indexed Tree，简称 BIT），由 Peter M. Fenwick 于 1994 年提出，是一种以极简代码高效维护"前缀信息"的数据结构。它的核心思想是：将原数组 $ a[1..n] $ 的信息按二进制低位（lowbit）分段，存进一个辅助数组 $ c[i] $，其中 $ c[i] $ 恰好覆盖区间 $ [i-\text{lowbit}(i)+1,\ i] $ 的和。于是"单点更新"和"前缀和查询"两个操作都能在 $ O(\log n) $ 时间内完成，空间仅需 $ O(n) $，且常数极小、代码通常不超过 20 行。相比朴素数组（更新 $ O(1) $ / 查询 $ O(n) $）和前缀和数组（更新 $ O(n) $ / 查询 $ O(1) $），树状数组把两者折中到 $ O(\log n) $，非常适合"频繁修改 + 频繁区间求和"的动态场景。它还能扩展出区间加/单点查（差分版）、区间加/区间查（双 BIT）以及求逆序对、动态第 K 大等高级用法。

原理示意图

数学公式

1. lowbit 定义

$$ \text{lowbit}(x) = x \;\&\; (-x) $$

变量解释：

  • $ x $：正整数下标（$ 1 \le x \le n $）
  • $ \& $：按位与运算
  • $ -x $：$ x $ 的补码（二进制取反加一），因此 $ x \&\; (-x) $ 恰好保留 $ x $ 二进制中最低位的 1

2. 管辖区间

$$ c[i] = \sum_{k = i-\text{lowbit}(i)+1}^{i} a[k] $$

变量解释：

  • $ c[i] $：树状数组第 $ i $ 个节点存储的区间和
  • $ a[k] $：原数组第 $ k $ 个元素（下标从 1 开始）
  • $ \text{lowbit}(i) $：节点 $ i $ 管辖的元素个数（区间长度）

3. 前缀和查询

$$ \text{sum}(i) = \sum_{k=1}^{i} a[k] = \sum_{j \in \{i,\ i-\text{lowbit}(i),\ \ldots\}} c[j] $$

变量解释：

  • $ \text{sum}(i) $：前 $ i $ 项前缀和
  • $ j $：沿 $ j \leftarrow j-\text{lowbit}(j) $ 路径上的节点集合（终止于 0）
  • 路径长度不超过 $ \log_2 n + 1 $，故单次查询 $ O(\log n) $

4. 单点更新

$$ a[i] \leftarrow a[i] + \delta \;\Longrightarrow\; c[j] \leftarrow c[j] + \delta,\quad j \in \{i,\ i+\text{lowbit}(i),\ \ldots\} $$

变量解释：

  • $ \delta $：第 $ i $ 个元素的增量（可为正负）
  • $ j $：沿 $ j \leftarrow j+\text{lowbit}(j) $ 路径上所有管辖到 $ a[i] $ 的节点（终止于 $ >n $）
  • 路径长度同样 $ \le \log_2 n + 1 $

5. 区间查询

$$ \text{rangeSum}(l, r) = \text{sum}(r) - \text{sum}(l-1) $$

变量解释：

  • $ l, r $：查询区间左右端点（$ 1 \le l \le r \le n $）
  • 通过两次前缀查询相减得到区间和，总复杂度 $ O(\log n) $

6. 复杂度推导（为什么是 $ O(\log n) $）

令 $ n $ 为数组长度。查询时每次操作 $ i \leftarrow i - \text{lowbit}(i) $，二进制中 1 的个数严格减少 1；$ i \le n $ 的二进制位数 $ \le \lfloor \log_2 n \rfloor + 1 $，所以最多迭代 $ \lfloor \log_2 n \rfloor + 1 $ 次，时间复杂度 $ T(n) = O(\log n) $。空间上辅助数组 $ c $ 与 $ a $ 等长，空间复杂度 $ S(n) = O(n) $。

核心要点

  • 核心一句话：用 lowbit 把前缀和按二进制区间切成 $ \log n $ 段，更新和查询都只动 $ \log n $ 个节点
  • 下标从 1 开始，$ c[i] $ 管辖长度 = $ \text{lowbit}(i) $，管辖区间为 $ [i-\text{lowbit}(i)+1, i] $
  • 更新方向 i += lowbit(i)（向上爬），查询方向 i -= lowbit(i)（向左聚合）
  • 建树可用 add(i, a[i]) 循环 $ O(n \log n) $；也可用差分法 $ O(n) $ 建树
  • 通过差分数组可扩展：区间加 + 单点查、区间加 + 区间查（双 BIT）、求逆序对、求动态第 K 大
  • 与线段树相比：树状数组代码短、常数小、空间省，但只适合"可减/可结合"操作（和、积、异或），不适合区间最值与懒标记的复杂组合

技术细节与参数详解

树状数组并非模型/函数，其"参数"是操作函数中的变量与实现细节，逐项详解如下：

#### 参数 1：数组长度 n

  • 含义：原数组的元素个数（也是树状数组 $ c $ 的长度上限）
  • 类型：正整数（int）
  • 默认值：无（由输入数据规模决定）
  • 取值范围：$ 1 \le n \le 10^7 $ 量级（内存允许范围内）
  • 对结果的影响：决定 BIT 空间与所有操作的对数复杂度基准；$ n $ 越大，单次操作步数越多（$ \lceil \log_2 n \rceil + 1 $）
  • 推荐设置：申请 $ n+1 $ 大小（下标 1 基），避免越界

#### 参数 2：下标基数 1-based

  • 含义：树状数组强制下标从 1 开始，0 号单元空闲（作为查询终止哨兵）
  • 类型：实现约定
  • 默认值：必须从 1 开始
  • 对结果的影响：若从 0 开始，lowbit(0)=0 会陷入死循环
  • 推荐设置：读入数据时整体右移一位，或用 idx = 原始idx + 1 映射

#### 参数 3：lowbit(x) 函数

  • 含义：返回 $ x $ 二进制中最低位 1 对应的幂值
  • 类型：int（实现为 x & -x）
  • 默认值：无（纯函数）
  • 取值范围：$ 1 \le \text{lowbit}(x) \le x $，且必为 2 的幂
  • 对结果的影响：直接决定管辖区间划分方式——区间长度永远等于 lowbit，这是保证 $ \log $ 复杂度的根基
  • 推荐设置：优先位运算 x & -x，避免 x - (x & (x-1)) 等慢写法；注意用 unsigned/long long 防止溢出

#### 参数 4：更新增量 delta

  • 含义：单点更新时加到 $ a[i] $ 上的数值（可为负）
  • 类型：数值（int/long long/浮点均可）
  • 默认值：无
  • 取值范围：任意数值（注意累加溢出，视值域选 int64 或 double）
  • 对结果的影响：所有管辖到 $ i $ 的节点都加上 delta；传入 0 则无操作
  • 推荐设置：根据数据范围选类型，大规模统计用 long long

#### 参数 5：查询下标 i

  • 含义：前缀查询 query(i) 的目标下标（求前 $ i $ 项和）
  • 类型：正整数
  • 取值范围：$ 1 \le i \le n $
  • 对结果的影响：$ i $ 的二进制中 1 的个数决定查询步数（最坏 $ \log n $ 步）；i=n 查询整组和
  • 边界：query(0) 直接返回 0（实现需先判断）

#### 参数 6：更新越界处理

  • 风险：idx > n 时若循环条件为 i <= n 会直接跳过——用于"区间查询"类扩展时需注意边界
  • 推荐：初始化时以 i <= n 为界；若频繁更新 $ idx = n $，保证 $ n $ 为 2 的幂可减少无效判断

#### 参数 7：建树方式（初始化）

  • 方式 A（朴素）：for i in 1..n: add(i, a[i])，$ O(n \log n) $
  • 方式 B（O(n) 差分）：c[i] += a[i]，再将 c[i] 累加给 c[i + lowbit(i)]，$ O(n) $
  • 对结果的影响：不影响最终正确性，只影响初始化耗时；$ n>10^6 $ 时推荐方式 B

#### 参数 8：变体——差分树状数组（区间加 / 单点查）

  • 含义：把原数组变换为差分数组 $ d[i] = a[i]-a[i-1] $，用 BIT 维护 $ d $
  • 操作：区间 $ [l,r] $ 加 $ v $ → add(l, v); add(r+1, -v)；单点查 $ a[i] $ → query(i)
  • 效果：区间修改与单点查询均 $ O(\log n) $

#### 参数 9：变体——双树状数组（区间加 / 区间查）

  • 含义：维护 $ B_1 $、$ B_2 $ 两个 BIT，实现 $ O(\log n) $ 的区间修改与区间求和
  • 核心公式：$ \sum_{i=1}^{x} a[i] = (x+1) \cdot \text{sum}(B_1, x) - \text{sum}(B_2, x) $
  • 推荐：两棵 BIT 大小均为 $ n+1 $；实测常数约为单 BIT 的 2 倍，仍远快于线段树

代码示例

class FenwickTree:
    """树状数组：单点更新 + 前缀和查询，复杂度 O(log n)"""

    def __init__(self, n: int):
        """初始化：n 为数据规模，c 为长度 n+1 的树数组（下标从 1 开始）"""
        self.n = n              # 数组长度（最大下标）
        self.c = [0] * (n + 1)  # 树状数组本体，0 号位空置作为哨兵

    def lowbit(self, x: int) -> int:
        """返回 x 二进制中最低位 1 对应的值（管辖区间长度）"""
        return x & -x           # 补码按位与：-x 的二进制是 x 取反加一

    def add(self, i: int, delta) -> None:
        """单点更新：a[i] += delta，同步所有管辖 i 的祖先节点"""
        while i <= self.n:      # 从 i 开始向上爬，直到超过 n 为止
            self.c[i] += delta  # 当前节点累加增量 delta
            i += self.lowbit(i) # 跳到下一个管辖范围更广的祖先节点

    def query(self, i: int) -> int:
        """前缀查询：返回 sum(a[1] .. a[i])"""
        s = 0                   # 累加器初始化
        while i > 0:            # 下标降到 0 时结束（哨兵）
            s += self.c[i]      # 累加当前节点区间和
            i -= self.lowbit(i) # 向左移到下一个不重叠的覆盖区间
        return s                # 返回前缀和

    def range_sum(self, l: int, r: int) -> int:
        """区间查询：sum(a[l] .. a[r]) = 前缀(r) - 前缀(l-1)"""
        return self.query(r) - self.query(l - 1)  # 两次前缀查询相减

    def build_linear(self, a) -> None:
        """O(n) 建树：差分思想，把每个 c[i] 分发给它的父节点"""
        for i in range(1, self.n + 1):       # 遍历所有下标
            self.c[i] += a[i]               # 先将原值放入
            j = i + self.lowbit(i)          # i 的父节点下标 j
            if j <= self.n:                 # 若父节点在范围内
                self.c[j] += self.c[i]      # 累加到父节点

# 使用示例（区间查询 + 逆序对计数）
if __name__ == "__main__":
    bit = FenwickTree(8)                      # 创建长度为 8 的树状数组
    for i, v in enumerate([3, 1, 4, 1, 5, 9, 2, 6], start=1):
        bit.add(i, v)                         # 逐个单点更新建树
    print("sum(1..5) =", bit.query(5))        # 前 5 项和：3+1+4+1+5=14
    print("sum(3..6) =", bit.range_sum(3, 6)) # 区间和：4+1+5+9=19

    # 逆序对计数：边插入边统计已插入且大于当前值的个数
    counter = FenwickTree(6)                  # 值域 [1,6] 的计数树
    inv = 0                                   # 逆序对计数器
    for x in [5, 2, 6, 1, 4]:                 # 依次处理每个数
        inv += counter.query(6) - counter.query(x)  # 已插入且 > x 的数量
        counter.add(x, 1)                     # 该值出现次数 +1
    print("逆序对 =", inv)                    # 输出 5

复杂度分析

  • 时间复杂度：
  • 单点更新 add：$ O(\log n) $，因为 i += lowbit(i) 最多执行 $ \lfloor \log_2 n \rfloor + 1 $ 次
  • 前缀查询 query：$ O(\log n) $，沿 i -= lowbit(i) 路径
  • 区间查询：两次前缀查询，$ O(\log n) $
  • 建树：朴素 $ O(n \log n) $；差分法 $ O(n) $（每个元素只向父节点传递一次）
  • 空间复杂度：辅助数组 $ c $ 长度 $ n+1 $，$ O(n) $；无递归，无额外栈空间
  • 推导：$ n $ 的二进制位数 $ b=\lfloor \log_2 n \rfloor + 1 $；查询每次减掉一个 lowbit 至少消掉 1 个二进制 1，更新每次加 lowbit 保证单调，最多 $ b $ 步到终点，因此 $ O(\log n) $

应用场景

  • 动态前缀和 / 区间和（流量区间统计、传感器序列汇总）
  • 区间加 / 单点查（差分版，如多次区间染色次数统计）
  • 区间加 / 区间查（双 BIT，账目区间变动后的余额快查）
  • 逆序对计数：值域离散化后按序插入，$ O(n \log n) $
  • 动态第 K 大 / 值域统计：配合二分或倍增，实现实时 TOP K
  • 二维扩展：二维 BIT 维护矩阵子矩形和（离线 + 离散化）

Vision Transformer（ViT）

类别：计算机视觉 | 难度：困难

算法简介

Vision Transformer（ViT）是 2021 年 ICLR 论文《An Image is Worth 16x16 Words》提出的开创性模型，首次将 NLP 的 Transformer 架构原封不动地搬到图像分类任务上，证明"注意力可以替代卷积"——当数据量足够大时（如 JFT-300M 预训练），ViT 的性能可以全面超越同期的 ResNet 等 CNN 模型。其核心思想分三步：① 把图像切分成固定大小的 patch（如 16×16 像素），每个 patch 展平后经线性投影变为 token 向量；② 在序列头部拼接一个可学习的 [CLS] 分类 token，并叠加可学习位置编码；③ 送入标准 Transformer Encoder（多头自注意力 + MLP）堆叠，最后取 [CLS] token 经过分类头输出类别概率。与 CNN 的局部归纳偏置（卷积、池化）不同，ViT 从第一层就在全局计算 patch 间的注意力，依靠大规模数据学习到空间结构。它启发了后续 DeiT、Swin、DINO、CLIP 等几乎所有视觉/多模态架构。

原理示意图

数学公式

1. Patch 展平与线性投影

$$ x_p = \text{reshape}(X), \quad z_p = x_p E, \quad E \in \mathbb{R}^{(P^2 \cdot C) \times D} $$

变量解释：

  • $ X \in \mathbb{R}^{H \times W \times C} $：输入图像（高 $ H $、宽 $ W $、通道数 $ C $）
  • $ P $：patch 边长（ViT-B/16 中 $ P=16 $）
  • $ x_p \in \mathbb{R}^{N \times (P^2 C)} $：展平后的 patch，$ N = \frac{HW}{P^2} $ 个 patch
  • $ E $：可学习的 patch 嵌入矩阵（线性层权重）
  • $ z_p $：patch 嵌入向量（token），维度 $ D $（ViT-B 中 $ D=768 $）

2. 输入序列（CLS token + 位置编码）

$$ z_0 = \big[\; x_{\text{class}} \;;\; z_p^1 E \; ; \; z_p^2 E \; ; \; \cdots \; ; \; z_p^N E \;\big] + E_{pos}, \quad E_{pos} \in \mathbb{R}^{(N+1) \times D} $$

变量解释：

  • $ x_{cls} $：可学习的分类 token（与 token 同维 $ D $，拼接在序列最前）
  • $ E_{pos} $：可学习的位置编码矩阵，为每个 token 提供位置信息（1D 足够，2D/相对位置编码效果相当）
  • $ z_0 $：送入 Encoder 的输入序列，长度 $ N+1 = 197 $，每行维度 $ D=768 $

3. 多头自注意力（MHA）

$$ \text{Attention}(Q, K, V) = \text{softmax}\!\Big(\frac{Q K^\top}{\sqrt{d_k}}\Big) V, \quad Q=z W_Q,\ K=z W_K,\ V=z W_V $$

变量解释：

  • $ z $：上一层的序列表示（shape $ L \times D $，$ L=197 $）
  • $ W_Q, W_K, W_V $：查询、键、值的投影矩阵（每头维度 $ d_k = D/h $）
  • $ d_k $：缩放因子，防止点积过大导致 softmax 梯度消失
  • $ h $：注意力头数（ViT-B 中 $ h=12 $，每头 $ d_k=64 $）
  • 多头：把 $ h $ 个头的输出拼接后经 $ W_O $ 合并（Concat(heads)W_O）

4. MLP 前馈层（带 GELU）

$$ \text{FFN}(x) = \text{GELU}(x W_1 + b_1)\, W_2 + b_2 $$

变量解释：

  • $ W_1 \in \mathbb{R}^{D \times 4D} $：第一层（升维，隐藏维度为 4D）
  • $ W_2 \in \mathbb{R}^{4D \times D} $：第二层（降回 D）
  • $ \text{GELU}(x) = x \cdot \Phi(x) $：高斯误差线性单元，平滑版 ReLU
  • ViT-B 中 MLP 隐藏维 $ 4D = 3072 $

5. Encoder 块（Pre-LN + 残差）

$$ z'_l = \text{MHA}(\text{LN}(z_{l-1})) + z_{l-1}, \qquad z_l = \text{FFN}(\text{LN}(z'_l)) + z'_l $$

变量解释：

  • $ \text{LN} $：层归一化（Pre-LN 位置，先归一化再进入子层，训练更稳定）
  • $ z_{l-1}, z_l $：第 $ l $ 层输入/输出
  • 残差连接 $ \oplus $ 防止深层梯度消失

6. 分类输出

$$ y = \text{MLPHead}\big(\text{LN}(z_L^0)\big) $$

变量解释：

  • $ z_L^0 $：最后一层 Encoder 输出的 [CLS] token（第 0 个位置）
  • $ \text{MLPHead} $：线性层（或预训练时带 LayerNorm + tanh 的两层 MLP）
  • $ y $：类别概率分布（ImageNet 1000 类）

核心要点

  • 图像即序列：把图像切成 patch，每个 patch 变成一个 token，Transformer 视角下与 NLP 完全统一
  • [CLS] token 负责聚合全局信息：分类结果取自 [CLS] 的输出，不取所有 patch 的均值
  • 位置编码必不可少：没有位置信息则 patch 顺序任意排列结果相同，图像空间结构丢失
  • 归纳偏置少：无卷积的局部性/平移不变性，需要大量数据（>14M）才比 CNN 强；数据少时用 DeiT 蒸馏或 CNN 更稳
  • 全局感受野：第一层注意力就在全图 patch 间计算，长程依赖天然建模
  • 训练技巧：混合分辨率微调（如 224→384）、权重衰减、AdamW、数据增强（mixup、CutMix、RandAugment）、EMA

技术细节与参数详解

以 timm 的 vit_base_patch16_224 / HuggingFace ViTModel 为准，逐参数详解：

#### 参数 1：patch_size（patch 边长 P）

  • 含义：图像切块的边长（像素），16×16 或 32×32 等
  • 类型：int 或 tuple(int, int)
  • 默认值：16（ViT-B/16）
  • 取值范围：通常 {14, 16, 32}；需能被图像边长整除
  • 对结果的影响：$ P $ 越小 patch 越多，token 序列越长，计算量（注意力 O(L²)）越大，但细节保留更好；$ P=32 $ 的 ViT-B/32 精度明显低于 /16
  • 推荐设置：分类常用 16；需兼顾速度可 32；医疗/细粒度用 14 或更小

#### 参数 2：img_size（输入分辨率）

  • 作用：训练/推理时的输入图像边长（H=W）
  • 类型：int
  • 默认值**：224（ImageNet 标准）
  • 取值范围：任意可被 patch_size 整除的值（微调时可提升至 384/512）
  • 对结果的影响：分辨率越高，token 越多（224→196 token，384→576 token），FLOPs 与内存显著上升，精度有提升
  • 推荐设置：推理要求高分辨率时用 384（位置编码需插值）

#### 参数 3：in_chans（输入通道数）

  • 作用：输入图像通道数
  • 类型：int
  • 默认值：3（RGB）
  • 取值范围：1（灰度）~ 任意
  • 对结果的影响：改投影层输入维，需对应调整 patch_embed.proj 权重
  • 推荐设置：常规 RGB 保持 3

#### 参数 4：embed_dim（嵌入维度 D）

  • 作用：token 向量维度，即 patch 投影的输出维度
  • 类型：int
  • 默认值：768（ViT-B）；ViT-S 384、ViT-L 1024、ViT-H 1280
  • 取值范围：通常 192~1280，须可被 num_heads 整除
  • 对结果的影响：模型容量核心维度——embed_dim 越大表达能力越强，但计算与内存线性/超线性增长
  • 推荐设置：桌面级 768（Base），服务器可 1024（Large）

#### 参数 5：depth（Encoder 层数，又称 num_layers）

  • 作用：堆叠的 Transformer Block 数量
  • 类型：int
  • 默认值：12（ViT-B）
  • 取值范围：通常 6~32（ViT-L 24、ViT-H 32）
  • 对结果的影响：层数越多抽象层次越高，但过深导致训练更难、推理更慢
  • 推荐设置：12~24 为最佳精度/成本平衡

#### 参数 6：num_heads（注意力头数 h）

  • 作用：多头自注意力头的数量
  • 类型：int
  • 默认值：12（ViT-B）
  • 取值范围：4~16 常见；必须能整除 embed_dim
  • 对结果的影响：头数多可学习更多样的关系；每头维度 $ d_k = D/h $，头数过少表达受限，过多则每头维度过小
  • 推荐设置：遵循 $ D/h = 64 $ 的经验（768/12）

#### 参数 7：mlp_ratio（MLP 放大倍数）

  • 作用：MLP 隐藏层维度 = embed_dim × mlp_ratio
  • 类型：float
  • 默认值：4.0（4×768=3072）
  • 取值范围：2.0~4.0 常见
  • 对结果的影响：MLP 占 ViT 参数的 2/3 以上；ratio 小则参数少、精度下降；4.0 为验证最优
  • 推荐设置：默认 4.0；轻量模型可降为 2.0~3.0

#### 参数 8：qkv_bias（QKV 偏置）

  • 作用：Q/K/V 投影是否带偏置项
  • 类型：bool
  • 默认值：True
  • 对结果的影响：偏置利于稳定训练；bias=True 与 proj_bias 组合使用
  • 推荐设置：True（与官方权重对齐）

#### 参数 9：drop_rate（全局 Dropout 概率）

  • 作用：对 transformer block 输出施加的 Dropout
  • 类型：float
  • 默认值：0.0（预训练）；0.1（微调常用）
  • 取值范围：0~1
  • 对结果的影响：抑制过拟合；过大会欠拟合导致精度下降
  • 推荐设置：预训练 0.0~0.1，微调 0.1；数据少时可 0.2

#### 参数 10：attn_drop_rate（注意力 Dropout）

  • 作用：softmax 注意力权重上的随机失活
  • 类型：float
  • 默认值：0.0
  • 取值范围：0~1
  • 对结果影响：正则化注意力分布，防某几个 patch 主导
  • 推荐设置：0.0（预训练）/ 0.1 微调

#### 参数 11：drop_path_rate（Stochastic Depth）

  • 作用：随机深度——每个 Block 按概率整层失活（残差路径）
  • 类型：float
  • 默认值：0.0
  • 取值范围：0~1，深层模型常线性增长（0~0.1）
  • 对结果的影响：显著改善深层 ViT 训练稳定性，等价于多网络集成
  • 推荐设置：ViT-B 0.1、ViT-L/H 0.2~0.3，随深度线性递增

#### 参数 12：norm_layer（归一化层）

  • 作用：块内归一化（LN），采用 Pre-LN 结构
  • 类型：nn.LayerNorm 或其变体（RMSNorm）
  • 默认值：LayerNorm（eps=1e-6，affine=True）
  • 对结果影响：Pre-LN 使梯度更稳，无需 warmup 也能训练较深模型
  • 推荐设置：默认 LayerNorm；注意力计算可加 QK-Norm 提高数值稳定性

#### 参数 13：pos_embed（位置编码）

  • 作用：为 $ N+1 $ 个 token 提供可学习位置信息
  • 类型：nn.Parameter，形状 $ (N+1, D) $
  • 默认值：可学习 1D 正弦初始化
  • 取值范围：1D/2D/相对位置编码
  • 对结果的影响：ViT 原实验 1D 与 2D 效果几乎无差别；缺少会严重掉点；分辨率改变时需插值
  • 推荐设置：默认可学习 1D；提升分辨率时对 pos_embed 双线性插值并微调

#### 参数 14：cls_token

  • 作用：聚合全局信息的特殊 token，最终输出作为分类特征
  • 类型：nn.Parameter，形状 $ (1, D) $
  • 默认值：随机初始化可学习向量
  • 对结果的影响：分类/对比学习（CLIP）都依赖 CLS 输出；也可改为全局平均池化（与 CLS 效果相近）
  • 推荐设置：默认保留 CLS

#### 参数 15：representation_size（预分类层/ head）

  • 作用：分类前插入的全连接降维层（预训练时用）
  • 类型：int 或 None
  • 默认值：None（直接线性分类）
  • 对结果的影响：加中间层便于多任务复用（如分割/检索）
  • 推荐设置：分类任务 None；检索微调可设 768

代码示例

# 使用 timm 创建并运行 ViT-Base/16（PyTorch）
import torch                       # 深度学习张量库
import timm                        # 图像模型库（timm）

model = timm.create_model(         # 创建模型
    "vit_base_patch16_224",        # 模型名：Base/16，输入 224x224
    pretrained=True,               # 加载 ImageNet 预训练权重
    num_classes=1000,              # 输出 1000 类
    drop_rate=0.1,                 # 全局 dropout 0.1
    attn_drop_rate=0.0,            # 注意力 dropout 0
    drop_path_rate=0.1,            # 随机深度 0.1
)
model.eval()                       # 切到推理模式（关闭 dropout 等）

x = torch.randn(2, 3, 224, 224)    # 2 张 224x224x3 图像输入
logits = model(x)                  # 前向传播 → (2, 1000) 的类别得分
pred = logits.argmax(dim=-1)       # 取最大得分下标作为预测类
print(logits.shape, pred)          # torch.Size([2, 1000]) tensor([...])

复杂度分析

设 patch 数 $ N = HW/P^2 $，token 维 $ D $，层数 $ L $，头数 $ h $：

  • 单头自注意力复杂度：$ O(L^2 D) $（计算 $ QK^T $ 需 $ L^2 \cdot D $ 次乘法），其中 $ L=N+1 $；多头并行不增加总开销，总注意力为 $ O(L^2 D) $
  • MLP 复杂度：每层 $ O(L D^2) $（两次大矩阵乘法 $ D \times 4D $）
  • 总时间复杂度：$ O(L \cdot (L^2 D + L D^2)) = O(L \cdot D \cdot (L + D)) $，对 224 输入 $ L \approx 200 $、$ D=768 $ 时以 $ L \cdot D^2 $ 为主
  • 空间复杂度：存储模型参数 $ O(L D^2) $，激活内存 $ O(L^2 \cdot \text{batch} \cdot D) $（注意力矩阵）；长序列时内存易爆炸，因此新模型（Swin、Deformable）会局部化注意力或加窗
  • 与 CNN 对比：CNN 复杂度随分辨率线性增长，ViT 随分辨率平方增长（token 数平方），所以 ViT 在高分辨率下成本急剧上升

应用场景

  • 图像分类：ImageNet 1000 类、细粒度分类（鸟类/车型），与 ResNet 同级甚至更优
  • 作为视觉 Backbone：成为 CLIP、DINO、SAM 编码器的主干，广泛支撑图文检索、自监督、分割
  • 视频理解：TimeSformer / VideoMAE 将 ViT 扩展到时序维
  • 多模态统一架构：ViT+Q 与文本 token 一同送入 LLM（如 LLaVA、Fuyu）
  • 医学影像：CT/病理切片（用较小 patch 或尺度金字塔）
  • 遥感图像：检测/语义分割（Swin/DeiT 变体）

LLaVA（Large Language and Vision Assistant）

类别：多模态 | 难度：困难

算法简介

LLaVA（Large Language and Vision Assistant）由威斯康星大学麦迪逊分校 Haotian Liu 等人于 2023 年 10 月（NeurIPS 2023，论文《Visual Instruction Tuning》）提出，是"视觉指令微调"的开创性工作，常被称为多模态领域的 Alpaca 时刻。它的核心贡献有两点：① 架构极简——用一个轻量线性层（后升级为 2 层 MLP）把 CLIP 视觉编码器的输出映射到 LLM 的输入空间，将图像变成"视觉 token"拼接到文本序列中，复用冻结或部分微调的 Vicuna/LLaMA 完成图文理解与对话；② 数据方案——用纯文本 GPT-4 在 COCO 图像上"看图说话"式生成三类指令数据（对话、详细描述、复杂推理），构造了 158K 规模的 LLaVA-Instruct 数据集，实现零样本跨模态对齐。两阶段训练（先冻结双塔只训投影器做对齐，再端到端微调投影器+LLM）使得 7B 级模型即可达到媲美 GPT-4 的视觉对话效果，开启了 LLaVA 系列（1.5/1.6-NeXT）并深刻影响了 Qwen-VL、InternVL 等后续开源多模态大模型。

原理示意图

数学公式

1. 视觉特征提取

$$ H_v = \text{VisionEncoder}(X_v), \quad H_v \in \mathbb{R}^{N_v \times D_v} $$

变量解释：

  • $ X_v $：输入图像（LLaVA 中为 336×336）
  • $ \text{VisionEncoder} $：CLIP 的 ViT-L/14 视觉编码器（取倒数第 2 层输出）
  • $ H_v $：视觉特征序列，$ N_v=24\times24=576 $ 个 patch 特征，每维 $ D_v=1024 $

2. 视觉 token 投影（对齐 LLM 嵌入空间）

$$ Z_v = \text{projector}(H_v) = W_2 \cdot \text{GELU}(W_1 H_v + b_1) + b_2 $$

变量解释：

  • $ W_1 \in \mathbb{R}^{D_h \times D_v} $、$ b_1 $：第一层 MLP 权重与偏置
  • $ W_2 \in \mathbb{R}^{D_{llm} \times D_h} $、$ b_2 $：第二层 MLP 权重与偏置
  • $ D_{llm} $：LLM 词嵌入维度（Vicuna-7B 为 4096）
  • $ Z_v \in \mathbb{R}^{576 \times D_{llm}} $：映射后的视觉 token（576 个"图像词"）

3. 多模态输入序列拼接

$$ X_{\text{input}} = [\,T_1,\, Z_v,\, T_2,\, Z_v,\, T_3,\, \ldots,\, Z_v,\, T_n\,] $$

变量解释：

  • $ T_i $：文本指令 token 序列片段
  • $ Z_v $：插入到 占位符位置（原始版本把全部视觉 token 放最前）
  • 拼接后总序列长度 = 文本长度 + 576 × 图像出现次数（受 max_seq_length 限制）

4. 自回归语言建模损失（核心训练目标）

$$ L = -\sum_{t=1}^{M} \log p_{\theta}\big(x_t^{\text{ans}} \mid X_{\text{instr}},\,X_{\text{img}},\,x_{

变量解释：

  • $ X_{\text{instr}} $：问题/指令 token
  • $ X_{\text{img}} $：图像视觉 token
  • $ x_t^{\text{ans}} $：回答（target）中第 $ t $ 个 token
  • $ \theta $：可训练参数（阶段 1 仅投影器；阶段 2 投影器 + LLM）
  • $ M $：回答序列长度；只对回答部分计算损失，指令与图像部分被 mask 掉

核心要点

  • 三大组件：冻结的 CLIP 视觉编码器 + 可训练轻量投影器 + 冻结/微调的 LLM，结构极简
  • 把图像变成"词"：576 个视觉 token 拼进文本序列，LLM 把看图当成"读懂一段插入的文本"
  • 数据是灵魂：用纯文本 GPT-4 自动生成视觉指令数据（158K），是 LLaVA 成功的核心
  • 两阶段训练：先对齐特征（只练投影器），再端到端指令微调（练投影器+LLM），由粗到精
  • 回答损失屏蔽：只对回答 token 计算损失，保证"只听该听的"
  • 随机图像填充：数据构造时随机化提问位置，防止图文错位，提升对齐鲁棒性
  • 可扩展：更换更强的 LLM（LLaMA2/3、Qwen）、视觉编码器或加入高分辨率/多尺度（LLaVA-1.5/NEXT）可平滑升级

技术细节与参数详解

以 LLaVA-1.5 官方实现（HuggingFace llava-hf/llava-1.5-7b）为准，逐参数详解：

#### 参数 1：vision_tower（视觉编码器）

  • 含义：提取图像特征的预训练视觉模型
  • 类型：字符串模型名 / 模型对象
  • 默认值：openai/clip-vit-large-patch14-336
  • 取值范围：CLIP ViT-L/14 及其 224/336 版本、SigLIP、InternViT 等
  • 对结果的影响：视觉编码器质量直接决定图像理解上限；336 分辨率（ViT-L/14 336）比 224 精度更高
  • 推荐设置：默认 CLIP-ViT-L/14@336；追求更高精度用 SigLIP/InternViT（如 LLaVA-OneVision）

#### 参数 2：vision_feature_layer（取视觉编码器哪一层）

  • 含义：取 CLIP 的倒数第几层特征作为输出
  • 类型：int
  • 默认值：-2（倒数第二层）
  • 对结果的影响：倒数第一层（CLS 池化层）会丢失空间细节，倒数第二层保留 patch 级空间信息，利于理解"图中哪里"
  • 推荐设置：默认 -2；其余层可作为消融变量

#### 参数 3：vision_feature_select_strategy（视觉特征选择策略）

  • 含义：从视觉层输出中选哪部分作为 patch 特征
  • 类型：str
  • 默认值：patch（LLaVA-1.5 用 patch 而非 cls）
  • 可选值：patch（取全部 patch 特征）、cls（只取 CLS token）
  • 对结果的影响：patch 保留 576 个空间特征，cls 只有一个全局特征（几乎不用）
  • 推荐设置：patch

#### 参数 4：mm_projector_type（投影器结构）

  • 含义：把视觉特征映射到 LLM 嵌入空间的网络结构
  • 类型：字符串
  • 默认值：mlp2x_gelu（2 层 MLP + GELU）
  • 可选值：linear（单线性层）、mlp2x_gelu、更复杂（如 Q-Former 风格）
  • 对结果的影响：MLP 投影（2 层）比线性投影对齐效果更好（表达能力更强），又不会像大投影器那样过拟合
  • 推荐设置：mlp2x_gelu（LLaVA-1.5 官方配置）

#### 参数 5：mm_hidden_size（视觉特征维度）

  • 含义：视觉编码器输出特征维度
  • 类型：int
  • 默认值：1024（CLIP ViT-L/14 的 patch 维）
  • 对结果的影响：与投影器输入维一致；改视觉塔时需同步改此值
  • 推荐设置：1024（CLIP-L）

#### 参数 6：llm（大语言模型底座）

  • 含义：承接视觉 token 的 LLM
  • 类型：模型名
  • 默认值：lmsys/vicuna-7b-v1.5（或 13B）
  • 可选：LLaMA、Vicuna、Mistral、Qwen 等
  • 对结果的影响：决定生成质量、推理深度与知识广度；13B 比 7B 强但更慢更贵
  • 推荐设置：7B 用于实验/边缘，13B 用于生产

#### 参数 7：image_size（输入图像尺寸）

  • 作用：送入视觉编码器的图像分辨率
  • 类型：int
  • 默认值：336（CLIP ViT-L/14@336）
  • 对结果的影响：分辨率越高 patch 越多 token 越多、细节越丰富，但显存与延迟上升；336 是精度/成本折中
  • 推荐设置：默认 336；物体/文字密集任务可升级到 384/512（anyres 多分辨率）

#### 参数 8：图像 token 数（grid）

  • 含义：$ 336/14=24 $，即 24×24=576 个视觉 token
  • 类型：int（由图像尺寸与 patch 决定）
  • 对结果的影响：token 数直接占用 LLM 上下文窗口（最大序列长度 2048 时图像约占 28%）
  • 推荐设置：默认 576；AnyRes 多分辨率会成倍增加 token 数

#### 参数 9：lora 微调（可选）

  • 含义：是否用 LoRA 低秩适配微调 LLM 层
  • 类型：bool + rank
  • 默认值：全参微调（不启用 LoRA）
  • 对结果的影响：LoRA 显存占用大幅下降，适合单卡微调；效果略逊全参
  • 推荐设置：7B 级单卡（24GB）可用 rank=128 的 LoRA

#### 参数 10：阶段 1 训练参数（特征对齐预训练）

  • 优化器：AdamW
  • 学习率：lr=1e-3（只训投影器）
  • 批大小：128（A100 级别）
  • 训练轮数：1 epoch
  • 数据：CC3M 清洗子集 595K 图文对（Caption 式）
  • 影响：把视觉特征与词嵌入粗对齐，为阶段 2 打底

#### 参数 11：阶段 2 训练参数（端到端指令微调）

  • 学习率：lr=2e-5（投影器 1e-4 或 2e-5）
  • 批大小：16（global batch）
  • 轮数：1 epoch（158K 数据）
  • 最大序列长度：max_seq_length=2048（决定图像 token + 文本上下文上限）
  • warmup_ratio：0.03（或 warmup_steps 少部分步）
  • 梯度累积：按显存调整（gradient_accumulation_steps）
  • 冻结策略：视觉编码器完全冻结，不参与梯度更新（省显存且稳定）

#### 参数 12：mm_vision_tower_lr（视觉塔学习率）

  • 含义：是否解冻视觉编码器并以独立学习率训练
  • 默认值：不训练（冻结）
  • 对结果的影响：完全冻结可省 3-4GB 显存且训练更稳定；高级版（如 LLaVA-OneVision）会部分解冻微调视觉塔
  • 推荐设置：默认冻结；数据足够时微调最后几层可提精度

#### 参数 13：padding_side / tokenizer 设置

  • 含义：文本 padding 位置与分词器
  • 默认值：右侧 padding、Vicuna 的 LlamaTokenizer（bos/eos 处理）
  • 对结果的影响：多模态拼接时若 padding 位置错误会导致序列错位
  • 推荐：与模型卡保持一致，加载时用 use_fast=True

复杂度分析

设视觉 patch 数 $ N_v $（默认 576）、LLM 层数 $ L $、隐层维 $ D $（7B 为 4096）、文本序列长 $ S $，总序列 $ T = N_v + S $：

  • 视觉编码：ViT-L 对 336×336 图像约 1.3 GFLOPs，与 LLM 相比可忽略
  • 投影器：每 token $ O(D_v D_{llm}) $，576 token 总量很小
  • LLM 前向（推理）：单 token 约 $ O(2LD^2) $，生成 $ M $ 个 token 需 $ O(2M L D^2) $；自回归解码无法并行，延迟与 $ M $ 线性相关
  • 训练：反向传播约 2~3 倍前向，且注意矩阵 $ O(T^2 D) $，长序列时 $ T=576+2048 $ 使注意力成为瓶颈
  • 显存：7B 模型 fp16 推理约 14GB 权重 + KV cache（$ T \times D $ 每层 ×2）；训练用 LoRA 约 24-32GB，全参需 80GB（A100/H100）
  • 对比纯文本 LLM：额外开销主要是 576 个视觉 token 的注意力计算与 KV cache，$ T $ 增长约 25%（文本 2048 时）
