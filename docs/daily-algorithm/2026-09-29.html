BFS 广度优先搜索

类别：图算法 | 难度：入门

算法简介

广度优先搜索（Breadth-First Search, BFS）是一种用于遍历或搜索图（Graph）和树（Tree）数据结构的经典算法。它的核心策略是逐层扩展：从起始节点出发，先访问所有距离为 1 的直接邻居，再访问距离为 2 的节点，以此类推，如同水波从中心向外扩散。

BFS 依赖队列（FIFO）实现：将起始节点入队，每次从队首取出一个节点进行访问，将其所有未访问的邻居依次入队。这种先进先出的特性保证了节点是按照距起点的层数（距离）递增的顺序被访问的。

在无权图（所有边权重相同）中，BFS 天然保证了从起点到每个可达节点的路径是最短路径（按边数计），这一性质使其成为求解无权图最短路径、连通性判断、层级遍历等问题的首选算法。

原理示意图

数学公式

1. BFS 访问层数（距离）公式

$$ \text{dist}(s, v) = \begin{cases} 0 & \text{if } v = s \\ \min_{(u,v) \in E} \text{dist}(s, u) + 1 & \text{otherwise} \end{cases} $$

变量解释：

  • $ s $：起始节点（source vertex）
  • $ v $：当前被访问的节点
  • $ E $：图中所有边的集合
  • $ \text{dist}(s, v) $：从起点 $ s $ 到节点 $ v $ 的最短边数（无权图）
  • $ \min_{(u,v) \in E} $：在所有指向 $ v $ 的边 $ (u, v) $ 中取最小值

2. 队列规模上界

$$ |Q| \leq \min(|V|, \ \Delta(G) \cdot \text{max\_layer}) $$

变量解释：

  • $ |Q| $：队列中同时存在的最大节点数
  • $ |V| $：图中顶点总数
  • $ \Delta(G) $：图的最大度数
  • $ \text{max\_layer} $：当前最大层数

3. 时间复杂度

$$ T(V, E) = O(|V| + |E|) $$

每个顶点入队/出队各一次 $ O(|V|) $，每条边在邻接表中被检查至多两次（无向图每条边检查两次，有向图一次），故总时间 $ O(|V| + |E|) $。

核心要点

  • BFS 使用队列（FIFO）保证同层节点先于下一层被访问
  • 在无权图中，BFS 首次访问某节点时即为最短路径
  • 需要 visited 标记避免重复访问和死循环
  • 常用邻接表表示图，访问效率为 $ O(1) $ 每条边
  • BFS 可用于求连通分量、最短路径、层级遍历、二分图判定（双色法）

技术细节与参数详解

#### 参数 1：graph（图的数据结构）

  • 含义：BFS 遍历的图或树结构
  • 类型：邻接表（dict[int, list[int]]）或邻接矩阵（list[list[bool/int]]）或网格（list[list[int]]）
  • 默认值：无（必须提供）
  • 取值范围：任意有效的图结构表示
  • 对结果的影响：邻接表适合稀疏图（$ |E| \ll |V|^2 $），空间 $ O(|V|+|E|) $；邻接矩阵适合稠密图，空间 $ O(|V|^2) $
  • 推荐设置：绝大多数场景用邻接表（collections.defaultdict(list)），网格类题目用二维数组 + 方向向量

#### 参数 2：source / start（起始节点）

  • 含义：BFS 遍历的起点
  • 类型：整数（节点编号）或元组（网格坐标 (row, col)）
  • 默认值：0 或 (0, 0)
  • 取值范围：图中任意有效节点
  • 对结果的影响：起点决定遍历的起始层和访问顺序；若图不连通，只有从起点可达的节点会被访问
  • 推荐设置：根据题目要求设置；若需遍历全图，对所有未访问节点分别启动 BFS

#### 参数 3：queue（队列）

  • 含义：存储待访问节点的 FIFO 队列
  • 类型：collections.deque（双端队列）
  • 默认值：deque()
  • 取值范围：无限制
  • 对结果的影响：使用 list 的 pop(0) 会导致 $ O(n) $ 出队；deque 的 popleft() 为 $ O(1) $，是 BFS 正确且高效的实现方式
  • 推荐设置：始终使用 collections.deque，避免使用 list

#### 参数 4：visited（已访问标记集合）

  • 含义：记录哪些节点已被访问，防止重复入队
  • 类型：set()（集合）或 list[bool]（布尔数组）
  • 默认值：空集合
  • 取值范围：包含已访问的节点 ID
  • 对结果的影响：缺少 visited 标记会导致无限循环（图中有环时）；使用布尔数组比集合更高效（$ O(1) $ 查找且无哈希开销）
  • 推荐设置：节点编号连续时用布尔数组 visited = [False] n；节点编号不连续或为坐标时用 set() 或 visited = [[False]W for _ in range(H)]

#### 参数 5：level / distance（层级/距离记录）

  • 含义：记录每个节点距起点的层数（边数）
  • 类型：dict[int, int] 或 list[int]（初始化为 -1 表示未访问）
  • 默认值：{-1} 或 [-1] * n
  • 取值范围：非负整数，起点为 0
  • 对结果的影响：不记录层级时只能判断连通性；记录后可输出最短路径长度、按层级分组处理
  • 推荐设置：用 dist = [-1] * n 同时充当 visited（-1 表示未访问）和距离记录，省去单独的 visited 集合

#### 参数 6：parent / predecessor（前驱节点记录）

  • 含义：记录每个节点在 BFS 树中的父节点，用于路径回溯
  • 类型：list[int] 或 dict[int, int]
  • 默认值：[-1] * n
  • 取值范围：节点编号或 -1（无前驱）
  • 对结果的影响：不需要路径回溯时可省略；需要时从终点沿 parent 链回溯到起点即可得到最短路径
  • 推荐设置：仅在最短路径需要输出具体路径时启用

#### 参数 7：directions（方向向量，网格 BFS 专用）

  • 含义：网格图中四方向或八方向的偏移量
  • 类型：list[tuple[int, int]]
  • 默认值：[(-1,0), (1,0), (0,-1), (0,1)]（四方向）
  • 取值范围：四方向或八方向
  • 对结果的影响：四方向只能上下左右移动（曼哈顿距离）；八方向可斜向移动（切比雪夫距离）
  • 推荐设置：迷宫/最短步数问题用四方向；棋盘类问题视规则而定

代码示例

from collections import deque  # 导入双端队列，保证 O(1) 入队出队

def bfs(adj, source, n):
    """
    BFS 广度优先搜索 - 求无权图最短路径
    :param adj: 邻接表，dict[int, list[int]]，key 为节点，value 为邻居列表
    :param source: 起始节点编号
    :param n: 图中节点总数
    :return: dist 列表（dist[i] 为 source 到 i 的最短边数）, parent 列表（路径回溯用）
    """
    # 初始化距离数组，-1 表示未访问（同时充当 visited 标记）
    dist = [-1] * n
    # 初始化前驱数组，-1 表示无前驱（起点或不可达）
    parent = [-1] * n
    # 创建 FIFO 队列
    queue = deque()

    # 将起点入队，距离设为 0
    queue.append(source)
    dist[source] = 0

    # 主循环：队列非空时持续处理
    while queue:
        # 从队首取出当前节点（FIFO 保证按层级顺序访问）
        u = queue.popleft()

        # 遍历当前节点的所有邻居
        for v in adj[u]:
            # 如果邻居未被访问过（dist == -1）
            if dist[v] == -1:
                # 距离 = 当前节点距离 + 1
                dist[v] = dist[u] + 1
                # 记录前驱节点，用于路径回溯
                parent[v] = u
                # 将邻居入队，等待后续处理
                queue.append(v)

    return dist, parent


def reconstruct_path(parent, source, target):
    """从 BFS 结果回溯最短路径"""
    path = []  # 存储路径节点
    current = target  # 从终点开始回溯
    while current != -1:  # 沿 parent 链回溯到起点
        path.append(current)  # 当前节点加入路径
        current = parent[current]  # 移动到前驱节点
    path.reverse()  # 反转路径（从起点到终点）
    # 检查路径是否有效（起点是否匹配）
    if path[0] == source:
        return path
    return []  # 不可达

n = 8  # 8 个节点 (0~7)
adj = {  # 邻接表

    1: [0, 3, 4],  # B 的邻居：A, D, E

# === 网格 BFS 示例：迷宫最短步数 ===
def bfs_grid(grid, start, end):
    """
    网格 BFS 求最短步数
    :param grid: 二维网格，0=可通行，1=障碍
    :param start: 起点坐标 (row, col)
    :param end: 终点坐标 (row, col)
    :return: 最短步数，不可达返回 -1
    """
    rows, cols = len(grid), len(grid[0])  # 网格行列数
    # 四方向向量：上、下、左、右
    directions = [(-1, 0), (1, 0), (0, -1), (0, 1)]
    # visited 矩阵，标记已访问的格子
    visited = [[False] * cols for _ in range(rows)]
    queue = deque()
    # 入队起点，步数为 0
    queue.append((start[0], start[1], 0))
    visited[start[0]][start[1]] = True

    while queue:
        r, c, steps = queue.popleft()  # 取出当前格子和步数
        if (r, c) == end:  # 到达终点
            return steps
        for dr, dc in directions:  # 遍历四个方向
            nr, nc = r + dr, c + dc  # 计算新坐标
            # 边界检查 + 障碍检查 + 未访问检查
            if 0 <= nr < rows and 0 <= nc < cols and not visited[nr][nc] and grid[nr][nc] == 0:
                visited[nr][nc] = True  # 标记已访问
                queue.append((nr, nc, steps + 1))  # 入队，步数+1
    return -1  # 不可达

复杂度分析

时间复杂度：$ O(|V| + |E|) $

  • 每个顶点最多入队一次、出队一次：$ O(|V|) $
  • 使用邻接表时，遍历所有顶点的邻居列表，所有边被检查的总次数：无向图每条边检查 2 次，有向图 1 次：$ O(|E|) $
  • 合计：$ O(|V| + |E|) $

空间复杂度：$ O(|V|) $

  • dist/visited 数组：$ O(|V|) $
  • parent 数组：$ O(|V|) $
  • 队列最大长度：最坏情况（完全二叉树底层）为 $ O(|V|) $
  • 递归栈：BFS 无递归（迭代实现），栈空间为 $ O(1) $
  • 合计：$ O(|V|) $

应用场景

  • 无权图最短路径：迷宫求解、社交网络中两人之间的最短关系链

  • 连通分量统计：对每个未访问节点启动 BFS，计数连通块数量
  • 二分图判定：BFS 双色染色法，检查相邻节点颜色是否冲突
  • 网格搜索：岛屿数量、最短离岛距离、单词搜索（LeetCode 200/1091/1162）
  • 拓扑排序兼容：结合入度表的 BFS 可实现 Kahn 拓扑排序

矩阵分解推荐

类别：推荐系统 | 难度：中等

算法简介

矩阵分解（Matrix Factorization, MF）是推荐系统中核心的协同过滤技术。其核心思想是将用户-物品评分矩阵 $ R $（通常极度稀疏）分解为两个低维矩阵的乘积：用户隐因子矩阵 $ P $ 和物品隐因子矩阵 $ Q $。通过学习这些隐因子（Latent Factors），模型能够泛化预测用户对未评分物品的偏好。

经典的矩阵分解方法源自 Simon Funk 在 Netflix Prize（2006）中提出的 Funk-SVD。与标准 SVD 不同，Funk-SVD 不要求矩阵完整，而是仅利用已观测的评分进行梯度下降优化。公式为 $ \hat{r}_{ui} = \mu + b_u + b_i + p_u^T q_i $，其中 $ \mu $ 是全局平均分，$ b_u $ 和 $ b_i $ 分别是用户和物品偏置，$ p_u $ 和 $ q_i $ 是 $ k $ 维隐因子向量。

矩阵分解有效解决了传统近邻协同过滤的两大痛点：①无法利用物品本身属性信息；②处理稀疏矩阵能力弱、泛化性差。通过降维到低维隐因子空间，即使两个用户没有共同评分的物品，也能通过隐因子相似性得到合理推荐。

原理示意图

数学公式

1. 预测公式（含偏置）

$$ \hat{r}_{ui} = \mu + b_u + b_i + p_u^T q_i $$

变量解释：

  • $ \hat{r}_{ui} $：预测的用户 $ u $ 对物品 $ i $ 的评分
  • $ \mu $：全局平均评分（所有已观测评分的均值）
  • $ b_u $：用户偏置，反映用户 $ u $ 的评分习惯（偏高或偏低）
  • $ b_i $：物品偏置，反映物品 $ i $ 相对全局的水平
  • $ p_u $：用户 $ u $ 的 $ k $ 维隐因子向量（$ p_u \in \mathbb{R}^k $）
  • $ q_i $：物品 $ i $ 的 $ k $ 维隐因子向量（$ q_i \in \mathbb{R}^k $）
  • $ p_u^T q_i $：隐因子向量的内积，衡量用户偏好与物品特征的匹配程度

2. 正则化损失函数

$$ L = \sum_{(u,i) \in \kappa} \left(r_{ui} - \mu - b_u - b_i - p_u^T q_i\right)^2 + \lambda\left(\|p_u\|^2 + \|q_i\|^2 + b_u^2 + b_i^2\right) $$

变量解释：

  • $ \kappa $：已观测评分子集 $ (u, i) \in \kappa $
  • $ r_{ui} $：用户 $ u $ 对物品 $ i $ 的真实评分
  • $ \lambda $：正则化系数，控制模型复杂度，防止过拟合
  • $ \|p_u\|^2 $、$ \|q_i\|^2 $：隐因子向量的 L2 范数平方
  • 损失第一项为 MSE 重建误差，第二项为 L2 正则化

3. 梯度下降更新规则

$$ p_u \leftarrow p_u + \eta \left(e_{ui} \cdot q_i - \lambda \cdot p_u\right) $$

$$ q_i \leftarrow q_i + \eta \left(e_{ui} \cdot p_u - \lambda \cdot q_i\right) $$

$$ b_u \leftarrow b_u + \eta \left(e_{ui} - \lambda \cdot b_u\right) $$

$$ b_i \leftarrow b_i + \eta \left(e_{ui} - \lambda \cdot b_i\right) $$

变量解释：

  • $ \eta $（eta）：学习率，控制每步更新的步长
  • $ e_{ui} = r_{ui} - \hat{r}_{ui} $：预测误差
  • $ \lambda $：正则化系数
  • 每条已观测评分 $ (u, i) $ 触发一次参数更新（SGD）

4. 隐因子维度与近似误差

$$ R \approx P \cdot Q^T, \quad P \in \mathbb{R}^{m \times k}, \quad Q \in \mathbb{R}^{n \times k} $$

变量解释：

  • $ R \in \mathbb{R}^{m \times n} $：$ m $ 个用户 $ \times $ $ n $ 个物品的评分矩阵
  • $ k $：隐因子维度（远小于 $ m $ 和 $ n $），控制模型表达能力
  • $ k $ 越大 → 表达力越强但过拟合风险增加；$ k $ 越小 → 泛化越好但可能欠拟合

核心要点

  • 矩阵分解将稀疏评分矩阵分解为低维用户/物品隐因子矩阵，核心是学习隐因子使其乘积逼近已知评分
  • 偏置项 $ b_u, b_i $ 捕捉用户/物品的全局偏差，与隐因子交互项 $ p_u^T q_i $ 分离
  • 使用 SGD（随机梯度下降）逐条评分更新，无需完整矩阵，天然支持稀疏数据
  • L2 正则化是防止过拟合的关键，$ \lambda $ 需通过交叉验证调优
  • 与标准 SVD 的区别：Funk-SVD 不要求矩阵完整，仅对已观测值优化

技术细节与参数详解

#### 参数 1：n_factors（隐因子数 k）

  • 含义：用户和物品隐因子向量的维度 $ k $，决定模型的表达能力
  • 类型：整数
  • 默认值：100（Surprise 库 SVD 默认）
  • 取值范围：1 ~ 数千（典型 5~200）
  • 对结果的影响：$ k $ 越大，模型表达力越强，能捕捉更细的偏好模式，但容易过拟合且训练变慢；$ k $ 越小，模型更泛化但可能欠拟合
  • 推荐设置：小数据集 5~20；中等数据集 20~50；大数据集 50~200；通过交叉验证选择最优值

#### 参数 2：n_epochs（迭代轮数）

  • 含义：SGD 遍历全部已观测评分的次数
  • 类型：整数
  • 默认值：20（Surprise 库 SVD 默认）
  • 取值范围：1 ~ 数百
  • 对结果的影响：太少则欠拟合（损失未收敛）；太多则过拟合（训练集误差极小但测试集误差反弹）
  • 推荐设置：配合早停策略，通常 10~50 轮；大矩阵可用 20~30 轮

#### 参数 3：biased（是否使用偏置）

  • 含义：是否在预测公式中包含 $ \mu + b_u + b_i $ 偏置项
  • 类型：布尔值
  • 默认值：True（Surprise 库默认）
  • 取值范围：True / False
  • 对结果的影响：True 时自动学习全局均值、用户偏置和物品偏置，适合显式评分数据；False 时预测公式简化为 $ \hat{r}_{ui} = p_u^T q_i $，适合隐式反馈或已去中心化的数据
  • 推荐设置：显式评分推荐用 True；隐式反馈或数据已预处理好用 False

#### 参数 4：lr_all（全局学习率 η）

  • 含义：SGD 中所有参数的共同学习率
  • 类型：浮点数
  • 默认值：0.005（Surprise 库 SVD 默认）
  • 取值范围：0.0001 ~ 1.0（典型 0.001~0.01）
  • 对结果的影响：太大会震荡不收敛；太小则收敛极慢；最优值通常在 0.001~0.01 之间
  • 推荐设置：0.005 作为起点；若损失不收敛则降至 0.001；若收敛太慢可升至 0.01

#### 参数 5：reg_all（全局正则化系数 λ）

  • 含义：所有参数的共同 L2 正则化系数
  • 类型：浮点数
  • 默认值：0.02（Surprise 库 SVD 默认）
  • 取值范围：0.0 ~ 1.0（典型 0.01~0.1）
  • 对结果的影响：0 表示不正则化，容易过拟合；太大会过度惩罚参数导致欠拟合
  • 推荐设置：0.02 作为起点；交叉验证在 0.01、0.02、0.05、0.1 中选择

#### 参数 6：lr_bu（用户偏置学习率）

  • 含义：用户偏置 $ b_u $ 的 SGD 学习率
  • 类型：浮点数
  • 默认值：None（回退到 lr_all）
  • 取值范围：0.0001 ~ 1.0
  • 对结果的影响：允许对偏置项使用与隐因子不同的学习率，更精细控制收敛
  • 推荐设置：一般保持默认（等于 lr_all）；仅在调优发现偏置收敛与隐因子不同步时单独设置

    矩阵分解推荐 (Funk-SVD) —— 从零实现 SGD 训练

    损失函数: SUM((r - r_hat)^2) + lambda * (||p_u||^2 + ||q_i||^2 + b_u^2 + b_i^2)
    """

                 reg_all=0.02, biased=True, init_mean=0.0, init_std_dev=0.1):
        # 隐因子维度 k：控制模型表达能力

        self.n_epochs = n_epochs
        # 全局学习率 eta：控制每步梯度更新的步长
        self.lr = lr_all
        # 全局正则化系数 lambda：防止过拟合
        self.reg = reg_all
        # 是否使用偏置项 mu + b_u + b_i
        self.biased = biased
        # 隐因子随机初始化的正态分布参数
        self.init_mean = init_mean        # 均值，默认 0
        self.init_std_dev = init_std_dev  # 标准差，默认 0.1
        # 训练后保存的参数（fit 后填充）
        self.mu = 0.0    # 全局平均评分
        self.bu = None   # 用户偏置数组, shape (n_users,)
        self.bi = None   # 物品偏置数组, shape (n_items,)
        self.P = None    # 用户隐因子矩阵, shape (n_users, k)
        self.Q = None    # 物品隐因子矩阵, shape (n_items, k)

    def fit(self, train_ratings):
        """
        训练矩阵分解模型
        :param train_ratings: list of (user_id, item_id, rating) 三元组
        """
        # 确定用户数和物品数
        n_users = max(r[0] for r in train_ratings) + 1  # 最大 user_id + 1
        n_items = max(r[1] for r in train_ratings) + 1  # 最大 item_id + 1

        # 计算全局平均评分 mu
        self.mu = np.mean([r[2] for r in train_ratings])
        # 初始化偏置为 0
        self.bu = np.zeros(n_users)
        self.bi = np.zeros(n_items)
        # 随机初始化隐因子矩阵 P 和 Q（正态分布）
        self.P = np.random.normal(self.init_mean, self.init_std_dev, (n_users, self.n_factors))
        self.Q = np.random.normal(self.init_mean, self.init_std_dev, (n_items, self.n_factors))

        # SGD 训练循环
        for epoch in range(self.n_epochs):  # 遍历每个 epoch
            for u, i, r in train_ratings:  # 遍历每条评分记录
                # 计算预测值 r_hat
                if self.biased:
                    pred = self.mu + self.bu[u] + self.bi[i] + np.dot(self.P[u], self.Q[i])
                else:
                    pred = np.dot(self.P[u], self.Q[i])
                # 计算预测误差 e = r - r_hat
                e = r - pred
                # 更新偏置项（含正则化）
                if self.biased:
                    self.bu[u] += self.lr * (e - self.reg * self.bu[u])  # b_u 梯度更新
                    self.bi[i] += self.lr * (e - self.reg * self.bi[i])  # b_i 梯度更新
                # 更新隐因子向量（需先保存旧 p_u，因为 q_i 更新依赖旧 p_u）
                p_u_old = self.P[u].copy()  # 备份当前 p_u
                self.P[u] += self.lr * (e * self.Q[i] - self.reg * self.P[u])  # p_u 梯度更新
                self.Q[i] += self.lr * (e * p_u_old - self.reg * self.Q[i])  # q_i 梯度更新（用旧 p_u）

            # 每个 epoch 后计算训练 RMSE
            rmse = self._compute_rmse(train_ratings)
            print(f"Epoch {epoch+1}/{self.n_epochs}, RMSE={rmse:.4f}")

    def predict(self, u, i):
        """预测用户 u 对物品 i 的评分"""
        if self.biased:
            return self.mu + self.bu[u] + self.bi[i] + np.dot(self.P[u], self.Q[i])
        return np.dot(self.P[u], self.Q[i])

    def recommend(self, u, n_items, top_k=10):
        """为用户 u 生成 Top-K 推荐列表"""
        scores = []  # 存储 (item_id, 预测分) 列表
        for i in range(n_items):  # 遍历所有物品
            scores.append((i, self.predict(u, i)))  # 预测评分
        scores.sort(key=lambda x: x[1], reverse=True)  # 按预测分降序排序
        return scores[:top_k]  # 返回 Top-K

    def _compute_rmse(self, ratings):
        """计算 RMSE"""
        sq_errors = []  # 平方误差列表
        for u, i, r in ratings:  # 遍历所有评分
            err = r - self.predict(u, i)  # 计算误差
            sq_errors.append(err ** 2)  # 平方
        return np.sqrt(np.mean(sq_errors))  # 返回均方根误差

复杂度分析

训练时间复杂度：$ O(E \cdot k \cdot T) $

  • $ E = |\kappa| $：已观测评分数（非零元素数）
  • $ k $：隐因子维度
  • $ T $：迭代轮数（n_epochs）
  • 每条评分的梯度更新为 $ O(k) $（内积和向量更新各 $ O(k) $）
  • 合计：$ O(E \cdot k \cdot T) $

预测时间复杂度：$ O(k) $

  • 预测单个 $ (u, i) $ 对只需计算 $ p_u^T q_i $，即 $ k $ 维向量内积
  • 为单个用户生成 Top-K 推荐：$ O(n \cdot k + n \log n) $，$ n $ 为物品数

空间复杂度：$ O((m + n) \cdot k + m + n) $

  • $ P $ 矩阵：$ O(m \cdot k) $
  • $ Q $ 矩阵：$ O(n \cdot k) $
  • 偏置数组：$ O(m + n) $
  • 合计：$ O((m + n) \cdot k) $

  • 电影/商品评分预测：Netflix Prize 经典场景，预测用户对未看过电影的评分

  • 新闻推荐：用户-文章隐因子模型，捕捉用户兴趣偏好
  • 电商个性化推荐：用户-商品隐因子匹配，生成"猜你喜欢"列表
  • 社交网络好友推荐：用户-用户隐因子相似度推荐潜在好友
  • 广告 CTR 预估：用户-广告隐因子矩阵分解，预估点击率

CatBoost

类别：集成学习 | 难度：中等

算法简介

CatBoost（Categorical Boosting）是俄罗斯搜索引擎巨头 Yandex 于 2017 年开源的梯度提升决策树（GBDT）框架。其名称来源于 Category + Boosting，核心优势在于对类别型特征的原生高效处理。

CatBoost 的三大核心创新：

1. Ordered Target Statistics（有序目标统计）：处理类别特征时，传统方法（如 One-Hot、Label Encoding）存在目标泄露和维度爆炸问题。CatBoost 对每个样本，仅使用该样本之前的目标值来计算类别特征的统计量，有效避免了目标泄露。

2. Ordered Boosting（有序提升）：传统 GBDT 在训练每棵树时使用相同的残差，导致预测偏移（prediction shift）。CatBoost 采用排列组合方式，对每个样本仅使用排列在它之前的样本训练的模型来计算残差，消除了预测偏移。

3. 对称决策树（Symmetric Tree）：CatBoost 使用 oblivious tree（对称树），同一层所有节点使用相同的分裂条件和特征。这不仅加速了训练和推理，还天然实现了正则化效果，减少过拟合。

与 XGBoost、LightGBM 相比，CatBoost 在类别特征丰富、数据量中等的场景下通常表现最优，且默认参数即可达到很好效果，调参成本最低。

原理示意图

数学公式

1. 梯度提升核心公式

$$ F_t(x) = F_{t-1}(x) + \eta \cdot h_t(x) $$

变量解释：

  • $ F_t(x) $：第 $ t $ 轮迭代后的模型预测值
  • $ F_{t-1}(x) $：上一轮模型的预测值
  • $ \eta $：学习率（learning_rate），控制每棵树的贡献权重
  • $ h_t(x) $：第 $ t $ 棵决策树（拟合当前残差）

2. 残差（负梯度）计算

$$ r_i^{(t)} = -\frac{\partial L(y_i, F_{t-1}(x_i))}{\partial F_{t-1}(x_i)} $$

变量解释：

  • $ r_i^{(t)} $：第 $ t $ 轮中样本 $ i $ 的残差（伪残差）
  • $ L $：损失函数（如 RMSE、Logloss）
  • $ y_i $：样本 $ i $ 的真实标签
  • $ F_{t-1}(x_i) $：上一轮模型对样本 $ i $ 的预测值
  • CatBoost 的 Ordered Boosting 中，$ F_{t-1} $ 仅由排列在 $ i $ 之前的样本训练得到

3. 有序目标统计（类别特征编码）

$$ \hat{x}_i^k = \frac{\sum_{j \in \sigma^{-1}(\{1, \ldots, i-1\})} [x_j^k = x_i^k] \cdot y_j + \alpha \cdot p}{\sum_{j \in \sigma^{-1}(\{1, \ldots, i-1\})} [x_j^k = x_i^k] + \alpha} $$

变量解释：

  • $ \hat{x}_i^k $：样本 $ i $ 的第 $ k $ 个类别特征的编码值
  • $ x_i^k $：样本 $ i $ 第 $ k $ 个特征的原始类别值
  • $ y_j $：样本 $ j $ 的目标值
  • $ \sigma $：训练数据的随机排列（permutation）
  • $ [\cdot] $：指示函数，条件成立为 1 否则为 0
  • $ \alpha $：平滑参数（smoothing parameter），控制先验的权重
  • $ p $：先验值，通常取全局目标均值

仅使用排列在 $ i $ 之前的样本计算编码，避免目标泄露。

4. 二分类 Logloss

$$ L(y_i, \hat{p}_i) = -[y_i \log \hat{p}_i + (1-y_i) \log(1 - \hat{p}_i)] $$

变量解释：

  • $ y_i \in \{0, 1\} $：真实标签
  • $ \hat{p}_i = \sigma(F(x_i)) = \frac{1}{1+e^{-F(x_i)}} $：Sigmoid 转换后的预测概率
  • $ L $：交叉熵损失

5. 回归 RMSE

$$ L(y_i, \hat{y}_i) = \frac{1}{2}(y_i - \hat{y}_i)^2 $$

变量解释：

  • $ y_i $：真实值
  • $ \hat{y}_i = F(x_i) $：模型预测值
  • 梯度为 $ \hat{y}_i - y_i $（预测值与真实值之差）

核心要点

  • CatBoost 的对称树结构使同一层所有节点使用相同的分裂条件，加速训练和推理 8 倍以上
  • Ordered Target Statistics 仅用前序样本目标值编码类别特征，从根源消除目标泄露
  • Ordered Boosting 通过排列消除梯度计算中的预测偏移，提升泛化能力
  • 默认参数即可达到优秀性能，调参成本远低于 XGBoost/LightGBM
  • 类别特征无需手动编码，直接传入 cat_features 参数即可自动处理

技术细节与参数详解

#### 参数 1：iterations（迭代次数 / 树的数量）

  • 含义：梯度提升中构建的决策树总数量 $ T $
  • 类型：整数
  • 默认值：1000
  • 取值范围：1 ~ 数万
  • 对结果的影响：太少则欠拟合（模型未充分学习）；太多则过拟合且训练时间长；通常与 learning_rate 联动调节
  • 推荐设置：500~2000 作为起点；配合早停（overfitting detector）自动选择最优树数量

#### 参数 2：learning_rate（学习率 η）

  • 含义：每棵树对最终预测的贡献权重（步长）
  • 类型：浮点数
  • 默认值：0.03（CatBoost 自动配置的默认值，与 XGBoost 的 0.3 不同）
  • 取值范围：0.001 ~ 1.0
  • 对结果的影响：太大 → 快速收敛但可能跳过最优解、过拟合；太小 → 收敛慢但泛化更好；通常与 iterations 反向调节
  • 推荐设置：0.01~0.1；小学习率 + 多树（如 0.03 + 1000）通常优于大学习率 + 少树

#### 参数 3：depth（树深度）

  • 含义：每棵对称决策树的最大深度
  • 类型：整数
  • 默认值：6（与 XGBoost/LightGBM 一致）
  • 取值范围：1 ~ 16（GPU 最大 8；注意对称树深度 $ d $ 对应 $ 2^d $ 个叶子节点）
  • 对结果的影响：深度大 → 单棵树表达力强但过拟合风险增加；深度小 → 简单树 + 更多迭代。CatBoost 对称树的叶节点数为 $ 2^{depth} $
  • 推荐设置：4~8；类别特征多时可用 6~8；小数据集用 3~5

#### 参数 4：l2_leaf_reg（L2 正则化系数）

  • 含义：叶子节点值的 L2 正则化系数 $ \lambda $
  • 类型：浮点数
  • 默认值：3.0
  • 取值范围：1.0 ~ 10.0（典型 1~10）
  • 对结果的影响：值越大 → 正则化越强，模型越保守，防过拟合；值越小 → 模型更激进拟合训练数据
  • 推荐设置：3.0 默认；过拟合时增大到 5~10；欠拟合时减小到 1~2

#### 参数 5：loss_function（损失函数）

  • 含义：训练优化的目标函数
  • 类型：字符串
  • 默认值：'Logloss'（分类）/ 'RMSE'（回归）
  • 取值范围：分类 → Logloss、CrossEntropy、MultiClass、MultiClassOneVsAll；回归 → RMSE、MAE、MAPE、Quantile、Poisson、Huber；排序 → QueryRMSE、PairLogit
  • 对结果的影响：决定模型的优化目标和适用场景；选错会导致模型无法学习
  • 推荐设置：二分类 Logloss；多分类 MultiClass；回归 RMSE

#### 参数 6：border_count（数值特征分箱数）

  • 含义：连续数值特征的离散化（分桶）数量上限
  • 类型：整数
  • 默认值：254（GPU）/ 32（CPU）
  • 取值范围：1 ~ 255（CPU 无限）
  • 对结果的影响：值越大 → 特征分割点越精细，但计算量增加；值太小 → 信息丢失。CatBoost 使用均匀或 Greedy 分箱策略
  • 推荐设置：CPU 用 254；GPU 用 128；大数据集可用 32~64 加速而不损失精度

#### 参数 7：od_type（过拟合检测类型）

  • 含义：早停（early stopping）策略类型
  • 类型：字符串
  • 默认值：'IncToDec'
  • 取值范围：'IncToDec'（从改善到恶化的检测）、'Iter'（固定迭代后停止）
  • 对结果的影响：自动在验证集指标不再改善时停止训练，节省训练时间并防止过拟合
  • 推荐设置：'IncToDec' 配合 od_wait 使用

#### 参数 8：od_wait（过拟合检测等待轮数）

  • 含义：过拟合检测器在指标不再改善后等待多少轮才停止训练
  • 类型：整数
  • 默认值：20（IncToDec）/ 500（Iter）
  • 取值范围：1 ~ 数百
  • 对结果的影响：太大 → 等待太久才停止，浪费资源且可能过拟合；太小 → 过早停止，模型未充分学习
  • 推荐设置：20~100；配合 eval_set 验证集使用

#### 参数 9：cat_features（类别特征索引）

  • 含义：指定数据中哪些列是类别型特征
  • 类型：列表（列索引或列名）
  • 默认值：None（无类别特征）
  • 取值范围：有效的列索引列表
  • 对结果的影响：指定后 CatBoost 自动使用 Ordered Target Statistics 编码，无需手动预处理；不指定则类别特征被当作数值处理
  • 推荐设置：所有非数值或低基数离散特征都应指定；高基数特征（>1000 类别）CatBoost 会自动使用更高效的编码

#### 参数 10：bootstrap_type（自助采样类型）

  • 含义：每棵树训练时的样本采样方法
  • 类型：字符串
  • 默认值：'Bayesian'（GPU）/ 'MVS'（CPU）
  • 取值范围：'Bayesian'（贝叶斯自助）、'Bernoulli'（伯努利采样）、'MVS'（最小方差采样）、'Poisson'（泊松采样）
  • 对结果的影响：影响每棵树使用的数据子集，从而影响模型多样性。Bayesian 根据权重采样 + bagging_temperature 控制随机性；Bernoulli 为简单随机采样
  • 推荐设置：CPU 用 MVS（默认）；GPU 用 Bayesian；数据量大时用 Bernoulli

#### 参数 11：bagging_temperature（贝叶斯采样温度）

  • 含义：当 bootstrap_type='Bayesian' 时控制采样随机性的温度参数
  • 类型：浮点数
  • 默认值：1.0
  • 取值范围：0.0 ~ 正无穷
  • 对结果的影响：0 → 退化为无随机性（确定性采样）；1 → 标准贝叶斯采样；>1 → 更激进的随机采样，增加多样性
  • 推荐设置：1.0 默认；过拟合时增大到 2~10

#### 参数 12：random_seed（随机种子）

  • 含义：控制训练过程所有随机性的种子值
  • 类型：整数
  • 默认值：0
  • 取值范围：0 ~ 2^31 - 1
  • 对结果的影响：相同种子 + 相同数据 → 可复现结果；不同种子 → 结果略有差异，可用于模型集成
  • 推荐设置：固定种子（如 42）确保实验可复现

#### 参数 13：grow_policy（树生长策略）

  • 含义：决策树的生长方式
  • 类型：字符串
  • 默认值：'SymmetricTree'
  • 取值范围：'SymmetricTree'（对称树，CatBoost 默认）、'Depthwise'（深度优先，同 XGBoost）、'Lossguide'（叶子优先，同 LightGBM）
  • 对结果的影响：SymmetricTree 是 CatBoost 的核心特色，训练和推理最快且天然正则化；Lossguide 可能获得更高精度但训练慢
  • 推荐设置：SymmetricTree（默认）；GPU 上优先 SymmetricTree

#### 参数 14：rsm（特征子采样比例）

  • 含义：每棵树训练时随机选择的特征比例（column subsampling）
  • 类型：浮点数
  • 默认值：None（不做子采样）
  • 取值范围：0.0 ~ 1.0
  • 对结果的影响：小于 1 → 每棵树只使用部分特征，增加模型多样性，防过拟合；太小 → 特征不足，欠拟合
  • 推荐设置：特征数多时设 0.5~0.8；特征少时设 None 或 1.0

#### 参数 15：feature_border_type（特征边界类型）

  • 含义：数值特征离散化（分箱）的策略
  • 类型：字符串
  • 默认值：'GreedyLogSum'
  • 取值范围：'GreedyLogSum'、'GreedyMinSum'、'MinLogLoss'、'Uniform'、'UniformAndQuantiles'
  • 对结果的影响：不同分箱策略影响分割点的选择质量。GreedyLogSum 基于信息增益做贪心分箱，通常效果最好
  • 推荐设置：GreedyLogSum（默认）

#### 参数 16：eval_metric（评估指标）

  • 含义：训练过程中在验证集上计算的评估指标
  • 类型：字符串
  • 默认值：与 loss_function 一致
  • 取值范围：RMSE、Logloss、AUC、F1、Precision、Recall、MultiClass、MAE、R2 等
  • 对结果的影响：不影响训练过程，但决定早停的判据和日志输出
  • 推荐设置：分类任务用 AUC 或 F1；回归用 RMSE 或 R2

#### 参数 17：verbose / logging_level（输出详细程度）

  • 含义：控制训练过程中的日志输出级别
  • 类型：整数或字符串
  • 默认值：None（默认每步输出）
  • 取值范围：0/'Silent'（无输出）、1/'Verbose'（每步输出）、200（每 200 步输出）、'Info'、'Debug'
  • 对结果的影响：不影响模型，仅影响训练日志
  • 推荐设置：训练时设 200（每 200 步输出）；最终训练设 0 或 'Silent'

#### 参数 18：task_type（任务类型）

  • 含义：指定在 CPU 还是 GPU 上训练
  • 类型：字符串
  • 默认值：'CPU'
  • 取值范围：'CPU'、'GPU'
  • 对结果的影响：GPU 训练速度可快 5~20 倍（大数据集），但部分参数在 GPU 上有限制（如 depth 最大 8、border_count 最大 255）
  • 推荐设置：有 GPU 选 GPU；无 GPU 选 CPU

#### 参数 19：one_hot_max_size（独热编码最大类别数）

  • 含义：类别特征基数低于此值时自动使用 One-Hot 编码
  • 类型：整数
  • 默认值：2（仅二值特征用 One-Hot）
  • 取值范围：2 ~ 数百
  • 对结果的影响：增大 → 更多低基数类别特征使用 One-Hot，可能提高精度但增加维度；CatBoost 默认对高基数特征使用目标统计而非 One-Hot
  • 推荐设置：2~10；特征类别数少且 GPU 训练时可适当增大

#### 参数 20：leaf_estimation_iterations（叶子值估计迭代次数）

  • 含义：每棵树叶节点值的梯度下降迭代次数
  • 类型：整数
  • 默认值：None（自动）
  • 取值范围：1 ~ 数十
  • 对结果的影响：更多迭代 → 叶子值更精确，模型表现可能更好但训练变慢；CatBoost 默认根据 loss_function 自动设置
  • 推荐设置：None（自动）；大数据集可设 1~3 加速

复杂度分析

训练时间复杂度：$ O(T \cdot N \cdot d \cdot F \cdot \log N) $

  • $ T $：迭代次数（iterations）
  • $ N $：训练样本数
  • $ d $：树深度（depth）
  • $ F $：特征数
  • $ \log N $：每次分裂时的排序开销（使用直方图可降低）
  • 对称树结构使每层只需寻找一次最优分割，比非对称树更快
  • 实际中 CatBoost GPU 训练可加速 5~20 倍

预测时间复杂度：$ O(T \cdot d) $

  • 对称树预测只需 $ T \times d $ 次比较（每棵树 $ d $ 次条件判断）
  • 对称树可用位运算并行化，推理极快

空间复杂度：$ O(T \cdot 2^d \cdot F) $

  • $ T $ 棵树，每棵 $ 2^d $ 个叶节点
  • 每个内部节点存储分裂特征和阈值：$ O(T \cdot (2^d - 1) \cdot 2) $
  • 模型文件大小与 $ T \times 2^d $ 成正比
