双指针（Two Pointers）

类别：技巧 | 难度：入门

算法简介

双指针（Two Pointers）是一类极其高效的遍历技巧：用两个（或多个）指针在数组、字符串、链表等线性数据结构中有序移动，取代暴力枚举中的多重循环。它的核心思想是"利用数据的有序性/单调性，让每个指针只向一个方向推进，从而避免重复扫描"，通常能把 $ O(n^2) $ 的暴力解法优化到 $ O(n) $，且空间复杂度保持 $ O(1) $。

双指针主要有四种形态：

  • 快慢指针：两个指针同向出发、速度不同（如快指针每次走 2 步、慢指针走 1 步），用于链表判环（Floyd 判圈算法）、找链表中点、找倒数第 k 个节点；
  • 左右指针（对撞指针）：一个指向头部、一个指向尾部，向中间收敛，用于有序数组的两数之和、反转数组、回文判断；
  • 滑动窗口：左右指针同向维护一个动态区间，右指针负责扩展、左指针负责收缩，解决连续子数组/子串最值问题；
  • 中心扩散：从中间向两边扩展，用于最长回文子串。

无论哪种形态，本质都是把"枚举所有组合"降维成"指针的线性推进"，代价是必须依赖数据的某种单调性质（有序、非负、滑窗可判）。

原理示意图

数学公式

① 快慢指针判环（Floyd 判圈）：环的判定与入口推导

设链表中环外部分长度为 $ a $，环长度为 $ b $。慢指针 $ slow $ 每次走 1 步，快指针 $ fast $ 每次走 2 步。

当 $ slow $ 走到环入口时，已走 $ a $ 步，此时 $ fast $ 已走 $ 2a $ 步，在环内超前 $ slow $ 共 $ 2a - a = a $ 步（模 $ b $ 意义下为 $ a \bmod b $ 步）。此后 $ fast $ 相对 $ slow $ 每步逼近 1 步，故相遇时经过 $ t $ 步满足：

$$ 2t - t \equiv a \pmod{b} \Rightarrow t \equiv a \pmod{b} $$

即 $ t $ 是满足 $ t \ge a $ 且 $ t \equiv a \pmod b $ 的最小正整数（$ t = a + k\cdot b,\ k \ge 0 $）。只要 $ b > 0 $（存在环），$ fast $ 与 $ slow $ 必在有限步内相遇，且相遇点距环入口为 $ b - (a \bmod b) $ 步。若 $ fast $ 先到达 $ NULL $，则说明链表无环。

环入口定位（进阶）：相遇后令 $ slow $ 回到头部、$ fast $ 保持在相遇点，二者各走 1 步再次相遇处即为环入口（因为此时 $ slow $ 走 $ a $ 步到入口，$ fast $ 走 $ a $ 步后也在入口）。

② 对撞指针（有序数组两数之和）

对严格递增数组 $ nums $，若有 $ i < j $ 使 $ nums[i] + nums[j] = target $，则：

  • 若 $ nums[i] + nums[j] > target $，因数组递增，任意 $ j' > j $ 更不可能满足，只能左移 $ j $；
  • 若 $ nums[i] + nums[j] < target $，任意 $ i' < i $ 更不可能满足，只能右移 $ i $。

即每次比较后至少排除一列/一行的候选组合，数学上等价于在 $ n \times n $ 的组合空间沿"锯齿对角线"单次扫描，因此最多 $ n $ 次比较：

$$ T(n) = O(n), \quad S(n) = O(1) $$

③ 滑动窗口通用复杂度

设序列长度 $ n $，左右指针各自最多移动 $ n $ 次，故：

$$ T(n) = O(n + n) = O(n), \quad S(n) = O(1)\ \text{（不含存储结果）} $$

核心要点

  • 双指针的本质是用单调性剪枝：每个指针只向一个方向移动，保证每个候选组合最多被"检查一次"，从而把 $ O(n^2) $ 降为 $ O(n) $。
  • 快慢指针经典三连：判环（Floyd）、找中点（快慢速差为 2）、找倒数第 $ k $ 个节点（先让 fast 走 $ k $ 步再同步走）。
  • 左右指针依赖"数组有序"这一前置条件；若数组无序需先排序（排序本身 $ O(n\log n) $）。
  • 滑动窗口依赖"窗口收缩单调性"（如非负数组的子数组和），右指针扩展、左指针收缩，用于最小/最大长度子串类问题。
  • 双指针是"技巧"而非"数据结构"，没有固定的 API 参数表，它的"参数"是指针的初始位置、速度、移动条件和终止条件——下面逐项拆解。

技术细节与参数详解

双指针本身没有 API 式参数，但设计一个双指针解法时有 5 个核心"设计参数"，逐一说明其含义与取值：

#### 设计参数 1：指针速度（快慢指针的核心）

  • 含义：快指针与慢指针每次移动的步数之比。
  • 类型：整数步长（如 1、2），或函数式条件（如 fast = fast.next.next）。
  • 默认值：经典判环用慢 1 步 / 快 2 步。
  • 取值范围：快慢任意正整数（只要速度不同即可判环）。
  • 对结果的影响：速度比决定相遇所需步数。若 fast 走 $ v_f $ 步、slow 走 $ v_s $ 步且 $ v_f > v_s $，相遇时间 $ t $ 满足 $ t \cdot (v_f - v_s) \equiv a \pmod b $；速度差太小会导致扫描步数变多（仍是 $ O(n) $）；速度差越大，$ fast $ 越可能先越界（对无环链表更快返回）。找中点必须用 2:1，才能保证 slow 恰好落在中点。
  • 推荐设置：判环用 2:1；找中点用 2:1；找倒数第 $ k $ 个节点用"快指针先走 $ k $ 步，然后等速"。

#### 算法参数 2：移动方向

  • 含义：两个指针相对移动的方向关系。
  • 类型：同向（快慢/滑窗）或相向（对撞）。
  • 取值范围：同向适合"窗口/链表"题型，相向适合"有序数组求和/回文/反转"题型。
  • 对结果的影响：方向选错会破坏单调性剪枝的正确性（例如无序数组上用对撞指针求两数之和会漏解）。
  • 推荐设置：先判断数据有序性与"是否依赖相邻区间"，有序+求和/最值 → 对撞；子串/区间 → 滑窗；链表 → 快慢。

#### 算法参数 3：指针移动的触发条件

  • 含义：什么条件下移动左/慢指针、什么条件下移动右/快指针。
  • 类型：条件分支（if sum > target）、循环维护（while 窗口不合法）。
  • 取值范围：常见触发有：比较和目标值大小、窗口内和超限、字符频次满足、环检测的判等。
  • 对结果的影响：条件决定了"剪枝"是否正确，移动条件写错是双指针解法的头号 bug 来源（漏移动导致死循环，或移动过头漏解）。
  • 推荐设置：每次循环只允许一个指针移动（或"扩展优先、收缩后检验"），保证单调性不被破坏。

#### 算法参数 4：循环终止条件

  • 含义：指针何时停止，返回结果。
  • 类型：i < j（对撞）、fast != null && fast.next != null（快慢）、right < n（滑窗）。
  • 默认值：对撞 while i < j；快慢 while fast and fast.next；滑窗 while right < len(nums)。
  • 对结果的影响：终止条件决定是否遗漏边界（如只含一个元素的窗口、空链表、无环链表）。
  • 推荐设置：写代码前先明确"空输入/单元素/无解"三条边界路径。

#### 算法参数 5：返回值与指针结束位置

  • 含义：结果来自指针（索引对、是否相遇、窗口起止）还是从指针扫描中归纳（如计数、去重）。
  • 类型：索引、布尔值、区间 [i, j)、或累计值。
  • 对结果的影响：决定了空间占用（是否额外开结果数组）。
  • 推荐设置：尽量原地返回（O(1) 额外空间），只有结果集本身需要时才允许 O(n) 空间。

代码示例

# ============ 示例 1：快慢指针 —— 判断链表是否有环（LeetCode 141）============
# 定义链表节点结构
class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val          # 节点值
        self.next = next        # 指向下一个节点的引用

def hasCycle(head: ListNode) -> bool:
    # 若链表为空或只有一个节点，必然无环，直接返回 False
    if not head or not head.next:
        return False
    slow = head                # 慢指针从头部出发，每次走 1 步
    fast = head                # 快指针也从头部出发，每次走 2 步
    while fast and fast.next:  # 只要 fast 还没走到链表末尾（防止 fast.next 越界）
        slow = slow.next       # 慢指针前进 1 个节点
        fast = fast.next.next  # 快指针前进 2 个节点
        if slow is fast:       # 快慢相遇 → 链表有环
            return True
    return False               # fast 先走到 None，说明链表无环


# ============ 示例 2：对撞指针 —— 有序数组两数之和（LeetCode 167）============
def two_sum(numbers: list[int], target: int) -> list[int]:
    i = 0                      # 左指针指向数组头
    j = len(numbers) - 1       # 右指针指向数组尾
    while i < j:               # 指针未交错则继续
        s = numbers[i] + numbers[j]   # 计算当前两数和
        if s == target:        # 恰好等于目标 → 返回下标（题目要求从 1 开始）
            return [i + 1, j + 1]
        elif s < target:       # 和太小：只能增大左指针（数组递增，右侧只会更大）
            i += 1
        else:                  # 和太大：只能减小右指针
            j -= 1
    return [-1, -1]            # 无解兜底（题目保证有解，防御性写法）


# ============ 示例 3：滑动窗口 —— 最长无重复字符子串（LeetCode 3）============
def length_of_longest_substring(s: str) -> int:
    window = set()             # 记录窗口内已出现的字符，O(1) 判重
    left = 0                   # 窗口左边界（慢指针）
    ans = 0                    # 记录历史最长长度
    for right in range(len(s)):    # 右指针（快指针）逐个扩展
        while s[right] in window:  # 若新字符已在窗口内，则收缩左边界直到不再重复
            window.remove(s[left]) # 从窗口中移除最左侧字符
            left += 1              # 左指针右移一格
        window.add(s[right])       # 将新字符加入窗口
        ans = max(ans, right - left + 1)   # 更新最长长度（当前窗口大小）
    return ans                 # 返回最长无重复子串长度

复杂度分析

时间复杂度推导：

  • 对撞指针 / 滑动窗口：左右指针各自最多移动 $ n $ 次，两指针合共不超过 $ 2n $ 步，故 $ T(n) = O(n) $。相比暴力枚举所有 $ (i,j) $ 组合的 $ \binom{n}{2} = \frac{n(n-1)}{2} = O(n^2) $，是从 $ O(n^2) $ 到 $ O(n) $ 的数量级优化。
  • 快慢指针（判环）：环外长度 $ a $、环长 $ b $，慢指针最坏绕环一周前相遇，故 $ T(n) = O(a + b) = O(n) $。
  • 需要排序的场景（如无序数组两数之和）：额外 $ O(n\log n) $。

空间复杂度推导：

  • 各指针仅占用常数个变量（$ slow, fast, left, right, ans $），$ S(n) = O(1) $。
  • 滑动窗口若用哈希集合记录字符，最坏 $ S(n) = O(\sigma) $，$ \sigma $ 为字符集大小（如 ASCII 128、Unicode 更大），可视为常数。

应用场景

  • 链表操作：环形链表检测与环入口、找链表中点、找倒数第 $ k $ 个节点（LeetCode 141/142/876/19）。
  • 有序数组问题：两数之和 II、三数之和、四数之和（对指针降维）、盛水最多的容器。
  • 字符串处理：反转字符串、回文判断、最长无重复子串、最小覆盖子串（滑动窗口）。
  • 归并场景：合并两个有序数组/链表（双指针各指向一个序列，逐个比较取小）。
  • 原地去重：删除排序数组重复项（快指针扫描、慢指针收集）。

ALiBi 注意力偏置（Attention with Linear Biases）

类别：深度学习 | 难度：中等

算法简介

ALiBi（Attention with Linear Biases，带线性偏置的注意力）是 2021 年由 Ofir Press、Noam Smith 等人在论文《Train Short, Test Long: Attention with Linear Biases Enables Input Length Extrapolation》中提出的位置编码替代方案。它彻底抛弃了在词嵌入上叠加位置编码（绝对位置嵌入或正弦编码）的传统做法，而是在注意力分数计算完之后，直接加上一个与 token 之间相对距离成线性比例的负偏置——距离越远，偏置越小（惩罚越大）。

这个看似简单的改动带来两个关键收益：

1. 训练短、测试长（length extrapolation）：用短序列（如 512 token）训练出的模型，可以直接泛化到更长序列（如 1024/2048+ token）而性能不衰减。传统绝对位置编码训练时从未见过长序列位置，外推时位置嵌入匹配失效；ALiBi 的距离惩罚是解析定义的，任何长度都能直接计算。

2. 无需位置嵌入参数：省去了位置编码层及其参数，同时位置信息完全由相对距离决定，天然具备平移不变性。

ALiBi 已在多语言机器翻译（M2M-100）、BLOOM 系列大模型上被采用（BLOOM 就用 ALiBi 替代了位置编码），是位置编码演进史（SIN → 学习位置 → ALiBi → RoPE → PI → NTK → YaRN）中承上启下的一环。

原理示意图

数学公式

① 标准缩放点积注意力（基线）

$$ \text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^{\mathsf{T}}}{\sqrt{d_k}}\right) V $$

变量解释：

  • $ Q \in \mathbb{R}^{L_q \times d_k} $：query 矩阵，$ L_q $ 为查询序列长度，$ d_k $ 为键的维度；
  • $ K \in \mathbb{R}^{L_k \times d_k} $：key 矩阵，$ L_k $ 为键序列长度（通常 $ L_q = L_k = n $）；
  • $ V \in \mathbb{R}^{L_k \times d_v} $：value 矩阵，$ d_v $ 为值的维度；
  • $ \sqrt{d_k} $：缩放因子，防止点积数值过大导致 softmax 饱和、梯度消失；
  • $ QK^{\mathsf{T}}/\sqrt{d_k} \in \mathbb{R}^{L_q \times L_k} $：注意力分数矩阵（未归一化的 logits）。

② ALiBi 的核心公式

$$ \text{softmax}\!\left(\frac{QK^{\mathsf{T}}}{\sqrt{d_k}} + m \cdot B\right) V $$

变量解释：

  • $ B \in \mathbb{R}^{L_q \times L_k} $：线性偏置矩阵，其中 $ B[i][j] = -(j - i) $（单向自注意力，$ j \ge i $；双向注意力用 $ -|j - i| $），即与两个 token 的相对距离成正比的负数；
  • $ m $：该注意力头专属的斜率（slope），一个正的超参数，每头不同；
  • $ m \cdot B $：逐元素相乘后加到注意力分数上，表示"离得越远，得分被减去越多"；
  • 其余符号同①。

③ 斜率 $ m $ 的几何级数取值（多头）

$$ m_h = 2^{-\frac{8h}{H}}, \quad h = 1, 2, \dots, H $$

变量解释：

  • $ H $：注意力头总数；
  • $ h $：第 $ h $ 个注意力头（从 1 计数）；
  • $ 2^{-8h/H} $：几何级数，相邻头之间的斜率为 $ \frac{1}{2^{8/H}} $ 倍。
  • 当 $ H=8 $ 时：$ m = \frac{1}{2}, \frac{1}{4}, \frac{1}{8}, \frac{1}{16}, \frac{1}{32}, \frac{1}{64}, \frac{1}{128}, \frac{1}{256} $——前面头部惩罚更轻（更擅长长距离依赖），后面头部惩罚更重（更擅长局部细节），多头在"距离敏感性"上自然分工。

④ 为什么 ALiBi 能外推（直觉推导）

对任意长度 $ n' > n_{train} $，偏置矩阵 $ B $ 的元素 $ -(j-i) $ 可以无歧义地计算（只需两个下标），与训练时见过的"位置号"无关。而绝对位置编码（正弦编码/学习嵌入）在位置 $ p > n_{train} $ 时要么超出训练分布、要么嵌入从未被学习过，位置信息立即失效。因此：

$$ P(\text{test length} = n') \text{ 可解析计算} \quad \forall n' \gg n_{train} $$

核心要点

  • ALiBi 的哲学：位置信息不是加在输入上，而是加在注意力分数上，且与"距离"而非"绝对位置"绑定——这是它能外推的根源。
  • 零新增训练参数、零额外推理成本：偏置矩阵 $ B $ 与斜率 $ m $ 都是预设的，不参与训练。
  • 每个 head 的 $ m $ 构成几何级数（$ 2^{-8h/H} $），大 slope 头专注近邻、小 slope 头专注全局，多头自然分工。
  • 训练时间：ALiBi 用短序列训练即可泛化到长序列，显著降低训练成本。
  • 与 RoPE 的关系：RoPE 是另一种优秀的相对位置方案（旋转矩阵），ALiBi 与 RoPE 是"二选一"的两条路线；RoPE 在长上下文 LLM（如 LLaMA）中更主流，ALiBi 在多语言/机器翻译（BLOOM、M2M-100）中验证成功。
  • 注意：ALiBi 只是给注意力加分，不改变注意力机制本身，实现极简单（几行代码），是"低开销、高收益"的典型。

技术细节与参数详解

#### 参数 1：slope 斜率 $ m $

  • 含义：第 $ h $ 个注意力头的距离惩罚系数，决定该头"多远开始衰减、衰减多快"。
  • 类型：非负实数（float），通常为 $ \frac{1}{2}, \frac{1}{4}, \dots $ 的几何级数。
  • 默认值：$ m_h = 2^{-8h/H} $（$ H $ 为总头数）；$ H=8 $ 时为 $ \{1/2, 1/4, \dots, 1/256\} $。
  • 取值范围：理论上 $ m > 0 $ 任意；论文对比了线性、多项式、几何、与头数无关的 $ m=2^{-8} $ 等多种方案，几何级数效果最优且最稳定。
  • 对结果的影响：$ m $ 过大 → 即使相邻 token 也被显著抑制，模型只看局部无法捕捉长程依赖；$ m $ 过小 → 惩罚近似于无，位置信息丢失，退化回"无位置编码的模型"。
  • 推荐设置：保持论文默认 $ 2^{-8h/H} $；若想增强长程依赖（如超长上下文任务），可适当缩小斜率底数（如 $ 2^{-8h/H} $ 改为 $ 2^{-6h/H} $）——需要实验调参。

#### 参数 2：偏置矩阵 $ B $

  • 含义：$ L_q \times L_k $ 的矩阵，元素为相对距离的负值（单向：$ -(j-i) $；双向：$ -|j-i| $）。
  • 类型：整数/浮点张量，随输入长度动态生成（不参与训练）。
  • 默认值：按"当前序列长度"实时构造。
  • 取值范围：单向 $ B[i][j] = \begin{cases} 0 & j \le i \\ -(j-i) & j > i \end{cases} $；双向 $ B[i][j] = -|j-i| $。
  • 对结果的影响：决定了"相对距离信息"以何种精度进入注意力——距离差 1 的惩罚是 $ -m $，距离差 10 的惩罚是 $ -10m $，呈线性（linear），这正是名字里 Linear 的由来。
  • 推荐设置：自回归（causal）模型用单向；编码器/双向模型用双向；若与因果掩码结合，因果掩码（$ -\infty $）与 $ B $ 直接相加即可。

#### 参数 3：是否可学习（可学习性）

  • 含义：$ m $ 与 $ B $ 是否作为可训练参数。
  • 默认值：不可学习（固定超参）。
  • 对结果的影响：论文实验证明可学习的 $ m $ 效果不如固定的几何级数（可学习引入训练不稳定性，且丢失外推先验）；$ B $ 若可学习则退化为"学习位置嵌入"，再次面临长度外推失效。
  • 推荐设置：固定 $ m $，不学习 $ B $。

#### 参数 4：与位置编码的关系

  • 含义：使用 ALiBi 后，输入嵌入层不再叠加任何位置编码（不要用 POS embedding，不要加正弦/学习嵌入）。
  • 默认值：ALiBi 模型应移除位置嵌入层。
  • 对结果的影响：若叠加位置嵌入 + ALiBi 二者都加，位置信息"双份"，效果与训练稳定性都会受损；若只加位置编码不加 ALiBi，则是普通 Transformer 的位置编码路线。
  • 推荐设置：使用 ALiBi 时彻底移除位置编码层（词嵌入 + ALiBi 就够了）。

#### 参数 5：序列长度与外推比

  • 含义：训练长度 $ n_{train} $ 与推理/测试长度 $ n_{test} $ 的关系。
  • 默认值：无严格默认，建议训练 512-1024 token。
  • 取值范围：$ n_{test} $ 可为 $ n_{train} $ 的 2-4 倍以上（论文 1024→2048/4096 效果良好）。
  • 对结果的影响：$ n_{test} / n_{train} $ 越大，位置外推越难；ALiBi 比绝对位置好得多，但超长倍数（如 16 倍）下仍可能衰减（此时可考虑 RoPE+NTK 等）。
  • 推荐设置：$ n_{test} \le 4 \times n_{train} $ 时效果最佳。

#### 参数 6：应用位置（self-attention vs cross-attention）

  • 含义：ALiBi 加在哪些注意力上。
  • 默认值：仅 self-attention 加（cross-attention 的 key/value 由另一端提供，相对位置语义不明，不加）。
  • 取值范围：仅 self-attention，或只加 decoder 不加 encoder（论文对 M2M 的做法）。
  • 对结果的影响：加在 cross-attention 上意义不大（无明确相对位置语义），且可能损伤性能。
  • 推荐设置：仅 self-attention 上使用。

代码示例

import torch
import torch.nn as nn
import math

def get_alibi_slopes(num_heads: int) -> torch.Tensor:
    """
    计算每个注意力头的斜率 m_h = 2^(-8h/H)，返回形状 (H,)
    num_heads: 注意力头数 H
    """
    # h 从 1 到 H 的编号
    h = torch.arange(1, num_heads + 1, dtype=torch.float32)
    # 2^(-8h/H)：指数为 -8h/H，底数 2，逐头计算
    return 2.0 ** (-8.0 * h / num_heads)

def build_alibi_bias(num_heads: int, seq_len: int, causal: bool = True) -> torch.Tensor:
    """
    构建 ALiBi 偏置张量，形状 (H, 1, L, L)，加到注意力分数上
    num_heads: 头数 H
    seq_len  : 序列长度 L
    causal   : 是否因果（单向）
    """
    # 位置索引 0..L-1
    pos = torch.arange(seq_len, dtype=torch.float32)
    # 相对距离矩阵：dist[i][j] = j - i（i 行 j 列）
    dist = pos[None, :] - pos[:, None]          # 形状 (L, L)，第 i 行第 j 列 = j - i
    if causal:                                # 因果模型：只允许 j >= i 看左侧
        dist = torch.clamp(dist, max=0)      # 把 j < i 的区域截断为 0（无惩罚）
    else:
        dist = -torch.abs(dist)               # 双向模型：用距离绝对值取负
    slopes = get_alibi_slopes(num_heads)      # (H,)
    # 每个 head 的偏置：slope[h] * dist，扩维到 (H, 1, L, L) 以便广播
    return (slopes[:, None, None] * dist[None, :, :]).unsqueeze(1)   # (H, 1, L, L)

# ---------- 在注意力中使用 ----------
class ALiBiMultiHeadAttention(nn.Module):
    def __init__(self, d_model: int, num_heads: int):
        super().__init__()
        self.d_model = d_model                  # 模型维度（总）
        self.num_heads = num_heads              # 头数 H
        self.d_head = d_model // num_heads      # 每头维度 d_k = d_model / H
        # 生成三个投影层（Q、K、V），每个把 d_model 投影到 d_model
        self.W_q = nn.Linear(d_model, d_model)
        self.W_k = nn.Linear(d_model, d_model)
        self.W_v = nn.Linear(d_model, d_model)

    def forward(self, x: torch.Tensor):
        """
        x: (B, L, d_model)  批 B，长度 L，维数 d_model
        返回: (B, L, d_model) 注意力输出
        """
        B, L, _ = x.shape
        # 1. 投影并切分为多头，形状 (B, H, L, d_head)
        Q = self.W_q(x).view(B, L, self.num_heads, self.d_head).transpose(1, 2)
        K = self.W_k(x).view(B, L, self.num_heads, self.d_head).transpose(1, 2)
        V = self.W_v(x).view(B, L, self.num_heads, self.d_head).transpose(1, 2)
        # 2. 计算注意力分数 QK^T / sqrt(d_k)，形状 (B, H, L, L)
        scores = (Q @ K.transpose(-2, -1)) / math.sqrt(self.d_head)
        # 3. 添加 ALiBi 线性偏置（关键步骤）：(H, 1, L, L) 广播到 (B, H, L, L)
        alibi = build_alibi_bias(self.num_heads, L, causal=True)   # (H, 1, L, L)
        scores = scores + alibi.to(scores.device)
        # 4. softmax + 加权 V
        probs = torch.softmax(scores, dim=-1)     # 每行（query 维度）归一化
        out = probs @ V                            # (B, H, L, d_head)
        # 5. 拼接多头回 d_model
        return out.transpose(1, 2).reshape(B, L, self.d_model)

复杂度分析

时间复杂度：

  • ALiBi 只在注意力分数矩阵上做一次逐元素加法：$ O(H \cdot L^2) $（$ H $ 头、每头 $ L \times L $ 矩阵）。
  • 标准缩放点积注意力本身为 $ O(H \cdot L^2 \cdot d_k) $，所以 ALiBi 的开销占比 $ \frac{O(L^2 H)}{O(L^2 H d_k)} = \frac{1}{d_k} $，相对计算可以忽略。

空间复杂度：

  • 偏置矩阵 $ B $ 形状 $ (H, L, L) $，即 $ O(H \cdot L^2) $——与注意力分数矩阵同阶，通常就地/复用注意力矩阵内存，不显著增加显存。
  • 对比学习位置嵌入：训练长度 $ L_{max} $ 需要 $ O(L_{max} \cdot d_{model}) $ 额外参数，且随 $ L_{max} $ 线性增长；ALiBi 零新增参数。

外推性：

  • 训练长度 $ L_{train} $ 与测试长度 $ L_{test} $ 解耦：$ L_{test} $ 可大于 $ L_{train} $ 而不需要再训练（绝对位置编码无此性质）——这是 ALiBi 最大的"性价比"。

应用场景

  • 超长文本外推：LLM 长上下文场景——短训练、长推理（如 1024 训练 → 4096 推理），无需续训即可扩长。
  • 多语言机器翻译：M2M-100、BLOOM 等 100+ 语言模型：多语言不同长度、长句翻译不失调。
  • 因果语言模型（decoder-only）：BLOOM 176B 直接使用 ALiBi 作为位置方案。
  • 检索/编码器任务：双向（绝对值）偏置的 ALiBi 也可用于 BERT 式编码器，代替位置嵌入。
  • 教学与轻量模型：零参数、易实现、不需要训练位置嵌入，非常适合资源受限的实训部署场景。

RNN 循环神经网络（Recurrent Neural Network）

类别：深度学习 | 难度：中等

算法简介

循环神经网络（RNN）是一类专门处理序列数据（时间序列、文本、语音等）的神经网络。与普通前馈网络（各层输入输出相互独立）不同，RNN 通过一个循环连接的隐藏状态（hidden state）$ h_t $，将上一时间步的"记忆"传递到当前时间步，从而建模序列中的时序依赖关系。

每一时间步 $ t $，RNN 执行同一个共享计算（参数在所有时间步共享）：

$$ h_t = \tanh(W_{ih} x_t + b_{ih} + W_{hh} h_{t-1} + b_{hh}) $$

$ h_t $ 既作为传递给下一时间步的"记忆"，也可输出（$ o_t $）用于预测。正是这种"同一参数在不同时间步反复使用"（weight sharing）使 RNN 能处理任意长度序列，且参数量不随序列长度增长——这与全连接层对每个时间步各学一套参数完全不同。

RNN 的局限同样著名：梯度消失/爆炸（长期依赖难以学习，训练不稳定），以及无法并行（必须按时间步顺序迭代）。因此实际工程中被 LSTM（引入记忆门控）、GRU（精简门控）和 Transformer（并行 + 注意力）逐步取代，但 RNN 作为理解序列建模的第一课，仍然是深度学习入门与面试必备，PyTorch 的 nn.RNN 是官方标准实现。

原理示意图

数学公式

① 隐藏状态更新公式（PyTorch nn.RNN 的实际计算）

$$ h_t = \tanh\!\big(W_{ih}\, x_t + b_{ih} + W_{hh}\, h_{t-1} + b_{hh}\big) $$

变量解释：

  • $ x_t \in \mathbb{R}^{d_{in}} $：第 $ t $ 时间步的输入向量（$ d_{in} $ = input_size）；
  • $ h_{t-1}, h_t \in \mathbb{R}^{d_h} $：上一时刻与当前时刻的隐藏状态（$ d_h $ = hidden_size，$ h_0 $ 默认全 0）；
  • $ W_{ih} \in \mathbb{R}^{d_h \times d_{in}} $：输入到隐藏的权重矩阵；
  • $ W_{hh} \in \mathbb{R}^{d_h \times d_h} $：隐藏到隐藏（循环）的权重矩阵——记忆的来源；
  • $ b_{ih}, b_{hh} \in \mathbb{R}^{d_h} $：输入与循环的偏置向量；
  • $ \tanh $：逐元素双曲正切激活函数，将输出压缩到 $ (-1, 1) $（nonlinearity 参数可取 'tanh' 或 'relu'）。

② 输出公式

$$ o_t = h_t \quad(\text{无额外输出层时，PyTorch 直接返回隐藏状态}) $$

$$ y_t = \mathrm{softmax}(W_{ho} h_t + b_{ho}) \quad(\text{接入分类头后的最终预测}) $$

变量解释：

  • $ o_t $：第 $ t $ 步的 RNN 输出（即 $ h_t $ 本身）；
  • $ W_{ho} \in \mathbb{R}^{d_{out} \times d_h} $：输出权重；$ b_{ho} $：输出偏置（这两者不属于 nn.RNN 本身，通常由外部线性层承担）；
  • $ y_t $：经过 $ \mathrm{softmax} $ 得到类别概率。

③ 参数数量公式（每层）

$$ \text{params} = d_h \times d_{in} + d_h \times d_h + d_h + d_h = d_h\,(d_{in} + d_h + 2) $$

变量解释：

  • $ W_{ih} $ 有 $ d_h \times d_{in} $ 个参数；
  • $ W_{hh} $ 有 $ d_h \times d_h $ 个参数；
  • 两个偏置各 $ d_h $，共 $ 2 d_h $；
  • 若 bias=False，删去 $ 2 d_h $；若 bidirectional=True，双倍（两个方向各一套全套参数）。

④ 梯度消失/爆炸的根源（BPTT）

反向传播损失 $ L $ 到第 $ k $ 时间步隐藏状态（时序反向传播 BPTT）：

$$ \frac{\partial L}{\partial h_k} = \frac{\partial L}{\partial h_T} \prod_{j=k+1}^{T} \frac{\partial h_j}{\partial h_{j-1}} = \frac{\partial L}{\partial h_T} \prod_{j=k+1}^{T} \mathrm{diag}\big(f'(h_j)\big)\, W_{hh}^{\mathsf{T}} $$

变量解释：

  • $ f' $ 为激活函数导数，$ \tanh' \in (0,1] $，常接近 0；
  • 连乘中每个因子含 $ \|W_{hh}\| $（矩阵谱范数）与 $ |f'| $；
  • 当 $ T - k $ 很大（长序列）且这些因子 < 1 时，乘积指数级衰减 → 梯度消失（长距离依赖丢失）；> 1 时指数爆炸 → 梯度爆炸（训练发散，需梯度裁剪）。

核心要点

  • 参数共享：同一组 $ (W_{ih}, W_{hh}, b_{ih}, b_{hh}) $ 在所有时间步复用，参数量与序列长度无关。
  • 记忆机制：隐藏状态 $ h_t $ 携带到 $ t $ 为止的历史信息，是 RNN 的"记忆体"。
  • 不可并行：$ h_t $ 依赖 $ h_{t-1} $，前向/反向必须按时间顺序迭代（Transformer 因此取而代之）。
  • 梯度消失/爆炸：长序列训练困难，是 RNN 的致命弱点（引出 LSTM/GRU 门控与梯度裁剪）。
  • nn.RNN 提供 8 个参数：input_size、hidden_size、num_layers、nonlinearity、bias、batch_first、dropout、bidirectional，下面逐个详解。

技术细节与参数详解（PyTorch nn.RNN 全参数）

PyTorch 签名：nn.RNN(input_size, hidden_size, num_layers=1, nonlinearity='tanh', bias=True, batch_first=False, dropout=0, bidirectional=False)

#### 参数 1：input_size（输入特征维度）

  • 含义：每个时间步输入 $ x_t $ 的特征数量（例如词向量维度 300、单变量时序=1、多变量时序=特征数）。
  • 类型：int
  • 默认值：无（必填）。
  • 取值范围：$ \ge 1 $ 的整数。
  • 对结果的影响：决定 $ W_{ih} $ 形状 $ d_h \times d_{in} $ 与参数量 $ d_h \cdot d_{in} $；过大导致参数量膨胀、过小丢失信息。
  • 推荐设置：词嵌入用 128-768；数值时序用实际特征数。

#### 参数 2：hidden_size（隐藏状态维度）

  • 含义：$ h_t $ 的维度 $ d_h $，即 RNN 的"记忆容量/表示宽度"。
  • 类型：int
  • 默认值：无（必填）。
  • 取值范围：任意正整数（32~1024 常见）。
  • 对结果的影响：越大表达力越强但越易过拟合、计算量 $ O(d_h^2) $ 增长；决定所有权重矩阵的第二维。
  • 推荐设置：小数据 64~256；大数据/强序列 256~1024；配合早停与 Dropout 防过拟合。

#### 参数 3：num_layers（循环层数）

  • 含义：堆叠的 RNN 层数（Stacked RNN），上一层输出作为下一层输入。
  • 类型：int
  • 默认值：1
  • 取值范围：$ \ge 1 $；常见 1~4（超过 3 层收益骤减、训练难度上升）。
  • 对结果的影响：多层可捕捉更抽象的层级时序特征，但梯度传播路径更长、训练更难（需要 dropout 正则化）。
  • 推荐设置：任务简单用 1~2；大语料可到 3~4。

#### 参数 4：nonlinearity（激活函数）

  • 含义：隐藏状态更新的非线性函数。
  • 类型：str，仅 'tanh' 或 'relu'。
  • 默认值：'tanh'（官方推荐）。
  • 取值范围：'tanh'、'relu'。
  • 对结果的影响：tanh 输出 $ (-1,1) $ 有界、中心化、梯度更稳定；relu 无上界、收敛快但更容易梯度爆炸与神经元死亡；实际标准都是 tanh。
  • 推荐设置：默认 'tanh'；只有在极短序列实验可用 'relu' 加速。

#### 参数 5：bias（是否使用偏置）

  • 含义：$ b_{ih} $ 与 $ b_{hh} $ 是否存在。
  • 类型：bool
  • 默认值：True
  • 对结果的影响：去掉偏置会降低拟合能力（无法建模线性偏移），几乎总是不利；仅在参数量受限的极端场景可关。
  • 推荐设置：True（默认）。

#### 参数 6：batch_first（批量维度是否在第一）

  • 含义：输入输出张量的维度顺序。
  • 类型：bool
  • 默认值：False → 输入形状 (seq_len, batch, input_size)
  • 可选：True → (batch, seq_len, input_size)
  • 对结果的影响：仅影响张量形状与转置成本；batch_first=True 与 Transformer/生态更一致，代码可读性更好。
  • 推荐设置：统一 batch_first=True，减少与其他模块拼接时的维度转换。

#### 参数 7：bidirectional（是否双向）

  • 含义：是否同时训练"正向"与"反向"两个 RNN，并把两个方向的隐藏状态拼接作为输出。
  • 类型：bool
  • 默认值：False
  • 对结果的影响：正向捕获"过去→现在"的依赖，反向捕获"未来→现在"的信息（在序列分类、NER 上显著提升）；但自回归生成场景禁用（未来信息不可见），且参数量、输出维度翻倍。
  • 推荐设置：非自回归任务（分类/标注）用 True；时序预测/生成任务必须 False。

#### 参数 8：权重初始化与 dtype 等隐式参数

  • 含义：nn.RNN 内部对 $ W_{ih} $、$ W_{hh} $ 用均匀分布 $ U(-\sqrt{k}, \sqrt{k}) $（$ k = 1/d_{in} $ 或 $ 1/d_h $）初始化；偏置全 0。
  • 推荐设置：一般不需要手动改；若梯度消失严重可尝试正交初始化（orthogonal_）与梯度裁剪（clip_grad_norm_）。

代码示例

# ============ 完整 RNN 序列建模示例（PyTorch）============
import torch
import torch.nn as nn

# 1. 造一条简单序列数据：batch=2，seq_len=5，每个时间步 3 个特征
x = torch.randn(2, 5, 3)        # (batch, seq_len, input_size)

# 2. 定义 RNN 层（逐参数含义见上文详解）
rnn = nn.RNN(
    input_size=3,               # 每个时间步输入特征维度 = 3
    hidden_size=4,              # 隐藏状态维度 = 4（记忆容量）
    num_layers=2,               # 堆叠 2 层循环层
    nonlinearity='tanh',        # 激活函数 tanh（或 'relu'）
    bias=True,                  # 使用偏置（b_ih、b_hh）
    batch_first=True,           # 输入形状 (batch, seq, feature)
    dropout=0.2,                # 第 1 层与第 2 层之间的 dropout（num_layers>1 生效）
    bidirectional=False         # 单向（时序预测场景）
)

# 3. 前向传播
out, h_n = rnn(x)
# out 形状: (batch=2, seq_len=5, hidden_size=4)，每个时间步的输出（=h_t）
# h_n  形状: (num_layers=2, batch=2, hidden_size=4)，各层最后一个时间步的隐藏状态

# 4. 打印参数量，验证"参数量与序列长度无关"
total = sum(p.numel() for p in rnn.parameters())
print("RNN 参数量:", total)
# 计算核对：第1层 (3+4)*4 + 4 + 4 = 40；第2层 (4+4)*4 + 8 = 40；合计 80

# 5. 用最终隐藏状态做分类头（如情感二分类）
classifier = nn.Linear(4, 2)      # 4 维隐藏状态 → 2 类
logits = classifier(h_n[-1])      # 取最后一层（层索引 -1）的最终隐藏状态
probs = torch.softmax(logits, dim=-1)  # 转概率
print("分类概率形状:", probs.shape)      # (batch=2, num_classes=2)


# ============ 自实现单层 RNN（与 nn.RNN 等价，便于理解每一步）============
class MyRNNCell(nn.Module):
    def __init__(self, input_size, hidden_size):
        super().__init__()
        self.W_ih = nn.Parameter(torch.randn(hidden_size, input_size))  # 输入→隐藏权重
        self.W_hh = nn.Parameter(torch.randn(hidden_size, hidden_size)) # 循环权重（记忆核心）
        self.b_ih = nn.Parameter(torch.zeros(hidden_size))              # 输入偏置
        self.b_hh = nn.Parameter(torch.zeros(hidden_size))              # 循环偏置

    def forward(self, x_t, h_prev):
        # x_t: (batch, input_size)  当前时刻输入
        # h_t: (batch, hidden)   上一时刻隐藏状态
        h_new = torch.tanh(
            x_t @ self.W_ih.t() + self.b_ih          # 输入投影 + 偏置
            + h_prev @ self.W_hh.t() + self.b_hh     # 隐藏投影（循环） + 偏置
        )
        return h_new  # 返回当前隐藏状态

# 使用 MyRNNCell 逐时间步迭代（等价于 nn.RNN 单层单方向）
cell = MyRNNCell(3, 4)
h = torch.zeros(2, 4)             # 初始 h_0 = 0
for t in range(5):                 # 顺序遍历 5 个时间步（RNN 无法并行）
    h = cell(x[:, t, :], h)        # 更新隐藏状态
print("逐时间步最终 h:", h.shape)    # (2, 4)

复杂度分析

时间复杂度：

  • 单层单向 RNN 每时间步：矩阵乘 $ W_{ih} x_t $ 为 $ O(d_h d_{in}) $，$ W_{hh} h_{t-1} $ 为 $ O(d_h^2) $，激活逐元素 $ O(d_h) $；合计 $ O(d_h(d_{in} + d_h)) $。
  • 序列长度 $ T $：总复杂度 $ O\big(T \cdot d_h (d_{in} + d_h)\big) $——与 $ T $ 线性（这是 RNN 相比 Transformer $ O(T^2) $ 在长序列上的潜在优势，但不可并行抵消了这一点）。
  • 多层 $ L $：乘以 $ L $；双向：乘以 2。

空间复杂度：

  • 参数：$ L \cdot d_h(d_{in} + d_h + 2) $（每层）；与 $ T $ 无关（参数共享）。
  • 训练过程存储：BPTT 需保存每个时间步的中间量（$ h_1, \dots, h_T $）用于反向传播，$ O(T \cdot d_h) $——随 $ T $ 线性增长，长序列内存压力大。

并行性：无法沿时间并行（依赖链）；可沿 batch 并行（batch 维度）。

应用场景

  • 序列建模教学/入门：理解"隐藏状态 + 参数共享 + BPTT"的教科书第一课。
  • 时间序列预测：单变量/多变量数值预测、传感器数据、电力负荷等（小规模场景仍可用）。
  • 短文本处理：字符级语言模型（如名字生成）、短句分类、词性标注（基线模型）。
  • 手写识别/语音前端：经典序列到序列（seq2seq）编码器（现代多被 GRU/LSTM/Transformer 替换）。
  • 教育/原理演示：天然适合展示循环依赖、梯度消失/爆炸等深度学习概念。

注：生产级长序列任务建议使用 LSTM/GRU（缓解梯度消失）或 Transformer（并行 + 长程），RNN 更多作为理解序列建模的起点。
