Prim 最小生成树

类别：图算法 | 难度：中等

算法简介

Prim 算法（普里姆算法）是求解最小生成树（Minimum Spanning Tree, MST）的经典贪心算法，由捷克数学家 Vojtěch Jarník 于 1930 年提出，后由 Robert C. Prim 于 1957 年独立重新发现。最小生成树问题：给定一个带权无向连通图，找到一棵包含全部 $ n $ 个顶点、恰好 $ n-1 $ 条边、且边权和最小的树。Prim 的核心思想是"点集扩张"：维护一个已覆盖顶点集合 $ U $，每次从连接 $ U $ 与 $ V-U $（未覆盖集合）的所有边（称"可增广边"）中选择权值最小的一条加入生成树，把该边的另一端点并入 $ U $，如此循环 $ n-1 $ 次，$ U $ 逐渐膨胀到整个顶点集，得到的树即为最小生成树。与 Kruskal 算法（边集扩张 + 并查集）相比，Prim 更适合稠密图，其正确性由"切割性质"（Cut Property）保证：对任意把顶点分成两部分的切割，权值最小的横跨切割的边必然属于某棵最小生成树，这使贪心选择永远不犯错。

原理示意图

数学公式

1. 切割性质（Prim 正确性的理论基础）

对于连通图 $ G=(V,E) $ 的任意顶点子集 $ U \subset V $（即一个"切割"），设 $ e=(u,v) $ 是横跨切割（$ u \in U,\ v \in V\setminus U $）的权值最小的边，则 $ e $ 必属于某棵最小生成树 $ T $：

$$ w(e) = \min_{(x,y)\in \delta(U)} w(x,y) \quad\Longrightarrow\quad e \in T $$

  • $ G=(V,E) $：图，$ V $ 为顶点集，$ E $ 为边集
  • $ U $：顶点集的一个真子集，代表"已覆盖集合"
  • $ \delta(U) $：所有横跨切割的边（一端在 $ U $、一端在 $ V\setminus U $）
  • $ w(x,y) $：边 $ (x,y) $ 的权值（非负实数）
  • $ e=(u,v) $：当前权值最小的横跨切割边
  • $ T $：图的一棵最小生成树

2. 生成树的边数不变量

$$ |E(T)| = |V| - 1 = n - 1 $$

  • $ n = |V| $：顶点总数
  • $ |E(T)| $：树 $ T $ 中边的条数，恒为 $ n-1 $（连通无环图的性质），这是算法循环次数 $ n-1 $ 的来源

3. 总代价公式（目标函数）

$$ \text{cost}(T) = \sum_{e \in T} w(e) \;\to\; \min $$

  • $ T $：生成树（$ n $ 个顶点、$ n-1 $ 条边的无环连通子图）
  • $ e $：树中的一条边；$ w(e) $：边 $ e $ 的权值
  • $ \text{cost}(T) $：整棵树的边权和，Prim 的目标就是让它最小

核心要点

  • 本质是点集扩张的贪心：每轮只关注"已覆盖 → 未覆盖"的可增广边
  • 用 visited 数组区分已覆盖与未覆盖，判断边合法性只需 $ O(1) $
  • 用优先队列（最小堆）维护所有可增广边，快速取最小权边
  • 稠密图选 Prim（尤其邻接矩阵版 $ O(V^2) $），稀疏图选 Kruskal
  • 堆优化版复杂度 $ O(E \log V) $，适合边数较大的稀疏连通图
  • 对带负权边同样有效（只要图连通）；MST 权值和唯一，但树形可能不唯一

技术细节与参数详解

Prim 没有传统意义的"超参数"，但其工程实现中有若干关键数据结构与选择，直接决定正确性与性能：

#### 参数 1：图的存储结构（邻接矩阵 vs 邻接表）

  • 含义：图在内存中的组织方式，决定枚举邻居的代价
  • 类型：list[list[int]]（矩阵）或 list[list[tuple]]（邻接表）
  • 默认值：算法本身无默认，需自行实现；竞赛/工程常见二选一
  • 取值范围：矩阵 $ V \times V $；邻接表总长 $ 2E $
  • 对结果的影响：结果（边集）相同，但时间复杂度不同——矩阵版单轮"取最小"需扫 $ V $ 个点 → 总 $ O(V^2) $；邻接表版配合堆为 $ O(E\log V) $
  • 推荐设置：顶点数 $ \le 2000 $ 且图较稠密时用邻接矩阵（实现简单）；稀疏大图用邻接表 + 二叉堆

#### 参数 2：visited 标记数组

  • 含义：标记每个顶点是否已收入生成树集合 $ U $
  • 类型：list[bool] 或位图
  • 默认值：全部 False，起点 True
  • 取值范围：$ \{True, False\} $ 共 $ n $ 个
  • 对结果的影响：判断"边合法"的唯一依据——合法边必须连接一个已覆盖点和一个未覆盖点；若两端都覆盖则跳过（否则成环）
  • 推荐设置：起点任意选择，最终权值和不变（MST 可能不唯一）

#### 参数 3：优先队列（最小堆）

  • 含义：保存所有"一端已覆盖"的候选边，按权值升序弹出
  • 类型：二叉堆（heapq）、配对堆、斐波那契堆
  • 默认值：Python 标准库 heapq
  • 取值范围：堆中最多同时存在 $ O(E) $ 条边
  • 对结果的影响：决定取最小边的时间——二叉堆弹出/插入均 $ O(\log E) $；懒惰删除（lazy deletion）允许堆中存在"过期边"，弹出时再验证合法性，实现更简单
  • 推荐设置：heapq + 懒惰删除（每轮压入新边的同时保留旧边，弹出时验证 visited 跳过）

#### 参数 4：key/dist 数组（另一种常见实现）

  • 含义：每个未覆盖顶点到 $ U $ 的最小连接边权
  • 类型：list[float/int]，长度 $ n $
  • 默认值：起点为 0，其余 $ \infty $
  • 取值范围：$ [0, \max w) $
  • 对结果的影响：不使用堆时，每次扫描 $ V $ 个未覆盖顶点取最小 dist，总复杂度 $ O(V^2) $——稠密图首选；配合堆+松弛（relax）等价于堆优化版
  • 推荐设置：稠密图直接用数组扫描；稀疏图用堆优化（把 (dist, v) 压堆）

#### 参数 5：起始顶点选择

  • 含义：第一次并入 $ U $ 的顶点
  • 类型：任意顶点编号（$ 0 \sim n-1 $）
  • 默认值：任意（通常取 0 或第一个顶点）
  • 对结果的影响：生成树具体形态可能不同，但权值和唯一最小；图连通时算法必然覆盖全部顶点
  • 注意：图不连通时算法提前终止（堆空但仍有未覆盖顶点），需在外层判定连通性

代码示例（邻接表 + 二叉堆，每行注释）

import heapq  # 标准库最小堆，O(log n) 插入与弹出

def prim(n, adj):
    """
    求带权连通图的最小生成树总权值（Prim + 堆优化）
    :param n:   顶点个数，顶点编号 0..n-1
    :param adj: 邻接表，adj[u] = [(v1, w1), (v2, w2), ...]
    :return:    (总权值, 树边数) 或 None（图不连通）
    """
    visited = [False] * n          # visited[i] 标记顶点 i 是否已并入生成树
    heap = []                       # 最小堆：存放候选边 (权值, 目标顶点)
    heapq.heappush(heap, (0, 0))    # 压入起点 0，权值 0 保证第一轮先取它
    total = 0                       # 累计生成树边权和
    cnt = 0                         # 已并入顶点数（最终应为 n）
    while heap:                     # 堆非空则继续扩张
        w, u = heapq.heappop(heap)  # 弹出可增广边中权值最小的一条 (w, u)
        if visited[u]:              # 若 u 已在树中，说明是懒惰删除的过期边
            continue                # 直接跳过，不重复处理
        visited[u] = True           # 将 u 并入已覆盖集合 U
        total += w                  # 累加该边权值（起点首轮的 w=0 不影响）
        cnt += 1                    # 已选顶点数 +1
        for v, wv in adj[u]:        # 遍历 u 的所有邻边，产生新的可增广边
            if not visited[v]:      # 只把"未覆盖"端点 v 的边加入堆
                heapq.heappush(heap, (wv, v))  # 堆内允许重复边，弹出时再验证
    return (total, cnt - 1) if cnt == n else None
    # cnt == n 表示覆盖所有顶点；树边数 = 顶点数 - 1

# 测试：7 个顶点、9 条边的带权无向图
n = 7
edges = [(0,1,2),(0,2,4),(1,2,1),(1,3,3),(2,4,5),(3,4,6),(3,5,8),(4,5,7),(5,6,9)]
adj = [[] for _ in range(n)]         # 初始化邻接表
for u, v, w in edges:
    adj[u].append((v, w))            # 无向图：u -> v 存一条
    adj[v].append((u, w))            # 无向图：v -> u 再存一条
print(prim(n, adj))  # 输出 (总权值, 树边数)

复杂度分析

时间复杂度（堆优化版）：最外层循环进行 $ n $ 次"确定一个顶点"（含起点），每次弹出堆顶 $ O(\log E) $；每条边最多入堆一次，$ O(E) $ 次压入 $ O(\log E) $。故总时间

$$ T(n,E) = O(n\log E) + O(E\log E) = O(E\log E) = O(E\log V) $$

其中 $ V $ 为顶点数、$ E $ 为边数（$ E \le V^2 $ 时 $ \log E = O(\log V) $）。若使用斐波那契堆可降到 $ O(E + V\log V) $。

  • 邻接矩阵朴素版：每轮扫描全部 $ V $ 个顶点取最小 dist，共 $ V $ 轮：$ T = O(V^2) $，不依赖 $ E $，故稠密图（$ E \approx V^2 $）比堆版更优。
  • 空间复杂度：visited 数组 $ O(V) $ + 邻接表 $ O(V+E) $ + 堆中最多 $ O(E) $ 个元素，总 $ O(V+E) $；邻接矩阵版为 $ O(V^2) $。

应用场景

  • 网络布线：设计局域网/数据中心/电网线路，使所有节点连通且总造价最小
  • 电信网络规划：基站回传线路、光缆规划、核心网拓扑设计，天然是 MST 问题
  • 路网与管网规划：城市道路、水气管网最短连通方案
  • 图像处理：图像分割中的最小生成树聚类（区域合并）
  • 算法基础：TSP 的 MST 下界、单链接聚类与 MST 等价

Q-Learning

类别：强化学习 | 难度：中等

核心简介

Q-Learning 是强化学习中最经典的无模型（model-free）、离策略（off-policy）时序差分（TD）算法，由 Chris Watkins 于 1989 年提出。它让智能体（Agent）在与环境（Environment）的不断交互中，通过"试错"学习最优决策策略。核心思想是维护一张 Q 表（Q-Table）：以状态为行、动作为列的二维表，每个单元格 $ Q(s,a) $ 表示"在状态 $ s $ 下执行动作 $ a $ 的预期长期回报"。智能体在每个状态按 ε-贪婪策略选择动作（大概率选当前 Q 值最大的动作——利用 exploitation；小概率随机选动作——探索 exploration），执行后获得即时奖励 $ r $ 与新状态 $ s' $，再用贝尔曼方程迭代更新 Q 值，使其逐渐收敛到真实最优值。它不需要环境的转移概率模型（"无模型"含义），只需交互采样。理论上，对有限马尔可夫决策过程（MDP），充分探索 + 满足 Robbins–Monro 条件时 Q 表必然收敛。是机器人控制、游戏 AI、导航等序贯决策的入门基石。

原理示意图

数学公式

1. Q 值更新公式（Q-Learning 核心）

$$ Q(s,a) \leftarrow Q(s,a) + \alpha\left[ r + \gamma \max_{a'} Q(s',a') - Q(s,a)\right] $$

  • $ s $：当前状态；$ a $：当前执行的动作
  • $ s' $：执行动作后转移到的下一状态
  • $ Q(s,a) $：更新前的状态-动作值（旧估计）
  • $ \alpha $：学习率，$ 0<\alpha\le 1 $，控制新信息修正旧估计的强度
  • $ r $：执行动作 $ a $ 后获得的即时奖励
  • $ \gamma $：折扣因子，$ 0\le\gamma<1 $，未来奖励的衰减系数
  • $ \max_{a'}Q(s',a') $：下一状态所有动作的最大 Q 值（对未来最优值的估计）
  • 方括号整体为时序差分误差（TD Error）：$ \delta = r + \gamma\max_{a'}Q(s',a') - Q(s,a) $

2. 贝尔曼最优方程（理论基石）

$$ Q^*(s,a) = r(s,a) + \gamma \sum_{s'} P(s'|s,a)\max_{a'} Q^*(s',a') $$

  • $ Q^* $：最优状态-动作值函数
  • $ P(s'|s,a) $：转移概率。Q-Learning 不需显式知道 $ P $，而是靠交互采样估计（无模型含义）
  • 该方程递归定义：当前价值 = 即时奖励 + 折扣后的未来最优价值期望

3. 学习率收敛条件（Robbins–Monro）

$$ \sum_{t=1}^{\infty}\alpha_t = \infty,\qquad \sum_{t=1}^{\infty}\alpha_t^2 < \infty $$

  • $ \alpha_t $：第 $ t $ 步的学习率（可衰减，如 $ \alpha_t=1/t $）
  • 含义：和发散保证可覆盖所有经验，平方和收敛保证估计方差收敛，从而 Q 值收敛到最优

4. ε-贪婪策略

$$ a = \begin{cases}\text{随机动作} & \text{概率 }\varepsilon\\ \arg\max_{a}Q(s,a) & \text{概率 }1-\varepsilon\end{cases} $$

  • $ \varepsilon $：探索概率，$ 0\le\varepsilon\le 1 $；高 $ \varepsilon $ 鼓励探索，低 $ \varepsilon $ 倾向利用

核心要点

  • 无模型：不需要转移概率与奖励模型，只依赖交互采样
  • 离策略：行为策略（ε-greedy）与目标策略（argmax 纯贪心）不同，仍收敛到最优 Q*
  • Q 表规模 = 状态数 × 动作数：离散化前提，状态空间大时"维度灾难"
  • 探索-利用权衡是核心难点：ε 过大学不到最优，过小陷局部最优
  • 收敛性：有限 MDP + 充分探索 + Robbins–Monro 条件 → 收敛
  • 局限：泛化差（未见状态无迁移）、收敛慢、仅适用于离散空间（连续空间需离散化或换 DQN）

技术细节与参数详解（FrozenLake 实践参数）

#### 参数 1：learning_rate（α，学习率）

  • 含义：新经验（TD 目标）对旧 Q 值修正的权重
  • 类型：浮点数
  • 默认值：无官方默认，常见 0.1~0.7
  • 取值范围：$ (0,1] $；α=0 永不更新，α=1 完全替换为 $ r+\gamma\max Q(s',a') $
  • 对结果的影响：α 过大震荡不收敛，过小收敛极慢
  • 推荐设置：环境确定/简单用 0.5~0.7；噪声大用 0.1~0.3；后期可衰减

#### 参数 2：gamma（γ，折扣因子）

  • 含义：未来奖励的折现比例，平衡即时与长期回报
  • 类型：浮点数
  • 默认值：常用 0.9~0.99
  • 取值范围：$ [0,1) $；γ=0 只看即时奖励，γ→1 追求长期总回报
  • 对结果的影响：γ 越小越短视；γ 越大越注重远期；无限时域任务必须 γ<1 保证值有界收敛
  • 推荐：长期规划取 0.9~0.99；短期任务 0.5~0.9

#### 参数 3：max_epsilon（初始探索率）

  • 含义：训练开始时探索概率上界
  • 默认值：通常 1.0（初期完全随机探索，了解环境全貌）
  • 取值范围：$ [0,1] $
  • 对结果的影响：设得过小导致初期过早利用，错过最优；设 1.0 保证充分探索

#### 参数 4：min_epsilon（最小探索率）

  • 含义：探索率衰减的下界，保留少量探索以应对环境变化
  • 默认值：0.05
  • 取值范围：$ [0,1] $，通常 0.01~0.1
  • 对结果的影响：过低在环境动态变化时无法适应；过高后期仍大量随机动作导致策略不稳

#### 参数 5：decay_rate（探索衰减率）

  • 含义：指数衰减速度，控制 ε 从 max 到 min 的快慢
  • 默认值：经验值 0.0001~0.001（取决于训练回合数）
  • 取值范围：$ (0,\infty) $，越大衰减越快
  • 对结果的影响：过大导致探索过早枯竭；过小则长期随机行动、学习效率低
  • 常见公式：指数衰减 ε = min_epsilon + (max_epsilon - min_epsilon) exp(-decay_rate episode)

#### 参数 6：n_training_episodes（训练回合数）

  • 含义：完整训练序列（初始状态→终止状态）的总次数
  • 类型：整数
  • 默认值：复杂环境需 $ 10^4\sim10^5 $ 量级
  • 对结果的影响：回合太少未收敛；太多浪费时间；评估时应关闭探索（纯贪心）
  • 评估方式：每 1000 回合做一次无探索评估，平均奖励趋于稳定即收敛

#### 参数 7：max_steps（每回合最大步数）

  • 含义：一回合内最大交互步数，防止智能体无限兜圈
  • 默认值：应大于最短路径长度（如 FrozenLake 用 99）
  • 对结果的影响：过小可能导致回合提前终止，无法到达目标

#### 参数 8：reward 奖励设计（环境侧）

  • 含义：环境对行为的即时反馈，引导学习方向
  • 默认值：FrozenLake：终点 +1，落洞/其他 0
  • 取值范围：任意实数；稀疏奖励（大部分为 0）收敛慢
  • 对结果的影响：奖励稀疏时需更多探索才偶发正反馈；可用内部势能（Potential-based shaping）加速
  • 推荐：简单任务保持简单奖励 + 足够多回合

#### 参数 9：Q 表初始化

  • 含义：所有 $ Q(s,a) $ 的初始值
  • 默认值：np.zeros((|S|, |A|))
  • 对结果的影响：全 0 较为中性；乐观初始化（高初值）鼓励先探索未知，加速早期探索；过高则前期过度乐观
  • 推荐：简单任务用全 0；鼓励探索可给正小初值（如 1.0）

代码示例（FrozenLake 环境，每行注释）

import numpy as np          # 数值计算库，用于 Q 表与 argmax
import random               # 随机数：探索动作
import gymnasium as gym     # 强化学习环境库（OpenAI Gym 后继）

# 1. 参数初始化
state_space = 16            # FrozenLake 4×4：16 个状态
action_space = 4            # 4 个动作：上下左右
Q = np.zeros((state_space, action_space))  # Q 表，全部初始为 0
alpha = 0.1                 # 学习率 α：控制新经验修正力度，0.1 更稳定
gamma = 0.99                # 折扣因子 γ：0.99 重视长期回报
max_epsilon = 1.0           # 初始探索率：初期完全随机探索
min_epsilon = 0.01          # 最小探索率：后期保留 1% 随机性
decay = 0.0005              # 衰减率：控制 ε 从 1.0 降到 0.01 的速度
episodes = 20000            # 训练回合数：多回合充分探索
max_steps = 200             # 每回合最多步数，防死循环

env = gym.make('FrozenLake-v1', map_name='4x4', is_slippery=False)
# 创建环境：非滑动模式（确定性），便于入门

def choose_action(state, eps):
    """ε-贪婪策略：根据当前 Q 值选择动作"""
    if random.uniform(0, 1) < eps:          # 以概率 eps 随机探索
        return random.randint(0, action_space - 1)  # 随机动作
    return int(np.argmax(Q[state]))       # 否则选 Q 值最大的动作（利用）

# 2. 训练主循环
for ep in range(episodes):
    state, _ = env.reset()   # 重置环境，得到初始状态（0）
    eps = min_epsilon + (max_epsilon - min_epsilon) * np.exp(-decay * ep)
    # 每回合重算 ε：指数衰减，从 max_epsilon 单调降到 min_epsilon
    done = False             # 终止标志
    step = 0
    while not done and step < max_steps:   # 未结束且未超步数时继续
        a = choose_action(state)           # 1) 依 ε-greedy 选择动作
        s2, r, terminated, truncated, _ = env.step(a)  # 2) 执行，得到新状态 s2 与奖励 r
        done = terminated or truncated    # 3) 判断回合是否结束
        # 4) 核心更新：TD target = r + γ·max Q(s2)；TD error = target − Q(state,a)
        td_error = r + gamma * np.max(Q[s2]) - Q[state, a]
        Q[state, a] += alpha * td_error   # 5) 新 Q = 旧 Q + α·TD error
        state = s2              # 6) 状态转移
        step += 1               # 步数 +1

# 3. 评估（纯利用，ε=0）
total = 0
for _ in range(100):
    state, _ = env.reset()
    done = False
    while not done:
        a = int(np.argmax(Q[state]))     # 完全贪心：只选 Q 最大动作
        state, r, terminated, truncated, _ = env.step(a)
        done = terminated or truncated
    total += r
print(f"100 回合评估平均奖励：{total/100:.2f}")  # 收敛后应接近 1.0

复杂度分析

  • 时间复杂度（训练）：设训练回合数 $ N $、每回合平均步数 $ L $，总交互 $ O(N\cdot L) $；每步仅 Q 表随机访问与更新 $ O(1) $，np.max(Q[s2]) 需扫描动作数 $ |A| $：$ O(|A|) $。总训练时间 $ O(N\cdot L\cdot |A|) $。
  • 空间复杂度：Q 表 $ O(|S|\times |A|) $。状态数随维度指数增长（维度灾难）：10 个离散变量每 10 档即 $ 10^{10} $ 状态。
  • 收敛复杂度：理论上需"每个状态-动作对访问无限次"才保证收敛，实践中依赖 $ \gamma $ 与奖励稀疏性，通常需 $ 10^4\sim10^5 $ 回合。

线性判别分析（LDA）

类别：监督学习 | 难度：中等

核心简介

线性判别分析（Linear Discriminant Analysis, LDA）是经典有监督降维与分类算法（与 NLP 中的主题模型 LDA "Latent Dirichlet Allocation" 完全不同）。核心思想：在数据服从多元高斯分布、且各类共享同一协方差矩阵的假设下，寻找线性投影方向 $ w $，使投影后同类数据尽量紧凑（类内散度最小）、异类数据尽量远离（类间散度最大），从而既能降维（最多压到 $ K-1 $ 维，$ K $ 为类别数），又能得到线性决策边界进行分类。分类侧利用贝叶斯公式把后验取对数，等价于"球化"空间中按马氏距离选最近均值并乘先验。LDA 有解析解、无需调参、可解释性强，广泛用于人脸识别、光谱分析、医学统计、金融风控等。

原理示意图

数学公式

1. 贝叶斯后验（分类模型基础）

$$ \log P(k|x) \propto -\tfrac{1}{2}(x-\mu_k)^{\mathsf{T}}\Sigma^{-1}(x-\mu_k) + \log\pi_k $$

  • $ k $：类别索引；$ x $：待分类 $ d $ 维特征向量
  • $ \mu_k $：第 $ k $ 类均值向量
  • $ \Sigma $：共享的 $ d\times d $ 协方差矩阵（各类相同——LDA 核心假设）
  • $ \Sigma^{-1} $：协方差矩阵的逆
  • $ \pi_k $：第 $ k $ 类先验概率（和为 1）
  • 第一项即马氏距离：$ (x-\mu_k)^{\mathsf{T}}\Sigma^{-1}(x-\mu_k) $

2. 类间散度与类内散度矩阵

$$ S_B = \sum_{k=1}^{K}n_k(\mu_k - \mu)(\mu_k - \mu)^{\mathsf{T}},\qquad S_W = \sum_{k=1}^{K}\sum_{i\in C_k}(x_i-\mu_k)(x_i-\mu_k)^{\mathsf{T}} $$

  • $ n_k $：第 $ k $ 类样本数；$ \mu $：总体均值向量
  • $ x_i $：第 $ i $ 个样本；$ C_k $：第 $ k $ 类样本集合
  • $ S_B $：类间散度（各类均值相对总体均值的离散程度）
  • $ S_W $：类内散度（各类内部样本离散程度）

3. LDA 目标（广义瑞利商）与特征分解

$$ w^{*} = \arg\max_{w}\frac{w^{\mathsf{T}}S_B w}{w^{\mathsf{T}}S_W w},\qquad S_B w = \lambda S_W w $$

  • $ w $：投影方向向量；$ w^{\mathsf{T}}S_B w $：投影后类间方差；$ w^{\mathsf{T}}S_W w $：投影后类内方差
  • 最大化该比值 → 类间远、类内紧凑
  • 广义特征分解：$ S_B w = \lambda S_W w $，取前 $ K-1 $ 个最大特征值对应特征向量组成投影矩阵

4. 特征分解（solver='eigen'）

$$ S_W^{-1}S_B \Rightarrow \lambda_1 \ge \lambda_2 \ge \cdots \ge \lambda_{K-1} $$

  • $ \lambda_i $：第 $ i $ 大特征值，衡量第 $ i $ 个判别方向的判别信息量
  • $ n\_components $ 取前 $ l $ 个方向实现降维

核心要点

  • LDA 是监督（需要标签），PCA 是无监督——两者最大区别
  • 最多投影到 $ K-1 $ 维（$ K $ 为类别数）；二分类 → 1 维直线
  • 假设"各类共享协方差 + 高斯" → 线性边界；去掉共享假设则成为 QDA（二次判别）
  • 特征数 >> 样本数时协方差奇异，需 shrinkage 或 svd
  • n_components 仅影响 transform，不影响 fit/predict

技术细节与参数解析（sklearn）

#### 参数 1：solver

  • 含义：求投影方向使用的数值求解方法
  • 类型：字符串，可取值 'svd'、'lsqr'、'eigen'
  • 默认值：'svd'
  • 取值范围：
  • 'svd'：奇异值分解，不显式算协方差矩阵，适合特征极多（高维）；不能与 shrinkage/covariance_estimator 配合
  • 'lsqr'：最小二乘解，支持 shrinkage，仅用于分类（不可 transform 降维）
  • 'eigen'：特征分解，支持 shrinkage 与协方差估计器，可分类可 transform；需显式计算协方差，特征多内存大
  • 对结果的影响：数学上等价，数值稳定性与适用范围不同
  • 推荐设置：常规中小数据 'svd'；高维小样本选 'eigen' 或 'lsqr'+shrinkage；需要降维必须 'svd'/'eigen'

#### 参数 2：shrinkage（收缩系数）

  • 含义：对样本协方差做收缩（向对角阵/单位阵收缩），缓解"样本数 << 特征数"的病态
  • 类型：None、'auto' 或浮点数
  • 默认值：None（不收缩）
  • 取值范围：'auto' 自动按 Ledoit–Wolf 估计最优收缩量；数值 $ [0,1] $：0=不收缩，1=完全收缩为对角阵
  • 对结果的影响：小样本高维时，不收缩分类方差大；适度收缩提升泛化；过大丢失结构
  • 注意：仅在 solver in ('lsqr','eigen') 生效；使用 covariance_estimator 时须为 None

#### 参数 3：priors（先验概率）

  • 含义：各类别先验 $ \pi_k $
  • 类型：array-like，长度 $ K $（类别数）
  • 默认值：None → 用训练集类别比例
  • 对结果的影响：类别不平衡时设置非均匀先验可纠正偏斜；须非负且和为 1

#### 参数 4：n_components（降维维数）

  • 含义：降维后保留的判别方向个数（仅影响 transform）
  • 类型：整数
  • 默认值：None → $ \min(K-1, d) $
  • 取值范围：$ \le\min(K-1, d) $
  • 对结果的影响：设小则损失少量判别信息，适合可视化；不影响分类预测

#### 参数 5：store_covariance

  • 含义：solver='svd' 时是否显式计算并存储类内协方差矩阵
  • 类型：布尔值
  • 默认值：False
  • 对结果的影响：True 增加计算量与内存，可供查看 covariance_ 属性

#### 参数 6：tol

  • 含义：判定 X 的奇异值是否显著的绝对阈值（估计 X 的秩）
  • 类型：浮点数
  • 默认值：1e-4
  • 对结果的影响：小于阈值奇异值对应维度被丢弃；仅对 solver='svd' 生效

#### 参数 7：covariance_estimator（自定义协方差估计器）

  • 含义：用自定义估计器（需有 fit 与 covariance_ 属性，如 LedoitWolf、OAS）替代经验协方差
  • 默认值：None
  • 对结果的影响：小样本高维时更稳健；仅与 'lsqr'/'eigen' 兼容；与 shrinkage 互斥

代码示例（Iris 数据集，每行注释）

import numpy as np                          # 数值运算
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis as LDA  # 导入 LDA 分类器
from sklearn.datasets import load_iris      # 经典三分类数据集
from sklearn.model_selection import train_test_split  # 划分训练/测试集
from sklearn.metrics import accuracy_score   # 准确率指标

X, y = load_iris(return_X_y=True)           # X:150×4 特征；y:150 个类别(0/1/2)
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.3, random_state=42)
# 70% 训练 / 30% 测试，固定随机种子保证可复现

lda = LDA(solver='svd', n_components=2)
# 创建 LDA 模型：svd 求解（默认，数值稳定）；降到 2 维便于可视化
lda.fit(X_train, y_train)                  # 用训练集拟合：计算各类均值、共享协方差、投影方向
X_proj = lda.transform(X_test)             # 将测试集投影到 2 维判别空间
print("投影后数据形状:", X_proj.shape)       # (45, 2) —— 类别数3，故最大降2维

pred = lda.predict(X_test)                 # 在原始空间中用贝叶斯分类
print("分类准确率:", accuracy_score(y_test, pred))  # 通常 >0.95

复杂度分析

  • 时间复杂度：设样本数 $ N $、特征数 $ d $、类别数 $ K $：
  • 计算各类均值 $ O(Nd) $；计算类内散度 $ S_W $ 需遍历样本做外积：$ O(Nd^2) $；广义特征问题 $ O(d^3) $。
  • 使用 'svd' 求解器避免显式协方差，仅做数据矩阵 SVD：约 $ O(Nd^2) $（$ N>d $ 时）。
  • 总时间一般 $ O(Nd^2 + d^3) $，特征数 $ d $ 大时高。
  • 空间复杂度：均值 $ K\times d $、协方差 $ d\times d $、投影矩阵 $ d\times(K-1) $：约 $ O(d^2 + Kd) $；svd 模式省掉 $ d\times d $ 协方差的显式存储。
  • 预测阶段：每个样本与 $ K $ 个均值算马氏距离 $ O(Kd^2) $（协方差预分解则 $ O(Kd) $）。
