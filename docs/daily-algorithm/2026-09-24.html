Prim 最小生成树

类别：图算法 | 难度：中等

算法简介

Prim（普里姆）算法用于求解连通带权无向图的最小生成树（Minimum Spanning Tree, MST）：从图中选出 n-1 条边，把全部 n 个顶点连成一棵树，且边权总和最小。与「每次挑全局最短的边」的 Kruskal 不同，Prim 是以点为中心生长：维护一个已加入树中的顶点集合 U，每一步都从「横跨 U 与 V−U 的所有边」中挑出权值最小的一条，把 U 外的那个顶点吸入树中，如此重复 n−1 次。该贪心策略的正确性由切分定理（Cut Property）保证：对图的任意一个割集，横跨割集的最小权边必定属于某棵最小生成树。Prim 天然适合稠密图（边多）与「以某点为中心扩建」的场景：朴素实现 O(V²) 与边数无关；配合优先队列（堆）优化后为 O(E log V)，边越稀疏越占优。工程上它是电网组网、光缆布线、网络路由协议（如 STP 的思想近亲）、聚类与 TSP 近似解的地基算法。

原理示意图

数学公式

公式 1：生成树的权值（优化目标）

$$ w(T) = \sum_{e \in T} w(e) \quad \text{s.t.} \quad |T| = n - 1,\ T \text{ 连通无环} $$

变量解释：

  • $ T $：生成树（边集合）
  • $ w(e) $：边 $ e $ 的权重（成本/距离）
  • $ |T| = n-1 $：n 个顶点的树恰有 n−1 条边（连通、无环的充要条件）

公式 2：切分定理（Prim 正确性的基石）

$$ \text{若 } e^* = \arg\min_{e \in \delta(U)} w(e), \text{ 则存在一棵 MST 包含 } e^* $$

变量解释：

  • $ U $：顶点集 $ V $ 的任意非空真子集（已入树的顶点集合）
  • $ \delta(U) = \{(u, v) \mid u \in U,\ v \in V \setminus U\} $：横跨 $ U $ 与 $ V \setminus U $ 的割集（所有候选边）
  • $ e^* $：割集中权值最小的边
  • 含义：反证可证，若某 MST 不含 $ e^* $，把它加入 MST 会成环，环上必有一条横跨割集的边 $ e' $，且 $ w(e') \geq w(e^*) $，替换它们权值不增。每一步的局部最优叠加为全局最优。

公式 3：Prim 的贪心迭代规则（key 数组松弛）

$$ \text{选点：} u^* = \arg\min_{v \in V \setminus U} key[v], \qquad \text{松弛：} key[v] \leftarrow \min\big(key[v],\ w(u^*, v)\big) $$

变量解释：

  • $ key[v] $：顶点 $ v $ 到树中任意顶点的最短边权（初始 $ +\infty $，起点置 0）
  • $ u^* $：本轮被吸入树的顶点（当前离树最近的点）
  • $ w(u^*, v) $：新入树点 $ u^* $ 到其邻居 $ v $ 的边权
  • 松弛即：新点入树后，重新审视每个树外顶点的「最短连接」，只能变短不能变长

公式 4：时间复杂度（堆优化，惰性删除）

$$ T(V, E) = O\big(E \log E\big) = O(E \log V) \quad \left(\because E \le V^2 \Rightarrow \log E \le 2\log V\right) $$

变量解释：

  • $ E $：边数（每条边最多入堆一次，弹出均摊）
  • $ \log E $：二叉堆一次插入/弹出代价
  • 推导：每条无向边入堆至多 2 次（两个端点各触发一次松弛），堆操作总量 $ O(E) $ 次，每次 $ O(\log E) $

核心要点

  • 以点为中心生长：与 Kruskal「全局挑边+并查集」不同，Prim 始终在「树」与「树外」之间挑最小横跨边，天然不成环，不需要并查集
  • 稠密图首选：朴素 $ O(V^2) $ 版本只与点数相关，边再多也不变；稀疏图 $ E = O(V) $ 时用堆优化 $ O(E \log V) $ 更划算
  • 贪心正确性：切分定理保证每步局部最优 → 全局最优，无需回溯
  • 只能用于连通无向图：非连通图要先跑连通分量，对每个分量分别求 MST（得到最小生成森林）；有向图无 MST 概念（对应的是最小树形图/朱刘算法）
  • 权值可负：MST 的贪心只比较相对大小，负权边不影响正确性（这一点与最短路 Dijkstra 的非负要求不同）
  • 解不唯一：当存在多条等权横跨边时有多棵 MST，但最小总权值唯一（部分题目据此要求输出字典序最小的树）

技术细节与参数详解

#### 参数 1：起点 start

  • 含义：算法开始时唯一入树的顶点 $ u_0 $，即 $ U $ 的初始元素
  • 类型：顶点编号（int 或任意可哈希对象）
  • 默认值：无（通常取 0 号顶点或任意点）
  • 取值范围：图中任意一个顶点
  • 对结果的影响：不影响最小总权值（MST 权值与起点无关）——由切分定理可证任意起点收敛到同一最优值；但影响等权情况下具体选哪条边，即多解时生成的树可能不同
  • 推荐设置：任意；工程上可从「度数最大的点」出发，使 key 数组更早被填满有意义值，略微减少堆操作

#### 参数 2：图存储结构（邻接矩阵 vs 邻接表）

  • 含义：底层携带图的数据结构，直接决定朴素 Prim 的效率
  • 类型：邻接矩阵（二维 list[list[int]]，adj[u][v] 存边权）或邻接表（list[list[(v, w)]]，每点挂 (邻居, 边权) 列表）
  • 默认值：算法题中按数据范围选择
  • 取值范围：矩阵空间 $ O(V^2) $；邻接表空间 $ O(V + E) $
  • 对结果的影响：不影响结果，只影响性能。矩阵版朴素 Prim 内层扫描「$ u^* $ 的所有出边」为 $ O(V) $，总 $ O(V^2) $；邻接表版配合堆为 $ O(E \log V) $。$ V \le 5000 $ 两者皆可，$ V $ 更大必须邻接表
  • 推荐设置：稠密图（$ E \approx V^2 $，如完全图）→ 邻接矩阵 + 朴素 $ O(V^2) $；稀疏图（$ E \approx V $）→ 邻接表 + 小根堆

#### 参数 3：优先队列实现（朴素数组 / 二叉堆 / 索引堆）

  • 含义：维护「树外顶点按 key 值排序」的数据结构，是性能的命门
  • 类型：朴素数组线性扫 min、heapq 二叉堆（惰性删除）、索引优先队列（支持 decrease-key）
  • 默认值：Python 中几乎都用 heapq（标准库无索引堆）
  • 取值范围与复杂度对照：
  • 朴素数组：找 min $ O(V) $ × 共 $ V $ 轮 → $ O(V^2) $（堆优化中的退化选择）
  • 二叉堆 + 惰性删除：堆中允许过期条目（出堆时检查 visited），每边最多 2 次入堆 → $ O(E \log V) $
  • 斐波那契堆（理论）：decrease-key 摊还 $ O(1) $ → $ O(E + V\log V) $（仅论文/竞赛层面意义）
  • 对结果的影响：不影响结果；影响时间与内存（惰性堆峰值大小 $ O(E) $，可临时膨胀）
  • 推荐设置：Python 直接 heapq + 惰性删除，简单且够快；面试手写时它是标准答案写法

#### 参数 4：key[ ] 数组（候选距离表）

  • 含义：key[v] 存顶点 v 「连入当前树的最小候选边权」，是 Prim 与 Dijkstra 最像的地方
  • 类型：一维数组，元素为 int/float
  • 默认值：全部初始化为 +∞（表示尚无边可达），key[start] = 0
  • 取值范围：$ [0, \infty) $；已入树顶点的 key 可视为「锁定值」不再参与
  • 对结果的影响：初值错误（如初始化为 0）会让算法一开始就把所有点视为可达；松弛方向写反（用 key[u] + w 累加）会退化成 Dijkstra 语义——Prim 是 key[v] = min(key[v], w(u,v))，没有加法！
  • 推荐设置：INF = float('inf') 或远大于所有边权之和的整数（避免溢出）

#### 参数 5：visited[ ] 数组（入树标记）

  • 含义：标记顶点是否已被吸收进树 $ U $，是防止成环、防止重复处理的关键
  • 类型：一维布尔数组
  • 默认值：全部 False
  • 取值范围：True / False
  • 对结果的影响：漏判visited会导致环（错误结果）；堆的惰性删除写法中，出堆时若 visited 已真必须 continue 跳过过期条目，否则同一点会被多次入树
  • 推荐设置：入树瞬间立即置 True；也可用「key 数组 + 集合」替代

#### 参数 6：parent[ ] 数组（前驱表，还原树）

  • 含义：parent[v] 记录 v 是「经过哪个顶点」被拉进树的，配合 key[v] 可还原出整棵 MST 的边集合
  • 类型：一维整数数组
  • 默认值：全部 -1
  • 取值范围：$ [-1, V) $；parent[start] = -1 恒成立
  • 对结果的影响：不影响 w(T)，只影响输出形式；求「具体选了哪些边 / 打印建设方案」时必需
  • 推荐设置：松弛成功时同步写 parent[v] = u^*，务必与 key 更新放在同一个 if 分支里

#### 参数 7：networkx.minimum_spanning_tree 的参数（库函数层）

  • 含义：Python 生态里直接可用的 MST 接口，支持指定 Prim
  • 类型：minimum_spanning_tree(G, weight='weight', algorithm='prim', ignore_nan=False)
  • 默认值：weight='weight'（读取边属性名）、algorithm='kruskal'（默认克鲁斯卡尔）、ignore_nan=False
  • 取值范围：algorithm ∈ {'kruskal', 'prim', 'boruvka'}；weight 为边属性字符串；ignore_nan 为布尔
  • 对结果的影响：algorithm 不改变最小权值（三者同解，多解时可能选边不同）；weight 指定用哪条边属性当权重；ignore_nan=True 时把含 NaN 的边当作不存在，False 则抛异常
  • 推荐设置：竞赛/面试手写为主；工程脚本用 networkx 时指定 algorithm='prim' 即可复现本文逻辑

代码示例

import heapq                                    # 导入标准库二叉堆（小根堆）

def prim_mst(n, adj, start=0):
    """
    堆优化 Prim 求最小生成树
    n: 顶点数(编号0..n-1)  adj: 邻接表 adj[u] = [(v, w), ...]  start: 起点编号
    返回: (最小总权值, 树的边列表)
    """
    INF = float('inf')                          # 无穷大哨兵，表示「尚无候选边」
    visited = [False] * n                       # visited[v]：顶点v是否已入树(初始都未入)
    key = [INF] * n                             # key[v]：v连入树的最小候选边权(初始+∞)
    parent = [-1] * n                           # parent[v]：v经哪个顶点入树(初始-1，用于还原树)
    key[start] = 0                              # 起点到“树”的距离定义为0，保证第一个出堆的是起点
    heap = [(0, start)]                         # 堆元素：(到树的最短边权, 顶点)，惰性删除写法
    total, edges = 0, []                        # total：累计边权；edges：选中的树边列表

    while heap:                                 # 堆不空则树外还有候选(连通图会在选满n个点后自然排空)
        w_u, u = heapq.heappop(heap)            # 弹出当前离树最近的顶点u及其边权w_u
        if visited[u]:                          # 惰性删除：u早已入树，这是过期条目
            continue                            #   直接跳过，不重复处理
        visited[u] = True                       # 正式把u吸收进树U
        total += w_u                            # 累加这条“入树边”的权值
        if parent[u] != -1:                     # 起点没有入树边，其余点记录(parent[u], u, w_u)
            edges.append((parent[u], u, w_u))   # 保存树边，供还原/打印建设方案
        for v, w in adj[u]:                     # 松弛：遍历新点u的所有邻居v
            if not visited[v] and w < key[v]:   # 仅处理树外点，且找到更短的候选边
                key[v] = w                      # 更新v连入树的最小边权(注意是w不是key[u]+w)
                parent[v] = u                   # 同步记录前驱，v将来经u入树
                heapq.heappush(heap, (w, v))    # 新候选条目入堆，旧条目留在堆中作废即可
    return total, edges                         # 返回最小总权值与最小生成树的边集

# ---- 演示：与上方示意图同构的 7 顶点带权图 ----
n = 7                                                        # 顶点数 A,B,C,D,E,F,G → 0..6
def E(u, v, w): adj[u].append((v, w)); adj[v].append((u, w))  # 无向边双向登记的辅助函数
adj = [[] for _ in range(n)]                                 # 初始化空邻接表
E(0, 1, 4); E(0, 2, 3); E(1, 3, 2); E(1, 4, 7)               # A-B=4, A-C=3, B-D=2, B-E=7
E(2, 4, 5); E(3, 5, 6); E(4, 5, 1); E(4, 6, 8)               # C-E=5, D-F=6, E-F=1, E-G=8
print(prim_mst(n, adj, start=0))                             # 输出: (21, [(2,0,3),(1,0,4),(3,1,2),(4,2,5),(5,4,1),(4,6,8)])

复杂度分析

时间复杂度（堆优化 + 惰性删除）：

  • 每条无向边最多触发 2 次 heappush（两个端点各入树一次时各松弛一次），入堆操作总量 $ O(E) $；每次 push/pop 代价 $ O(\log H) $，堆峰值 $ H \le 2E $，故 $ T = O(E \log E) $
  • 由 $ E \le V(V-1)/2 \Rightarrow \log E \le 2 \log V $，等价写为 $ O(E \log V) $
  • 朴素实现（数组扫 min）：外层 $ V $ 轮 × 每轮扫 $ V $ 个 key + 扫全部边 → $ O(V^2) $，与 E 无关
  • 稀疏图（$ E = O(V) $）：堆版 $ O(V\log V) $ 优于朴素；稠密图（$ E = O(V^2) $）：堆版 $ O(V^2 \log V) $ 反而劣于朴素 $ O(V^2) $

空间复杂度：

  • 邻接表 $ O(V + E) $ + key/parent/visited 三数组 $ O(V) $ + 堆峰值 $ O(E) $ → 总计 $ O(V + E) $

应用场景

  • 通信/电力网络设计：n 个机房/基站用最少光缆/线缆连通（权=距离或造价），是 MST 最经典落地场景，装维工程中「片区组网最小布线」问题即为此模型
  • 网络协议与链路冗余计算：以太网 STP 消除二层环路的思想与生成树高度同源；SDN 控制器做最小开销拓扑计算
  • 聚类分析：单链接层次聚类的「最小间距合并」本质是 MST 逐步生长，切掉 MST 里最长的几条边即得簇
  • 图像分割：把像素视为顶点、相邻像素亮度差为边权，MST 切边法是经典快速分割管线（Felzenszwalb 算法核心）
  • TSP 近似解：先求 MST 再前序遍历，可得到不超过最优 2 倍的旅行商回路（度量空间下）
  • 电路布线与管线铺设：自来水管网、燃气管网的最小连通成本规划

Q-Learning

类别：强化学习 | 难度：中等

算法简介

Q-Learning 由 Chris Watkins 于 1989 年提出，是值函数方法中最经典的无模型（model-free）强化学习算法。它不依赖环境的转移概率模型，仅靠「智能体与环境试错交互」学出一张 Q 表：Q(s, a) 存「在状态 s 执行动作 a，之后一直按最优策略走的期望累计奖励」。核心机制是时序差分（TD）学习：每走一步，用「实际拿到的即时奖励 + 下一状态的乐观估计（max）」去修正当前 Q 值，公式为 $ Q \leftarrow Q + \alpha[r + \gamma\max_{a'}Q(s',a') - Q] $。它是 off-policy 算法——行为策略（例如 ε-greedy 探索）与被评估的目标策略（贪心 argmax）可以不同，这意味着探索充分性不影响学到的目标是最优的。在所有状态-动作对被无限次访问且满足 Robbins-Monro 随机近似条件（学习率衰减）的前提下，Q-Learning 以概率 1 收敛到最优动作值函数 $ Q^* $。表格版适用于中小规模离散状态空间；状态爆炸时它升级为 DQN（用神经网络逼近 Q），是 DeepMind 2015 年 Atari 的直系祖先。

原理示意图

数学公式

公式 1：折扣累计回报（学习目标）

$$ G_t = r_{t+1} + \gamma r_{t+2} + \gamma^2 r_{t+3} + \cdots = \sum_{k=0}^{\infty} \gamma^k \, r_{t+k+1} $$

变量解释：

  • $ G_t $：从时刻 $ t $ 起长期看总共能拿到的折扣奖励和（回报）
  • $ r_{t+k+1} $：第 $ k+1 $ 步之后环境反馈的即时奖励
  • $ \gamma \in [0, 1) $：折扣因子，越往后的奖励打折越狠，保证无穷级数收敛并体现「远期奖励不如近期」的偏好

公式 2：贝尔曼最优方程（Q 的不动点）

$$ Q^*(s, a) = \mathbb{E}_{s' \sim P}\left[\, r + \gamma \max_{a'} Q^*(s', a') \,\middle|\, s, a \right] $$

变量解释：

  • $ Q^*(s,a) $：最优动作值函数——状态 s 做动作 a 后永远按最优策略行动的期望回报
  • $ \mathbb{E}_{s' \sim P} $：对环境的随机转移 $ P(s'|s,a) $ 取期望（环境有随机性，如 FrozenLake 会打滑）
  • $ r $：本步即时奖励
  • $ \max_{a'} Q^*(s', a') $：下一个状态的乐观估计（假设之后都走最优）——这正是 Q-Learning off-policy 的根源

公式 3：Q-Learning 的 TD 更新规则（唯一的训练公式）

$$ Q(s_t, a_t) \leftarrow Q(s_t, a_t) + \alpha \Big[\underbrace{r_{t+1} + \gamma \max_{a'} Q(s_{t+1}, a')}_{\text{TD 目标 } y_t} - Q(s_t, a_t)\Big] $$

变量解释：

  • $ \alpha \in (0, 1] $：学习率，新旧估计的混合比例（0.1 表示只吸收 10% 的误差）
  • $ y_t = r_{t+1} + \gamma \max_{a'} Q(s_{t+1},a') $：TD 目标，一个「事后看到更多真相」的估计
  • $ \delta_t = y_t - Q(s_t,a_t) $：时序差分误差（TD error），衡量「惊喜」程度
  • 只有单步采样（不需要完整回合），即 bootstrap 自举：用估计修正估计

公式 4：ε-greedy 行为策略

$$ \pi(a \mid s) = \begin{cases} \text{随机动作（等概率）} & \text{概率 } \epsilon \\ \arg\max_a Q(s, a) & \text{概率 } 1 - \epsilon \end{cases} $$

变量解释：

  • $ \epsilon \in [0,1] $：探索概率，控制「尝鲜」频率
  • $ \arg\max_a Q(s,a) $：当前 Q 表下的贪心动作（利用 exploitation）
  • 随机探索保证每个 (s,a) 都有机会被访问→收敛的必要条件；训练后期衰减 ε 以稳定收敛

公式 5：收敛定理（Watkins & Dayan, 1992）

$$ \lim_{t \to \infty} Q_t(s, a) = Q^*(s, a) \ \text{(wp 1)}, \quad \text{若 } \sum_t \alpha_t = \infty,\ \sum_t \alpha_t^2 < \infty,\ \text{所有}(s,a)\text{被无限次访问} $$

变量解释：

  • 条件一 $ \sum \alpha_t = \infty $：学习率不能衰减太快，保证误差终能清零（步子总和要够长）
  • 条件二 $ \sum \alpha_t^2 < \infty $：方差要收敛，步子平方和有限（不能永远大步长震荡）
  • 条件三：持续探索（ε-greedy + 衰减即满足）；工程上常用固定小 ε 牺牲理论保证换实用稳定

核心要点

  • off-policy 双策略：训练用 ε-greedy（保探索），收敛目标用 greed argmax（保最优）；体验策略不重要，表格里的 Q 才是学到的「最优策略」
  • TD 单步自举：无需环境模型、无需完整回合、无需蒙特卡洛等到终局，每一步都立刻小幅修正 Q
  • max 过高估计偏差：$ \max $ 算子会系统性高估（毕竟取的是含噪声估计的最大值），后续 Double Q-Learning（拆两组表分别选与估）专门修这个偏差
  • 适用范围：状态与动作都得离散且可枚举，Q 表规模 $ |S| \times |A| $；连续/高维状态需先离散化或改用 DQN/Actor-Critic
  • 奖励设计是半条命：稀疏奖励（只有终点 +1）学习极慢，负的步进奖励（每步 -0.01）能加速收敛但可能诱发「走捷径冒险」
  • 冷启动与探索衰减配合：前期大 ε 广撒网，后期小 ε 精利用；ε 衰减太慢浪费时间，太快会过早锁死次优路径

技术细节与参数详解

#### 参数 1：α — 学习率（learning rate）

  • 含义：TD 误差 $ \delta $ 中被吸收进新 Q 值的比例，控制单次更新幅度
  • 类型：float（sklearn 之外的裸实现中直接写为超参数）
  • 默认值：社区惯用 0.1（无官方默认，自行设定）
  • 取值范围：(0, 1]
  • 对结果的影响：α 大→学得快但 Q 值震荡、对随机环境的噪声敏感、可能不收敛；α 小→收敛平稳但需要海量交互样本；α=1 完全相信最新 TD 目标（随机环境下 Q 剧烈抖动）。理论收敛要 α 按 Robbins-Monro 条件衰减（如 $ \alpha_t = 1/(N(s,a)+1) $）
  • 推荐设置：确定性环境取 0.5–1.0（无噪声，大步收敛反而快，迷宫必走最优）；随机环境（有打滑/噪声）取 0.1–0.3 并随回合衰减，或直接用 $ \alpha = 0.1 $ 配合大量 episode

#### 参数 2：γ — 折扣因子（discount factor）

  • 含义：未来第 k 步奖励的打折率，编码「远期值多少钱」；也保证无穷回报收敛
  • 类型：float
  • 默认值：0.9 / 0.95（Gymnasium 教程常客）
  • 取值范围：[0, 1)。γ=0 目光最短浅：只看即时奖励 r；γ→1 完全有远见：无限看重长期回报（回合任务可取 0.99+，连续任务勿取 1 否则回报发散）
  • 对结果的影响：γ 小→学出「功利短视」策略（绕近道拿小奖励，放弃远处大奖励）；γ 大→有耐心规划长线，但信用分配链变长、学习变慢；跨回合任务若 γ 太接近 1，Q 值可能难以稳定
  • 推荐设置：标准迷宫/寻路 γ=0.9~0.95；有明确终局的棋类/关卡任务 γ=0.99；只想优化即时 KPI 时 γ=0.3~0.5

#### 参数 3：ε — 探索率（exploration rate，ε-greedy）

  • 含义：每步以 ε 概率随机选动作（探索），1−ε 概率取 Q 表最优（利用）
  • 类型：float
  • 默认值：初始化 1.0，随训练衰减
  • 取值范围：[0, 1]。ε=1 纯随机（Q 表被随机数据喂饱但不使用）；ε=0 纯贪心（可能永远锁死在第一次选的路径上，学不出最优）
  • 对结果的影响：ε 大→样本覆盖广、收敛慢但稳；ε 小→利用充分但易陷入局部次优路径；固定 ε 会造成策略评估期末端永远带随机性
  • 推荐设置：ε 从 1.0 起步按每回合乘 0.995–0.999 指数衰减，下限 clamp 到 ε_min=0.05，兼顾早期广覆盖与后期高利用

#### 参数 4：ε 衰减率与 ε_min（decay / min epsilon）

  • 含义：ε 的指数衰减系数与地板值，两者共同决定「探索→利用」的换挡节奏
  • 类型：float（decay 常写 $ \epsilon \leftarrow \max(\epsilon_{\min},\ \epsilon \times \text{decay}) $）
  • 默认值：decay=0.995，ε_min=0.05（500~2000 回合规模的常见配比）
  • 取值范围：decay ∈ (0.9, 1)；ε_min ∈ [0, 0.2]
  • 对结果的影响：衰减过快（0.95/回合）→探索窗口太短，学不到关键状态；过慢（0.999+ 短任务）→全程随机行为，Q 虽在学但策略表现差；ε_min 设 0 在非平稳环境会丧失再探索能力
  • 推荐设置：让 ε 大约在「总回合数的 70–80% 处」降到地板值，反推 decay；即 decay ≈ ($ \epsilon_{min}/\epsilon_0 $)^(1/(0.75×总回合))

#### 参数 5：episodes — 训练回合数

  • 含义：完整「起点→终点（或截断）」的交互轮数，决定总样本量
  • 类型：int
  • 默认值：1000（玩具任务）；复杂网格 5000~10000
  • 取值范围：正整数；受「每个 (s,a) 至少被访问多次」约束
  • 对结果的影响：太少→少见状态（如靠近陷阱的关键格子）Q 仍为初值；太多→浪费算力（可配「早停：连续 N 回合走同一路径」缓解）；回合数与 ε 衰减、α 衰减节奏联动
  • 推荐设置：小网格 1000–2000 起，看「最近 100 回合平均回报」曲线平了再加量；别拍脑袋定死

#### 参数 6：max_steps — 单回合步数上限

  • 含义：一个回合最多走几步，超出即截断，防止智能体在环里打转烧时间
  • 类型：int
  • 默认值：100（小任务）；常取状态数的 5–10 倍
  • 取值范围：正整数；必须显著大于最优路径长度
  • 对结果的影响：设太小→没到终点就被掐断，终止奖励学不到（信用分配断裂）；设太大→早期随机乱走的回合极耗时；截断处是否给负奖励也影响学习（一般不给、直接开始新回合）
  • 推荐设置：约为最短路径长度的 10 倍并向上取整；或训练中后期逐步收紧（课程式学习）

#### 参数 7：Q 表初始化（init value）

  • 含义：训练开始前 Q(s,a) 的初始值
  • 类型：float 或全 0 数组
  • 默认值：全 0（np.zeros((n_states, n_actions))）
  • 取值范围：任意实数；乐观初始化（如全 +5）也是合法技巧
  • 对结果的影响：全 0 起步在「负奖励主导」的环境里会触发大量「系统性不尝试」——所有动作估值为 0、贪心总挑第一个动作，探索不足；乐观大初值让每个 (s,a) 至少被试一次（试过就降回真实值），自带内置探索
  • 推荐设置：正奖励稀疏环境用乐观初始化（+1 以上）；带负奖励的稠密环境用全 0 即可，配合 ε-greedy 补探索

#### 参数 8：奖励函数设计（reward shaping）

  • 含义：环境对每种转移给出的即时数值 r(s, a, s')，直接决定 Q 表的含义
  • 类型：由任务定义，常为：到达终点 +1~+100、掉陷阱 −1~−100、普通移动 −0.001~−0.01（或 0）
  • 默认值：经典 FrozenLake：终点 +1、洞 0、空格 0（稀疏奖励）
  • 取值范围：实数（量纲和量级要一致）
  • 对结果的影响：稀疏奖励（只有终局 ±1）最纯粹但学习极慢；步进负奖励催促赶路却可能诱发「冒险抄近道」；陷阱重罚使策略绕远保命；量级失衡（终点 +1 vs 步罚 −0.5）会让智能体宁可原地打转也不奔终点——奖励即目标，写歪一步整个学习方向歪
  • 推荐设置：终点奖励绝对值 >= 全程步罚总和的 10 倍；每步小负奖励 −0.01 量级；陷阱 −1（勿设过巨，否则早期 Q 全是深坑学不动）

代码示例

import numpy as np                                                # 数值计算库，Q表即二维数组

# ── 3×4 网格世界：S 起点、G 终点、T 陷阱、# 墙 ──
GRID = [['S', '.', '.', '.'],                                     # 行0
        ['.', '#', '.', 'T'],                                     # 行1：#为墙 T为陷阱
        ['.', '.', '.', 'G']]                                     # 行2：G为终点
ROWS, COLS = len(GRID), len(GRID[0])                              # 网格尺寸：3行4列
N_STATES = ROWS * COLS                                            # 状态数=格子数=12（状态编码=行×列数+列）
N_ACTIONS = 4                                                     # 动作数：0上 1下 2左 3右

def to_state(r, c):                                               # (行,列)→状态编号
    return r * COLS + c                                           # 压缩成一维索引，方便查Q表

def step(state, action):                                          # 环境转移函数：返回(下一状态,奖励,是否结束)
    r, c = divmod(state, COLS)                                    # 解码回行列坐标
    dr, dc = [(-1,0),(1,0),(0,-1),(0,1)][action]                  # 动作到位移的映射表：上/下/左/右
    nr, nc = r + dr, c + dc                                       # 计算目标格
    if not (0 <= nr < ROWS and 0 <= nc < COLS):                   # 撞墙/出界：原地不动
        return state, -0.1, False                                 #   给小负奖励，惩罚无效动作
    cell = GRID[nr][nc]                                           # 查看目标格内容
    if cell == '#':                                               # 撞到障碍墙：弹回原地
        return state, -0.1, False                                 #   同样小惩罚
    if cell == 'T':                                               # 踩进陷阱：回合结束
        return to_state(nr, nc), -1.0, True                       #   重罚 -1.0
    if cell == 'G':                                               # 抵达终点：回合结束
        return to_state(nr, nc), +1.0, True                       #   大奖 +1.0
    return to_state(nr, nc), -0.01, False                         # 普通空格：轻微步罚催促赶路

ALPHA = 0.1                                                       # α学习率：每步只吸收10%的TD误差(有噪声环境稳)
GAMMA = 0.95                                                      # γ折扣因子：较有远见，看重2~20步外的终点奖励
EPSILON, EPS_MIN, DECAY = 1.0, 0.05, 0.995                        # ε从1起步、地板0.05、每回合×0.995衰减
EPISODES, MAX_STEPS = 1500, 100                                   # 训练1500回合、单回合至多100步防打转

Q = np.zeros((N_STATES, N_ACTIONS))                               # Q表初始化全0：12行(状态)×4列(动作)

for ep in range(EPISODES):                                        # ── 主训练循环：逐回合试错 ──
    s, done, steps = to_state(0, 0), False, 0                     # 每回合从起点S出发
    while not done and steps < MAX_STEPS:                         # 未到终点且未超步数限制
        if np.random.rand() < EPSILON:                            # ε-greedy：以ε概率探索
            a = np.random.randint(N_ACTIONS)                      #   随机选动作(保证后期少见状态也被访问)
        else:                                                     # 1−ε概率利用
            a = int(np.argmax(Q[s]))                              #   贪心取当前Q表最优动作(打平取列号最小)
        s2, r, done = step(s, a)                                  # 与环境交互：拿下一状态s2、奖励r、终止标志
        target = r + GAMMA * np.max(Q[s2])                        # TD目标 y = r + γ·maxQ(s',·)(终局态Q[s2]无后继价值)
        if done:                                                  # 若本步即终局(到G或T)：
            target = r                                            #   目标里不应再加未来项，直接用r
        Q[s, a] += ALPHA * (target - Q[s, a])                     # 核心更新：向TD目标小步校正Q(s,a)
        s = s2                                                    # 状态滚动前移
        steps += 1                                                # 步数计数
    EPSILON = max(EPS_MIN, EPSILON * DECAY)                       # 回合结束：ε指数衰减但不低于地板值

s, path = to_state(0, 0), [to_state(0, 0)]                        # ── 推理：用学到的Q表贪心走一遍 ──
while True:                                                       # 从起点出发直到终点
    a = int(np.argmax(Q[s]))                                      # 纯贪心(推理期不再探索，ε=0)
    s, _, done = step(s, a)                                       # 按环境规则移动
    path.append(s)                                                # 记录路径
    if done: break                                                # 到达终点/陷阱停止
print("总回报检验:", sum(Q[0]), "| 最优路径:", path)                # 期望输出右绕墙直达G的12步内路径

复杂度分析

时间复杂度：

  • 单步更新：查表 $ O(1) $ + 求 $ \max_{a'} Q(s',\cdot) $ 扫动作列 $ O(A) $ → 每步 $ O(A) $
  • 单回合 $ O(\text{steps} \times A) $；整个训练 $ O(\text{episodes} \times \text{avg\_steps} \times A) $，与状态数无关（只访问实际遇到的状态）
  • 对比：DQN 单步需前向+反向传播神经网络 $ O(\text{网络参数量}) $；表格版胜在纯查表极快，输在状态数上限

空间复杂度：

  • Q 表 $ O(|S| \times |A|) $——唯一的天花板：10000 状态 × 10 动作 = 10⁵ 浮点数尚可；图像状态 10⁶⁰⁺ 直接爆炸，必须换函数逼近（DQN）
  • 其余辅助变量 $ O(|S|) $（每状态访问计数等）可忽略

应用场景

  • 迷宫/网格寻路与调度：扫地机器人房间覆盖、仓库 AGV 路径决策、数据中心作业调度的经典入门模型
  • 游戏 AI：FrozenLake、CliffWalking、简单棋类；状态可枚举的老式街机游戏可直接表格化
  • 推荐与运营决策：冷启动场景把「用户分群×运营动作」离散成状态-动作对，以点击/转化奖励在线学策略
  • 通信网络：无线信道接入选择、路由策略自适应、网络切片资源分配等可建模成离散决策序列的任务（装维侧：动态选线/择路排障策略学习）
  • 更高级形态的地基：DQN/Double DQN/Dueling DQN 全部继承 Q-Learning 的 TD 更新式，只是把 Q 表换成神经网络；理解它=理解半个深度强化学习

线性判别分析（LDA）

类别：监督学习 | 难度：中等

算法简介

线性判别分析（Linear Discriminant Analysis, LDA）由 R. A. Fisher 于 1936 年提出（又称 Fisher 判别法），是一种既当分类器、又当降维器的经典监督线性模型。它的核心直觉只有一句话：把数据投影到低维直线上，使得「同类投影点抱得紧（类内方差小），异类投影点离得远（类间间距大）」。与 PCA 这种「无监督、只保留总方差最大方向」的降维不同，LDA 在降维时用到了标签 y：其优化目标是广义瑞利商 $ J(w) = w^T S_B w / w^T S_W w $（分子类间散度最大化、分母类内散度最小化），二分类时解析解为 $ w \propto S_W^{-1}(\mu_1-\mu_2) $，本质是「先白化类内协方差、再连两类均值」。LDA 的判别决策面是线性的（多分类时是若干超平面），概率视角下它等价于「假设各类数据服从共享协方差矩阵的高斯分布，按最大后验分类」——所以它和 QDA（二次判别分析）是一对亲兄弟：QDA 允许各类有自己的协方差，决策面变二次曲面。当特征维度高、样本少时（如 128 维特征只有 200 个样本），LDA 的协方差估计不稳定，需要 shrinkage 正则收缩。工程上它是人脸识别 Fisherface、医学诊断、故障检测和「有标签高维数据的预降维」的常青算法。

原理示意图

数学公式

公式 1：类内散度矩阵（within-class scatter）

$$ S_W = \sum_{c=1}^{C} \sum_{i:\, y_i = c} (x_i - \mu_c)(x_i - \mu_c)^\top $$

变量解释：

  • $ C $：类别数；$ x_i \in \mathbb{R}^d $：第 i 个样本的 d 维特征向量
  • $ \mu_c = \frac{1}{N_c}\sum_{i: y_i=c} x_i $：第 c 类的均值向量（类中心）
  • $ N_c $：第 c 类样本数；$ (x_i-\mu_c)(x_i-\mu_c)^\top $：样本到类中心的离差外积，累积起来即各类协方差的 $ N_c $ 倍加权和
  • 直觉：衡量「同类内部抱团有多松散」，是 $ d \times d $ 矩阵，目标是让它（投影后）尽可能小

公式 2：类间散度矩阵（between-class scatter）

$$ S_B = \sum_{c=1}^{C} N_c \, (\mu_c - \mu)(\mu_c - \mu)^\top, \qquad \mu = \frac{1}{N}\sum_{i=1}^{N} x_i $$

变量解释：

  • $ \mu $：全体样本的总均值向量（把所有类揉在一起的中心）
  • $ (\mu_c - \mu) $：第 c 类中心相对全局中心的偏移，权重为类样本量 $ N_c $
  • 直觉：衡量「各类中心彼此离得多远」；二分类时 $ S_B = (\mu_1-\mu_2)(\mu_1-\mu_2)^\top $ 恒为秩 1 矩阵

公式 3：Fisher 判别准则（广义瑞利商，优化目标）

$$ J(w) = \frac{w^\top S_B w}{w^\top S_W w} $$

变量解释：

  • $ w \in \mathbb{R}^d $：待求的投影方向（判别超平面的法向量）
  • $ w^\top S_B w $：投影后的类间距离（分子，想最大）
  • $ w^\top S_W w $：投影后的类内方差（分母，想最小）
  • $ J(w) $ 尺度不变：$ w $ 放大 $ \lambda $ 倍分子分母同乘 $ \lambda^2 $，比值不变，因此只关心方向不关心长度

公式 4：二分类解析解

$$ w^* \propto S_W^{-1}(\mu_1 - \mu_2) $$

变量解释：

  • $ S_W^{-1} $：类内散度矩阵的逆（先「白化」——沿类内分布扁的方向拉伸，把椭圆团簇捏成圆）
  • $ (\mu_1-\mu_2) $：两类的中心连线方向
  • 直觉：先按类内形状校正空间，再连类中心——若各类是各向同性球，则退化为直接连心线；类内呈斜长条时，逆矩阵把投影方向掰向「宽度」方向以减少重叠
  • 推导：对 $ J(w) $ 求导取零，等价于广义特征值问题 $ S_B w = \lambda S_W w $；二分类时 $ S_B $ 秩 1，唯一非零特征值对应 $ \lambda = (\mu_1-\mu_2)^\top S_W^{-1}(\mu_1-\mu_2) $，特征向量即上式

公式 5：多分类广义特征值问题（降维解）

$$ S_B w_j = \lambda_j S_W w_j, \quad j = 1, \dots, k, \qquad k \le \min(d,\ C-1) $$

变量解释：

  • $ w_j $：第 j 个判别方向；$ \lambda_j $：广义特征值，第 j 大的「类间/类内」分离能力
  • $ k $：保留的判别维度数；上限 $ C-1 $ 是因 $ S_B $ 是 $ C $ 个秩 1 外积之和，秩至多 $ C-1 $（C 类均值被 1 个全局均值约束）——3 分类最多降到 2 维，这是与 PCA(可降到任意维)最大的不同
  • 投影降维即 $ z = W_k^\top x,\ W_k = [w_1, \dots, w_k] $

核心要点

  • 监督降维：与 PCA 最大区别——PCA 找「总方差最大」的无监督方向（可能方向上两类糅在一起），LDA 找「可分性最强」的带标签方向；标签信息是免费的监督信号
  • 降维上限 C−1：类别数减一是硬上限，多分类 LDA 的判别空间至多 $ C-1 $ 维，不是想降几维降几维
  • 概率等价形式：LDA = 各类共享协方差矩阵 $ \Sigma $ 的高斯朴素贝叶斯推广版的判别函数，决策面线性；QDA 放开「共享协方差」假设则决策面为二次曲面
  • 两类用法一招通吃：fit+predict 直接做线性分类器（精度常与逻辑回归互有胜负）；fit+transform 做 n_components≤C−1 的监督降维，做后续分类器的前处理
  • 小样本陷阱：$ d > n $ 时 $ S_W $ 奇异（不可逆），必须用 solver='lsqr'/'eigen' + shrinkage='auto' 或先 PCA 压维——人脸识别（10304 维特征 × 几百样本）必踩此坑
  • 对特征尺度敏感：散度矩阵由协方差撑起，量纲不一致（如「年龄∈[18,80] vs 收入∈[0,10⁶]」）时大数值特征主宰方向，先做 StandardScaler 标准化是标配

技术细节与参数详解

#### 参数 1：solver — 求解算法

  • 含义：用哪种数值方法求解 LDA 的特征值分解/协方差估计
  • 类型：字符串 {'svd', 'lsqr', 'eigen'}
  • 默认值：'svd'
  • 取值范围：三个可选值
  • 对结果的影响：
  • 'svd'：直接对数据矩阵做奇异值分解，不显式计算协方差，数值最稳、天然支持大特征数；唯一不支持 shrinkage 的选项；分类预测时有专用 predict 快速路径
  • 'lsqr'：最小二乘法解方程组，可与 shrinkage 联用，计算最快但只有分类（无 transform 相关属性时降维也支持）
  • 'eigen'：经典广义特征值分解 $ S_B w = \lambda S_W w $，可与 shrinkage 联用，是降维 + shrinkage 的唯一路径，数值上受 $ S_W $ 病态影响最大
  • 推荐设置：特征数很多、不需要收缩 → 'svd'（默认）；样本 < 特征数或类内协方差可疑 → 'lsqr' + shrinkage 只做分类；需要收缩正则 + 降维同时使用 → 'eigen' + shrinkage

#### 参数 2：shrinkage — 协方差收缩正则

  • 含义：把类内协方差向「单位阵 × 迹/d」方向收缩的正则强度，缓解小样本/病态协方差；仅 solver='lsqr'/'eigen' 有效
  • 类型：None / 'auto' / float
  • 默认值：None（不收缩，等价于经典 LDA / svd 的行为）
  • 取值范围：float ∈ [0.0, 1.0]，或字符串 'auto'
  • 对结果的影响：0 = 无正则（小样本下方差大、过拟合，$ S_W $ 可能不可逆）；1 = 完全对角化为各向同性（退化为近似「类中心最近邻」）；'auto' 按 Ledoit-Wolf 引理从数据自动学出最优收缩系数 —— n≈d 或 d>n 时显著提升泛化精度；样本量足够大时 'auto' 收缩值自动趋近 0，几乎无损
  • 推荐设置：样本数 < 特征数×10 时一律 shrinkage='auto'；想精细调就网格搜索 0~1 之间（如 0.1/0.3/0.5）；注意配 solver='lsqr' 或 'eigen'，否则报错

#### 参数 3：priors — 类别先验概率

  • 含义：各类的先验 $ P(y=c) $，直接进入贝叶斯判别函数（对数先验偏置项）
  • 类型：None 或长度 C 的浮点数组
  • 默认值：None（按训练集各类频率估计）
  • 取值范围：和为 1 的正数序列（sklearn 不严格校验归一化，但语义上应当归一）
  • 对结果的影响：改变判别阈值位置——给稀有类更大先验 → 把更多边界样本判给该类（提高召回、牺牲精度），是无需重采样即可处理类别不平衡的旋钮；类别频率与真实世界的部署分布不一致时（训练集男女 1:1，真实 2:8）必须显式修正，否则决策面系统性偏斜
  • 推荐设置：训练集分布 ≈ 部署分布 → 用默认 None；类别不平衡或部署分布已知 → 手动传 [0.3, 0.7] 这类真实占比

#### 参数 4：n_components — 降维目标维数

  • 含义：transform 输出的判别子空间维数 k（分类任务无直接用处，纯降维任务的核心参数）
  • 类型：None 或 int
  • 默认值：None（分类用全部 C−1 个判别方向；若用于 transform，None 时自动取 C−1）
  • 取值范围：$ 0 < k \le \min(n\_features,\ n\_classes - 1) $，传超上限值会报错
  • 对结果的影响：k 越大保留判别信息越全，但超出真实可分维度的部分只含噪声；k=1~2 可把 C 类数据可视化到直线/平面上观察分离度，是 LDA 最讨喜的用途；k 过小可能丢掉对后续分类器有价值的小特征值方向（有时第 2、3 判别方向才区分出细节类别）
  • 推荐设置：先 None 看训练后 explain_variance_ratio_（svd solver 下该属性可用）累计贡献再定 k；可视化固定 1 或 2；给下游分类器用 k=C−1 直接取满

#### 参数 5：store_covariance — 是否保存协方差矩阵

  • 含义：训练后是否计算并保存带偏置（ddof=1）的类内加权协方差矩阵到 covariance_ 属性
  • 类型：bool
  • 默认值：False
  • 取值范围：True / False
  • 对结果的影响：不影响预测结果，只影响内存与可解释性；True 时可检查 covariance_ 判断特征相关性、做马氏距离类外分析、白化处理等；特征维数 d 很大时多存一个 $ d\times d $ 矩阵
  • 推荐设置：调试/分析期 True；生产推理或超高维保持 False 省内存

#### 参数 6：tol — 奇异值秩判定阈值

  • 含义：仅 svd solver 使用——判定协方差矩阵秩的容差：奇异值 sᵢ ≤ tol·s₁ 视为数值零
  • 类型：float
  • 默认值：1e-4
  • 取值范围：正浮点数，通常 1e-8 ~ 1e-2 对数尺度调
  • 对结果的影响：tol 过大 → 把本有信息的方向判为退化方向，预测时某些投影维度被丢弃，边界样本概率输出异常（log 概率 -inf）；tol 过小 → 噪声方向被当作有效，数值不稳定；该参数极少需要动
  • 推荐设置：保持默认；仅当 predict_log_proba 出现 -inf 或特征间强共线时报错时，尝试放大到 1e-2

代码示例

from sklearn.datasets import load_wine                            # 葡萄酒数据集：178样本×13特征×3类
from sklearn.discriminant_analysis import LinearDiscriminantAnalysis  # sklearn 的 LDA 实现
from sklearn.model_selection import train_test_split              # 训练/测试集切分工具
from sklearn.preprocessing import StandardScaler                  # 标准化器：LDA对特征尺度敏感
from sklearn.metrics import accuracy_score, classification_report # 评估指标

X, y = load_wine(return_X_y=True)                                 # X:(178,13)特征矩阵，y:178条0/1/2类标签
X_tr, X_te, y_tr, y_te = train_test_split(                        # 按 7:3 切分
    X, y, test_size=0.3, stratify=y, random_state=42)             # stratify=y 保持三类比例一致

scaler = StandardScaler()                                         # 零均值单位方差标准化
X_tr_s = scaler.fit_transform(X_tr)                               # 在训练集上拟合并变换(防数据泄漏)
X_te_s = scaler.transform(X_te)                                   # 测试集只用同一个scaler变换

# 用法一：LDA 直接当线性分类器（svd 求解 + 显式类别先验）
clf = LinearDiscriminantAnalysis(                                 # 实例化 LDA 分类器
    solver='svd',                                                 # 奇异值分解求解：数值稳、不用算协方差逆
    priors=None,                                                  # 先验=None：按训练集类频率估计
    store_covariance=True,                                        # 保存协方差矩阵供后续分析
    tol=1e-4,                                                     # 秩判定容差，默认值
).fit(X_tr_s, y_tr)                                               # 拟合：估均值/协方差/判别方向
y_pred = clf.predict(X_te_s)                                      # 线性判别面直接预测类别
print("LDA分类准确率:", accuracy_score(y_te, y_pred))              # 标准化后约 0.98~1.00
print(classification_report(y_te, y_pred))                        # 每类的查准/查全/F1 明细

# 用法二：LDA 监督降维 + 可视化（eigen 求解 + Ledoit-Wolf 收缩）
dr = LinearDiscriminantAnalysis(                                  # 第二个实例专用于降维
    solver='eigen',                                               # 广义特征值分解：支持降维+收缩组合
    shrinkage='auto',                                             # 自动估计最优收缩系数(小样本保险丝)
    n_components=2,                                               # 降到2维：上限=类别数3−1=2，可视化刚好
).fit(X_tr_s, y_tr)                                               # 拟合判别子空间
Z_tr = dr.transform(X_tr_s)                                       # 训练集投影：(124,13)→(124,2)
Z_te = dr.transform(X_te_s)                                       # 测试集用同一子空间投影降维
print("降维后形状:", Z_te.shape)                                   # 输出 (54, 2)

# 用法三：降到 2 维后接一个简单分类器，验证监督降维的威力
from sklearn.neighbors import KNeighborsClassifier                # k近邻：低维空间中简单有效
knn = KNeighborsClassifier(n_neighbors=5).fit(Z_tr, y_tr)         # 在 2 维判别空间上训练 kNN
print("LDA降维+kNN 准确率:", accuracy_score(y_te, knn.predict(Z_te)))  # 与13维直接分类几乎持平
print("13维特征被压成2维判别方向，仍保留约 99%+ 的可分性")           # coef_ 形状 (3,13)·scalings_ 形状 (13,2)

复杂度分析

时间复杂度（sklearn 实测口径）：

  • 'svd'：对 $ n \times d $ 数据做 SVD ≈ $ O(n \cdot d \cdot \min(n, d)) $，不需要显式 $ S_W^{-1} $，是高维首选；随后构造判别面 $ O(C \cdot d^2) $
  • 'lsqr'/'eigen'：计算 $ S_W, S_B $ 各 $ O(n \cdot d^2) $，广义特征分解 $ O(d^3) $——特征 10⁴ 时 $ d^3 $ 不可承受，必须先降维
  • 推理（predict）：每个样本 $ O(C \cdot d) $ 线性打分，极快

空间复杂度：

  • 均值与类中心 $ O(C \cdot d) $；协方差 $ O(d^2) $（store_covariance=True 才保留）；svd 还要求数据矩阵驻留内存 $ O(n \cdot d) $
  • 降维结果存储 $ O(n \cdot k) $；对比 PCA：同为线性变换，PCA 无 C−1 上限、无标签利用

应用场景

  • 人脸识别（Fisherface）：Eigenface 用 PCA 只保「脸长得像」的方向，Fisherface 用 LDA 保「谁是谁」的方向，光照噪声被压掉，是小样本高维识别的经典解法
  • 医学诊断与生物标记物筛选：把几十项化验指标投到 C−1 维判别空间判「健康/患病」，系数可解释为各指标权重
  • 故障检测与预诊断（贴近装维场景）：光功率、误码率、时延抖动等多维遥测数据 LDA 判「正常/劣化/中断」，指导派单优先级
  • 金融风控：破产预测（Altman Z-score 本质就是手工线判别）、信用卡欺诈的预降维建模
  • 文本分类：TF-IDF 高维稀疏特征先 LDA 压到 C−1 维再训练轻量分类器
  • 可视化：多类别高维数据投到 2D 判别平面，看类簇是否天然可分、有没有标签错标
