分治法（Divide and Conquer）

类别：分治算法 | 难度：中等

算法简介

分治法（Divide and Conquer）是一种"化整为零、逐个击破、再合零为整"的算法设计范式，核心思想是把一个规模为 $ n $ 的大问题递归地分解为若干个规模更小、结构相同（自相似）的子问题，分别求解子问题后再把子问题的解合并为原问题的解。它严格包含三个步骤：

1. 分（Divide）：将原问题分解为 $ k $ 个规模大致相等的子问题（通常 $ k=2 $，即对半划分）。这一步是递归的——子问题会被当作独立的新问题继续分解，直到规模小到可以直接求解（递归基，base case）。

2. 治（Conquer）：递归地求解每个子问题。当子问题规模足够小（如只剩 1 个元素）时，直接给出平凡解。

3. 合（Combine）：将各子问题的解合并构造出原问题的解。合并步骤的代价决定了整个算法的最终复杂度，是分治法设计的"决胜点"。

典型代表：归并排序（Merge Sort）、快速排序（Quick Sort）、二分查找（Binary Search）、Strassen 矩阵乘法、快速幂、最近点对问题、FFT 快速傅里叶变换。分治法的效率由主定理（Master Theorem）统一刻画，只要递推式形如 $ T(n)=aT(n/b)+f(n) $，即可直接套用主定理的三种情形求出渐进复杂度，无需每次重新展开递归树。

数学公式

1. 分治法通用递推式（分治方程）

$$ T(n) = a \cdot T\left(\frac{n}{b}\right) + f(n) $$

  • $ T(n) $：规模为 $ n $ 的原问题的总时间复杂度
  • $ a $：将原问题分解出的子问题个数（如归并排序二分，$ a=2 $）
  • $ b $：每次划分后子问题规模缩小为原规模的 $ 1/b $（如对半划分，$ b=2 $）
  • $ T(n/b) $：求解单个规模为 $ n/b $ 的子问题所需时间
  • $ f(n) $：分解与合并（Divide + Combine）阶段所花费的时间

2. 主定理（Master Theorem）三种情形

设 $ T(n)=aT(n/b)+f(n) $，$ n=b^k $，令 $ c_{crit}=\log_b a $（临界指数，即递归树叶子节点总数 $ a^{\log_b n}=n^{\log_b a} $ 的指数）：

  • 情形一（叶子主导）：若 $ f(n)=O(n^{c_{crit}-\epsilon}) $（$ \epsilon>0 $），即合并开销小于叶子节点开销，则

$$ T(n) = \Theta(n^{\log_b a}) $$

  • 情形二（均衡）：若 $ f(n)=\Theta(n^{c_{crit}}) $，即合并开销与叶子开销同阶，则

$$ T(n) = \Theta(n^{\log_b a} \log n) $$

  • 情形三（根主导）：若 $ f(n)=\Omega(n^{c_{crit}+\epsilon}) $，且满足正则条件 $ a f(n/b) \le c f(n) $（$ 0

$$ T(n) = \Theta(f(n)) $$

  • $ a $：子问题个数；$ b $：规模缩小倍数；$ f(n) $：分解与合并开销
  • $ c_{crit}=\log_b a $：临界指数，比较 $ f(n) $ 与 $ n^{\log_b a} $ 的相对大小确定落入哪种情形
  • $ \epsilon $：任意小的正数，用于刻画"渐进地大于/小于"

3. 归并排序复杂度推导

$$ T(n) = 2T\left(\frac{n}{2}\right) + O(n), \quad T(1) = O(1) $$

  • $ 2T(n/2) $：两个规模 $ n/2 $ 的子问题各自递归求解
  • $ O(n) $：一次合并需要线性扫描两个子数组（共 $ n $ 个元素）
  • 对照主定理：$ a=2,\ b=2,\ f(n)=O(n) $，$ c_{crit}=\log_2 2=1 $，$ f(n)=\Theta(n^1) $ → 情形二，得 $ T(n)=\Theta(n\log n) $
  • 递归树验证：第 $ k $ 层有 $ 2^k $ 个规模 $ n/2^k $ 的子问题，每层合并总代价 $ O(n) $，共 $ \log_2 n $ 层 → 总代价 $ O(n) \times \log_2 n = O(n\log n) $

4. 二分查找复杂度归因

$$ T(n) = T\left(\frac{n}{2}\right) + O(1), \quad T(1)=O(1) $$

  • $ a=1 $（只递归一个子问题）、$ b=2 $、$ f(n)=O(1) $；$ c_{crit}=\log_2 1 = 0 $，$ f(n)=O(n^0) $ → 情形二
  • 得 $ T(n) = \Theta(\log n) $：每次比较后搜索区间减半，最多 $ \log_2 n $ 次比较

核心要点

  • 分治法三要素缺一不可：分解必须让子问题"自相似且独立"，递归必须终止于基例，合并必须正确还原全局解
  • 复杂度取决于"分"与"合"的相对代价：分治方程 $ T(n)=aT(n/b)+f(n) $ 中 $ f(n) $ 一旦超过 $ n^{\log_b a} $，整体复杂度由合并步骤主导（主定理情形三）
  • 归并排序是稳定、最坏 $ O(n\log n) $ 的比较排序，代价是需要 $ O(n) $ 辅助空间；快速排序原地划分、空间 $ O(\log n) $，但最坏退化 $ O(n^2) $，可通过随机化/三数取中规避
  • 分治法天然适合并行化：子问题互相独立，可分配到多核/多机（如 MapReduce、FFT 蝶形运算）
  • 主定理不是万能：当子问题规模不同（如 $ T(n)=T(n/3)+T(2n/3) $）或 $ f(n) $ 非多项式时，需改用递归树或代入法

技术细节与参数详解

分治法不是一个函数库，而是一种算法设计范式；其"可调参数"体现为递归实现中的各类设计决策变量。以下以归并排序与快速排序的 Python 实现为对象，逐一详解这些决策参数。

#### 参数1：递归基（base case）规模阈值

  • 含义：子问题规模小到多少时停止递归、直接求解（分治法的终止条件）
  • 类型：整数（比较次数阈值）
  • 默认值：归并排序通常为 len(arr) <= 1；工程实现常取 16~64（如 Timsort 使用 64）
  • 取值范围：$ \ge 1 $ 的整数
  • 对结果的影响：阈值过小→递归层数深、函数调用开销大；阈值过大→退化为插入排序逻辑、失去分治优势
  • 推荐设置：教学场景取 1（最简）；生产环境取 16~32 并切换插入排序（小数组插入排序常数小）

#### 参数2：划分比例 b（分几份、每份多小）

  • 含义：每次把问题切分后子问题规模与父问题规模的比例（$ n/b $）
  • 类型：正整数（平衡分治）或比例（非平衡分治）
  • 默认值：归并排序 $ b=2 $（对半）；快速排序期望 $ b=2 $（由枢轴决定）
  • 取值范围：$ b \ge 2 $；快速排序在极端情况 $ b \approx n $（每次只分成 1 与 n-1）
  • 对结果的影响：平衡划分（$ b=2 $）才能得到 $ O(n\log n) $；完全不平衡划分退化为 $ O(n^2) $
  • 推荐设置：尽量让子问题规模均衡（二分），这是分治法效率的前提

#### 参数3：枢轴选择策略 pivot（快速排序专用）

  • 含义：快速排序"治"阶段选择哪个元素作为划分基准
  • 类型：选择算法（首元素/末元素/随机/三数取中/median-of-medians）
  • 默认值：朴素实现取首元素或末元素
  • 取值范围：可以是数组任意位置的元素
  • 对结果的影响：固定取首元素时，对已排序数组每次划分最不平衡 → 退化为 $ O(n^2) $；随机选取使期望复杂度稳定在 $ O(n\log n) $，且不受恶意输入影响
  • 推荐设置：随机枢轴（概率保证期望 $ O(n\log n) $）或三数取中（取 left/mid/right 的中位数，抗已排序输入）

#### 参数4：划分（分区）算法 partition

  • 含义：将数组按枢轴重排为"左小右大"两段的具体扫描方式
  • 类型：Lomuto 划分 / Hoare 划分
  • 默认值：教科书常用 Lomuto（简单）；工程与标准库多用 Hoare（两指针相向扫描）
  • 取值范围：两种分区都原地完成；Hoare 交换次数约为 Lomuto 的 1/3
  • 对结果的影响：Lomuto 对大量重复元素时性能差（大量交换）；Hoare 更快但边界条件易错；两者都能保证最终正确性
  • 推荐设置：一般问题用 Hoare 分区 + 随机枢轴；代码教学用 Lomuto（易读）

#### 参数5：合并辅助数组 merge（归并排序专用）

  • 含义：合并两个有序子数组时是否申请临时数组，以及使用"前插"还是"哨兵"技巧
  • 类型：内存策略（原地 / 辅助数组）
  • 默认值：经典归并排序使用与原数组等长的辅助数组
  • 取值范围：可以原地归并（使用旋转/插入技巧），但常数显著变大
  • 对结果的影响：辅助数组使时间稳定 $ O(n\log n) $、空间 $ O(n) $；原地归并空间 $ O(1) $ 但时间退化
  • 推荐设置：默认辅助数组即可；对内存敏感场景（超大数据）才考虑原地变种

#### 参数6：子问题求解顺序与递归深度（调用栈）

  • 含义：递归调用在函数栈上的展开层数 = 递归树深度
  • 类型：整数（栈深）
  • 默认值：平衡分治深度 $ \log_2 n $；非平衡分治最坏深度 $ n $
  • 取值范围：$ \log_2 n \le 深度 \le n $
  • 对结果的影响：深度过大导致栈溢出（Python 默认递归深度约 1000）；每层递归有函数调用开销
  • 推荐设置：递归深度预计超 1000 时改迭代实现，或改用递归深度可设的语言/环境（sys.setrecursionlimit）

代码示例

# -*- coding: utf-8 -*-
"""分治法三大经典实现：归并排序、快速排序、二分查找（每行均附注释）"""
from typing import List

def merge_sort(arr: List[int]) -> List[int]:
    """归并排序：分治法的经典代表，返回排好序的新列表"""
    # 递归基：数组为空或只剩 1 个元素时天然有序，直接返回（治的平凡解）
    if len(arr) <= 1:
        return arr
    # 分（Divide）：取中点，把数组对半劈开（b=2 的平衡划分）
    mid = len(arr) // 2
    # 治（Conquer）：递归对左半部分排序
    left = merge_sort(arr[:mid])
    # 治（Conquer）：递归对右半部分排序
    right = merge_sort(arr[mid:])
    # 合（Combine）：合并两个有序子数组，返回完整有序结果
    return merge(left, right)

def merge(left: List[int], right: List[int]) -> List[int]:
    """合并函数：把两个已排序列表线性扫描合成一个有序列表，复杂度 O(n)"""
    # 结果数组，长度约为 len(left)+len(right)
    result = []
    # i、j 分别是 left 与 right 的遍历指针
    i = j = 0
    # 双指针扫描：谁小先取谁（稳定性的来源——左子数组元素优先）
    while i < len(left) and j < len(right):
        # 取两个子数组当前位置中较小者加入结果
        if left[i] <= right[j]:
            result.append(left[i])
            i += 1  # 左指针前进
        else:
            result.append(right[j])
            j += 1  # 右指针前进
    # 左数组可能有剩余元素（右数组已耗尽），全部接上
    result.extend(left[i:])
    # 右数组可能有剩余元素（左数组已耗尽），全部接上
    result.extend(right[j:])
    # 返回合并后的完整有序数组
    return result

import random

def quick_sort(arr: List[int], low: int, high: int) -> None:
    """快速排序：原地分区 + 递归排序，直接修改传入数组"""
    # 递归基：区间为空或单元素时天然有序，直接返回
    if low >= high:
        return
    # 分（Divide）：随机选枢轴并交换到末尾，避免最坏 O(n^2)（枢轴参数）
    pivot_idx = random.randint(low, high)
    # 把随机选中的枢轴换到数组最右端，便于后续分区
    arr[high], arr[pivot_idx] = arr[pivot_idx], arr[high]
    # 分区：Lomuto 分区，返回枢轴最终位置（划分参数）
    p = partition(arr, low, high)
    # 治（Conquer）：递归排序枢轴左侧（都小于枢轴）
    quick_sort(arr, low, p - 1)
    # 治（Conquer）：递归排序枢轴右侧（都大于枢轴）
    quick_sort(arr, p + 1, high)

def partition(arr: List[int], low: int, high: int) -> int:
    """Lomuto 分区：以 arr[high] 为枢轴，原地重排并返回枢轴位置"""
    pivot = arr[high]   # 枢轴值取右端元素
    i = low             # i 指向"小于枢轴区域"的边界
    # 从左到右扫描整个区间（除枢轴本身）
    for j in range(low, high):
        # 遇到比枢轴小的元素，交换到左侧区域并扩大左区
        if arr[j] < pivot:
            arr[i], arr[j] = arr[j], arr[i]
            i += 1  # 左区右边界 +1
    # 把枢轴放到左右两区交界处（此时 i 即为枢轴正确位置）
    arr[i], arr[high] = arr[high], arr[i]
    # 返回枢轴最终下标（分治划分点）
    return i

def binary_search(arr: List[int], target: int) -> int:
    """二分查找：在有序数组中找 target，返回下标，找不到返回 -1"""
    # 定义查找区间左右边界（闭区间）
    lo, hi = 0, len(arr) - 1
    # 区间非空时持续折半
    while lo <= hi:
        # 取中点（避免 (lo+hi) 溢出）
        mid = (lo + hi) // 2
        # 命中目标，直接返回下标（治）
        if arr[mid] == target:
            return mid
        # 目标比中点大：放弃左半，区间缩到右半（分/递归）
        elif arr[mid] < target:
            lo = mid + 1
        # 目标比中点小：放弃右半，区间缩到左半（分/递归）
        else:
            hi = mid - 1
    # 区间耗尽仍未找到：返回 -1
    return -1

if __name__ == "__main__":
    # 测试：乱序数组
    data = [27, 43, 3, 9, 82, 10, 27]
    # 归并排序验证（返回新列表）
    print("归并排序:", merge_sort(data))
    # 快速排序验证（原地修改）
    quick_sort(data, 0, len(data) - 1)
    print("快速排序:", data)
    # 二分查找验证（在有序数组上）
    print("找 9 的位置:", binary_search(sorted(data), 9))
    print("找 100:", binary_search(sorted(data), 100))

复杂度分析

时间复杂度（推导）：

  • 归并排序：递推式 $ T(n)=2T(n/2)+O(n) $。展开递归树：第 $ k $ 层有 $ 2^k $ 个节点，每个节点规模 $ n/2^k $，每层总代价 $ 2^k \times O(n/2^k)=O(n) $；树高 $ \log_2 n $ → 总时间 $ T(n) = \underbrace{O(n)+\cdots+O(n)}_{\log_2 n\text{ 层}} = O(n\log n) $。最好/最坏/平均均为 $ \Theta(n\log n) $。
  • 快速排序：最好/平均 $ T(n)=2T(n/2)+O(n)=O(n\log n) $（平衡划分）；最坏 $ T(n)=T(n-1)+O(n)=O(n^2) $（每次划分极度不平衡，递归树退化为链，第 $ k $ 层代价 $ n-k $，求和 $ \sum_{k=0}^{n-1}(n-k)=O(n^2) $）。随机化枢轴使最坏情况概率几乎为 0，期望 $ O(n\log n) $。
  • 二分查找：$ T(n)=T(n/2)+O(1)=O(\log n) $。

空间复杂度：

  • 归并排序：合并需 $ O(n) $ 辅助数组（递归深度 $ \log n $ 的栈开销可忽略）→ $ O(n) $
  • 快速排序：原地分区 $ O(1) $ 辅助空间 + 递归栈深度（期望 $ \log n $，最坏 $ n $）→ 期望 $ O(\log n) $，最坏 $ O(n) $
  • 二分查找：迭代实现无递归栈 → $ O(1) $

应用场景

  • 大数据排序：归并排序是 JDK Arrays.sort（对象数组）、Python list.sort 底层 Timsort 的基础，稳定且对缓存友好
  • 二分查找族：有序数据检索（数据库 B+ 树、字典查找）、求根（数值分析）、最值下界问题
  • 大整数乘法 / 矩阵乘法：Karatsuba 乘法 $ O(n^{1.585}) $、Strassen 矩阵乘法 $ O(n^{2.807}) $，均通过分块降低复杂度
  • 最近点对：平面最近点对问题分治 $ O(n\log n) $ 优于暴力 $ O(n^2) $
  • 并行计算：MapReduce、FFT（快速傅里叶变换）、归并式聚合天然并行
  • 竞赛与面试：归并排序求逆序对数量、最大子数组和（分治变体）、整数分治幂等

算法简介

RoPE（Rotary Position Embedding，旋转位置编码）由苏剑林提出，在论文 RoFormer: Enhanced Transformer with Rotary Position Embedding 中正式定义，是目前大模型（LLaMA、GLM、Qwen、Baichuan、DeepSeek 等）使用最广泛的位置编码方案之一。它的核心思想是：不把位置信息加到词向量上，而是把位置信息编码为对 Query（查询）和 Key（键）向量的"旋转变换"——每个位置 $ m $ 对应一个旋转角度 $ m\theta_i $，把词向量按维度两两分组，在二维复平面上旋转该角度。这样设计的美妙之处在于：经过旋转后的 Query 与 Key 做内积（点积）时，结果恰好只与相对位置差 $ m-n $ 有关，从而以"绝对位置编码"的形式实现了"相对位置编码"的效果，而且无需训练参数、天然具备外推能力（长度泛化）。

相比传统绝对位置编码（正弦/余弦相加）与可学习位置编码（embedding 查表），RoPE 有三点优势：①相对位置信息直接注入注意力分数计算，建模长程依赖更自然；②每个位置是"旋转"而非"平移"，相邻位置的编码差异呈周期性连续变化，利于梯度传播；③没有额外可学习参数，不增加模型规模。它的经典公式可类比复数平面上的旋转变换：$ f(\mathbf{x}, m) = R(m)\mathbf{x} $，其中 $ R(m) $ 是随位置 $ m $ 旋转 $ \theta $ 的旋转矩阵。

原理示意图

图注：左图为二维情形——位置 $ m $ 把向量 $ q=(x,y) $ 逆时针旋转 $ m\theta $ 弧度；右图为 RoPE 在 Transformer 中的注入位置：Q、K 经各自权重矩阵得到后，分别乘以随位置变化的旋转矩阵 $ R(m) $、$ R(n) $，再计算内积。由于旋转矩阵正交、且"先旋转 m 再旋转 n 的逆"等于旋转 $ m-n $，内积结果天然只依赖相对位置差。

数学公式

1. 二维旋转位置编码（出发点）

$$ f_q(x_m, m) = R(m) \, x_m, \qquad R(m) = \begin{pmatrix} \cos m\theta & -\sin m\theta \\ \sin m\theta & \cos m\theta \end{pmatrix} $$

  • $ x_m $：位置 $ m $ 处的词向量（二维情形，视为复数 $ x_1 + i x_2 $）
  • $ R(m) $：旋转矩阵，把向量逆时针旋转 $ m\theta $ 弧度
  • $ m $：词元在序列中的绝对位置（0, 1, 2, ...）
  • $ \theta $：旋转频率（base 角），控制旋转的快慢

2. 内积只依赖相对位置的证明（二维）

$$ \langle R(x_m, m), R(x_n, n) \rangle = \text{Re}\left[ x_m x_n^* \, e^{i(m-n)\theta} \right] $$

  • $ x_m, x_n $：位置 $ m $、$ n $ 处的词向量（复数表示 $ x_1+ix_2 $）
  • $ x_n^* $：$ x_n $ 的共轭复数
  • $ e^{i(m-n)\theta} $：旋转相位，仅取决于位置差 $ m-n $
  • 结论：内积 = 词向量原始内积被相位 $ (m-n)\theta $ 旋转，绝对位置 $ m,n $ 被抵消，只留下相对位置差——这就是 RoPE"用绝对实现相对"的根本原因

3. 高维推广：旋转频率（inv_freq）

$$ \theta_i = base^{-\frac{2i}{d}} = 10000^{-\frac{2i}{d}}, \quad i = 0, 1, \ldots, d/2-1 $$

  • $ i $：维度分组下标（第 $ i $ 组两个维度共享一个频率）
  • $ d $：向量维度（head_dim，如 LLaMA 为 64/128）
  • $ base $（$ \theta_{base} $）：频率基底，默认 10000（与正弦位置编码一致）；越大→低频段整体变慢→越利于长文本外推
  • $ \theta_i $：第 $ i $ 组的旋转角速度。$ i $ 越小频率越高（低频维度，周期短、敏感于近邻位置）；$ i $ 越大频率越低（高频维度，周期长、敏感于远距离位置）——与 Sinusoidal 编码同构

4. 块对角旋转矩阵（完整 RoPE 变换）

$$ R_{\Theta,m}^{d} = \bigoplus_{i=0}^{d/2-1} \begin{pmatrix} \cos m\theta_i & -\sin m\theta_i \\ \sin m\theta_i & \cos m\theta_i \end{pmatrix} $$

  • $ \bigoplus $：块对角拼接（block diagonal），即把 $ d/2 $ 个 $ 2\times2 $ 旋转块排成大对角矩阵
  • $ R_{\Theta,m}^{d} $：$ d\times d $ 正交旋转矩阵，作用于整个 $ d $ 维向量
  • 实际实现不显式构造大矩阵（空间 $ O(d^2) $ 太贵），而是用 rotate_half 的按位重组技巧 $ O(d) $ 完成等价乘法

4. 长上下文缩放（NTK-aware / YaRN）

$$ \theta_i' = \left(\frac{base}{s}\right)^{-\frac{2i}{d}} \cdot \text{scale}, \qquad s = \frac{L'}{L} $$

  • $ s $：长度缩放因子（YaRN 的 scaling_factor），$ L' $ 为目标扩展长度，$ L $ 为训练长度
  • NTK-aware：把 $ base $ 乘以缩放 $ s^{d/(d-2)} $（等价于缩小 $ \theta_i $），使长位置仍有足够高频分量，短位置不受影响
  • YaRN：进一步对高频/低频维度施加不同的温度缩放与注意力 logit 温度 $ t $（attention_factor），并配合 NTK 插值，被广泛用于 LLaMA 长上下文（如 8K/32K/128K 扩展）

核心要点

  • 本质：位置编码 = 对 Q/K 向量做"旋转"，旋转角 = 位置 × 频率；点积自动把绝对位置差转成相对位置差
  • 零参数：旋转矩阵由公式直接计算，无需训练，天然支持长度外推（直接外推优于学习式位置编码）
  • 逐层注入：RoPE 作用于每一层的 Q、K（而非只加在输入 embedding 上），位置信息贯穿整个网络
  • 实现技巧：用 inv_freq = 1.0 / (base ** (arange(0, d, 2) / d)) 生成频率表；旋转用 rotate_half 重排 + 逐元素乘余弦/正弦，避免构造大矩阵
  • 长文本三件套：linear scaling（线性插值）→ NTK-aware（调 base 保持高频）→ YaRN（分频加权 + logit 温度），层层递进
  • 外推上限：不缩放时有效长度受 $ 2\pi / \theta_{d/2-1} $ 约束；缩放比例 $ s $ 过大时需配合微调（如 8K 段微调）

技术细节与参数详解

RoPE 的实现参数集中在 HuggingFace RotaryEmbedding / LlamaRotaryEmbedding 及各家扩展版本中。以下逐一详解。

#### 参数1：head_dim（隐藏维度分组基数）

  • 含义：每个注意力头 Q/K 向量的维度 $ d $，决定频率表长度（频率组数 $ =d/2 $）
  • 类型：正整数
  • 默认值：LLaMA-2 为 128，LLaMA-1/7B 为 64，一般取 $ 32\sim128 $
  • 取值范围：通常为 2 的倍数（因按两两分组旋转）；常见 32/64/128
  • 对结果的影响：$ d $ 越大频率组越多，可表达的位置分辨率越高，但每头的计算量线性增长
  • 推荐设置：跟随模型配置（如 head_dim=128）；自定义时取 64 起步

#### 2. theta（base，旋转基底）

  • 含义：频率基底的底数，公式 $ \theta_i=base^{-2i/d} $ 中的 base
  • 类型：浮点数
  • 默认值：10000（原 RoFormer 与 LLaMA 默认）
  • 取值范围：一般 $ 10^3 \sim 10^6 $；长文本扩展常用 500000、1000000 或更高
  • 对结果的影响：base 越大→所有 $ \theta_i $ 越小→旋转越慢→有效上下文越长（能表示更长距离的相对位置差）；但过大会导致近邻位置区分度下降（低频段过多）
  • 推荐设置：标准训练 10000；需 2~4 倍长度外推时先试 base=500000 或 NTK-aware 缩放

#### 3. inv_freq（旋转频率表）

  • 含义：预先算好的频率表 $ \theta_i = base^{-2i/d} $，形状为 [d/2]，供所有位置复用
  • 类型：torch.FloatTensor（[d/2] 或 [1,1,d/2]）
  • 默认值：由 theta 和 head_dim 经 1.0 / (theta ** (torch.arange(0, d, 2).float() / d)) 计算
  • 取值范围：$ \theta_{d/2-1} = base^{-(d-2)/d} \to base^{-1} $（数值恒正）
  • 对结果的影响：决定每个维度的旋转速度；低频（$ i $ 小）旋转快，捕捉近距；高频（$ i $ 大）旋转慢，捕捉远距。插值/缩放本质都是修改这张表
  • 推荐设置：训练时用 float32 保持精度（低精度 bf16 会精度损失，Qwen 等用 float32 缓存）

#### 4. position_ids（位置索引）

  • 含义：每个 token 的位置编号 $ m $，用于查频率角 $ m\cdot\theta_i $
  • 类型：torch.LongTensor，形状 [batch, seq_len]
  • 默认值：arange(seq_len) 的广播复制
  • 取值范围：非负整数；长上下文微调时可为绝对位置偏移
  • 对结果的影响：直接决定旋转角度；位置编号连续（1,2,3,...）与间隔（如 2,4,6,...）对应不同旋转步长
  • 推荐设置：连续递增 0~L-1；分段扩展任务可自定义位置偏移

#### 5. scale（scaling_factor，长文本缩放因子）

  • 含义：YaRN / NTK 等扩展方案中的长度缩放比例 $ s = L' / L $
  • 类型：浮点数
  • 默认值：1.0（不缩放）；长文本微调常用 2~16
  • 取值范围：$ \ge 1 $；过大（如 >32）时需配合微调
  • 对结果的影响：线性插值把全部 $ \theta_i $ 缩小 $ s $ 倍（即频率变慢），使长距离仍有区分度；NTK-aware 只缩放高频部分；YaRN 对高频全保留、低频缩放，最优
  • 推荐设置：目标 32K 且训练 4K → $ s=8 $；配合 rope_type="yarn" 与注意力温度 $ \sqrt{s} $ 一起使用

#### 6. max_position_embeddings / original_max_position_embeddings

  • 含义：模型支持的最大位置（新/原）
  • 类型：正整数
  • 默认值：LLaMA-7B 训练 2048/4096；扩展后 8192~131072
  • 取值范围：$ \ge $ 训练序列长度
  • 对结果的影响：决定 cos/sin 缓存表长度与位置上限；超过上限仍可外推（RoPE 特性），但质量下降
  • 推荐设置：训练与推理设置保持一致；扩展时把 max_position_embeddings 提为目标长度并配 scaling

#### 6. rotate_half 旋转实现技巧

  • 含义：把向量分为前后两半 $ \mathbf{q}_1, \mathbf{q}_2 $，旋转等价于 (−q2, q1) 拼接后与 (cos, sin) 逐元素相乘加
  • 原理：$ R(\theta)(q_1,q_2) = (q_1\cos\theta - q_2\sin\theta,\ q_1\sin\theta + q_2\cos\theta) $
  • 影响：把 $ O(d^2) $ 矩阵乘法降为 $ O(d) $ 逐元素乘法，是工业级实现的关键优化
  • 推荐设置：官方实现 rotate_half 配合预计算好的 cos/sin（形状 [1, seq, 1, d]）广播乘加

#### 7. attention factor（YaRN 注意力温度）

  • 含义：YaRN 中除以注意力分数前的温度系数 $ \sqrt{t} $，用于补偿长文本下注意力分布熵变化
  • 类型：浮点数
  • 默认值：$ 1.0 $（常规 RoPE）；YaRN 建议 $ t = 0.1 \ln s + 1 $
  • 影响：防止扩展后注意力过锐/过钝，稳定长程注意力
  • 推荐设置：按 YaRN 论文：$ t \approx 0.1\ln s + 1 $，$ s $ 为目标缩放

#### 8. gamma 与 beta（YaRN 高低频分界）

  • 含义：区分高频/低频维度的边界参数（$ \beta $ 起止频率）
  • 类型：浮点数
  • 默认值：YaRN 推荐 $ beta_{fast}=32 $、$ beta_{slow}=1 $，并定义缩放窗口内混合 NTK 与线性缩放
  • 影响：决定哪些维度完全保留（高频）、哪些完全缩放（低频）、哪些过渡
  • 推荐设置：保持论文默认；精细调优时观察注意力图选择

代码示例

# -*- coding: utf-8 -*-
"""RoPE 旋转位置编码：从频率表到旋转注入的完整实现（逐行注释）"""
import math
import torch
import torch.nn as nn

def precompute_rope_frequencies(head_dim: int, seq_len: int, theta: float = 10000.0) -> tuple:
    """
    预计算 cos/sin 缓存：对任意 seq_len 生成 [seq_len, head_dim] 的旋转编码
    head_dim: 每个注意力头的维度（必须为偶数）
    seq_len:  最大序列长度
    theta:    频率基频 base（默认 10000，可调用于长度外推）
    """
    # 1. 生成频率索引：0, 2, 4, ..., head_dim-2（每 2 个维度共享一个频率）
    #    arange(0, head_dim, 2) 取偶数下标，长度正好 head_dim // 2
    freqs = torch.arange(0, head_dim, 2, dtype=torch.float32)
    # 2. 计算每个频率组的旋转频率 theta_i = base ^ (-2i / head_dim)
    #    注意这里指数是 (freqs / head_dim)，等价于 2i/head_dim
    inv_freq = 1.0 / (theta ** (freqs / head_dim))          # 形状 [head_dim//2]
    # 3. 位置 m 与频率外积：angles[m, i] = m * theta_i，形状 [seq_len, head_dim//2]
    m = torch.arange(seq_len, dtype=torch.float32)       # 位置序列 [seq_len]
    # outer 外积：seq_len × head_dim//2 的旋转角矩阵
    angles = torch.outer(m, inv_freq)                    # [seq_len, head_dim//2]
    # 4. 每个频率复用两次（相邻两维同一频率），得到 [seq_len, head_dim] 的角矩阵
    angles = torch.cat([angles, angles], dim=-1)         # [seq_len, head_dim]
    # 5. 对角度矩阵逐元素求 cos/sin，作为旋转缓存（训练与推理共享）
    cos_cache = torch.cos(angles)                        # [seq_len, head_dim]
    sin_cache = torch.sin(angles)                        # [seq_len, head_dim]
    # 返回余弦表、正弦表、频率表
    return cos_cache, sin_cache, inv_freq

def rotate_half(x: torch.Tensor) -> torch.Tensor:
    """
    rotate_half 技巧：把后一半维度的元素取负后与前半交换
    等价于复数乘法中"实部、虚部交换"的快速实现，避免构造 d×d 旋转矩阵
    x: [batch, seq, num_heads, head_dim]
    """
    # 沿最后维度切成两半：x1 前半、x2 后半
    x1, x2 = x[..., : x.shape[-1] // 2], x[..., x.shape[-1] // 2 :]
    # 返回 (-x2, x1)：即后一半取负后拼到前面——这就是旋转乘法的"虚部交换"
    return torch.cat((-x2, x1), dim=-1)

def apply_rotary_pos_emb(q: torch.Tensor, k: torch.Tensor,
                         cos: torch.Tensor, sin: torch.Tensor) -> tuple:
    """
    对 Q、K 施加 RoPE 旋转：
    q/k: [batch, seq, num_heads, head_dim]（batch_first）
    cos/sin: [batch, seq, 1, head_dim]（自动广播到每个头）
    """
    # 1. 旋转公式：q_rot = q*cos + rotate_half(q)*sin
    # 注意 rotate_half(q) 前的负号由 rotate_half 内部实现（-x2, x1）
    q_embed = (q * cos) + (rotate_half(q) * sin)   # [batch, seq, num_heads, head_dim]
    # 2. 对 K 施加相同旋转（位置 n 的旋转角度不同，由 cos/sin 的第 n 行决定）
    k_embed = (k * cos) + (rotate_half(k) * sin)   # 同一缓存、不同位置取值
    # 返回旋转后的 Q、K
    return q_embed, k_embed

# ---- 最小可运行示例：验证"内积只依赖相对位置差" ----
if __name__ == "__main__":
    # 参数：头维度 8（4 组频率），序列长度 16，base=10000
    head_dim, seq_len, theta = 8, 16, 10000.0
    # 预计算 cos/sin 缓存
    cos_cache, sin_cache, inv_freq = precompute_rope_frequencies(head_dim, seq_len, theta)
    # 把缓存补成 [1, seq, 1, head_dim] 以支持广播
    cos_b = cos_cache.unsqueeze(0).unsqueeze(0)   # [1, 16, 1, 8]
    sin_b = sin_cache.unsqueeze(0).unsqueeze(0)   # [1, 16, 1, 8]

    # 随机生成 Q、K：batch=1, seq=16, 头数=1, head_dim=8
    q = torch.randn(1, seq_len, 1, head_dim)
    k = torch.randn(1, seq_len, 1, head_dim)
    # 施加 RoPE
    q_emb, k_emb = apply_rotary_pos_emb(q, k, cos_b, sin_b)
    # 计算注意力分数矩阵 [16, 16]（点积，省略 sqrt(d) 缩放）
    scores = (q_emb @ k_emb.transpose(-1, -2)).squeeze()   # [16, 16]
    # 验证：scores[m, n] 的差异只取决于 |m-n|
    d0 = scores[0, 0]   # 位置 (0,0) 分数
    d1 = scores[1, 1]   # 位置 (1,1) 分数（与 (0,0) 距离同为 0）
    d5 = scores[0, 5]   # 距离 5
    d6 = scores[1, 6]   # 距离 5（应与 d5 相近）
    print("同位置分数 (0,0)/(1,1) 差:", (d0 - d1).abs().item())
    print("等距分数 (0,5)/(1,6) 差:", (d5 - d6).abs().item())
    print("inv_freq 表:", inv_freq.tolist())

预期输出（每次随机数不同，但量级一致）：

同位置分数 (0,0)/(1,1) 差: ~0.0（数值精度内）
等距分数 (0,5)/(1,6) 差: ~0.0（相对位置一致性验证）
inv_freq 表: [1.0, 0.1, 0.01, 0.001]

复杂度分析

时间复杂度：

  • 频率表预计算：$ O(seq\_len \times head\_dim) $（一次性，外积）
  • 单次旋转注入：每个元素一次乘加，$ O(batch \times seq \times num\_heads \times head\_dim) $，与注意力本身的 $ O(L^2 \cdot d) $ 相比完全可忽略；对比显式构造旋转矩阵 $ O(d^2) $，rotate_half 把每位置旋转降到 $ O(d) $
  • 总体开销占比：RoPE 引入的额外时间约为注意力的 $ O(1) $ 常数，工程上可忽略

空间复杂度：

  • cos/sin 缓存：$ O(seq \times head\_dim) $，远小于 KV 缓存 $ O(L \times num\_layers \times num\_heads \times head\_dim) $
  • inv_freq 表：$ O(head\_dim / 2) $，可忽略
  • 无额外训练参数：RoPE 本身不引入任何可学习参数，参数量 $ O(1) $

应用场景

  • 大语言模型（LLM）主干：LLaMA/LLaMA-2/3、Qwen 系列、GLM、Baichuan、DeepSeek、Mistral 等全部采用 RoPE（或其扩展），支持上下文 8K~128K
  • 长上下文扩展：配合 NTK-aware / YaRN / 动态 NTK / Linear scaling 将 4K 模型扩展到 32K/128K（如 Qwen2.5、Gemma 长文本版）
  • 多模态与视觉-语言模型：视觉特征序列（如 ViT patch 序列）同样用 RoPE 注入空间顺序
  • 在线推理 KV 缓存优化：RoPE 无参数、纯计算，利于 CUDA kernel 融合；支持推理时的缓存复算与并行预填充

CNN 卷积神经网络（Convolutional Neural Network）

类别：深度学习 | 难度：中等

算法简介

卷积神经网络（Convolutional Neural Network, CNN）是一类专门处理网格结构数据（图像、音频频谱、时序信号）的深度学习模型，其核心组件是卷积层（Convolutional Layer）：用一组可学习的"卷积核（kernel/filter）"在输入上滑动，逐位置计算局部加权和，从而提取局部特征。与传统全连接网络相比，CNN 利用三个关键归纳偏置大幅降低参数量并提升泛化能力：①局部连接——每个神经元只连接输入的一小块感受野，符合图像局部相关性；②权值共享——同一卷积核在整个输入上滑动复用，参数数量与输入尺寸无关；③平移等变性——特征在图像中平移，卷积响应也平移，使网络对目标位置不敏感。

一个典型 CNN 由卷积层 + 激活函数（ReLU）+ 池化层（Pooling） 堆叠构成，最后接全连接层/全局平均池化输出分类。卷积层负责"提特征"，池化层负责"降采样"（减小特征图尺寸、增强平移不变性、扩大感受野），堆叠的深层卷积逐级抽象：浅层学边缘/纹理，中层学部件（眼睛/轮子），深层学语义目标。自 2012 年 AlexNet 在 ImageNet 夺冠以来，VGG、GoogLeNet、ResNet、MobileNet 等经典结构不断演进；今天 CNN 仍是图像分类、目标检测（YOLO 系）、语义分割（U-Net）的骨干，也是混合架构（如 ViT 前的特征提取器）的主力。

数学公式

1. 卷积运算（单个输出像素）

$$ y_{i,j} = \sum_{c=0}^{C_{in}-1} \sum_{u=0}^{K_h-1} \sum_{v=0}^{K_w-1} x_{c, i\cdot s_h + u\cdot d_h - p_h,\ j\cdot s_w + v\cdot d_w - p_w} \cdot w_{c,u,v} + b $$

  • $ y_{i,j} $：输出特征图第 $ i $ 行第 $ j $ 列的值
  • $ x $：输入特征图；$ C_{in} $：输入通道数（如 RGB 图像 $ C_{in}=3 $）
  • $ K_h, K_w $：卷积核高、宽（如 3×3 则 $ K_h=K_w=3 $）
  • $ w_{c,u,v} $：卷积核权重（可学习参数）；$ b $：偏置（可选）
  • $ s_h, s_w $：行/列方向滑动步长（stride）
  • $ p_h, p_w $：行/列方向填充（padding）
  • $ d_h, d_w $：膨胀系数（dilation，空洞卷积）；$ d=1 $ 为普通卷积

2. 输出尺寸公式

$$ H_{out} = \left\lfloor \frac{H_{in} + 2p_h - d_h(K_h - 1) - 1}{s_h} \right\rfloor + 1, \qquad W_{out} = \left\lfloor \frac{W_{in} + 2p_w - d_w(K_w - 1) - 1}{s_w} \right\rfloor + 1 $$

  • $ H_{in}, W_{in} $：输入特征图高、宽
  • $ p, s, d, K $：同公式 1
  • 当 $ d=1, K=3, p=1, s=1 $ 时：$ H_{out} = H_{in} $（same padding，保持尺寸不变）

3. ReLU 激活函数

$$ \text{ReLU}(x) = \max(0, x) = \begin{cases} x & x > 0 \\ 0 & x \le 0 \end{cases} $$

  • $ x $：卷积输出（logit）；作用：引入非线性，缓解梯度消失，计算简单；负半轴梯度恒 0 → 神经元死亡问题可用 LeakyReLU 缓解

4. 最大池化（MaxPool）

$$ y_{i,j} = \max_{0 \le u < K, 0 \le v < K} x_{i\cdot s + u,\ j\cdot s + v} $$

  • 在 $ K\times K $ 窗口内取最大值作为输出；下采样 $ 1/s^2 $，增强平移不变性、扩大感受野，且无参数

5. 全连接分类输出（Softmax）

$$ P(y = k | \mathbf{z}) = \frac{e^{z_k}}{\sum_{j=1}^{C} e^{z_j}} $$

  • $ \mathbf{z} $：最后一层 logits 向量；$ C $：类别数；$ e^{z_k} $：指数化使分数非负、可比较
  • 交叉熵损失：$ \mathcal{L} = -\sum_{k} y_k \log P(y=k|\mathbf{z}) $，$ y_k $ 为 one-hot 真实标签

核心要点

  • 三大归纳偏置：局部连接（感受野）、权值共享（同一核滑全图）、平移等变性——使 CNN 参数远少于全连接，且天然适合图像
  • 感受野（Receptive Field）：输出像素依赖的输入区域，随层数加深而增大：$ RF_l = RF_{l-1} + (K_l-1)\prod_{i
  • 通道含义：out_channels = 卷积核个数 = 输出特征通道数；每个核提取一种特征（边缘/纹理/部件）
  • 参数计算：单个卷积核参数 = $ C_{in}\times K_h\times K_w + 1(\text{bias}) $；整层参数 = $ out\_channels \times (C_{in}K_hK_w+1) $，与输入分辨率无关
  • 池化 vs 卷积下采样：池化无参数、简单粗暴；stride>1 的卷积也可下采样（如 ResNet stem），信息保留更好
  • BN 与 ReLU 顺序：主流为 Conv → BN → ReLU（BN 归一化每通道统计量，加速收敛、允许更大学习率）

技术细节与参数详解

以 PyTorch torch.nn.Conv2d、MaxPool2d、BatchNorm2d、ReLU 为准逐一详解。

#### 参数1：in_channels（输入通道数）

  • 含义：输入特征图的通道数（RGB 图=3，灰度图=1，上层输出通道数）
  • 类型：int
  • 默认值：无（必填）
  • 取值范围：$ \ge 1 $ 的正整数
  • 对结果的影响：决定卷积核的深度（每个核是 $ C_{in}\times K_h\times K_w $ 张量）；与上一层 out_channels 必须一致，否则报维度错误
  • 推荐设置：首层取图像通道数；中间层取上一层 out_channels

#### 参数2：out_channels（输出通道数，卷积核数量）

  • 含义：本层输出特征图的通道数 = 卷积核个数；也是"本层特征抽象维度"
  • 类型：int
  • 默认值：无（必填）
  • 取值范围：$ \ge 1 $；常见 16~4096（随深度递增）
  • 对结果的影响：越大→特征表示越丰富、模型容量越大，但参数与计算量线性增长，易过拟合
  • 推荐设置：经典模式 64→128→256→512 逐层翻倍（下采样后通道翻倍维持信息量）；轻量网络用 16/32 起步

#### 参数3：kernel_size（卷积核尺寸）

  • 含义：卷积窗口的高×宽（$ K_h\times K_w $）
  • 类型：int 或 tuple (kh, kw)
  • 默认值：无（必填）
  • 取值范围：奇数常用（1, 3, 5, 7），且 $ \le $ 输入尺寸；偶数值需配合 padding 精调
  • 对结果的影响：核越大→感受野越大、参数越多（$ O(K^2) $）、计算量越大；核 1×1 只做通道混合（瓶颈层）；3×3 是性价比最优（两个 3×3 ≈ 一个 5×5 的感受野，参数却少 18/25）
  • 推荐设置：主流 3×3（VGG/ResNet 风格）；大核 7×7 仅在网络入口（如 ResNet stem）

#### 参数4：stride（步长）

  • 含义：卷积核每次滑动的像素步数
  • 类型：int 或 tuple
  • 默认值：1
  • 取值范围：$ \ge 1 $ 的正整数
  • 对结果的影响：stride>1 会按比例缩小输出尺寸（下采样）；stride=1 且配合 padding 可保持尺寸。stride 越大信息压缩越激进、特征图越小、计算越快，但过度丢失细节
  • 推荐设置：特征提取层用 1；下采样用 2（代替池化或与其搭配）

#### 参数5：padding（填充）

  • 含义：输入四周补零（或 padding_mode 指定方式）的层数
  • 类型：int / tuple / 字符串（"same"/"valid"）
  • 默认值：0
  • 取值范围：$ \ge 0 $；"same" 表示自动补齐至输出与输入同尺寸
  • 对结果的影响：控制输出尺寸、保留边界信息；无 padding 时特征图每层缩小 $ K-1 $，边界像素只被少核覆盖，信息损失
  • 推荐设置：3×3 核配 padding=1 保持尺寸（ResNet 惯例）；padding='same' 避免手动计算

#### 参数6：dilation（空洞率）

  • 含义：卷积核各元素之间的间隔（空洞卷积）
  • 类型：int 或 tuple
  • 默认值：1（普通卷积）
  • 取值范围：$ \ge 1 $；间隔 = dilation − 1
  • 对结果的影响：不增加参数地扩大感受野（如 dilation=2 的 3×3 核感受野等效 5×5）；常用于语义分割（DeepLab ASPP）与多尺度特征提取；过大会产生"棋盘格"效应、丢失细粒度信息
  • 推荐设置：普通任务默认 1；分割/检测小目标时在深层启用 2~4

#### 参数7：groups（分组卷积）

  • 含义：把输入/输出通道分组，每组内独立卷积
  • 类型：int
  • 默认值：1（普通卷积）
  • 取值范围：必须整除 in_channels 与 out_channels；groups=in_channels 即深度可分离卷积（Depthwise）
  • 对结果的影响：参数与计算量除以 groups（通道间不再全连接混合）；深度可分离卷积（MobileNet）以微小精度换数量级压缩；分组卷积也可做并行
  • 推荐设置：常规 1；轻量移动端网络用 depthwise（groups=in_channels）+ 1×1 pointwise

#### 参数8：bias（偏置项）

  • 含义：每个输出通道的加法偏置（标量）
  • 类型：bool
  • 默认值：True
  • 对结果的影响：提供平移自由度；若其后接 BatchNorm（自带可学习缩放/平移），建议 bias=False 避免冗余参数
  • 推荐设置：Conv → BN 顺序时 bias=False；Conv → ReLU 直连时 bias=True

#### 参数9：padding_mode（填充方式）

  • 含义：padding 区域的填充值来源
  • 类型：str（'zeros'/'reflect'/'replicate'/'circular'）
  • 默认值：'zeros'
  • 影响：'zeros' 零填充；'reflect' 镜像反射（边界渐变自然，常用于图像重建任务）；'replicate' 复制边缘
  • 推荐设置：分类任务默认 'zeros'；图像修复/超分常用 'reflect'

#### 参数10：MaxPool2d 的 ceil_mode（向上取整）

  • 含义：当输入尺寸不能整除核/步长时，输出尺寸是否向上取整（多出的一行一列按有效像素池化）
  • 类型：bool
  • 默认值：False（向下取整，丢弃不足窗口）
  • 影响：True 会保留边界信息，输出可能多 1 行；False 让特征图按严格整数缩放
  • 推荐设置：常规 False；配合特定尺寸对齐需求（如 U-Net）时 True

#### 参数11：MaxPool2d 的 return_indices

  • 含义：是否同时返回池化窗口内最大值的位置索引
  • 类型：bool
  • 默认值：False
  • 影响：True 时返回 (output, indices)，用于 MaxUnpool2d 反池化上采样（如自编码器、分割网络）
  • 推荐设置：一般任务 False；需要对称编解码时 True

#### 参数12：BatchNorm2d 的 num_features / eps / momentum / affine

  • 含义：对每个通道在 batch 与空间维度上归一化：$ \hat{x} = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}}\gamma + \beta $
  • 类型：int num_features；float eps（默认 1e-5）；float momentum（默认 0.1）；bool affine（默认 True）
  • 影响：缓解内部协变量偏移、允许更大学习率；训练用 batch 统计量、推理用滑动均值（running_mean/var）
  • 推荐设置：num_features=out_channels；eps 默认；momentum 0.1；affine=True

#### 参数13：ReLU / LeakyReLU 的 slope（负斜率）

  • 含义：负半轴斜率 $ \alpha $，LeakyReLU = max(0,x) + α·min(0,x)
  • 默认值：ReLU 无参数；LeakyReLU negative_slope=0.01
  • 影响：解决 ReLU 死亡神经元；α 越大负区保留信息越多
  • 推荐设置：普通 CNN 用 ReLU；担心死亡单元用 LeakyReLU(0.01~0.2)

代码示例

# -*- coding: utf-8 -*-
"""用 PyTorch 搭建一个用于 MNIST 手写数字识别的简易 CNN（逐行注释）"""
import torch
import torch.nn as nn
import torch.nn.functional as F

class SimpleCNN(nn.Module):
    """三层卷积 + 两层全连接的微型 CNN：输入 1×28×28 灰度图 → 输出 10 类"""

    def __init__(self, num_classes: int = 10):
        # 调用父类 nn.Module 的构造函数（必须）
        super().__init__()
        # ---- 第一个卷积块：提取低级特征（边缘/角点） ----
        # in_channels=1 因为 MNIST 是单通道灰度图
        # out_channels=16 提取 16 种特征，kernel=3×3, padding=1 保持 28×28 尺寸
        self.conv1 = nn.Conv2d(1, 16, kernel_size=3, stride=1, padding=1, bias=False)
        # 对 16 个通道做批归一化（卷积后、激活前）
        self.bn1 = nn.BatchNorm2d(16)
        # 2×2 最大池化：28×28 → 14×14
        self.pool1 = nn.MaxPool2d(kernel_size=2, stride=2)
        # ---- 第二个卷积块：提取组合特征 ----
        # 输入 16 通道 → 输出 32 通道；padding=1 保持尺寸 14×14
        self.conv2 = nn.Conv2d(16, 32, kernel_size=3, stride=1, padding=1, bias=False)
        # 对 32 通道归一化
        self.bn2 = nn.BatchNorm2d(32)
        # 再池化：14×14 → 7×7
        self.pool2 = nn.MaxPool2d(kernel_size=2, stride=2)
        # ---- 全连接分类头：把 32×7×7 展平为 1568 维 → 64 隐层 → 10 类 ----
        self.fc1 = nn.Linear(32 * 7 * 7, 64)   # 1568 个输入神经元 → 64 个
        # 输出层：64 → 10（MNIST 十个数字类别）
        self.fc2 = nn.Linear(64, 10)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        """前向传播：x 形状 [batch, 1, 28, 28]"""
        # 第一卷积块：卷积 → BN → ReLU → 池化
        x = self.pool1(F.relu(self.bn1(self.conv1(x))))   # [B,16,14,14]
        # 第二卷积块：同样的"卷积→BN→ReLU→池化"流水线
        x = self.pool2(F.relu(self.bn2(self.conv2(x))))   # [B,32,7,7]
        # 展平：把 [B,32,7,7] 变成 [B, 32*7*7]（保留 batch 维）
        x = x.view(x.size(0), -1)
        # 全连接：隐层激活 + 输出 logits
        x = F.relu(self.fc1(x))   # [B,64]
        x = self.fc2(x)           # [B,10] 未经 softmax（训练用 CrossEntropyLoss 自带）
        return x

if __name__ == "__main__":
    # 实例化模型
    model = SimpleCNN(num_classes=10)
    # 构造随机输入模拟一个 batch：4 张 28×28 灰度图
    dummy = torch.randn(4, 1, 28, 28)
    # 前向传播得到输出
    out = model(dummy)
    # 打印输出形状与模型总参数量
    print("输出形状:", out.shape)            # 应为 [4, 10]
    total = sum(p.numel() for p in model.parameters())
    print("模型总参数量:", total)
    # 打印第一个卷积核的权重形状
    print("conv1 权重形状:", model.conv1.weight.shape)  # [16, 1, 3, 3]

复杂度分析

时间复杂度（推导）：单个卷积层计算量（乘加次数）为输出特征图规模 × 每像素运算量：

$$ C_{conv} = O\left( C_{out} \times C_{in} \times K^2 \times H_{out} \times W_{out} \right) $$

  • $ C_{out} \times C_{in} \times K^2 $：每个输出像素要做的乘加次数（对全部输入通道做核内卷积）
  • $ H_{out}\times W_{out} $：输出像素总数（≈ $ H_{in}W_{in}/s^2 $）
  • 直观理解：计算量 = 输出元素数 × 每个元素的乘加数；相比全连接层 $ O(C_{out}C_{in}H_{in}W_{in}) $，卷积因局部连接与权值共享而节省约 $ K^2 $ 倍；$ K=3 $ 时省约 9 倍

空间复杂度：参数 $ O(C_{out} \cdot C_{in} \cdot K^2) $（与图像分辨率无关），加上中间特征图缓存 $ O(C_{out}\cdot H_{out}\cdot W_{out}\cdot batch) $。显存大头通常是各层特征图（梯度回传需要），可通过 checkpointing 折中。

池化层：无参数，计算 $ O(C_{in}\cdot H\cdot W) $，把特征图缩小 $ s^2 $ 倍，同时约减后续层计算量。

应用场景

  • 图像分类：ImageNet 分类（ResNet、EfficientNet、ConvNeXt），医疗影像（X 光/病理切片）诊断
  • 目标检测：YOLO 系列、SSD、Faster R-CNN 骨干网均为 CNN 特征提取器，检测框回归基于 CNN 特征图
  • 语义分割 / 实例分割：U-Net、DeepLab 系列（空洞卷积 + 多尺度），自动驾驶/遥感地物分类
  • 人脸识别与关键点：FaceNet（CNN 特征 + 三元组损失）、姿态估计（HRNet）
