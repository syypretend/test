DFS 深度优先搜索

类别：图算法 | 难度：入门

算法简介

深度优先搜索（Depth First Search，DFS）是最基础的图遍历算法之一，核心思想是"一条路走到黑，撞墙再回头"：从起始顶点出发，尽可能深地访问邻接顶点，直到当前顶点的所有邻接点都被访问过，才回溯到上一个顶点继续探索其他分支。与广度优先搜索（BFS）"层层推进"不同，DFS 是"纵深推进"。实现上 DFS 天然适配递归（系统调用栈自动保存回溯现场），也可用显式栈迭代实现。DFS 的价值远不止遍历：连通分量计数、环检测、拓扑排序、二分图判定、走迷宫、排列组合枚举、回溯法（N 皇后、数独）都以 DFS 为骨架。其核心配套机制是"访问标记"（visited）防止重复访问，以及"回溯"（backtracking）在搜索问题中撤销选择恢复现场。理解 DFS 的关键在于三个时刻：进入顶点时做什么（前序）、探索完一条边返回时做什么（后序）、以及回溯时做什么（恢复现场）。

原理示意图

数学公式

1. 图的基本量

$$ G = (V, E),\quad |V| = n,\quad |E| = e $$

变量解释：

  • $ G $：待遍历的图（Graph），由顶点集与边集组成
  • $ V $：顶点集合（Vertex），$ n = |V| $ 为顶点个数
  • $ E $：边集合（Edge），$ m = e = |E| $ 为边条数
  • $ n $、$ e $：复杂度分析的两个基本输入规模，分别决定时间下界的顶点扫描开销与边扫描开销

2. 邻接矩阵表示：$ A[i][j] \in \{0,1\} $ 表示顶点 $ i $ 到 $ j $ 是否有边。查一个邻居需扫描整行 → 每顶点 $ O(n) $，全体 $ O(n^2) $。

3. 邻接表表示：每个顶点维护其邻居链表，总长度为 $ 2e $（无向图每条边存两次）。

4. 时间复杂度推导：

  • 邻接矩阵：$ T(n) = \underbrace{n \times O(n)}_{\text{每顶点扫一整行}} = O(n^2) $
  • 邻接表：$ T(n) = \underbrace{O(n)}_{\text{每个顶点入栈出栈各一次}} + \underbrace{O(2e)}_{\text{每条边被检查两次}} = O(n + e) $

5. 空间复杂度推导：

  • 递归栈：最坏退化为链状图，递归深度 $ n $ → $ S(n) = O(n) $；最好为完全图（第一层就访问完全部）→ $ O(1) $
  • visited 数组：$ S(n) = O(n) $
  • 合计：$ S(n) = O(n) $（一般写 $ O(n) $，因为 visited 数组恒为 $ O(n) $，递归栈最坏 $ O(n) $）

变量解释：

  • $ O $：大 O 记号，描述渐进上界
  • $ n $：顶点数
  • $ e $：边数
  • $ 2e $：无向图中每条无向边在邻接表中出现两次（两个方向）

核心要点

  • DFS 采用"递归 + 回溯"策略，深度优先于广度；与 BFS（队列）对应的是栈/递归栈
  • visited 标记是防重复访问的核心，每次进入顶点前先判 visited
  • 连通分量判定：对每个未访问顶点启动一次 DFS，启动次数 = 连通分量个数
  • 画问题（回溯法）在 DFS 基础上增加"撤销标记"（恢复现场），注意与纯遍历的"只标记不撤销"区分
  • 迭代版 DFS 手动维护栈；若要严格保持递归版顺序，邻接点需逆序入栈

技术细节与参数详解

DFS 没有 sklearn 式的一堆超参数，但实现中的"关键配置"决定行为正确性与性能，逐项讲解：

#### 参数1：visited（访问标记数组）

  • 含义：记录每个顶点是否已被访问，避免死循环与重复访问
  • 类型：布尔数组 / 哈希集合（Python 常用 set 或 list[bool]）
  • 默认值：全部初始化为 False（或空集合）
  • 取值范围：每个顶点两个状态：False（未访问）/ True（已访问）
  • 对结果的影响：漏标记 → 图上有环时会无限递归/栈溢出；错误标记 → 漏访问顶点，连通分量统计错误
  • 推荐设置：用邻接矩阵时 visited = [False] * n；顶点编号不连续时用 set() 或 dict；注意 visited 传递方式（递归函数内要传入同一引用，勿按值复制）

#### 参数2：递归深度与 sys.setrecursionlimit

  • 含义：Python 解释器对递归调用层数的上限，超过则抛 RecursionError
  • 类型：整数（sys.setrecursionlimit(n)）
  • 默认值：约 1000
  • 取值范围：正整数，实际受 C 栈限制（堆栈溢出风险）
  • 对结果的影响：图深度超过默认 1000 时（如链状 10^4 顶点）直接崩溃；设置过大会导致段错误（Segmentation Fault）
  • 推荐设置：sys.setrecursionlimit(max(1000000, len(graph))) 或在超深图中改用迭代栈版本（工程上更稳）

#### 参数3：图的存储结构（邻接矩阵 vs 邻接表）

  • 含义：决定"找邻居"的速度，直接决定复杂度
  • 类型：list[list[int]]（矩阵，$ n \times n $）或 dict[list] / list[list[int]]（邻接表）
  • 默认值：无默认，按输入规模选择
  • 取值范围：矩阵适合稠密图（$ e \approx n^2 $），邻接表适合稀疏图
  • 对结果的影响：矩阵版 $ O(n^2) $、邻接表版 $ O(n+e) $；在 $ n=10^5 $ 的稀疏图上矩阵直接不可用
  • 推荐设置：工程与面试默认邻接表；只有 $ n \le 1000 $ 或题目明确给矩阵时才用矩阵

#### 参数4：起点与遍历起点（多源场景）

  • 含义：从哪个顶点开始搜；非连通图需对每个未访问顶点启动一次
  • 类型：顶点编号（整数）或起点集合（多源）
  • 默认值：通常 0 号顶点
  • 对结果的影响：决定访问顺序；非连通图若只从一点出发会漏掉其他连通分量
  • 推荐设置：外层 for v in range(n): if not visited[v]: dfs(v) 保证全图覆盖，且循环次数即连通分量个数

#### 参数5：剪枝条件（回溯搜索场景）

  • 含义：在递归入口判断当前状态是否越界/非法/更优，提前 return，避免无效展开
  • 类型：布尔条件表达式（边界判断、可行性剪枝、最优性剪枝）
  • 对结果的影响：剪枝质量决定回溯法的效率（如 N 皇后无剪枝是 $ O(n!) $ 量级，有剪枝大幅下降）；剪枝错误则漏解
  • 推荐设置：先判断"当前状态是否合法"再展开子状态；DFS 前按排序等策略优先探索"更可能成功"的分支

#### 参数6：回溯动作（撤销/恢复现场）

  • 含义：搜索类 DFS 在递归返回后把状态恢复为进入前（如把 visited 置回 False、把 path 弹出、棋盘格子复原）
  • 类型：代码片段（在递归调用之后执行）
  • 对结果的影响：遍历类 DFS 不撤销（每个顶点只访问一次）；搜索/排列组合类必须撤销，否则漏解
  • 推荐设置：记忆口诀"进点标记、出点撤销"；用 Python 时注意 path 用 append/pop 而非重新赋值

代码示例

# -*- coding: utf-8 -*-
# 需求：邻接表实现 DFS 全图遍历（含非连通图），并统计连通分量个数与访问顺序
import sys                      # 导入 sys，用于调整递归深度限制
from collections import defaultdict  # 导入 defaultdict，方便构造邻接表（键不存在时自动创建空列表）

# 构造示例图：无向图（6 个顶点，两个连通分量）
# 分量1：0-1-2（三角形缺一条边，实际为 0-1、1-2、0-2）；分量2：3-4、4-5
graph = defaultdict(list)      # graph[v] 存放顶点 v 的所有邻居
edges = [(0, 1), (1, 2), (0, 2), (3, 4), (4, 5)]   # 5 条无向边
for u, v in edges:             # 逐条边建邻接表
    graph[u].append(v)         # 无向图：u 的邻居加 v
    graph[v].append(u)         # 无向图：v 的邻居加 u

n = 6                          # 顶点个数（编号 0..5）
visited = [False] * n          # visited[v] 记录 v 是否已被 DFS 访问过
sys.setrecursionlimit(10000)   # 提高递归深度上限，防止深链图触发 RecursionError

def dfs(v, comp):
    """深度优先搜索：从顶点 v 出发，把访问到的顶点加入连通分量 comp"""
    visited[v] = True          # 1. 先标记当前顶点已访问（防止重复入栈）
    comp.append(v)             # 2. 前序：记录访问序列（本顶点属于当前连通分量）
    for w in graph[v]:         # 3. 遍历 v 的每一个邻居 w
        if not visited[w]:     # 4. 只对未访问的邻居继续深入（核心：visited 判重）
            dfs(w, comp)       # 5. 递归深入 w（系统调用栈自动保存 v 的现场）

components = []                # 收集所有连通分量，便于展示 DFS 全图覆盖
for v in range(n):             # 外层循环：处理非连通图，保证每个顶点都被访问
    if not visited[v]:         # 若 v 从未被访问，说明是一个新连通分量的起点
        comp = []              # 新建当前分量列表
        dfs(v, comp)           # 启动一次 DFS，从 v 深挖到底
        components.append(comp)  # 将本次 DFS 访问到的顶点存入总列表

# 输出结果
print("邻接表：", dict(graph))
print("连通分量个数：", len(components))   # 启动 DFS 的次数 = 连通分量个数
print("各分量顶点：", components)          # 例如 [[0,1,2],[3,4,5]]

# 附加：迭代版 DFS（手动栈），访问顺序可能与递归版不同（取决于入栈顺序）
def dfs_iter(start):
    """迭代 DFS：用显式栈模拟递归，先标记后入栈，防止重复入栈"""
    stack = [start]            # 1. 栈初始化为起点
    visited2 = {start}         # 2. visited2 在入栈时就标记（关键：避免同一顶点多次入栈）
    order = []                 # 3. 记录访问顺序
    while stack:               # 4. 栈空则结束
        v = stack.pop()        # 5. 弹栈顶顶点（后进先出，即深度优先）
        order.append(v)        # 6. 记录访问
        for w in reversed(graph[v]):   # 7. 逆序入栈，保证出栈顺序与递归版一致
            if w not in visited2:      # 8. 未访问才入栈
                visited2.add(w)        # 9. 入栈即标记，避免重复入栈
                stack.append(w)       # 10. 压栈
    return order               # 返回访问序列

# 打印迭代版结果（从 0 出发）
print("迭代版从0出发访问序列：", dfs_iter(0, visited))

复杂度分析

时间复杂度（邻接表）：

$$ T(n, e) = O(n) + O(2e) = O(n + e) $$

推导：每个顶点恰被访问一次（visited 保证），贡献 $ O(n) $；DFS 在顶点处遍历其邻接表，每条无向边在两个顶点处各出现一次，总检查 $ 2e $ 次，贡献 $ O(2e) $。两者相加即 $ O(n + e) $。

时间复杂度（邻接矩阵）：

$$ T(n) = O(n^2) $$

推导：判断"是否存在未访问邻居"需要扫描整行 $ n $ 个位置，每个顶点一次，共 $ n \times n = n^2 $ 次判断。

空间复杂度：

$$ S(n) = O(n) $$

推导：visited 数组 $ O(n) $；递归调用栈最坏（链状图）深度 $ n $ → $ O(n) $；两者取主导得 $ O(n) $。邻接表存储本身 $ O(n + e) $ 不计入辅助空间。

应用场景

  • 图连通性：判断无向图/有向图是否连通、求连通分量个数（并查集之外的标准 DFS 解法）
  • 环检测：有向图 DFS 的"灰色顶点"（递归栈中）可判环；无向图判环看"非父边的 visited 邻居"
  • 拓扑排序：DFS 后序（离开时间倒序）即拓扑序，Kahn 算法之外的另一标准解法
  • 回溯搜索：N 皇后、数独、迷宫寻路、排列组合、子集枚举——全部是 DFS + 剪枝
  • 路径与树论：树的直径（两次 DFS）、LCA 的 DFS 序、并查集不适用时的连通分量标记
  • 二进制枚举：状态空间 $ 2^n $ 的搜索（如子集、状态压缩）也常用 DFS 展开

DeepFM 推荐模型

类别：推荐系统 | 难度：困难

算法简介

DeepFM（A Factorization-Machine based Neural Network for CTR Prediction）由华为诺亚方舟实验室于 2017 年提出，是点击率（CTR）预估与推荐排序的经典深度学习模型。它把因子分解机（FM）与深度神经网络（DNN）融合进同一个端到端框架：FM 部分负责显式建模低阶（一阶 + 二阶）特征交叉，DNN 部分通过多层非线性变换隐式建模高阶特征交叉，两者共享同一份 embedding（特征嵌入向量），避免了 Wide&Deep 需要人工构造 wide 侧特征工程的缺点。关键设计有三：① 输入稀疏的类别特征经 embedding 层映射为稠密向量，FM 侧与 DNN 侧共享这份向量（共享参数减少内存、加速收敛）；② FM 二阶项用"向量内积"替代传统多项式的高阶权重，把 $ O(n^2) $ 的参数压缩到 $ O(nk) $；③ 输出层为二分类 sigmoid，训练用二元交叉熵损失。DeepFM 无需预训练，联合训练一次完成，在 Criteo 等 CTR 基准上优于 FM、Wide&Deep 与 DCN。如今 DeepFM 及其变体（xDeepFM、FiBiNET 等）仍是工业推荐系统离线排序的主流 baseline。

原理示意图

数学公式

1. FM 预测公式（含一阶与二阶特征交叉）

$$ \hat{y}_{FM}(x) = w_0 + \sum_{i=1}^{n} w_i x_i + \sum_{i=1}^{n}\sum_{j=i+1}^{n} \langle \mathbf{v}_i, \mathbf{v}_j \rangle x_i x_j $$

变量解释：

  • $ \hat{y}_{FM}(x) $：FM 部分的预测得分
  • $ n $：特征维数（One-hot 展开后的总维度）
  • $ w_0 $：全局偏置项（标量）
  • $ w_i $：第 $ i $ 个特征的一阶权重（线性项系数）
  • $ x_i $：第 $ i $ 个特征的取值（0/1 或连续值）
  • $ \mathbf{v}_i $：第 $ i $ 个特征的 embedding 向量（$ k $ 维）
  • $ \langle \mathbf{v}_i, \mathbf{v}_j \rangle $：两个向量内积 $ \sum_{f=1}^k v_{i,f} v_{j,f} $，用来表示 $ x_i $ 与 $ x_j $ 的二阶交叉强度
  • $ k $：embedding 维度（超参数）

2. 二阶项化简（关键优化，复杂度从 $ O(n^2 k) $ 降到 $ O(nk) $）

$$ \sum_{i=1}^{n}\sum_{j=i+1}^{n} \langle \mathbf{v}_i, \mathbf{v}_j \rangle x_i x_j = \frac{1}{2}\sum_{f=1}^{k} \left[ \left(\sum_{i=1}^{n} v_{i,f} x_i\right)^2 - \sum_{i=1}^{n} v_{i,f}^2 x_i^2 \right] $$

变量解释：

  • $ f $：embedding 的第 $ f $ 个维度（$ f=1,\dots,k $）
  • $ v_{i,f} $：第 $ i $ 个特征 embedding 的第 $ f $ 维分量
  • $ \sum_{i} v_{i,f} x_i $：各特征的 $ f $ 维分量加权和；平方项 $ (\cdot)^2 $ 会包含 $ i=j $ 的自交叉项，所以减去 $ \sum_i v_{i,f}^2 x_i^2 $ 剔除，再乘 $ 1/2 $ 消除重复计数（$ ii $）
  • 效果：每次预测只需 $ O(kn) $ 而非 $ O(k n^2) $

3. DeepFM 总输出（FM 得分 + DNN 得分，经 sigmoid）

$$ \hat{y} = \sigma\left( \hat{y}_{FM}(x) + \hat{y}_{DNN}(x^{(emb)}) \right),\qquad \sigma(z)=\frac{1}{1+e^{-z}} $$

变量解释：

  • $ \hat{y}_{DNN}(x^{(emb)}) $：深度网络对 embedding 拼接向量的输出（MLP 逐层变换）
  • $ x^{(emb)} $：各 field 的 embedding 拼接后的稠密向量
  • $ \sigma(\cdot) $：sigmoid 函数，把得分映射到 $ (0,1) $ 作为点击概率

4. 训练目标（二元交叉熵损失）

$$ \mathcal{L} = -\frac{1}{N}\sum_{i=1}^{N}\left[ y_i \log \hat{y}_i + (1-y_i)\log(1-\hat{y}_i) \right] + \lambda \|\Theta\|_2^2 $$

变量解释：

  • $ N $：训练样本数（batch 内样本数）
  • $ y_i $：第 $ i $ 个样本的真实标签（点击=1，未点击=0）
  • $ \hat{y}_i $：模型预测点击概率
  • $ \Theta $：全部可训练参数
  • $ \lambda $：L2 正则化强度（超参数）

核心要点

  • DeepFM = FM（低阶显式交叉）+ Deep（高阶隐式交叉），共享 embedding 是灵魂设计
  • 相比 Wide&Deep，DeepFM 用 FM 替代人工特征工程，无需预训练、端到端联合训练
  • 二阶交叉用内积建模，参数从 $ O(n^2) $ 降到 $ O(nk) $；利用平方差公式将计算从 $ O(n^2k) $ 优化到 $ O(nk) $
  • 稀疏类别特征必须经过 embedding 才能进入 DNN；连续特征也可做 embedding 或直接拼接
  • 工业落地要点：embedding 维度 $ k $ 通常 8~64，hidden_units 常取 (400, 400) 或 (512, 256)，配合 BN、Dropout、L2 防止过拟合

技术细节与参数详解

以 DeepCTR / TensorFlow 实现的 DeepFM 为基准，逐参数详解：

#### 参数1：embedding_dim（特征嵌入维度，即 $ k $）

  • 含义：每个 field（特征域）映射成稠密向量的长度；FM 内积与 DNN 输入共享该维度
  • 类型：正整数
  • 默认值：DeepCTR 默认 8
  • 取值范围：4 ~ 256（工业界常见 8、16、32、64）
  • 对结果的影响：$ k $ 太小 → 交叉表达能力不足（欠拟合）；$ k $ 太大 → 参数爆炸（$ O(nk) $）、过拟合、训练变慢
  • 推荐设置：特征量大时取 16~64；离线实验从小（8）开始，按 AUC/LogLoss 递增

#### 参数2：dnn_hidden_units（深度网络各层神经元数）

  • 含义：DNN 部分隐藏层每层的神经元个数（列表，长度=层数）
  • 类型：list[int]
  • 默认值：DeepCTR 默认 (128, 128)
  • 取值范围：常见 (64,)、(128, 64)、(256, 128, 64)；层数 1~5
  • 对结果的影响：层数与宽度决定高阶交叉的表达上限；过深过宽易过拟合且训练慢
  • 推荐设置：从 (128, 64) 起步；数据量大再加宽 (512, 256, 128)；配 Dropout

#### 参数3：activation（激活函数）

  • 含义：DNN 各隐藏层的非线性激活
  • 类型：str（如 'relu'、'tanh'、'sigmoid'）
  • 默认值：'relu'
  • 取值范围：常用 relu / tanh；输出层固定 sigmoid
  • 对结果的影响：relu 缓解梯度消失、收敛快；tanh 平滑但深层易梯度消失
  • 推荐设置：隐藏层默认 relu（配 BN 效果更佳）

#### 参数4：dropout（随机失活比例）

  • 含义：训练时以概率 $ p $ 随机丢弃神经元，防止 DNN 部分过拟合
  • 类型：float
  • 默认值：DeepCTR 默认 0.0（关闭）
  • 取值范围：0.0 ~ 0.9
  • 对结果的影响：DNN 越宽越需要；但过大（>0.5）欠拟合
  • 推荐设置：0.2 ~ 0.5；与 l2_reg 二选一或叠加

#### 参数5：l2_reg_embedding / l2_reg_dnn（L2 正则强度）

  • 含义：分别对 embedding 与 DNN 参数的 L2 惩罚权重（对应 $ \lambda $）
  • 类型：float
  • 默认值：DeepCTR 默认 1e-5 ~ 1e-3
  • 取值范围：0 ~ 1
  • 对结果的影响：惩罚大 → 参数趋小、泛化好但可能欠拟合；过小 → 过拟合
  • 推荐设置：1e-5 ~ 1e-3 起步，配合验证集网格搜索

#### 参数6：batch_size

  • 含义：每次梯度更新的样本数
  • 类型：int
  • 默认值：DeepCTR 默认 256
  • 取值范围：32 ~ 8192（GPU 显存允许）
  • 对结果的影响：小批量噪声大但收敛快；大批量稳定但内存/显存开销大、可能需要调学习率
  • 推荐设置：256/512/1024；与 learning_rate 联动（大批量配大学习率）

#### 参数7：learning_rate

  • 含义：优化器（Adam）步长
  • 类型：float
  • 默认值：0.001
  • 取值范围：1e-5 ~ 0.1
  • 对结果的影响：过大震荡不收敛；过小收敛极慢
  • 推荐设置：0.001（Adam）起步，若 AUC 波动大降为 0.0001

#### 参数8：epochs

  • 含义：全量数据训练轮数
  • 类型：int
  • 默认值：10（DeepCTR）
  • 对结果的影响：过少欠拟合；过多过拟合（观察验证集 AUC 拐点）
  • 推荐设置：配合 EarlyStopping（patience=2~3）动态停止

#### 参数9：use_bn（Batch Normalization）

  • 含义：DNN 隐藏层前是否做批归一化
  • 类型：bool
  • 默认值：DeepCTR 默认 False
  • 对结果的影响：加速收敛、稳定梯度，配合 relu 效果明显；但会增加少量计算
  • 推荐设置：深层网络（≥3 层）建议 True

#### 参数10：loss（损失函数）

  • 含义：训练目标
  • 类型：str
  • 默认值：'binary_crossentropy'
  • 对结果的影响：分类任务必须二元交叉熵；错用 MSE 会训练缓慢且不利于概率输出
  • 推荐设置：CTR 场景固定 binary_crossentropy

# -*- coding: utf-8 -*-
# 需求：用 DeepCTR 实现 DeepFM，训练一个 CTR 点击率预测模型（二分类）
# 依赖：pip install deepctr deepctr 需要 tensorflow 2.x 环境
import pandas as pd                      # 数据处理
from sklearn.model_selection import train_test_split  # 划分训练/测试集
from sklearn.preprocessing import LabelEncoder, MinMaxScaler  # 特征编码与归一化
from deepctr.models import DeepFM        # 导入 DeepFM 模型
from deepctr.feature_column import SparseFeat, DenseFeat, get_feature_names  # 特征列定义

# 1. 构造 1000 条模拟样本：稀疏特征（类别）+ 稠密特征（连续）
data = pd.DataFrame({
    'user_id': ['u%d' % (i % 100) for i in range(1000)],   # 100 个用户（类别特征）
    'item_id': ['i%d' % (i % 50) for i in range(1000)],    # 50 个物品（类别特征）
    'price': [float(i % 100) / 100 for i in range(1000)],  # 价格 0~0.99（连续特征）
    'click': [1 if (i % 7) < 3 else 0 for i in range(1000)]  # 标签：约 42% 点击
})

# 2. 特征编码：类别特征 LabelEncoder 转连续编号（DeepCTR 内部会 One-hot + Embedding）
sparse_features = ['user_id', 'item_id']          # 稀疏（类别）特征列表
dense_features = ['price']                        # 稠密（连续）特征列表
for col in sparse_features:                       # 逐列编码
    lbe = LabelEncoder()                          # 创建标签编码器
    data[col] = lbe.fit_transform(data[col])      # 将字符串类别转为 0..n-1 的整数
# 3. 连续特征归一化到 [0,1]，加快收敛
for col in dense_features:
    mms = MinMaxScaler()
    data[col] = mms.fit_transform(data[col].values.reshape(-1, 1))
# 4. 划分训练集与测试集
train, test = train_test_split(data, test_size=0.2, random_state=42)
# 5. 定义特征列：SparseFeat 用于类别（hash/vocabulary），DenseFeat 用于连续
fixlen_feature_columns = (
    [SparseFeat(feat, vocabulary_size=data[feat].nunique() + 1, embedding_dim=8) for feat in sparse_features]
    + [DenseFeat(feat, 1) for feat in dense_features]
)
dnn_feature_columns = fixlen_feature_columns            # DNN 侧输入（与 FM 共享 embedding）
linear_feature_columns = fixlen_feature_columns         # 线性侧输入（FM 一阶项）
# 6. 构建 DeepFM 模型：dnn_hidden_units 指定 DNN 层结构
model = DeepFM(
    linear_feature_columns=linear_feature_columns,      # FM 一阶与二阶输入
    dnn_feature_columns=dnn_feature_columns,            # DNN 部分输入（共享 embedding）
    dnn_hidden_units=(128, 64),                        # 隐藏层 [128, 64]
    dnn_activation='relu',                              # 激活函数
    dnn_dropout=0.2,                                    # dropout 0.2
    dnn_use_bn=True,                                    # 开启 Batch Normalization
    l2_reg_linear=1e-5,                                 # 线性部分 L2
    l2_reg_embedding=1e-5,                              # embedding L2
    l2_reg_dnn=1e-5                                     # DNN 部分 L2
)
# 7. 编译：Adam 优化器 + 二元交叉熵损失
model.compile(optimizer='adam', loss='binary_crossentropy', metrics=['AUC'])
# 8. 训练
history = model.fit(
    model.input_dict_from_df(test[sparse_features + dense_features]),  # 构建模型输入（稀疏列 DataFrame）
    test['click'].values,          # 标签
    batch_size=256,                # 批大小
    epochs=10,                     # 轮数
    validation_split=0.2,          # 20% 做验证
    verbose=1
)
# 9. 预测
pred = model.predict(model.input_dict_from_df(test[sparse_features + dense_features]))  # 输出点击概率
print("预测概率示例：", pred[:5].flatten())

复杂度分析

FM 部分时间复杂度：

$$ T_{\text{FM}} = O(n k) $$

推导：利用 $ \frac{1}{2}\sum_f[(\sum_i v_{i,f}x_i)^2 - \sum_i v_{i,f}^2 x_i^2] $ 化简，一阶项 $ O(n) $，二阶化简后 $ O(nk) $（两层循环 $ i $ 与 $ f $），若直接双重枚举 $ i

DNN 部分时间复杂度：

$$ T_{\text{DNN}} = O\left(\sum_{l=1}^{L} d_{l-1} \cdot d_l\right) $$

推导：第 $ l $ 层全连接输入 $ d_{l-1} $ 维、输出 $ d_l $ 维，矩阵乘 $ O(d_{l-1}d_l) $；$ L $ 层求和。输入维度 $ d_0 = m \cdot k $（$ m $ 个 field × embedding 维 $ k $）。

空间复杂度（参数总量）：

$$ S = O(nk) + O\left(\sum_{l=1}^{L} d_{l-1} \cdot d_l\right) $$

推导：FM 侧 embedding 参数 $ n \times k $；DNN 侧每层权重矩阵 $ d_{l-1} \times d_l $；两者相加。相比纯 FM（$ O(nk) $）DeepFM 增加的是 DNN 权重。

应用场景

  • CTR 预估：广告、推荐流中预测用户点击概率，DeepFM 是工业界主力 baseline
  • 推荐排序：用户特征（性别、年龄、历史类目）+ 物品特征（类目、价格）+ 上下文特征 → 排序打分
  • 转化率预估（CVR）：与 CTR 共享特征体系，输出概率做转化率预估
  • 广告投放：AUC/GAUC 提升直接对应收入提升，DeepFM 训练快、可解释（FM 低阶部分）
  • 召回/粗排特征：DeepFM embedding 可复用为向量召回的用户/物品表征

AdaBoost

类别：集成学习 | 难度：中等

算法简介

AdaBoost（Adaptive Boosting，自适应提升）是 Boosting 家族的开山算法，由 Freund 与 Schapire 于 1995 年提出，2003 年获得 Gödel 奖。核心思想是串行训练一组弱学习器（weak learner），让后一个学习器重点关注前一个学习器分错的样本：每轮结束后，对被分错（或损失大）的样本加大权重，被分对则降低权重，然后用加权后的样本分布训练下一个弱学习器；最终所有弱学习器按各自"话语权"（alpha，分类误差越低话语权越高）加权投票得到强分类器。理论保证：只要每个弱学习器的错误率略低于随机猜测（二分类 < 0.5），随着迭代次数 $ T $ 增加，训练误差可以指数级下降。sklearn 的 AdaBoostClassifier 默认基学习器是深度为 1 的决策树（决策桩），常用 algorithm='SAMME.R'（实数 AdaBoost，用加权概率预测而非类别标签）。AdaBoost 对异常点敏感（异常点会被不断放大权重），这既是它的特点也是局限；现代工业界更多使用梯度提升（GBDT/XGBoost/LightGBM），但 AdaBoost 的思想（自适应权重 + 加法模型）是理解整个提升树的基石。

原理示意图

数学公式

1. 样本权重初始化

$$ D_1(i) = \frac{1}{N},\quad i = 1, 2, \dots, N $$

变量解释：

  • $ D_1(i) $：第 1 轮迭代时第 $ i $ 个样本的权重
  • $ N $：训练样本总数

2. 第 t 轮加权错误率

$$ \varepsilon_t = \sum_{i: h_t(x_i) \ne y_i} D_t(i) $$

变量解释：

  • $ \varepsilon_t $：第 $ t $ 轮弱学习器 $ h_t $ 在加权分布下的错误率
  • $ h_t(x_i) $：第 $ t $ 个弱学习器对样本 $ x_i $ 的预测（±1）
  • $ y_i $：真实标签（±1）
  • $ D_t(i) $：第 $ t $ 轮样本权重；求和只针对分错样本，故 $ 0 \le \varepsilon_t \le 1 $

3. 弱学习器的话语权（权重系数）

$$ \alpha_t = \frac{1}{2}\ln\frac{1-\varepsilon_t}{\varepsilon_t} $$

变量解释：

  • $ \alpha_t $：第 $ t $ 个弱学习器在最终投票中的权重
  • $ \ln $：自然对数
  • 性质：$ \varepsilon_t $ 越小，$ (1-\varepsilon_t)/\varepsilon_t $ 越大，$ \alpha_t $ 越大——"越准越有话语权"；$ \varepsilon_t = 1/2 $ 时 $ \alpha_t = 0 $（随机猜测无贡献）；$ \varepsilon_t \ge 1/2 $ 时算法应终止（不满足弱学习条件）

5. 样本权重更新（归一化后）

$$ D_{t+1}(i) = \frac{D_t(i) \cdot \exp(-\alpha_t \cdot y_i \cdot h_t(x_i))}{Z_t} $$

变量解释：

  • $ \exp(\cdot) $：指数函数
  • $ y_i \cdot h_t(x_i) $：分对时 $ = +1 $，分错时 $ = -1 $
  • $ Z_t $：归一化因子 $ Z_t = \sum_i D_t(i)\exp(-\alpha_t y_i h_t(x_i)) $，保证 $ D_{t+1} $ 是合法概率分布（和为 1）
  • 效果：分对的样本权重乘 $ e^{-\alpha_t}<1 $（减小）；分错的乘 $ e^{\alpha_t}>1 $（增大），从而下轮更关注错分样本

6. 最终强分类器（加权投票）

$$ H(x) = \operatorname{sign}\left( \sum_{t=1}^{T} \alpha_t h_t(x) \right) $$

变量解释：

  • $ H(x) $：集成后的最终分类结果（±1）
  • $ \operatorname{sign}(\cdot) $：符号函数（>0 取 +1，<0 取 -1）
  • $ T $：弱学习器个数（n_estimators）
  • $ \sum_{t=1}^{T}\alpha_t h_t(x) $：所有弱学习器按话语权 $ \alpha_t $ 加权求和

核心要点

  • AdaBoost 是串行提升：每轮训练一个弱学习器，并用它更新样本权重分布
  • 权重更新规则：分错样本权重指数放大（×$ e^{\alpha_t} $），分对缩小（×$ e^{-\alpha_t} $）
  • 投票权重 $ \alpha_t = \frac12\ln\frac{1-\varepsilon_t}{\varepsilon_t} $：错误率越低话语权越大
  • 训练误差上界：$ \frac{1}{N}\sum_i [H(x_i)\ne y_i] \le \prod_t 2\sqrt{\varepsilon_t(1-\varepsilon_t)} $，随 $ T $ 指数下降
  • sklearn 两个算法变体：SAMME（用类别标签）与 SAMME.R（用加权概率，sklearn 1.2 起改名 'samme' / 'samme.r'）
  • 对异常点敏感：异常样本权重会滚雪球式放大；使用时注意数据质量

技术细节与参数详解

以 sklearn.ensemble.AdaBoostClassifier 为基准，逐参数详解：

#### 参数1：base_estimator（基学习器，sklearn 1.2 起改名 estimator）

  • 含义：作为弱学习器的分类器对象
  • 类型：estimator 对象（支持样本权重 sample_weight）
  • 默认值：None → DecisionTreeClassifier(max_depth=1)（决策桩）
  • 取值范围：任意带 sample_weight 的分类器，如决策树、逻辑回归
  • 对结果的影响：默认决策桩最简单、方差小、不易过拟合，是 Boosting 的黄金搭档；换成深树或 SVM 会显著改变性能与训练时间
  • 推荐设置：默认决策桩；确需自定义时保持"弱"（浅层）以发挥 Boosting 的叠加效果

#### 参数2：n_estimators（弱学习器个数，即 $ T $）

  • 含义：串行训练的弱分类器数量
  • 类型：int
  • 默认值：50
  • 取值范围：1 ~ 任意大（受时间与过拟合约束）
  • 对结果的影响：$ T $ 太小欠拟合；太大在噪声数据上过拟合（AdaBoost 训练误差可到 0，测试可能回升）。训练误差上界 $ \prod_t 2\sqrt{\varepsilon_t(1-\varepsilon_t)} $ 随 $ T $ 指数下降
  • 推荐设置：先用默认 50 观察，结合 GridSearchCV 在 50~500 间搜索；配合 early stopping 思想（交叉验证选择）

#### 参数3：learning_rate（学习率，步长收缩）

  • 含义：每轮对最终得分的贡献收缩系数：实际投票为 $ \alpha_t \times \text{learning_rate} $
  • 类型：float
  • 默认值：1.0
  • 取值范围：$ (0, 1] $（建议）
  • 对结果的影响：学习率小 → 每轮步子小、需要更多 n_estimators 补偿（两者呈反比）；学习率大 → 收敛快但易过拟合/不稳定
  • 推荐设置：学习率与 n_estimators 联动调优：learning_rate=0.1 时 n_estimators 适当加大（如 300~500）

#### 参数4：algorithm（提升算法，sklearn 1.2 起改名为 estimator 参数的 SAMME/SAMME.R）

  • 含义：AdaBoost 分类的具体算法
  • 类型：str
  • 默认值：'SAMME.R'（sklearn 旧版本；1.5 后仅支持 'samme' 与 'samme.r'）
  • 取值范围：'SAMME'（离散 AdaBoost，用类别标签 0/1）、'SAMME.R'（实数 AdaBoost，用预测概率）
  • 对结果的影响：SAMME.R 收敛更快、通常精度更高（利用概率信息），但要求基学习器能输出概率（predict_proba）；SAMME 只要求类别
  • 推荐设置：默认 'SAMME.R'；若基学习器不支持 predict_proba 才用 'SAMME'

#### 参数5：random_state（随机种子）

  • 含义：控制基学习器内部随机性（如决策树特征分裂的随机选择）
  • 类型：int 或 None
  • 默认值：None（每次运行结果不完全一致）
  • 对结果的影响：固定种子 → 可复现实验；不固定 → 结果有微小波动
  • 推荐设置：实验、调参、对比时固定（如 42）

#### 参数6：loss（仅 AdaBoostRegressor）

  • 含义：回归版本的损失函数
  • 类型：str（'linear'、'square'、'exponential'）
  • 默认值：'linear'
  • 取值范围：linear / square / exponential
  • 对结果的影响：对异常值敏感性依次增大（exponential 最敏感）
  • 推荐设置：分类任务用 AdaBoostClassifier（无此参数）；回归默认 linear

    n_samples=2000,        # 样本数 2000
    n_features=20,         # 特征数 20

复杂度分析

时间复杂度：

$$ T(n, d, T) = O(T \cdot (n d + n)) $$

推导：每轮训练一个深度为 1 的决策桩：寻找最优分裂点需要扫描 $ n $ 个样本 × $ d $ 个特征 → $ O(nd) $；分裂后更新样本权重并归一化需 $ O(n) $。共 $ T $ 轮，故 $ O(T(nd + n)) $。若基学习器为深度 $ h $ 的树，则单轮为 $ O(n d h) $，总体 $ O(T n d h) $。

空间复杂度：

$$ S = O(T \cdot \text{size}(h_t) + n) $$

推导：需要保存 $ T $ 个弱学习器（每个决策桩存分裂特征、阈值、左右叶子标签，$ O(1) $ 级）+ 样本权重向量 $ O(n) $；输入数据 $ O(nd) $ 不计入辅助空间。

应用场景

  • 二分类基线：Kaggle 早期竞赛、业务快速 baseline（比单棵决策树强、比 GBDT 轻量）
  • 异常检测：少数类加权后 AdaBoost 能加强对困难样本区分，但注意异常点敏感性
  • 特征选择：低权重特征重要性排序（feature_importances_）辅助工程筛选
  • 多分类：SAMME 支持多分类（一对多方式），小规模多分类任务可用
  • 教学与面试：理解 Boosting 原理的标准模型，为学习 XGBoost/LightGBM 打基础
  • 在线学习：作为集成成员的在线更新单元（配合流式数据版本）
