摩尔投票法（Boyer-Moore Majority Vote）

类别：技巧 | 难度：入门

算法简介

摩尔投票法（Boyer-Moore majority vote algorithm）由 Robert S. Boyer 与 J Strother Moore 于 1981 年提出，是一种在线性时间、常数空间内寻找"多数元素"（出现次数超过 $ \lfloor n/2 \rfloor $ 的元素）的经典算法。核心思想是"抵消"：把数组中的每个元素想象成一张选票，当两个不同的元素相遇时互相抵消；由于多数元素的票数超过总数一半，即使与所有其他元素逐一抵消，最终剩下的候选者一定是它。算法只需要两个变量：一个候选者 candidate 和一个计数器 count，遍历一遍数组即可得出答案，是处理数据流场景的典型算法。它无需排序、无需哈希表，空间复杂度被压到 $ O(1) $，在内存受限的嵌入式、流式场景中尤其有价值。

原理示意图

数学公式

① 多数元素的判定条件（问题定义）：

$$ \text{若 } count(x) > \left\lfloor \frac{n}{2} \right\rfloor \text{，则 } x \text{ 是多数元素} $$

变量解释：

  • $ n $：数组长度
  • $ count(x) $：元素 $ x $ 在数组中出现的次数
  • $ \lfloor n/2 \rfloor $：$ n/2 $ 向下取整，"超过一半"即大于该值

② 抵消过程的数学性质（算法正确性核心）：设多数元素为 $ m $，其余元素集合为 $ O $。每次抵消"两个不同的元素"等价于消耗一个 $ m $ 和一个 $ O $ 中的元素（或两个 $ O $ 中的元素）。因为 $ count(m) > count(O) $（多数元素比所有其他元素的总和还多），所以无论抵消顺序如何，$ m $ 永远不会被完全抵消，最终留下的候选必然为 $ m $：

$$ count(m) > n - count(m) \;\Longrightarrow\; count(m) - (n - count(m)) > 0 $$

符号解释：

  • $ count(m) $：多数元素的出现次数
  • $ n - count(m) $：非多数元素的总出现次数
  • 不等式成立意味着"净票数"恒为正，保证候选最终存活

③ 推广形式（找超过 $ n/k $ 的元素）：多数元素至多有 $ k-1 $ 个，需要维护 $ k-1 $ 个候选对（candidate 数组 + count 数组）。例如 LeetCode 229 题求超过 $ n/3 $ 的元素，用 2 个候选对即可：

$$ count(m_i) > \frac{n}{k} \quad (i = 1, 2, \ldots, k-1) $$

符号解释：

  • $ m_i $：第 $ i $ 个候选多数元素（至多 $ k-1 $ 个）
  • $ k $：推广参数，如 $ k=3 $ 表示寻找出现超过 $ n/3 $ 的元素

核心要点

  • 核心思想是"不同元素互相抵消"，多数元素数量过半，必然最后胜出
  • 只需 1 次遍历 + 常数空间，时间复杂度 $ O(n) $、空间复杂度 $ O(1) $
  • 前提条件：必须保证存在超过一半的元素；否则需要二次扫描验证候选的计数
  • 推广：找超过 $ n/k $ 的元素需 $ k-1 $ 个候选对
  • 天然适配流式数据：只需维护两个变量，无需保存整个数组
  • 1981 年由 Boyer 和 Moore 提出，是数据流算法的典型代表

技术细节与参数详解

摩尔投票算法没有库函数参数，其核心是 3 个状态变量 + 1 个可选参数，逐一详解：

#### 参数1：输入数组 nums（及其长度 $ n $）

  • 含义：待寻找多数元素的整数数组，即"选票序列"
  • 类型：一维数组（Python 中为 list[int]）
  • 默认值：无（必需输入）
  • 取值范围：$ n \geq 0 $；$ n = 0 $ 时为空输入，无多数元素
  • 对结果的影响：长度决定判定阈值 $ \lfloor n/2 \rfloor $；元素分布决定抵消轨迹（不改变结果正确性）
  • 推荐设置：无特殊要求；若题目不保证存在多数元素，遍历后需额外扫描验证

#### 参数2：候选变量 candidate

  • 含义：当前胜出的候选元素，即"最终可能成为多数元素的元素"
  • 类型：与数组元素同类型（如 int）
  • 默认值：无（用任意哨兵值初始化，首次扫描时被覆盖）
  • 取值范围：任意数组元素值
  • 对结果的影响：它承载抵消过程的"幸存者"；当 count 归零时被替换为当前元素
  • 推荐设置：初始化为任意哨兵（如 None），靠逻辑在 count == 0 时赋值

#### 参数3：计数器 count

  • 含义：当前候选元素"未被抵消的净票数"
  • 类型：int
  • 默认值：0
  • 取值范围：$ [0, n] $，算法过程中从 0 增减，最终剩余值表示候选的净胜票数
  • 对结果的影响：是驱动候选切换的唯一开关——遇到相同元素 count += 1，不同元素 count -= 1；count == 0 时更换候选
  • 示例：输入 [2,2,1,1,1,2,2] 中 count 变化轨迹为 1 → 2 → 1 → 0 → 1 → 0 → 1

#### 参数4：推广参数 k（可选）

  • 含义：推广变体中"超过 $ n/k $"的分母，用于寻找超过 $ n/k $ 次的元素
  • 类型：int
  • 默认值：$ k = 2 $（标准问题，找超过一半的元素）
  • 取值范围：$ k \geq 2 $
  • 对结果的影响：$ k = 2 $ 时维护 1 个候选对；$ k = 3 $ 时维护 2 个候选对；$ k $ 越大候选对越多，内存开销 $ O(k) $
  • 推荐设置：只找多数元素用默认 $ k=2 $；题目明确要求"超过 $ n/3 $"等才增大 $ k $

代码示例

def majority_element(nums):
    """摩尔投票法：寻找出现次数超过 n/2 的多数元素（LeetCode 169）"""
    candidate = None  # 候选元素，初始化为空
    count = 0         # 计数票数：初始为 0

    # 第一遍扫描：对抗与抵消阶段，找出候选元素
    for num in nums:              # 遍历数组中的每一个元素
        if count == 0:           # 如果净票数为 0，旧候选已"被抵消完"
            candidate = num      # 把当前元素立为新候选
            count = 1            # 新候选初始计 1 票
        elif num == candidate:   # 如果当前元素与候选相同
            count += 1           # 给它投一票，计数 +1
        else:                    # 否则当前元素与候选不同
            count -= 1           # 一票抵消：候选净票数 -1

    # 题目保证存在多数元素，candidate 即答案
    return candidate             # 返回最终候选

# ---------- 验证 ----------
nums = [2, 2, 1, 1, 1, 2, 2]    # 多数元素 2 出现 4 次 > 7/2
print(majority_element(nums))   # 期望输出: 2

推广变体（找超过 n/3 的元素，LeetCode 229）：

def majority_element_n3(nums):
    """寻找出现次数超过 n/3 的元素（最多 2 个）"""
    cand1 = cand2 = None   # 两个候选：k=3 时最多 2 个候选
    cnt1 = cnt2 = 0         # 两个候选各自的计数票数

    # 第一阶段：三个不同元素互抵，维护 2 个候选对
    for num in nums:                              # 遍历每个元素
        if cand1 is not None and num == cand1:    # 与候选 1 相同
            cnt1 += 1                             # 候选 1 票数 +1
        elif cand2 is not None and num == cand2:  # 与候选 2 相同
            cnt2 += 1                             # 候选 2 票数 +1
        elif cnt1 == 0:                           # 候选 1 空缺
            cand1, cnt1 = num, 1                  # 立候选 1，票数置 1
        elif cnt2 == 0:                           # 候选 2 空缺
            cand2, cnt2 = num, 1                  # 立候选 2，票数置 1
        else:                                     # 三者都不同，三向抵消
            cnt1 -= 1                             # 候选 1 票数 -1
            cnt2 -= 1                             # 候选 2 票数 -1

    # 第二阶段：重新统计两个候选的真实出现次数，验证是否 > n/3
    res = []                                   # 结果列表
    for cand in (cand1, cand2):                # 逐个验证两个候选
        if cand is None:                       # 候选可能为空
            continue                           # 跳过空候选
        if nums.count(cand) > len(nums) // 3:  # 统计真实次数是否超阈值
            res.append(cand)                   # 超阈值则加入结果
    return res                                 # 返回结果（最多 2 个）

复杂度分析

时间复杂度：$ O(n) $

  • 遍历一次数组，每个元素执行常数次操作（比较、自增/自减、赋值），总操作次数 $ \approx c \cdot n $（$ c $ 为常数）→ 取最高阶为 $ O(n) $
  • 推广变体（$ k $ 个候选）仍是一次遍历：$ O(k \cdot n) $，$ k $ 固定时仍为 $ O(n) $

空间复杂度：$ O(1) $（经典版）

  • 只使用 candidate 和 count 两个标量变量，与输入规模 $ n $ 无关
  • 推广版为 $ O(k) $，$ k $ 固定时退化为 $ O(1) $

推导依据：每轮循环体的比较与算术操作均为 $ O(1) $，总操作数 $ \le 4n + O(1) $，按大 O 定义取最高阶为 $ O(n) $；空间上无论 $ n $ 多大都只占用固定数量的变量，故 $ O(1) $。

应用场景

  • LeetCode 经典面试题：169（多数元素）、229（众数 II），字节跳动、微软等公司高频题
  • 流式数据处理：网络日志中找出现超过一半的错误码，无需缓存整个数据流
  • 选举/投票统计：无序选票中快速确定获胜者，无需遍历统计全部候选票数
  • 分布式系统：多数派判定（如 Raft 中多数节点 ≥ n/2+1 的提交判断）
  • 嵌入式/内存受限场景：常数空间特性适合内存紧张的单片机设备

XGBoost（极致梯度提升）

类别：集成学习 | 难度：中等

算法简介

XGBoost（eXtreme Gradient Boosting，极致梯度提升）是陈天奇于 2016 年提出的梯度提升树（GBDT）的高效实现，是表格数据竞赛（Kaggle 等）与工业界的"标配"算法。核心思想是加法模型 + 梯度提升：训练 $ K $ 棵 CART 决策树，每一棵新树都在学习之前所有树的残差（负梯度方向），最终把 $ K $ 棵树输出相加得到预测值。与普通 GBDT 相比，XGBoost 做了三大改进：① 目标函数显式加入正则项（叶节点数 + L1/L2 权重惩罚），抑制过拟合；② 对损失函数做二阶泰勒展开（同时用一阶梯度 $ g $ 和二阶梯度 $ h $），收敛更快、精度更高；③ 工程优化：预排序 + 加权分位数草图、列块存储、缓存感知访问、多线程并行，训练速度比普通 GBDT 快数倍到数十倍。超参数分三大类：通用参数（booster 等）、Booster 参数（树结构、正则、采样）和学习任务参数（objective/eval_metric）。

原理示意图

数学公式

① 加法模型（整体预测）：

$$ \hat{y}_i^{(t)} = \sum_{k=1}^{t} f_k(x_i) = \hat{y}_i^{(t-1)} + f_t(x_i) $$

符号解释：

  • $ \hat{y}_i^{(t)} $：第 $ t $ 轮迭代后对样本 $ x_i $ 的预测值（前 $ t $ 棵树之和）
  • $ f_k(x_i) $：第 $ k $ 棵 CART 树对样本 $ x_i $ 的输出（叶节点权重）
  • $ \hat{y}_i^{(t-1)} $：前 $ t-1 $ 棵树的预测值；$ f_t(x_i) $：本轮新增树的输出

② 目标函数（带正则）：

$$ \text{Obj} = \sum_{i=1}^{N} L(y_i, \hat{y}_i) + \sum_{k=1}^{t} \Omega(f_k), \quad \Omega(f) = \gamma T + \frac{1}{2}\lambda \|w\|^2 + \alpha \|w\|_1 $$

符号解释：

  • $ L(y_i, \hat{y}_i) $：单个样本的损失函数（如平方误差、对数损失）；$ y_i $ 为真实标签，$ \hat{y}_i $ 为预测值
  • $ N $：样本总数
  • $ \Omega(f) $：第 $ f $ 棵树的复杂度惩罚（正则化）
  • $ T $：该树的叶节点个数；$ w $：叶节点权重向量
  • $ \gamma $：叶节点惩罚系数（对应 gamma）；$ \lambda $：L2 正则（reg_lambda，默认 1）；$ \alpha $：L1 正则（reg_alpha，默认 0）
  • $ \|w\|^2 $ 为 L2 范数平方，$ \|w\|_1 $ 为 L1 范数（绝对值之和）

③ 二阶泰勒展开（每轮新增树的优化目标）：

$$ \text{Obj}^{(t)} \approx \sum_{i=1}^{N} \left[ L(y_i, \hat{y}_i^{(t-1)}) + g_i f_t(x_i) + \frac{1}{2} h_i f_t^2(x_i) \right] + \gamma T + \frac{1}{2}\lambda \sum_{j=1}^{T} w_j^2 $$

符号解释：

  • $ g_i = \partial_{\hat{y}^{(t-1)}} L(y_i, \hat{y}_i^{(t-1)}) $：损失对上一轮预测值的一阶偏导（梯度）
  • $ h_i = \partial^2_{\hat{y}^{(t-1)}} L(y_i, \hat{y}_i^{(t-1)}) $：二阶偏导（Hessian 对角元素）
  • 常数项 $ L(y_i, \hat{y}_i^{(t-1)}) $ 与当前树无关，优化时可省略
  • 使用二阶信息是 XGBoost 相比 GBDT（只用 $ g_i $）的关键差异

④ 最优叶节点权重与分裂增益：

$$ w_j^* = -\frac{\sum_{i \in I_j} g_i}{\sum_{i \in I_j} h_i + \lambda} $$

$$ \text{Gain} = \frac{1}{2} \left[ \frac{(\sum_{i \in I_L} g_i)^2}{\sum_{i \in I_L} h_i + \lambda} + \frac{(\sum_{i \in I_R} g_i)^2}{\sum_{i \in I_R} h_i + \lambda} - \frac{(\sum_{i \in I} g_i)^2}{\sum_{i \in I} h_i + \lambda} \right] - \gamma $$

符号解释：

  • $ I_j $：落入第 $ j $ 个叶节点的样本集合；$ I_L $、$ I_R $ 分别为分裂后左右子节点的样本集
  • $ w_j^* $：该叶节点最优权重（闭式解）
  • $ \text{Gain} $：按特征值分裂产生的增益；增益 $ \leq 0 $（或小于 gamma）时不再分裂

核心要点

  • 加法模型 + 梯度提升：每棵新树拟合前序模型的"负梯度（残差）"方向
  • 使用一阶 + 二阶导数（泰勒展开），比 GBDT 精度更高、收敛更快
  • 内置 L1/L2 正则化 + 叶节点惩罚，从算法层面抑制过拟合
  • 预剪枝（gamma）+ 后剪枝（增益检查）双保险
  • 高效工程：C 级实现、列块存储、直方图近似（hist）、并行/GPU/分布式
  • 原生支持缺失值处理：分裂时自动学习缺失值走向
  • 调参路径：先粗（eta/max_depth/min_child_weight）→ 再正则（lambda/alpha/gamma）→ 最后降 eta 增轮次

技术细节与参数详解

XGBoost 超参数分三大类，逐个详解（以 Python xgboost 库 sklearn API 与原生 API 为准）：

#### 通用参数（General Parameters）

##### 参数 1：booster

  • 含义：基础模型类型（每轮加法单元的模型）
  • 类型：字符串枚举
  • 默认值：'gbtree'
  • 取值范围：gbtree（树）、gblinear（线性）、dart（带 dropout 的树）
  • 对结果的影响：gbtree 捕捉非线性；gblinear 适合稀疏线性；dart 增加随机丢弃防过拟合
  • 推荐设置：默认 gbtree；高维稀疏特征用 gblinear；严重过拟合试 dart

#### 树结构参数（Booster 参数）

##### 参数 2：eta / learning_rate

  • 含义：学习率，每棵树贡献的缩步因子（收缩率）
  • 类型：float
  • 默认值：0.3
  • 取值范围：$ (0, 1] $，实际建议 $ 0.01 \sim 0.3 $
  • 对结果的影响：越小每棵树贡献越少、泛化越好但需更多棵树；过大易震荡过拟合
  • 推荐设置：先 0.1 起步，后期降到 0.01~0.05 并增大轮数

##### 参数 3：max_depth

  • 含义：单棵 CART 树的最大深度
  • 类型：int
  • 默认值：6
  • 取值范围：$ [0, \infty) $，0 表示不限深度（不推荐）
  • 对结果的影响：越深容量越大但易过拟合且训练慢；太浅欠拟合
  • 推荐设置：默认 6；小数据或噪声多时 3~5；大数据量 8~12 需配正则

##### 参数 4：min_child_weight

  • 含义：叶节点样本二阶梯度（权重）之和的最小值（近似最小样本数）
  • 类型：float
  • 默认值：1
  • 取值范围：$ [0, \infty) $
  • 对结果的影响：越大越保守，抑制过小样本叶子，防过拟合；过大会欠拟合
  • 推荐设置：默认 1；样本少或噪声高时 3~10 尝试

##### 参数 5：gamma

  • 含义：节点分裂所需的最小损失下降增益（预剪枝强度）
  • 类型：float
  • 默认值：0
  • 取值范围：$ [0, \infty) $
  • 对结果的影响：只有分裂增益 $ > \gamma $ 才分裂，越大树越矮越保守
  • 推荐设置：默认 0；过拟合时 0.1~0.5 网格搜

##### 参数 6：subsample

  • 含义：每棵树的样本采样比例（行采样）
  • 类型：float
  • 默认值：1
  • 取值范围：$ (0, 1] $，常用 $ 0.5 \sim 0.9 $
  • 对结果的影响：小于 1 引入随机性降低方差、抗过拟合；过小欠拟合
  • 推荐设置：大数据集 0.8 左右，配合加大轮数

##### 参数 7：colsample_bytree

  • 含义：每棵树建立时特征采样比例（列采样）
  • 类型：float
  • 默认值：1
  • 取值范围：$ (0, 1] $，常用 $ 0.6 \sim 0.9 $
  • 对结果的影响：降低特征间相关性影响，显著抗过拟合（类似随机森林）
  • 推荐设置：特征多时 0.6~0.8

##### 参数 8：colsample_bylevel / colsample_bynode

  • 含义：每层 / 每个节点分裂时的特征采样比例
  • 类型：float
  • 默认值：1
  • 取值范围：$ (0, 1] $，需满足 bynode ≤ bylevel ≤ bytree
  • 对结果的影响：更细粒度随机化
  • 推荐设置：一般不动；需要极致随机化时 0.7 左右

##### 参数 9：lambda / reg_lambda

  • 含义：L2 正则项系数（叶权重平方惩罚）
  • 类型：float
  • 默认值：1
  • 取值范围：$ [0, \infty) $
  • 对结果的影响：越大权重越扁平、模型越简单；数值回归中稳定权重更新
  • 推荐设置：默认 1；过拟合时增到 2~5 网格搜

##### 参数 10：alpha / reg_alpha

  • 含义：L1 正则系数（权重绝对值惩罚）
  • 类型：float
  • 默认值：0
  • 取值范围：$ [0, \infty) $
  • 对结果的影响：L1 将不重要的叶权重压成 0，有特征筛选作用；高维特征场景收益明显
  • 推荐设置：默认 0；高维稀疏特征时 0.1~1.0

##### 参数 11：max_delta_step

  • 含义：每步更新权重的最大增量限制（类似梯度裁剪）
  • 类型：int/float
  • 默认值：0（不限）
  • 取值范围：$ [0, \infty) $
  • 对结果的影响：类别极端不平衡时限制每步幅度，稳定训练
  • 推荐设置：默认 0；极端不平衡时 1~10

##### 参数 12：scale_pos_weight

  • 含义：正样本权重缩放（类别不平衡调节）
  • 类型：float
  • 默认值：1
  • 取值范围：$ (0, \infty) $，常用 $ \frac{\text{负样本数}}{\text{正样本数}} $
  • 对结果的影响：给正样本损失加权，提高召回率
  • 推荐设置：正样本比例 $ p $ 时设为 $ \frac{1-p}{p} $

##### 参数 13：tree_method

  • 含义：树构建算法（分裂搜索策略）
  • 类型：字符串枚举
  • 默认值：auto（1.6+ 实际默认 hist）
  • 取值范围：exact（精确贪心）、approx（分位数近似）、hist（直方图）、gpu_hist（GPU）
  • 对结果的影响：exact 最准最慢；hist 用直方图离散化训练快数倍，精度损失极小
  • 推荐设置：小数据 exact；大数据一律 hist

#### 学习任务参数

##### 参数 14：objective

  • 含义：优化目标（损失函数类型）
  • 类型：字符串枚举
  • 默认值：reg:squarederror
  • 取值范围：回归 reg:squarederror/reg:squaredlogerror；二分类 binary:logistic；多分类 multi:softmax/multi:softprob；排序 rank:pairwise 等
  • 对结果的影响：决定损失形态、梯度与输出含义（是否概率）
  • 推荐设置：回归 reg:squarederror；二分类 binary:logistic；多分类 multi:softprob

##### 参数 15：eval_metric

  • 含义：验证集评估指标（不参与优化，只做监控/早停）
  • 类型：字符串或列表
  • 默认值：随 objective 自动（如 rmse、logloss）
  • 取值范围：rmse/mae/logloss/error/auc/mlogloss/ndcg 等
  • 对结果的影响：不改变模型，但决定早停判断与汇报指标
  • 推荐设置：分类 auc，回归 rmse

##### 参数 16：num_boost_round / n_estimators

  • 含义：迭代轮数（树的棵树总数）
  • 类型：int
  • 默认值：原生 0（无）、sklearn 接口 100
  • 取值范围：$ [1, \infty) $，常与 eta 联动（约成反比）
  • 对结果的影响：太少欠拟合；太多配合早停防过拟合
  • 推荐设置：eta=0.05 时 500~2000 + 早停

##### 参数 17：early_stopping_rounds

  • 含义：验证集指标连续 N 轮未提升则提前终止
  • 类型：int
  • 默认值：无
  • 取值范围：$ \geq 1 $
  • 对结果的影响：防过拟合并省时间；需配合 evals 传验证集
  • 推荐设置：10~50

##### 参数 18：nthread / n_jobs

  • 含义：并行训练线程数
  • 类型：int
  • 默认值：-1（全部核心）
  • 取值范围：$ [1, \text{核心数}] $ 或 -1
  • 对结果的影响：线程多训练快；小数据集并行开销可能反超
  • 推荐设置：默认 -1；共享服务器限核（如 4）

##### 参数 19：base_score

  • 含义：模型初始化预测值（常数基线/全局偏差）
  • 类型：float
  • 默认值：0.5
  • 取值范围：$ \mathbb{R} $（概率输出需 [0,1]）
  • 对结果的影响：对偏态数据影响收敛起点
  • 推荐设置：默认 0.5；偏态可设为标签均值/先验概率

##### 参数 20：num_class

  • 含义：多分类任务类别数（仅 multi:soft* 需要）
  • 类型：int
  • 默认值：无（多分类必填）
  • 取值范围：$ \geq 2 $
  • 对结果的影响：决定输出维度（每类概率）
  • 推荐设置：设为类别数

#### 实用调参顺序建议

1. 固定 eta=0.1 → 调 max_depth（3~10）与 min_child_weight（1~10）

2. 调 gamma（0~0.5）、subsample（0.6~0.9）、colsample_bytree（0.6~0.9）

3. 调 reg_alpha（0~1）、reg_lambda（1~5）

4. 最后 eta 降 0.01~0.05，num_boost_round 提 500~2000 + 早停

代码示例

import xgboost as xgb                                   # 导入 xgboost 库
from sklearn.datasets import load_breast_cancer          # 乳腺癌数据集（二分类）
from sklearn.model_selection import train_test_split     # 划分训练/测试集
from sklearn.metrics import accuracy_score               # 计算准确率

# 1. 加载数据并划分
data = load_breast_cancer()                              # 获取 569 样本 30 特征数据集
X = data.data                                           # 特征矩阵
y = data.target                                         # 标签（0/1）
X_train, X_test, y_train, y_test = train_test_split(    # 80% 训练 / 20% 测试
    X, y, test_size=0.2, random_state=42)              # 固定随机种子

# 2. 构造 DMatrix（XGBoost 高效内部数据格式）
dtrain = xgb.DMatrix(X_train, label=y_train)            # 训练数据封装
dtest  = xgb.DMatrix(X_test,  label=y_test)             # 测试数据封装

# 3. 参数设置（每个参数已在前文详解）
params = {
    'booster':          'gbtree',            # 基础模型：决策树
    'objective':        'binary:logistic',  # 二分类，输出概率
    'eval_metric':      'auc',              # 早停监控指标：AUC
    'eta':              0.1,                # 学习率：每棵树贡献 10%
    'max_depth':        6,                  # 单树最大深度 6
    'min_child_weight': 1,                  # 叶子最小权重和（默认）
    'subsample':        0.8,                # 每棵树采 80% 样本
    'colsample_bytree': 0.8,                # 每棵树采 80% 特征
    'reg_lambda':       1.0,                # L2 正则（默认 1）
    'reg_alpha':        0.1,                # L1 正则（稀疏化）
    'gamma':            0.1,                # 最小分裂增益阈值
    'nthread':          4,                  # 并行线程 4 个
    'scale_pos_weight': 1,                  # 类别均衡时保持 1
    'tree_method':      'hist',             # 直方图加速
}

# 4. 训练并启用早停
evals = [(dtrain, 'train'), (dtest, 'val')]          # 监控训练与验证
model = xgb.train(                                    # 原生 API 训练
    params=params,                                   # 参数字典
    dtrain=dtrain,                                   # 训练数据
    num_boost_round=500,                             # 最大轮数
    evals=evals,                                     # 监控列表
    early_stopping_rounds=20,                        # 连续 20 轮不提升则停
    verbose_eval=10,                                 # 每 10 轮打印
)

# 5. 预测与评估
prob = model.predict(dtest)                           # 输出测试概率
y_pred = (prob > 0.5).astype(int)                    # 阈值 0.5 转 0/1
print('AUC:', model.best_score)                       # 最优 AUC
print('准确率:', accuracy_score(y_test, y_pred))      # 准确率

# 6. 特征重要性（辅助特征筛选）
imp = model.get_score(importance_type='gain')         # 按增益统计重要性
print('Top5:', sorted(imp.items(), key=lambda x: -x[1])[:5])  # 前 5 重要特征

复杂度分析

单棵树训练的时间复杂度（exact 模式）：

  • 每层分裂需对特征排序（列块缓存）：排序 $ O(n \log n) $
  • 遍历 $ n $ 个样本找最优分裂点：$ O(n) $
  • 特征数 $ d $、深度 $ D $：单树 $ O(D \cdot d \cdot n \log n) $
  • 用 hist 直方图：样本离散到 $ H $ 个桶，遍历成本 $ O(H) $，$ H \ll n $ 时大幅加速

整体训练时间复杂度（$ T $ 棵树）：

$$ T_{\text{train}} = O\left(T \cdot D \cdot d \cdot n \log n\right) \quad \text{（exact 模式）} $$

空间复杂度：

  • 训练数据（列块压缩存储）：$ O(n \cdot d) $
  • 模型参数（所有叶权重 + 树结构）：$ O\left(\sum_{t=1}^{T} 2^{D_t}\right) \approx O(T \cdot 2^D) $
  • 直方图模式额外 $ O(d \cdot K) $（$ K $ 为桶数）

推导依据：每棵树最坏生成满二叉树节点数 $ 2^{D+1}-1 $，存储 $ O(2^D) $；排序主导时间成本故取对数项。

  • 竞赛制霸算法：Kaggle 表格类比赛长期霸榜
  • 排序推荐：点击率预估、搜索排序（LambdaMART）
  • 电信领域：客服工单分类、故障预测、用户流失预警、资源需求预测
  • 与深度学习互补：表格数据优先 XGBoost，图像/文本优先深度模型；可做 stacking 融合

协同过滤推荐（Collaborative Filtering）

类别：推荐系统 | 难度：中等

算法简介

协同过滤（Collaborative Filtering，CF）是推荐系统最经典的技术，核心思想是"物以类聚、人以群分"：不依赖物品内容或用户属性，仅通过群体用户行为矩阵（评分、点击、购买）预测"用户会不会喜欢某物品"。分三大流派：① 基于用户的协同过滤（User-based CF）：找与目标用户行为最相似的用户（邻居），推荐他们喜欢而目标用户没接触过的物品；② 基于物品的协同过滤（Item-based CF）：计算物品间相似度，推荐与用户历史喜欢的物品相似的物品（工业界更主流，可离线预计算）；③ 基于模型的协同过滤（Model-based CF）：矩阵分解（SVD、ALS）把用户-物品矩阵拆成"用户隐向量 + 物品隐向量"的低维乘积，用内积预测缺失评分。核心子问题：相似度度量（余弦、皮尔逊、Jaccard）、评分预测、隐因子维度选择。协同过滤存在数据稀疏、冷启动等痛点，实践中常与基于内容的方法、流行度兜底组合使用。

原理示意图

数学公式

① 余弦相似度（最常用）：

$$ \text{sim}(u, v) = \frac{\mathbf{r}_u \cdot \mathbf{r}_v}{\|\mathbf{r}_u\|_2 \cdot \|\mathbf{r}_v\|_2} = \frac{\sum_{i \in I_{uv}} r_{ui} \cdot r_{vi}}{\sqrt{\sum_{i} r_{ui}^2} \cdot \sqrt{\sum_{i} r_{vi}^2}} $$

符号解释：

  • $ u, v $：两个用户（或物品）
  • $ \mathbf{r}_u $：用户 $ u $ 的评分向量
  • $ \mathbf{r}_u \cdot \mathbf{r}_v $：向量点积（同方向程度）
  • $ \|\mathbf{r}_u\|_2 $：向量的 L2 模（长度），分母归一化消除绝对量级差异
  • $ I_{uv} $：$ u $ 与 $ v $ 共同评分的物品集合；值域 $ [-1, 1] $

② 皮尔逊相关系数（中心化余弦）：

$$ \text{sim}(u, v) = \frac{\sum_{i \in I_{uv}} (r_{ui} - \bar{r}_u)(r_{vi} - \bar{r}_v)}{\sqrt{\sum_{i \in I_{uv}} (r_{ui} - \bar{r}_u)^2} \cdot \sqrt{\sum_{i \in I_{uv}} (r_{vi} - \bar{r}_v)^2}} $$

符号解释：

  • $ r_{ui} $：用户 $ u $ 对物品 $ i $ 的评分；$ \bar{r}_u $：用户 $ u $ 的平均评分
  • 分子：两用户评分偏差的共变（协方差）；分母：各自标准差乘积
  • 比余弦更抗"评分习惯差异"（有人全打 4 分、有人全打 2 分）

③ User-based CF 评分预测（加权均值）：

$$ \hat{r}_{ui} = \bar{r}_u + \frac{\sum_{v \in N_k(u)} \text{sim}(u, v) \cdot (r_{vi} - \bar{r}_v)}{\sum_{v \in N_k(u)} |\text{sim}(u, v)|} $$

符号解释：

  • $ \hat{r}_{ui} $：预测用户 $ u $ 对物品 $ i $ 的评分
  • $ N_k(u) $：用户 $ u $ 的 $ k $ 个最近邻用户集合
  • $ r_{vi} - \bar{r}_v $：邻居对物品的相对评分（去除邻居个人评分习惯）
  • $ \bar{r}_u $：目标用户平均分（基线）；分母用 $ |\text{sim}| $ 保证权重非负

④ 矩阵分解（SVD 隐因子模型）：

$$ R_{m \times n} \approx P_{m \times k} \cdot Q_{n \times k}^\top, \quad \hat{r}_{ui} = \mathbf{p}_u \cdot \mathbf{q}_i $$

$$ \min_{P, Q} \sum_{(u,i) \in \text{Obs}} \left( r_{ui} - \mathbf{p}_u \mathbf{q}_i^\top \right)^2 + \lambda \left( \|\mathbf{p}_u\|^2 + \|\mathbf{q}_i\|^2 \right) $$

符号解释：

  • $ m $：用户数；$ n $：物品数；$ k $：隐因子维度（超参数）
  • $ \mathbf{p}_u $：用户 $ u $ 的 $ k $ 维隐向量；$ \mathbf{q}_i $：物品 $ i $ 的 $ k $ 维隐向量
  • $ \text{Obs} $：有评分的观测集合（只优化已知评分）
  • $ \lambda $：正则系数；ALS 迭代：固定 $ Q $ 更新 $ P $ 再固定 $ P $ 更新 $ Q $

核心要点

  • 三大流派：User-based（人以群分）、Item-based（物以类聚）、Model-based（矩阵分解）
  • 相似度是关键：余弦（方向）、皮尔逊（去中心化）、Jaccard（集合交并）
  • User-based 对用户量增长成本高（相似度矩阵 $ O(m^2) $）；Item-based 可离线预算，电商主流
  • 矩阵分解：SVD/ALS 压缩稀疏矩阵到隐因子空间，预测更稠密、泛化更强
  • 两大痛点：冷启动（新用户/新物品无行为）与稀疏性（评分矩阵 99% 缺失）
  • 评价指标：RMSE/MAE（评分精度）、Precision@K/Recall@K（Top-N 命中）
  • 工程化：与内容推荐、流行度兜底、隐式反馈（Implicit ALS）组合

技术细节与参数详解

按三类实现分别详解核心参数。

#### A. User/Item-Based CF（基于内存）关键参数

参数 1：近邻数 k

  • 含义：选取的最相似邻居数量（Top-k）
  • 类型：int
  • 默认值：常用 10~50
  • 取值范围：$ [1, \min(\text{用户数}, \text{物品数})] $
  • 对结果的影响：$ k $ 太小噪声大；$ k $ 太大引入不相似邻居、预测稀释；存在最优区间
  • 推荐设置：从 10 起，验证集网格搜 10~100

参数 2：相似度函数 similarity

  • 含义：相似度计算方式
  • 类型：字符串（pearson / cosine / jaccard / adjusted_cosine）
  • 默认值：pearson
  • 对结果的影响：皮尔逊抗评分习惯；余弦简单；Jaccard 适合 0/1 行为；调整余弦用于 Item-based
  • 推荐设置：评分数据用 pearson；隐式反馈（0/1）用 cosine/jaccard

参数 3：min_support（共同评分下限）

  • 含义：参与相似度计算的最小共同评分数
  • 类型：int
  • 默认值：常用 1~5
  • 对结果的影响：共同评分数少时相似度不可靠；过高牺牲覆盖率
  • 推荐设置：共同评分 ≥ 3

参数 4：normalize（评分归一化）

  • 含义：是否做均值中心化
  • 类型：bool
  • 默认值：True
  • 对结果的影响：减去用户均值后相似度更纯；预测时会加回基线
  • 推荐设置：一律 True

参数 5：threshold（相似度阈值）

  • 含义：低于阈值的相似度置 0 不参与预测
  • 类型：float
  • 默认值：0
  • 取值范围：$ [-1, 1] $
  • 对结果的影响：去除弱相似/负相似邻居，提升稳定性
  • 推荐设置：0~0.2

#### 模型法（SVD / ALS）参数

参数 6：n_factors / rank（隐因子维度 $ k $）

  • 含义：用户/物品隐向量维度
  • 类型：int
  • 默认值：surprise 100；Spark ALS 10
  • 取值范围：$ [1, \min(m,n)] $，常用 10~200
  • 对结果的影响：越大表达力强但过拟合；过小欠拟合
  • 推荐设置：100 起；小数据集 10~50；网格搜

参数 7：n_epochs / maxIter（迭代轮数）

  • 类型：int
  • 默认值：surprise 20；Spark ALS 10
  • 对结果的影响：太少未收敛；太多耗时且可能过拟合
  • 推荐设置：surprise 20~50；ALS 10~30

参数 8：lr_all / reg_all（SGD 学习率与正则）

  • 类型：float
  • 默认值：lr_all=0.005，reg_all=0.02
  • 取值范围：lr $ 10^{-4} \sim 10^{-1} $；reg $ 10^{-3} \sim 1 $
  • 对结果的影响：学习率大收敛快易震荡；正则大防过拟合但欠拟合
  • 推荐设置：lr 0.001~0.01；reg 0.01~0.1 网格搜

参数 9：biased（surprise SVD 偏置）

  • 类型：bool
  • 默认值：True
  • 对结果的影响：偏置项（全局均值 + 用户/物品偏置）提升精度明显
  • 推荐设置：默认 True

参数 10：regParam、alpha（Spark ALS 正则与置信度）

  • 类型：float
  • 默认值：regParam=0.1、alpha=0.01
  • 含义：正则；alpha 控制隐式反馈置信度（$ c_{ui} = 1 + \alpha \cdot r_{ui} $）
  • 推荐设置：隐式数据 alpha=10~40；显式评分 alpha=0.01

参数 11：coldStartStrategy（冷启动策略）

  • 类型：字符串（nan / drop）
  • 默认值：nan
  • 对结果的影响：drop 跳过冷启动样本，避免 NaN 报错；不解决冷启动本质
  • 推荐设置：评估用 drop；线上用热门兜底

参数 12：random_state（随机种子）

  • 类型：int
  • 默认值：无

代码示例

import numpy as np                              # 导入数值计算库

# ---------- 准备数据：用户-物品评分矩阵 ----------
# 4 用户对 4 物品的评分（0 表示未评分）
R = np.array([
    [5, 4, 0, 3],    # 用户 u1：A=5, B=4, C=0(未评分), D=3
    [4, 5, 4, 0],    # 用户 u2：A=4, B=5, C=4, D=0
    [1, 0, 2, 5],    # 用户 u3：A=1, C=2, D=5
    [0, 3, 4, 2],    # 用户 u4：B=3, C=4, D=2
], dtype=float)

# ---------- Step1: 手动实现余弦相似度 ----------
def cosine_sim_manual(a, b):
    """计算两个评分向量的余弦相似度（忽略任一侧为 0 的列）"""
    mask = (a > 0) & (b > 0)     # 双方都有评分的列掩码
    if mask.sum() == 0:          # 无共同评分
        return 0.0               # 相似度为 0
    a_, b_ = a[mask], b[mask]     # 取共同评分部分
    return (a_ @ b_) / (np.linalg.norm(a_) * np.linalg.norm(b_) + 1e-9)  # 余弦公式

n_users = R.shape[0]  # 用户数
sim_matrix = np.zeros((n_users, n_users))  # 4x4 相似度矩阵
for u in range(n_users):                  # 遍历用户 u
    for v in range(n_users):              # 遍历用户 v
        sim_matrix[u, v] = cosine_sim_manual(R[u], R[v])  # 填充相似度
print('用户相似度矩阵:')
print(sim_matrix.round(2))

# ---------- Step2: User-Based 评分预测 ----------
def predict_rating(u, i, R, sim_matrix, k=2):
    """预测用户 u 对物品 i 的评分（k 近邻加权均值）"""
    neighbors = np.argsort(sim_matrix[u])[::-1]  # 相似度降序邻居
    neighbors = neighbors[neighbors != u]          # 去掉自身
    sims, ratings = [], []                        # 收集邻居相似度与评分
    for v in neighbors:                            # 遍历邻居
        if R[v, i] > 0:                             # 邻居评过分才采用
            sims.append(sim_matrix[u, v])          # 记录相似度
            ratings.append(R[v, i])                # 记录评分
        if len(sims) >= k:                          # 凑够 k 个
            break
    if not sims:                                    # 无可用邻居
        return np.mean(R[u][R[u] > 0]) if (R[u] > 0).any() else 0.0  # 平均分兜底
    sims = np.array(sims); ratings = np.array(ratings)  # 转数组
    return (sims @ ratings) / (np.abs(sims).sum() + 1e-9)  # 加权均值

print(f"预测 r(u1, C) = {predict_rating(0, 2, R, sim_matrix):.2f}")

# ---------- Step3: 生成推荐列表 ----------
target = 0                          # 目标用户 u1
scores = {}                          # 物品→预测分字典
for item in range(R.shape[1]):       # 遍历物品
    if R[target, item] == 0:         # 只预测未评分物品
        scores[item] = predict_rating(target, item, R, sim_matrix)  # 预测
top_n = sorted(scores.items(), key=lambda x: -x[1])[:2]  # Top-2
print("为用户 u1 推荐 Top-2:", [(i + 1, round(s, 2)) for i, s in top_n])

from pyspark.ml.recommendation import ALS  # Spark 推荐算法库

als = ALS(                       # 初始化 ALS 实例
    userCol="userId",              # 用户 ID 列
    itemCol="itemId",              # 物品 ID 列

    rank=10,                       # 隐因子维度 k=10

复杂度分析

基于内存 CF：

  • User-based 相似度：两两用户计算 $ O(m^2 \cdot \bar{n}) $（$ m $ 用户数、$ \bar{n} $ 平均共同评分数），最坏 $ O(m^2 \cdot n) $
  • Item-based：预计算 $ O(n^2 \cdot \bar{m}) $（$ n $ 物品数）——物品数 << 用户数时 Item-based 更划算（电商首选）
  • 预测：每预测一个 $ O(k \cdot \bar{n}) $；空间：相似度矩阵 $ O(m^2) $ 或 $ O(n^2) $

矩阵分解（SVD/ALS）：

  • SVD（SGD）：$ O(n_{\text{epoch}} \cdot |\text{Obs}| \cdot k) $（$ |\text{Obs}| $ 非零评分数、$ k $ 隐因子数）
  • ALS：每轮每个用户求解 $ k \times k $ 线性方程组：$ O((m + n) \cdot k^3 + |\text{Obs}| \cdot k^2) $
  • 空间：$ O((m + n) \cdot k) $，远小于稠密矩阵 $ O(mn) $

推导要点：相似度矩阵时间来自"两两配对计数"；矩阵分解时间来自"内积 + 梯度更新"，正比于隐因子数 × 迭代轮数。

  • 电商推荐（Amazon 用 Item-based）："买了 A 的用户也买了 B"；物品相似度离线预算
