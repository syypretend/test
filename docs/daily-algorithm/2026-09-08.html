哈希表

类别：数据结构 | 难度：入门

一、核心原理

哈希表（Hash Table），又称散列表，是一种通过哈希函数将键（Key）映射到数组下标，从而实现 $ O(1) $ 平均时间复杂度的增删查改的数据结构。它是计算机科学中最基础、最重要的数据结构之一，广泛应用于数据库索引、缓存系统、编译器符号表、密码学等场景。

#### 1.1 基本概念

概念英文定义
哈希函数Hash Function将任意大小的键映射为固定大小整数（数组下标）的函数，记作 $ H(key) $
哈希冲突Collision不同键映射到同一数组下标的现象
同义词Synonym发生冲突的多个键互为同义词
负载因子Load Factor ($ \alpha $)$ \alpha = \frac{n}{m} $，$ n $ 为已存元素个数，$ m $ 为哈希表长度
桶/槽位Bucket / Slot哈希表中存储元素的位置
再哈希Rehashing当负载因子超过阈值时，扩容并重新哈希所有元素

#### 1.2 哈希函数构造方法

除留余数法（最常用）：

$$ H(key) = key \bmod p $$

  • $ key $：待哈希的键
  • $ p $：通常取不大于表长 $ m $ 的最大质数，且不接近 $ 2 $ 的幂
  • 为什么选质数：若 $ p $ 取 $ 2^k $，则 $ H(key) $ 仅保留 $ key $ 的低 $ k $ 位，低位分布不均匀的键会产生大量冲突

直接定址法：

$$ H(key) = a \times key + b $$

  • $ a, b $：常数，适合键分布连续的场景
  • 优点：无冲突；缺点：空间浪费大

平方取中法：

$$ H(key) = \text{mid}(key^2) $$

  • 取 $ key $ 平方后的中间若干位作为哈希值
  • 适合键分布未知的情况，中间位受键各位影响最大，分布更均匀

折叠法：将键分为若干段后叠加（移位折叠或边界折叠），适合键位数较多的情况。

#### 1.3 冲突解决策略

##### 开放定址法（Open Addressing）

所有元素直接存储在哈希表数组中，冲突时按某种规则探测下一个空位。

线性探测（Linear Probing）：

$$ H(key, i) = (H(key) + i) \bmod m, \quad i = 0, 1, 2, \ldots, m-1 $$

  • $ i $：探测次数，从 $ 0 $ 开始递增
  • $ m $：哈希表长度
  • 一次聚集（Primary Clustering）：连续被占用的位置形成"块"，越来越长，插入新元素时探测次数线性增长

二次探测（Quadratic Probing）：

$$ H(key, i) = (H(key) + c_1 \cdot i + c_2 \cdot i^2) \bmod m $$

  • $ c_1, c_2 $：常数（常取 $ c_1=0, c_2=1 $）
  • 缓解一次聚集，但可能产生二次聚集（不同初始哈希值的键可能产生相同探测序列）
  • 重要定理：当表长 $ m $ 为质数且 $ \alpha \leq 0.5 $ 时，一定能找到空位插入

双重哈希（Double Hashing）：

$$ H(key, i) = (H_1(key) + i \times H_2(key)) \bmod m $$

  • $ H_1, H_2 $：两个独立哈希函数
  • $ H_2(key) $ 必须与 $ m $ 互质，否则探测序列会很快循环
  • 常取 $ H_2(key) = 1 + (key \bmod (m-2)) $
  • 线性探测是 $ H_2(key) = 1 $ 的特例

##### 链地址法（Separate Chaining / 拉链法）

每个桶维护一个链表（或红黑树），冲突元素挂在同一链表上。

  • 插入：$ O(1) $（头插法）
  • 查找：$ O(1 + \alpha) $（平均链表长度为 $ \alpha $）
  • 删除：需先查找再删除，$ O(1 + \alpha) $
  • $ \alpha $ 可以大于 $ 1 $，表永远不会"满"

二、核心参数详解

#### 2.1 哈希表容量（Table Size / Capacity）

属性说明
含义哈希表底层数组的长度，即桶的数量
类型整数
默认值初始值通常为 16（Java HashMap）或根据预期元素数动态计算
取值范围正整数，建议为质数（开放定址法）或 $ 2 $ 的幂（工程实现）
对结果的影响容量越大，冲突概率越低，查找越快，但空间浪费越多
推荐设置预估元素数 $ n $，设 $ m \approx n / 0.75 $（保证负载因子在 $ 0.6 \sim 0.75 $）；若用开放定址法，$ m $ 取质数且 $ \alpha \leq 0.7 $

#### 2.2 负载因子阈值（Load Factor Threshold）

属性说明
含义触发扩容（Rehash）的负载因子临界值
类型浮点数
默认值0.75（Java HashMap、C++ unordered_map）
取值范围$ (0, 1) $；链地址法可 $ >1 $，但通常设为 $ 0.75 $
对结果的影响阈值越低，扩容越频繁，空间换时间；阈值越高，冲突越多，时间换空间
推荐设置通用场景 $ 0.75 $；内存敏感场景 $ 0.9 $；高性能场景 $ 0.5 \sim 0.6 $

数学解释——线性探测的期望探测次数与 $ \alpha $ 的关系：

$$ \text{成功 ASL} = \frac{1}{2}\left(1 + \frac{1}{1-\alpha}\right) $$

$$ \text{失败 ASL} = \frac{1}{2}\left(1 + \frac{1}{(1-\alpha)^2}\right) $$

当 $ \alpha = 0.75 $ 时，成功 ASL $ \approx 3 $，失败 ASL $ \approx 8.5 $；当 $ \alpha = 0.9 $ 时，成功 ASL $ \approx 5.5 $，失败 ASL $ \approx 50.5 $，性能急剧恶化。

#### 2.3 哈希函数选择（Hash Function）

属性说明
含义将键映射到 $ [0, m-1] $ 的函数
类型函数
默认值取决于键类型：整数用取模，字符串用多项式哈希
取值范围任何满足 $ H: \text{Key} \to [0, m-1] $ 的函数
对结果的影响分布越均匀，冲突越少，性能越好；差的哈希函数会导致大量聚集
推荐设置整数：$ H(k) = k \bmod p $（$ p $ 为质数）；字符串：DJB2 或 FNV-1a 哈希

#### 2.4 扩容策略（Resize / Rehash Strategy）

属性说明
含义扩容时新表容量的计算方式
类型枚举/函数
默认值翻倍（$ m' = 2m $）
取值范围$ m' > m $，通常 $ m' = 2m $ 或 $ m' = \text{next\_prime}(2m) $
对结果的影响翻倍策略分摊 $ O(1) $ 插入，但单次 Rehash 为 $ O(n+m) $；渐进式 Rehash（如 Redis）可分散开销
推荐设置通用：翻倍 + 质数调整；Redis 风格：渐进式 Rehash 避免卡顿

#### 2.5 冲突解决策略（Collision Resolution）

属性说明
含义处理哈希冲突的方法
类型枚举：链地址法 / 开放定址法（线性探测/二次探测/双重哈希）
默认值链地址法（Java、C++ STL）
取值范围任何合法的冲突解决策略
对结果的影响链地址法：$ \alpha $ 可 $ >1 $，删除简单，有额外指针开销；开放定址法：空间紧凑，缓存友好，但 $ \alpha $ 必须 $ <1 $，删除需墓碑标记
推荐设置通用：链地址法 + 链表转红黑树（Java HashMap 风格，链表 $ \geq 8 $ 转树，$ \leq 6 $ 转回链表）；高性能读多写少：开放定址法（线性探测，缓存友好）

三、数学公式与符号解释

#### 3.1 负载因子

$$ \alpha = \frac{n}{m} $$

  • $ n $：哈希表中已存储的元素个数
  • $ m $：哈希表的桶数量（数组长度）
  • $ \alpha $：负载因子，衡量哈希表"拥挤程度"的核心指标

#### 3.2 链地址法的期望查找长度

在均匀哈希假设下，链地址法的查找时间取决于链表长度。成功查找需要遍历链表找到目标元素：

$$ \text{ASL}_{\text{success}} = 1 + \frac{\alpha}{2} - \frac{\alpha}{2n} \approx 1 + \frac{\alpha}{2} $$

  • $ 1 $：检查桶位置本身
  • $ \frac{\alpha}{2} $：在链表中平均遍历的元素数（均匀分布下链表平均长度为 $ \alpha $，成功查找平均遍历一半）

失败查找需要遍历整个链表：

$$ \text{ASL}_{\text{fail}} = \alpha + e^{-\alpha} $$

  • $ \alpha $：链表平均长度
  • $ e^{-\alpha} $：桶为空的概率贡献

#### 3.3 线性探测的期望探测次数

$$ \text{ASL}_{\text{success}} = \frac{1}{2}\left(1 + \frac{1}{1-\alpha}\right) $$

$$ \text{ASL}_{\text{fail}} = \frac{1}{2}\left(1 + \frac{1}{(1-\alpha)^2}\right) $$

推导思路：设 $ A(\alpha) $ 为失败查找的期望探测次数，则 $ A(\alpha) \approx \frac{1}{1-\alpha} $（几何分布近似），成功查找的探测次数为已有元素探测次数的平均，通过积分可得上述结果。

#### 3.4 扩容的分摊复杂度

虽然单次 Rehash 为 $ O(n) $，但 $ n $ 次插入后的总扩容开销为：

$$ T_{\text{total}} = \sum_{i=0}^{\log_2 m} 2^i = 2m - 1 = O(m) $$

分摊到每次插入：

$$ T_{\text{amortized}} = \frac{O(m)}{m} = O(1) $$

四、代码实现与逐行注释

#### 4.1 Python 实现：链地址法哈希表

class HashTable:
    """链地址法哈希表实现"""
    
    def __init__(self, initial_capacity=16, load_factor_threshold=0.75):
        # capacity: 初始桶数量，默认16（2的幂，便于位运算取模）
        self.capacity = initial_capacity
        # load_factor_threshold: 负载因子阈值，超过则触发扩容
        self.load_factor_threshold = load_factor_threshold
        # size: 当前存储的元素个数
        self.size = 0
        # buckets: 桶数组，每个桶是一个列表（链表），初始为空列表
        self.buckets = [[] for _ in range(self.capacity)]
    
    def _hash(self, key):
        """哈希函数：将key映射到[0, capacity-1]"""
        # 使用Python内置hash()获取整数哈希值
        # 对capacity取模得到桶下标
        # & (capacity-1) 等价于 % capacity（当capacity为2的幂时）
        return hash(key) % self.capacity
    
    def put(self, key, value):
        """插入/更新键值对"""
        # 计算key对应的桶下标
        index = self._hash(key)
        # 获取该桶的链表
        bucket = self.buckets[index]
        # 遍历链表，检查key是否已存在
        for i, (k, v) in enumerate(bucket):
            if k == key:
                # key已存在，更新value
                bucket[i] = (key, value)
                return
        # key不存在，在链表末尾追加（也可头插法: bucket.insert(0, (key, value))）
        bucket.append((key, value))
        self.size += 1
        # 检查是否需要扩容：当前负载因子 = size / capacity
        if self.size > self.capacity * self.load_factor_threshold:
            self._resize()
    
    def get(self, key, default=None):
        """查找key对应的value"""
        index = self._hash(key)          # 计算桶下标
        bucket = self.buckets[index]     # 获取桶链表
        for k, v in bucket:              # 遍历链表
            if k == key:                 # 找到key
                return v                 # 返回对应的value
        return default                   # 未找到，返回默认值
    
    def remove(self, key):
        """删除key"""
        index = self._hash(key)
        bucket = self.buckets[index]
        for i, (k, v) in enumerate(bucket):
            if k == key:
                del bucket[i]            # 直接从链表删除（链地址法无需墓碑标记）
                self.size -= 1
                return True
        return False                     # key不存在
    
    def _resize(self):
        """扩容：容量翻倍，重新哈希所有元素"""
        old_buckets = self.buckets
        self.capacity *= 2               # 容量翻倍
        self.buckets = [[] for _ in range(self.capacity)]  # 创建新桶数组
        self.size = 0                    # 重置size，put时会重新计数
        # 遍历旧桶中所有元素，重新插入到新桶
        for bucket in old_buckets:
            for key, value in bucket:
                self.put(key, value)
    
    def __contains__(self, key):
        """支持 in 操作符"""
        return self.get(key) is not None
    
    def __len__(self):
        """支持 len() 函数"""
        return self.size

#### 4.2 Python 实现：开放定址法（线性探测）

class OpenAddressingHashTable:
    """开放定址法哈希表（线性探测）"""
    
    _DELETED = object()  # 墓碑标记（删除占位符），与None区分
    
    def __init__(self, capacity=17, load_factor_threshold=0.7):
        # capacity取质数（开放定址法要求），默认17
        self.capacity = capacity
        self.load_factor_threshold = load_factor_threshold
        self.size = 0
        # keys和values分别存储，None表示空位，_DELETED表示已删除
        self.keys = [None] * capacity
        self.values = [None] * capacity
    
    def _hash(self, key):
        return hash(key) % self.capacity  # 主哈希函数
    
    def _probe(self, key):
        """线性探测：返回key应插入或已存在的位置"""
        index = self._hash(key)           # 初始哈希位置
        first_deleted = -1                # 记录探测中遇到的第一个墓碑位置
        for i in range(self.capacity):    # 最多探测capacity次
            pos = (index + i) % self.capacity  # 线性探测：(H(k)+i) % m
            if self.keys[pos] is None:
                # 空位：key不存在
                # 返回墓碑位置（如果有）以复用空间，否则返回当前空位
                return (first_deleted if first_deleted != -1 else pos, False)
            if self.keys[pos] is self._DELETED:
                # 墓碑：记录第一个墓碑位置，继续探测
                if first_deleted == -1:
                    first_deleted = pos
                continue
            if self.keys[pos] == key:
                # 找到key：返回位置和True表示已存在
                return (pos, True)
        # 探测了整个表都没找到空位（理论上load_factor<1时不会发生）
        return (-1, False)
    
    def put(self, key, value):
        pos, exists = self._probe(key)
        if pos == -1:
            raise Exception("Hash table is full")
        if exists:
            self.values[pos] = value  # 更新已有key的value
        else:
            self.keys[pos] = key      # 插入新key
            self.values[pos] = value
            self.size += 1
            if self.size > self.capacity * self.load_factor_threshold:
                self._resize()
    
    def get(self, key, default=None):
        pos, exists = self._probe(key)
        if exists:
            return self.values[pos]
        return default
    
    def remove(self, key):
        """删除：用墓碑标记，不能直接置None（否则会打断探测链）"""
        pos, exists = self._probe(key)
        if exists:
            self.keys[pos] = self._DELETED  # 标记为墓碑
            self.values[pos] = None
            self.size -= 1
            return True
        return False
    
    def _resize(self):
        """扩容：取下一个质数作为新容量"""
        old_keys, old_values = self.keys, self.values
        self.capacity = self._next_prime(self.capacity * 2)
        self.keys = [None] * self.capacity
        self.values = [None] * self.capacity
        self.size = 0
        for i in range(len(old_keys)):
            if old_keys[i] is not None and old_keys[i] is not self._DELETED:
                self.put(old_keys[i], old_values[i])
    
    @staticmethod
    def _next_prime(n):
        """找到大于等于n的最小质数"""
        def is_prime(num):
            if num < 2:
                return False
            for i in range(2, int(num**0.5) + 1):
                if num % i == 0:
                    return False
            return True
        while not is_prime(n):
            n += 1
        return n

五、复杂度推导

操作平均情况最坏情况推导说明
查找$ O(1) $$ O(n) $平均：均匀哈希下探测次数为常数；最坏：所有键冲突到一个桶
插入$ O(1) $$ O(n) $平均：计算哈希 $ O(1) $ + 链表/探测 $ O(1+\alpha) $；最坏：全冲突
删除$ O(1) $$ O(n) $链地址法：先查找 $ O(1+\alpha) $ + 删除 $ O(1) $；开放定址法同查找
扩容—$ O(n+m) $需重新哈希所有 $ n $ 个元素到新表，但分摊为 $ O(1) $

分摊分析：采用翻倍扩容策略时，$ n $ 次插入的总开销为 $ O(n) $（每次插入 $ O(1) $ + 偶尔的 $ O(n) $ 扩容被分摊），因此分摊插入复杂度为 $ O(1) $。

Focal Loss

类别：损失函数 | 难度：中等

一、核心原理

Focal Loss 由 Lin et al. 在 2017 年论文《Focal Loss for Dense Object Detection》（RetinaNet）中提出，旨在解决类别不平衡（class imbalance）和易样本主导训练（easy negative dominance）的问题。在目标检测中，背景（负样本）数量远超前景（正样本），大量易分的背景样本贡献了绝大部分损失，淹没了难分样本（如小目标、遮挡目标）的梯度信号。

#### 1.1 从交叉熵到 Focal Loss

标准二分类交叉熵（BCE）：

$$ \text{CE}(p, y) = \begin{cases} -\log p & \text{if } y = 1 \\ -\log(1-p) & \text{if } y = 0 \end{cases} $$

为了简化表达，定义 $ p_t $：

$$ p_t = \begin{cases} p & \text{if } y = 1 \\ 1-p & \text{if } y = 0 \end{cases} $$

则交叉熵可统一写为：

$$ \text{CE}(p_t) = -\log(p_t) $$

  • $ p $：模型对正类的预测概率，$ p = \sigma(z) $（$ z $ 为 logit，$ \sigma $ 为 sigmoid）
  • $ y $：真实标签，$ 1 $ 为正类，$ 0 $ 为负类
  • $ p_t $：模型对真实类别的预测概率，$ p_t $ 越大表示预测越正确

问题：当 $ p_t $ 很大（如 $ 0.9 $）时，样本已被正确分类，但 $ \text{CE}(p_t) = -\log(0.9) \approx 0.105 $ 仍有非零损失。大量易样本累积的损失会主导总损失和梯度方向。

Focal Loss 引入调制因子：

$$ \text{FL}(p_t) = -(1 - p_t)^\gamma \log(p_t) $$

  • $ (1 - p_t)^\gamma $：调制因子（modulating factor）
  • $ \gamma $：聚焦参数（focusing parameter），$ \gamma \geq 0 $
  • 当 $ p_t \to 1 $（易样本）时，$ (1-p_t)^\gamma \to 0 $，损失被大幅降低
  • 当 $ p_t $ 较小（难样本）时，$ (1-p_t)^\gamma \to 1 $，损失几乎不受影响
  • $ \gamma = 0 $ 时，$ \text{FL} = \text{CE} $，退化为标准交叉熵

加入类别平衡权重 $ \alpha $：

$$ \text{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t) $$

  • $ \alpha_t $：类别平衡权重，$ \alpha_t = \alpha $（正类）或 $ 1-\alpha $（负类）
  • 作用：补偿正负样本数量不平衡

二、核心参数详解

#### 2.1 聚焦参数 $ \gamma $（gamma / focusing parameter）

属性说明
含义控制调制因子 $ (1-p_t)^\gamma $ 的幂次，决定对易样本的抑制力度
类型浮点数（非负）
默认值$ 2.0 $（论文推荐，RetinaNet 实验最佳）
取值范围$ [0, +\infty) $，实际常用 $ [0, 5] $
对结果的影响$ \gamma=0 $：退化为标准 CE，无聚焦效果；$ \gamma $ 越大，易样本权重越低，模型越聚焦难样本；$ \gamma $ 过大可能导致难样本过拟合
推荐设置目标检测：$ \gamma=2 $；分类任务：$ \gamma \in [1, 2] $；极端不平衡：$ \gamma=2 \sim 3 $

数学推导——$ \gamma $ 对梯度的缩放作用：

Focal Loss 对 $ p_t $ 的导数为：

$$ \frac{\partial \text{FL}}{\partial p_t} = -\gamma (1-p_t)^{\gamma-1}(-1)\log(p_t) - \frac{(1-p_t)^\gamma}{p_t} $$

$$ = \gamma(1-p_t)^{\gamma-1}\log(p_t) - \frac{(1-p_t)^\gamma}{p_t} $$

当 $ p_t \to 1 $（易样本），$ (1-p_t)^{\gamma-1} \to 0 $（$ \gamma > 1 $ 时），梯度趋近于零；当 $ p_t $ 较小（难样本），$ (1-p_t)^\gamma \to 1 $，梯度接近标准 CE 的梯度。

#### 2.2 类别平衡权重 $ \alpha $（alpha / balancing parameter）

属性说明
含义为正负类分配不同权重，补偿数量不平衡
类型浮点数
默认值$ 0.25 $（RetinaNet 论文推荐）
取值范围$ (0, 1) $；$ \alpha_t = \alpha $（正类），$ \alpha_t = 1-\alpha $（负类）
对结果的影响$ \alpha $ 越大，正类权重越高；与 $ \gamma $ 配合使用，单独调 $ \alpha $ 效果有限
推荐设置$ \gamma=2 $ 时 $ \alpha=0.25 $；若不使用 $ \gamma $（$ \gamma=0 $），$ \alpha $ 可设为类别频率的倒数

注意：论文实验表明，$ \gamma $ 增大时，$ \alpha $ 应适当减小。$ \gamma=0 $ 时最佳 $ \alpha=0.71 $；$ \gamma=2 $ 时最佳 $ \alpha=0.25 $。这是因为 $ \gamma $ 已经抑制了大量负样本，再用大的 $ \alpha $ 会过度补偿正类。

#### 2.3 损失归约方式（reduction）

属性说明
含义多个样本的 Focal Loss 如何聚合为标量
类型枚举：'none' / 'mean' / 'sum'
默认值'mean'（PyTorch FocalLoss 默认）
取值范围三种模式
对结果的影响mean：取平均，梯度尺度稳定；sum：取总和，受 batch size 影响；none：不归约，逐样本输出
推荐设置训练用 mean；分析难样本分布用 none

#### 2.4 多分类扩展参数

属性说明
含义Focal Loss 从二分类扩展到多分类的方式
类型布尔/枚举
默认值多分类：$ p_t = \text{softmax}(z)[y] $，即模型对真实类别的 softmax 概率
取值范围—
对结果的影响多分类 Focal Loss 公式：$ \text{FL} = -\alpha_t (1-p_t)^\gamma \log(p_t) $，其中 $ p_t $ 为 softmax 输出中真实类别的概率
推荐设置多分类时 $ \alpha $ 可设为各类频率的倒数，或每类一个权重向量

三、数学公式与符号解释

#### 3.1 Focal Loss 完整公式（二分类）

$$ \text{FL}(p_t) = -\alpha_t (1 - p_t)^\gamma \log(p_t) $$

符号说明：

  • $ p_t $：模型对真实类别的预测概率
  • 当 $ y=1 $（正类）：$ p_t = p = \sigma(z) $
  • 当 $ y=0 $（负类）：$ p_t = 1-p = 1-\sigma(z) $
  • $ \alpha_t $：类别平衡权重
  • 当 $ y=1 $：$ \alpha_t = \alpha $
  • 当 $ y=0 $：$ \alpha_t = 1-\alpha $
  • $ \gamma $：聚焦参数，控制易样本权重衰减速度
  • $ \log $：自然对数（$ \ln $）

#### 3.2 调制因子的作用分解

$$ \text{FL}(p_t) = \underbrace{-\log(p_t)}_{\text{标准交叉熵}} \times \underbrace{(1-p_t)^\gamma}_{\text{调制因子}} \times \underbrace{\alpha_t}_{\text{类别权重}} $$

三部分作用：

1. $ -\log(p_t) $：标准交叉熵，对错误分类施加惩罚

2. $ (1-p_t)^\gamma $：调制因子，当 $ p_t $ 大（易样本）时趋近 $ 0 $，降低权重；当 $ p_t $ 小（难样本）时趋近 $ 1 $，保持权重

3. $ \alpha_t $：类别权重，补偿正负样本数量不平衡

#### 3.3 梯度推导

Focal Loss 对 logit $ z $ 的梯度（$ p = \sigma(z) $，$ y=1 $ 正类时 $ p_t = p $）：

$$ \frac{\partial \text{FL}}{\partial z} = \frac{\partial \text{FL}}{\partial p} \cdot \frac{\partial p}{\partial z} = \frac{\partial \text{FL}}{\partial p} \cdot p(1-p) $$

其中：

$$ \frac{\partial \text{FL}}{\partial p} = -\alpha \left[ -\gamma(1-p)^{\gamma-1}\log p + \frac{(1-p)^\gamma}{p} \right] $$

$$ = \alpha \left[ \gamma(1-p)^{\gamma-1}\log p - \frac{(1-p)^\gamma}{p} \right] $$

最终梯度：

$$ \frac{\partial \text{FL}}{\partial z} = \alpha \cdot p(1-p) \left[ \gamma(1-p)^{\gamma-1}\log p - \frac{(1-p)^\gamma}{p} \right] $$

对比标准 CE 的梯度 $ -\alpha \cdot p(1-p) \cdot \frac{1}{p} = -\alpha(1-p) $，Focal Loss 的梯度多了 $ (1-p)^\gamma $ 因子，在 $ p \to 1 $ 时梯度被大幅抑制。

#### 3.4 与 OHEM 的对比

对比项OHEM (Online Hard Example Mining)Focal Loss
核心思想选取损失最大的 top-k 样本反向传播连续加权所有样本，易样本权重低
硬/软硬选择（离散阈值）软加权（连续函数）
超参数k（选取数量）$ \gamma, \alpha $
计算开销需排序选择直接加权，无需额外操作
效果论文实验中 Focal Loss 略优于 OHEM—

#### 4.1 PyTorch 实现：二分类 Focal Loss

import torch
import torch.nn as nn
import torch.nn.functional as F

class BinaryFocalLoss(nn.Module):
    """二分类 Focal Loss 实现"""
    
    def __init__(self, alpha=0.25, gamma=2.0, reduction='mean'):
        super().__init__()
        # alpha: 正类权重，默认0.25（RetinaNet推荐）
        self.alpha = alpha
        # gamma: 聚焦参数，默认2.0
        self.gamma = gamma
        # reduction: 损失归约方式
        self.reduction = reduction
    
    def forward(self, logits, targets):
        """
        Args:
            logits:  模型输出logit，shape [N]或[N,1]，未经sigmoid
            targets: 真实标签，shape [N]，值为0或1
        Returns:
            focal loss 标量
        """
        # 确保形状一致
        logits = logits.view(-1)          # 展平为 [N]
        targets = targets.float()         # 转为float类型
        
        # 计算sigmoid概率 p = σ(z)
        p = torch.sigmoid(logits)          # p ∈ (0,1)，正类预测概率
        
        # 计算 p_t：模型对真实类别的预测概率
        # y=1时 p_t=p，y=0时 p_t=1-p
        p_t = p * targets + (1 - p) * (1 - targets)
        
        # 计算 α_t：类别平衡权重
        # y=1时 α_t=α，y=0时 α_t=1-α
        alpha_t = self.alpha * targets + (1 - self.alpha) * (1 - targets)
        
        # 标准交叉熵损失：CE = -log(p_t)
        ce_loss = F.binary_cross_entropy_with_logits(
            logits, targets, reduction='none'
        )  # 逐样本计算，不做归约
        
        # 调制因子：(1 - p_t)^gamma
        modulating_factor = (1 - p_t) ** self.gamma
        
        # Focal Loss = α_t * (1-p_t)^γ * CE
        focal_loss = alpha_t * modulating_factor * ce_loss
        
        # 按指定方式归约
        if self.reduction == 'mean':
            return focal_loss.mean()       # 所有样本取平均
        elif self.reduction == 'sum':
            return focal_loss.sum()        # 所有样本取总和
        else:
            return focal_loss              # 逐样本返回，不归约

#### 4.2 PyTorch 实现：多分类 Focal Loss

class FocalLoss(nn.Module):
    """多分类 Focal Loss 实现"""
    
    def __init__(self, alpha=None, gamma=2.0, reduction='mean'):
        super().__init__()
        # alpha: 各类别权重向量，shape [num_classes]
        #   None表示不加类别权重（均匀权重）
        #   也可传入list/tensor，如 [0.1, 0.4, 0.5] 为3类权重
        self.alpha = alpha
        self.gamma = gamma
        self.reduction = reduction
    
    def forward(self, logits, targets):
        """
        Args:
            logits:  [N, C] 未经过softmax的模型输出
            targets: [N] 类别索引，值为0到C-1
        Returns:
            focal loss 标量
        """
        # 计算softmax概率：p_c = exp(z_c) / Σ exp(z_i)
        log_probs = F.log_softmax(logits, dim=1)  # log(p)，数值稳定
        probs = torch.exp(log_probs)               # p = softmax概率
        
        # 获取每个样本对真实类别的概率 p_t
        # targets shape [N] → [N,1] → one_hot → 取对应位置
        targets = targets.view(-1, 1)             # [N,1]
        pt = probs.gather(1, targets).squeeze(1)  # [N]，每个样本的p_t
        log_pt = log_probs.gather(1, targets).squeeze(1)  # log(p_t)
        
        # 调制因子 (1-p_t)^γ
        modulating_factor = (1 - pt) ** self.gamma
        
        # 类别权重
        if self.alpha is not None:
            # alpha转换为tensor并放到正确设备
            if isinstance(self.alpha, (list, tuple)):
                alpha = torch.tensor(self.alpha, device=logits.device)
            else:
                alpha = self.alpha
            # 根据targets获取每个样本对应的alpha值
            alpha_t = alpha[targets.squeeze(1)]  # [N]
        else:
            alpha_t = 1.0  # 不加类别权重
        
        # Focal Loss = -α_t * (1-p_t)^γ * log(p_t)
        focal_loss = -alpha_t * modulating_factor * log_pt
        
        if self.reduction == 'mean':
            return focal_loss.mean()
        elif self.reduction == 'sum':
            return focal_loss.sum()
        else:
            return focal_loss

线性注意力 Transformer

类别：前沿架构 | 难度：困难

一、核心原理

标准 Transformer 的自注意力机制计算复杂度为 $ O(L^2 d) $，其中 $ L $ 为序列长度，$ d $ 为特征维度。当 $ L $ 很大（如长文本、高分辨率图像）时，计算和显存开销急剧增长。线性注意力（Linear Attention）通过核化技巧（kernel trick）将注意力复杂度从 $ O(L^2 d) $ 降至 $ O(L d^2) $，在 $ d \ll L $ 时显著加速。

#### 1.1 标准 Self-Attention 回顾

标准自注意力的计算公式：

$$ \text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V $$

展开为：

$$ \text{Attention}(Q, K, V) = \sum_{j=1}^{L} \frac{\exp(q_i \cdot k_j / \sqrt{d_k})}{\sum_{j'=1}^{L} \exp(q_i \cdot k_{j'} / \sqrt{d_k})} v_j $$

  • $ Q \in \mathbb{R}^{L \times d} $：Query 矩阵
  • $ K \in \mathbb{R}^{L \times d} $：Key 矩阵
  • $ V \in \mathbb{R}^{L \times d} $：Value 矩阵
  • $ L $：序列长度
  • $ d $：特征维度（$ d_k $ 为 Key 维度）
  • 复杂度瓶颈：$ QK^T $ 的计算为 $ O(L^2 d) $，且需存储 $ L \times L $ 的注意力矩阵

#### 1.2 核化技巧：将 Softmax 分解

线性注意力的核心思想是：将 softmax 注意力中的 $ \exp(q \cdot k) $ 替换为可分解的核函数 $ \phi(q) \cdot \phi(k) $。

设存在特征映射 $ \phi: \mathbb{R}^d \to \mathbb{R}^r $，使得注意力可以写成：

$$ \text{Attn}_i = \frac{\sum_{j=1}^{L} \phi(q_i) \cdot \phi(k_j) \cdot v_j}{\sum_{j=1}^{L} \phi(q_i) \cdot \phi(k_j)} $$

利用矩阵乘法的结合律，改变计算顺序：

标准注意力（先算 $ QK^T $，再乘 $ V $）：

$$ \text{Attn} = \text{softmax}(QK^T) V = \underbrace{(QK^T)}_{O(L^2 d)} V $$

线性注意力（先算 $ K^T V $，再乘 $ Q $）：

$$ \text{Attn} = \frac{\phi(Q) \left( \phi(K)^T V \right)}{\phi(Q) \phi(K)^T \mathbf{1}} $$

  • $ \phi(K)^T V $：形状为 $ r \times d $，计算复杂度 $ O(L r d) $
  • $ \phi(Q) (\phi(K)^T V) $：形状为 $ L \times d $，计算复杂度 $ O(L r d) $
  • 总复杂度：$ O(L r d) $，当 $ r \approx d $ 时为 $ O(L d^2) $
  • 当 $ L \gg d $ 时，$ O(L d^2) \ll O(L^2 d) $

#### 1.3 特征映射 $ \phi $ 的选择

##### 方案一：ELU + 1（Linear Transformer, Katharopoulos et al. 2020）

$$ \phi(x) = \text{ELU}(x) + 1 $$

其中 $ \text{ELU}(x) = \begin{cases} x & x \geq 0 \\ e^x - 1 & x < 0 \end{cases} $

  • 优点：简单高效，$ \phi(x) \geq 0 $ 保证非负性
  • 缺点：逼近 softmax 的精度有限

##### 方案二：随机特征（Performer / FAVOR+，Choromanski et al. 2020）

使用随机特征方法近似 softmax 核：

$$ \phi(x) = \frac{1}{\sqrt{r}} \exp(\Omega x - \frac{\|x\|^2}{2}) $$

  • $ \Omega \in \mathbb{R}^{r \times d} $：随机投影矩阵，每行从高斯分布 $ \mathcal{N}(0, I_d) $ 采样
  • $ r $：随机特征维度，$ r $ 越大近似越精确
  • 理论保证：当 $ r = O(\epsilon^{-2} \log(1/\delta)) $ 时，近似误差以概率 $ 1-\delta $ 不超过 $ \epsilon $

##### 方案三：ReLU（简化版）

$$ \phi(x) = \text{ReLU}(x) $$

  • 最简单但效果一般，因为 ReLU 可能输出全零

#### 1.4 因果（Causal）线性注意力

在自回归生成中，位置 $ i $ 只能关注位置 $ 1 \sim i $。标准 softmax 注意力通过 mask 实现，但线性注意力需要递推计算。

定义累积矩阵 $ S_t = \sum_{j=1}^{t} \phi(k_j) v_j^T $，则：

$$ y_t = \frac{\phi(q_t)^T S_t}{\phi(q_t)^T z_t} $$

其中 $ z_t = \sum_{j=1}^{t} \phi(k_j) $ 为累积分母。

递推关系：

$$ S_t = S_{t-1} + \phi(k_t) v_t^T $$

$$ z_t = z_{t-1} + \phi(k_t) $$

  • 每步仅需 $ O(d^2) $ 更新 $ S_t $，无需存储 $ L \times L $ 矩阵
  • 总复杂度：$ O(L d^2) $
  • 这使得线性注意力可以像 RNN 一样增量推理，极大节省 KV Cache 显存

二、核心参数详解

#### 2.1 特征映射函数 $ \phi $（feature_map）

属性说明
含义将 Query/Key 映射到非负特征空间的函数，替代 softmax 中的 $ \exp $
类型函数/模块
默认值elu + 1（Katharopoulos et al. 2020）

#### 2.2 随机特征维度 $ r $（num_random_features）

属性说明
含义Performer/FAVOR+ 中随机投影矩阵 $ \Omega $ 的行数，即特征映射的输出维度
类型整数
默认值$ 256 $（Performer 论文）
取值范围$ [1, +\infty) $，通常 $ [64, 1024] $
对结果的影响$ r $ 越大，对 softmax 核的近似越精确，但计算开销增加（$ O(Lrd) $）；$ r $ 太小会导致近似误差大

理论误差上界：使用正交随机特征（ORF）时，近似误差：

$$ \epsilon = O\left(\frac{1}{\sqrt{r}}\right) $$

即 $ r $ 增加 4 倍，误差减半。

#### 2.3 是否因果（causal / is_causal）

含义是否使用因果 mask（自回归生成场景）
类型布尔值
默认值False（双向注意力，如 BERT）
取值范围True / False
对结果的影响False：可并行计算 $ \phi(K)^T V $，速度最快；True：需递推计算累积矩阵 $ S_t $，但推理时 KV Cache 为 $ O(d^2) $
推荐设置编码器（BERT 类）：False；解码器（GPT 类）：True

#### 2.4 头数 $ h $（num_heads）

属性说明
含义多头注意力中的头数
类型整数
默认值$ 8 $（与标准 Transformer 一致）
取值范围$ [1, +\infty) $，通常 $ [4, 32] $
对结果的影响每头维度 $ d_h = d/h $；线性注意力复杂度为 $ O(L h d_h^2) = O(L d^2 / h) $，头数越多反而越快
推荐设置短序列：$ h=8 $；长序列：$ h=16\sim32 $（更多头可降低 $ d_h $，减少 $ O(d_h^2) $ 开销）

#### 2.5 归一化方式（normalization）

属性说明
含义注意力分数的归一化分母
类型枚举
默认值$ \phi(q) \cdot \sum_j \phi(k_j) $（分母为 $ \phi(q) $ 与 $ \phi(K) $ 的行和内积）
取值范围不归一化 / 行和归一化
对结果的影响归一化保证输出尺度稳定；不归一化可能导致输出值过大
推荐设置始终使用归一化；某些实现中省略归一化以加速（如线性 Transformer 原文）

三、数学公式与符号解释

#### 3.1 标准注意力

$$ \text{Attn}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right) V = D^{-1} A V $$

  • $ A = \exp(QK^T / \sqrt{d_k}) \in \mathbb{R}^{L \times L} $：未归一化的注意力矩阵
  • $ D = \text{diag}(A \mathbf{1}) $：行和构成的对角矩阵
  • $ QK^T $：$ L \times L $ 矩阵乘法，复杂度 $ O(L^2 d) $

#### 3.2 线性注意力

$$ \text{LinAttn}(Q, K, V) = \frac{\phi(Q)(\phi(K)^T V)}{\phi(Q)(\phi(K)^T \mathbf{1})} $$

符号说明：

  • $ \phi(Q) \in \mathbb{R}^{L \times r} $：Query 经特征映射后的矩阵
  • $ \phi(K) \in \mathbb{R}^{L \times r} $：Key 经特征映射后的矩阵
  • $ \phi(K)^T V \in \mathbb{R}^{r \times d} $：先算此矩阵积，复杂度 $ O(Lrd) $
  • $ \phi(Q) (\phi(K)^T V) \in \mathbb{R}^{L \times d} $：再乘 Query，复杂度 $ O(Lrd) $
  • $ \phi(K)^T \mathbf{1} \in \mathbb{R}^{r} $：分母中的行和
  • $ \mathbf{1} \in \mathbb{R}^{L} $：全 $ 1 $ 向量
  • $ r $：特征映射输出维度

#### 3.3 因果线性注意力的递推

$$ S_t = S_{t-1} + \phi(k_t) v_t^T \in \mathbb{R}^{r \times d} $$

$$ z_t = z_{t-1} + \phi(k_t) \in \mathbb{R}^{r} $$

$$ y_t = \frac{\phi(q_t)^T S_t}{\phi(q_t)^T z_t} \in \mathbb{R}^{d} $$

  • $ S_t $：累积矩阵，存储到时刻 $ t $ 为止的所有 $ \phi(k) v^T $ 之和
  • $ z_t $：累积分母向量
  • $ S_0 = \mathbf{0}_{r \times d} $, $ z_0 = \mathbf{0}_r $：初始为零
  • 每步更新复杂度：$ O(rd + r) = O(rd) $
  • 总复杂度：$ O(Lrd) $

#### 3.4 Performer 随机特征近似

$$ \phi(x) = \frac{h(x)}{\sqrt{r}}, \quad h(x) = \exp(\Omega x - \frac{\|x\|^2}{2}) $$

  • $ \Omega \in \mathbb{R}^{r \times d} $：随机高斯矩阵
  • $ \|x\|^2 $：$ x $ 的 $ L_2 $ 范数平方
  • 近似保证：$ \mathbb{E}[\phi(x)^T \phi(y)] = \exp(x^T y) $，即期望上恢复 softmax 核

#### 4.1 PyTorch 实现：线性注意力（非因果）

import torch
import torch.nn as nn
import torch.nn.functional as F

def elu_feature_map(x):
    """ELU+1 特征映射：φ(x) = ELU(x) + 1 ≥ 0"""
    # ELU(x) = x if x≥0 else e^x - 1
    # +1 保证非负性：φ(x) = ELU(x) + 1 ≥ 0
    return F.elu(x) + 1

class LinearAttention(nn.Module):
    """线性注意力层（非因果，适用于编码器）"""
    
    def __init__(self, dim, num_heads=8, feature_map='elu'):
        super().__init__()
        # dim: 输入特征维度 d
        # num_heads: 注意力头数 h
        # feature_map: 特征映射类型
        self.num_heads = num_heads
        self.head_dim = dim // num_heads  # 每头维度 d_h = d/h
        self.scale = self.head_dim ** -0.5  # 缩放因子 1/√d_h
        
        # Q/K/V 投影：将输入映射到 Q、K、V
        # 输出维度为 3*dim（包含Q、K、V各一个dim）
        self.qkv = nn.Linear(dim, dim * 3, bias=False)
        # 输出投影：将多头输出合并回 dim
        self.proj = nn.Linear(dim, dim)
        
        # 选择特征映射函数
        if feature_map == 'elu':
            self.feature_map = elu_feature_map
        elif feature_map == 'relu':
            self.feature_map = F.relu
        else:
            self.feature_map = elu_feature_map  # 默认 ELU+1
    
    def forward(self, x):
        """
        Args:
            x: [B, L, d] 输入序列
        Returns:
            [B, L, d] 输出序列
        """
        B, L, d = x.shape
        
        # 1. 计算 Q, K, V
        qkv = self.qkv(x)  # [B, L, 3*d]
        qkv = qkv.reshape(B, L, 3, self.num_heads, self.head_dim)
        q, k, v = qkv.unbind(dim=2)  # 各 [B, L, h, d_h]
        
        # 转置为 [B, h, L, d_h]
        q = q.transpose(1, 2)  # [B, h, L, d_h]
        k = k.transpose(1, 2)  # [B, h, L, d_h]
        v = v.transpose(1, 2)  # [B, h, L, d_h]
        
        # 2. 应用特征映射 φ
        q = self.feature_map(q)  # φ(Q)，[B, h, L, d_h]，值非负
        k = self.feature_map(k)  # φ(K)，[B, h, L, d_h]，值非负
        
        # 3. 线性注意力核心计算
        # 分子：φ(Q) * (φ(K)^T V)
        # 先算 φ(K)^T V：[B, h, d_h, d_h]
        kv = torch.einsum('bhld,bhle->bhde', k, v)  # φ(K)^T V，O(L*d_h²)
        
        # 再算 φ(Q) * kv：[B, h, L, d_h]
        numerator = torch.einsum('bhld,bhde->bhle', q, kv)  # O(L*d_h²)
        
        # 分母：φ(Q) * (φ(K)^T 1)
        k_sum = k.sum(dim=2, keepdim=True)  # Σ φ(k_j)，[B, h, 1, d_h]
        denominator = torch.einsum('bhld,bhmd->bhlm', q, k_sum)  # φ(q_i)·Σφ(k_j)
        denominator = denominator.squeeze(-1) + 1e-6  # 加epsilon防除零
        
        # 4. 归一化
        out = numerator / denominator.unsqueeze(-1)  # [B, h, L, d_h]
        
        # 5. 合并多头，输出投影
        out = out.transpose(1, 2).reshape(B, L, d)  # [B, L, d]
        out = self.proj(out)  # 线性投影
        
        return out

class CausalLinearAttention(nn.Module):
    """因果线性注意力（递推实现，适用于自回归生成）"""
    
    def __init__(self, dim, num_heads=8, feature_map='elu'):
        super().__init__()
        self.num_heads = num_heads
        self.head_dim = dim // num_heads
        self.qkv = nn.Linear(dim, dim * 3, bias=False)
        self.proj = nn.Linear(dim, dim)
        
        if feature_map == 'elu':
            self.feature_map = elu_feature_map
        else:
            self.feature_map = F.relu
    
    def forward(self, x):
        """
        递推计算因果线性注意力
        Args:
            x: [B, L, d]
        Returns:
            [B, L, d]
        """
        B, L, d = x.shape
        h, dh = self.num_heads, self.head_dim
        
        qkv = self.qkv(x).reshape(B, L, 3, h, dh)
        q, k, v = qkv.unbind(dim=2)  # 各 [B, L, h, d_h]
        
        # 应用特征映射
        q = self.feature_map(q)  # [B, L, h, d_h]
        k = self.feature_map(k)  # [B, L, h, d_h]
        
        outputs = []
        # 初始化累积矩阵 S 和分母 z
        # S: [B, h, d_h, d_h] — 累积 Σ φ(k_j) v_j^T
        S = torch.zeros(B, h, dh, dh, device=x.device)
        # z: [B, h, d_h] — 累积 Σ φ(k_j)
        z = torch.zeros(B, h, dh, device=x.device)
        
        # 逐时间步递推
        for t in range(L):
            qt = q[:, t]  # [B, h, d_h]
            kt = k[:, t]  # [B, h, d_h]
            vt = v[:, t]  # [B, h, d_h]
            
            # 更新累积矩阵：S_t = S_{t-1} + φ(k_t) v_t^T
            # φ(k_t) v_t^T: [B, h, d_h, 1] × [B, h, 1, d_h] → [B, h, d_h, d_h]
            S = S + torch.einsum('bhd,bhe->bhde', kt, vt)
            
            # 更新累积分母：z_t = z_{t-1} + φ(k_t)
            z = z + kt  # [B, h, d_h]
            
            # 计算输出：y_t = φ(q_t)^T S_t / (φ(q_t)^T z_t)
            # 分子：φ(q_t)^T S_t = [B, h, d_h] × [B, h, d_h, d_h] → [B, h, d_h]
            numerator = torch.einsum('bhd,bhde->bhe', qt, S)
            # 分母：φ(q_t)^T z_t = [B, h, d_h] · [B, h, d_h] → [B, h]
            denominator = torch.einsum('bhd,bhd->bh', qt, z) + 1e-6  # 防除零
            # 归一化
            yt = numerator / denominator.unsqueeze(-1)  # [B, h, d_h]
            
            outputs.append(yt)
        
        # 拼接所有时间步输出
        out = torch.stack(outputs, dim=1)  # [B, L, h, d_h]
        out = out.reshape(B, L, d)         # 合并多头
        out = self.proj(out)                # 输出投影
        
        return out

复杂度推导（非因果线性注意力）：

1. 计算 $ \phi(K)^T V $：矩阵乘法 $ r \times L $ 乘 $ L \times d $ → $ O(L r d) $

2. 计算 $ \phi(Q) (\phi(K)^T V) $：矩阵乘法 $ L \times r $ 乘 $ r \times d $ → $ O(L r d) $

3. 计算分母 $ \phi(K)^T \mathbf{1} $：$ O(L r) $

4. 总时间复杂度：$ O(L r d) $，当 $ r = d $ 时为 $ O(L d^2) $

交叉点：当 $ L > d $ 时，$ O(L d^2) < O(L^2 d) $，线性注意力更快。典型 Transformer 中 $ d=512 $，因此当 $ L > 512 $ 时线性注意力有优势。
