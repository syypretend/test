A* 搜索算法

类别：图算法 | 难度：中等

算法简介

A（A Star）搜索算法是一种启发式搜索算法，广泛用于路径规划、游戏寻路、机器人导航等场景。它综合了 Dijkstra 算法（保证最短路径）和贪心最佳优先搜索（利用启发信息加速）的优点：每个节点 n 都有一个评价函数 $ f(n) = g(n) + h(n) $，其中 $ g(n) $ 是从起点到当前节点 n 的实际已花费代价，$ h(n) $ 是从当前节点 n 到目标节点的启发式估计代价。算法每次从开放集合（open_set）中取出 $ f $ 值最小的节点进行扩展，直到目标节点被取出（或 open_set 为空）。只要启发式函数满足可采纳性（即 $ h(n) $ 永远不会高估真实代价），A 就保证能找到最优路径；启发式越接近真实代价，扩展的节点越少，搜索越快。A* 的本质是"现实代价 + 未来预测"的双重评估，比纯 BFS/Dijkstra 更具方向性，比贪心搜索更稳健。

原理示意图

数学公式

A* 的核心是评价函数，它把"已走的路"和"估计还要走的路"加起来作为节点优先级：

$$ f(n) = g(n) + h(n) $$

变量解释：

  • $ n $：当前待评估的节点
  • $ f(n) $：节点 n 的综合代价值（越小优先级越高，优先被扩展）
  • $ g(n) $：从起点到节点 n 的实际最小代价（每一步真实消耗累加）
  • $ h(n) $：从节点 n 到目标节点的启发式估计代价，是算法"聪明"的来源

为了让 A* 保证找到最优解，启发式必须满足两个性质：

可采纳性（Admissible）：$ h(n) $ 永远不超过真实最短代价，即 $ h(n) \le h^*(n) $（$ h^* $ 为真实最小代价），这样 A* 是完备且最优的。

一致性 / 单调性（Consistent）：对任意节点 n 及其后继 n'，满足三角不等式：

$$ h(n) \le c(n, n') + h(n') $$

变量解释：

  • $ c(n, n') $：从 n 移动到相邻节点 n' 的实际单步代价
  • 一致性比可采纳性更强：满足一致性的 $ h $ 必然可采纳，且保证每个节点第一次被扩展时即已拿到最优 $ g $ 值

常见启发式函数：

启发式公式适用场景
曼哈顿距离$ h = |x_1 - x_2| + |y_1 - y_2| $只允许上下左右移动的网格
欧几里得距离$ h = \sqrt{(x_1-x_2)^2 + (y_1-y_2)^2} $允许任意方向移动（可穿越）
切比雪夫距离$ h = \max(|x_1-x_2|,\ |y_1-y_2|) $允许 8 方向移动
对角线距离$ h = D_1 \cdot \Delta x + D_2 \cdot \Delta y $含斜向代价的 8 方向移动

核心要点

  • A* = Dijkstra（保证最优）+ 启发式搜索（提高效率）的结合体，通过 $ f = g + h $ 决定扩展顺序
  • 用优先队列维护 open_set，每次弹出 $ f $ 最小的节点；用 closed_set 记录已最优扩展的节点防止重复
  • 启发式 $ h $ 的可采纳性决定最优性；$ h=0 $ 时 A* 退化为 Dijkstra，$ h $ 越接近真实值搜索越快
  • 启发式函数满足一致性（三角不等式）时每个节点只需扩展一次，性能最好
  • 用 parent 指针回溯即可得到最终路径；障碍物不可通行时按"跳过"处理
  • 实际工程中常用权重 A*（$ f = g + \varepsilon h $，$ \varepsilon>1 $）换取速度、牺牲最优性

技术细节与参数详解

#### 参数 1：启发式函数 h(n)

  • 含义：当前节点到目标点的估计剩余代价，决定搜索"方向感"
  • 类型：函数（曼哈顿 / 欧几里得 / 切比雪夫 / 自定义）
  • 默认值：网格场景通常默认曼哈顿距离
  • 取值范围：$ 0 \le h(n) \le h^*(n) $（可采纳）；$ h=0 $ 退化为 Dijkstra
  • 对结果的影响：$ h $ 过小 → 扩展节点多、慢但保证最优；$ h $ 过大（>真实值）→ 快但不保证最优
  • 推荐设置：4 方向移动用曼哈顿，8 方向用对角线，连续空间用欧几里得；无法确定时宁可用偏小的估计

#### 参数 2：g_score（起点到当前节点的实际代价）

  • 含义：从起点沿路径累加的真实代价
  • 类型：float 或 int（由单步代价类型决定）
  • 默认值：起点为 0，其余节点初始化为 $ +\infty $
  • 对结果的影响：值越大优先级越低；算法会在发现更短路径时更新 open 中节点的 g 值
  • 推荐设置：要求单步代价非负；若存在负边请改用 Bellman-Ford 等算法

#### 参数 3：open_set（开放集）

  • 含义：存放待扩展节点的优先队列（Priority Queue），按 f 值排序
  • 类型：二叉堆 / 斐波那契堆
  • 默认实现：Python 常用 heapq（小顶堆），插入/弹出均为 $ O(\log N) $
  • 对结果的影响：堆结构决定弹出最小 f 节点的效率，直接影响整体复杂度
  • 推荐设置：节点极多时可选用斐波那契堆降低弹出成本

#### 参数 4：closed_set（闭集）

  • 含义：记录已最优方式扩展过的节点，防止重复扩展
  • 类型：set / 哈希表，查询 O(1)
  • 默认实现：哈希集合
  • 对结果的影响：配合一致性启发式时节点入 closed 即为最优；若启发式不一致可能出现"closed 后再发现更优"，需额外校验
  • 推荐设置：与一致性启发式配套使用最安全

#### 参数 5：parent 指针（回溯链）

  • 含义：记录每个节点最优前驱，用于最终重建路径
  • 类型：字典 {node: parent_node}
  • 默认值：起点 parent 为 None
  • 对结果的影响：路径质量与记录时机相关——仅当 g 值被更优路径更新时才改写 parent
  • 推荐设置：目标节点出 closed 后沿 parent 链反推到起点即得路径

#### 参数 6：tie-breaking（同 f 值打破平局）

  • 含义：多个节点 f 值相同时的取舍策略
  • 常用策略：f 相同选 h 更小的（靠近目标）、或选 g 更大的（已走较远）、或按插入顺序
  • 对结果的影响：处理不当会导致路径绕路不美观，甚至影响性能
  • 推荐设置：f 相同时选 h 更小的节点（更有方向性）

#### 参数 7：权重系数 ε（weighted A*）

  • 含义：$ f = g + \varepsilon h $ 中的 $ \varepsilon $，工程化扩展参数
  • 默认值：1.0（标准 A*，保证最优）
  • 取值范围：通常 $ 1 \le \varepsilon \le 10 $
  • 对结果的影响：$ \varepsilon $ 越大越激进、越快但路径越差；用于实时场景做时间-质量折中
  • 推荐设置：要求最优解用 1.0；限时寻路可先用 $ \varepsilon=2 $ 起步并动态调低

代码示例

import heapq  # 优先队列库，用于维护 open_set

def heuristic(a, b):
    """曼哈顿距离启发式函数：4 方向移动网格的常用启发"""
    # 计算两个坐标的横向与纵向差，累加为估计代价
    return abs(a[0] - b[0]) + abs(a[1] - b[1])

def a_star(grid, start, goal):
    """A* 寻路主函数：返回从 start 到 goal 的路径（坐标列表）"""
    rows, cols = len(grid), len(grid[0])  # 网格行数与列数
    # open_set 为优先队列，元素为 (f, g, x, y, path)
    # f 为综合代价、g 为实际代价、path 记录走过的路径，直接随堆存储便于回溯
    open_set = [(0, 0, start[0], start[1], [start])]
    # g_score 字典：记录每个坐标的最优实际代价
    g_score = {start: 0}
    # closed_set 集合：记录已最优扩展的节点
    closed_set = set()

    while open_set:  # 只要开放集合还有节点就继续搜索
        f_cur, g_cur, x, y, path = heapq.heappop(open_set)  # 弹出 f 最小的节点
        if (x, y) in closed_set:  # 已被最优扩展则跳过（一致性保证下）
            continue
        if (x, y) == goal:        # 到达目标：直接返回路径
            return path
        closed_set.add((x, y))    # 标记该节点为已扩展
        # 遍历四个方向的相邻格子（上下左右）
        for dx, dy in ((-1, 0), (1, 0), (0, -1), (0, 1)):
            nx, ny = x + dx, y + dy  # 相邻节点坐标
            # 越界或障碍物则跳过（grid 中 0 表示空地，1 表示障碍）
            if not (0 <= nx < rows and 0 <= ny < cols and grid[nx][ny] == 0):
                continue
            tentative_g = g_cur + 1          # 假设单步代价为 1
            if tentative_g < g_score.get((nx, ny), float('inf')):
                # 找到更优的 g 时更新并加入 open_set
                g_score[(nx, ny)] = tentative_g
                h = heuristic((nx, ny), goal)        # 计算启发式 h
                f = tentative_g + h                # 综合代价 f = g + h
                heapq.heappush(open_set, (f, tentative_g, nx, ny, path + [(nx, ny)]))
    return None  # 无路可达时返回 None

说明：示例采用"路径随堆存储"便于直观理解；工程上更常用 parent 指针字典以避免路径复制，节省内存。

复杂度分析

时间复杂度：

  • 最坏情况（启发式很差/图很大且无目标可达）：$ O(b^d) $，其中 b 为平均分支因子、d 为最优解的深度。推导：搜索树中每个节点扩展其所有邻居，节点总数上界为 $ b^d $ 量级；每个节点的插入/弹出在二叉堆上为 $ O(\log N) $。
  • 实际经验：启发式 $ h $ 越接近 $ h^* $，扩展节点数越接近 $ d $，实践中 A 远快于 Dijkstra（Dijkstra 需 $ O((V+E)\log V) $，A 只探索"朝向目标"的子图）。

空间复杂度：$ O(b^d) $（最坏）。open_set、closed_set、g_score 各存储一层搜索树，节点总数决定内存；可通过迭代加深 A（IDA）将空间降为 $ O(d) $。

应用场景

  • 游戏与 RTS 中 NPC 寻路、自动寻路系统
  • 机器人 / 无人机路径规划与避障
  • 地图导航软件（与路网 + 启发式结合）
  • 迷宫求解、拼图问题（如 15 数字）的最优解搜索
  • 自动驾驶局部路径规划与图搜索基础

对比学习 SimCLR

类别：自监督学习 | 难度：困难

算法简介

SimCLR（Simple Framework for Contrastive Learning of Visual Representations）是 Google Brain 团队 2020 年提出的自监督视觉表征学习框架，论文标题即"简单"——它不依赖任何手工设计的负样本挖掘、记忆库或动量编码器，仅凭"数据增强 + 对比损失"两板斧就达到了媲美监督学习的效果。核心流程：对同一张图片做两次随机的强数据增强，得到两个"正视图"（positive views）$ x_i $ 与 $ \tilde{x}_j $，其余批次内样本作为"负样本"（negatives）；两个视图分别经过共享的编码器（如 ResNet）和投影头（MLP，projection head）映射为嵌入向量，用带温度系数的 NT-Xent 损失拉近正对、推远负对。SimCLR 的三个关键发现：① 组合型数据增强（随机裁剪+颜色抖动等）远优于单一增强；② 非线性投影头显著提升表征质量；③ 温度系数与归一化嵌入缺一不可。训练出的编码器可作为特征提取器，在少量标注数据上微调即可迁移到下游任务。

原理示意图

数学公式

1. 余弦相似度（衡量两个嵌入向量的接近程度）：

$$ \text{sim}(u, v) = \frac{u^\top v}{\lVert u \rVert \lVert v \rVert} $$

变量解释：

  • $ u, v $：两个归一化后的特征向量（投影头的输出）
  • $ u^\top v $：向量内积
  • $ \lVert u \rVert, \lVert v \rVert $：向量的 L2 范数，分母做归一化，使相似度范围落在 $ [-1, 1] $

2. NT-Xent 损失（Normalized Temperature-scaled Cross Entropy，核心损失函数）：

$$ \mathcal{L}_{NT\text{-}Xent}(i, j) = -\log \frac{\exp(\text{sim}(z_i, z_j)/\tau)}{\sum_{k=1}^{2N} \mathbb{1}_{[k \neq i]} \exp(\text{sim}(z_i, z_k)/\tau)} $$

变量解释：

  • $ z_i, z_j $：一对正样本（同源增强视图）的投影向量
  • $ N $：batch size，一次喂入的原图数；增强后共 $ 2N $ 个视图
  • $ \tau $：温度系数（temperature），缩放相似度得分
  • $ \mathbb{1}_{[k \neq i]} $：指示函数，排除 $ z_i $ 自己，其余 $ 2N-1 $ 个视图参与分母（其中 1 个正对 + $ 2N-2 $ 个负样本）
  • 整体含义：让"正对相似度"在全体样本中的占比尽可能大，等价于一个多分类 softmax 交叉熵

3. 总损失（每个正对都算一次，取平均）：

$$ \mathcal{L} = \frac{1}{2N} \sum_{k=1}^{2N} \mathcal{L}_{NT\text{-}Xent}(2k-1, 2k) + \mathcal{L}_{NT\text{-}Xent}(2k, 2k-1) $$

变量解释：

  • $ 2N $：视图总数；每对正视图各贡献两次损失（对称计算）
  • $ \frac{1}{2N} $：对所有正对的损失取平均

核心要点

  • 核心思想：让同一图像的不同增强视图表征接近，让不同图像的视图表征远离（构造"正负样本对"）
  • 投影头（Projection Head）是关键设计：编码器输出送入两层 MLP 后再算对比损失，效果显著优于直接在编码器特征上算
  • 数据增强组合（裁剪缩放 + 颜色抖动 + 灰度化 + 高斯模糊）的合理搭配是成功的最大功臣
  • NT-Xent 损失= 温度缩放 + 余弦相似度 + softmax 交叉熵，归一化嵌入和温度参数缺一不可
  • 无监督预训练 + 下游微调（linear probe）即可达到接近监督学习的效果，这正是自监督的意义
  • 扩展方向：SimCLR v2（加深投影头）、MoCo、BYOL 等后续框架

技术细节与参数详解

#### 参数 1：温度系数 temperature τ

  • 含义：NT-Xent 损失中的缩放因子，控制相似度分布的尖锐程度
  • 类型：float
  • 默认值：SimCLR 论文使用 $ \tau = 0.1 $（ImageNet 上）
  • 取值范围：$ 0.05 \sim 1.0 $ 常见
  • 对结果的影响：$ \tau $ 越小 → 相似度分布越尖锐，模型更聚焦"困难负样本"，但过小易导致训练不稳定/特征坍缩；$ \tau $ 越大 → 分布越平滑，收敛慢、区分度弱。论文通过消融实验验证 $ \tau=0.1 $ 附近的 loss 曲线（特征归一化下）表现最好
  • 推荐设置：初始 $ \tau=0.1 $，观察损失曲线后微调；训练中后期可适当调度（如特征坍缩时放大 $ \tau $）

#### 参数 2：batch size N

  • 含义：每个训练批次送入的原始图像数（每张图产生 2 个视图，共 $ 2N $ 个）
  • 类型：int
  • 默认值：SimCLR 论文在 ImageNet 上使用 4096（甚至更大）
  • 取值范围：16 ~ 8192+（取决于显存）
  • 对结果的影响：batch 越大 → 负样本越多 → 对比信号越强、表征质量越高；论文实验显示 batch 从 256 提到 4096 线性提升准确率（但收益递减）；batch 过小时正负样本区分困难、易坍缩
  • 推荐设置：显存允许下尽量大（如 512/1024）；用梯度累积或大 batch 训练的变体弥补显存限制

#### 参数 3：投影头 hidden_dim / output_dim（MLP 结构）

  • 含义：投影头 g(·) 是两层 MLP，hidden_dim 是隐藏层维度，output_dim 是最终嵌入（对比空间）维度
  • 类型：int
  • 默认值：论文使用与编码器输出相同的维度（如 2048），MLP 隐藏层 2048、输出 128
  • 对结果的影响：对比损失在投影空间计算，输出维度太低会损失信息、太高则噪声增加；隐藏层激活常用 ReLU
  • 推荐设置：ResNet50 编码器（输出 2048 维）搭配 hidden=2048, out=128 是经典配置；下游用编码器输出（非投影输出）做微调

#### 参数 4：编码器 backbone（encoder）

  • 含义：提取图像特征的主干网络，通常为 ResNet 系列
  • 类型：torchvision.models.resnet50 等
  • 默认值：ResNet-50（论文基线）
  • 对结果的影响：主干容量越大表征越强（论文用 ResNet-50 至 ResNet-200 缩放对比）；但训练成本随之上升
  • 推荐设置：资源有限用 ResNet-18/34，正式实验用 ResNet-50+

#### 参数 5：数据增强组合 augmentation

  • 含义：对每个样本生成不同视图的变换集合，包括随机裁剪缩放（crop+resize）、颜色抖动（color jitter）、随机灰度化（grayscale）、高斯模糊（blur）、随机翻转（flip）等
  • 类型：torchvision.transforms 组合
  • 默认值：论文方案 = RandomResizedCrop + RandomColorJitter(0.8) + RandomGrayscale(0.2) + RandomGaussianBlur + Normalize
  • 对结果的影响：这是 SimCLR 最重要的超参之一——随机裁剪+颜色抖动是关键，缺少任一都会明显掉点；只做单一增强（如仅裁剪）表征质量大幅下降
  • 推荐设置：按论文默认组合起步，再针对数据集特点调权重（如医学影像减弱颜色抖动）

#### 参数 6：优化器与学习率

  • 含义：训练使用的优化器、初始学习率与调度策略
  • 默认值：LARS（Large Batch），学习率 0.3 × batch/256，cosine decay
  • 对结果的影响：大 batch 下普通 SGD/Momentum 易不稳定，LARS 可线性扩展；学习率过大发散、过小收敛慢
  • 推荐设置：小规模复现可用 AdamW + cosine scheduler 起步；复现论文请用 LARS

#### 参数 7：训练轮数 epochs / 权重衰减 weight_decay

  • 含义：训练总轮数与正则化强度
  • 默认值：SimCLR 论文预训练 1000 epochs；weight_decay 1e-6~1e-4
  • 对结果的影响：epoch 越多表征越好（论文 100→1000 epochs 线性评估提升明显）；weight_decay 防止过拟合/稳定训练
  • 推荐设置：资源受限用 100-300 epochs；weight_decay 按 batch 大小微调

#### 参数 8：负样本与特征归一化（L2 norm）

  • 含义：将投影向量归一化为单位向量后再算余弦相似度（与损失中的分子匹配）
  • 默认值：SimCLR 恒做 L2 归一化
  • 对结果的影响：不归一化时损失行为退化（温度失去意义）；归一化后温度才精确控制分布
  • 推荐设置：始终在相似度计算前对 z 做 L2 归一化

代码示例

import torch
import torch.nn as nn
import torch.nn.functional as F
import torchvision.models as models

class ProjectionHead(nn.Module):
    """SimCLR 投影头：两层 MLP + ReLU，输出到对比空间"""
    def __init__(self, in_dim=2048, hidden_dim=2048, out_dim=128):
        super().__init__()
        # 第一层：线性变换 + ReLU（论文不加 BatchNorm 效果更稳定）
        self.fc1 = nn.Linear(in_dim, hidden_dim)
        # 第二层：线性变换，输出对比空间的 128 维向量
        self.fc2 = nn.Linear(hidden_dim, out_dim)

    def forward(self, x):
        # 前向传播：先线性+ReLU，再线性输出
        return self.fc2(F.relu(self.fc1(x)))


class SimCLR(nn.Module):
    """SimCLR 整体框架：编码器 + 投影头"""
    def __init__(self, base_encoder=models.resnet50, out_dim=128):
        super().__init__()
        # 去掉 ResNet 最后一层全连接，作为特征提取器（输出 2048 维）
        self.encoder = nn.Sequential(*list(base_encoder().children())[:-1])
        # 在编码器输出之上接投影头
        self.projection_head = ProjectionHead(in_dim=2048, hidden_dim=2048, out_dim=out_dim)

    def forward(self, x):
        # 编码器输出为 (B, 2048, 1, 1)，压平为 (B, 2048)
        h = self.encoder(x).flatten(start_dim=1)
        # 投影头输出对比空间表示 z
        z = self.projection_head(h)
        # L2 归一化（对相似度计算至关重要）
        return F.normalize(z, dim=1)


def nt_xent_loss(z_i, z_j, temperature=0.1):
    """NT-Xent 损失：拉近正对、推开负对（InfoNCE 变体）"""
    batch_size = z_i.shape[0]
    # 拼接两个视图，得到 (2N, D) 的完整表示
    z = torch.cat([z_i, z_j], dim=0)              # (2N, D)
    # 计算所有视图两两之间的相似度矩阵（2N x 2N）
    sim = torch.mm(z, z.t())                      # 已归一化，内积即余弦相似度
    # 去掉对角线（自身相似度恒为 1），用大负数填充避免影响 softmax
    mask = torch.eye(sim.shape[0], device=sim.device).bool()
    sim = sim.masked_fill(mask, -1e9)
    # 提取每个样本对应的正对索引：(i, i+N) 与 (i+N, i) 互为
    positives = torch.cat([torch.diag(sim, batch), torch.diag(sim, -batch)], dim=0)  # 2N
    # 除自身外所有样本的相似度作为分母（含 1 个正对 + 2N-2 个负样本）
    denom = torch.logsumexp(sim / temperature, dim=1)   # 对每个行做 log-sum-exp
    # 损失 = -log(正对概率)，取 2N 个正对损失的平均
    loss = -torch.mean(positives / temperature - denom)
    return loss

注：torch.arange 相关细节为保证自对（i 与 i+N）对应；masked_fill 去除自相似。

复杂度分析

时间复杂度：每步训练 $ \mathcal{O}(2N \cdot F + (2N)^2) $。推导：编码器对 $ 2N $ 张增强视图各自前向传播一次，计算量为 $ O(2N \cdot F) $（$ F $ 为单张图编码成本）；NT-Xent 损失需计算 $ 2N \times 2N $ 相似度矩阵，为 $ O((2N)^2) $。batch 越大，相似度矩阵开销增长越明显。

空间复杂度：$ O(2N \cdot D) $（特征矩阵）+ 编码器参数。特征矩阵存 $ 2N $ 个 D 维向量；无负样本（全部来自 batch 内）所以无需额外存储大量负样本库，这也是 SimCLR 相对"伪负样本库"方法更简单的原因。

应用场景

  • 图像自监督预训练：大模型（数百万无标注图片）上学习通用特征，再少量标注微调
  • 医疗影像、遥感等标注稀缺领域：用无标签数据预训练后再做分类/分割
  • 表征学习：供下游检索、聚类、零样本分类使用
  • 视频、音频、文本等多模态自监督的通用对比范式（后续大量模型沿用 NT-Xent）

支持向量机

类别：监督学习 | 难度：中等

算法简介

支持向量机（Support Vector Machine, SVM）是一种经典的监督学习算法，核心思想是最大化间隔（max-margin）：在特征空间中寻找一个最优超平面，使其到两类样本（正类/负类）最近点的距离之和最大，这些"离超平面最近"的样本点就是支持向量（Support Vectors）——它们决定了超平面位置，其他样本对模型毫无影响。线性不可分时，SVM 通过核技巧（Kernel Trick）将样本隐式映射到高维空间再做线性划分，从而处理非线性分类。SVM 天然支持小样本、高维数据，泛化能力强，是分类问题的经典基线。sklearn 中的 SVC（C-Support Vector Classification）基于 libsvm 实现，使用 SMO 算法求解对偶二次规划问题；除了分类，还可通过 probability=True 输出概率、通过 decision_function_shape 支持多分类（一对多/一对一）。尽管深度学习当道，SVM 在中小规模数据、文本分类、生物信息等领域仍是可靠之选。

原理示意图

数学公式

1. 硬间隔（线性可分）目标函数：最大化间隔等价于最小化 $ \frac{1}{2}\lVert w \rVert^2 $：

$$ \min_{w,b} \frac{1}{2}\lVert w \rVert^2 \quad \text{s.t.} \quad y_i(w^\top x_i + b) \ge 1, \ \forall i $$

变量解释：

  • $ w $：超平面法向量（决定方向）
  • $ b $：偏置项（决定平移）
  • $ x_i $：第 $ i $ 个训练样本特征
  • $ y_i $：第 $ i $ 个样本标签，取 $ +1 $ 或 $ -1 $
  • 约束保证所有样本都在间隔带外；间隔宽度为 $ 2/\lVert w \rVert $

2. 软间隔（加入松弛变量，C-SVM）

$$ \min_{w,b,\xi} \frac{1}{2}\lVert w \rVert^2 + C\sum_{i=1}^{n} \xi_i \quad \text{s.t.} \quad y_i(w^\top x_i + b) \ge 1 - \xi_i, \ \xi_i \ge 0 $$

变量解释：

  • $ C $：惩罚系数（正则化参数），控制"误分类代价"与"间隔大小"的权衡
  • $ \xi_i $：第 $ i $ 个样本的松弛变量，允许其越过间隔边界（容忍噪声/线性不可分）

3. 对偶问题与核函数

$$ \max_\alpha \sum_{i=1}^{n} \alpha_i - \frac{1}{2}\sum_{i=1}^{n}\sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j K(x_i, x_j) \quad \text{s.t.} \quad 0 \le \alpha_i \le C, \ \sum_{i}\alpha_i y_i = 0 $$

变量解释：

  • $ \alpha_i $：拉格朗日乘子，非零的 $ \alpha_i $ 对应支持向量
  • $ K(x_i, x_j) $：核函数，等价于高维空间中向量内积 $ \phi(x_i)^\top \phi(x_j) $，无需显式计算映射 $ \phi $
  • $ C $：上界约束，限制 $ \alpha_i $ 最大取 $ C $

4. 常用核函数

核公式参数
线性核$ K(x_i,x_j)=x_i^\top x_j $无
多项式核$ K=(\gamma x_i^\top x_j + r)^d $gamma, coef0, degree
RBF 径向基核$ K=\exp(-\gamma \lVert x_i - x_j \rVert^2) $gamma
Sigmoid 核$ K=\tanh(\gamma x_i^\top x_j + r) $gamma、coef0

核心要点

  • 最大间隔原则是 SVM 泛化能力强的根源：间隔越大，结构风险越低
  • 分类决策只由支持向量决定（稀疏性），非支持向量样本不参与最终模型
  • 核技巧让 SVM 无需显式高维映射即可处理非线性，RBF 核最常用
  • 软间隔参数 C 控制对误分类的容忍度：C 大→严格、易过拟合；C 小→宽松、易欠拟合
  • SVM 是二分类器，多分类通过 one-vs-rest（OvR）或 one-vs-one（OvO）组合实现
  • 特征尺度对 SVM（尤其核函数）影响极大，必须标准化后再训练

技术细节与参数详解（sklearn.svm.SVC）

#### 参数 1：C（惩罚系数）

  • 含义：对误分类样本的惩罚强度，控制"最大间隔"与"容忍误差"的权衡
  • 类型：float
  • 默认值：1.0
  • 取值范围：$ (0, +\infty) $，如 0.001 ~ 1000
  • 对结果的影响：C 越大 → 越严格拟合训练集（间隔小、易过拟合）；C 越小 → 间隔越大、对噪声越宽容（易欠拟合）
  • 推荐设置：从 1.0 起步，配合 GridSearchCV 在 [0.1, 1, 10] 附近网格搜索

#### 参数 2：kernel（核函数类型）

  • 类型：{'linear', 'poly', 'rbf', 'sigmoid', 'precomputed'} 或自定义 callable
  • 默认值：'rbf'
  • 对结果的影响：决定映射方式与模型表达能力；RBF 能处理大多数非线性问题，linear 适合高维稀疏特征（文本）
  • 推荐设置：特征多且稀疏用 linear；一般情况用 rbf；precomputed 用于自定义核矩阵

#### 参数 3：gamma（核函数系数）

  • 含义：RBF / poly / sigmoid 核的系数，控制单个样本影响半径
  • 类型：float 或 'scale'/'auto'
  • 默认值：'scale'（即 $ 1/(n\_features \cdot X.var()) $）；'auto' 为 $ 1/n\_features $
  • 取值范围：(0, ∞)，常用 $ 10^{-3} \sim 10^3 $
  • 对结果的影响：gamma 大 → 影响半径小、决策边界复杂、易过拟合；gamma 小 → 边界平滑、易欠拟合
  • 推荐设置：'scale' 起步，RBF 下与 C 联合网格搜索

#### 参数 4：degree（多项式核的次方）

  • 含义：仅 kernel='poly' 有效，多项式展开的阶数
  • 类型：int
  • 默认值：3
  • 取值范围：$ \ge 1 $（常用 2-5）
  • 对结果的影响：degree 越大 → 决策边界越复杂，越易过拟合，且计算开销上升
  • 推荐设置：默认 3；高维噪声数据降低到 2

#### 参数 5：coef0（核函数独立项）

  • 含义：poly 与 sigmoid 核中的常数项 r（公式中独立项）
  • 类型：float
  • 默认值：0.0
  • 对结果的影响：影响多项式核的缩放与 sigmoid 核的偏移，通常影响较小但不可忽略
  • 推荐设置：保持默认，或与 gamma 一起在 poly 核中微调

#### 参数 6：shrinking（启发式收缩）

  • 含义：是否启用 SMO 的 shrinking 启发式（跳过已收敛的变量以加速）
  • 类型：bool
  • 默认值：True
  • 对结果的影响：True 通常更快，但在某些数据集上可能略慢（尤其 cache 小、特征多时）
  • 推荐设置：保持默认 True；个别场景可尝试 False 对比

#### 参数 7：probability（是否输出概率）

  • 含义：是否启用 Plott 概率估计（训练后额外做交叉验证拟合 sigmoid）
  • 类型：bool
  • 默认值：False
  • 对结果的影响：True 会显著增加训练时间（需额外的 5 折交叉验证），但可用 predict_proba() 输出概率
  • 推荐设置：需要概率/置信度时开启；仅需分类标签时保持 False 以节省时间

#### 参数 8：tol（停止迭代容差）

  • 含义：优化迭代的收敛容忍度（损失/梯度变化小于该值时停止）
  • 类型：float
  • 默认值：0.001
  • 对结果的影响：越小精度越高、耗时越长；过大提前停止损失质量
  • 推荐设置：默认 0.001；追求快速原型可放宽到 0.01

#### 参数 9：cache_size（核缓存大小，MB）

  • 含义：内核矩阵缓存（内存）上限，单位 MB
  • 类型：int（MB）
  • 默认值：200
  • 对结果的影响：核矩阵 K 的计算可被缓存，缓存越大重复计算越少、训练越快，但内存占用升高
  • 推荐设置：样本量大时调大（如 500~1000）加速训练

#### 参数 10：class_weight（类别权重）

  • 含义：给不同类别的样本分配不同 C 权重（缓解类别不平衡）
  • 类型：dict / 'balanced' / None
  • 默认值：None
  • 对结果的影响：'balanced' 自动按类别频率反比加权；可手工给少数类更高权重
  • 推荐设置：类别不平衡时优先尝试 'balanced'

#### 参数 11：max_iter（最大迭代次数）

  • 含义：SMO 求解器的最大迭代上限，-1 表示无限制
  • 类型：int
  • 默认值：-1
  • 对结果的影响：设小值可控制训练时间，但可能未收敛导致模型质量差
  • 推荐设置：默认 -1；大数据集可设上限并监控 n_iter_

#### 参数 12：decision_function_shape / break_ties / random_state

  • 含义：多分类策略与平局处理。decision_function_shape 可选 'ovo'（一对一，默认）或 'ovr'（一对多）；break_ties=True 时按决策值破坏平局；random_state 控制概率估计时的随机性
  • 默认值：'ovo' / False / None
  • 对结果的影响：OvO 训练 K(K-1)/2 个二分类器，OvR 训练 K 个；break_ties 只影响 predict() 而非 predict_proba()
  • 推荐设置：多分类默认即可；需要概率排序可开 break_ties

代码示例

import numpy as np
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.preprocessing import StandardScaler  # 特征标准化
from sklearn.svm import SVC                        # 支持向量分类器
from sklearn.metrics import classification_report  # 分类评估报告

# 1. 加载鸢尾花数据集（3 类、4 特征、150 样本）
X, y = load_iris(return_X_y=True)

# 2. 划分训练/测试集（70% 训练 / 30% 测试）
X_train, X_test, y_train, y_test = train_test_split(
    X, y, test_size=0.3, random_state=42)  # random_state 固定切分结果

# 3. 标准化：核方法对特征尺度敏感，必须做
scaler = StandardScaler()
X_train = scaler.fit_transform(X_train)  # 用训练集拟合均值/方差
X_test = scaler.transform(X_test)        # 用同一组参数变换测试集（防数据泄露）

# 4. 构建 SVC 模型（RBF 核 + 概率输出 + 类别平衡）
model = SVC(
    C=1.0,            # 正则化强度：间隔与误分类的权衡
    kernel='rbf',     # RBF 径向基核：处理非线性
    gamma='scale',    # 核系数 = 1/(n_features * X.var())
    probability=True, # 开启 predict_proba() 概率输出
    class_weight='balanced',  # 类别不平衡时自动加权
    tol=0.001,        # 迭代收敛容差
    cache_size=200,   # 核缓存 200MB
    max_iter=-1       # 无迭代上限
)

# 5. 训练（内部用 SMO 求解对偶问题）
model.fit(X_train, y_train)

# 6. 预测与评估
y_pred = model.predict(X_test)            # 硬分类预测
print(classification_report(y_test, y_pred))  # 打印精确率/召回率/F1
print("支持向量个数：", len(model.support_vectors_))      # 观察稀疏性
print("支持向量索引:", model.support_)                    # 支持向量样本编号

注：StandardScaler 需在训练前拟合；model.support_vectors_ 展示 SVM 只依赖少量支持向量这一特性。

复杂度分析

时间复杂度：训练一般为 $ \mathcal{O}(n^2 \sim n^3) $（SMO 的经验复杂度），$ n $ 为样本数。推导：对偶问题的核矩阵计算是 $ O(n^2) $，SMO 每次更新两个变量并迭代，整体介于二次与三次之间；probability=True 额外做 5 折交叉验证，约增加 5 倍训练时间。预测阶段仅需与支持向量计算核，为 $ O(n_{SV} \cdot d) $（$ n_{SV} $ 为支持向量数、$ d $ 为特征维度）。

空间复杂度：$ O(n \cdot d) $（存样本与核缓存，缓存上限由 cache_size 控制）。

  • 生物信息学：基因表达、蛋白质分类（特征多、样本少）
