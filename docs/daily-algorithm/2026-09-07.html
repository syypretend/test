快速选择

类别：查找算法 | 难度：入门

原理

快速选择（QuickSelect）是由 Tony Hoare 发明的选择算法，用于在未排序数组中查找第 k 小（或第 k 大）的元素。它是快速排序的变体，核心区别在于：快速排序需要递归处理分区后的两侧，而快速选择只需递归处理包含目标元素的那一侧。

算法基于分治策略：每次选取一个基准元素（pivot），通过分区（partition）操作将数组分为"小于基准"和"大于基准"两部分，然后判断目标位置 k 落在哪个分区，只递归处理那个分区。这种"单边递归"的剪枝策略使得期望时间复杂度为 O(n)，优于排序后取值的 O(n log n)。

分区方案有两种主流实现：Lomuto 分区（选最右元素为 pivot，单指针扫描，实现简单但交换次数多）和 Hoare 分区（双指针从两端向中间扫描，交换次数少但实现稍复杂）。

核心要点

  • 分治 + 剪枝：只递归包含目标 k 的一侧，不完整排序
  • 期望 O(n)：每次分区后平均排除一半元素，T(n) = T(n/2) + O(n) = O(n)
  • 最坏 O(n²)：当 pivot 选择不当（如已排序数组选首/尾元素）时退化为 O(n²)
  • 随机化 pivot 可将最坏情况概率降至极低，实践中几乎不会出现
  • 原地算法：空间复杂度 O(1)（不含递归栈），递归栈 O(log n) 期望
  • 两种分区方案：Lomuto（简单直观）和 Hoare（高效但边界处理复杂）

技术细节与参数详解

#### partition 函数核心参数

#### pivot 选择策略

  • 含义：选择哪个元素作为分区基准
  • 类型：策略选择（固定位置 / 随机 / 三数取中）
  • 默认值：最右元素 nums[right]（Lomuto）或最左元素 nums[left]（Hoare）
  • 取值范围：数组中任意元素
  • 对结果的影响：
  • 固定选首/尾元素：对已排序数组退化为 O(n²)
  • 随机选择：期望 O(n)，最坏概率极低
  • 三数取中（median-of-three）：取 left、mid、right 的中位数，稳定性好
  • 推荐设置：面试中用随机化 pivot 最稳妥；竞赛中三数取中更高效

#### left（左边界）

  • 含义：当前递归处理的子数组左端索引
  • 类型：int
  • 取值范围：0 到 len(nums)-1
  • 对结果的影响：缩小搜索范围，每次递归更新为分区点的左/右侧

#### right（右边界）

  • 含义：当前递归处理的子数组右端索引
  • 类型：int
  • 取值范围：0 到 len(nums)-1
  • 对结果的影响：与 left 配合确定搜索范围

#### k（目标位置）

  • 含义：要查找的第 k 小元素在排序后数组中的位置（0-indexed）
  • 类型：int
  • 取值范围：0 到 len(nums)-1
  • 对结果的影响：决定分区后递归左侧还是右侧
  • 若 pivot_index == k：找到目标，返回 nums[pivot_index]
  • 若 k < pivot_index：递归左分区
  • 若 k > pivot_index：递归右分区

#### Lomuto 分区参数

#### i（小元素边界指针）

  • 含义：维护"小于 pivot 的元素区域"的右边界
  • 类型：int
  • 初始值：left - 1
  • 对结果的影响：j 扫描过程中遇到小于 pivot 的元素时，i 先加 1 再交换 nums[i] 与 nums[j]
  • 最终值：分区完成后 i+1 即为 pivot 的正确位置

#### j（扫描指针）

  • 含义：从 left 到 right-1 遍历子数组
  • 类型：int
  • 对结果的影响：逐个比较 nums[j] 与 pivot，小于则交换到左侧区域

#### Hoare 分区参数

#### 双指针 i / j

  • 含义：i 从左向右找大于等于 pivot 的元素，j 从右向左找小于等于 pivot 的元素
  • 对结果的影响：找到后交换，直到 i >= j，此时 j 为分区点
  • 注意：Hoare 分区返回的 j 不一定是 pivot 的最终位置，但保证左侧 <= pivot、右侧 >= pivot

代码示例

import random


def quickselect_lomuto(nums, left, right, k):
    """Lomuto 分区版快速选择：查找排序后第 k 位置（0-indexed）的元素"""
    if left == right:                    # 递归终止：只剩一个元素
        return nums[left]

    # 随机选择 pivot 并交换到最右
    pivot_idx = random.randint(left, right)  # 随机化避免最坏情况
    nums[pivot_idx], nums[right] = nums[right], nums[pivot_idx]  # pivot 放到最右

    # Lomuto 分区
    pivot = nums[right]                  # 基准值
    i = left - 1                         # 小元素边界，初始在 left 左侧
    for j in range(left, right):         # 扫描 left 到 right-1
        if nums[j] <= pivot:             # 当前元素 <= 基准
            i += 1                       # 扩展小元素区域
            nums[i], nums[j] = nums[j], nums[i]  # 交换到左侧

    # 将 pivot 放到正确位置
    pi = i + 1                           # pivot 的最终位置
    nums[pi], nums[right] = nums[right], nums[pi]

    # 判断 k 在哪个分区
    if k == pi:                          # 找到目标
        return nums[pi]
    elif k < pi:                         # k 在左分区
        return quickselect_lomuto(nums, left, pi - 1, k)
    else:                                # k 在右分区
        return quickselect_lomuto(nums, pi + 1, right, k)


def quickselect_hoare(nums, left, right, k):
    """Hoare 分区版快速选择：双指针，交换次数更少"""
    if left == right:                    # 递归终止
        return nums[left]

    pivot_idx = random.randint(left, right)  # 随机选 pivot
    pivot = nums[pivot_idx]

    # Hoare 分区：双指针从两端向中间扫描
    i, j = left, right
    while True:
        while nums[i] < pivot:           # 左指针找 >= pivot 的
            i += 1
        while nums[j] > pivot:           # 右指针找 <= pivot 的
            j -= 1
        if i >= j:                       # 指针相遇，分区完成
            break
        nums[i], nums[j] = nums[j], nums[i]  # 交换不符合位置的元素
        i += 1                           # 继续扫描
        j -= 1

    # j 为分区点：左半 [left, j] <= pivot，右半 [j+1, right] >= pivot
    if k <= j:                           # k 在左分区
        return quickselect_hoare(nums, left, j, k)
    else:                                # k 在右分区
        return quickselect_hoare(nums, j + 1, right, k)


def find_kth_largest(nums, k):
    """查找数组中第 k 大的元素（LeetCode 215）
    第 k 大 = 排序后第 (n-k) 位置（0-indexed）
    """
    n = len(nums)
    return quickselect_lomuto(nums, 0, n - 1, n - k)


# 使用示例
nums = [3, 2, 1, 5, 6, 4]
print(find_kth_largest(nums, 2))         # 输出 5（第 2 大）
# 原理：排序后 [1,2,3,4,5,6]，第 2 大 = 第 (6-2)=4 位置 = 5

nums2 = [3, 2, 3, 1, 2, 4, 5, 5, 6]
print(find_kth_largest(nums2, 4))        # 输出 4（第 4 大）

# 查找中位数
nums3 = [7, 10, 4, 3, 20, 15]
median_idx = len(nums3) // 2             # 中位数位置
print(quickselect_lomuto(nums3, 0, len(nums3) - 1, median_idx))  # 输出 10（中位数）

复杂度分析

  • 期望时间：O(n)，每次分区平均排除一半元素，T(n) = T(n/2) + O(n) = O(n)
  • 最坏时间：O(n²)，当每次 pivot 都是最大/最小元素时（随机化后概率极低）
  • 空间：O(1) 原地操作，递归栈 O(log n) 期望、O(n) 最坏
  • 对比排序：排序后取值 O(n log n)，快速选择更高效

应用场景

  • Top K 问题：查找数组中第 K 大/小的元素（LeetCode 215）
  • 中位数查找：无需排序即可 O(n) 找到中位数
  • 百分位数计算：大规模数据的 P50/P95/P99 统计
  • 数据流中的顺序统计（配合蓄水池抽样）
  • 快速分区后的近似排序（部分排序只需 O(n + k log k)）

交叉熵损失

类别：损失函数 | 难度：入门

原理

交叉熵损失（Cross-Entropy Loss）是深度学习中最常用的分类任务损失函数。它衡量模型输出的概率分布与真实标签分布之间的差异：当预测概率接近真实标签时损失趋近于 0，远离时损失趋向无穷大。

数学上，对于单样本多分类问题，交叉熵损失公式为：L = -Σ y_c · log(p_c)，其中 y_c 是 one-hot 编码的真实标签（只有目标类为 1，其余为 0），p_c 是模型对类别 c 的预测概率（由 softmax 将 logits 转换得到）。

PyTorch 的 nn.CrossEntropyLoss 内部组合了 LogSoftmax 和 NLLLoss：先对 logits 做 softmax 得到概率，再取对数，最后与真实标签做负对数似然。这意味着使用者无需在模型最后一层手动添加 softmax，直接传入原始 logits 即可。

核心要点

  • 结合 LogSoftmax + NLLLoss：直接接收 logits，不需手动 softmax
  • 多分类标准损失：适用于类别数 >= 2 的分类任务
  • 梯度特性良好：softmax + 交叉熵的梯度为 (p - y)，简单且数值稳定
  • 类别不平衡处理：通过 weight 参数给少数类更高权重
  • 标签平滑：label_smoothing 参数防止模型过度自信，提升泛化
  • ignore_index：可忽略 padding 等无需计算损失的样本

技术细节与参数详解

#### nn.CrossEntropyLoss 核心参数

#### weight（类别权重）

  • 含义：为每个类别设置不同的损失权重，用于处理类别不平衡
  • 类型：Tensor，形状为 (C,)，C 为类别数
  • 默认值：None（所有类别权重为 1）
  • 取值范围：正实数，通常少数类给较大值（如 2-10），多数类给 1
  • 对结果的影响：损失公式变为 L = -Σ w_c · y_c · log(p_c)，少数类的损失被放大
  • 推荐设置：类别比例 1:5 时设 weight=[1, 5]；也可用逆频率 weight = N / (C * N_c)

#### ignore_index（忽略索引）

  • 含义：指定一个目标值，该值不参与损失计算（常用于 padding）
  • 类型：int
  • 默认值：-100
  • 取值范围：任意整数，通常设为 -100 或 -1
  • 对结果的影响：target 中等于 ignore_index 的样本不会贡献损失和梯度
  • 推荐设置：NLP 序列标注中 padding 标签设为 -100；普通分类任务保持默认

#### reduction（归约模式）

  • 含义：控制如何对 batch 中各样本的损失进行汇总
  • 类型：str
  • 默认值："mean"
  • 可选值：
  • "none"：不归约，返回每个样本的损失（形状 (N,)）
  • "mean"：返回所有样本损失的平均值（标量）
  • "sum"：返回所有样本损失的总和（标量）
  • 对结果的影响：
  • "mean"：最常用，损失值与 batch 无关，便于比较
  • "sum"：损失随 batch 大小变化，需手动调整学习率
  • "none"：用于自定义损失处理，如 focal loss 手动加权
  • 推荐设置：绝大多数场景用 "mean"

#### label_smoothing（标签平滑系数）

  • 含义：将 one-hot 标签软化为 [ε/C, ..., 1-ε+ε/C, ..., ε/C]，防止过度自信
  • 类型：float
  • 默认值：0.0（不启用）
  • 取值范围：0.0 到 1.0
  • 对结果的影响：
  • 0.0：标准 one-hot，模型倾向过度自信
  • 0.1：标签变为 [0.1/C, ..., 0.9+0.1/C, ..., 0.1/C]，提升泛化
  • 过大（>0.3）：模型欠拟合，预测趋于均匀分布
  • 推荐设置：
  • 大数据集（>100K）：0.0 或 0.05
  • 小数据集（<10K）：0.1
  • 知识蒸馏中常用 0.1
  • 公式：smoothed_label = (1-ε) * one_hot + ε / C

#### size_average（已废弃）

  • 含义：旧版参数，控制是否对 batch 取平均
  • 类型：bool
  • 默认值：None
  • 对结果的影响：已被 reduction 替代，新代码不应使用
  • 推荐设置：使用 reduction 代替

#### reduce（已废弃）

  • 含义：旧版参数，控制是否归约
  • 类型：bool
  • 默认值：None
  • 对结果的影响：已被 reduction 替代
  • 推荐设置：使用 reduction 代替

#### 输入形状要求

#### input（logits）

  • 含义：模型输出（未经 softmax 的原始值）
  • 类型：Tensor，形状为 (N, C) 或 (N, C, d1, d2, ...)
  • 要求：不需要手动 softmax，函数内部自动处理
  • C：类别数

#### target（目标标签）

  • 含义：真实类别标签
  • 类型：Tensor
  • 形状：(N,) 或 (N, d1, d2, ...)，与 input 的非类别维度一致
  • 取值范围：0 到 C-1 的整数（类别索引），或 ignore_index

代码示例

import torch
import torch.nn as nn

# ===== 1. 基本用法 =====
# 3 个样本，5 个类别
logits = torch.randn(3, 5)              # 模型输出（未经 softmax）
targets = torch.tensor([1, 0, 4])       # 真实标签（类别索引）

# 标准交叉熵损失
criterion = nn.CrossEntropyLoss()       # reduction 默认 'mean'
loss = criterion(logits, targets)       # 计算损失
print(f"标准 CE Loss: {loss.item():.4f}")

# ===== 2. 类别权重（处理不平衡）=====
# 假设 5 个类别，类别 0 是少数类，给更高权重
weights = torch.tensor([5.0, 1.0, 1.0, 1.0, 1.0])  # 类别 0 权重为 5
criterion_weighted = nn.CrossEntropyLoss(weight=weights)
loss_weighted = criterion_weighted(logits, targets)
print(f"加权 CE Loss: {loss_weighted.item():.4f}")

# ===== 3. 标签平滑 =====
criterion_smooth = nn.CrossEntropyLoss(label_smoothing=0.1)  # 平滑系数 0.1
loss_smooth = criterion_smooth(logits, targets)
print(f"标签平滑 CE Loss: {loss_smooth.item():.4f}")

# ===== 4. 忽略 padding（NLP 场景）=====
# 5 个样本，3 个类别，最后两个是 padding（label=-100）
logits_nlp = torch.randn(5, 3)
targets_nlp = torch.tensor([0, 2, 1, -100, -100])  # -100 被 ignore_index 忽略
criterion_nlp = nn.CrossEntropyLoss(ignore_index=-100)
loss_nlp = criterion_nlp_nlp = criterion_nlp(logits_nlp, targets_nlp)
print(f"忽略 padding CE Loss: {loss_nlp.item():.4f}")

# ===== 5. reduction='none' 获取逐样本损失 =====
criterion_none = nn.CrossEntropyLoss(reduction='none')
losses_per_sample = criterion_none(logits, targets)  # 形状 (3,)
print(f"逐样本损失: {losses_per_sample.tolist()}")

# ===== 6. 在训练循环中使用 =====
model = nn.Linear(10, 5)                 # 假设 10 维输入，5 类输出
optimizer = torch.optim.Adam(model.parameters(), lr=1e-3)
criterion = nn.CrossEntropyLoss(label_smoothing=0.1)  # 带标签平滑

for epoch in range(3):
    x = torch.randn(32, 10)               # 32 个样本，10 维特征
    y = torch.randint(0, 5, (32,))        # 随机标签 0-4
    logits = model(x)                      # 前向传播（输出 logits）
    loss = criterion(logits, y)            # 计算交叉熵损失
    optimizer.zero_grad()                  # 清空梯度
    loss.backward()                        # 反向传播
    optimizer.step()                       # 更新参数
    print(f"Epoch {epoch}: loss={loss.item():.4f}")

# ===== 7. 手动计算交叉熵（理解原理）=====
def manual_cross_entropy(logits, target):
    """手动实现交叉熵，验证 nn.CrossEntropyLoss 的计算"""
    probs = torch.softmax(logits, dim=-1)  # softmax 转概率
    log_probs = torch.log(probs)            # 取对数
    loss = -log_probs[target]               # 负对数似然
    return loss

# 对比
logit = torch.tensor([2.0, 1.0, 0.1])
target = 0
manual = manual_cross_entropy(logit, target)
pytorch = nn.CrossEntropyLoss()(logit.unsqueeze(0), torch.tensor([target]))
print(f"手动: {manual.item():.6f}, PyTorch: {pytorch.item():.6f}")
# 两者应完全一致

复杂度分析

  • 计算复杂度：O(N·C)，N 为样本数，C 为类别数。softmax + log + NLL 各 O(C)
  • 梯度复杂度：O(N·C)，梯度为 (p - y) / N，简洁且稳定
  • 数值稳定性：内部使用 LogSoftmax 实现，避免直接计算 exp 大数溢出
  • 内存：O(N·C) 用于存储 logits 和中间结果

应用场景

  • 图像分类：ResNet/ViT 等模型的最终分类头（ImageNet 1000 类）
  • 文本分类：BERT 分类任务的输出层（情感分析、意图识别）
  • 序列标注：NER、POS tagging 中每个 token 的分类（配合 ignore_index）
  • 知识蒸馏：教师模型的 soft label 配合标签平滑
  • 语音识别：CTC loss 的基础组件
  • 多模态对比学习：CLIP 中图文匹配的对称交叉熵

Mamba 状态空间模型

类别：前沿架构 | 难度：困难

原理

Mamba 是 Albert Gu 和 Tri Dao 在 2023 年提出的状态空间模型（State Space Model, SSM），核心创新是选择性状态空间机制（Selective State Space），解决了 Transformer 在长序列上的 O(n²) 复杂度问题，同时保持了 RNN 的线性推理效率。

SSM 基础：状态空间模型源自控制理论，用两个方程描述序列建模：

  • 状态更新方程：h(t) = A·h(t-1) + B·x(t)（连续时间）
  • 观测输出方程：y(t) = C·h(t) + D·x(t)

通过零阶保持（ZOH）离散化将连续参数 A、B、C、D 转为离散形式 Ā、B̄、C̄、D̄，使其可在数字计算中使用。

Mamba 的关键创新：传统 SSM（如 S4）的参数 A、B、C 是固定的（时间不变），Mamba 将 B、C、D（及 Δt）设计为输入相关的（input-dependent），即这些参数由当前输入 x_t 通过线性投影动态生成。这使得模型能根据输入内容选择性地记住或遗忘信息——重要信息保留到隐状态，无关信息被压缩丢弃。

架构对比：

  • Transformer：注意力机制看全局，但 O(n²) 复杂度，推理时需缓存 KV cache
  • RNN/LSTM：O(1) 推理，但训练无法并行，长程记忆有限
  • Mamba：O(n) 训练（并行扫描）+ O(1) 推理（RNN 式递推），且通过选择性机制实现内容感知的遗忘

核心要点

  • 选择性扫描（Selective Scan）：B、C、Δ 参数随输入动态变化，实现内容感知的遗忘
  • 线性复杂度：训练 O(n)（并行前缀扫描），推理 O(1)（RNN 式状态递推）
  • 无注意力机制：完全摒弃 self-attention，用 SSM 替代
  • 硬件感知设计：针对 GPU SRAM/HBM 访问模式优化，减少内存搬运
  • 隐状态压缩：用固定大小的隐状态 h_t 压缩历史信息，替代 KV cache
  • 与 Transformer 对比：长序列更快、推理更省内存；短序列质量相当
  • Mamba-2 改进：将 SSM 与注意力统一为结构化矩阵乘法，进一步加速

技术细节与参数详解

#### SSM 核心参数

#### A（状态转移矩阵）

  • 含义：控制隐状态如何从上一时刻传递到当前时刻，决定信息遗忘速率
  • 类型：矩阵，形状为 (d_state, d_state) 或对角化为 (d_state,)
  • 默认值：在 S4 中用 HiPPO 矩阵初始化；Mamba 中用对角矩阵，参数化为 A = -exp(A_log) 保证负定性
  • 对结果的影响：
  • A 的对角元素为负实数 → 稳定的指数衰减记忆
  • 衰减率大（|A| 大）→ 快速遗忘，只记近期信息
  • 衰减率小（|A| 小）→ 长期记忆，保留远期信息
  • Mamba 特性：A 是时间不变的（固定），但 Δ 使其等效变为输入相关
  • 推荐设置：用 A_log 参数化，初始化为 HiPPO 矩阵的对角部分

#### A_log（对数参数化 A）

  • 含义：A 的对数形式，A = -exp(A_log)，确保 A 为负实数（稳定性）
  • 类型：Tensor，形状为 (d_state,) 或 (d_inner, d_state)
  • 默认值：由 HiPPO 矩阵初始化取对数
  • 对结果的影响：保证状态转移矩阵的特征值为负，系统稳定
  • 推荐设置：可学习参数，通过反向传播更新

#### B（输入投影矩阵）

  • 含义：将输入 x_t 映射到状态空间的矩阵，决定输入如何写入隐状态
  • 类型：矩阵，形状为 (d_state,) 或 (d_state, d_inner)
  • Mamba 创新：B 是输入相关的，B = Linear(x_t)，而非固定参数
  • 对结果的影响：
  • B 大 → 当前输入对状态影响大（"记住"当前信息）
  • B 小 → 当前输入被忽略（"遗忘"当前信息）
  • 推荐设置：可学习参数，Mamba 中通过 s_B(x) = Linear(x) 动态生成

#### C（输出投影矩阵）

  • 含义：将隐状态 h_t 映射到输出 y_t 的矩阵，决定如何从状态读取信息
  • 类型：矩阵，形状为 (d_state,) 或 (d_state, d_inner)
  • Mamba 创新：C 也是输入相关的，C = Linear(x_t)
  • 对结果的影响：
  • C 大 → 从状态中读取更多信息
  • C 小 → 当前状态对输出贡献小
  • 推荐设置：可学习参数，Mamba 中通过 s_C(x) = Linear(x) 动态生成

#### D（跳跃连接 / 直通项）

  • 含义：输入到输出的直接连接，类似 ResNet 的残差连接
  • 类型：标量或向量
  • 默认值：可学习的初始化为较小的值
  • 对结果的影响：保证输入信息总能直接到达输出，避免梯度消失
  • 推荐设置：可学习参数，初始化为 0 或小常数

#### Δt（离散化步长 / 时间步）

  • 含义：控制连续 SSM 离散化的步长，决定状态更新的"分辨率"
  • 类型：标量或向量
  • Mamba 创新：Δ 是输入相关的，Δ = softplus(Linear(x_t))
  • 对结果的影响：
  • Δ 大 → 状态更新幅度大，快速适应新输入（"关注"当前）
  • Δ 小 → 状态更新幅度小，保持历史状态（"忽略"当前）
  • Δ 的输入相关性是 Mamba 选择性机制的核心
  • 推荐设置：通过 softplus 保证正值，初始化为均匀分布 [Δ_min, Δ_max]

#### 离散化后的参数 Ā、B̄

  • 含义：通过 ZOH 离散化将连续 A、B 转为离散形式
  • 公式：Ā = exp(Δ·A)，B̄ = (Δ·A)^{-1} · (Ā - I) · Δ·B
  • 对结果的影响：将连续微分方程转为可计算的递推关系
  • 注意：由于 Δ 输入相关，Ā、B̄ 也是输入相关的

#### Mamba Block 架构参数

#### d_model（模型维度）

  • 含义：输入/输出的特征维度
  • 类型：int
  • 默认值：通常 512-4096
  • 推荐设置：与同规模 Transformer 相同（如 130M 模型用 d_model=768）

#### d_inner（内部扩展维度）

  • 含义：Mamba block 内部投影后的维度，类似 FFN 的中间维度
  • 类型：int
  • 默认值：通常为 2 × d_model
  • 对结果的影响：影响模型容量和参数量
  • 推荐设置：2 × d_model，与 Transformer FFN 扩展比一致

#### d_state（状态维度）

  • 含义：SSM 隐状态 h_t 的维度
  • 类型：int
  • 默认值：16（Mamba 论文默认）
  • 取值范围：8-256
  • 对结果的影响：
  • 大 → 记忆容量更大，能存储更多信息，但参数和计算量增加
  • 小 → 记忆容量有限，但更高效
  • 推荐设置：16 用于小模型，64-128 用于大模型

#### d_conv（局部卷积宽度）

  • 含义：Mamba block 中的 1D 因果卷积核大小，用于局部特征提取
  • 类型：int
  • 默认值：4
  • 对结果的影响：
  • 大 → 捕获更长范围的局部依赖，但计算量增加
  • 小 → 更短范围的局部建模
  • 推荐设置：4 是论文默认值，兼顾效率和局部建模

#### expand（扩展系数）

  • 含义：内部维度相对 d_model 的扩展倍数
  • 类型：int
  • 默认值：2
  • 对结果的影响：d_inner = expand × d_model，影响参数量和容量
  • 推荐设置：2 是标准设置

#### selective_scan（选择性扫描）

  • 含义：Mamba 的核心运算，高效实现输入相关的 SSM 递推
  • 类型：函数（硬件优化实现）
  • 对结果的影响：通过并行前缀扫描实现 O(n) 训练，比朴素 RNN 递推快数百倍
  • 注意：CUDA 实现针对 GPU 内存层次优化，PyTorch 原生实现较慢

代码示例

import torch
import torch.nn as nn
import torch.nn.functional as F
from einops import rearrange

class MambaBlock(nn.Module):
    """Mamba Block：选择性状态空间模型的核心模块"""

    def __init__(self, d_model, d_state=16, d_conv=4, expand=2):
        super().__init__()
        self.d_model = d_model              # 输入/输出维度
        self.d_state = d_state              # SSM 状态维度
        self.d_conv = d_conv                # 局部卷积核大小
        self.expand = expand                # 内部扩展系数
        self.d_inner = expand * d_model     # 内部维度

        # 1. 输入投影：d_model -> d_inner
        self.in_proj = nn.Linear(d_model, self.d_inner * 2, bias=False)
        # 投影后分为两路：x（主路）和 z（门控路）

        # 2. 局部卷积：提取局部特征
        self.conv1d = nn.Conv1d(
            in_channels=self.d_inner,       # 输入通道 = 内部维度
            out_channels=self.d_inner,      # 输出通道 = 内部维度
            kernel_size=d_conv,             # 卷积核大小
            padding=d_conv - 1,             # 因果卷积：只看过去
            groups=self.d_inner,            # 深度可分离卷积
            bias=True,
        )

        # 3. SSM 参数投影（选择性机制核心）
        # x -> Δ, B, C 三个输入相关参数
        self.x_proj = nn.Linear(self.d_inner, d_state * 2 + self.d_inner, bias=False)
        # 输出维度: d_state(B) + d_state(C) + d_inner(Δ)

        # 4. Δ 的可学习投影（初始化为均匀分布）
        self.dt_proj = nn.Linear(self.d_inner, self.d_inner, bias=True)
        # 初始化 dt_proj.bias 为 [dt_min, dt_max] 的均匀分布
        dt_init_std = 0.02
        nn.init.uniform_(self.dt_proj.weight, -dt_init_std, dt_init_std)
        dt_max = 0.1
        dt_min = 0.001
        nn.init.uniform_(self.dt_proj.bias, dt_min, dt_max)

        # 5. A_log（可学习参数）
        # 初始化为 HiPPO 矩阵的对角部分取对数
        A = torch.arange(1, d_state + 1, dtype=torch.float32)  # [1, 2, ..., d_state]
        A = A.repeat(self.d_inner, 1)       # (d_inner, d_state)
        self.A_log = nn.Parameter(torch.log(A))  # A = -exp(A_log) 保证负定

        # 6. D（跳跃连接，可学习标量）
        self.D = nn.Parameter(torch.ones(self.d_inner))

        # 7. 输出投影：d_inner -> d_model
        self.out_proj = nn.Linear(self.d_inner, d_model, bias=False)

    def forward(self, x):
        """前向传播
        x: (batch, seq_len, d_model) -> (batch, seq_len, d_model)
        """
        batch, seq_len, _ = x.shape

        # 1. 输入投影 + 分叉
        xz = self.in_proj(x)                # (B, L, 2*d_inner)
        x_main, z = xz.chunk(2, dim=-1)      # 各 (B, L, d_inner)

        # 2. 局部卷积 + SiLU 激活
        x_main = x_main.transpose(1, 2)     # (B, d_inner, L) for Conv1d
        x_main = self.conv1d(x_main)[:, :, :seq_len]  # 因果截断
        x_main = x_main.transpose(1, 2)     # (B, L, d_inner)
        x_main = F.silu(x_main)             # SiLU 激活

        # 3. 选择性参数生成（Mamba 核心）
        x_dbl = self.x_proj(x_main)          # (B, L, d_state*2 + d_inner)
        # 分割为 Δ, B, C
        delta = x_dbl[:, :, :self.d_inner]           # (B, L, d_inner)
        B = x_dbl[:, :, self.d_inner:self.d_inner + self.d_state]   # (B, L, d_state)
        C = x_dbl[:, :, -self.d_state:]              # (B, L, d_state)

        # Δ 通过投影 + softplus（保证正值）
        delta = F.softplus(self.dt_proj(delta))      # (B, L, d_inner)

        # 4. 选择性扫描（SSM 递推）
        # 获取 A
        A = -torch.exp(self.A_log)           # (d_inner, d_state)，负定矩阵

        y = self.selective_scan(x_main, delta, A, B, C, self.D)
        # y: (B, L, d_inner)

        # 5. 门控 + 输出投影
        y = y * F.silu(z)                    # 与 z 门控路相乘
        output = self.out_proj(y)            # (B, L, d_model)
        return output

    def selective_scan(self, x, delta, A, B, C, D):
        """选择性扫描（简化版，展示原理）
        实际使用 CUDA 优化的 mamba_ssm 包实现

        离散化：A_bar = exp(delta * A), B_bar = delta * B
        递推：h_t = A_bar * h_{t-1} + B_bar * x_t
        输出：y_t = C * h_t + D * x_t
        """
        batch, seq_len, d_inner = x.shape
        d_state = A.shape[1]

        h = torch.zeros(batch, d_inner, d_state, device=x.device)  # 初始隐状态
        outputs = []

        for t in range(seq_len):
            # 离散化（ZOH）
            dt = delta[:, t, :]              # (B, d_inner)
            A_bar = torch.exp(dt.unsqueeze(-1) * A.unsqueeze(0))  # (B, d_inner, d_state)
            B_bar = dt.unsqueeze(-1) * B[:, t, :].unsqueeze(1)    # (B, d_inner, d_state)

            # 状态更新
            h = A_bar * h + B_bar * x[:, t, :].unsqueeze(-1)  # (B, d_inner, d_state)

            # 输出
            y_t = (h * C[:, t, :].unsqueeze(1)).sum(-1) + D.unsqueeze(0) * x[:, t, :]
            # y_t: (B, d_inner)
            outputs.append(y_t)

        return torch.stack(outputs, dim=1)   # (B, L, d_inner)


class MambaModel(nn.Module):
    """完整的 Mamba 语言模型"""

    def __init__(self, vocab_size, d_model=768, n_layers=12, d_state=16, d_conv=4, expand=2):
        super().__init__()
        self.embedding = nn.Embedding(vocab_size, d_model)  # 词嵌入
        self.layers = nn.ModuleList([
            MambaBlock(d_model, d_state, d_conv, expand)    # 堆叠 Mamba Block
            for _ in range(n_layers)
        ])
        self.norm = nn.LayerNorm(d_model)                   # 最终层归一化
        self.lm_head = nn.Linear(d_model, vocab_size, bias=False)  # 语言模型输出头

    def forward(self, input_ids):
        """前向传播
        input_ids: (batch, seq_len) -> logits: (batch, seq_len, vocab_size)
        """
        x = self.embedding(input_ids)         # (B, L, d_model)
        for layer in self.layers:
            x = x + layer(x)                   # 残差连接 + Mamba Block
        x = self.norm(x)                        # 层归一化
        logits = self.lm_head(x)                # (B, L, vocab_size)
        return logits


# 使用示例
model = MambaModel(
    vocab_size=32000,                          # 词表大小
    d_model=768,                               # 模型维度（类似 BERT-base）
    n_layers=12,                               # 层数
    d_state=16,                                # SSM 状态维度
    d_conv=4,                                  # 局部卷积核
    expand=2,                                  # 扩展系数
)
print(f"参数量: {sum(p.numel() for p in model.parameters()) / 1e6:.1f}M")

# 前向传播
input_ids = torch.randint(0, 32000, (4, 512))  # batch=4, seq_len=512
logits = model(input_ids)
print(f"输入: {input_ids.shape}")
print(f"输出: {logits.shape}")                 # (4, 512, 32000)

复杂度分析

  • 训练复杂度：O(n·d²)，通过并行前缀扫描实现线性序列复杂度（Transformer 为 O(n²·d)）
  • 推理复杂度：O(1) 每步（RNN 式递推，只需前一步隐状态），无需 KV cache
  • 推理内存：O(d_state) 每层，远小于 Transformer 的 O(n·d) KV cache
  • 长序列优势：序列越长优势越大，100K token 时 Mamba 比 Transformer 快 5-10 倍
  • 并行扫描：利用 GPU 并行前缀扫描（associative scan）实现 O(log n) 深度的并行计算

应用场景

  • 长文本生成：超长上下文（100K+ token）的小说/文档生成，线性复杂度优势显著
  • 代码补全：超长代码文件的上下文理解（MambaCode）
  • DNA/基因组序列分析：超长生物序列建模
  • 时序预测：金融/传感器/天气的长序列预测
  • 语音识别：超长音频序列建模（替代 Conformer）
  • 替代 Transformer 的大模型：Jamba（AI21）将 Mamba 与 Transformer 混合，兼顾长短依赖
  • 视觉模型：Vision Mamba（Vim）用于图像分类和分割
