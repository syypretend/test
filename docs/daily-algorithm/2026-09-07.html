快速选择

类别：查找算法 | 难度：入门

搜索关键词：quickselect kth smallest partition hoare select median

原理

快速选择（Quickselect）由 Tony Hoare 于 1961 年提出，是快速排序的衍生算法。其核心思想是利用分治法，选取一个基准元素（pivot）将数组分为两部分，根据基准位置与目标位置 k 的关系，只递归处理其中一侧。由于每次只需处理一侧子数组，平均时间复杂度为 O(n)，远优于先排序再选择的 O(n log n)。

数学公式

递归时间复杂度推导：

$$ T(n) = T\left(\frac{n}{2}\right) + O(n) $$

变量解释：

  • $ T(n) $：处理规模为 $ n $ 的子数组所需时间
  • $ T\left(\frac{n}{2}\right) $：递归处理一侧子数组（约 $ n/2 $ 规模）的时间
  • $ O(n) $：当前层 partition 操作的线性扫描时间

展开求和：

$$ T(n) = n + \frac{n}{2} + \frac{n}{4} + \cdots + 1 = 2n = O(n) $$

最坏情况时间复杂度：

$$ T_{worst}(n) = T(n-1) + O(n) = \sum_{i=1}^{n} i = O(n^2) $$

空间复杂度：

$$ S(n) = O(\log n) $$

  • $ S(n) $：递归调用栈深度，平均每次将数组规模减半，栈深度为 $ \log_2 n $

核心要点

  • 基于快速排序的 partition 思想，但只递归一侧
  • 平均 O(n)，最坏 O(n²)（随机化 pivot 可极大降低概率）
  • 不需要完整排序，只需找到第 k 小/大元素
  • 原地操作，空间复杂度 O(log n)（递归栈）

技术细节与参数详解

#### 参数1：pivot 选取策略

  • 含义：选择数组中哪个元素作为分区基准
  • 类型：枚举策略
  • 默认值：取最后一个元素 arr[high]
  • 取值范围：固定首位 / 固定末位 / 随机选取 / 三数取中 / 中位数的中位数（BFPRT）
  • 对结果的影响：固定选取在已排序数组上会退化到 O(n²)；随机选取将最坏情况概率降至极低
  • 推荐设置：随机选取 random.choice(arr) 或三数取中法

#### 参数2：k（目标位置）

  • 含义：要查找的第 k 小元素的位置（0-indexed）
  • 类型：整数
  • 默认值：无（由调用者指定）
  • 取值范围：$ 0 \le k < n $（n 为数组长度）
  • 对结果的影响：k=0 返回最小值，k=n-1 返回最大值，k=n//2 返回中位数
  • 推荐设置：根据业务需求设定，求中位数时 k = len(arr) // 2

#### 参数3：partition 方式

  • 含义：分区函数的实现方式
  • 类型：枚举（Lomuto / Hoare）
  • 默认值：Lomuto 分区（单指针，实现简单）
  • 取值范围：Lomuto 分区 / Hoare 分区（双指针，交换次数更少）
  • 对结果的影响：Hoare 分区平均交换次数更少，实际运行更快；Lomuto 实现更简洁
  • 推荐设置：性能敏感场景用 Hoare，教学/简单场景用 Lomuto

代码示例

import random  # 导入随机数模块，用于随机选取 pivot

def partition(arr, low, high):
    """Lomuto 分区函数，将数组分为 <=pivot 和 >pivot 两部分"""
    pivot = arr[high]  # 选取最后一个元素作为基准
    i = low - 1       # i 指向"小于 pivot 区域"的右边界
    for j in range(low, high):  # 遍历 low 到 high-1 的所有元素
        if arr[j] <= pivot:     # 如果当前元素小于等于 pivot
            i += 1              # 扩展小于 pivot 的区域
            arr[i], arr[j] = arr[j], arr[i]  # 交换，把小元素放到左侧
    arr[i + 1], arr[high] = arr[high], arr[i + 1]  # 将 pivot 放到正确位置
    return i + 1  # 返回 pivot 的最终位置索引

def quickselect(arr, low, high, k):
    """快速选择主函数：在 arr[low..high] 中找第 k 小元素"""
    if low == high:        # 递归终止：只有一个元素
        return arr[low]     # 直接返回该元素

    # 随机选取 pivot 并交换到末尾，避免最坏情况
    rand_idx = random.randint(low, high)    # 随机选一个索引
    arr[rand_idx], arr[high] = arr[high], arr[rand_idx]  # 交换到 high 位置

    pivot_idx = partition(arr, low, high)  # 分区，获取 pivot 最终位置

    if k == pivot_idx:        # pivot 恰好在目标位置
        return arr[k]         # 找到了，返回结果
    elif k < pivot_idx:       # 目标在 pivot 左侧
        return quickselect(arr, low, pivot_idx - 1, k)  # 只递归左半部分
    else:                     # 目标在 pivot 右侧
        return quickselect(arr, pivot_idx + 1, high, k) # 只递归右半部分

# 使用示例
arr = [3, 1, 4, 1, 5, 9, 2, 6, 5, 3, 5]  # 测试数组
k = 5                                     # 找第 6 小元素（0-indexed）
result = quickselect(arr, 0, len(arr) - 1, k)  # 调用快速选择
print(f"第 {k+1} 小的元素是: {result}")        # 输出结果

复杂度分析

  • 时间复杂度（平均）：$ O(n) $ — 每层 partition 扫描 $ n $，递归深度 $ \log n $，但总工作量为 $ n + n/2 + n/4 + \cdots = 2n $
  • 时间复杂度（最坏）：$ O(n^2) $ — 每次只减少 1 个元素，需 $ n $ 层递归，每层扫描 $ n, n-1, \cdots, 1 $
  • 空间复杂度：$ O(\log n) $ — 递归调用栈平均深度

应用场景

  • 求无序数组的中位数（k = n/2）
  • Top-K 问题（求最大/最小的 K 个元素）
  • 统计学中的百分位数计算
  • 数据库查询中的 ORDER BY LIMIT 优化

交叉熵损失

类别：损失函数 | 难度：入门

搜索关键词：cross entropy loss nn.CrossEntropyLoss weight ignore_index reduction label_smoothing softmax logits target

原理

交叉熵损失（Cross-Entropy Loss）是分类任务中最常用的损失函数。它衡量模型预测的概率分布与真实标签分布之间的差异。结合 Softmax 函数，它将神经网络输出 logits 转换为概率分布，再与真实标签计算交叉熵。PyTorch 的 nn.CrossEntropyLoss 内部将 LogSoftmax 和 NLLLoss 合并，数值稳定性更好。

数学公式

Softmax 函数：

$$ \text{Softmax}(z_i) = \frac{e^{z_i}}{\sum_{j=1}^{C} e^{z_j}} $$

变量解释：

  • $ z_i $：第 $ i $ 个类别的 logit（未归一化的网络输出）
  • $ C $：类别总数
  • $ e^{z_i} $：将 logit 转为正数，保证概率非负
  • 分母 $ \sum_{j=1}^{C} e^{z_j} $：归一化因子，保证所有概率之和为 1

交叉熵损失（多分类）：

$$ \mathcal{L} = -\frac{1}{N}\sum_{i=1}^{N}\sum_{c=1}^{C} y_{i,c} \cdot \log(\hat{y}_{i,c}) $$

变量解释：

  • $ N $：样本总数（batch size）
  • $ C $：类别总数
  • $ y_{i,c} $：第 $ i $ 个样本的真实标签（one-hot 编码，正确类别为 1，其余为 0）
  • $ \hat{y}_{i,c} $：模型对第 $ i $ 个样本预测为类别 $ c $ 的概率（Softmax 输出）
  • 负号：将最大化概率转化为最小化损失

二分类交叉熵（BCE）：

$$ \mathcal{L}_{BCE} = -\frac{1}{N}\sum_{i=1}^{N}\left[y_i \log(\hat{y}_i) + (1-y_i)\log(1-\hat{y}_i)\right] $$

变量解释：

  • $ y_i $：第 $ i $ 个样本的真实标签（0 或 1）
  • $ \hat{y}_i $：模型预测为正类的概率（Sigmoid 输出，范围 $ (0,1) $）
  • $ (1-y_i)\log(1-\hat{y}_i) $：负类样本的损失项

带标签平滑的交叉熵：

$$ \mathcal{L}_{smooth} = -\sum_{c=1}^{C}\left[(1-\epsilon)\cdot y_c + \frac{\epsilon}{C}\right]\log(\hat{y}_c) $$

变量解释：

  • $ \epsilon $：平滑系数（通常取 0.1），表示对真实标签的不确定度
  • $ (1-\epsilon)\cdot y_c + \frac{\epsilon}{C} $：平滑后的软标签，正确类别权重降为 $ 1-\epsilon $，其余类别分配 $ \epsilon/C $
  • 效果：防止模型过度自信，提升泛化能力

核心要点

  • 结合了 Softmax + NLLLoss，数值稳定（使用 LogSumExp 技巧）
  • 适用于多分类任务，预测值越大、真实标签对应类别概率越高则损失越小
  • 标签平滑可防止过拟合，提升模型泛化
  • 梯度推导结果简洁：$ \frac{\partial \mathcal{L}}{\partial z_i} = \hat{y}_i - y_i $（Softmax 输出减去 one-hot 标签）

技术细节与参数详解

#### 参数1：weight

  • 含义：为每个类别分配权重，用于处理类别不平衡问题
  • 类型：Tensor（1D，长度为类别数 C）
  • 默认值：None（所有类别权重相同）
  • 取值范围：正浮点数，通常根据类别频率的反比设置
  • 对结果的影响：稀有类别获得更大权重，模型更关注少数类；权重过大可能导致过拟合
  • 推荐设置：$ w_c = \frac{N}{C \cdot n_c} $（$ n_c $ 为类别 c 的样本数）

#### 参数2：ignore_index

  • 含义：指定一个标签值，该值对应的样本不参与损失计算
  • 类型：整数
  • 默认值：-100
  • 取值范围：任意整数，通常用 -100 避免与合法类别标签冲突
  • 对结果的影响：用于忽略 padding 位置或无标注样本，使损失只计算有效位置
  • 推荐设置：NLP 任务中 padding token 的 label 设为 -100

#### 参数3：reduction

  • 含义：指定如何对 batch 内所有样本的损失进行聚合
  • 类型：字符串枚举
  • 默认值：'mean'
  • 取值范围：'none'（返回每个样本的损失）/ 'mean'（返回平均值）/ 'sum'（返回总和）
  • 对结果的影响：'mean' 对 batch 大小不敏感；'sum' 在大 batch 时梯度更大；'none' 用于自定义聚合
  • 推荐设置：训练时用 'mean'，调试分析时用 'none'

#### 参数4：label_smoothing

  • 含义：标签平滑系数，将 hard label 软化为 soft label
  • 类型：浮点数
  • 默认值：0.0（不启用）
  • 取值范围：$ [0, 1) $
  • 对结果的影响：0.1 是常用值，能提升泛化但可能略微降低训练准确率；值过大（>0.3）会导致欠拟合
  • 推荐设置：图像分类 0.1，NLP 翻译 0.1，大模型预训练 0.1

代码示例

import torch                      # 导入 PyTorch
import torch.nn as nn             # 导入神经网络模块

# 创建 CrossEntropyLoss 实例，启用标签平滑
criterion = nn.CrossEntropyLoss(  # 实例化交叉熵损失函数
    weight=None,                  # 不设置类别权重
    ignore_index=-100,            # 忽略标签为 -100 的样本
    reduction='mean',             # 对 batch 内损失取平均
    label_smoothing=0.1,          # 标签平滑系数 0.1
)

# 模拟模型输出（logits，未经过 Softmax）
logits = torch.tensor([           # 3 个样本，5 个类别
    [2.1, 0.5, -1.0, 0.3, 0.1],   # 样本1的原始输出
    [0.1, 3.2, 0.0, -0.5, 0.2],   # 样本2的原始输出
    [-0.3, 0.1, 2.8, 0.4, 0.0],   # 样本3的原始输出
])

# 真实标签（类别索引）
targets = torch.tensor([0, 1, 2]) # 3个样本分别属于类别0、1、2

# 计算损失
loss = criterion(logits, targets) # 前向计算交叉熵损失
print(f"Loss: {loss.item():.4f}")  # 打印损失值

# 反向传播
loss.backward()                    # 自动计算梯度

# 梯度等于 Softmax输出 - OneHot标签
print(f"Logits grad: {logits.grad}") # 查看梯度值

复杂度分析

  • 时间复杂度：$ O(N \times C) $ — $ N $ 为 batch size，$ C $ 为类别数，需对每个样本计算 Softmax 和 log
  • 空间复杂度：$ O(N \times C) $ — 存储中间的 Softmax 概率矩阵

应用场景

  • 图像分类（ImageNet, ResNet, ViT）
  • 自然语言处理（BERT, GPT 的语言模型损失）
  • 语音识别（CTC + CrossEntropy）
  • 多标签分类（使用 BCEWithLogitsLoss 变体）

Mamba 状态空间模型

类别：前沿架构 | 难度：困难

搜索关键词：Mamba state space model SSM selective scan A_log D dt hidden state RCALG input-dependent linear time invariant

原理

Mamba 是 2023 年提出的选择性状态空间模型（Selective SSM, S6），被视为 Transformer 的有力竞争者。它源于控制理论中的状态空间模型（SSM），通过选择性扫描机制（Selective Scan）让模型根据输入内容动态决定哪些信息保留在隐藏状态中、哪些遗忘。相比 Transformer 的注意力机制，Mamba 在长序列建模中实现了线性时间复杂度 O(n)，同时保持了与 Transformer 相当甚至更优的性能。

数学公式

连续时间 SSM 状态方程：

$$ h'(t) = A \cdot h(t) + B \cdot x(t) $$

变量解释：

  • $ h(t) $：时刻 $ t $ 的隐藏状态（hidden state）
  • $ h'(t) $：隐藏状态的时间导数
  • $ A $：状态转移矩阵（控制状态如何随时间演化）
  • $ B $：输入矩阵（控制输入如何影响状态）
  • $ x(t) $：时刻 $ t $ 的输入信号

连续时间 SSM 输出方程：

$$ y(t) = C \cdot h(t) + D \cdot x(t) $$

变量解释：

  • $ y(t) $：时刻 $ t $ 的输出
  • $ C $：输出矩阵（控制状态如何映射到输出）
  • $ D $：跳跃连接（skip connection），通常设为 1，保证残差连接

离散化（Zero-Order Hold 方法）：

$$ \bar{A} = e^{\Delta A}, \quad \bar{B} = (\Delta A)^{-1}(e^{\Delta A} - I) \cdot \Delta B $$

变量解释：

  • $ \Delta $：离散化步长（sampling interval），控制状态更新的粒度
  • $ \bar{A}, \bar{B} $：离散化后的状态矩阵和输入矩阵
  • $ e^{\Delta A} $：矩阵指数，通过泰勒展开或结构化近似计算

离散递推形式：

$$ h_t = \bar{A} \cdot h_{t-1} + \bar{B} \cdot x_t $$

$$ y_t = C \cdot h_t + D \cdot x_t $$

变量解释：

  • $ h_t $：第 $ t $ 步的离散隐藏状态
  • $ h_{t-1} $：上一步的隐藏状态
  • $ x_t $：第 $ t $ 步的输入 token

Mamba 选择性机制（核心创新）：

$$ B_t = \text{Linear}_B(x_t), \quad C_t = \text{Linear}_C(x_t), \quad \Delta_t = \text{softplus}(\text{Linear}_{\Delta}(x_t)) $$

变量解释：

  • $ B_t, C_t $：输入依赖的矩阵（不再是固定参数，而是根据当前输入 $ x_t $ 动态生成）
  • $ \Delta_t $：输入依赖的离散化步长（决定当前 token 对状态更新的影响强度）
  • $ \text{softplus} $：$ \text{softplus}(z) = \log(1 + e^z) $，保证 $ \Delta_t > 0 $

选择性扫描递推：

$$ h_t = \bar{A}_t \cdot h_{t-1} + \bar{B}_t \cdot x_t $$

$$ \bar{A}_t = \exp(\Delta_t \cdot A), \quad \bar{B}_t = \Delta_t \cdot B_t $$

变量解释：

  • $ \bar{A}_t $：输入依赖的离散化状态矩阵，每个位置 $ t $ 的 $ \bar{A} $ 不同
  • $ \bar{B}_t $：输入依赖的离散化输入矩阵
  • 核心：由于 $ \bar{A}_t, \bar{B}_t $ 依赖 $ x_t $，无法用全局卷积计算，必须用顺序扫描

核心要点

  • 从固定参数 SSM（S4）到输入依赖 SSM（Mamba/S6）的关键跃迁
  • 选择性机制让模型根据内容决定保留/遗忘信息，类似 LSTM 的门控但更高效
  • 线性时间复杂度 $ O(n) $，推理时类似 RNN 逐 token 生成，无需 KV Cache
  • 硬件感知并行扫描（Hardware-Aware Scan）利用 GPU SRAM 加速
  • 参数 $ A $ 初始化为 HiPPO 矩阵，赋予长程记忆能力

技术细节与参数详解

#### 参数1：d_model（模型维度）

  • 含义：输入 token 的嵌入维度，也是残差流的宽度
  • 类型：整数
  • 默认值：无（由配置指定）
  • 取值范围：通常 256 ~ 8192
  • 对结果的影响：越大模型容量越强但计算量和显存增加；过小导致欠拟合
  • 推荐设置：小型模型 512，中型 1024，大型 2048

#### 参数2：d_state（状态维度）

  • 含义：SSM 隐藏状态 $ h_t $ 的维度（即矩阵 $ A $ 的维度 $ N \times N $ 中的 $ N $）
  • 类型：整数
  • 默认值：16
  • 取值范围：8 ~ 256
  • 对结果的影响：越大记忆容量越强，能捕获更长距离依赖；但计算量随 $ N $ 线性增长
  • 推荐设置：16（论文默认），长序列任务可增大到 64~128

#### 参数3：d_conv（卷积宽度）

  • 含义：局部卷积的核大小，用于捕获短距离依赖
  • 类型：整数
  • 默认值：4
  • 取值范围：2 ~ 8
  • 对结果的影响：在 SSM 之前进行短距离特征提取；过大会增加计算但收益递减
  • 推荐设置：4（论文默认值）

#### 参数4：expand（扩展因子）

  • 含义：MLP/SSM 模块的内部扩展比例，决定隐藏层宽度
  • 类型：整数
  • 默认值：2
  • 取值范围：1 ~ 8
  • 对结果的影响：expand=2 表示内部维度为 2×d_model，越大模型非线性能力越强但参数翻倍
  • 推荐设置：2（Mamba 论文默认）

#### 参数5：A_init（A 矩阵初始化）

  • 含义：状态转移矩阵 A 的初始化方式
  • 类型：枚举
  • 默认值：HiPPO 矩阵
  • 取值范围：HiPPO / 随机 / 对角矩阵
  • 对结果的影响：HiPPO 矩阵赋予模型对历史信息的正交记忆基，能捕获长程依赖；随机初始化需更长训练
  • 推荐设置：HiPPO（论文默认）

#### 参数6：dt_init（Δ 初始化范围）

  • 含义：离散化步长 $ \Delta $ 的初始化范围
  • 类型：字符串枚举
  • 默认值：'random'
  • 取值范围：'random' / 'constant'
  • 对结果的影响：$ \Delta $ 控制时间尺度，初始化范围决定了模型初始时关注的时间粒度
  • 推荐设置：'random'，范围 $ [0.001, 0.1] $（论文设置）

代码示例

import torch                                            # 导入 PyTorch
import torch.nn as nn                                    # 导入神经网络模块
import torch.nn.functional as F                          # 导入函数式接口
import math                                              # 导入数学模块

class SimpleMambaBlock(nn.Module):                        # 定义简化的 Mamba Block
    def __init__(self, d_model, d_state=16, d_conv=4, expand=2):
        super().__init__()                               # 调用父类初始化
        self.d_model = d_model                           # 保存模型维度
        self.d_state = d_state                           # 保存状态维度
        self.d_inner = d_model * expand                   # 内部扩展维度
        self.d_conv = d_conv                              # 卷积核宽度

        # 输入投影：d_model -> d_inner * 2（分为两个分支）
        self.in_proj = nn.Linear(d_model, self.d_inner * 2, bias=False)

        # 局部卷积：捕获短距离依赖
        self.conv = nn.Conv1d(                           # 1D 卷积层
            in_channels=self.d_inner,                    # 输入通道 = 内部维度
            out_channels=self.d_inner,                   # 输出通道 = 内部维度
            kernel_size=d_conv,                           # 卷积核大小
            padding=d_conv - 1,                           # 因果卷积，左 padding
            groups=self.d_inner,                          # 深度可分离卷积
            bias=True,
        )

        # SSM 参数投影（选择性机制核心）
        self.x_proj = nn.Linear(                          # 输入依赖参数生成
            self.d_inner, d_state * 2 + 1, bias=False     # 生成 B, C, dt
        )

        # A 矩阵（可学习参数，log 参数化保证负实部）
        A = torch.arange(1, d_state + 1, dtype=torch.float32)  # HiPPO 简化初始化
        A = A.unsqueeze(0).expand(self.d_inner, -1)       # 扩展到 d_inner 维
        self.A_log = nn.Parameter(torch.log(A))           # log 参数化，训练时取 exp

        # D 参数（跳跃连接）
        self.D = nn.Parameter(torch.ones(self.d_inner))    # 残差连接权重

        # 输出投影：d_inner -> d_model
        self.out_proj = nn.Linear(self.d_inner, d_model, bias=False)

    def forward(self, x):
        """x: (batch, seq_len, d_model) -> (batch, seq_len, d_model)"""
        batch, seq_len, _ = x.shape                        # 获取输入形状

        # 1. 输入投影并分为两个分支
        xz = self.in_proj(x)                               # (batch, seq, d_inner*2)
        x_branch, z = xz.chunk(2, dim=-1)                 # 分为 x 和 z 分支

        # 2. 局部卷积 + SiLU 激活
        x_branch = x_branch.transpose(1, 2)                # (batch, d_inner, seq)
        x_branch = self.conv(x_branch)[:, :, :seq_len]    # 因果卷积裁剪
        x_branch = x_branch.transpose(1, 2)                # (batch, seq, d_inner)
        x_branch = F.silu(x_branch)                        # SiLU 激活函数

        # 3. 选择性 SSM 扫描
        A = -torch.exp(self.A_log)                         # 从 log 恢复 A，保证负实部
        D = self.D                                         # 跳跃连接参数

        # 生成输入依赖的 B, C, dt
        x_dbl = self.x_proj(x_branch)                      # (batch, seq, d_state*2+1)
        B_t = x_dbl[..., :self.d_state]                   # B_t: (batch, seq, d_state)
        C_t = x_dbl[..., self.d_state:2*self.d_state]     # C_t: (batch, seq, d_state)
        dt_t = F.softplus(x_dbl[..., -1])                 # Δ_t: (batch, seq, 1), >0

        # 离散化 + 顺序扫描
        h = torch.zeros(batch, self.d_inner, self.d_state, device=x.device)  # 初始状态
        outputs = []                                       # 收集每步输出

        for t in range(seq_len):                           # 顺序扫描每个时间步
            dt = dt_t[:, t, :]                             # 当前步的 Δ: (batch, 1)
            dA = torch.exp(dt.unsqueeze(-1) * A)           # 离散化 A: (batch, d_inner, d_state)
            dB = dt.unsqueeze(-1) * B_t[:, t, :].unsqueeze(1)  # 离散化 B: (batch, d_inner, d_state)

            h = dA * h + dB * x_branch[:, t, :].unsqueeze(-1)  # 状态更新: h_t = Ā·h + B̄·x
            y_t = torch.sum(h * C_t[:, t, :].unsqueeze(1), dim=-1)  # 输出: C·h
            y_t = y_t + D * x_branch[:, t, :]              # 加上跳跃连接 D·x
            outputs.append(y_t)                            # 保存当前步输出

        y = torch.stack(outputs, dim=1)                    # (batch, seq, d_inner)

        # 4. 门控 + 输出投影
        y = y * F.silu(z)                                  # 用 z 分支门控
        output = self.out_proj(y)                         # 投影回 d_model
        return output                                      # 返回结果

# 使用示例
mamba = SimpleMambaBlock(d_model=512, d_state=16)        # 创建 Mamba Block
x = torch.randn(2, 100, 512)                              # 模拟输入: batch=2, seq=100, dim=512
y = mamba(x)                                              # 前向传播
print(f"Input shape: {x.shape}")                          # 打印输入形状
print(f"Output shape: {y.shape}")                          # 打印输出形状

复杂度分析

  • 训练时间复杂度：$ O(n \cdot d \cdot N) $ — $ n $ 为序列长度，$ d $ 为模型维度，$ N $ 为状态维度；利用并行扫描可优化
  • 推理时间复杂度：$ O(n \cdot d \cdot N) $ — 逐 token 生成，每步 $ O(d \cdot N) $，无 KV Cache 开销
  • 空间复杂度：$ O(n \cdot d \cdot N) $ — 训练时需存储中间状态用于反向传播（或用重计算策略降为 $ O(d \cdot N) $）
  • 对比 Transformer：推理时 Transformer 需 $ O(n^2 \cdot d) $ 的 KV Cache，Mamba 只需 $ O(d \cdot N) $ 的固定状态

应用场景

  • 长文本语言建模（DNA 序列、音频、长文档）
  • 替代 Transformer 的大模型骨干网络（Mamba-2.8B, Jamba）
  • 语音识别与生成（长序列建模优势）
  • 时间序列预测（金融、气象、传感器数据）
  • 视频理解（长帧序列建模）
