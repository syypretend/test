快速选择

类别：查找算法 | 难度：入门

算法简介

快速选择（Quickselect）是一种基于分治思想的选择算法，用于在无序数组中查找第 K 小（或第 K 大）的元素。它由 Tony Hoare 于 1961 年提出，与快速排序同源，但关键区别在于：快速排序需要对整个数组完全排序（O(n log n)），而快速选择只需递归处理包含目标元素的一侧子区间，平均时间复杂度仅为 O(n)。

原理示意图

核心原理

快速选择的核心操作是 分区（Partition）：

1. 从数组中选择一个基准元素（pivot）

2. 将数组分为两部分：小于 pivot 的元素放在左边，大于 pivot 的放在右边

3. 此时 pivot 处于其最终排序位置（索引 p）

4. 比较 p 与目标索引 k：

  • 若 p == k，直接返回 pivot（找到第 K 小元素）
  • 若 p > k，在左子区间递归查找
  • 若 p < k，在右子区间递归查找

由于每次只递归一侧（不像快速排序两侧都递归），平均时间复杂度为 $ O(n) $。

数学公式

期望时间复杂度递推式：

$$ T(n) = T(n/2) + O(n) $$

其中 $ T(n) $ 是处理规模为 $ n $ 的数组所需期望时间，$ T(n/2) $ 是递归一侧子区间的时间，$ O(n) $ 是分区操作的时间。由主定理可得 $ T(n) = O(n) $。

最坏情况时间复杂度：

$$ T_{worst}(n) = T(n-1) + O(n) = O(n^2) $$

最坏情况发生在每次 pivot 都选到最大或最小元素时（如已排序数组选第一个元素为 pivot）。通过随机化 pivot 选择，可以将最坏情况概率降到极低。

空间复杂度：

$$ S(n) = O(\log n) $$

递归栈深度，平均情况下为 $ O(\log n) $。

代码实现

import random

def quickselect(arr, k, left=0, right=None):
    """
    在无序数组中查找第 k 小的元素（0-indexed）
    
    参数:
        arr:  待查找的无序数组
        k:    目标排序位置（0表示最小元素）
        left: 当前区间左边界
        right: 当前区间右边界
    返回:
        第 k 小的元素值
    """
    if right is None:
        right = len(arr) - 1                    # 初始化右边界为数组末尾索引

    if left == right:
        return arr[left]                        # 区间只有一个元素，直接返回

    # 随机选择 pivot，避免最坏情况
    pivot_idx = random.randint(left, right)     # 在 [left, right] 范围内随机选一个索引
    arr[pivot_idx], arr[right] = arr[right], arr[pivot_idx]  # 将 pivot 交换到区间最右端

    # Lomuto 分区方案
    store_idx = left                            # store_idx 指向下一个"小于 pivot"的元素应放置的位置
    for i in range(left, right):                # 遍历区间内除 pivot 外的所有元素
        if arr[i] < arr[right]:                 # 当前元素小于 pivot
            arr[store_idx], arr[i] = arr[i], arr[store_idx]  # 将其交换到 store_idx 位置
            store_idx += 1                      # store_idx 右移一位

    # 将 pivot 放到最终位置
    arr[store_idx], arr[right] = arr[right], arr[store_idx]  # pivot 现在在 store_idx，左侧都小于它

    # 比较 pivot 位置与目标 k
    if store_idx == k:
        return arr[store_idx]                   # pivot 恰好在第 k 个位置，找到了！
    elif store_idx < k:
        return quickselect(arr, k, store_idx + 1, right)   # pivot 位置偏左，在右半部分递归
    else:
        return quickselect(arr, k, left, store_idx - 1)   # pivot 位置偏右，在左半部分递归


# 使用示例
data = [7, 10, 4, 3, 20, 15]                   # 原始无序数组
result = quickselect(data, 2)                  # 查找第 3 小的元素（k=2，0-indexed）
print(f"第 3 小的元素是: {result}")             # 输出: 第 3 小的元素是: 7

  • 数据库查询：实现 ORDER BY ... LIMIT K 的高效执行计划
  • 统计学：计算百分位数、四分位数等统计量
  • 数据流分析：在数据流中维护第 K 大/小的元素

交叉熵损失

类别：损失函数 | 难度：入门

算法简介

交叉熵损失（Cross-Entropy Loss）是深度学习中最常用的多分类损失函数。它衡量模型输出的概率分布与真实标签分布之间的差异：预测越接近真实标签，损失越小；预测越偏离，损失越大。PyTorch 中 nn.CrossEntropyLoss 内部组合了 LogSoftmax 和 NLLLoss，直接接收 logits（未归一化的原始输出），无需手动添加 softmax 层。

原理示意图

核心原理

交叉熵源于信息论，度量两个概率分布 $ p $ 和 $ q $ 的差异：

  • $ p $ 是真实标签的分布（one-hot 编码，即正确类别概率为 1，其余为 0）
  • $ q $ 是模型预测的概率分布（通过 softmax 将 logits 转换为概率）

交叉熵越小，两个分布越接近，模型预测越准确。PyTorch 的 CrossEntropyLoss 先对 logits 做 softmax 得到概率 $ q $，再取对数，最后与真实标签做负对数似然（NLL）。

数学公式

交叉熵公式（多分类）：

$$ H(p, q) = -\sum_{i=1}^{C} p_i \log(q_i) $$

其中 $ C $ 是类别数，$ p_i $ 是真实分布中第 $ i $ 类的概率（one-hot 编码下只有正确类别为 1），$ q_i $ 是模型预测的第 $ i $ 类概率。

Softmax 函数：

$$ q_i = \text{softmax}(z_i) = \frac{\exp(z_i)}{\sum_{j=1}^{C} \exp(z_j)} $$

其中 $ z_i $ 是第 $ i $ 类的 logit 值（原始未归一化输出），$ \exp(z_i) $ 将其转换为正数，分母对所有类别求和实现归一化。

实际计算（one-hot 标签简化）：

$$ L = -\log(q_y) $$

其中 $ y $ 是真实标签的类别索引，$ q_y $ 是模型对正确类别预测的概率。由于 one-hot 编码中只有正确类别 $ p_y = 1 $，其余类别 $ p_i = 0 $，交叉熵公式简化为只取正确类别的负对数概率。

带标签平滑的交叉熵：

$$ L = -(1-\epsilon) \log(q_y) - \frac{\epsilon}{C} \sum_{i=1}^{C} \log(q_i) $$

其中 $ \epsilon $ 是平滑因子，$ C $ 是类别数。标签平滑将硬标签 $ [1, 0, 0] $ 软化为 $ [1-\epsilon+\frac{\epsilon}{C}, \frac{\epsilon}{C}, \frac{\epsilon}{C}] $，防止模型过度自信，提高泛化能力。

代码实现

import torch
import torch.nn as nn

# === 基础用法 ===
logits = torch.tensor([[2.0, 1.0, 0.1],   # 样本1的3类原始输出（logits）
                        [0.5, 3.0, 0.2]])   # 样本2的3类原始输出（logits）
labels = torch.tensor([0, 1])               # 真实标签：样本1属于类0，样本2属于类1

# 创建交叉熵损失函数
criterion = nn.CrossEntropyLoss()            # 默认参数：无权重、无平滑、mean 聚合

# 计算损失（内部自动做 softmax + NLL）
loss = criterion(logits, labels)            # logits 不需要手动 softmax
print(f"Loss: {loss.item():.4f}")            # 输出损失值，如 0.4823

# === 带类别权重（处理类别不平衡）===
weights = torch.tensor([1.0, 1.0, 3.0])      # 类别0和1权重为1，类别2权重为3（少数类加权）
criterion_weighted = nn.CrossEntropyLoss(weight=weights)  # 少数类损失放大3倍
loss_weighted = criterion_weighted(logits, labels)        # 加权后的损失
print(f"Weighted Loss: {loss_weighted.item():.4f}")

# === 带标签平滑 ===
criterion_smooth = nn.CrossEntropyLoss(label_smoothing=0.1)  # 标签平滑系数0.1
loss_smooth = criterion_smooth(logits, labels)                 # 平滑后的损失
print(f"Smoothed Loss: {loss_smooth.item():.4f}")

# === 忽略填充位置（NLP场景常见）===
logits_padded = torch.tensor([[2.0, 1.0, 0.1],
                               [0.5, 3.0, 0.2],
                               [1.0, 0.8, 0.5]])    # 第3个样本是填充
labels_padded = torch.tensor([0, 1, -100])            # -100 标记填充位置
criterion_ignore = nn.CrossEntropyLoss(ignore_index=-100)  # 忽略 -100 标记的样本
loss_ignore = criterion_ignore(logits_padded, labels_padded)  # 只计算前2个样本的损失
print(f"Ignored Loss: {loss_ignore.item():.4f}")

Mamba 状态空间模型

类别：前沿架构 | 难度：困难

算法简介

Mamba 是 Albert Gu 和 Tri Dao 于 2023 年提出的新型序列建模架构，基于状态空间模型（State Space Model, SSM），通过选择性扫描（Selective Scan）机制实现了线性时间复杂度 $ O(n) $ 的长序列建模。与 Transformer 的二次复杂度 $ O(n^2) $ 相比，Mamba 在处理超长序列（如 100K+ token）时具有显著的推理速度和内存优势，同时保持了与 Transformer 相当的建模质量。

Mamba 的核心创新在于：传统 SSM 是线性时不变（LTI）系统，参数固定不变，无法根据输入内容选择性记忆；Mamba 引入了输入依赖的参数化，使模型能够根据当前输入动态决定"记住什么、遗忘什么"，类似于 LSTM 的门控机制但更高效。

原理示意图

核心原理

Mamba 的核心包含三个关键组件：

1. 连续状态空间方程（S4 基础）

状态空间模型将一维序列映射到隐藏状态，再由隐藏状态映射到输出，通过连续微分方程描述：

$$ h'(t) = Ah(t) + Bx(t), \quad y(t) = Ch(t) + Dx(t) $$

其中 $ h(t) $ 是隐藏状态，$ x(t) $ 是输入，$ y(t) $ 是输出，$ A, B, C, D $ 是可学习参数矩阵。

2. 离散化（Zero-Order Hold）

通过零阶保持（ZOH）将连续方程离散化，使其可处理离散序列：

$$ \bar{A} = \exp(\Delta A), \quad \bar{B} = (\Delta A)^{-1}(\exp(\Delta A) - I) \cdot \Delta B $$

其中 $ \Delta $ 是离散化步长（可学习的时间尺度参数），$ \bar{A}, \bar{B} $ 是离散化后的参数。

3. 选择性扫描（Mamba 核心创新）

Mamba 的关键突破是让 $ B, C, \Delta $ 参数依赖于输入 $ x_t $（而非固定不变）：

  • 传统 SSM（S4）：$ A, B, C, \Delta $ 是固定参数，与输入无关（LTI 系统）
  • Mamba：$ B(x_t), C(x_t), \Delta(x_t) $ 通过线性投影从当前输入 $ x_t $ 计算，使模型能根据输入内容动态调整状态更新

这打破了 LTI 约束，使 Mamba 具备了选择性——对重要信息保留更多、对无关信息遗忘更快。

数学公式

连续状态空间方程（SSM 基础）：

$$ h'(t) = Ah(t) + Bx(t), \quad y(t) = Ch(t) + Dx(t) $$

其中 $ h(t) \in \mathbb{R}^N $ 是 $ N $ 维隐藏状态，$ x(t) \in \mathbb{R} $ 是标量输入，$ y(t) \in \mathbb{R} $ 是标量输出，$ A \in \mathbb{R}^{N \times N} $ 是状态转移矩阵，$ B \in \mathbb{R}^{N \times 1} $ 是输入映射矩阵，$ C \in \mathbb{R}^{1 \times N} $ 是输出映射矩阵，$ D $ 是跳跃连接（通常设为可学习或 0）。

离散化（ZOH 方法）：

$$ \bar{A} = \exp(\Delta A), \quad \bar{B} = (\Delta A)^{-1}(\exp(\Delta A) - I) \cdot \Delta B $$

其中 $ \Delta \in \mathbb{R}^+ $ 是离散化步长（时间尺度），$ \exp(\cdot) $ 是矩阵指数，$ \bar{A}, \bar{B} $ 是离散化后的参数矩阵。$ \Delta $ 控制了模型对历史信息的"压缩率"：$ \Delta $ 大则关注远距离依赖，$ \Delta $ 小则关注局部细节。

离散递推方程：

$$ h_t = \bar{A} h_{t-1} + \bar{B} x_t, \quad y_t = C h_t + D x_t $$

其中 $ h_t $ 是第 $ t $ 步的隐藏状态，$ h_{t-1} $ 是上一步隐藏状态，$ x_t $ 是当前输入。$ \bar{A} $ 决定了历史信息的保留程度，$ \bar{B} $ 决定了新信息的写入程度。

Mamba 选择性参数化（核心创新）：

$$ B_t = \text{Linear}_B(x_t), \quad C_t = \text{Linear}_C(x_t), \quad \Delta_t = \text{softplus}(\text{Linear}_\Delta(x_t)) $$

其中 $ B_t, C_t, \Delta_t $ 均通过线性投影从当前输入 $ x_t $ 计算得到（而非固定参数），$ \text{softplus} $ 确保 $ \Delta_t > 0 $。这使得模型能根据输入内容动态调整状态更新策略——对重要 token 给予更大的 $ \Delta_t $（保留更多信息），对无关 token 给予较小的 $ \Delta_t $（快速遗忘）。

选择性扫描并行计算：

$$ y_t = C_t \cdot \left( \prod_{k=1}^{t} \bar{A}_k \right) h_0 + \sum_{k=1}^{t} \left( \prod_{j=k+1}^{t} \bar{A}_j \right) \bar{B}_k x_k $$

由于 $ \bar{A}_t $ 依赖输入，无法像 S4 那样使用 FFT 加速，Mamba 采用硬件感知的并行扫描算法实现高效计算。

代码实现

import torch
import torch.nn as nn
import torch.nn.functional as F
import math

class MambaBlock(nn.Module):
    """Mamba 选择性状态空间模型块"""

    def __init__(self, d_model, d_state=16, d_conv=4, expand=2):
        """
        初始化 Mamba 块

        参数:
            d_model:  模型维度（输入和输出维度）
            d_state:  SSM 隐藏状态维度 N
            d_conv:   局部卷积核大小
            expand:   内部维度扩展倍数
        """
        super().__init__()
        self.d_model = d_model                              # 保存模型维度
        self.d_state = d_state                              # 保存 SSM 状态维度
        self.d_conv = d_conv                                # 保存卷积核大小
        self.d_inner = expand * d_model                    # 内部扩展维度 = expand × d_model

        # 1. 输入投影：d_model → d_inner
        self.in_proj = nn.Linear(d_model, self.d_inner * 2, bias=False)  # 投影到 2×d_inner（SSM分支 + 门控分支）

        # 2. 局部卷积：捕获短距离依赖
        self.conv1d = nn.Conv1d(
            in_channels=self.d_inner,                      # 输入通道数 = d_inner
            out_channels=self.d_inner,                     # 输出通道数 = d_inner
            kernel_size=d_conv,                            # 卷积核大小
            padding=d_conv - 1,                             # 因果卷积：只在左侧填充
            groups=self.d_inner,                            # 深度可分离卷积（每通道独立卷积）
            bias=True
        )

        # 3. x_proj：输入依赖的参数投影（选择性机制核心）
        self.x_proj = nn.Linear(
            self.d_inner,                                   # 输入维度
            d_state * 2 + self.d_inner,                      # 输出维度 = Δ(B) + C + Δ 投影
            bias=False
        )

        # 4. dt_proj：Δ 的低秩投影
        self.dt_rank = math.ceil(d_model / 16)              # Δ 低秩维度 = ceil(d_model / 16)
        self.dt_proj = nn.Linear(self.d_inner, self.d_inner, bias=True)

        # 5. SSM 参数 A（固定，不依赖输入）
        A = torch.arange(1, d_state + 1, dtype=torch.float32).repeat(self.d_inner, 1)  # A 初始化为 1~N
        self.A_log = nn.Parameter(torch.log(A))            # 存储为 log(A)，确保 A > 0
        self.D = nn.Parameter(torch.ones(self.d_inner))    # 跳跃连接参数 D

        # 6. 输出投影：d_inner → d_model
        self.out_proj = nn.Linear(self.d_inner, d_model, bias=False)

    def forward(self, x):
        """
        前向传播

        参数:
            x: 输入张量，形状 (batch, seq_len, d_model)
        返回:
            输出张量，形状 (batch, seq_len, d_model)
        """
        batch, seq_len, _ = x.shape                         # 获取批量大小和序列长度

        # 1. 输入投影 + 分支
        xz = self.in_proj(x)                                # (batch, seq_len, 2×d_inner)
        x, z = xz.chunk(2, dim=-1)                          # 分为 SSM 分支 x 和门控分支 z

        # 2. 因果卷积 + SiLU 激活
        x = x.transpose(1, 2)                               # (batch, d_inner, seq_len) 供 Conv1d 使用
        x = self.conv1d(x)[:, :, :seq_len]                  # 因果卷积，截取前 seq_len 个位置
        x = x.transpose(1, 2)                               # (batch, seq_len, d_inner)
        x = F.silu(x)                                      # SiLU 激活: x * sigmoid(x)

        # 3. 选择性投影：从 x 计算 Δ, B, C
        x_dbl = self.x_proj(x)                              # (batch, seq_len, d_state*2 + d_inner)
        dt, B, C = torch.split(                             # 分割投影结果
            x_dbl,
            [self.d_inner, self.d_state, self.d_state],     # 三部分：Δ 投影、B、C
            dim=-1
        )
        dt = F.softplus(self.dt_proj(dt))                   # Δ 投影 + softplus 确保 Δ > 0

        # 4. 选择性扫描（SSM 核心计算）
        A = -torch.exp(self.A_log)                          # 从 log(A) 恢复 A，取负确保衰减（稳定性）
        dA = torch.exp(dt.unsqueeze(-1) * A)               # 离散化: Ā = exp(Δ·A)，形状 (batch, seq_len, d_inner, d_state)
        dB = dt.unsqueeze(-1) * B.unsqueeze(2)             # 离散化: B̄ = Δ·B，形状 (batch, seq_len, d_inner, d_state)

        # 逐步扫描（实际实现用并行扫描优化）
        h = torch.zeros(batch, self.d_inner, self.d_state, device=x.device)  # 初始化隐藏状态为 0
        ys = []
        for t in range(seq_len):                            # 逐时间步计算
            h = dA[:, t] * h + dB[:, t] * x[:, t].unsqueeze(-1)  # 状态更新: h_t = Ā·h_{t-1} + B̄·x_t
            y_t = torch.einsum('bdn,bd->bn', h, C[:, t])   # 输出: y_t = C_t · h_t
            ys.append(y_t)
        y = torch.stack(ys, dim=1)                          # (batch, seq_len, d_inner)

        # 5. 跳跃连接
        y = y + x * self.D.unsqueeze(0).unsqueeze(0)       # y = y + D * x（残差连接）

        # 6. 门控分支：z · SiLU(z) 逐元素相乘
        y = y * F.silu(z)                                   # 门控: SSM 输出 × SiLU(门控分支)

        # 7. 输出投影
        output = self.out_proj(y)                           # (batch, seq_len, d_model)
        return output


# 使用示例
model = MambaBlock(d_model=512, d_state=16, d_conv=4, expand=2)  # 创建 Mamba 块
