快速选择

类别：查找算法 | 难度：入门

算法简介

快速选择（Quickselect）是一种基于分治思想的选择算法，用于在无序数组中查找第 K 小（或第 K 大）的元素。它由 Tony Hoare 于 1961 年提出，与快速排序同源，但关键区别在于：快速排序需要对整个数组完全排序（O(n log n)），而快速选择只需递归处理包含目标元素的一侧子区间，平均时间复杂度仅为 O(n)。

核心原理

快速选择的核心操作是 分区（Partition）：

1. 从数组中选择一个基准元素（pivot）

2. 将数组分为两部分：小于 pivot 的元素放在左边，大于 pivot 的放在右边

3. 此时 pivot 处于其最终排序位置（索引 p）

4. 比较 p 与目标索引 k：

  • 若 p == k，直接返回 pivot（找到第 K 小元素）
  • 若 p > k，在左子区间递归查找
  • 若 p < k，在右子区间递归查找

由于每次只递归一侧（不像快速排序两侧都递归），平均时间复杂度为 $ O(n) $。

数学公式

1. 期望时间复杂度递推式

$$ T(n) = T(n/2) + O(n) $$

其中 $ T(n) $ 是处理规模为 $ n $ 的数组所需期望时间，$ T(n/2) $ 是递归处理一侧子区间的期望时间，$ O(n) $ 是分区操作的时间。由主定理求解得 $ T(n) = O(n) $。

2. 最坏时间复杂度递推式

$$ T(n) = T(n-1) + O(n) = O(n^2) $$

当每次选到最差基准（如数组已排序且选第一个元素为 pivot），每次只减少一个元素，退化为 $ O(n^2) $。

3. 随机化后期望复杂度

$$ E[T(n)] \leq \frac{4n}{n+1} \cdot c = O(n) $$

其中 $ E[T(n)] $ 为随机选择 pivot 时的期望时间，$ c $ 为分区常数因子。随机化 pivot 后最坏情况概率极低。

参数详解

| 参数 | 含义 | 类型 | 默认值 | 取值范围 | 对结果的影响 | 推荐设置 |

|------|------|------|--------|----------|-------------|---------|

| arr | 输入数组 | list/array | 必填 | 任意可比较元素 | 决定查找的数据源 | - |

| k | 目标排名（第 k 小） | int | 必填 | 1 ≤ k ≤ len(arr) | 决定查找哪个顺序统计量 | 根据需求指定 |

| pivot_strategy | 基准选择策略 | str | "random" | "random"/"first"/"last"/"median_of_three" | 影响最坏情况概率和平均性能 | "random" 或 "median_of_three" |

| partition_scheme | 分区方案 | str | "lomuto" | "lomuto"/"hoare" | 影响交换次数和实现复杂度 | "lomuto" 简单，"hoare" 更高效 |

| inplace | 是否原地操作 | bool | True | True/False | True 节省内存，False 需额外 O(n) 空间 | True |

参数详细说明：

  • k：第 k 小元素的排名，从 1 开始计数。例如 k=1 返回最小值，k=len(arr) 返回最大值，k=len(arr)//2 返回中位数
  • pivot_strategy：
  • "random"：随机选择 pivot，期望复杂度 O(n)，最坏情况概率极低
  • "first"：选第一个元素，已排序数组会退化到 O(n²)
  • "last"：选最后一个元素，同样可能退化
  • "median_of_three"：取首、中、尾三元素的中位数作为 pivot，实际中表现优秀
  • partition_scheme：
  • "lomuto"：单指针方案，实现简单，但交换次数较多
  • "hoare"：双指针对向扫描，交换次数少约 3 倍，原始 Hoare 方案
  • inplace：原地操作仅用 O(log n) 递归栈空间；非原地需复制数组，空间 O(n)

代码实现（Python，逐行注释）

import random  # 导入随机模块，用于随机选择基准元素

def quickselect(arr, k, pivot_strategy="random", inplace=True):
    """快速选择算法：在 arr 中查找第 k 小的元素（k 从 1 开始计数）"""
    # 如果不要求原地操作，复制一份数组避免修改原数组
    if not inplace:
        arr = arr[:]  # 浅拷贝整个数组，空间复杂度 O(n)

    # 将 k 转换为零索引：第 k 小 → 索引 k-1
    target_idx = k - 1  # 例如 k=1（最小值）→ target_idx=0

    # 调用内部递归函数，在 [left, right] 区间内查找第 target_idx 个元素
    return _quickselect_recursive(arr, target_idx, 0, len(arr) - 1, pivot_strategy)

def _quickselect_recursive(arr, target_idx, left, right, pivot_strategy):
    """递归核心函数：在 arr[left..right] 区间内查找排在 target_idx 位置的元素"""
    # 基本情况：区间只有一个元素，直接返回
    if left == right:  # 当左右指针重合，说明只剩一个元素
        return arr[left]  # 这个元素就是答案

    # 根据策略选择基准元素（pivot）的索引
    if pivot_strategy == "random":  # 随机选择策略
        pivot_idx = random.randint(left, right)  # 在 [left, right] 范围内随机选一个索引
    elif pivot_strategy == "first":  # 选第一个元素
        pivot_idx = left  # 直接取左边界索引
    elif pivot_strategy == "last":  # 选最后一个元素
        pivot_idx = right  # 直接取右边界索引
    elif pivot_strategy == "median_of_three":  # 三数取中策略
        mid = (left + right) // 2  # 计算中间索引
        # 比较首、中、尾三个元素，取中位数所在的索引
        candidates = [(arr[left], left), (arr[mid], mid), (arr[right], right)]  # 构建三元组
        candidates.sort(key=lambda x: x[0])  # 按值排序
        pivot_idx = candidates[1][1]  # 取中间值的索引
    else:  # 未知策略，默认随机
        pivot_idx = random.randint(left, right)  # 回退到随机选择

    # 将 pivot 交换到区间最右端，方便 Lomuto 分区
    arr[pivot_idx], arr[right] = arr[right], arr[pivot_idx]  # 交换 pivot 和右端元素

    # --- Lomuto 分区方案 ---
    # 维护一个指针 store_idx，指向"小于 pivot 区域"的右边界
    store_idx = left  # 初始化为左边界，表示当前小于 pivot 的区域为空

    # 遍历区间内除 pivot（已在 right 位置）外的所有元素
    for i in range(left, right):  # i 从 left 到 right-1
        if arr[i] < arr[right]:  # 如果当前元素小于 pivot（pivot 现在在 arr[right]）
            arr[store_idx], arr[i] = arr[i], arr[store_idx]  # 将小元素交换到 store_idx 位置
            store_idx += 1  # 扩展"小于 pivot 区域"的边界

    # 将 pivot 放到最终位置：store_idx 处
    arr[store_idx], arr[right] = arr[right], arr[store_idx]  # pivot 到位，此时 store_idx 就是 pivot 的最终排序位置

    # 比较 pivot 位置与目标位置，决定递归方向
    if store_idx == target_idx:  # pivot 恰好在目标位置
        return arr[store_idx]  # 找到了，直接返回
    elif store_idx > target_idx:  # pivot 在目标位置的右边
        # 目标在左子区间，只递归左侧
        return _quickselect_recursive(arr, target_idx, left, store_idx - 1, pivot_strategy)
    else:  # pivot 在目标位置的左边
        # 目标在右子区间，只递归右侧
        return _quickselect_recursive(arr, target_idx, store_idx + 1, right, pivot_strategy)

# === 使用示例 ===
arr = [7, 10, 4, 3, 20, 15, 8, 12]  # 测试数组
k = 3  # 找第 3 小的元素

result = quickselect(arr, k, pivot_strategy="random")  # 执行快速选择
print(f"第 {k} 小的元素是: {result}")  # 输出: 第 3 小的元素是: 7

# 找中位数
n = len(arr)  # 数组长度
if n % 2 == 1:  # 奇数个元素
    median = quickselect(arr, n // 2 + 1)  # 中间那个就是中位数
else:  # 偶数个元素
    left_mid = quickselect(arr, n // 2)  # 左中位数
    right_mid = quickselect(arr, n // 2 + 1)  # 右中位数
    median = (left_mid + right_mid) / 2  # 取平均
print(f"中位数: {median}")  # 输出中位数

  • 电商平台实时排序中的 Top K 维护

交叉熵损失

类别：损失函数 | 难度：入门

算法简介

交叉熵损失（Cross-Entropy Loss）是深度学习中最常用的多分类损失函数。它衡量模型输出的概率分布与真实标签分布之间的差异：预测越接近真实标签，损失越小；预测越偏离，损失越大。PyTorch 中 nn.CrossEntropyLoss 内部组合了 LogSoftmax 和 NLLLoss，直接接收 logits（未归一化的原始输出），无需手动添加 softmax 层。

核心原理

交叉熵源于信息论，度量两个概率分布 $ p $ 和 $ q $ 的差异：

  • $ p $ 是真实标签的分布（one-hot 编码，即正确类别概率为 1，其余为 0）
  • $ q $ 是模型预测的概率分布（通过 softmax 将 logits 转换为概率）

交叉熵越小，两个分布越接近，模型预测越准确。PyTorch 的 CrossEntropyLoss 先对 logits 做 softmax 得到概率 $ q $，再取对数，最后与真实标签做负对数似然（NLL）。

数学公式

1. Softmax 函数

$$ q_i = \frac{\exp(z_i)}{\sum_{j=1}^{C} \exp(z_j)} $$

其中 $ z_i $ 是第 $ i $ 类的 logit 值，$ C $ 是类别总数，$ q_i $ 是第 $ i $ 类的预测概率。Softmax 将任意实数向量归一化为概率分布。

2. 交叉熵损失（单样本）

$$ \mathcal{L} = -\sum_{i=1}^{C} p_i \log q_i = -\log q_{y} $$

其中 $ p_i $ 是真实标签的 one-hot 分布（只有正确类别 $ y $ 处为 1，其余为 0），$ q_i $ 是 softmax 预测概率。由于 one-hot 特性，求和简化为 $ -\log q_y $，即正确类别的预测概率对数值的负数。

3. 带权重的交叉熵损失

$$ \mathcal{L}_{weighted} = -\sum_{i=1}^{C} w_i \cdot p_i \log q_i = -w_{y} \log q_{y} $$

其中 $ w_i $ 是第 $ i $ 类的权重，$ w_y $ 是正确类别的权重。用于类别不平衡场景，给少数类更高的权重。

4. 带标签平滑的交叉熵损失

$$ \mathcal{L}_{smooth} = -(1-\epsilon) \log q_y - \frac{\epsilon}{C} \sum_{i=1}^{C} \log q_i $$

其中 $ \epsilon $ 是平滑系数（取值 0~1），$ C $ 是类别数，$ q_y $ 是正确类别的预测概率。标签平滑将 one-hot 的硬标签 "软化" 为在正确类别上分配 $ (1-\epsilon) $ 概率、在其他类别上均匀分配 $ \epsilon/C $ 概率的软标签。

5. 批量平均损失（reduction='mean'）

$$ \mathcal{L}_{batch} = \frac{1}{N} \sum_{n=1}^{N} \mathcal{L}_n $$

其中 $ N $ 是批次中的样本数（忽略被 ignore_index 标记的样本），$ \mathcal{L}_n $ 是第 $ n $ 个样本的损失。

参数详解

| 参数 | 含义 | 类型 | 默认值 | 取值范围 | 对结果的影响 | 推荐设置 |

|------|------|------|--------|----------|-------------|---------|

| weight | 各类别权重 | Tensor | None | 正实数向量 | 少数类权重越大，模型越关注该类 | 类别不平衡时设置，权重与类别频率成反比 |

| ignore_index | 忽略的标签索引 | int | -100 | 任意整数 | 该索引的样本不计入损失 | 填充位置用 -100 或 -1 |

| reduction | 损失聚合方式 | str | "mean" | "mean"/"sum"/"none" | "mean"返回标量均值，"sum"返回总和，"none"返回逐样本损失 | 训练用"mean"，调试用"none" |

| label_smoothing | 标签平滑系数 | float | 0.0 | 0.0 ~ 1.0 | 值越大，正则化越强，防止过度自信 | 0.1 为常用值，类别多时可增大 |

参数详细说明：

  • weight：形状为 (C,) 的张量，$ C $ 为类别数。例如 10 类分类中，给第 3 类和第 7 类权重设为 2.0，其余为 1.0，则模型对第 3、7 类的损失翻倍，更关注这些类别的预测准确率
  • ignore_index：在 NLP 任务中，序列长度不一致时需要填充（padding），将填充位置标签设为 -100，这些位置不计入损失计算。注意 ignore_index 不需要出现在 weight 中
  • reduction：
  • "mean"：默认值，返回 batch 内所有（非忽略）样本损失的平均值，适合大多数训练场景
  • "sum"：返回损失总和，可用于自定义归一化逻辑
  • "none"：返回形状 (N,) 的逐样本损失，适合分析各样本损失分布或自定义加权
  • label_smoothing：
  • 0.0：标准 one-hot 硬标签，模型可能对预测过度自信
  • 0.1：最常用值，将 10% 概率均匀分配给其他类别，提高泛化能力
  • 较大值（如 0.3）可能导致欠拟合，需配合验证集调参

代码实现（PyTorch，逐行注释）

import torch  # 导入 PyTorch 核心库
import torch.nn as nn  # 导入神经网络模块，包含各种损失函数和层
import torch.optim as optim  # 导入优化器模块，包含 SGD、Adam 等

# ============================================================
# 示例 1：基本用法
# ============================================================
criterion = nn.CrossEntropyLoss()  # 创建标准交叉熵损失函数，无权重、无标签平滑

# 模拟模型输出的 logits（未经 softmax 的原始输出）
# 形状: (batch_size=4, num_classes=10)，表示 4 个样本、10 个类别
outputs = torch.randn(4, 10)  # 生成 4x10 的随机张量作为 logits

# 真实标签：每个样本一个类别索引，取值 0~9
labels = torch.tensor([2, 5, 1, 7])  # 4 个样本的正确类别分别是第 2、5、1、7 类

loss = criterion(outputs, labels)  # 计算交叉熵损失：内部先 softmax 再 NLL
print(f"基本交叉熵损失: {loss.item():.4f}")  # 输出损失值，.item() 将标量张量转为 Python float

# ============================================================
# 示例 2：类别权重（处理类别不平衡）
# ============================================================
weight = torch.ones(10)  # 初始化 10 个类别的权重全为 1.0
weight[3] = 2.0  # 将第 3 类权重设为 2.0，表示该类更重要（可能是少数类）
weight[7] = 2.0  # 将第 7 类权重设为 2.0

criterion_weighted = nn.CrossEntropyLoss(weight=weight)  # 创建带权重的损失函数
loss_weighted = criterion_weighted(outputs, labels)  # 计算加权交叉熵损失
print(f"加权交叉熵损失: {loss_weighted.item():.4f}")  # 当标签为 3 或 7 时，损失翻倍

# ============================================================
# 示例 3：标签平滑
# ============================================================
criterion_smooth = nn.CrossEntropyLoss(label_smoothing=0.1)  # 标签平滑系数 0.1
loss_smooth = criterion_smooth(outputs, labels)  # 计算带标签平滑的损失
print(f"标签平滑损失: {loss_smooth.item():.4f}")  # 正则化效果，防止过度自信

# ============================================================
# 示例 4：ignore_index 忽略填充位置
# ============================================================
criterion_ignore = nn.CrossEntropyLoss(ignore_index=-100)  # 忽略标签为 -100 的样本
outputs2 = torch.randn(5, 10)  # 5 个样本
labels2 = torch.tensor([2, -100, 5, -100, 7])  # 第 2、4 个样本标签为 -100（填充位）
loss_ignore = criterion_ignore(outputs2, labels2)  # 只计算 3 个有效样本的平均损失
print(f"忽略填充后损失: {loss_ignore.item():.4f}")  # -100 标签的样本不影响损失

# ============================================================
# 示例 5：不同 reduction 方式
# ============================================================
loss_mean = nn.CrossEntropyLoss(reduction='mean')(outputs, labels)  # 返回标量：均值
loss_sum = nn.CrossEntropyLoss(reduction='sum')(outputs, labels)   # 返回标量：总和
loss_none = nn.CrossEntropyLoss(reduction='none')(outputs, labels) # 返回 (4,) 向量
print(f"mean: {loss_mean.item():.4f}, sum: {loss_sum.item():.4f}")  # sum ≈ mean × 4
print(f"逐样本损失: {loss_none.tolist()}")  # 查看每个样本各自的损失值

# ============================================================
# 示例 6：完整训练流程
# ============================================================
class SimpleClassifier(nn.Module):  # 定义一个简单分类模型
    def __init__(self, input_dim=784, num_classes=10):  # 输入维度 784（如 28x28 图像），10 类
        super().__init__()  # 调用父类初始化
        self.fc = nn.Sequential(  # 使用 Sequential 构建多层感知机
            nn.Linear(input_dim, 256),  # 全连接层：784 → 256
            nn.ReLU(),                 # ReLU 激活函数
            nn.Dropout(0.5),           # Dropout 正则化，50% 概率置零
            nn.Linear(256, num_classes) # 输出层：256 → 10（输出 logits）
        )

    def forward(self, x):  # 前向传播
        return self.fc(x)  # 直接通过全连接网络，输出 logits（不加 softmax）

model = SimpleClassifier()  # 实例化模型
criterion = nn.CrossEntropyLoss()  # 损失函数（内部含 softmax）
optimizer = optim.Adam(model.parameters(), lr=0.001)  # Adam 优化器，学习率 0.001

# 模拟一个训练 batch
batch_size = 32  # 批次大小
x_train = torch.randn(batch_size, 784)  # 随机输入：(32, 784)
y_train = torch.randint(0, 10, (batch_size,))  # 随机标签：(32,)，值 0~9

model.train()  # 设为训练模式（启用 Dropout）
outputs_train = model(x_train)  # 前向传播得到 logits：(32, 10)
loss = criterion(outputs_train, y_train)  # 计算交叉熵损失

optimizer.zero_grad()  # 清空梯度（PyTorch 默认累积梯度，需手动清零）
loss.backward()        # 反向传播，自动计算各参数梯度
optimizer.step()       # 更新参数（根据梯度和学习率）

print(f"训练批次损失: {loss.item():.4f}")  # 打印当前 batch 的损失值

# 验证模式
model.eval()  # 设为评估模式（关闭 Dropout）
with torch.no_grad():  # 不计算梯度，节省内存和计算
    outputs_eval = model(x_train)  # 前向传播
    predictions = outputs_eval.argmax(dim=1)  # 取概率最大的类别作为预测
    accuracy = (predictions == y_train).float().mean()  # 计算准确率
print(f"预测准确率: {accuracy.item():.2%}")  # 输出百分比格式

常见问题

  • CrossEntropyLoss vs NLLLoss：CrossEntropyLoss = LogSoftmax + NLLLoss。前者直接接收 logits，后者需要先手动 LogSoftmax
  • 为什么不用手动加 softmax：CrossEntropyLoss 内部已自动计算 softmax，直接传 logits 可提高数值稳定性（利用 LogSumExp 技巧避免溢出）
  • 标签应该是类别索引还是 one-hot：应为类别索引（0 到 C-1 的整数），不是 one-hot 编码

Mamba 状态空间模型

类别：前沿架构 | 难度：困难

算法简介

Mamba 是 Albert Gu 和 Tri Dao 于 2023 年提出的新型序列建模架构，基于状态空间模型（State Space Model, SSM），通过选择性扫描（Selective Scan）机制实现了线性时间复杂度 $ O(n) $ 的长序列建模。与 Transformer 的二次复杂度 $ O(n^2) $ 相比，Mamba 在处理超长序列（如 100K+ token）时具有显著的推理速度和内存优势，同时保持了与 Transformer 相当的建模质量。

Mamba 的核心创新在于：传统 SSM 是线性时不变（LTI）系统，参数固定不变，无法根据输入内容选择性记忆；Mamba 引入了输入依赖的参数化，使模型能够根据当前输入动态决定"记住什么、遗忘什么"，类似于 LSTM 的门控机制但更高效。

核心原理

Mamba 的核心包含三个关键组件：

1. 连续状态空间方程（S4 基础）

状态空间模型将一维序列映射到隐藏状态，再由隐藏状态映射到输出，通过连续微分方程描述：

$$ h'(t) = Ah(t) + Bx(t), \quad y(t) = Ch(t) + Dx(t) $$

其中 $ h(t) $ 是隐藏状态，$ x(t) $ 是输入，$ y(t) $ 是输出，$ A, B, C, D $ 是可学习参数矩阵。

2. 离散化（Zero-Order Hold）

通过零阶保持（ZOH）将连续方程离散化，使其可处理离散序列：

$$ \bar{A} = \exp(\Delta A), \quad \bar{B} = (\Delta A)^{-1}(\exp(\Delta A) - I) \cdot \Delta B $$

其中 $ \Delta $ 是离散化步长（可学习的时间尺度参数），$ \bar{A}, \bar{B} $ 是离散化后的参数。

3. 选择性扫描（Mamba 核心创新）

Mamba 的关键突破是让 $ B, C, \Delta $ 参数依赖于输入 $ x_t $（而非固定不变）：

  • 传统 SSM（S4）：$ A, B, C, \Delta $ 是固定参数，与输入无关（LTI 系统）
  • Mamba：$ B(x_t), C(x_t), \Delta(x_t) $ 通过线性投影从当前输入 $ x_t $ 计算，使模型能根据输入内容动态调整状态更新

这打破了 LTI 约束，使 Mamba 具备了选择性——对重要信息保留更多、对无关信息遗忘更快。

数学公式

1. 离散化状态递推

$$ h_t = \bar{A} h_{t-1} + \bar{B} x_t $$

其中 $ h_t $ 是时刻 $ t $ 的隐藏状态，$ \bar{A} $ 是离散化后的状态转移矩阵（控制遗忘），$ \bar{B} $ 是离散化后的输入矩阵（控制写入），$ x_t $ 是当前输入。此公式描述了状态如何随时间更新。

2. 输出计算

$$ y_t = C(x_t) \cdot h_t + D \cdot x_t $$

其中 $ C(x_t) $ 是输入依赖的输出矩阵（从当前输入通过线性投影得到），$ h_t $ 是当前隐藏状态，$ D \cdot x_t $ 是残差连接（通常 $ D $ 为简单缩放）。

3. 选择性参数生成

$$ \Delta_t = \text{softplus}(W_\Delta \cdot x_t), \quad B_t = W_B \cdot x_t, \quad C_t = W_C \cdot x_t $$

其中 $ W_\Delta, W_B, W_C $ 是可学习的投影矩阵，$ x_t $ 是当前输入，$ \text{softplus} $ 确保步长 $ \Delta_t > 0 $。这使得 $ B, C, \Delta $ 随输入动态变化，是 Mamba 选择性的来源。

4. 并行扫描（Parallel Scan）

$$ h_t = \sum_{i=1}^{t} \left(\prod_{j=i+1}^{t} \bar{A}_j\right) \bar{B}_i x_i $$

由于 $ \bar{A}_j $ 现在依赖输入（不再固定），无法用卷积高效计算。Mamba 使用并行前缀扫描（Parallel Prefix Scan）算法，将 $ O(n) $ 的顺序递推转化为 $ O(\log n) $ 深度的并行计算，在 GPU 上实现高效训练。

参数详解

| 参数 | 含义 | 类型 | 默认值 | 取值范围 | 对结果的影响 | 推荐设置 |

|------|------|------|--------|----------|-------------|---------|

| d_model | 模型维度（输入/输出维度） | int | 256 | 64~4096 | 维度越大，表达能力越强，但计算量增加 | 256~1024 |

| d_state | SSM 隐藏状态维度 | int | 16 | 8~256 | 影响状态记忆容量，越大能记住更多信息 | 16~64 |

| d_conv | 局部卷积核大小 | int | 4 | 2~8 | 局部特征提取窗口，类似短距离 n-gram | 4 |

| expand | 内部扩展因子 | int | 2 | 1~4 | MLP 中间维度 = d_model × expand，影响 FLOPs | 2 |

| dt_rank | $ \Delta $ 投影的秩 | str/int | "auto" | "auto"或1~64 | 控制 $ \Delta $ 生成的低秩压缩程度 | "auto"（≈d_model/16） |

| dt_min | $ \Delta $ 最小值 | float | 0.001 | >0 | 限制最小时间步长，防止信息衰减过快 | 0.001 |

| dt_max | $ \Delta $ 最大值 | float | 0.1 | >dt_min | 限制最大时间步长，防止信息遗忘过慢 | 0.1 |

| dt_init | $ \Delta $ 初始化方式 | str | "random" | "random"/"constant" | 影响训练初期的时间尺度分布 | "random" |

| dt_scale | $ \Delta $ 初始化缩放 | float | 1.0 | >0 | 控制初始化时 $ \Delta $ 的范围 | 1.0 |

| bias | 是否使用偏置 | bool | False | True/False | Linear 层是否带 bias | False（Mamba 通常不用） |

参数详细说明：

  • d_model：模型的输入和输出维度，类似于 Transformer 中的 d_model。决定了每层的参数量和计算量。语言模型中通常 256~1024，大模型可达 4096+
  • d_state：SSM 的隐藏状态维度 $ N $（即矩阵 $ A $ 的大小为 $ N \times N $）。越大意味着状态能存储的信息越多，但参数量和计算量也增加。Mamba 论文默认 16，实践中 32~64 也有使用
  • d_conv：在 SSM 之前施加的 1D 因果卷积的核大小。用于提取局部（短距离）模式，补偿 SSM 对局部信息的处理不足。核大小 4 表示模型关注前 4 个 token 的局部模式
  • expand：Mamba block 内部 MLP 的扩展因子。中间隐藏维度 = d_model × expand，类似于 Transformer FFN 的 4 倍扩展。expand=2 是性能与效率的平衡点
  • dt_rank：$ \Delta $ 的低秩投影维度。Mamba 不直接从 $ d\_model $ 映射到标量 $ \Delta $，而是先投影到低秩空间再投影回 1 维。"auto" 会自动设为 $ \lceil d\_model / 16 \rceil $，压缩信息的同时保留关键时间尺度信息
  • dt_min / dt_max：$ \Delta $ 被约束在 $ [dt\_min, dt\_max] $ 范围内。$ \Delta $ 小意味着状态更新慢（长期记忆），$ \Delta $ 大意味着状态更新快（短期记忆）。通过 softplus + 限制确保数值稳定
  • dt_init：初始化策略。"random" 在 $ [\log(dt\_min), \log(dt\_max)] $ 区间均匀采样，使不同通道有不同的时间尺度，有利于捕捉多尺度信息
  • bias：Linear 投影层是否使用偏置项。Mamba 论文中默认不使用 bias，减少参数量且不影响效果

代码实现（PyTorch 简化版，逐行注释）

import torch  # 导入 PyTorch 核心库
import torch.nn as nn  # 导入神经网络模块
import torch.nn.functional as F  # 导入函数式接口
import math  # 导入数学库
from einops import repeat  # 导入 einops 的 repeat 函数，用于张量重复

# ============================================================
# Mamba block 简化实现
# ============================================================
class MambaBlock(nn.Module):  # 定义 Mamba 基本模块
    """Mamba 状态空间模型的核心 Block，简化版实现"""
    
    def __init__(self, d_model=256, d_state=16, d_conv=4, expand=2, dt_rank="auto"):
        super().__init__()  # 调用父类初始化
        self.d_model = d_model  # 模型维度
        self.d_state = d_state  # SSM 隐藏状态维度 N
        self.d_conv = d_conv  # 局部卷积核大小
        self.expand = expand  # 内部扩展因子
        self.d_inner = int(d_model * expand)  # 内部维度 = d_model × expand
        
        # dt_rank 自动计算
        if dt_rank == "auto":  # 如果 dt_rank 为 "auto"
            self.dt_rank = max(1, math.ceil(d_model / 16))  # 自动计算：d_model/16 向上取整，至少为 1
        else:
            self.dt_rank = dt_rank  # 使用指定值
        
        # --- 输入投影 ---
        # 将输入从 d_model 投影到 d_inner（2倍扩展），类似 Transformer 的 FFN
        self.in_proj = nn.Linear(d_model, self.d_inner * 2, bias=False)  
        # 注意：投影到 2×d_inner，一半给 SSM 分支，一半给门控分支
        
        # --- 局部卷积 ---
        # 1D 因果卷积，提取局部模式（短距离依赖）
        self.conv1d = nn.Conv1d(  # 一维卷积层
            in_channels=self.d_inner,  # 输入通道数 = 内部维度
            out_channels=self.d_inner,  # 输出通道数 = 内部维度
            kernel_size=d_conv,  # 卷积核大小 = 4
            groups=self.d_inner,  # 分组卷积（depthwise），每个通道独立卷积
            padding=d_conv - 1,  # 因果卷积：左填充 kernel_size-1，确保只看过去信息
        )
        
        # --- 选择性参数投影 ---
        # x → dt（时间步长 Δ）
        self.x_proj = nn.Linear(self.d_inner, self.dt_rank + d_state * 2, bias=False)
        # 投影到 dt_rank + 2×d_state：dt_rank 给 Δ，d_state 给 B，d_state 给 C
        
        # dt → A, B（从低秩空间投影回高维）
        self.dt_proj = nn.Linear(self.dt_rank, self.d_inner, bias=True)
        # 将低秩 dt 投影回 d_inner 维度，用于生成 Δ
        
        # --- SSM 参数 A 的初始化 ---
        # A 初始化为对角矩阵的负实部（HiPPO 矩阵），有助于记忆长程依赖
        A = repeat(  # 使用 einops repeat
            torch.arange(1, d_state + 1, dtype=torch.float32),  # 生成 1 到 N 的序列
            'n -> d n',  # 将 1D 张量扩展为 2D：(d_inner, d_state)
            d=self.d_inner,  # 第一维大小为 d_inner
        )
        A = -A.expand(self.d_inner, d_state).contiguous()  # 取负值，使 A 为负实部对角矩阵
        self.A_log = nn.Parameter(torch.log(A))  # 存储为 log(A) 参数，训练时保证 A < 0
        
        # D 参数（残差/跳跃连接）
        self.D = nn.Parameter(torch.ones(self.d_inner))  # D 初始化为 1，残差缩放
        
        # --- 输出投影 ---
        self.out_proj = nn.Linear(self.d_inner, d_model, bias=False)  # 从 d_inner 投影回 d_model
    
    def forward(self, x):
        """前向传播
        x: (batch, seq_len, d_model)
        return: (batch, seq_len, d_model)
        """
        batch, seq_len, _ = x.shape  # 解包输入形状
        
        # 1. 输入投影：d_model → 2×d_inner（分两路：SSM 分支 + 门控分支）
        xz = self.in_proj(x)  # (batch, seq_len, 2×d_inner)
        x_proj, z = xz.chunk(2, dim=-1)  # 沿最后一维分成两半
        
        # 2. 因果卷积：提取局部模式
        x_proj = x_proj.transpose(1, 2)  # (batch, d_inner, seq_len) — Conv1d 需要 (B, C, L) 格式
        x_proj = self.conv1d(x_proj)  # 一维因果卷积，核大小 4
        x_proj = x_proj[:, :, :seq_len]  # 裁剪因 padding 导致的多余长度（因果卷积右端会有多余）
        x_proj = x_proj.transpose(1, 2)  # (batch, seq_len, d_inner) — 转回原始格式
        x_proj = F.silu(x_proj)  # SiLU 激活（Swish 函数：x * sigmoid(x)）
        
        # 3. 选择性参数生成：从输入动态计算 Δ, B, C
        x_dbl = self.x_proj(x_proj)  # (batch, seq_len, dt_rank + 2×d_state)
        dt, B, C = x_dbl.split(  # 按维度切分
            [self.dt_rank, self.d_state, self.d_state], dim=-1  # 分别取出 Δ 的低秩表示、B、C
        )
        
        # 4. Δ 生成（从低秩空间投影回高维）
        dt = F.softplus(self.dt_proj(dt))  # 先线性投影回 d_inner，再 softplus 确保 Δ > 0
        
        # 5. 获取 A 参数
        A = -torch.exp(self.A_log)  # A = -exp(A_log)，确保 A < 0（稳定状态衰减）
        
        # 6. 选择性扫描（简化版，实际使用 CUDA 并行 scan kernel）
        # 这里用 Python 循环演示原理，实际部署用 mamba_ssm 的 selective_scan_fn
        h = torch.zeros(batch, self.d_inner, self.d_state, device=x.device)  # 初始化隐藏状态
        ys = []  # 存储每个时间步的输出
        
        for t in range(seq_len):  # 遍历序列每个时间步
            # 离散化 A_bar = exp(Δ × A)，B_bar = Δ × B（ZOH 简化）
            dt_t = dt[:, t, :]  # (batch, d_inner) — 当前时间步的 Δ
            A_bar = torch.exp(dt_t.unsqueeze(-1) * A)  # (batch, d_inner, d_state) — 离散化 A
            B_bar = dt_t.unsqueeze(-1) * B[:, t, :].unsqueeze(1)  # (batch, d_inner, d_state) — 离散化 B
            
            # 状态更新：h_t = A_bar × h_{t-1} + B_bar × x_t
            h = A_bar * h + B_bar * x_proj[:, t, :].unsqueeze(-1)  # 状态递推更新
            
            # 输出：y_t = C_t × h_t + D × x_t
            y_t = torch.sum(C[:, t, :].unsqueeze(1) * h, dim=-1)  # (batch, d_inner) — C 与 h 内积
            y_t = y_t + self.D * x_proj[:, t, :]  # 加上残差连接
            ys.append(y_t)  # 收集输出
        
        y = torch.stack(ys, dim=1)  # (batch, seq_len, d_inner) — 堆叠所有时间步输出
        
        # 7. 门控：y * silu(z)
        y = y * F.silu(z)  # 门控分支 z 通过 SiLU 激活后与 SSM 输出逐元素相乘
        
        # 8. 输出投影：d_inner → d_model
        output = self.out_proj(y)  # (batch, seq_len, d_model) — 投影回原始维度
        return output  # 返回最终输出

# ============================================================
# 使用示例
# ============================================================
batch_size = 2  # 批次大小
seq_len = 128  # 序列长度
d_model = 256  # 模型维度

mamba = MambaBlock(d_model=256, d_state=16, d_conv=4, expand=2)  # 实例化 Mamba block
x = torch.randn(batch_size, seq_len, d_model)  # 随机输入
output = mamba(x)  # 前向传播

print(f"输入形状: {x.shape}")  # (2, 128, 256)
print(f"输出形状: {output.shape}")  # (2, 128, 256) — 与输入形状相同
print(f"参数量: {sum(p.numel() for p in mamba.parameters()) / 1e6:.2f}M")  # 打印参数量（百万）

复杂度分析

| 指标 | Mamba | Transformer |

|------|-------|-------------|

| 训练时间复杂度 | $ O(n \cdot d \cdot N) $ | $ O(n^2 \cdot d) $ |

| 推理时间复杂度 | $ O(n \cdot d \cdot N) $ | $ O(n^2 \cdot d) $ |

| 推理内存 | $ O(1) $（固定状态） | $ O(n) $（KV Cache） |

| 长序列支持 | 100K+ token | 通常 ≤ 8K token |

其中 $ n $ 为序列长度，$ d $ 为模型维度，$ N $ 为 SSM 状态维度。
