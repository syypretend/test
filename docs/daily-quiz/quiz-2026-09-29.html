算法编程 ⭐⭐ 第 1 题

判断二分图

给定一个无向图（$n$ 个节点，编号 $0 \sim n-1$，edges 为无向边列表），判断该图是否为**二分图**：即能否用两种颜色给所有顶点染色，使得任意一条边的两个端点颜色不同。是则返回 True，否则返回 False。
输入
函数参数：n（整数，节点数）、edges（二维列表，每项为一条无向边 [u, v]）
输出
返回布尔值 True（是二分图）/ False（不是二分图）
示例 1
输入：n=4, edges=[[0,1],[1,2],[2,3],[3,0]]
输出：True
4 个点构成偶环，可交替染成 0/1 两种颜色。
示例 2
输入：n=3, edges=[[0,1],[1,2],[2,0]]
输出：False
三角形是奇环，无法用两种颜色保证所有边两端异色。
约束
$1 \le n \le 1000$；$0 \le |edges| \le n(n-1)/2$；$0 \le u, v < n$（测试数据可能包含自环与重边，需自行容错）

💡 解题思路

**核心定理：无向图为二分图当且仅当图中不含奇环。**

采用 **BFS 染色法**：用一个 color 数组（-1 表示未染色，0/1 表示两种颜色）。
1. 遍历所有节点，若当前节点未染色，则以它为起点做 BFS，染 0 色；
2. 扩展时把每个未染色邻居染成与当前节点相反的色（color ^ 1）；
3. 若发现邻居已染色且颜色与当前节点相同，说明存在奇环，直接返回 False；
4. 所有连通分量遍历完均无冲突，返回 True。

注意：图可能不连通，必须对每个连通分量分别染色；重边不影响判色，自环（u==v）在扩展时必然触发同色冲突，天然判为非二分图。

📝 参考代码（python）

from collections import deque

def solve(n, edges):
    # 1. 建邻接表（容忍重边）
    g = [[] for _ in range(n)]
    for u, v in edges:
        g[u].append(v)
        g[v].append(u)

    color = [-1] * n          # -1 未染色；0/1 两种颜色
    for start in range(n):    # 遍历所有连通分量
        if color[start] != -1:
            continue
        color[start] = 0
        q = deque([start])
        while q:
            u = q.popleft()
            for v in g[u]:
                if color[v] == -1:        # 未染色 -> 染相反色
                    color[v] = color[u] ^ 1
                    q.append(v)
                elif color[v] == color[u]:  # 邻居同色 -> 奇环
                    return False
    return True

⚡ 复杂度分析

时间 O(n + |E|) 空间 O(n + |E|)（邻接表 + color 数组）

🎯 考点

二分图判定（染色法）、奇环与二分图的等价关系、BFS 遍历不连通分量、自环与重边容错

二分查找：循环边界与区间收缩

关于在**非降序数组**中查找**第一个大于等于 target 的元素位置**（即 lower_bound）的二分实现，下列说法中**错误**的是？
--- 以下为答案与解析 ---
✅ 正确答案：D

💡 解题思路

本题考察二分查找变体（lower_bound）的循环边界与区间收缩规则。逐项核对：A 描述闭区间退出关系正确；B 描述中点防溢出写法正确；C 描述左闭右开区间写法正确；D 的问题在于 lower_bound 要找的是**第一个** ≥ target 的位置，即使 nums[mid] == target，左侧可能还有等于 target 的元素，必须继续向左收缩（hi = mid），不能直接返回。

🎯 考点

二分查找变体、循环边界条件（闭区间 vs 左闭右开）、循环不变量、lower_bound 的定义与退出时含义

🔍 逐项分析

  • 正确：闭区间 [lo, hi] 在 while lo <= hi 中收缩（nums[mid] < target 时 lo = mid+1，否则 hi = mid-1），退出时必然 lo == hi + 1，且 lo 即为下界位置。
  • 正确：mid = lo + (hi - lo) // 2 与 (lo + hi) // 2 结果相同，但避免了 lo + hi 溢出（经典面试考点）。
  • 正确：左闭右开区间 [lo, hi) 的循环条件是 lo < hi；nums[mid] >= target 时 mid 可能是答案，收缩 hi = mid 保留候选；nums[mid] < target 时 lo = mid + 1。退出时 lo 即答案。
  • 错误：找到 nums[mid] == target 时，**最左侧**可能还有等于 target 的元素（如数组 [1,2,2,2,3] 中 target=2，mid 可能落在中间那个 2），必须继续向左搜索（hi = mid），直到循环结束才能保证返回第一个位置。
AI公式推导 ⭐⭐ 第 3 题

Word2Vec Skip-gram：目标函数、参数梯度与负采样

设词表大小为 $V$，给定中心词 $w_I$（索引 $I$）与上下文词 $w_O$（索引 $O$）。每个词 $w$ 有两个向量：输入向量 $v_w$（作中心词时）与输出向量 $u_w$（作上下文时）。

请完成三步推导：
1. 写出条件概率 $P(w_O \mid w_I)$ 的 softmax 形式与单样本对数似然 $L$；
2. 分别对 $v_{w_I}$ 与 $u_{w_j}$ 求偏导，说明梯度的含义；
3. 说明全词表 softmax 的计算瓶颈，并给出负采样（Negative Sampling）目标函数 $J$ 对 $v_{w_I}$ 的梯度。
--- 以下为答案与解析 ---

🎯 考点

Softmax 归一化与对数似然、输入/输出双向量参数化、链式法则与期望形式梯度、全词表瓶颈 O(Vd)、负采样二分类目标与 O((K+1)d) 复杂度

📐 推导过程

### 1. 条件概率与目标函数

Skip-gram 用中心词 $w_I$ 预测上下文词 $w_O$，条件概率用 softmax 归一化：

$$P(w_O \mid w_I) = \frac{\exp(u_{w_O}^{\top} v_{w_I})}{\sum_{j=1}^{V} \exp(u_{w_j}^{\top} v_{w_I})}$$

单个样本的对数似然（也是负损失）：

$$L = \log P(w_O \mid w_I) = u_{w_O}^{\top} v_{w_I} - \log\sum_{j=1}^{V} \exp(u_{w_j}^{\top} v_{w_I})$$

（Skip-gram 对整个窗口求多个上下文词对数似然的均值，各样本梯度形式相同，这里推导单样本。）

### 2. 对输入向量 $v_{w_I}$ 求梯度
记 $s_j = u_{w_j}^{\top} v_{w_I}$。第一部分求导得 $u_{w_O}$；第二部分用链式法则：

$$\frac{\partial}{\partial v_{w_I}} \log\sum_j e^{s_j} = \frac{1}{\sum_j e^{s_j}}\sum_j e^{s_j} \frac{\partial s_j}{\partial v_{w_I}} = \sum_j \frac{e^{s_j}}{\sum_k e^{s_k}} u_{w_j} = \sum_{j=1}^{V} P(w_j \mid w_I)\, u_{w_j}$$

合并两部分：

$$\boxed{\frac{\partial L}{\partial v_{w_I}} = u_{w_O} - \sum_{j=1}^{V} P(w_j \mid w_I)\, u_{w_j}}$$

含义：正样本（真实上下文）的输出向量 $u_{w_O}$ **拉近**中心词向量，同时把所有词的期望输出向量（权重为条件概率）**推远**。

### 3. 对输出向量 $u_{w_j}$ 的梯度

同样由链式法则（只有 $j$ 项含 $u_{w_j}$）：

$$\frac{\partial L}{\partial u_{w_j}} = \big(\mathbb{1}[w_j = w_O] - P(w_j \mid w_I)\big)\, v_{w_I}$$

即正样本：$(1 - P(w_O|w_I))v_{w_I}$；负样本：$-P(w_j|w_I)v_{w_I}$。

### 4. 计算瓶颈与负采样

上式中的 $\sum_{j=1}^{V}$ 每步更新都要遍历词表（$V$ 可达 $10^5 \sim 10^6$），计算量为 $O(V \cdot d)$。

**负采样（Negative Sampling）** 把 $V$ 分类的 softmax 换成 $K+1$ 个二分类：对正样本对 $(w_I, w_O)$ 与 $K$ 个按噪声分布 $P_n(w)$ 采样出的负样本 $w_k$，目标为：

$$J = \log \sigma(u_{w_O}^{\top} v_{w_I}) + \sum_{k=1}^{K} \mathbb{E}_{w_k \sim P_n(w)}\big[\log \sigma(-u_{w_k}^{\top} v_{w_I})\big]$$

其中 $\sigma(x)=1/(1+e^{-x})$，噪声分布常用 $P_n(w) \propto \mathrm{cnt}(w)^{3/4}$。

利用 $\dfrac{d}{dx}\log\sigma(x) = 1-\sigma(x)$、$\dfrac{d}{dx}\log\sigma(-x) = -\sigma(x)$：

$$\frac{\partial J}{\partial v_{w_I}} = \big(1 - \sigma(u_{w_O}^{\top} v_{w_I})\big)u_{w_O} - \sum_{k=1}^{K} \sigma(u_{w_k}^{\top} v_{w_I})\, u_{w_k}$$

同理 $\partial J/\partial u_{w_O} = (1-\sigma(u_O^\top v))v_{w_I}$，$\partial J/\partial u_{w_k} = -\sigma(u_k^\top v) v_{w_I}$。

每次更新只涉及 $K+1$ 个词向量（$K$ 通常取 5~20），单步复杂度降至 $O((K+1)d)$，远小于 $O(Vd)$。

🧠 直觉解释

Word2Vec 的本质是让中心词向量在嵌入空间中与「真实上下文词」更接近、与「随机采样词」更远，最终学到的向量空间保留了语义与共现相似度（经典结果：vec(king) − vec(man) + vec(woman) ≈ vec(queen)）。
AI面试问答 ⭐⭐ 第 4 题

Transformer 为什么要位置编码？RoPE 的原理与优势

面试高频题：自注意力机制本身不含任何顺序信息，为什么 Transformer 必须加位置编码？请说明正弦绝对位置编码与旋转位置编码（RoPE）的原理，并对比两者在表达能力、可外推性与工程实现上的优劣。
--- 以下为答案与解析 ---

📌 回答要点

  • 注意力是「位置无关」的：Attention(Q,K,V) = softmax(QK^T/√d)V 只对 token 内容做加权求和，打乱输入顺序，输出同样顺序置换。模型无法区分「我爱学习」与「学习爱我」，因此必须把顺序信息显式注入输入。
  • 正弦绝对位置编码：位置 m 被编码为固定三角函数 $PE_{m,2i}=\sin(m/10000^{2i/d})$、$PE_{m,2i+1}=\cos(m/10000^{2i/d})$ 加到词向量上。优点：无需训练、理论上可外推到任意长度；缺点：位置信息叠加进内容向量后经 QK^T 混合，模型需自行学习如何「解耦」使用位置。
  • RoPE 原理：对 query 与 key 按位置施加二维旋转矩阵 $R_m$（复数域等价为乘以 $e^{im\theta}$），即 $q_m = R_m q$、$k_n = R_n k$。旋转矩阵满足 $R_m^{\top} R_n = R_{n-m}$（正交性），于是
    $$(R_m q)^{\top}(R_n k) = q^{\top} R_{n-m}\, k$$
    注意乘积只依赖相对位置 $n-m$，与绝对位置无关。
  • RoPE 优势：1) 显式把「相对位置」编码进注意力分数，语义与位置天然分离；2) 旋转正交不改变向量范数，数值稳定；3) 无需学习位置矩阵、无额外参数，推理时用复数乘法快速实现；4) 对长度外推更友好（位置由连续角度参数化，未训练长度也有定义）。
  • 工程实现：按维度分块，每两个维度一组做 2×2 旋转（维度频率 θ_i = 10000^{−2i/d}，即不同维度旋转速度不同，低频长距离、高频短距离），实际计算为：旋转后的 $x = (x_0\cos\theta - x_1\sin\theta, x_0\sin\theta + x_1\cos\theta, \dots)$。主流大模型（LLaMA、Qwen、GLM）均采用 RoPE。

⭐ 加分项

  • 与相对位置编码对比：T5/ALiBi 直接把相对位置偏置加进注意力分数（显式位置偏置表），RoPE 则把相对位置「隐式」编码进 Q·K 内积，无需存储位置偏置表，训练更干净。
  • 长度外推优化：RoPE 超出训练长度后，常用位置插值（PI）、NTK-aware 缩放、YaRN 等方法扩展上下文，效果优于绝对位置编码，这是 LLM 长上下文工程的核心话题。
  • 绝对位置（learned/sinusoidal）在超过训练长度时要么无定义（未学到）要么退化，RoPE 相位连续的特性使外推成为可能。

🔮 追问预测

  • 追问1：为什么 RoPE 的内积只依赖相对位置？—— 因为旋转矩阵是正交的，$R_m^\top R_n = R_{n-m}$，代入内积即得 $q^\top R_{n-m} k$，与 m、n 的绝对值无关，只差 n−m。
  • 追问2：RoPE 如何处理超过训练窗口的长序列？—— 思路：频率缩放/插值（把旋转频率降到更慢，让新位置落在已见相位范围内），或 NTK-aware 外推等，都是工业界主流做法。
  • 追问3：绝对位置编码为什么外推能力差？—— learned 位置在训练长度外无 embedding；sinusoidal 虽可生成任意位置向量，但模型训练时从未见过这些位置相位，点积分布与训练分布偏移，性能衰减。
