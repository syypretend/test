算法编程 ⭐⭐ 第 1 题

打家劫舍 III：树形 DP 的两状态设计

小区变成了一棵二叉树：每个节点代表一栋房子，节点值是该房子的现金。小偷不能同时偷直接相连的两栋房子（即父节点与子节点不能同时选），否则会触发报警。

给定二叉树的层序数组（null 表示空节点），求一夜能偷到的最高金额。

为什么是树形 DP：对任意节点 $u$，只需要知道「抢 $u$」和「不抢 $u$」两种状态下子树的最优值：
- 抢 $u$：两个孩子都不能抢，收益为 $u.val + skip(left) + skip(right)$；
- 不抢 $u$：两个孩子各自可以抢也可以不抢，收益为 $\max(take,skip)(left)+\max(take,skip)(right)$。

两种状态互相依赖、自底向上合并，正是树形 DP 的标准形态。
输入
一个层序数组，元素为整数或 null（Python 中为 None），按完全二叉树的层序排列，末尾的空节点可省略。
输出
一个整数，表示能偷到的最高金额。
示例 1
输入：[3,2,3,null,3,null,1]
输出：7
偷第 1 层（3）和第 3 层的两个 3，再偷最右下的 1，总额 3+3+1=7；不能同时偷 3 和它的孩子 2、3。
示例 2
输入：[3,4,5,1,3,null,1]
输出：9
偷 4 + 5 = 9，或 3+1+3=7，最优为 9。
约束
节点数 $1\le n\le 10^4$；$0\le node.val\le 10^4$；树可能是一条链（深度可达 $n$），递归实现需注意栈深度。

💡 解题思路

对每个节点定义两个 DP 值：take[u] 表示抢 u 时子树最大收益，skip[u] 表示不抢 u 时子树最大收益。转移：take[u]=u.val+skip[left]+skip[right]；skip[u]=max(take,skip)[left]+max(take,skip)[right]。答案 max(take[root],skip[root])。因为孩子要先算完，采用后序遍历；链式树最深可达 10^4，Python 递归容易爆栈，参考代码用显式栈做迭代后序，把「访问标记」压栈两次实现。

📝 参考代码（python）

from collections import deque


class TreeNode:
    __slots__ = ("val", "left", "right")

    def __init__(self, val=0):
        self.val = val
        self.left = None
        self.right = None


def build_tree(level_order):
    """按层序数组建树，None 表示空节点。"""
    if not level_order or level_order[0] is None:
        return None
    root = TreeNode(level_order[0])
    q = deque([root])
    i = 1
    while q and i < len(level_order):
        node = q.popleft()
        if i < len(level_order) and level_order[i] is not None:
            node.left = TreeNode(level_order[i])
            q.append(node.left)
        i += 1
        if i < len(level_order) and level_order[i] is not None:
            node.right = TreeNode(level_order[i])
            q.append(node.right)
        i += 1
    return root


def rob(level_order):
    root = build_tree(level_order)
    if root is None:
        return 0

    # take[u] / skip[u]：以 u 为根的子树，在「抢 u」/「不抢 u」时的最大收益
    take, skip = {}, {}
    stack = [(root, False)]          # (节点, 是否已访问过孩子)
    while stack:
        node, visited = stack.pop()
        if node is None:
            continue
        if visited:                  # 后序位置：孩子已经算完
            lt = take.get(node.left, 0)
            ls = skip.get(node.left, 0)
            rt = take.get(node.right, 0)
            rs = skip.get(node.right, 0)
            take[node] = node.val + ls + rs
            skip[node] = max(lt, ls) + max(rt, rs)
        else:                        # 先序位置：先压自己，再压孩子
            stack.append((node, True))
            stack.append((node.left, False))
            stack.append((node.right, False))

    return max(take[root], skip[root])

⚡ 复杂度分析

时间 O(n)，每个节点进出栈各一次 空间 O(n)，哈希表存两状态 + 显式栈（递归实现则为 O(h) 栈空间）

🎯 考点

树形 DP 的状态设计（选/不选当前节点）、后序遍历的自底向上合并、父子互斥约束的转化、递归深度与迭代后序的工程取舍。

💡 解题思路

树状数组的核心是二进制拆分：t[i] 管理的是区间 (i-lowbit(i), i] 这一段，查询前缀和时不断去掉最低位的 1，修改时不断进位到最低位的 1，路径长度都是 O(log n)。

🎯 考点

lowbit 的补码含义、t[i] 的管理区间、更新/查询方向、O(n) 建树、以及「区间加+区间求和」的双 BIT 扩展。

🔍 逐项分析

  • A 正确：i & -i 利用补码取出最低位的 1；更新向上 i += lowbit(i)，查询向下 i -= lowbit(i)，两个方向都恰好经过 O(log n) 个节点。
  • B 错误：t[i] 只管理 (i-lowbit(i), i] 这一段，不是 a[1..i] 的完整前缀和。例如 i=6 时 lowbit=2，t[6] 只管 a[5]+a[6]。
  • C 错误：可以 O(n) 建树——先令 t[i]=a[i]，再对每个 i 把 t[i] 加到 t[i+lowbit(i)] 上，每个节点只被加一次，总复杂度 O(n)。
  • D 错误：维护差分数组 D 的两棵 BIT（一棵存 D，一棵存 i·D）即可支持区间加、区间求和，查询时用前缀和公式组合，仍是 O(log n)。
AI公式推导 ⭐⭐⭐ 第 3 题

DDPM 扩散模型：从 ELBO 推导到「预测噪声」的 MSE

上一期（11-04）用变分下界推导了 VAE 的 ELBO。扩散模型 DDPM 同样是最大化对数似然的下界，但它的前向过程被设计成高斯马尔可夫链，最终训练目标却简化为一个非常干净的噪声预测均方误差。

请完成：
1. 推导前向过程的闭式边缘分布 $q(x_t\mid x_0)$；
2. 写出后验 $q(x_{t-1}\mid x_t,x_0)$ 的均值与方差；
3. 从 ELBO 出发，说明每一层 KL 如何化为 $\|\epsilon-\epsilon_\theta\|^2$，并得到 $L_{\text{simple}}$。
--- 以下为答案与解析 ---

🎯 考点

高斯马尔可夫链的闭式边缘分布（方差可加性）、贝叶斯后验的高斯配方、ELBO 的三项分解、固定方差下 KL 退化为均值匹配、噪声参数化与重参数化技巧。

📐 推导过程

符号约定：$x_0$ 为真实数据，$x_1,\dots,x_T$ 为逐步加噪得到的隐变量；噪声日程 $\beta_t\in(0,1)$，记 $\alpha_t=1-\beta_t$，$\bar\alpha_t=\prod_{s=1}^{t}\alpha_s$，且 $\bar\alpha_T\approx 0$。

第 1 步：前向过程是马尔可夫高斯链

$$q(x_t\mid x_{t-1})=\mathcal N\left(x_t;\sqrt{\alpha_t}\,x_{t-1},\ \beta_t I\right)$$

等价的重参数化写法（$\epsilon_t\sim\mathcal N(0,I)$）：

$$x_t=\sqrt{\alpha_t}\,x_{t-1}+\sqrt{\beta_t}\,\epsilon_t$$

第 2 步：推导任意时刻的边缘分布 $q(x_t\mid x_0)$（闭式解）

展开两步：

$$x_t=\sqrt{\alpha_t}\left(\sqrt{\alpha_{t-1}}x_{t-2}+\sqrt{\beta_{t-1}}\epsilon_{t-1}\right)+\sqrt{\beta_t}\epsilon_t$$

设归纳假设 $x_{t-1}=\sqrt{\bar\alpha_{t-1}}x_0+\sqrt{1-\bar\alpha_{t-1}}\,\epsilon'$，代入得

$$x_t=\sqrt{\alpha_t\bar\alpha_{t-1}}\,x_0+\sqrt{\alpha_t(1-\bar\alpha_{t-1})}\,\epsilon'+\sqrt{\beta_t}\,\epsilon_t$$

两个独立零均值高斯相加，方差相加：

$$\alpha_t(1-\bar\alpha_{t-1})+\beta_t=\alpha_t-\alpha_t\bar\alpha_{t-1}+1-\alpha_t=1-\bar\alpha_t$$

因此

$$x_t=\sqrt{\bar\alpha_t}\,x_0+\sqrt{1-\bar\alpha_t}\,\epsilon,\qquad \epsilon\sim\mathcal N(0,I)$$

即 $q(x_t\mid x_0)=\mathcal N\left(\sqrt{\bar\alpha_t}x_0,(1-\bar\alpha_t)I\right)$。这是 DDPM 能在任意 $t$ 一步采样、无需逐步加噪的关键。

第 3 步：反向过程需要后验 $q(x_{t-1}\mid x_t,x_0)$

由贝叶斯公式，$q(x_{t-1}\mid x_t,x_0)\propto q(x_t\mid x_{t-1})\,q(x_{t-1}\mid x_0)$。两个高斯相乘仍是高斯，对指数部分配方。两个分布的精度（方差的倒数）相加：

$$\frac{1}{\tilde\beta_t}=\frac{\alpha_t}{\beta_t}+\frac{1}{1-\bar\alpha_{t-1}}
=\frac{\alpha_t(1-\bar\alpha_{t-1})+\beta_t}{\beta_t(1-\bar\alpha_{t-1})}
=\frac{1-\bar\alpha_t}{\beta_t(1-\bar\alpha_{t-1})}$$

$$\tilde\beta_t=\frac{\beta_t(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}$$

均值由两个均值按精度加权：

$$\tilde\mu_t=\frac{\sqrt{\alpha_t}(1-\bar\alpha_{t-1})}{1-\bar\alpha_t}x_t
+\frac{\sqrt{\bar\alpha_{t-1}}\,\beta_t}{1-\bar\alpha_t}x_0$$

第 4 步：写出 ELBO 并分解

$$\log p_\theta(x_0)\ge \mathbb E_q\left[\log p_\theta(x_T)+\sum_{t=1}^{T}\log p_\theta(x_{t-1}\mid x_t)-\sum_{t=1}^{T}\log q(x_t\mid x_{t-1})\right]$$

整理成三项：

$$-L_T-\sum_{t=2}^{T}L_{t-1}-L_0$$

其中 $L_T=\mathrm{KL}(q(x_T\mid x_0)\|p_\theta(x_T))$ 与参数无关（$\bar\alpha_T\approx0$ 时近似先验）；$L_0=-\log p_\theta(x_0\mid x_1)$；核心是

$$L_{t-1}=\mathbb E_q\left[\mathrm{KL}\left(q(x_{t-1}\mid x_t,x_0)\,\|\,p_\theta(x_{t-1}\mid x_t)\right)\right]$$

第 5 步：固定方差的高斯 KL 退化为均值匹配

取 $p_\theta(x_{t-1}\mid x_t)=\mathcal N(\mu_\theta(x_t,t),\sigma_t^2 I)$，$\sigma_t^2$ 固定。两个同方差高斯的 KL 为

$$\mathrm{KL}=\frac{1}{2\sigma_t^2}\|\tilde\mu_t-\mu_\theta\|^2+\text{常数}$$

所以训练目标等价于让网络预测的均值逼近后验均值 $\tilde\mu_t$。

第 6 步：把均值预测改写为噪声预测

由第 2 步，$x_0=\dfrac{x_t-\sqrt{1-\bar\alpha_t}\,\epsilon}{\sqrt{\bar\alpha_t}}$。代入 $\tilde\mu_t$ 并化简：

$$\tilde\mu_t=\frac{1}{\sqrt{\alpha_t}}\left(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\epsilon\right)$$

于是让网络输出 $\epsilon_\theta(x_t,t)$，并令

$$\mu_\theta(x_t,t)=\frac{1}{\sqrt{\alpha_t}}\left(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\,\epsilon_\theta(x_t,t)\right)$$

两者相减：

$$\tilde\mu_t-\mu_\theta=\frac{1}{\sqrt{\alpha_t}}\cdot\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\left(\epsilon_\theta-\epsilon\right)$$

平方后得到

$$L_{t-1}=\frac{\beta_t^2}{2\sigma_t^2\alpha_t(1-\bar\alpha_t)}
\mathbb E\left\|\epsilon-\epsilon_\theta\!\left(\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon,\ t\right)\right\|^2$$

第 7 步：去掉权重得到简化损失

DDPM 发现把前面的系数丢掉、对 $t$ 均匀采样，训练更稳定且效果更好：

$$L_{\text{simple}}=\mathbb E_{t,x_0,\epsilon}\left\|\epsilon-\epsilon_\theta\left(\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon,\ t\right)\right\|^2$$

采样（反向生成）：从 $x_T\sim\mathcal N(0,I)$ 开始，对 $t=T,\dots,1$

$$x_{t-1}=\frac{1}{\sqrt{\alpha_t}}\left(x_t-\frac{\beta_t}{\sqrt{1-\bar\alpha_t}}\epsilon_\theta(x_t,t)\right)+\sigma_t z,\qquad z\sim\mathcal N(0,I)$$

（$t=1$ 时 $z=0$。）

🧠 直觉解释

前向过程把图像一步步"溶解"成标准高斯噪声，且任意时刻都能用 $\sqrt{\bar\alpha_t}x_0+\sqrt{1-\bar\alpha_t}\epsilon$ 一步到位；反向过程则训练一个网络在每一步"猜出当时加进去的噪声"，猜准了就能把它减掉，从而一步步还原图像。ELBO 的每一层 KL 在固定方差下都等价于"预测噪声的均方误差"，这就是 DDPM 损失如此简洁的根本原因。
AI面试问答 ⭐⭐ 第 4 题

MoE 混合专家：为什么参数变多而计算量不涨？如何保证负载均衡？

面试官问：「MoE（Mixture-of-Experts）为什么能在不显著增加计算量的情况下把模型参数量做大？训练时专家负载不均衡怎么办？MoE 推理一定更快吗？」请给出结构化回答。
--- 以下为答案与解析 ---

📌 回答要点

  • 结构替换：MoE 把 Transformer 的 FFN 层换成 $N$ 个并列专家 $E_1,\dots,E_N$ 加一个轻量路由网络。对每个 token，路由计算 $g=\mathrm{softmax}(W_g x)$，只取 Top-$k$（常见 $k=1$ 或 $2$）个专家加权求和：$y=\sum_{i\in\mathrm{TopK}} g_i E_i(x)$。
  • 参数与计算解耦：总参数量随 $N$ 线性增长（知识容量变大），但每个 token 只经过 $k$ 个专家，前向 FLOPs 约等于稠密模型的 $k/N$ 倍。例如 Mixtral 8×7B 总参数约 46.7B、每 token 激活约 12.9B；DeepSeek-V3 总参数 671B、激活 37B。
  • 为什么要负载均衡：路由是"赢者通吃"的，训练初期容易强者愈强，出现专家坍缩（少数专家吃掉大部分 token，其余专家几乎不更新）。Switch Transformer 的辅助损失为 $\mathcal L_{\text{aux}}=\alpha N\sum_{i=1}^{N} f_i P_i$，其中 $f_i$ 是实际分到专家 $i$ 的 token 比例，$P_i$ 是路由给专家 $i$ 的平均概率；两者都高才受罚，促使分配均匀。
  • 工程约束：常用 capacity factor（专家容量 $=\text{capacity factor}\times\text{tokens}/N$）限制单专家负载，超出容量的 token 被丢弃（token dropping）或走残差；容量因子调大减少丢弃但增加显存与通信。专家并行（expert parallelism）把不同专家放到不同 GPU，需要 All-to-All 通信，因此对互联带宽敏感。
  • 代价与取舍：所有专家都要驻留显存，显存占用不降；路由带来动态计算、负载抖动和训练不稳定；小 batch 或单序列解码时每 token 只算少数专家，算术强度低，权重加载和通信反而可能让推理不变快。

⭐ 加分项

  • 细粒度 + 共享专家：DeepSeekMoE 把专家切得更细（更多、更小的专家）提高组合灵活性，并设置始终激活的共享专家来承载通用知识，减少不同专家之间的知识冗余。
  • 路由稳定性技巧：router z-loss 惩罚路由 logits 的幅值、对门控做 float32 计算、噪声注入（训练时给路由加高斯噪声）都能缓解专家坍缩和训练抖动。
  • Dense 到 MoE 的转换：MoE upcycling 把一个稠密模型的 FFN 复制成多个专家再继续预训练，比从零训练更省算力。
  • 与稠密模型的公平比较：应同时报告总参数与激活参数、训练 token 数、推理硬件与 batch 条件；只比总参数会高估 MoE 的实际收益。

🔮 追问预测

  • 追问：Top-$k$ 的 $k$ 怎么选？ 回答思路：$k$ 越大，单 token 用到的专家越多、质量通常越好，但 FLOPs 与通信线性上升；$k=1$ 最省算力但路由容错差，$k=2$ 是质量/效率的常用折中。还要结合专家总数 $N$、单专家容量和硬件互联带宽一起定。
  • 追问：capacity factor 设小了会怎样？ 回答思路：单专家能处理的 token 数受限，超出的 token 被丢弃（不经过该层或走残差），造成信息损失与训练/推理不一致；设大一些可减少丢弃，但会浪费显存并增加 All-to-All 通信量，通常按任务在 1.0～2.0 之间调。
  • 追问：MoE 微调要注意什么？ 回答思路：下游数据少时路由容易漂移、专家进一步失衡，可冻结路由或加负载均衡损失；学习率通常比稠密模型更小；要监控每个专家的 token 占比与梯度范数，防止部分专家"死掉"。
  • 追问：MoE 推理一定更快吗？ 回答思路：不一定。预填充阶段 batch 大、矩阵乘效率高时收益明显；单请求逐 token 解码时每步只激活少数专家，显存带宽和专家并行通信成为瓶颈，吞吐提升有限，需要靠大批量/专家本地化/量化来摊薄。
