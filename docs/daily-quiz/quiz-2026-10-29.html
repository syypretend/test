算法编程 ⭐⭐ 第 1 题

环形打家劫舍（首尾相邻版）

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是**相邻的房屋装有相互连通的防盗系统**，如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警。

这一次，房屋围成一个**环**——也就是说，第一间房和最后一间房也是相邻的。给定一个代表每个房屋存放金额的非负整数数组 nums，请计算在**不触动警报装置**的情况下，一夜之内能够偷窃到的最高金额。

提示：环形约束并不能简单地"把数组当成链"做一次 DP，请思考如何把一个环拆成两个**互斥的线性子问题**。
输入
一个非负整数数组 nums，表示每间房屋的金额。
输出
一个整数，表示能偷到的最大金额。
示例 1
输入：nums = [2, 3, 2]
输出：3
不能偷第 0 间和第 2 间（首尾相邻），只能偷第 1 间的 3，故最大金额为 3。
示例 2
输入：nums = [1, 2, 3, 1]
输出：4
偷第 0 间（1）和第 2 间（3），二者不相邻，合计 4；不能选 1+3+1 因为首尾相邻。
示例 3
输入：nums = [10, 1, 1, 10]
输出：11
两端的 10 相邻（环形），只能取其一：10 + 1 = 11，而不是 20。
约束
1 <= nums.length <= 100；0 <= nums[i] <= 1000；nums 首尾视为相邻。

💡 解题思路

环形数组的关键在于：**第 0 间和第 n-1 间互斥**。于是最优解必然属于下面两种情况之一：

1. **不偷第 n-1 间**：问题退化为在 nums[0..n-2] 上做线性打家劫舍；
2. **不偷第 0 间**：问题退化为在 nums[1..n-1] 上做线性打家劫舍。

两者取最大即可（若同时不偷首尾，两种方案都覆盖得到，不影响正确性）。

线性版本的状态定义：dp[i] 表示考虑前 i 间房能偷到的最大金额，转移为

$$dp[i] = \max(dp[i-1],\; dp[i-2] + nums[i-1])$$

含义是"第 i 间不偷"或"第 i 间偷（则第 i-1 间必不偷）"。用两个滚动变量即可把空间降到 O(1)。

**易错点**：
- n=2 时首尾相邻，两个子数组各只有一个元素，答案是 max(nums)；
- 不能直接 max(线性DP(nums), 线性DP(nums[1:-1]) + nums[0] + nums[-1]) 之类拼凑，容易重复计数；
- 全 0 数组要返回 0 而不是 -1。

📝 参考代码（python）

def rob(nums):
    """环形打家劫舍：拆成"不偷最后一间"和"不偷第一间"两个线性问题。"""
    n = len(nums)
    if n == 1:
        return nums[0]

    def rob_line(arr):
        # dp[i] = 前 i 间房能偷到的最大金额（滚动两个变量）
        prev2, prev1 = 0, 0
        for x in arr:
            prev2, prev1 = prev1, max(prev1, prev2 + x)
        return prev1

    return max(rob_line(nums[:-1]), rob_line(nums[1:]))

⚡ 复杂度分析

时间 O(n) 空间 O(1)

🎯 考点

考点：动态规划（Topic 13）·环形 DP 的"破环成链"技巧。核心是把环形互斥约束转化为两个线性子问题，再用滚动变量把空间压到 O(1)。同类思想可迁移到"环形加油站""环形最大子数组和（LeetCode 918）"等题。

💡 解题思路

关键在于"**不是所有节点都有 log n 的高度**"。完全二叉树中，绝大多数节点集中在底层，而底层节点高度为 0，几乎不用下沉；高度越大节点越少，代价按几何级数衰减，求和后收敛为常数。

🎯 考点

考点：堆（Topic 5）·建堆摊还复杂度分析。要能写出求和式并用几何级数收敛说明 O(n)，同时区分"建堆""插入建堆""堆排序"三者复杂度。

🔍 逐项分析

  • A 正确：高度为 h 的节点数约为 n/2^(h+1)，每个下沉最多 h 次比较交换，总代价 T(n) = Σ_{h=0}^{log n} (n/2^(h+1))·h = (n/2)·Σ h/2^h = (n/2)·2 = O(n)。（利用 Σ_{h≥1} h/2^h = 2。）
  • B 错误：把"最坏高度 O(log n)"直接乘节点数 n，忽略了不同高度节点的数量分布，这是把上界当成了紧界；只有根节点附近才接近 log n 层，数量极少。
  • C 错误：两者说反了——逐个插入建堆是 O(n log n)（每次上浮 O(log n)），自底向上建堆才是 O(n)，这正是标准库优先采用它的原因。
  • D 错误：建堆只保证"堆序性质"（父 ≤/≥ 子），是**偏序**而非全序；堆排序仍要反复取堆顶并下沉，整体是 O(n log n)。
AI公式推导 ⭐⭐⭐ 第 3 题

从 BCE 到 softplus：二分类损失的数值稳定推导

训练二分类模型时，标签 $y\in\{0,1\}$，模型输出 logit $z$，预测概率 $p=\sigma(z)$。教科书上的二元交叉熵为

$$L=-\big[y\log p+(1-y)\log(1-p)\big]$$

但工程实现（如 PyTorch 的 BCEWithLogitsLoss）从不先算 $p$ 再取对数，而是直接在 logit 上计算。请完成以下任务：

1. 把 $p=\sigma(z)$ 代入，把 $L$ 化简为只含 $z$ 的形式，并证明
$L=\mathrm{softplus}(z)-y z$；
2. 说明"先算 $p$ 再取 $\log$"在 $|z|$ 很大时为什么会产生 $\infty$ / NaN；
3. 给出 $\mathrm{softplus}$ 的数值稳定实现形式并证明其等价性；
4. 推导 $\dfrac{\partial L}{\partial z}=\sigma(z)-y$，并解释它为什么天然数值安全。
--- 以下为答案与解析 ---

🎯 考点

考点：交叉熵 + sigmoid 的数值稳定性（AI 池·神经网络基础/训练技巧维度）。要掌握：恒等式 $\log\sigma(z)=-\mathrm{softplus}(-z)$、$L=\mathrm{softplus}(z)-yz$、$\partial L/\partial z=\sigma(z)-y$，以及 softplus/log-sum-exp 的稳定写法。这三条正是所有深度学习框架损失函数实现的骨架。

📐 推导过程

**Step 0：符号与两个恒等式**

记 $\sigma(z)=\dfrac{1}{1+e^{-z}}$，则 $1-\sigma(z)=\sigma(-z)=\dfrac{1}{1+e^{z}}$，且 $\sigma'(z)=\sigma(z)\big(1-\sigma(z)\big)$。

**Step 1：代入并化简为 logit 形式**

先看两个对数项：

$$\log\sigma(z)=\log\frac{1}{1+e^{-z}}=-\log\big(1+e^{-z}\big)$$

$$\log\big(1-\sigma(z)\big)=\log\frac{1}{1+e^{z}}=-\log\big(1+e^{z}\big)$$

代回 $L$：

$$L=y\log\big(1+e^{-z}\big)+(1-y)\log\big(1+e^{z}\big)$$

引入 $\mathrm{softplus}(x)=\log(1+e^{x})$，即

$$L=y\,\mathrm{softplus}(-z)+(1-y)\,\mathrm{softplus}(z)$$

利用恒等式 $\mathrm{softplus}(-z)=\mathrm{softplus}(z)-z$（因为 $\log(1+e^{-z})=\log\frac{1+e^{z}}{e^{z}}=\log(1+e^{z})-z$）展开：

$$L=y\big[\mathrm{softplus}(z)-z\big]+(1-y)\mathrm{softplus}(z)=\mathrm{softplus}(z)-y z$$

**关键收益**：$L$ 只依赖 $z$，其中没有任何 $\log 0$ 或 $\log$ 的负数参数，而 $y$ 只以线性项 $yz$ 出现。

**Step 2：先算 $p$ 再取 $\log$ 的数值灾难**

设 $z=-40$（模型非常确信是负类）。数学上 $p=\sigma(-40)=e^{-40}/(1+e^{-40})\approx 4.2\times10^{-18}$，但 float32 的最小正规数约为 $1.2\times10^{-38}$、次正规数下限约 $1.4\times10^{-45}$，而 float16 的下限只有约 $6\times10^{-8}$。于是：

- float16 下 $e^{-40}$ 直接下溢为 $0$，$p=0$，$\log p=-\infty$，$L=+\infty$，反向传播得到 $\mathrm{NaN}$；
- $z=+40$ 时 $e^{40}\approx2.4\times10^{17}$ 在 float32 中上溢（上限约 $3.4\times10^{38}$ 尚可，但 float16 上限仅 $65504$，$e^{11.09}$ 即溢出），$p$ 被截断为 $1$，$\log(1-p)=-\infty$。

本质原因是：**取对数把相对误差放大了**——$p$ 的极小值被浮点下溢抹成 0 后，$\log$ 无法从其"死值"恢复信息。而 $\mathrm{softplus}(z)-yz$ 中，先做的是加法，大数被 $\max$ 保护，不会走到 $\infty$。

**Step 3：softplus 的稳定形式**

$$\mathrm{softplus}(x)=\max(x,0)+\log\big(1+e^{-|x|}\big)$$

证明（分两种情况，指数项恒 $\le 0$ 故永不溢出）：

- $x\ge 0$：$\max=x$，右端 $=x+\log(1+e^{-x})=\log\big(e^{x}(1+e^{-x})\big)=\log(e^{x}+1)$ ✓
- $x<0$：$\max=0$，右端 $=\log(1+e^{x})=\log(1+e^{-|x|})$ ✓

这与 log-sum-exp 的稳定技巧同源：$\log\sum_i e^{x_i}=m+\log\sum_i e^{x_i-m}$，$m=\max_i x_i$；此处只有两个"项" $0$ 与 $x$，故 $m=\max(0,x)$。

**Step 4：梯度推导**

对 $L=\mathrm{softplus}(z)-yz$ 求导，$\dfrac{d}{dz}\mathrm{softplus}(z)=\sigma(z)$，于是

$$\frac{\partial L}{\partial z}=\sigma(z)-y$$

若沿原始链路核对一遍：$\dfrac{\partial L}{\partial p}=-\dfrac{y}{p}+\dfrac{1-y}{1-p}$，$\dfrac{\partial p}{\partial z}=p(1-p)$，相乘得

$$\frac{\partial L}{\partial z}=-y(1-p)+(1-y)p=p-y=\sigma(z)-y$$

与上式一致，说明 sigmoid 与 log 的导数**精确抵消**了 $p(1-p)$ 分母，所以梯度里不再出现 $1/p$ 这类"小分母"。即使 $\sigma(z)$ 在数值上饱和到 $0$ 或 $1$，梯度也只是变成 $0$（消失），而不会像 $1/p$ 那样爆炸成 $\infty$。

**Step 5：多分类推广（选修）**

同样的手法给出 softmax + 交叉熵的稳定形式：对 logits $z\in\mathbb{R}^{K}$ 与 one-hot $y$，

$$L=-z_{c}+\log\sum_{k=1}^{K}e^{z_k}=\log\sum_{k}e^{z_k-m}-(z_c-m),\quad m=\max_k z_k$$

这正是 torch.nn.CrossEntropyLoss 内部使用 log-sum-exp 的原因。

🧠 直觉解释

$y\log\sigma(z)$ 这类项在数学上"等价"，在浮点数上却"不等价"：把 $\log$ 与 $\sigma$ 合并成 softplus 后，最大的数被 $\max$ 保护住、指数项恒非正，既不会溢出也不会下溢；而梯度化简成 $\sigma(z)-y$ 后连分母都不剩，只可能"梯度消失"，不可能"梯度爆炸"。
AI面试问答 ⭐⭐⭐ 第 4 题

MLA（多头潜在注意力）如何压缩 KV Cache？

面试官问：DeepSeek 系列模型使用 MLA（Multi-head Latent Attention）替代标准 MHA，号称把推理时的 KV Cache 压缩到原来的十分之一量级，而效果不降反升。请你讲清楚：MLA 到底压了什么、怎么压的、为什么它比 MQA/GQA 更"安全"，以及实现上最棘手的地方在哪里。
--- 以下为答案与解析 ---

📌 回答要点

  • **先说痛点**：自回归解码时每层都要缓存历史 token 的 K 和 V，显存占用为 $2\cdot n_h\cdot d_h\cdot L\cdot B$（头数×头维×序列长×批大小），长上下文场景下 KV Cache 往往比模型权重还大，且 decode 阶段每步都要把整份 cache 从 HBM 读进 SM，是典型的 memory-bound 瓶颈——所以压缩的不只是显存，更是**带宽**。
  • **MQA/GQA 的思路是"共享头"**：MQA 让所有 Q 头共用 1 组 KV，GQA 让每组若干 Q 头共用 1 组 KV（GQA 组数 $g$ 介于 1 和 $n_h$ 之间）。压缩率等于 $n_h/g$，粗暴有效，但共享意味着不同头被迫用同一份 K/V 表达不同 subspace，表达能力受损。
  • **MLA 的思路是"低秩压缩"而非"共享"**：不再缓存完整 K/V，而是先把隐状态 $h_t$ 投影成一个低维 latent $c_t=W^{DKV}h_t\in\mathbb{R}^{d_c}$，其中 $d_c\ll 2n_hd_h$，**只缓存 $c_t$**；需要时再用上投影矩阵 $W^{UK},W^{UV}$ 还原出各头的 K、V。因为每个头仍然有自己独立的上投影，头与头之间不再共享同一份表示，所以能在极大压缩下保住 MHA 级别的表达能力。
  • **关键补丁：解耦 RoPE**。RoPE 是位置相关的旋转操作，它与线性投影**不可交换**（$\mathrm{RoPE}(Wc)\neq W\,\mathrm{RoPE}(c)$），因此如果对缓存的 latent 直接施加 RoPE，还原出的 K 位置信息就错了；而如果先还原再 RoPE，则每步都要重算全部历史 K，缓存收益归零。MLA 的解法是**额外维护一份很小的、显式带 RoPE 的 key** $k^R_t$（每头仅 $d_h^R$ 维，通常 64），查询侧也拼接对应的带位置分量，两部分得分相加。所以严格说 MLA = 「低秩压缩（$c^{KV}$）」+「解耦 RoPE（$k^R$）」两件事。
  • **收益与代价**：推理时 $W^{UK}$ 可以"吸收"进 $W^Q$、$W^{UV}$ 吸收进 $W^O$，从而在 decode 阶段不做显式还原，计算量甚至低于 MHA；代价是实现复杂（prefill 与 decode 两套 kernel、吸收前后数值一致性、张量并行时 latent 维度的切分方式受限、量化时 latent 分布更敏感）。

⭐ 加分项

  • 能给出量级感：DeepSeek-V2 报告中，MLA 的 KV Cache 约为同等 MHA 的 1/10 左右，吞吐提升数倍；DeepSeek-V3 继续沿用，说明不是一次性技巧。
  • 能说清对比维度：MQA/GQA 压的是"头数"（结构化共享），MLA 压的是"表示维度"（低秩），两者正交，理论上可以叠加（先低秩再分组），但工程收益与复杂度需要权衡。
  • 能指出"效果不降反升"的机理：低秩瓶颈相当于对 KV 表示加了强正则，配合更大的训练规模，反而缓解了过拟合；且 latent 缓存减少了访存，允许更大 batch。
  • 能把 KV Cache 问题上升为"推理优化的三段论"：减少缓存体积（MLA/GQA）、减少读取次数（PagedAttention 分页管理、continuous batching）、减少精度位宽（KV 量化 FP8/INT8），三者可以组合使用。

🔮 追问预测

  • **追问：为什么 RoPE 不能作用在压缩后的 latent 上？** 回答思路：RoPE 是逐位置的正交旋转，作用在 $q,k$ 上依赖 head 维度的成对结构；而 latent 是跨头共享的低维向量，旋转矩阵与上投影矩阵 $W^{UK}$ 不对易，先转后投 ≠ 先投后转，结果相当于给 K 施加了错误的位置相位；解耦一份独立的小 key 是最省事的修复。
  • **追问：MLA 和 GQA 能不能一起用？** 回答思路：可以，先做低秩投影再在 latent 上分组共享；但压缩率叠加后表达能力下降更快，实践中更常见的是 MLA 单独使用。
  • **追问：KV Cache 量化与 MLA 叠加有什么坑？** 回答思路：latent 的数值范围由投影矩阵决定，不同通道方差差异大，per-tensor 量化误差大，需要 per-channel / 分组量化；且 FP8 下的动态范围要结合 RoPE 分量的独立尺度处理。
  • **追问：既然 MLA 这么好，为什么不是所有模型都用？** 回答思路：一是实现与训练成本高（需要专门 kernel 与并行策略），二是吸收式优化与 LoRA 微调、张量并行的组合约束多；很多团队用 GQA 就能拿到 80% 的收益，性价比更高。
