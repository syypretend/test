算法编程 ⭐⭐ 第 1 题

最近公共祖先（LCA）

给定一棵二叉树（所有节点值互不相同）以及树中的两个节点值 p、q。

二叉树中，节点 x 的「祖先」定义为从根节点到 x 的路径上的所有节点（包含 x 自身）。请找出 p 与 q 的最近公共祖先（LCA）：在同时是 p 与 q 的祖先的节点中，深度最大的那个。

注意：若 p 是 q 的祖先（或 p == q），则 LCA 就是 p 自身。

二叉树以层序遍历数组给出（LeetCode 风格），空位置用 None 占位。示例中的树形如下：
3
      /   \
     5     1
    / \   / \
   6   2 0   8
      / \
     7   4
输入
tree：层序遍历数组（列表），tree[0] 为根节点，None 表示空占位
p、q：两个目标节点值，保证存在于树中（允许 p == q，允许一个是另一个的祖先）
输出
返回 p 与 q 的最近公共祖先的节点值。
示例 1
输入：tree = [3,5,1,6,2,0,8,None,None,7,4], p = 5, q = 1
输出：3
5 位于根 3 的左子树，1 位于右子树，p、q 分居根的两侧，因此 LCA 为 3。
示例 2
输入：tree = [3,5,1,6,2,0,8,None,None,7,4], p = 5, q = 4
输出：5
4 位于 5 的子树内（路径 5→2→4），即 5 本身是 4 的祖先，因此 LCA 为 5。
约束
1 ≤ 树中节点数 ≤ 10^5 所有节点值互不相同，-10^5 < Node.val < 10^5 p、q 均存在于树中，允许 p == q 或祖先关系 层序数组不含尾部悬空 None （本题通过函数参数传入，无需读取标准输入）

💡 解题思路

「思路一：后序递归（经典解法）」
定义递归函数 lca(node)，语义为：在以 node 为根的子树中查找 p 或 q——若找到，返回该目标节点或更深处已定位的 LCA；找不到返回 None。
① 递归出口：node 为空，或 node.val 就是 p 或 q → 直接返回 node（命中目标后无需再下探：若另一个目标在其子树内，LCA 恰为命中节点本身；若不在，子树里也搜不出新信息）；
② 分别递归左右子树，得到 left 与 right；
③ 若 left、right 均非空 → p、q 分居 node 两侧 → node 就是 LCA；
④ 否则返回非空的那个（它可能携带 p、q 之一，也可能是深层已确定的 LCA），逐层向上透传。

正确性要点：p、q 分居两侧时，任何比当前节点更深的节点都不可能同时是二者的祖先，故当前节点即 LCA；都在同一侧时，LCA 必在该侧子树内，由下层结果透传。

「思路二：哈希记录父指针」
建树遍历时用字典记录每个节点的父节点；把 p 到根的全部祖先存入集合，再从 q 沿父指针上溯，第一个出现在集合中的节点即 LCA。

两种方法时间均为 O(n)；空间上思路一仅 O(h) 递归栈，思路二需 O(n) 的父指针字典。

📝 参考代码（python）

def solve(tree, p, q):
    import sys
    from collections import deque
    sys.setrecursionlimit(200000)   # 防御深链树递归爆栈（约束 n <= 1e5）

    class TreeNode:
        __slots__ = ('val', 'left', 'right')
        def __init__(self, val=0, left=None, right=None):
            self.val = val          # 节点值（本题约定互不相同）
            self.left = left        # 左孩子
            self.right = right      # 右孩子

    def build_tree(arr):
        """层序数组建树：arr[0] 为根，None 为空占位（与 LeetCode 序列化一致）"""
        if not arr or arr[0] is None:
            return None
        root = TreeNode(arr[0])
        queue = deque([root])       # 存「已建好、等待挂孩子」的节点
        i = 1                       # 下一个待写入的层序下标
        while queue and i < len(arr):
            cur = queue.popleft()
            if i < len(arr):        # —— 挂左孩子 ——
                if arr[i] is not None:
                    cur.left = TreeNode(arr[i])
                    queue.append(cur.left)
                i += 1
            if i < len(arr):        # —— 挂右孩子 ——
                if arr[i] is not None:
                    cur.right = TreeNode(arr[i])
                    queue.append(cur.right)
                i += 1
        return root

    root = build_tree(tree)

    def lca(node):
        """在 node 子树中查找 p / q：返回找到的目标节点或已定位的 LCA；都无则 None"""
        # 出口：空树，或当前节点本身就是 p/q —— 直接上交，不再下探
        # （若 node 是 p 且 q 在其子树内，LCA 就是 p 自己，无需深入）
        if node is None or node.val == p or node.val == q:
            return node
        left = lca(node.left)       # 左子树中的查找结果
        right = lca(node.right)     # 右子树中的查找结果
        if left and right:          # 两侧各命中一个目标 → p、q 分居两侧
            return node             #   → 当前节点就是 LCA
        return left if left else right  # 同侧或只找到一个 → 向上透传非空结果

    return lca(root).val

💡 解题思路

逐一审查四个说法，判断其对滑动窗口的正确性来源、复杂度、与相关技巧差异的表述是否准确。

🎯 考点

核心考点：滑动窗口的本质前提是约束指标对指针移动的单调性。
B 对应「忽略单调性前提」误区（正确替代：前缀和 + 哈希表）；C 对应「混淆同向双指针与对撞双指针」误区；D 对应「高估窗口维护结构限制」误区（可增量维护的 O(log n) 结构同样适用）。
同主题衔接：第 1 期出过滑动窗口编程题（长度最小的子数组），本期补概念维度并联动第 2 期「和为 K 的子数组」。

🔍 逐项分析

  • A 正确：单调性是滑动窗口正确性与 O(n) 复杂度的共同来源。以正整数数组为例：右指针右移 → 窗口和单调不减；左指针右移 → 窗口和单调不增。于是「满足约束的最短窗口」必然遵循『右探至刚好满足 → 记录答案 → 从左收缩至刚好不满足 → 再右探』的节奏，每个下标被左右指针各经过一次，任何最优候选都不会被跳过。若元素可负，这一性质即被破坏，滑动窗口失据。
  • B 错误：元素允许负数后，窗口和随右端扩张不再单调递增、随左端收缩不再单调递减——收缩左端可能导致「重新满足约束」，单遍扫描会漏解。第 2 期正解是前缀和 + 哈希表：以 count[pre[i]−K] 累加，与元素正负无关。这恰好说明滑动窗口的前提是「指标单调性」，而非「连续子数组」这一形态本身。
  • C 错误：对撞双指针依赖的是「数组有序带来的可排除性」——当前解偏大即可安全放过一批候选；同向滑动窗口依赖的是「窗口指标对边界移动的单调性」。前者解决有序结构上的配对/判定问题，后者解决连续子数组/子串的最优化与计数，两者的正确性来源与适用对象都不同：两数之和的数组若无序，滑动窗口无从下手；而求最短子数组也用不上对撞指针。
  • D 错误：滑动窗口只要求窗口信息可以增量维护，并不要求 O(1)。滑动窗口最大值用单调双端队列，整体 O(n)；滑动中位数用对顶堆，整体 $O(n \log n)$——都远优于暴力 $O(n^2)$，『只能退回暴力』是对复杂度的误判。
AI公式推导 ⭐⭐ 第 3 题

K-Means 为什么「就近分配 + 取均值」交替执行？——E/M 两步的最优性与收敛性推导

K-Means 每轮迭代交替执行两步：E 步（把每个样本分配给最近的中心）、M 步（把每个中心移动到其簇内样本的均值）。这看似只是经验的启发式，实际上每一步都可证明是当前条件下的精确最优解。

请完成以下推导：
① 写出 K-Means 的目标函数（簇内平方误差和 SSE），并明确 one-hot 分配变量 $r_{ik}$ 的定义与约束；
② 证明 E 步最优性：中心 $\{\mu_k\}$ 固定时，「逐样本取最近中心」的分配使目标函数最小；
③ 推导 M 步最优解：分配固定时，对目标函数关于 $\mu_c$ 求梯度并置零，证明最优中心恰为簇内均值 $\mu_c = \frac{1}{|C_c|}\sum_{i\in C_c} x_i$；
④ 说明收敛性：为什么两步交替执行时目标函数单调不增，且算法必在有限步内停止（收敛到局部最优）？
--- 以下为答案与解析 ---

🎯 考点

SSE / one-hot 目标函数形式；E 步的逐样本独立性与 argmin 下界论证；M 步对 $\mu_c$ 的梯度推导与严格凸性（结果 = 簇均值的原因）；坐标下降视角的单调收敛论证与「划分有限 ⟹ 有限步停止」；局部最优与 k-means++ 缓解初始化敏感。
这是无监督学习的核心推导之一，面试常以「请证明 K-Means 的收敛性」或「为什么 M 步取均值」的形式出现。
知识点池衔接：AI-6 朴素贝叶斯/KNN/K-Means 首次轮换，继第 11 期（SVM 对偶、Dropout）之后继续补齐机器学习基础空白。

📐 推导过程

「第 0 步：目标函数与符号」
样本集 $\{x_1,\dots,x_n\}\subset\mathbb{R}^d$，中心 $\{\mu_1,\dots,\mu_K\}$。引入 one-hot 分配变量：
$$r_{ik}=\begin{cases}1, & x_i \text{ 被分配到簇 } k \\ 0, & \text{否则}\end{cases}\qquad \sum_{k=1}^{K} r_{ik}=1\ \ (\forall i)$$
K-Means 的目标是最小化簇内平方误差和（SSE，sklearn 中即 <code>inertia_</code>）：
$$J(R,M)=\sum_{i=1}^{n}\sum_{k=1}^{K} r_{ik}\,\|x_i-\mu_k\|^2$$
$J$ 关于 $(R,M)$ 联合优化是非凸问题，K-Means 采用「坐标下降」：固定一端、精确优化另一端，交替进行。

「第 1 步：E 步——固定 M 优化 R，就近分配最优」
固定中心后，不同样本的决策互不耦合，$J$ 可按样本拆解：
$$J=\sum_{i=1}^{n}\underbrace{\sum_{k=1}^{K}r_{ik}\|x_i-\mu_k\|^2}_{\text{只依赖样本 } i \text{ 自身的分配}}$$
对单个样本 $i$：由约束 $\sum_k r_{ik}=1$ 且 $r_{ik}\in\{0,1\}$，其选择是 one-hot 的，设所选簇为 $k_i$，则该样本贡献 $\|x_i-\mu_{k_i}\|^2$。由最小值的定义，任意选择都满足：
$$\|x_i-\mu_{k_i}\|^2\ \ge\ \min_{1\le k\le K}\|x_i-\mu_k\|^2$$
取 $k_i=\arg\min_k\|x_i-\mu_k\|^2$ 时等号成立——即「就近分配」精确达到该子问题的下界。各样本子问题相互独立且同时取到最小，故此时 $J$ 取得固定 $M$ 下的全局最小。（若到两个中心等距，任取其一目标值相同。）

「第 2 步：M 步——固定 R 优化 $\mu_c$，均值最优」
固定分配后，$J$ 反过来可按中心拆解（记 $C_c=\{i: r_{ic}=1\}$，设 $|C_c|\ge 1$）：
$$J=\sum_{c=1}^{K} J_c,\qquad J_c(\mu_c)=\sum_{i\in C_c}\|x_i-\mu_c\|^2$$
各 $J_c$ 只含自己的 $\mu_c$，可独立求解。将范数平方按坐标展开 $\|x_i-\mu_c\|^2=\sum_{j=1}^{d}(x_{ij}-\mu_{cj})^2$，对 $\mu_c$ 求梯度：
$$\nabla_{\mu_c} J_c=\sum_{i\in C_c} 2(\mu_c-x_i)$$
令梯度为零：
$$\sum_{i\in C_c}(\mu_c-x_i)=0\ \Rightarrow\ |C_c|\,\mu_c=\sum_{i\in C_c}x_i\ \Rightarrow\ \boxed{\mu_c^{*}=\frac{1}{|C_c|}\sum_{i\in C_c}x_i}$$
二阶条件：$\nabla^2_{\mu_c}J_c=2|C_c|\,I_d\succ 0$（正定），即 $J_c$ 是关于 $\mu_c$ 的严格凸二次函数，该驻点为唯一全局最小。
几何解释：到一组点平方距离和最小的点，正是这组点的「重心」——这就是 M 步取均值的由来。
（工程细节：若某簇为空即 $|C_c|=0$，则 $\mu_c$ 根本不出现在 $J$ 中，实现上通常对该中心重新初始化或直接剔除。）

「第 3 步：收敛性——单调不增 ⟹ 收敛」
设第 $t$ 轮结束时的解为 $(R^{(t)},M^{(t)})$。每轮 = 一次 E + 一次 M，两步各自做到「另一端固定下的精确最小化」：
$$J(R^{(t+1)},M^{(t)})\ \le\ J(R^{(t)},M^{(t)})\qquad\text{(E 步取到逐点最优)}$$
$$J(R^{(t+1)},M^{(t+1)})\ \le\ J(R^{(t+1)},M^{(t)})\qquad\text{(M 步取到各簇最优)}$$
链式相加得 $J^{(t+1)}\le J^{(t)}$，目标单调不增；又 $J\ge 0$ 有下界，故 $J$ 序列必收敛。
更强的「有限步停止」：可行划分 $R$ 至多 $K^n$ 种，是有限集合。若某轮 E 步使 $J$ 严格下降，则划分一定发生变化；若 E 步后划分不变，则 M 步的中心也不变（各簇均值未变），算法已到不动点，此后轮次完全重复。$J$ 的值随划分确定、严格下降不能无限持续，故必有限步达到不动点。该不动点满足「E 步条件 + 中心 = 簇均值」，即局部最优（KKT 点），但一般不是全局最优——K-Means 对初始化敏感，实践中用 k-means++ （按 $\|x-\mu\|^2$ 加权抽样初始中心）与多次重启来缓解。

「关键结论」
E 步：one-hot 选择子问题逐样本独立，取最近中心即达下界，精确最优；
M 步：凸二次目标梯度 $\sum_{i\in C_c}2(\mu_c-x_i)$ 置零，得簇内均值；
交替执行 = 坐标下降，每步精确最小化 ⟹ $J$ 单调不增且有下界 ⟹ 收敛；划分有限 ⟹ 有限步到局部最优不动点。

🧠 直觉解释

K-Means 就是「按当前中心站好队（E 步），再把中心搬到每队的重心（M 步）」的坐标下降：两步都只会让总误差只降不升，而误差有下界，所以必然停住——但停在哪个局部最优点，取决于最初中心摆在哪里。

📌 回答要点

  • BN 训练流程（逐通道、跨 batch）：对每个特征通道 $c$，在当前 mini-batch 的所有样本（及空间位置）上统计 $\mu_B^{(c)}$ 与方差 $\sigma_B^{2(c)}$，归一化 $\hat{x}^{(c)}=\frac{x^{(c)}-\mu_B^{(c)}}{\sqrt{\sigma_B^{2(c)}+\epsilon}}$，再做可学习仿射 $y^{(c)}=\gamma^{(c)}\hat{x}^{(c)}+\beta^{(c)}$。$\gamma,\beta$ 由反向传播学习，作用是让网络在需要时能恢复原始分布（极端情况 $\gamma=\sigma、\beta=\mu$ 时仿射恰好抵消归一化）。
  • BN 推理流程：不再用当前 batch 统计，而用训练期间每步以指数移动平均（EMA）累积的全局统计量 $\mu_{\text{run}}、\sigma_{\text{run}}$。原因：① 推理时常为单样本/batch 极小（在线服务逐条请求），batch 维无法统计（batch=1 时方差为 0）；② 同一输入的输出不应随所在 batch 的其他样本而变，否则破坏确定性与评估可复现性。
  • 归一化维度的本质区别：输入按 $(N,C,H,W)$ 或 $(N,L,d)$ 排列时，BN 沿 N（batch）+ 空间维、对每个通道独立归一化——统计量跨样本共享，随 batch 成分波动；LN 沿特征维、对每个样本独立归一化（如对每个 token 的 $d$ 维向量整体归一化）——与其他样本无关，天然与 batch 无关。
  • Transformer 选 LN 的原因：① 变长序列：batch 内各句长度参差、padding 对齐后有效位置错位，BN 的跨样本统计噪声大且语义混杂；② 自回归解码的训练/推理不一致：训练 teacher forcing 全序列并行，推理逐 token 生成，BN 的 batch 统计进一步放大分布漂移；③ 小 batch 乃至 batch=1 都稳健：大模型推理、微调常见小 batch，LN 逐样本归一化不受影响，而 BN 的统计质量随 batch 变小急剧劣化；④ 工程与结构：pre-LN（LN 置于残差子层之前）让主干保持恒等映射、梯度直通浅层，深层 Transformer 训练更稳，已是现代大模型标配。

⭐ 加分项

  • BN 推理时可折叠：推理时 $\mu_{\text{run}}、\sigma_{\text{run}}$ 为常数，$y=\frac{\gamma}{\sqrt{\sigma_{\text{run}}^2+\epsilon}}x+\big(\beta-\frac{\gamma\,\mu_{\text{run}}}{\sqrt{\sigma_{\text{run}}^2+\epsilon}}\big)$ 是固定线性变换，可合并进前一层的 $W,b$，推理零额外开销。
  • BN 与 Dropout 不宜同用：两重随机性叠加使训练/推理方差校准漂移（训练用 batch 统计 + 随机丢弃，推理两者都关），这正是第 11 期 Dropout 题的经典坑的延伸；现代网络一般 BN 与 Dropout 二选一。
  • 大模型演进：LLaMA 系列用 RMSNorm——去掉均值中心化，仅 $\bar{x}=\frac{x}{\sqrt{\frac{1}{d}\sum_i x_i^2+\epsilon}}$ 再乘可学习缩放，省一次均值计算且效果与 LN 持平；后续工作进一步探索 QK-Norm、logit soft-cap 等稳定化技巧。
  • BN 并未淘汰：固定分辨率、大 batch 的 CV 任务里 BN 往往更快更准（卷积通道语义稳定、batch 统计估计充分）；小 batch 检测/分割任务常用 GroupNorm 等 BN 变体折中。

🔮 追问预测

  • 追问「BN 推理用移动平均统计，训练与推理仍有分布差异怎么办」：EMA 只是整体数据分布的近似；fine-tune 阶段 batch 小、统计漂移大时，可冻结 BN 统计（eval 模式）、改用 GroupNorm/LN，或推理前做统计重校准（recalibration）。
  • 追问「Pre-LN 与 Post-LN 的区别，为何 GPT-2 之后大模型几乎都用 Pre-LN」：Post-LN 把 LN 放在残差相加之后，主干被逐层缩放，深层时梯度爆炸/消失、依赖精调 warmup；Pre-LN 让残差主干恒等，梯度沿主干无衰减直达浅层，训练稳定、对学习率更宽容（代价是有效深度略降，近期也有 sandwich-LN、deep-norm 等折中方案）。
  • 追问「既然 LN 逐样本归一化，同一句子拆到不同 batch 输出一致吗」：一致，LN 保证逐样本确定性输出；对比 BN 的 batch 依赖性，这也是在线服务更倾向 LN/RMSNorm 的工程理由之一。
