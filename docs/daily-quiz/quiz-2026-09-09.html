算法编程 ⭐⭐ 第 1 题

每日温度

给定一个整数数组 temperatures，表示每天的温度。返回一个数组 answer，其中 answer[i] 是指对于第 i 天，下一个更高温度出现在几天后。如果此后没有更高的温度，则 answer[i] == 0。
输入
一个整数列表 temperatures
输出
一个整数列表 answer，与 temperatures 等长
示例 1
输入：temperatures = [73,74,75,71,69,72,76,73]
输出：[1,1,4,2,1,1,0,0]
第0天(73°)次日就遇到74°，所以answer[0]=1；第2天(75°)要到第6天(76°)才遇到更高温，间隔4天；第6、7天后面没有更高温，所以为0。
示例 2
输入：temperatures = [30,40,50,60]
输出：[1,1,1,0]
前三天每天都比次日低1级，最后一天没有更高温。
示例 3
输入：temperatures = [30,60,90]
输出：[1,1,0]
第2天(90°)后面没有更高温度。
约束
1 <= temperatures.length <= 10^5 30 <= temperatures[i] <= 100

--- 以下为答案与解析 ---

💡 解题思路

使用单调递减栈（存索引）。遍历数组，当前温度比栈顶索引对应温度高时，弹出栈顶并计算天数差。栈中始终维持温度递减的索引序列。

📝 参考代码（python）

def daily_temperatures(temperatures):
    n = len(temperatures)
    answer = [0] * n
    stack = []  # 存索引，对应温度单调递减
    for i in range(n):
        while stack and temperatures[i] > temperatures[stack[-1]]:
            idx = stack.pop()
            answer[idx] = i - idx
        stack.append(i)
    return answer

⚡ 复杂度分析

时间 O(n) 空间 O(n)

🎯 考点

单调栈经典应用：栈中维护递减序列，遇到更大值时批量结算。每个元素最多入栈出栈各一次，总时间 O(n)。
算法概念 ⭐ 第 2 题

二叉搜索树（BST）的中序遍历性质

对一棵合法的二叉搜索树（BST）进行中序遍历（左→根→右），得到的节点值序列具有什么性质？
--- 以下为答案与解析 ---
✅ 正确答案：A

💡 解题思路

BST 的定义：左子树所有节点值 < 根节点值 < 右子树所有节点值。中序遍历先访问左子树（更小的值），再访问根，最后右子树（更大的值），因此天然产生严格递增序列。

🎯 考点

BST 中序遍历严格递增是核心性质。面试常考：①判断 BST 合法性（中序遍历后检查递增）；②BST 中序遍历得到有序序列 → 二叉搜索树本质等价于有序数组。

🔍 逐项分析

  • A 正确。BST 中序遍历严格递增是 BST 的定义性质之一，也是判断一棵二叉树是否为 BST 的常用方法。
  • B 错误。递减是反序。若中序遍历递减，则该树是「反 BST」（右 < 根 < 左），不符合标准 BST 定义。
  • C 错误。标准 BST 要求左 < 根 < 右（严格小于），不允许相等的值。若允许相等则退化为一般有序树，不再是标准 BST。部分工程实现允许相等值放右子树，但教科书定义和 LeetCode 题目通常要求严格递增。
  • D 错误。BST 的中序遍历序列是确定的（由树结构决定），且必定递增，与插入顺序无关。插入顺序只影响树的形状，不影响中序遍历结果。
AI公式推导 ⭐⭐ 第 3 题

逻辑回归梯度推导（复习）

设逻辑回归模型为 $h_\theta(x) = \sigma(\theta^T x) = \frac{1}{1+e^{-\theta^T x}}$，损失函数为对数似然损失（交叉熵）：

$$J(\theta) = -\frac{1}{m}\sum_{i=1}^{m}\left[y^{(i)}\log h_\theta(x^{(i)}) + (1-y^{(i)})\log(1-h_\theta(x^{(i)}))\right]$$

请完整推导 $J(\theta)$ 对参数 $\theta$ 的梯度 $\frac{\partial J}{\partial \theta}$，并说明推导过程中用到的关键导数公式。
--- 以下为答案与解析 ---

🎯 考点

核心考点：①Sigmoid 导数 $\sigma'(z) = \sigma(z)(1-\sigma(z))$；②交叉熵 + Sigmoid 组合使梯度简化为 $h - y$（消除 Sigmoid 导数项）；③这一性质使得逻辑回归训练比用 MSE 更稳定（MSE 梯度含 $\sigma'$ 项，在 $z$ 绝对值大时梯度趋零）。复习关联：09-02 学习逻辑回归梯度推导，本次为默写复习。

📐 推导过程

**步骤 1：简化符号**

令 $z = \theta^T x$，$h = \sigma(z) = \frac{1}{1+e^{-z}}$，对单个样本 $(x, y)$，损失为：

$$L = -\left[y \log h + (1-y) \log(1-h)\right]$$

平均损失 $J = \frac{1}{m}\sum_{i=1}^m L^{(i)}$，先推导单样本 $\frac{\partial L}{\partial \theta}$。

---

**步骤 2：求 $\frac{\partial h}{\partial z}$（Sigmoid 导数）**

$$h = \frac{1}{1+e^{-z}} = (1+e^{-z})^{-1}$$

$$\frac{\partial h}{\partial z} = -(1+e^{-z})^{-2} \cdot (-e^{-z}) = \frac{e^{-z}}{(1+e^{-z})^2} = \frac{1}{1+e^{-z}} \cdot \frac{e^{-z}}{1+e^{-z}}$$

注意到 $1 - h = \frac{e^{-z}}{1+e^{-z}}$，因此：

$$\boxed{\frac{\partial h}{\partial z} = h(1-h)}$$

---

**步骤 3：求 $\frac{\partial L}{\partial h}$**

$$L = -y \log h - (1-y) \log(1-h)$$

$$\frac{\partial L}{\partial h} = -\frac{y}{h} - \frac{(1-y)}{1-h} \cdot (-1) = -\frac{y}{h} + \frac{1-y}{1-h}$$

通分：

$$\frac{\partial L}{\partial h} = \frac{-y(1-h) + (1-y)h}{h(1-h)} = \frac{-y + yh + h - yh}{h(1-h)} = \frac{h - y}{h(1-h)}$$

---

**步骤 4：链式法则求 $\frac{\partial L}{\partial z}$**

$$\frac{\partial L}{\partial z} = \frac{\partial L}{\partial h} \cdot \frac{\partial h}{\partial z} = \frac{h - y}{h(1-h)} \cdot h(1-h) = h - y$$

$$\boxed{\frac{\partial L}{\partial z} = h_\theta(x) - y}$$

这是最关键的一步：Sigmoid + 交叉熵的组合使得梯度形式极其简洁。

---

**步骤 5：求 $\frac{\partial L}{\partial \theta}$**

由于 $z = \theta^T x$，所以 $\frac{\partial z}{\partial \theta} = x$，由链式法则：

$$\frac{\partial L}{\partial \theta} = \frac{\partial L}{\partial z} \cdot \frac{\partial z}{\partial \theta} = (h_\theta(x) - y) \cdot x$$

---

**步骤 6：对全部 $m$ 个样本求平均**

$$\boxed{\frac{\partial J}{\partial \theta} = \frac{1}{m}\sum_{i=1}^{m}\left(h_\theta(x^{(i)}) - y^{(i)}\right) x^{(i)}}$$

梯度下降更新规则：$\theta \leftarrow \theta - \eta \frac{\partial J}{\partial \theta}$

🧠 直觉解释

Sigmoid + 交叉熵的梯度恰好等于预测值减真实值 $(h - y)$，形式极其简洁。这不是巧合——交叉熵损失是 Sigmoid 输出层的自然配对损失函数，使得梯度不会因 Sigmoid 导数饱和而消失。
AI面试问答 ⭐⭐ 第 4 题

解释 Transformer 的自注意力机制

请详细解释 Transformer 中的自注意力（Self-Attention）机制，包括 Q/K/V 的含义、注意力计算公式中缩放因子的作用，以及多头注意力相比单头注意力有什么优势。
--- 以下为答案与解析 ---

📌 回答要点

  • **Q/K/V 的含义**：输入序列的每个 token 生成三个向量——Query（查询，当前 token 想关注什么）、Key（键，该 token 可被匹配的特征）、Value（值，该 token 的实际内容信息）。Q 和 V 通过点积计算「该 token 对当前 token 的相关性」，加权求和 V 得到输出。三个矩阵 $W^Q, W^K, W^V$ 是可学习参数。
  • **注意力计算公式**：$\text{Attention}(Q,K,V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$。其中 $QK^T$ 计算所有 token 对的相似度（点积越大越相关），softmax 归一化为注意力权重，再加权求和 V 得到输出。
  • **缩放因子 $\sqrt{d_k}$ 的作用**：当维度 $d_k$ 较大时，$QK^T$ 的值方差变大，导致 softmax 进入饱和区（梯度趋近于 0，训练停滞）。除以 $\sqrt{d_k}$ 将方差缩放回 1 附近，使 softmax 梯度保持健康。具体推导：若 Q、K 各分量独立同分布、均值 0 方差 1，则 $QK^T = \sum_{i=1}^{d_k} q_i k_i$ 的方差为 $d_k$，除以 $\sqrt{d_k}$ 后方差变为 1。
  • **多头注意力的优势**：将 Q/K/V 投影到 $h$ 个不同的子空间，每个「头」独立计算注意力，再拼接。优势：①不同头可以关注不同模式（如句法关系 vs 语义关系）；②多个子空间表示增强了模型容量；③计算量与单头近似（每个头维度 $d_k/h$，总参数量不变）。

⭐ 加分项

  • 自注意力的时间复杂度为 $O(n^2 d)$（$n$ 为序列长度），这是 Transformer 处理长序列的瓶颈，催生了 Sparse Attention、Linear Attention、Flash Attention 等优化方向。
  • 因果注意力（Causal/Masked Attention）：在解码器中通过上三角 mask 实现「只看前面的 token」，防止信息泄露。这与 GPT 类模型的自回归生成直接相关。
  • 自注意力与 RNN 的本质区别：RNN 依赖序列顺序逐步传递信息（O(n) 步），自注意力可以一步建立任意两个 token 的直接联系，更适合并行计算和长距离依赖。

🔮 追问预测

  • 追问1：为什么用点积而不是加性注意力（additive attention）？——回答：点积可以利用矩阵乘法高度并行加速，效率远高于加性注意力（逐个计算）。当 $d_k$ 小时两者效果相当，$d_k$ 大时点积需缩放，实践中效率优势更关键。
  • 追问2：位置编码为什么需要？——回答：自注意力本身是排列不变的（打乱 token 顺序结果不变），位置编码注入位置信息。Sinusoidal 编码利用正余弦不同频率的周期性，使模型能学习相对位置；RoPE 通过旋转矩阵编码相对位置，更适合长序列外推。
