0-1 背包问题

有一个容量为 capacity 的背包和 n 件物品，第 i 件物品的重量为 weights[i]、价值为 values[i]。**每件物品只能选择一次**（要么放、要么不放），在总重量不超过背包容量的前提下，求能装入背包的最大总价值。这是动态规划最经典的入门题：先想清楚状态 dp[j] 的含义，再思考为什么容量要**逆序**遍历。
输入
函数参数：n（物品数量 int）、weights（物品重量 List[int]）、values（物品价值 List[int]）、capacity（背包容量 int）
输出
返回一个整数：最大总价值
示例 1
输入：n=3, weights=[1,2,3], values=[6,10,12], capacity=5
输出：22
选物品 2（重2值10）和物品 3（重3值12），总重 2+3=5 ≤ 5，总价值 10+12=22；选物品 1+3 价值只有 18。
示例 2
输入：n=2, weights=[1,1], values=[2,3], capacity=1
输出：3
容量只有 1，只能放一件，取价值更大的物品 2（值 3）。
约束
1 ≤ n ≤ 300；0 ≤ capacity ≤ 3000；1 ≤ weights[i] ≤ capacity；1 ≤ values[i] ≤ 1000
🧑‍💻 在线代码编辑器
def knapsack(n, weights, values, capacity): # dp[j] 表示容量 j 时能获得的最大价值 dp = [0] * (capacity + 1) # 逐件物品处理，容量 j 从大到小逆序遍历 # 请完成实现 return dp[capacity]
--- 以下为答案与解析 ---

💡 解题思路

定义 dp[j] 表示「容量为 j 时能获得的最大价值」。逐件物品处理：若当前物品重量为 w、价值为 v，则容量 j 上的决策为 dp[j] = max(dp[j], dp[j-w] + v)。**必须逆序遍历 j**：正序时 dp[j-w] 可能已经是「本轮已经放入当前物品」后的状态，导致同一件物品被放多次（变成完全背包）。逆序保证 dp[j-w] 还是上一轮（未放当前物品）的值，满足 0-1 每件最多一次的要求。单件超重的物品直接跳过。时间复杂度 O(n·capacity)，空间 O(capacity)。

📝 参考代码（python）

def knapsack(n, weights, values, capacity):
    # dp[j] 表示容量恰好为 j 时能放入的最大价值（初始 0 = 不放任何物品）
    dp = [0] * (capacity + 1)

    for i in range(n):
        w, v = weights[i], values[i]
        if w > capacity:
            continue            # 单件重量超过容量，直接放弃

        # 注意：容量必须逆序遍历！
        # 正序遍历会让 dp[j-w] 已包含当前物品，导致同一物品被重复放入
        for j in range(capacity, w - 1, -1):
            dp[j] = max(dp[j], dp[j - w] + v)

    return dp[capacity]

⚡ 复杂度分析

时间 O(n·capacity) 空间 O(capacity)

🎯 考点

0-1 背包状态定义 dp[j]；逆序遍历保证每件物品只用一次（正序会退化为完全背包）；单件超重跳过；容量为 0 或物品为空时结果为 0。

二叉树遍历序列与唯一重建

给定一棵二叉树的若干遍历序列，以下关于「遍历序列能否唯一确定二叉树」的说法，**正确的是**（单选）：
--- 以下为答案与解析 ---
✅ 正确答案：A

💡 解题思路

重建二叉树的本质是「递归地确定根、划分左右子树」。前序（根左右）第一个元素 = 根；中序（左根右）以根为界天然划分左右子树 → 前序+中序唯一。后序（左右根）最后一个元素 = 根，同样可以唯一划分 → 中序+后序唯一。前序+后序都没有提供「根的孩子是左还是右」的信息（只有度 2 的节点能确定），因此度为 1 时出现歧义，不能唯一确定。

🎯 考点

前序+中序/中序+后序可唯一重建；前序+后序在单孩子节点处有歧义；后序最后一个元素是根；层序+中序也可唯一重建。

🔍 逐项分析

  • 正确。前序遍历的第一个元素就是根节点，中序遍历以根为界天然把序列切成左子树与右子树两部分；对左右子树递归执行同一过程，每一步的划分都是唯一确定的，因此整棵树可以唯一重建。
  • 错误。前序+后序只在度为 2 的节点处能确定左右孩子边界；度为 1 的节点无法判断它的唯一孩子是左孩子还是右孩子。反例：前序 [1,2]、后序 [2,1]，既对应 1 的左孩子为 2，也对应 1 的右孩子为 2，两种形态都合法。
  • 错误。后序遍历的最后一个元素就是根节点，再用中序遍历以根为界划分左右子树，递归即可唯一重建（与「前序+中序」完全对称），因此中序+后序同样能唯一确定二叉树。
  • 错误。后序遍历按「左-右-根」输出，最后一个元素才是根：后序 [2,1] 的根是 1 而不是 2；且若根是 2，前序遍历首位也应是 2，与实际前序 [1,2] 矛盾。
AI公式推导 ⭐⭐ 第 3 题

朴素贝叶斯：从贝叶斯定理到参数估计的完整推导

从贝叶斯定理出发，逐步推导朴素贝叶斯分类器的决策规则与参数估计（先验、离散特征、连续特征），并解释「朴素」假设为什么能降低参数复杂度、拉普拉斯平滑为什么必要。要求给出每一步公式。
--- 以下为答案与解析 ---

🎯 考点

贝叶斯定理、条件独立假设、MAP 决策、MLE 参数估计（类别先验/离散计数/高斯参数）、拉普拉斯平滑防零概率、对数空间防下溢。

📐 推导过程

**目标**：推导朴素贝叶斯分类器的决策规则与参数估计方法。

**符号定义**：样本 $X = (x_1, x_2, \dots, x_m)$ 有 $m$ 个特征，类别 $C \in \{C_1, \dots, C_K\}$ 共 $K$ 类。

---

**步骤 1：贝叶斯定理——后验概率**

对给定样本 $X$，分类目标是选择后验概率最大的类别（MAP 决策）：

$$P(C_k \mid X) = \frac{P(X \mid C_k)\, P(C_k)}{P(X)}$$

其中 $P(C_k)$ 是先验概率（类别占比），$P(X \mid C_k)$ 是似然（该类别下产生此样本的概率），$P(X)$ 是归一化常数。

---

**第二步：朴素（条件独立）假设**

直接估计 $P(X \mid C_k)$ 需要联合分布，参数随 $m$ 指数爆炸。朴素贝叶斯假设：**给定类别后，各特征条件独立**：

$$P(X \mid C_k) = \prod_{i=1}^{m} P(x_i \mid C_k)$$

于是决策规则变为：

$$\hat{C} = \arg\max_{C_k}\; P(C_k) \prod_{i=1}^{m} P(x_i \mid C_k)$$

$P(X)$ 对所有类别相同，可从 argmax 中省略。

**第三步（对数空间，防下溢）**：$m$ 个概率相乘会迅速下溢为 0，取对数把连乘变连加：

$$\hat{C} = \arg\max_{C_k} \Big[\underbrace{\log P(C_k)}_{\text{先验}} + \sum_{i=1}^{m} \underbrace{\log P(x_i \mid C_k)}_{\text{各特征似然}}\Big]$$

---

**第四步：参数估计（极大似然 MLE）**

**(a) 先验 $P(C_k)$**：最大化「类别服从多项分布」的对数似然，解出：

$$P(C_k) = \frac{N_k}{N}$$

即训练集中类别 $C_k$ 的样本占比（$N_k$ 为该类样本数，$N$ 为总样本数）。

**(b) 离散特征 $x_i$**（多项式朴素贝叶斯）：设 $x_i$ 取值为 $v$，统计类内计数：

$$\hat{P}(x_i = v \mid C_k) = \frac{N_{kiv}}{N_k}$$

为避免某特征取值在训练集未出现导致概率为 0（连乘瞬间归零），加**拉普拉斯平滑**：

$$\hat{P}(x_i = v \mid C_k) = \frac{N_{kiv} + \alpha}{N_k + \alpha \cdot n_i}$$

其中 $n_i$ 是特征 $x_i$ 的取值个数，$\alpha \ge 0$（$\alpha=1$ 即拉普拉斯平滑）。

**(c) 连续特征 $x_i$**（高斯朴素贝叶斯）：假设 $P(x_i \mid C_k) = \mathcal{N}(x_i; \mu_{ki}, \sigma_{ki}^2)$，对高斯对数似然求偏导：

$$\frac{\partial}{\partial \mu_{ki}} \sum_{j \in C_k} \left[ -\frac{(x_i^{(j)} - \mu_{ki})^2}{2\sigma_{ki}^2} \right] = 0 \Rightarrow \hat{\mu}_{ki} = \frac{1}{N_k}\sum_{j \in C_k} x_i^{(j)}$$

$$\frac{\partial}{\partial \sigma_{ki}^2} \sum_{j \in C_k} \left[ -\frac{1}{2}\log\sigma_{ki}^2 - \frac{(x_i^{(j)} - \mu_{ki})^2}{2\sigma_{ki}^2} \right] = 0 \Rightarrow \hat{\sigma}_{ki}^2 = \frac{1}{N_k}\sum_{j \in C_k} \big(x_i^{(j)} - \hat{\mu}_{ki}\big)^2$$

即类内均值与类内方差（MLE 的方差分母是 $N_k$ 而非 $N_k-1$）。

---

**关键结论**：朴素贝叶斯分类器 = 贝叶斯定理 + 特征条件独立假设 + MLE（或贝叶斯）参数估计。最终决策：

$$\hat{C} = \arg\max_{C_k} \Big[\log \hat{P}(C_k) + \sum_{i=1}^{m} \log \hat{P}(x_i \mid C_k)\Big]$$

🧠 直觉解释

「朴素」指条件独立假设：把联合分布拆成各特征边缘似然的乘积，参数从指数级降到线性级，代价是丢失特征间相关性——但实际文本分类等场景中依然表现良好，甚至特征强相关时也能用（所谓「朴素而有效」）。
AI面试问答 ⭐⭐ 第 4 题

知识蒸馏的原理与温度 T 的作用

面试高频题：解释知识蒸馏（Knowledge Distillation）的基本原理，为什么要用「软标签」，温度参数 T 起什么作用，以及蒸馏损失函数各部分的含义。
--- 以下为答案与解析 ---

📌 回答要点

  • 动机与框架：用一个较大的「教师」模型训练一个更小的「学生」模型，让学生模仿教师的输出分布。教师软概率不仅给出预测类别，还蕴含类别间的相似度关系（暗知识），例如「猫」样本在教师输出中 0.6 猫、0.2 虎、0.1 豹，这部分信息量远超硬标签。
  • 温度缩放：把 softmax 的 logits 除以温度 T：$q_i = \exp(z_i/T) / \sum_j \exp(z_j/T)$。T>1 时分布变得更平缓、各类别差距缩小，从而放大类别间的相对关系；T 越大分布越接近均匀，T=1 就是普通 softmax。
  • 蒸馏损失：$L = (1-\alpha) T^2 \cdot \mathrm{KL}(p_T^{teacher} \| p_T^{student}) + \alpha \cdot \mathrm{CE}(y_{true}, p_{student})$。第一项让学生软输出对齐教师的软输出（暗知识），第二项让学生仍然学习真实硬标签；系数 $T^2$ 用于平衡梯度尺度——软标签梯度正比于 $1/T^2$，乘 $T^2$ 后与硬标签损失同量级（Hinton 2016 附录推导）。
  • 实践细节：训练全程用 T>1，推理时学生恢复 T=1；学生可只用教师对（无标签）数据生成的软标签做半监督训练；师生结构不必相同，教师甚至可以是一个集成模型。
  • LLM 时代的蒸馏：对大模型常用「序列级 logits 蒸馏」（教师生成 logits/分布，学生匹配）与「分布/特征蒸馏」，与 RLHF 对齐（如用强教师模型的偏好分布做 SFT/DPO 数据）结合；知名案例 DistilBERT（BERT 层数减半，保留 97% 效果、提速 60%）。

⭐ 加分项

  • 温度 T 的直觉：T→∞ 时 softmax 趋向均匀分布，暗知识被抹平；T 过小退化为硬标签，丢失相似度信息；常见调参范围 2~8，需交叉验证。
  • 为什么软标签信息更多：硬标签只告诉「这是猫」，软标签还隐含「猫与虎比与坦克更接近」的类别结构先验，学生可以同时学到特征相似度。
  • 师生容量鸿沟：教师太大、学生太小，软标签中的细粒度信息学生根本拟合不了，收益反而下降；可用中间尺寸助教模型或多教师平均缓解。
  • 与剪枝/量化的组合：蒸馏属于训练阶段压缩，剪枝/量化属于推理阶段压缩，二者可叠加（如 DistilBERT + INT8 量化）。
  • 自蒸馏与正则化：同构模型自蒸馏（聚合多个 epoch 的教师）等价于一种正则化；蒸馏也可视为把「软标签噪声」注入训练的正则手段。

🔮 追问预测

  • 温度 T 过大或过小分别会怎样？—— T→∞ 分布趋于均匀、熵最大，类别间区分信息全部丢失；T→1 退化为硬标签训练，学生失去暗知识；需要网格搜索（常见 2~8）并监控验证集。
  • 为什么用 KL 散度而不是直接用 MSE 对齐 logits？—— KL 作用在归一化的概率分布上，天然强调类别间的相对概率结构（暗知识所在）；而 MSE 直接回归 logits 会被绝对尺度主导，且不建模概率分布的语义结构；另外软标签目标本身是概率，用概率空间的距离更自然。
  • 蒸馏能否与量化、剪枝一起用？—— 可以。蒸馏在训练阶段产出更小更准的学生，量化/剪枝在推理阶段进一步降内存和延迟，实践中常组合（先蒸馏得到紧凑学生，再对其量化/剪枝）。
