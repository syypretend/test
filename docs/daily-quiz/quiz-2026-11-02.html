算法编程 ⭐⭐ 第 1 题

三数之和：排序 + 双指针 + 原地去重

给定一个整数数组 nums，判断其中是否存在三个元素 nums[i]、nums[j]、nums[k]（i、j、k 互不相同），使它们之和为 0。请返回所有和为 0 且不重复的三元组。

为避免同一组答案因顺序不同被重复计数，本题约定：每个三元组内部按非降序排列；所有三元组按字典序升序排列后返回。例如 [-1,0,1] 与 [0,-1,1] 视为同一组，只输出 [-1,0,1]。
输入
整数数组 nums，函数签名 three_sum(nums: List[int]) -> List[List[int]]。
输出
返回 List[List[int]]：所有和为 0 的不重复三元组，组内升序、组间字典序升序。
示例 1
输入：nums = [-1, 0, 1, 2, -1, -4]
输出：[[-1, -1, 2], [-1, 0, 1]]
排序后为 [-4, -1, -1, 0, 1, 2]；-1 + (-1) + 2 = 0，-1 + 0 + 1 = 0。
示例 2
输入：nums = [0, 1, 1]
输出：[]
任意三个数之和都不为 0，返回空列表。
示例 3
输入：nums = [0, 0, 0]
输出：[[0, 0, 0]]
三个 0 之和为 0；虽然元素值相同，但下标互不相同，是一组合法解。
约束
3 ≤ nums.length ≤ 3000；-10^5 ≤ nums[i] ≤ 10^5。结果中不能有重复三元组；每个三元组内部升序，整体按字典序升序。
🧑‍💻 在线代码编辑器
def three_sum(nums): # 思路提示：先排序，固定第一个数，再用左右双指针找另外两个数 # 注意：外层 i、内层 l/r 都要跳过重复值，避免重复三元组 # 返回：所有不重复的三元组；每个三元组升序，整体按字典序升序 pass
--- 以下为答案与解析 ---

💡 解题思路

先对数组排序，固定第一个数 nums[i]，问题就退化为在 i+1 到 n-1 的区间内寻找两数之和等于 -nums[i]，用左右指针相向移动即可。

排序带来两个关键好处：① 当前和小于目标时，只有把左指针右移才可能变大；当前和大于目标时，只有把右指针左移才可能变小，指针移动方向具有单调性；② 相同元素在排序后相邻，便于跳过重复。

去重分三层：外层 i 若与前一个数相同则跳过；找到一组解后，左指针跳过与nums[l] 相同的值，右指针跳过与 nums[r] 相同的值。另外，若 nums[i] > 0，由于数组已升序，后面所有数都为正，三数之和不可能为 0，可直接 break。

📝 参考代码（python）

def three_sum(nums):
    nums = sorted(nums)                 # 排序：便于双指针与跳过重复
    n = len(nums)
    res = []
    for i in range(n - 2):
        if nums[i] > 0:                 # 最小的数已为正，后面不可能凑出 0
            break
        if i > 0 and nums[i] == nums[i - 1]:
            continue                    # 跳过重复的第一个数
        target = -nums[i]
        l, r = i + 1, n - 1
        while l < r:
            s = nums[l] + nums[r]
            if s == target:
                res.append([nums[i], nums[l], nums[r]])
                l += 1
                r -= 1
                while l < r and nums[l] == nums[l - 1]:
                    l += 1              # 跳过重复的第二个数
                while l < r and nums[r] == nums[r + 1]:
                    r -= 1              # 跳过重复的第三个数
            elif s < target:
                l += 1                  # 和太小，左指针右移
            else:
                r -= 1                  # 和太大，右指针左移
    return res

⚡ 复杂度分析

时间 O(n^2)：排序 O(n log n)，外层 O(n) × 双指针 O(n) 空间 O(1) 额外空间（不计返回结果；Python 的排序内部有 O(n) 临时缓冲）

🎯 考点

排序 + 双指针的单调性；三层去重（i、l、r）；nums[i] > 0 的提前终止；结果顺序的确定性约定。常见 bug：找到解后只移动一个指针导致死循环；去重时写成 if 而不是 while；外层去重忘记 i > 0 的边界。
算法概念 ⭐⭐ 第 2 题

区间 DP：为什么必须按区间长度递增枚举？

区间 DP 的经典例题「戳气球」：有 n 个气球，第 i 个气球上的数字为 nums[i]。戳破第 i 个气球可获得 nums[i-1] × nums[i] × nums[i+1] 枚硬币（越界时按 1 计算），戳破后左右气球变为相邻。求戳破所有气球能获得的最大硬币数。

围绕「状态定义、枚举顺序、转移方向」，判断下列说法哪一项正确。
--- 以下为答案与解析 ---
✅ 正确答案：A

💡 解题思路

区间 DP 的核心是「大区间由小区间合并而来」。戳气球的正向过程会改变相邻关系：先戳破一个气球后，它左右两边的新邻居会互相影响，子问题并不独立。

逆向思考：枚举区间 (i,j) 中「最后一个被戳破」的气球 k。在 k 被戳破之前，区间 (i,k) 和 (k,j) 内的气球已经全部被戳破，且 a[i]、a[k]、a[j] 是 k 此刻的左右边界，所以 k 的得分固定为 a[i]×a[k]×a[j]，左右两个子区间互不影响。这就是区间 DP 的转移来源。

因为 f[i][j] 依赖的 f[i][k] 与 f[k][j] 长度都严格小于 j-i+1，所以必须让短区间先算完，最自然的顺序就是按区间长度 len = 1,2,...,n 递增枚举。

🎯 考点

区间 DP 三要素：状态定义（开区间/闭区间）、按长度递增的枚举顺序、分割点转移；「最后一个操作」的逆向思维；复杂度 O(n^3) 时间、O(n^2) 空间。小例子：nums=[3,1,5] 时，先戳 1 得 3×1×5=15，再戳 3 得 1×3×5=15，最后戳 5 得 1×5×1=5，总计 35，为最大值。

🔍 逐项分析

  • A 正确。补哨兵 1 后，f[i][j] 表示开区间 (i,j)；枚举最后戳破的 k 把区间拆成 (i,k) 与 (k,j)，两个子区间都更短，按长度递增枚举可保证依赖已计算；总复杂度 O(n^3)、空间 O(n^2)。
  • B 错误。枚举「第一个戳破」的气球后，左右气球会变成相邻，后续得分依赖新的邻居关系，两个子问题不再独立；只有「最后一个戳破」才能把区间干净地分开。
  • C 错误。f[i][j] 既依赖 f[i][k]（k<j），也依赖 f[k][j]（k>i）。外层 i 从小到大时，f[k][j] 的起点 k>i 还没算，会读到未初始化值。可行的替代顺序是 i 从大到小、j 从小到大，或直接按长度枚举；不能笼统说任意 i/j 顺序都行。
  • D 错误。状态数确实是 O(n^2)，但每个状态要枚举 O(n) 个分割点 k，总时间是 O(n^3)；空间 O(n^2)。
AI公式推导 ⭐⭐⭐ 第 3 题

RoPE 旋转位置编码：从复数旋转到相对位置内积的完整推导

RoPE（Rotary Position Embedding）用旋转矩阵把位置信息注入 query/key。请完成以下推导：

（1）在二维情形，把向量看成复数，说明为什么对 q、k 分别旋转 mθ、nθ 后，内积只依赖相对位置 m-n；
（2）写出二维旋转矩阵，并证明 R_m^T R_n = R_{n-m}；
（3）推广到 d 维（d 为偶数），说明如何分块、频率 θ_i 如何取；
（4）解释 RoPE 为什么不需要额外可学习参数，以及它保持向量范数的原因。
--- 以下为答案与解析 ---

🎯 考点

复数旋转与旋转矩阵的等价性；R_m^T R_n = R_{n-m} 是相对位置性质的代数根源；d 维按二维块对角拼接，θ_i = 10000^(-2i/d) 的多尺度频率；正交变换保范数、无额外参数；q/k 加旋转而 value 不加。

📐 推导过程

第 0 步：符号约定。设位置 m 处的二维 query 为 $q=(q_0,q_1)^T$，位置 n 处的二维 key 为 $k=(k_0,k_1)^T$，$\theta$ 为常数角频率。把二维实向量与复数一一对应：
$$z_q=q_0+iq_1,\qquad z_k=k_0+ik_1$$
两个实向量的内积等于复数内积的实部：
$$\langle q,k\rangle=q^Tk=\mathrm{Re}\left(z_q\overline{z_k}\right)$$

第 1 步：给 q、k 分别旋转位置角度。定义位置 m 的旋转为 $z_q^{(m)}=z_qe^{im\theta}$，位置 n 的旋转为 $z_k^{(n)}=z_ke^{in\theta}$。则
$$\langle R_mq,R_nk\rangle=\mathrm{Re}\left[z_qe^{im\theta}\overline{z_ke^{in\theta}}\right]=\mathrm{Re}\left[z_q\overline{z_k}e^{i(m-n)\theta}\right]$$
复数的共轭把 $e^{in\theta}$ 变成 $e^{-in\theta}$，两个旋转因子的指数相减，只剩 $m-n$。因此旋转后的内积只依赖相对位置 $m-n$，与绝对位置 m、n 各自是多少无关。

第 2 步：写成旋转矩阵并证明正交关系。二维旋转矩阵为
$$R_m=\begin{pmatrix}\cos m\theta & -\sin m\theta\\ \sin m\theta & \cos m\theta\end{pmatrix}$$
它是正交矩阵，满足 $R_m^T=R_{-m}=R_m^{-1}$。于是
$$R_m^TR_n=R_{-m}R_n=R_{(n-m)\theta}=R_{n-m}$$
所以
$$(R_mq)^T(R_nk)=q^TR_m^TR_nk=q^TR_{n-m}k$$
这正是第 1 步复数推导的矩阵版本。注意 $R_m^TR_m=I$，旋转不改变向量长度：$\|R_mq\|_2=\|q\|_2$。

第 3 步：推广到 d 维。设 $d$ 为偶数，把 d 维向量切成 $d/2$ 个二维块，第 i 块使用角频率 $\theta_i$。定义块对角矩阵
$$R^d_{\Theta,m}=\mathrm{diag}\left(R(m\theta_0),R(m\theta_1),\ldots,R(m\theta_{d/2-1})\right)$$
对 query 和 key 分别做位置旋转：
$$q_m=R^d_{\Theta,m}W_qx_m,\qquad k_n=R^d_{\Theta,n}W_kx_n$$
则
$$q_m^Tk_n=(W_qx_m)^T\left(R^d_{\Theta,m}\right)^TR^d_{\Theta,n}(W_kx_n)=(W_qx_m)^TR^d_{\Theta,n-m}(W_kx_n)$$
块对角矩阵的转置仍是块对角，且每块满足 $R(m\theta_i)^TR(n\theta_i)=R((n-m)\theta_i)$，所以整个 d 维内积仍然只依赖 $n-m$。展开到每个块：
$$q_m^Tk_n=\sum_{i=0}^{d/2-1}\left[(W_qx_m)^{(i)}\right]^TR((n-m)\theta_i)(W_kx_n)^{(i)}$$
其中上标 $(i)$ 表示第 i 个二维块。

第 4 步：频率如何取。常用
$$\theta_i=10000^{-2i/d},\qquad i=0,1,\ldots,\frac{d}{2}-1$$
即 $\theta_i=\mathrm{base}^{-2i/d}$，base 通常取 10000。i 较小时 $\theta_i$ 接近 1，旋转快、波长短，编码局部细节；i 较大时 $\theta_i$ 接近 0，旋转慢、波长长，编码长距离信息。不同频率的几何级数让模型同时拥有多个尺度的位置分辨率。NTK-aware、YaRN 等长上下文扩展方法，本质上是在改 base 或对频率做插值/缩放。

第 5 步：性质与实现要点。RoPE 没有可学习参数，它只是按位置确定性地旋转 q、k；旋转矩阵正交，所以保持范数与内积的尺度；相对位置性质来自 $R_m^TR_n=R_{n-m}$，而不是来自额外的相对位置偏置。实现时通常把相邻两维 $(x_{2i},x_{2i+1})$ 作为一对做旋转（也可用 rotate_half 的拼接口径），并预先缓存每个位置的 $\cos$、$\sin$ 表。Value 不加 RoPE，因为注意力加权的是 value 的内容，位置信息已经通过 q·k 的分数进入。

🧠 直觉解释

RoPE 把「位置」变成「旋转角度」：q 和 k 各自转过与位置成正比的角度，点积时两个角度相减，只剩下相对位置差。于是注意力分数天然感知「两个 token 相距多远」，而不是「它们各自在句子的第几个位置」。
AI面试问答 ⭐⭐ 第 4 题

PPO 与 DPO 的 KL 正则：同一目标函数的两种解法

面试官问：PPO 和 DPO 都常被描述为「带 KL 正则的偏好优化」。请回答：

（1）二者优化的目标函数是什么？KL 正则分别体现在哪里？
（2）DPO 是如何从同一个 KL 正则目标推导出无需奖励模型的损失的？
（3）它们在什么意义上等价？工程上又有哪些关键差异？
--- 以下为答案与解析 ---

📌 回答要点

  • 共同的目标函数：$\max_\pi\ \mathbb{E}_{x\sim D,\,y\sim\pi(\cdot|x)}\left[r(x,y)\right]-\beta\,D_{\mathrm{KL}}\left(\pi(\cdot|x)\,\|\,\pi_{\mathrm{ref}}(\cdot|x)\right)$。PPO 先用奖励模型给出 $r(x,y)$，在线采样并用显式 KL 惩罚（常把 $-\beta\log\frac{\pi_\theta}{\pi_{\mathrm{ref}}}$ 加到每个 token 的奖励里）约束策略；PPO-Clip 的 clip 只是策略比率的信任域近似，不等于 KL 本身。
  • DPO 从同一个目标出发，对每个 prompt $x$ 求最优策略。把 KL 正则的优化写成逐 $y$ 的变分问题，可得闭式解 $\pi^*(y|x)=\frac{1}{Z(x)}\pi_{\mathrm{ref}}(y|x)\exp\left(\frac{r(x,y)}{\beta}\right)$，其中 $Z(x)=\sum_y\pi_{\mathrm{ref}}(y|x)\exp\left(\frac{r(x,y)}{\beta}\right)$ 是配分函数。
  • 把闭式解反解出奖励：$r(x,y)=\beta\log\frac{\pi^*(y|x)}{\pi_{\mathrm{ref}}(y|x)}+\beta\log Z(x)$。奖励被重参数化为「策略相对参考策略的对数比」加上一个只依赖 $x$ 的常数。
  • 代入 Bradley-Terry 偏好模型 $P(y_w\succ y_l|x)=\sigma\left(r(x,y_w)-r(x,y_l)\right)$。同一个 $x$ 下，$\beta\log Z(x)$ 在相减时消掉，得到 DPO 损失 $$L_{\mathrm{DPO}}=-\mathbb{E}\left[\log\sigma\left(\beta\log\frac{\pi_\theta(y_w|x)}{\pi_{\mathrm{ref}}(y_w|x)}-\beta\log\frac{\pi_\theta(y_l|x)}{\pi_{\mathrm{ref}}(y_l|x)}\right)\right]$$ 因此 DPO 不需要显式奖励模型，也不需要在线采样；KL 约束被「吸收」进了参考策略与闭式解中，表现为对偏离 $\pi_{\mathrm{ref}}$ 的隐式惩罚。
  • 等价性的边界：在无限偏好数据、模型容量足够、优化到全局最优的理想条件下，DPO 的最优解与 PPO 所优化的同一 KL 正则目标的最优解一致；DPO 的隐式奖励 $r_\theta=\beta\log\frac{\pi_\theta}{\pi_{\mathrm{ref}}}$ 与 PPO 的奖励模型在最优处对应。但二者不是算法等价：PPO 是在线策略优化，DPO 是离线偏好学习。

⭐ 加分项

  • DPO 的梯度可以写成 $\nabla_\theta L=-\beta\,\sigma(-\Delta)\left[\nabla_\theta\log\pi_\theta(y_w|x)-\nabla_\theta\log\pi_\theta(y_l|x)\right]$，其中 $\Delta=\beta\left[\log\frac{\pi_\theta(y_w)}{\pi_{\mathrm{ref}}(y_w)}-\log\frac{\pi_\theta(y_l)}{\pi_{\mathrm{ref}}(y_l)}\right]$。模型把偏好分得越错，$\sigma(-\Delta)$ 越大，梯度权重越高；这就是「难样本 mining」的自带效果。
  • 配分函数 $Z(x)$ 能消掉的前提是「同一个 prompt 下比较 chosen/rejected」。如果要做跨 prompt 的绝对概率比较，或需要显式奖励分数，就不能把 $Z(x)$ 当作常数忽略。
  • PPO 的 KL 常用 k3 估计 $\log\frac{\pi_{\mathrm{ref}}}{\pi_\theta}$（无偏但方差大）或 k1 估计 $-\log\frac{\pi_\theta}{\pi_{\mathrm{ref}}}$（有偏但方差小）；实际 RLHF 还会用自适应 KL 系数，按当前 KL 与目标值的偏差动态调 $\beta$。
  • DPO 的工程优势是只需一对偏好样本、一次前向/反向，训练稳定且便宜；局限是离线数据覆盖不足时容易过拟合偏好对、出现长度偏置或「chosen/rejected 似然同时下降」。IPO、KTO、ORPO、Online DPO 等都是在补这些短板。
  • SFT 与偏好优化的关系：DPO 的参考策略通常就是 SFT 模型；$\beta$ 越大越贴近参考策略，越小越敢偏离。β 同时影响 KL 强度和损失对 log-ratio 差的敏感度，不能把 DPO 的 β 与 PPO 的 β 直接按数值等同。

🔮 追问预测

  • 追问：DPO 为什么不需要奖励模型？回答思路：KL 正则目标的最优策略与奖励存在一一对应，奖励可写成 β log(π/π_ref)+常数；Bradley-Terry 只用到同一 prompt 下的奖励差，常数消掉，于是可以直接用策略对数比构造分类损失。
  • 追问：PPO 的 clip 能替代 KL 吗？回答思路：不能。clip 是对重要性采样比率的逐样本截断，属于启发式信任域；KL 是分布层面的整体惩罚，约束的是策略分布而不是单个比率。实际 RLHF 通常在奖励里显式加 KL，并配合自适应系数。
  • 追问：DPO 的 β 和 PPO 的 β 是一回事吗？回答思路：都控制「偏离参考策略的强度」，但 DPO 的 β 还缩放 log-ratio 之差、改变损失斜率与梯度尺度；两者数值不能直接跨算法比较，需要按数据与模型重新调。
  • 追问：离线偏好数据不足时 DPO 会怎样？回答思路：偏好对只覆盖有限 (x,y_w,y_l)，模型可能利用数据偏差（长度、格式、特定措辞），出现分布外泛化差与 reward hacking；可用 Online DPO/迭代采样、混合 SFT 数据、增加数据覆盖与去偏。
  • 追问：DPO 的训练目标与 SFT 有什么关系？回答思路：当 β→∞ 时 DPO 退化为尽量贴近参考策略（类似强约束的 SFT）；β 适中时，它在「提高 chosen 概率、降低 rejected 概率」之间做加权；参考策略一般冻结，不能与策略同时更新。
