算法编程 ⭐⭐ 第 1 题

最长公共子序列（LCS）

给定两个字符串 text1 和 text2，请实现函数 solve(text1, text2)，返回它们**最长公共子序列（LCS）**的长度。

子序列是指：从原字符串中**按顺序**删除若干（或零个）字符后得到的新字符串，**不要求连续**。例如 "ace" 是 "abcde" 的子序列，而 "aec" 不是。

**要求**：使用二维动态规划，令 $dp[i][j]$ 表示 text1 前 $i$ 个字符与 text2 前 $j$ 个字符的 LCS 长度；当两个字符相等时取左上角 $+1$，否则取上、左的较大值。
输入
两个字符串 `text1`、`text2`，均只含小写英文字母。
输出
一个整数：最长公共子序列的长度。
示例 1
输入：text1 = "abcde", text2 = "ace"
输出：3
最长公共子序列是 "ace"，长度为 3。
示例 2
输入：text1 = "abc", text2 = "def"
输出：0
没有任何公共字符，长度为 0。
示例 3
输入：text1 = "abc", text2 = "abcbc"
输出：3
最长公共子序列是 "abc"（text2 中取前 3 个字符即可），长度为 3。
约束
- $0 \le |text1|, |text2| \le 1000$ - 字符串只含小写英文字母。

💡 解题思路

**状态定义**：$dp[i][j]$ = $text1[0:i]$ 与 $text2[0:j]$ 的最长公共子序列长度（$i, j$ 为前缀长度，$dp[0][*] = dp[*][0] = 0$ 表示空串）。

**转移方程**：
- 若 $text1[i-1] = text2[j-1]$（当前两个字符相等），则该字符一定可以接到任意更短前缀的 LCS 后面，$dp[i][j] = dp[i-1][j-1] + 1$；
- 否则，两个字符至少有一个不会出现在 LCS 中，$dp[i][j] = \max(dp[i-1][j],\, dp[i][j-1])$。

**为什么相等时不用考虑 $\max(dp[i-1][j], dp[i][j-1])$**：若 $text1[i-1] = text2[j-1]$，则把这一对字符加入，必然得到比两边任意一个更长的合法公共子序列（可由 LCS 最优子结构 + 反证法验证），故直接取 $dp[i-1][j-1] + 1$ 即可，且不会比只考虑前 $i-1$ 或前 $j-1$ 个字符更差。

实现用 $(m+1) \times (n+1)$ 二维数组，下标从 1 开始避免边界判断；也可滚动数组只保留两行把空间压到 $O(\min(m,n))$。

📝 参考代码（python）

def solve(text1, text2):
    m, n = len(text1), len(text2)
    dp = [[0] * (n + 1) for _ in range(m + 1)]
    for i in range(1, m + 1):
        for j in range(1, n + 1):
            if text1[i - 1] == text2[j - 1]:
                dp[i][j] = dp[i - 1][j - 1] + 1
            else:
                dp[i][j] = max(dp[i - 1][j], dp[i][j - 1])
    return dp[m][n]

⚡ 复杂度分析

时间 O(mn)——双重循环填表，m、n 为两串长度 空间 O(mn)——二维 dp 表；可滚动数组优化为 O(min(m,n))

🎯 考点

双序列 DP 模板（LCS 是母题，变体有「编辑距离」「最长重复子数组」）；转移方程分「相等 / 不相等」两类；与 LIS（单序列 DP，第 7 期）、0-1 背包（组合 DP，第 17 期）对比，建立 DP 题型分类体系。

💡 解题思路

循环队列的核心难点在于：用下标差如何**区分空与满**——不额外记录时，front == rear 既可能是空也可能是满。常用两种解法：牺牲一个存储单元，或额外计数器。四个选项分别考查：牺牲单元的判空判满条件（A）、把空满条件记反（B）、计数器方案的判满值（C）、把空状态误当满状态（D）。

🎯 考点

循环队列三件套记忆点：① 判空 front == rear；② 牺牲单元判满 (rear+1)%cap == front；③ 实际容量 cap-1。替代方案是 size 计数器（满 = cap）或布尔标志位。工程应用：Ring Buffer（日志/音频/网络缓冲）、生产者-消费者模型、LeetCode 622 设计循环队列。

🔍 逐项分析

  • **A 正确**。牺牲一个单元：队满时让 rear 停在 front 前一个位置，因此判满条件是 (rear + 1) % capacity == front；判空条件是 front == rear。因为空出了一个位置无法存放数据，实际可容纳 capacity - 1 个元素——这是最常见的实现（STL deque/很多开源代码的默认方案）。
  • **B 错误**。判空条件是 front == rear，而不是 rear == (front + 1) % capacity。rear 恰好在 front 前一格 恰恰是**满**的条件（牺牲单元方案），题干把空、满条件写反了，属典型记忆混淆。
  • **C 错误**。引入 size 计数器后，满的条件是 size == capacity（数组满员，所有格都用上），空的条件是 size == 0。写成 size == capacity - 1 少算了一个元素（那是牺牲单元方案的容量上限），会提前报满、浪费一格。
  • **D 错误**。rear == front 表示队列**为空**，不是满——入队前检查它判断的是「是否空队列」而非「是否满」；满的判断要用 (rear+1) % capacity == front（牺牲单元）或 size == capacity（计数器）。
AI公式推导 ⭐⭐⭐ 第 3 题

DPO 直接偏好优化：最优策略闭式解与梯度推导

在 RLHF 中，人类偏好数据 $\mathcal{D} = \{(x, y_w, y_l)\}$（$y_w$ 为被偏好的回答，$y_l$ 为被拒绝的回答）通常先训一个**奖励模型**，再用强化学习（如 PPO）对齐策略。**DPO（Direct Preference Optimization，Rafailov et al., 2023）** 提出：既然奖励模型的最优解可以闭式解出，那么可以直接用**参考策略** $\pi_{\text{ref}}$ 与当前策略的比值来表达偏好。

请完成以下推导（分 4 步）：
**(1)** 求解带 KL 约束的 RL 目标 $\max_{\pi}\, \mathbb{E}_{y \sim \pi(\cdot|x)}[r(x,y)] - \beta\, \text{KL}(\pi(\cdot|x)\|\,\pi_{\text{ref}}(\cdot|x))$ 的最优策略闭式解 $\pi^*(y|x)$；
**(2)** 由最优策略反解奖励 $r(x,y)$（称为奖励重参数化）；
**(3)** 将其代入 Bradley-Terry 偏好模型 $P(y_w \succ y_l|x) = \sigma\big(r(x,y_w) - r(x,y_l)\big)$，得到 DPO 的偏好概率表达式（说明配分函数如何抵消）；
**(4)** 写出 DPO 训练目标 $\mathcal{L}_{\text{DPO}}$ 及其对 $\theta$ 的梯度，并解释梯度中的权重项含义。
--- 以下为答案与解析 ---

🎯 考点

考点：① 拉格朗日法求带 KL 约束的最优策略闭式解；② 奖励重参数化（策略比值编码奖励）；③ Bradley-Terry 代入时配分函数抵消（不计算 Z 的关键）；④ 梯度权重 σ(-u) 的自适应加权语义；⑤ 与 PPO/RLHF 的对比（免奖励模型、免在线采样、无重要性权重）。

📐 推导过程

**第 1 步：求解带 KL 约束的 RL 最优策略**

对每个输入 $x$，问题为（记 $\pi_y = \pi(y|x)$，$p_y = \pi_{\text{ref}}(y|x)$，约束 $\sum_y \pi_y = 1$）：

$$\max_{\pi} \sum_y \pi_y r(x,y) - \beta \sum_y \pi_y \log\frac{\pi_y}{p_y} \;\;\text{s.t.}\;\; \sum_y \pi_y = 1$$

构造拉格朗日函数 $\mathcal{L} = \sum_y \pi_y r(x,y) - \beta \sum_y \pi_y \log\frac{\pi_y}{p_y} + \lambda\left(\sum_y \pi_y - 1\right)$，对 $\pi_y$ 求偏导并令为 0：

$$\frac{\partial \mathcal{L}}{\partial \pi_y} = r(x,y) - \beta\left(\log\frac{\pi_y}{p_y} + 1\right) + \lambda = 0$$

$$\Rightarrow \log \frac{\pi_y}{p_y} = \frac{r(x,y) + \lambda - \beta}{\beta} \;\Rightarrow\; \pi_y = p_y \cdot \exp\left(\frac{r(x,y) + \lambda - \beta}{\beta}\right)$$

令 $Z(x) = \sum_y p_y \exp\left(\frac{r(x,y)}{\beta}\right)$（配分函数），由归一化 $\sum_y \pi_y = 1$ 得 $\exp\left(\frac{\lambda-\beta}{\beta}\right) = \frac{1}{Z(x)}$，于是最优策略为：

$$\boxed{\pi^*(y|x) = \frac{1}{Z(x)}\, \pi_{\text{ref}}(y|x)\, \exp\!\left(\frac{r(x,y)}{\beta}\right)}$$

**第 2 步：奖励重参数化（Reward Reparameterization）**

上式两边取对数解出 $r(x,y)$（把 $\pi^*$ 换成当前要训练的策略 $\pi_\theta$）：

$$r(x,y) = \beta \log \frac{\pi_\theta(y|x)}{\pi_{\text{ref}}(y|x)} + \beta \log Z(x)$$

这说明：**策略比值就是对「隐式奖励」的重新参数化**——不必训练独立的奖励模型，奖励被编码进了策略与参考策略的对数比里（由 $\beta$ 控制幅度）。

**第 3 步：代入 Bradley-Terry 偏好模型**

Bradley-Terry：$P(y_w \succ y_l \mid x) = \dfrac{e^{r(x,y_w)}}{e^{r(x,y_w)} + e^{r(x,y_l)}} = \sigma\big(r(x,y_w) - r(x,y_l)\big)$。把第 2 步 $r$ 的表达式代入，两个 $\beta\log Z(x)$ 项**完全抵消**：

$$P(y_w \succ y_l \mid x) = \sigma\!\left(\beta\log \frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta\log \frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\right)$$

配分函数 $Z(x)$ 只在括号外出现且互为相反数消去，这正是 DPO 无需显式计算配分函数的关键——它只依赖策略与参考策略的比值。

**第 4 步：DPO 目标与梯度**

DPO 用偏好数据的负对数似然作为训练目标（对偏好概率取 $\log$ 再加负号）：

$$\mathcal{L}_{\text{DPO}}(\theta) = -\mathbb{E}_{(x,y_w,y_l)\sim \mathcal{D}}\left[\log \sigma\!\left(\beta \log\frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta \log\frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\right)\right]$$

令 $u = \beta\left(\log\frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \log\frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\right)$，利用 $\sigma'(u) = \sigma(u)(1-\sigma(u))$ 与 $\sigma(-u) = 1-\sigma(u)$，链式法则得梯度：

$$\nabla_\theta \mathcal{L}_{\text{DPO}} = -\beta\, \mathbb{E}\left[\sigma(-u)\cdot\left(\nabla_\theta \log \pi_\theta(y_w|x) - \nabla_\theta \log \pi_\theta(y_l|x)\right)\right]$$

**权重项含义**：$\sigma(-u)$ 就是「当前策略对偏好对犯错的置信程度」——若 $u > 0$（策略已给出偏好对的概率高于参考），$\sigma(-u)$ 接近 0，梯度小、更新放缓；若 $u < 0$（策略偏好反了），$\sigma(-u) \to 1$，梯度接近满量，朝增大 $\pi(y_w)$、减小 $\pi(y_l)$ 的方向大步修正。整体无需奖励模型、无需在线采样（数据离线即可），训练过程即用 ref 策略对比的隐式奖励做加权梯度上升。

🧠 直觉解释

DPO 把「学一个奖励模型」变成「直接学策略」，用 πθ/π_ref 的比值 + sigmoid 权重隐式编码了 Bradley-Terry 偏好：策略比参考策略更偏好的样本（u>0）几乎不再更新，只有犯错的样本才会获得大梯度。
AI面试问答 ⭐⭐ 第 4 题

SVM 的核技巧：为什么核函数能让线性 SVM 处理非线性问题？

面试官：「线性 SVM 只能处理线性可分数据。请解释**核技巧（Kernel Trick）**是如何让 SVM 处理非线性分类的；常用的核函数有哪些、怎么选；并简述 **SMO 算法**的基本思想。」
--- 以下为答案与解析 ---

📌 回答要点

  • **核技巧的数学基础（为什么只需要内积）**：SVM 的对偶问题 $\max \sum_i \alpha_i - \frac12 \sum_{i,j}\alpha_i\alpha_j y_i y_j \langle x_i, x_j \rangle$ 与决策函数 $f(x) = \text{sign}\left(\sum_i \alpha_i y_i \langle x_i, x \rangle + b\right)$ 都**只依赖样本间的内积**，而从不直接出现样本坐标。因此把样本映射到高维特征空间 $\phi(x)$ 后，内积 $\langle \phi(x_i), \phi(x_j) \rangle$ 可以用核函数 $K(x_i, x_j)$ 直接计算，**避免显式计算高维映射**（维灾难消失），这就是核技巧。
  • **常用核函数**：① 线性核 $K(x,z)=\langle x,z\rangle$（高维稀疏/线性可分场景，快且可解释）；② 多项式核 $K(x,z)=(\gamma\langle x,z\rangle + r)^d$（已知多项式阶时用）；③ 高斯（RBF）核 $K(x,z)=\exp(-\gamma\|x-z\|^2)$——最常用，隐含映射到无穷维特征空间、只有一个超参 $\gamma$，类不可分时先用它；④ Sigmoid 核（类神经网络的激活形式）。
  • **选型思路（经验法则）**：先验线性可分、特征多且样本少（如文本 TF-IDF）→ 线性核；特征少、样本多、明显非线性 → RBF；类别边界近似多项式 → 多项式；工程默认流程是「先试线性核，再试 RBF 配 $\gamma$（如 $\gamma=1/d$）网格搜索 + 交叉验证」。
  • **SMO 算法思想**：对偶问题约束中 $\sum_i \alpha_i y_i = 0$ 决定——每次只能同时优化**两个**变量（其余固定）才能满足等式约束。SMO 选违反 KKT 条件最严重的两个 $\alpha_i$（用启发式：外层遍历边界点，内层选 $|E_i - E_j|$ 最大的 $j$，$E$ 为预测误差），对其解析求解二次规划后更新 $b$ 与误差缓存，反复迭代直至收敛。每个子问题都有闭式解，因此 SMO 把 O(n²) 甚至更昂贵的二次规划求解变成 O(n)~O(n²) 的可行迭代。
  • **加分项（深层理解）**：核函数合法的充要条件是核矩阵 Gram 半正定（Mercer 条件）；RBF 的 $\gamma$ 大 → 决策边界更弯曲（过拟合风险），$\gamma$ 小 → 更平滑（欠拟合）；$C$（软间隔惩罚）大 → 尽可能分开、容忍小噪更小；核函数可组合（线性组合/乘积仍为核）。

⭐ 加分项

  • **与对偶问题联系**：核技巧与第 11 期「SVM 对偶推导」联动——对偶形式天然只含内积，这是核技巧能成立的前提（先有对偶，才有核）。
  • **与正则化联系**：软间隔 $C$ 实质是目标里 $\frac12\|w\|^2 + C\sum \xi_i$ 的权衡，等价于损失项的惩罚系数，正则化直觉一致。
  • **工程细节**：sklearn 中 RBF 的 gamma 默认 'scale'（= 1/(n_features·X.var())），调参通常先 grid 扫 C ∈ {0.1..1000}、gamma ∈ {0.001..1}；核函数在 kernel 参数中一行切换，验证时注意归一化（特征尺度对 RBF 距离影响大）。
  • **局限与替代**：核方法在百万级样本上训练慢（核矩阵 O(n²) 存储），深度网络/核近似（如 Random Fourier Features）是替代方向；这也解释了现代大模型为何少用核 SVM。

🔮 追问预测

  • **追问 1：RBF 为什么最常用？** 回答：RBF 的隐式映射维数无限（高斯核可展开为多项式级数），覆盖的决策边界形状最灵活；只有 γ 一个超参；对两类任何分布几乎都能拟合到任意精度，配合 C 控制复杂程度。
  • **追问 2：核函数必须满足什么条件？** 回答：Mercer 条件——对任意样本集，核矩阵 $K_{ij}=K(x_i,x_j)$ 必须对称半正定，否则对应的优化问题无解或决策不可解释；核的闭式组合（正系数和、乘积）保持合法。
  • **追问 3：SMO 为什么一次只选两个 α？** 回答：对偶约束 $\sum\alpha_i y_i = 0$ 是一个线性等式——任意两个变量即可在保持等式成立的条件下做一次解析优化（把两者绑定、转成一个一维二次问题），其余变量固定。选三个或更多会破坏解析解，得不偿失。
  • **追问 4：γ 和 C 对过拟合的影响？** 回答：γ 控制核函数的宽度（决策边界弯曲程度），γ 过大高方差；C 控制对误分类的容忍度，C 过大几乎不允许误差，也可能过拟合且计算更慢。实际用交叉验证扫 C×γ 网格。
