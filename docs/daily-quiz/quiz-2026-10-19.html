算法编程 ⭐⭐ 第 1 题

模幂运算（快速幂）

给定整数 a、非负整数 n 和正整数 mod，请实现函数 my_pow(a, n, mod)，返回 $a^n \bmod mod$ 的**非负余数**（结果落在 $[0, mod)$ 内，与 Python % 语义一致）。

要求使用**快速幂（二进制取幂）**：$n$ 最大可达 $10^{18}$，若朴素地循环乘 $n$ 次，单次调用要做 $10^{18}$ 次乘法，必然超时；快速幂只需与 $\log_2 n$ 同阶次乘法（$n=10^{18}$ 时不超过 60 次）。

> 衔接今日晨间讲解《快速幂》——本题为该主题的编程实战。
输入
三个整数 `a`、`n`、`mod`，由函数参数传入。含义见题目描述。
输出
整数：$a^n \bmod mod$ 的非负余数。
示例 1
输入：a = 2, n = 10, mod = 1000
输出：24
$2^{10} = 1024$，$1024 \bmod 1000 = 24$。按二进制拆位：$10 = 1010_2$，累乘 $a^{2^1}$ 与 $a^{2^3}$ 两项。
示例 2
输入：a = 2, n = 0, mod = 1
输出：0
陷阱用例：$\bmod 1$ 时任何整数的余数都是 0——包括 $a^0 = 1$。若结果初始化写成 res = 1 而不是 res = 1 % mod，本题会错误地返回 1。
示例 3
输入：a = 5, n = 3, mod = 7
输出：6
$5^3 = 125$，$125 \bmod 7 = 6$。
约束
- $-10^9 \le a \le 10^9$ - $0 \le n \le 10^{18}$ - $1 \le mod \le 10^9 + 7$ 注：负底数是合法输入，结果须与 Python 的 `(a**n) % mod` 完全一致（非负余数口径）。

--- 以下为答案与解析 ---

💡 解题思路

把指数 $n$ 写成二进制：$n = \sum_i b_i \cdot 2^i$，则 $a^n = \prod_i (a^{2^i})^{b_i}$。维护 base = a^(2^i)（每轮自平方一次），当 $n$ 的当前最低位为 1 时把 base 累乘进结果 res，然后 $n$ 右移一位。整个过程只需 $\lfloor\log_2 n\rfloor + 1$ 轮。

三个防御点：
1. **res 初始化为 1 % mod**：mod = 1 时余数恒为 0，直接写 res = 1 会错；
2. **base 先归一化为 a % mod**：由同余乘法性质 $a \equiv b \pmod m \Rightarrow a^n \equiv b^n \pmod m$，负底数归一化到 $[0, mod)$ 后再取幂结果不变；
3. **每步乘法后立即 % mod**：防止中间数膨胀成天文数字（Python 不会溢出，但大数乘法会拖慢速度；在 C/Java 中则是必然溢出）。

📝 参考代码（python）

def my_pow(a: int, n: int, mod: int) -> int:
    """迭代二进制快速幂：返回 a^n mod mod 的非负余数，O(log n)。"""
    res = 1 % mod          # 防御点①：mod=1 时任何数余数为 0（含 a^0=1）
    base = a % mod         # 防御点②：归一化到 [0, mod)，负底数也正确（同余乘法性质）
    while n > 0:
        if n & 1:                      # 当前二进制位为 1：累乘这一项
            res = res * base % mod    # 防御点③：每步取模防中间数膨胀
        base = base * base % mod      # 底数自平方：a^(2^i) -> a^(2^(i+1))
        n >>= 1                       # 指数右移，处理下一个二进制位
    return res


# 自测（与内置 pow 交叉验证）
if __name__ == "__main__":
    assert my_pow(2, 10, 1000) == 24
    assert my_pow(2, 0, 1) == 0
    assert my_pow(-3, 3, 7) == pow(-3, 3, 7) == 1
    assert my_pow(123456789, 10**18, 998244353) == pow(123456789, 10**18, 998244353)
    print("all pass")

⚡ 复杂度分析

时间 O(log n)——循环次数为 n 的二进制位数，n ≤ 10^18 时至多 60 轮；朴素实现 O(n) 在 n=10^18 下不可行 空间 O(1)——迭代版本只用了常数个变量（递归版本 O(log n) 调用栈）

🎯 考点

二进制取幂（快速幂）模板题，考点：① 二进制拆位思想（指数下降一阶、底数平方一阶）；② mod=1 与 n=0 边界；③ 负底数同余归一化；④ 每步取模防溢出。应用：RSA 模幂、费马小定理求模逆元（$a^{p-2} \bmod p$）、组合数取模（$\binom{n}{k} \bmod p$）、矩阵快速幂加速线性递推（如斐波那契 $O(\log n)$）。

💡 解题思路

并查集的两个优化各自作用在何处、摊还分析依赖什么量、结构的能力边界（只合不分）是本题三条考查线。

🎯 考点

并查集三件套：① 摊还复杂度 α(n) 的成立条件（两优化齐上）；② 秩 = 树高上界 ≠ 集合大小（按秩合并与按大小合并是两种策略）；③ 路径压缩的局部性（只压缩访问路径）；④ 能力边界：只支持合并，不支持分裂/删除。应用：Kruskal 最小生成树判环（第 16 期 Q2 已考）、连通分量、离线 LCA。

🔍 逐项分析

  • **A 正确**。路径压缩 + 按秩合并的组合结论由 Tarjan 证明：任意操作序列均摊 O(α(n))，α 是阿克曼反函数，增长极慢，$n \le 2^{2^{2^{2^{2}}}}$ 内 α ≤ 4。只做路径压缩（无按秩合并）时，摊还上界退化为 O(log n)；只做按秩合并（无路径压缩）最坏也是 O(log n)——两个优化都做才能进到 α(n)。B/C/D 分别在「秩的含义」「压缩的作用范围」「结构能力边界」上设错。
  • **B 错误**。秩（rank）记录的是**树高的上界**（路径压缩后不再是真实高度，只保证不小于真实高度），不是元素个数。合并方向也是反的：按秩合并把**秩小的根挂到秩大的根下面**，两根秩相等时新根的秩 +1。记录元素个数的策略叫「按大小合并」，与「按秩合并」是两种不同策略（按大小合并时才是「元素多的当根」）。混淆两者是并查集最高频的误区。
  • **C 错误**。路径压缩只影响**本次 find 实际访问过的那条路径**：把路径上的节点直接接到根。树中其他分支的节点深度完全不变，因此树高一般仍大于 1。只有当 find 访问了所有分支时树才可能整体变「扁」。
  • **D 错误**。并查集的近线性摊还结论**只对「只合并不分裂」的操作序列成立**：一旦支持删除/分裂，秩与路径压缩的摊还分析全部失效。要支持删除/分裂通常改用：① 可撤销并查集——只支持按栈序（LIFO）撤销最近一次合并，每次 O(log n)；② 离线做法——按删除时刻从后往前反向「加点」；③ 其他结构（如 LCT）。
AI公式推导 ⭐⭐⭐ 第 3 题

投机解码：拒绝采样修正为什么能保证输出分布不变

投机解码（Speculative Decoding）用小模型 $q$（draft）起草 $\gamma$ 个 token，再让目标大模型 $p$（target）一次前向并行验证，从而在不改变输出分布的前提下加速解码。其「验证—修正」环节采用**拒绝采样（rejection sampling）**：

- 草稿按 $q$ 抽出 token $x \sim q(\cdot)$；
- 以接受概率 $\alpha(x) = \min\left(1,\ \frac{p(x)}{q(x)}\right)$ 接受 $x$；
- 若拒绝，从某个「残差分布」$r(\cdot)$ 重新采样一个 token 作为该步输出。

请完成推导：

**(a)** 推导残差分布 $r(x)$ 的表达式；

**(b)** 证明「接受路径 + 拒绝后重采样路径」合成后的最终输出分布**恰好等于目标模型分布 $p(x)$**（这是「无损加速」的数学根据）；

**(c)** 推导期望接受率 $\mathbb{E}_{x \sim q}[\alpha(x)]$ 与 $p, q$ 的总变差距离 $TV(p, q)$ 的关系，并解释它对「草稿模型该怎么选」的指导意义。

> 衔接今日晨间讲解《投机解码 Speculative Decoding》——本题把讲解中的结论推进到公式级证明。
--- 以下为答案与解析 ---

🎯 考点

考点：① 拒绝采样的接受/拒绝路径构造（$\min(p,q)$ 拆分是核心技巧）；② 修正后分布严格等于 $p$ 的分情况证明（Leviathan et al. 2023 / Chen et al. 2023 的严格采样性质）；③ 接受率 $= 1 - TV(p,q)$ 的闭式联系；④ 几何级数期望产出与「草稿要对齐分布而非对齐概率最大值」的选型直觉。与第 9/16/18 期已考的 KV Cache / MQA-GQA / 量化互补，补齐大模型推理加速的第四块拼图。

📐 推导过程

**约定**：词表为 $V$；$p(x) \ge 0$、$q(x) > 0$，且 $\sum_{x \in V} p(x) = \sum_{x \in V} q(x) = 1$；记 $(z)_+ = \max(z, 0)$。

---

**第 1 步：接受路径贡献的分布**

「$x$ 被抽出且被接受」的联合概率为：

$$q(x) \cdot \alpha(x) = q(x) \min\left(1, \frac{p(x)}{q(x)}\right) = \min(q(x),\ p(x))$$

（分情况验证：$p(x) \ge q(x)$ 时比值 $\ge 1$，取 1，得 $q(x)$；$p(x) < q(x)$ 时比值 $< 1$，取比值，约去 $q(x)$ 得 $p(x)$。两种情况统一为 $\min(p, q)$。）

**第 2 步：拒绝概率**

$$P(\text{rej}) = \sum_{x} q(x)\left(1 - \alpha(x)\right) = 1 - \sum_{x} \min(p(x), q(x)) \triangleq 1 - \beta$$

其中 $\beta = \sum_x \min(p(x), q(x)) \le 1$。

**第 3 步：残差分布 (a)**

拒绝后，应从「$p$ 有、而 $q$ 没有给足」的概率质量里重采样：

$$r(x) = \frac{(p(x) - q(x))_+}{\sum_{u}(p(u) - q(u))_+} = \frac{(p(x) - q(x))_+}{1 - \beta}$$

分母一致性证明：由 $\sum p = \sum q$，正差与负差总量相等：

$$\sum_x (p - q)_+ = \sum_x (q - p)_+ = \frac{1}{2}\sum_x |p(x) - q(x)| \triangleq TV(p, q)$$

又 $\min(p, q) = p - (p - q)_+$ 对 $p > q$ 的部分成立、对 $p \le q$ 部分为 $p$，逐项相加得 $\beta = \sum \min(p,q) = 1 - TV(p,q)$，故 $1 - \beta = TV(p,q) = \sum(p-q)_+$ ✓（分母恰为正差总量，$r$ 是合法分布）。

**第 4 步：合成分布 = p 的证明 (b)**

$$P(\text{out} = x) = \underbrace{\min(p(x), q(x))}_{\text{接受路径}} + \underbrace{P(\text{rej}) \cdot r(x)}_{\text{拒绝重采样路径}}$$

代入 $P(\text{rej}) = 1 - \beta = \sum(p-q)_+$ 与 $r(x)$：

$$P(\text{out} = x) = \min(p(x), q(x)) + (p(x) - q(x))_+$$

分情况化简：

- 若 $p(x) \ge q(x)$：$\min = q(x)$，$(p - q)_+ = p(x) - q(x)$，合计 $q + (p - q) = p(x)$；
- 若 $p(x) < q(x)$：$\min = p(x)$，$(p - q)_+ = 0$，合计 $p(x)$。

两种情况都得到 $p(x)$，故 $\forall x: P(\text{out}=x) = p(x)$，且总和为 1 ✓。**证毕**：无论草稿模型好坏，修正后的每一步输出分布严格等于目标模型分布——投机解码是「无损」的，采样上的差异只体现在速度，不体现在质量。

**第 5 步：期望接受率与 TV 距离 (c)**

$$\mathbb{E}_{x \sim q}[\alpha(x)] = \sum_x q(x)\min\left(1, \frac{p(x)}{q(x)}\right) = \sum_x \min(q(x), p(x)) = \beta = 1 - TV(p, q)$$

其中 $TV(p, q) = \frac{1}{2}\sum_x |p(x) - q(x)| \in [0, 1]$。两个极端：

- $q = p$：$TV = 0$，接受率 $= 1$，草稿全部通过；
- $q$ 与 $p$ 几乎不重叠：$TV \to 1$，接受率 $\to 0$，退化成纯 $p$ 解码还倒贴 $q$ 的开销。

**第 6 步（延伸）：每轮期望产出 token 数**

若近似认为每步接受率均为 $\beta$，起草 $\gamma$ 个 token 的一轮中，期望被接受的 token 数为几何级数求和：

$$\mathbb{E}[\#\text{accepted}] = 1 + \beta + \beta^2 + \cdots + \beta^{\gamma} = \frac{1 - \beta^{\gamma+1}}{1 - \beta}$$

（含「最后被拒位置由残差分布补采 1 个」。）草稿分布越准（$\beta \to 1$），一轮的目标模型前向次数摊到越多 token 上，加速比越高；反之收益迅速归零。

🧠 直觉解释

拒绝采样修正把「$p$ 比 $q$ 多出来的概率质量」原封不动补回去，接受的部分恰好对齐两者的公共质量 $\min(p,q)$——两条路径拼起来不多不少正好是 $p$。因此投机解码的加速是「白拿的」：输出分布与直接用 $p$ 解码逐位相同，加速上限 $1 - \beta$ 只取决于草稿与目标分布的 TV 距离，选草稿模型的唯一目标就是把分布对准。
AI面试问答 ⭐⭐ 第 4 题

偏差-方差分解与模型诊断：训练 99% 验证 70% 怎么办

面试官给你一个场景：同一个任务上——

- **模型 A**：训练集准确率 99%，验证集准确率 70%；
- **模型 B**（换小后的模型）：训练集 75%，验证集 74%。

请回答：

1. 从偏差-方差角度分别诊断 A、B 的问题；
2. 给出各自的改进方向；
3. 写出回归平方损失下的偏差-方差分解公式，并说明它的前提与局限。
--- 以下为答案与解析 ---

📌 回答要点

  • **分解公式（第 3 问）**：对随机抽取的训练集 $D$、平方损失，有
    $$\mathbb{E}_{D,\varepsilon}\left[(y - \hat f(x; D))^2\right] = \underbrace{\text{Bias}^2[\hat f]}_{\text{系统性偏离}} + \underbrace{\text{Var}[\hat f]}_{\text{对训练集扰动的敏感度}} + \underbrace{\sigma^2}_{\text{不可约噪声}}$$
    其中 $\text{Bias}[\hat f] = \mathbb{E}_D[\hat f(x;D)] - f^*(x)$，$\text{Var}[\hat f] = \mathbb{E}_D[(\hat f - \mathbb{E}_D\hat f)^2]$，$\sigma^2$ 是任何模型都无法消除的贝叶斯误差下界。
  • **模型 A：低偏差、高方差（过拟合）**。训练-验证 gap 高达 29 个百分点，说明模型容量相对数据过剩，把训练集的噪声也背了下来：训练误差逼近贝叶斯下界（偏差小），但对「换一份训练集」极度敏感（方差大）。
  • **模型 A 改进**：① 正则化——L2/L1、Dropout、早停；② 增数据 / 数据增强；③ 降容量（与 B 的方向相反）；④ Bagging 类集成（多模型平均直接压方差）。
  • **模型 B：高偏差（欠拟合）、方差可控**。train 与 val 几乎重合（74-75%）但双双偏低，说明不是「背噪声」而是「学不动」：特征表达能力不足，训练误差本身就被偏差顶住。
  • **模型 B 改进**：① 加容量（更深/更宽、更强模型）；② 加特征 / 特征工程 / 换表征；③ 若上了正则则减弱正则强度；④ 若是 Boosting 家族可加轮数。**诊断口诀：train 和 val 一起低 → 欠拟合（bias），train 高 val 低 → 过拟合（variance），两者都要看绝对值和 gap。**

⭐ 加分项

  • **深度学习时代该分解的局限**：经典 U 形权衡（容量↑先降偏差后升方差）在过参数化区域不完全成立——存在**双下降（double descent）**：容量越过插值阈值（刚好能记全训练集）后测试误差会先升后再次下降，巨大网络可以同时低偏差低方差。
  • **分解只在平方损失下精确成立**：0-1 分类损失没有严格的加性 bias-variance 分解（只有近似或代理分析），所以面试里要说清「公式前提是回归平方损失 + 对 $D$ 取期望」。
  • **与集成家族的对应**：随机森林/Bagging 平均 $m$ 个高方差低偏差的树，若树间近似独立方差近似降为 $1/m$ 量级 → 主降方差；GBDT/Boosting 顺序拟合负梯度逐步纠偏 → 主降偏差（呼应第 1、16 期已学的集成主题）。
  • **工程上不直接测分解**：严格测 Var 要对多份独立训练集重复训练，代价高；实践中用**学习曲线**（train/val 误差随样本量、容量的走势）做等价诊断。

🔮 追问预测

  • 追问：**为什么 Bagging 降方差、Boosting 降偏差？**——Bagging 是有放回并行采样 + 平均：$\text{Var}\left(\frac{1}{m}\sum \hat f_i\right) = \frac{\sigma^2}{m} + \rho\sigma^2\left(1 - \frac{1}{m}\right)$，平均把独立部分的方差压掉、不抬偏差；Boosting 串行拟合，后一轮专门纠正前一轮的系统性错误，主要削偏差，但逐步拟合使其方差略升。
  • 追问：**深度网络参数上亿，为什么不是必然高方差？**——显式正则（weight decay、Dropout、早停、数据增强）+ 隐式正则（SGD 噪声、BN 的平滑效应）共同压制有效容量；过参数化 + 强正则下模型的「有效自由度」远小于参数量，双下降也说明容量不能只用参数量衡量。
  • 追问：**只有一个数据集时怎么估计方差？**——用多个随机种子重复训练看验证指标波动（含数据顺序/初始化的方差下界），或用 K 折交叉验证近似；bootstrap 重采样 (.632 自助法) 也可给出偏差-方差的近似估计。
