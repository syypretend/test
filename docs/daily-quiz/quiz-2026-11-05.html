算法编程 ⭐⭐⭐ 第 1 题

柱状图中的最大矩形（单调栈）

给定 $n$ 个非负整数，表示柱状图中每个柱子的高度，每个柱子宽度均为 $1$。求该柱状图中能够勾勒出的最大矩形面积。

要求设计 $O(n)$ 的解法：对每根柱子，找出「以它为高度时能向左右扩展到的最远边界」，用单调递增栈在弹栈时一次性结算。
输入
一个整数数组 heights，表示各柱子的高度。
输出
一个整数，表示最大矩形面积。
示例 1
输入：heights = [2,1,5,6,2,3]
输出：10
以高度 5 和 6 组成宽 2 的矩形，面积为 5×2=10，是最大者。
示例 2
输入：heights = [2,4]
输出：4
高度 4 的柱子单独构成 4×1=4；两根合起来高度只能取 2，面积 2×2=4。
约束
1 <= heights.length <= 10^5；0 <= heights[i] <= 10^4。答案最大可达 10^9，Python 整数无溢出问题。

def largestRectangleArea(heights): """ 返回柱状图中能勾勒出的最大矩形面积。 :param heights: List[int]，每个柱子的高度，宽度均为 1 :return: int """ # 在这里编写你的代码 pass
--- 以下为答案与解析 ---

💡 解题思路

枚举「矩形的高度」而不是左右边界：对每根柱子 i，若以 heights[i] 为矩形高度，则矩形能向左延伸到第一个高度严格小于它的柱子之后，向右延伸到第一个高度严格小于它的柱子之前。用单调递增栈维护尚未确定右边界的下标：遍历到 i 时，若 heights[i] 小于栈顶高度，说明栈顶柱子的右边界就是 i，弹栈并以其高度结算；左边界是弹栈后新的栈顶（若栈空则为 -1）。在数组末尾追加哨兵 0，保证遍历结束后栈中所有柱子都被结算。由于每个下标最多入栈、出栈一次，总复杂度 O(n)。

📝 参考代码（python）

def largestRectangleArea(heights):
    # 单调递增栈：存下标，栈内对应高度单调不减
    stack = []
    best = 0
    # 末尾加哨兵 0，强制把栈中剩余柱子全部弹出结算
    for i, h in enumerate(heights + [0]):
        while stack and heights[stack[-1]] > h:
            height = heights[stack.pop()]       # 被弹出柱子作为矩形高度
            left = stack[-1] if stack else -1   # 左边第一个更矮的柱子
            width = i - left - 1                # 右边界 i，左边界 left
            best = max(best, height * width)
        stack.append(i)
    return best

⚡ 复杂度分析

时间 O(n)，每个下标入栈、出栈各至多一次 空间 O(n)，栈最多存放 n 个下标

🎯 考点

单调栈的「延迟结算」思想；哨兵简化边界处理；用下标而非高度入栈才能算宽度；严格大于才弹栈，保证等高峰值也能正确处理（等高的前一根会在后一根处结算出更大或相等的宽度）。
算法概念 ⭐⭐ 第 2 题

差分数组：区间批量加法的 O(1) 更新

需要对长度为 $n$ 的数组 $a$ 执行 $m$ 次操作「把区间 $[l, r]$ 内所有元素加上 $v$」，最后一次性输出整个数组。定义差分数组 $d$：$d[0]=a[0]$，$d[i]=a[i]-a[i-1]\ (i\ge 1)$。下列哪项描述是正确的？
--- 以下为答案与解析 ---
✅ 正确答案：A

💡 解题思路

差分数组的核心是把「区间整体加 v」转化为「两个端点的单点修改」：区间内每个元素的增量在差分表示中会相互抵消，只有 l 处的差值增加 v、r+1 处的差值减少 v。所有离线修改结束后，对 d 做一次前缀和即得最终数组。

🎯 考点

差分是前缀和的逆运算；区间修改 O(1)、离线还原 O(n)；二维差分可把子矩阵加值转为四个角点的修改；当查询与修改交替出现时，需升级为树状数组/线段树。

🔍 逐项分析

  • A 正确。d[l] += v 使从 l 开始的所有位置在累加前缀和时都多出 v；d[r+1] -= v 让 r+1 及之后的位置把这份增量抵消掉，恰好只影响 [l, r]。每次修改 O(1)，m 次共 O(m)，还原 O(n)，总计 O(n+m)。
  • B 错误。O(log n) 是「需要在线查询任意前缀和/区间和」时才引入树状数组或线段树的代价；本题只要求全部修改做完后统一输出，差分数组即可做到 O(1) 修改。
  • C 错误。差分数组恰恰是为区间修改设计的；单点修改在它上面反而是 d[i] += v、d[i+1] -= v 这种退化形式。
  • D 错误。还原要用前缀和 a[i] = d[0] + d[1] + ... + d[i]，因为 d[i] 的定义就是相邻元素的差；后缀和没有对应含义。
AI公式推导 ⭐⭐⭐ 第 3 题

InfoNCE 对比损失：对 query 向量的梯度推导

InfoNCE 是句向量 / 图文检索模型（如 Sentence-BERT、CLIP）最常用的训练目标，也是 RAG 中 embedding 微调的基础。设 query 向量为 $q\in\mathbb{R}^d$，正样本为 $k^+$，$K$ 个负样本为 $k_1,\dots,k_K$。相似度取带温度的余弦/内积打分：

$$s(q,k)=\frac{q^{\top}k}{\tau}$$

损失定义为

$$\mathcal{L}=-\log\frac{\exp(s(q,k^+))}{\exp(s(q,k^+))+\sum_{j=1}^{K}\exp(s(q,k_j))}$$

请推导 $\dfrac{\partial\mathcal{L}}{\partial q}$，并说明温度 $\tau$ 在梯度中的作用。
--- 以下为答案与解析 ---

🎯 考点

InfoNCE = (K+1) 路交叉熵；梯度 = (1/τ)(E_p[k] − k+)；温度同时缩放梯度幅值与 softmax 尖锐度；batch 内负样本即 in-batch negatives，对称式损失对 q、k 两侧各算一次；K 越大 InfoNCE 越紧地逼近互信息下界 log K − L。

📐 推导过程

第 1 步：统一记号。 令 $z_0=s(q,k^+)=\dfrac{q^{\top}k^+}{\tau}$，$z_j=s(q,k_j)=\dfrac{q^{\top}k_j}{\tau}\ (j=1..K)$。则
$$\mathcal{L}=-z_0+\log\Big(e^{z_0}+\sum_{j=1}^{K}e^{z_j}\Big)=-z_0+\log\sum_{i=0}^{K}e^{z_i}$$

第 2 步：对 logits 求导。 对任意 $i\in\{0,..,K\}$：
$$\frac{\partial \mathcal{L}}{\partial z_i}=-\mathbb{1}[i=0]+\frac{e^{z_i}}{\sum_{m=0}^{K}e^{z_m}}=-\mathbb{1}[i=0]+p_i$$
其中 $p_i=\mathrm{softmax}(z)_i$ 是「正样本 + 全部负样本」上的 softmax 概率。这一步说明：InfoNCE 本质就是一个 $(K+1)$ 分类的交叉熵，正样本是正确类别。

第 3 步：logits 对 q 求导。 因为 $z_i=\dfrac{q^{\top}k_i}{\tau}$（把 $k^+$ 记作 $k_0$），有
$$\frac{\partial z_i}{\partial q}=\frac{k_i}{\tau}$$

第 4 步：链式法则合并。
$$\frac{\partial \mathcal{L}}{\partial q}=\sum_{i=0}^{K}\frac{\partial \mathcal{L}}{\partial z_i}\cdot\frac{\partial z_i}{\partial q}=\frac{1}{\tau}\Big(\sum_{i=0}^{K}p_i k_i-k_0\Big)$$
即
$$\boxed{\ \frac{\partial \mathcal{L}}{\partial q}=\frac{1}{\tau}\big(\mathbb{E}_{p}[k]-k^{+}\big)\ }$$

第 5 步：含义与温度的作用。
- $\mathbb{E}_p[k]$ 是按 softmax 权重对所有候选做的加权平均；梯度方向是「从负样本加权中心指向正样本」，即把 $q$ 拉向 $k^+$、推离被赋予高概率的困难负样本。
- 当 $p_0\to 1$（已经分对且 margin 很大）时 $\mathbb{E}_p[k]\to k^+$，梯度趋于 0，损失饱和。
- 温度 $\tau$ 出现在两个地方：一是缩放梯度 $1/\tau$；二是改变 $p$ 的尖锐程度——$\tau$ 越小分布越尖锐，梯度越集中在最难的负样本上（更难但更易训练不稳定、需要梯度裁剪或 warmup）；$\tau$ 越大分布越平滑，所有负样本都参与、梯度更稳但判别力弱。
- 若进一步对 $\tau$ 求导：$\partial z_i/\partial\tau=-q^{\top}k_i/\tau^2$，可得 $\partial\mathcal{L}/\partial\tau=\dfrac{1}{\tau}\big(\mathbb{E}_p[q^{\top}k]-q^{\top}k^+\big)$，因此 $\tau$ 也可学习（如 CLIP 的可学习 logit scale）。

🧠 直觉解释

InfoNCE 就是一个「正样本 vs 一堆负样本」的 softmax 分类：梯度等于（按概率加权的负样本中心）减去正样本，温度决定你把注意力放在多难的负样本上。
AI面试问答 ⭐⭐ 第 4 题

大模型幻觉的成因与工程化缓解方案

面试官问：「你们线上大模型应用怎么处理幻觉（Hallucination）？请说明幻觉的成因，以及你会从哪些层面做缓解。」
--- 以下为答案与解析 ---

📌 回答要点

  • 先定义再分类：幻觉指模型生成了不忠实于输入或不符合事实的内容，分为内在幻觉（与给定上下文矛盾）和外在幻觉（无法从上下文验证、凭空补充）。两者治理手段不同，先分清再谈方案。
  • 成因一：知识与目标错配。预训练目标是 next-token 似然，优化的是「像人写的」而不是「是真的」；长尾事实在训练语料中出现少，模型只能用相似模式补全，表现为自信地编造。
  • 成因二：上下文使用失败。RAG 场景中检索没召回、召回了噪声、或关键信息落在长上下文中部（lost in the middle），模型仍按参数记忆作答，造成与文档冲突。
  • 成因三：解码与对齐副作用。高温采样放大随机性；RLHF 偏好「有帮助、完整」的回答，会诱发模型在不知道时也硬答（谄媚/过度自信），而不是说「不确定」。
  • 缓解要分层落地：① 数据层——RAG 保证可溯源、chunk 与召回评估、必要时做知识库时效更新；② 训练层——SFT 加入「据实回答/拒答」样本，偏好优化中用事实性奖励，领域内做继续预训练；③ 解码层——降低 temperature/top-p、结构化输出、工具调用替代记忆性回答；④ 后处理层——引用对齐校验、规则/小模型事实核查、置信度低时转人工；⑤ 评估层——建立事实性评测集与 faithfulness 指标，线上抽样监控。

⭐ 加分项

  • 指出幻觉不可能被彻底消除，工程目标是「把不可控幻觉变成可检测、可兜底的风险」，因此要配套引用、置信度与人工兜底，而不是只追求模型能力。
  • 能区分「事实性（factuality）」与「忠实性（faithfulness）」：RAG 场景更应先保证忠实性（不超出上下文），再谈参数知识的事实性。
  • 提到长上下文的位置偏置：把关键证据放在开头/结尾或做重排，比单纯扩大窗口更有效。
  • 提到不确定性估计：logit 熵、多次采样一致性（self-consistency）、语义熵都可作为拒答/转人工的信号。

🔮 追问预测

  • 追问：RAG 已经给了文档，为什么还会幻觉？ 答：检索可能没召回正确片段；上下文有冲突或噪声；模型存在位置偏置和「参数记忆优先」倾向；生成时仍可能做无依据的跨句推理。对应要做召回评估、重排、引用约束和「仅依据上下文作答」的提示与训练。
  • 追问：怎么量化幻觉率？ 答：构建领域事实性测试集，用人工标注或强模型做 judge，指标包括事实错误率、无依据断言比例、引用支持率（faithfulness）；线上可用抽样人评 + 自动核查 + 用户反馈闭环。
  • 追问：怎么让模型学会说「不知道」？ 答：训练数据中加入拒答与澄清样本；做校准（confidence calibration）；推理时用一致性/熵阈值触发拒答；产品层提供「未找到依据」的标准话术与转人工入口。
