算法编程 ⭐⭐ 第 1 题

合并 K 个升序链表（最小堆多路归并）

给定 $k$ 条升序排列的链表（每条链表用 Python 列表表示，[] 表示空链表），请把它们合并为一条新的升序链表并返回。

要求使用**最小堆（优先队列）**实现多路归并：先把每条链表的头节点加入大小为 $k$ 的最小堆，每次弹出堆顶（当前所有链头中的最小值）接到结果末尾，再将被弹出节点所在链的下一个节点入堆，重复直到堆空。

这是堆结构除 TopK 外的经典应用——**多路归并**，复杂度为 $O(N\log k)$，其中 $N$ 为总节点数。
输入
参数 `lists`：二维列表，`lists[i]` 为第 i 条升序链表的节点值列表（可为空）。共 $k$ 条链。
输出
返回合并后的升序链表的节点值列表。
示例 1
输入：lists = [[1,4,5],[1,3,4],[2,6]]
输出：[1,1,2,3,4,4,5,6]
三条链各自有序，逐轮弹出全局最小：1→1→2→3→4→4→5→6。
示例 2
输入：lists = []
输出：[]
没有链表，结果为 []。
约束
0 ≤ k ≤ 10^4；每条链表长度 0 ≤ $n_i$ ≤ 500，总节点数 $N$ ≤ 10^5；节点值 $-10^4$ ≤ val ≤ $10^4$，每条链表内严格升序。

--- 以下为答案与解析 ---

💡 解题思路

1. 把每条非空链表的头节点以 (值, 链索引, 下标) 三元组压入最小堆，堆大小 ≤ k，初始化 $O(k)$。
2. 循环弹出堆顶 (val, i, idx)——这是当前所有链剩余节点中的最小值，追加到结果；若该链还有后继节点则立即压入，堆始终保持『每条链最多一个代表』，故每次堆操作 $O(\log k)$。
3. 共弹出 $N$ 个节点，总时间 $O(N\log k)$；堆最多 $k$ 个元素，额外空间 $O(k)$（不计输出）。
4. 元组第三位（链内下标）用于区分不同链的相同值，防止堆比较时退化到比较整个列表。

📝 参考代码（python）

import heapq

def solve_lists(lists):
    # (值, 链表索引, 下标) 组成堆元素，索引/下标做二级比较防止相同值互相比较列表
    heap = []
    for i, lst in enumerate(lists):
        if lst:
            heapq.heappush(heap, (lst[0], i, 0))
    res = []
    while heap:
        val, i, idx = heapq.heappop(heap)
        res.append(val)
        if idx + 1 < len(lists[i]):
            heapq.heappush(heap, (lists[i][idx + 1], i, idx + 1))
    return res

⚡ 复杂度分析

时间 O(N log k) 空间 O(k)（不含输出）

🎯 考点

堆的 Top 式弹出/压入、多路归并模型、(值,链号,下标) 元组消重、堆大小与 k 的关系、空链与 k=0 的边界。
算法概念 ⭐ 第 2 题

回溯算法：性质与适用条件

关于**回溯算法（Backtracking）**，下列说法正确的是？

提示：回溯通常以深度优先搜索（DFS）为骨架，在递归深入时『做选择』、返回前『撤销选择』，并常配合剪枝加速。
--- 以下为答案与解析 ---
✅ 正确答案：C

💡 解题思路

逐个选项分析：A 混淆『剪枝』与『贪心提前决策』；B 混淆实现方式；C 是回溯的核心语义（搜索 + 撤销 + 剪枝可选）；D 混淆回溯与普通 DFS 的状态管理差异。

🎯 考点

回溯三要素（选择/递归/撤销）、剪枝对正确性与效率的不同影响、递归与显式栈的关系、回溯与 DFS 的差异。

🔍 逐项分析

  • A 错：剪枝只跳过『必然不可行 / 必然不优于当前最优』的分支，被剪分支原本就产生不了更优解，所以不影响最终答案，只影响搜索量。
  • B 错：递归只是实现手段；显式栈（手动压栈模拟系统调用栈）同样可以完成回溯，仅可读性差。
  • C 对：回溯=DFS + 路径状态维护 + 可选剪枝；撤销选择（undo）保证各分支状态独立，是回溯正确性的关键；剪枝不改正确性。
  • D 错：普通 DFS 常不维护『本次选择的影响』，也不负责撤销；回溯必须在递归返回后恢复现场，二者并非等价。
AI公式推导 ⭐⭐⭐ 第 3 题

Word2Vec Skip-gram 负采样损失与梯度完整推导

推导任务：从极大似然出发，推导 Skip-gram 模型的目标函数；说明原始 softmax 归一化为何代价高昂；引入**负采样（Negative Sampling）**近似后，完整推导其对输出向量 $\mathbf{u}_o$、负样本向量 $\mathbf{u}_k$ 与中心词向量 $\mathbf{v}_c$ 的三个梯度公式。

要求写清每一步的链式法则与 sigmoid 恒等式，不能只给结论。
--- 以下为答案与解析 ---

🎯 考点

softmax 全表归一化的 O(|V|d) 代价、负采样二分类目标、sigmoid 导数与 1−σ(x)=σ(−x) 恒等式、正/负样本对中心词与输出向量的四条梯度公式、梯度上升更新语义。

📐 推导过程

**符号约定**：词汇表 $V$，向量维数 $d$。每个词 $w$ 有两套向量：作为中心词时的**输入向量** $\mathbf{v}_w\in\mathbb{R}^d$，作为目标/上下文词时的**输出向量** $\mathbf{u}_w\in\mathbb{R}^d$。给定中心词 $c$ 与其上下文词 $o$。\n\n---\n\n**Step 1 原始目标：条件概率的极大似然**\n\nSkip-gram 对单个样本 $(c,o)$ 建模条件概率：\n$$P(o\mid c)=\frac{\exp(\mathbf{u}_o^{\top}\mathbf{v}_c)}{\sum_{w\in V}\exp(\mathbf{u}_w^{\top}\mathbf{v}_c)}$$\n\n取对数得：\n$$L=\log P(o\mid c)=\mathbf{u}_o^{\top}\mathbf{v}_c-\log\Big(\sum_{w\in V}\exp(\mathbf{u}_w^{\top}\mathbf{v}_c)\Big)$$\n\n对 $\mathbf{v}_c$ 求导（分母项是 softmax 期望形式）：\n$$\frac{\partial L}{\partial \mathbf{v}_c}=\mathbf{u}_o-\sum_{w\in V}\underbrace{\frac{\exp(\mathbf{u}_w^{\top}\mathbf{v}_c)}{\sum_{j}\exp(\mathbf{u}_j^{\top}\mathbf{v}_c)}}_{=P(w\mid c)}\mathbf{u}_w=\mathbf{u}_o-\mathbb{E}_{w\sim P(\cdot\mid c)}[\mathbf{u}_w]$$\n\n即『真实词的输出向量 − 全词加权平均输出向量』。但分母求和遍历整个词表 $V$（百万级），每个样本 $O(|V|\cdot d)$ 不可接受——这是**负采样（Negative Sampling）**的动机。\n\n---\n\n**Step 2 负采样：把多分类换成 $K+1$ 个二分类**\n\n把『从全词表选 $o$』改为『判断 (c,o) 是否正例』。对正样本希望 $\sigma(\mathbf{u}_o^{\top}\mathbf{v}_c)\to 1$，对按噪声分布 $P_n(w)$ 抽出的 $K$ 个负样本 $w_1,\dots,w_K$ 希望 $\sigma(\mathbf{u}_{w_k}^{\top}\mathbf{v}_c)\to 0$。取对数 sigmoid 并求和：\n$$J=\log\sigma(\mathbf{u}_o^{\top}\mathbf{v}_c)+\sum_{k=1}^{K}\log\sigma(-\mathbf{u}_{w_k}^{\top}\mathbf{v}_c)$$\n\n其中 $\sigma(x)=1/(1+e^{-x})$，且满足两个恒等式：\n$$\sigma'(x)=\sigma(x)\big(1-\sigma(x)\big),\qquad 1-\sigma(x)=\sigma(-x)$$\n\n---\n\n**Step 3 对输出向量求导**\n\n记 $s=\mathbf{u}_o^{\top}\mathbf{v}_c$，对正样本输出向量 $\mathbf{u}_o$：\n$$\frac{\partial J}{\partial \mathbf{u}_o}=\frac{\sigma'(s)}{\sigma(s)}\cdot\frac{\partial s}{\partial \mathbf{u}_o}=\big(1-\sigma(s)\big)\mathbf{v}_c=\boxed{\sigma(-\mathbf{u}_o^{\top}\mathbf{v}_c)\,\mathbf{v}_c}$$\n\n对负样本输出向量 $\mathbf{u}_k$（令 $s_k=\mathbf{u}_k^{\top}\mathbf{v}_c$）：\n$$\frac{\partial J}{\partial \mathbf{u}_k}=\frac{\sigma'(-s_k)}{\sigma(-s_k)}\cdot(- \mathbf{v}_c)=-\big(1-\sigma(-s_k)\big)\mathbf{v}_c=\boxed{-\sigma(\mathbf{u}_k^{\top}\mathbf{v}_c)\,\mathbf{v}_c}$$\n\n直觉：正样本的梯度系数 $\sigma(-s)\in(0,1)$ 是『模型对该对的犯错程度』——$s$ 越小（越容易错），系数越大，更新越猛；负样本系数 $\sigma(s_k)$ 同理。\n\n---\n\n**Step 4 对中心词向量 $\mathbf{v}_c$ 求导（各项叠加）**\n\n正项对 $\mathbf{v}_c$ 的贡献 $(1-\sigma(s))\mathbf{u}_o$，每个负项对 $\mathbf{v}_c$ 的贡献 $-(1-\sigma(-s_k))\mathbf{u}_k$：\n$$\frac{\partial J}{\partial \mathbf{v}_c}=\big(1-\sigma(\mathbf{u}_o^{\top}\mathbf{v}_c)\big)\mathbf{u}_o-\sum_{k=1}^{K}\big(1-\sigma(-\mathbf{u}_k^{\top}\mathbf{v}_c)\big)\mathbf{u}_k=\boxed{\sigma(-\mathbf{u}_o^{\top}\mathbf{v}_c)\,\mathbf{u}_o-\sum_{k=1}^{K}\sigma(\mathbf{u}_k^{\top}\mathbf{v}_c)\,\mathbf{u}_k}$$\n\n---\n\n**Step 5 参数更新与直觉**\n\n梯度上升：$\mathbf{v}_c\leftarrow\mathbf{v}_c+\eta\frac{\partial J}{\partial \mathbf{v}_c}$、$\mathbf{u}_o\leftarrow\mathbf{u}_o+\eta\frac{\partial J}{\partial \mathbf{u}_o}$、$\mathbf{u}_k\leftarrow\mathbf{u}_k+\eta\frac{\partial J}{\partial \mathbf{u}_k}$。\n\n更新效果：正项把 $\mathbf{v}_c$ 拉向 $\mathbf{u}_o$（增大二者内积，让模型更确信 (c,o) 共现），负项把 $\mathbf{v}_c$ 推离 $\mathbf{u}_k$（压低与噪声词的内积）。整体等价于『让正样本对的内积大于负样本对』，每次更新只需访问 $K+1$ 个输出向量，复杂度降为 $O(Kd)$ 与词表规模无关。

🧠 直觉解释

负采样把『百万分类』退化为 K+1 个二分类：正样本项把中心词向量拉向真实上下文，负样本项把它推离噪声词；梯度系数恰是各自当前的犯错概率，犯错越大更新越猛。
AI面试问答 ⭐⭐ 第 4 题

Transformer 为什么需要位置编码？绝对位置编码与 RoPE 有何区别？

面试场景：面试官问『Transformer 的注意力机制明明是『置换等变』的，为什么还要位置编码？现在主流大模型用的 RoPE（旋转位置编码）和传统的正弦/可学习绝对位置编码比，有什么区别？』

请给出有层次的回答：先答必要性，再讲绝对编码做法与局限，最后对比 RoPE 的原理与优势。
--- 以下为答案与解析 ---

📌 回答要点

  • 必要性：自注意力计算 $\mathbf{Attention(Q,K,V)}=\mathrm{softmax}(QK^{ op}/\sqrt{d})V$ 只依赖两两 token 的相似度，对序列做任何置换，输出只是同步换位——模型天然不感知顺序；语言语义高度依赖词序（『猫追狗』vs『狗追猫』），因此必须把位置信息显式注入。
  • 绝对位置编码两类：① 正弦编码（原版 Transformer），位置 $p$ 的第 $2i/2i+1$ 维分别取 $\sin(p/10000^{2i/d})$、$\cos(p/10000^{2i/d})$，不同频率的周期波使任意两点位置向量互不相同；② 可学习位置表（BERT/GPT-2），把位置映射为一个可训练向量，与词向量相加。二者都以「加法」把绝对位置烙进输入。
  • 绝对编码的局限：位置信息与内容向量叠加后纠缠，模型需隐式学会相对位置；超过训练长度（如 512）时未见过的位置向量分布失配，外推能力差；相对位置（谁在谁后面多远）要网络自己从数据里学。
  • RoPE 原理：把词向量按奇偶位拆成 $d/2$ 组复数组，将位置 $m$ 的旋转角度 $ heta_i=m\cdot10000^{-2i/d}$ 以旋转矩阵 $R(m)$ 与 Q/K 向量相乘：$\mathbf{q}_m=R(m)\mathbf{q}$、$\mathbf{k}_n=R(n)\mathbf{k}$。利用旋转内积性质 $\langle R(m)\mathbf{q},R(n)\mathbf{k} angle=\langle \mathbf{q},R(n-m)\mathbf{k} angle$——内积只依赖位置差 $n-m$，天然编码**相对位置**。
  • 对比结论：RoPE 无参、作用于 Q/K 而非输入、携带相对位置、可与线性注意力兼容且支持更好的长度外推（配合插值/NTK），是 LLaMA、Qwen 等主流大模型的标配；正弦/可学习绝对编码实现简单、适合训练内长度的任务，但外推能力弱。

⭐ 加分项

  • RoPE 的复数视角：$d$ 维向量按对拆成复数 $z=[x_0+ix_1,\dots]$，旋转位置编码等价于 $z\cdot e^{im heta_i}$（频率调制），可证明内积携带相对位置差。
  • 外推工程化：RoPE 配合长度外推技巧（位置插值、NTK-aware scaling、YaRN）可以把训练 4K 的模型用到 128K+；纯正弦绝对编码无法等价实现，只能重新训练。
  • 延伸：T5 用相对位置 bias（训练出每对相对距离的标量偏置），ALiBi 直接给注意力分数加线性距离惩罚，二者属于位置偏置族的其他代表；多模态 2D/3D 场景有 2D-RoPE 等扩展。

🔮 追问预测

  • 追问1『正弦编码也能给任意位置生成向量，为什么外推还是崩？』→ 位置向量虽处处有定义，但模型权重只在训练长度的位置组合上见过 Q/K 分布，超长后 softmax 落入未见区域退化；RoPE 数学上支持任意位置，仍需插值/NTK 等手段校准分布。
  • 追问2『为什么 RoPE 外推不完全 free？』→ 内积虽只依赖位置差，但注意力得分随距离衰减的模式是训练时学到的，超出训练长度后长距离组合分布失配；插值方法本质是压缩位置差使分布落在训练区间内。
  • 追问3『绝对编码 vs 相对编码哪个更好，业界怎么选？』→ 长序列与局部先验场景相对编码占优（RoPE/相对 bias）；绝对编码实现简单、短文本足够。工程上 GPT 系在绝对可学习位置表基础上叠加相对 bias 等混合方案。
