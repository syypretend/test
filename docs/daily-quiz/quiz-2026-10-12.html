算法编程 ⭐⭐ 第 1 题

跳跃游戏 II（最少跳跃次数）

给定一个长度为 $n$ 的非负整数数组 $\text{nums}$，你初始位于下标 $0$。数组中的每个元素 $\text{nums}[i]$ 表示你在该位置可以跳跃的**最大**长度（即从 $i$ 可跳到 $i+1, i+2, \dots, i+\text{nums}[i]$ 中的任意一个下标）。假设你**总能到达最后一个下标**，求到达下标 $n-1$ 所需的**最少跳跃次数**。

> 改编自 LeetCode 45（Jump Game II），考查**贪心选择 + 层序推进**思想：维护"当前这一跳的最右边界"，扫描到边界时步数 +1。
输入
输入为一个非负整数数组 `nums`（作为函数参数传入）
输出
返回一个整数：到达最后一个下标所需的最少跳跃次数
示例 1
输入：nums = [2, 3, 1, 1, 4]
输出：2
先从 0 跳到 1（跳 1 步），再从 1 跳到 4（跳 3 步），共 2 次跳跃。
示例 2
输入：nums = [2, 3, 0, 1, 4]
输出：2
0 → 1 → 4，最少 2 次跳跃。
约束
$1 \leq \text{nums.length} \leq 10^5$，$0 \leq \text{nums}[i] \leq 10^5$，题目保证一定能到达最后一个下标。

--- 以下为答案与解析 ---

💡 解题思路

贪心 + 层扩展（BFS 压缩版）：把每一次跳跃看成"一层"，维护 cur_end（当前层能到的最右边界）与 farthest（扫描过程中可达的最远下标）。从左到右扫描，不断用 i + nums[i] 更新 farthest；当 i 到达 cur 时说明当前层的所有选择都已考察完，必须再跳一次，并把 cur 更新为 farthest；一旦 cur 覆盖到 n-1 就提前结束。每层恰好 +1，等价于在层图上求最短路。

📝 参考代码（python）

def solve(nums):
    n = len(nums)
    if n <= 1:
        return 0
    jumps = 0        # 已跳次数
    cur = 0          # 当前这一跳能到达的最右边界
    farthest = 0     # 扫描过程中能到达的最远下标
    for i in range(n - 1):
        farthest = max(farthest, i + nums[i])
        if i == cur:            # 到达本跳边界：必须再跳一次
            jumps += 1
            cur = farthest
            if cur >= n - 1:    # 已经能到终点，提前结束
                break
    return jumps

⚡ 复杂度分析

时间 O(n) 空间 O(1)

🎯 考点

贪心选择性质：在当前位置的可达区间内，选择能延伸最远的落脚点即为最优（该区间内的所有点下一次跳跃的可达区间是单调包含的，因此按"层"推进即最优）；注意循环只需扫到 n-2（最后一位无需跳）；边界情况 n=1 返回 0。
算法概念 ⭐⭐ 第 2 题

最短路算法辨析

关于单源/多源最短路径算法，以下哪种说法**正确**？
--- 以下为答案与解析 ---
✅ 正确答案：B

💡 解题思路

逐一核对各算法的最短适用条件与复杂度。Dijkstra 的正确性依赖'每次取出堆顶时其距离已确定'，该结论仅在所有权重非负时成立；Bellman-Ford 通过至多 n-1 轮松弛逐层传播距离；Floyd 是多源全局算法；DAG 上可直接用拓扑序松弛。

🎯 考点

三种经典最短路算法的最短适用：Dijkstra（非负权、O((V+E)logV)）、Bellman-Ford（可负权、检测负环、O(VE)）、Floyd（多源、O(V³)）；注意'负权边'与'负权环'是两个不同的破坏条件。

🔍 逐项分析

  • A 错误：Dijkstra 的正确性不仅依赖'无负权环'，而是要求所有边权非负。即使不存在负权环，只要存在一条负权边，已确定的最短路就可能被后续负边修正，贪心失效（例如 s→a 权 2、s→b 权 3、a→b 权 -2，Dijkstra 会先确定 a=2，但实际 b=1）。
  • B 正确：Bellman-Ford 初始化 dist[s]=0，对每条边 (u,v,w) 做松弛 dist[v] = min(dist[v], dist[u]+w)，重复 |V|-1 轮后若第 |V| 轮仍可松弛，说明存在负权环（因为任何无负环图的最短路至多含 n-1 条边）。
  • C 错误：Floyd-Warshall 求的是任意两点间的多源最短路径（动态规划按中间点枚举），时间复杂度 O(V³)；单源最短路径是 Dijkstra/Bellman-Ford 的范畴。
  • D 错误：DAG 上正确做法是按拓扑序松弛（O(V+E)），或仍可用 Bellman-Ford；Dijkstra 的正确性条件与'是否有环'无关，只要有负权边它就可能给出错误结果。
AI公式推导 ⭐⭐ 第 3 题

推导 GBDT：为什么每棵树拟合的是"负梯度"（回归时即残差）

给定加法模型 $F_M(\mathbf{x}) = \sum_{m=1}^M f_m(\mathbf{x})$（$f_m$ 为回归树）与损失函数 $L(y, F)$，推导第 $m$ 轮最优新树应拟合的目标，并说明：平方损失下该目标即**残差** $y - F_{m-1}(\mathbf{x})$；对其他损失则是**负梯度**——这就是"梯度提升（Gradient Boosting）"名称的由来。
--- 以下为答案与解析 ---

🎯 考点

函数空间梯度下降：$F$ 逐轮沿 $-\partial L/\partial F$ 更新；平方损失负梯度=残差；叶子值需重新优化而非直接取伪残差；shrinkage 学习率 $\nu$ 防止过拟合；该推导同样解释了为什么 GBDT 对异常值敏感（平方损失残差被大离群点放大）。

📐 推导过程

**符号定义**：数据集 $\{(\mathbf{x}_i, y_i)\}_{i=1}^N$；第 $m$ 轮前的累积模型 $F_{m-1}(\mathbf{x})$。

**Step 1 加法模型逐轮贪心**
第 $m$ 轮要在函数空间最小化整体损失：
$$f_m^* = \arg\min_{f} \sum_{i=1}^N L\big(y_i,\, F_{m-1}(\mathbf{x}_i) + f(\mathbf{x}_i)\big)$$
直接对这个泛函优化不可行，改用**函数空间中的梯度下降**：把 $F_{m-1}(\mathbf{x}_i)$ 视为一个'参数'，沿其负梯度方向更新。

**Step 2 一阶泰勒展开**
固定 $f$ 很小，将 $L$ 对 $F_{m-1}(\mathbf{x}_i)$ 一阶展开：
$$L\big(y_i, F_{m-1}(\mathbf{x}_i)+f\big) \approx L(y_i, F_{m-1}(\mathbf{x}_i)) + \frac{\partial L}{\partial F}\Big|_{F_{m-1}(\mathbf{x}_i)} \cdot f(\mathbf{x}_i)$$
要使损失下降最快，$f(\mathbf{x}_i)$ 应取负梯度方向，于是定义**伪残差**：
$$r_{im} = -\left.\frac{\partial L(y_i, F(\mathbf{x}_i))}{\partial F(\mathbf{x}_i)}\right|_{F = F_{m-1}}$$

**Step 3 平方损失下伪残差退化为残差**
令 $L(y, F) = \frac{1}{2}(y - F)^2$，则：
$$\frac{\partial L}{\partial F} = -(y - F) \;\Longrightarrow\; r_{im} = y_i - F_{m-1}(\mathbf{x}_i)$$
即：平方损失时，**负梯度就是当前预测的残差**。因此 GBDT 的每棵树都用回归树去拟合 $(\mathbf{x}_i, r_{im})$。

**Step 4 叶子取值重算**
第 $m$ 棵树把特征空间划分为叶区域 $\{R_{mj}\}_{j=1}^{J}$，每个叶子的输出并非直接取 $r$，而是重新优化：
$$c_{mj} = \arg\min_{c} \sum_{\mathbf{x}_i \in R_{mj}} L\big(y_i, F_{m-1}(\mathbf{x}_i) + c\big)$$
平方损失下该最小值即叶内残差均值 $c_{mj} = \operatorname{mean}_{i\in R_{mj}} r_{im}$；对一般损失（如对数损失）无闭式解时，用一步 Newton 近似求 $c_{mj}$。

**Step 5 带收缩率更新**
$$F_m(\mathbf{x}) = F_{m-1}(\mathbf{x}) + \nu \cdot f_m(\mathbf{x}), \qquad 0 < \nu \le 1$$
学习率 $\nu$（shrinkage）抑制过拟合，配合更多棵树使用。

**关键结论**
$$f_m \approx \text{回归树拟合}\;\{(\mathbf{x}_i, r_{im})\}, \quad r_{im} = -\left[\frac{\partial L(y_i, F)}{\partial F}\right]_{F_{m-1}}$$
对平方损失：$r_{im} = y_i - F_{m-1}(\mathbf{x}_i)$。

**直觉解释**：每一棵新树都在"指方向"——沿着损失函数在函数空间的最陡下降方向补一步，就像梯度下降更新参数一样；只是这里的'参数'是整个函数 $F$。平方损失时最陡方向恰好就是没拟合好的残差，所以教材里常说'GBDT 拟合残差'，严格说是**拟合负梯度，平方损失下负梯度恰为残差**。

🧠 直觉解释

GBDT 的每棵树不是随便拟合残差，而是做函数空间中的梯度下降：平方损失下负梯度恰等于残差，所以'拟合残差'只是'拟合负梯度'的一个特例；损失换成绝对值/对数损失时，伪残差会变为符号函数/概率差等形式，这才是 Boosting 叫'Gradient'的原因。
AI面试问答 ⭐⭐ 第 4 题

为什么深层网络普遍用 ReLU 而非 sigmoid/tanh？ReLU 有什么缺点？

面试高频：解释 ReLU、sigmoid、tanh 三者的梯度行为与各自缺陷，并说明 ReLU 在深层网络中的优势及其'死亡神经元'问题。
--- 以下为答案与解析 ---

📌 回答要点

  • 激活函数与其导数：$\sigma(z)=\frac{1}{1+e^{-z}}$，$\sigma'(z)=\sigma(z)(1-\sigma(z)) \le \frac{1}{4}$，在 $|z|$ 较大时 $\sigma' \to 0$ 进入饱和区；$\tanh$ 导数 $1-\tanh^2(z) \in (0,1]$，同样在 $|z|\to\infty$ 时饱和为 0。
  • 梯度消失：反向传播时激活导数是逐层连乘的因子，sigmoid 导数最大只有 1/4，深层网络连乘后梯度指数级缩小，浅层几乎无法学习；ReLU 正区间导数为 1，连乘不再衰减，梯度可以'直通'到很深的层。
  • ReLU 优点：正区导数恒 1（无饱和、收敛快）；计算极便宜（一次比较 max(0,x)，前向/反向均 O(1)）；负区输出恒 0 带来稀疏激活；配合 He 初始化（方差 2/n）训练深网络是 2012 后工业界标准选择。
  • ReLU 的缺点与'死亡 ReLU'：负半轴梯度恒为 0，一旦某个神经元在所有样本上的输入都落在负区（初始化不当、学习率过大、大量负偏置），其权重梯度永远为 0，神经元永久死亡（输出恒 0，参数不再更新），死亡比例过高会降低模型容量。
  • 改进方案：Leaky ReLU（负区斜率 α，如 0.01）、PReLU（α 可学习）、ELU（负区指数平滑，导数在 0 处连续）、GELU（Transformer 的标准选择，$x\Phi(x)$ 光滑近似 ReLU 并具随机正则特性）。

⭐ 加分项

  • 零中心问题：sigmoid/ReLU 输出均非零中心，后层输入全为正会导致权重梯度方向一致（zigzag 收敛），tanh 与 Leaky ReLU 负区缓解此问题；BatchNorm 可系统性解决。
  • 初始化搭配：sigmoid/tanh → Xavier/Glorot（方差 1/n 或 2/(n_in+n_out)），ReLU 系 → He（方差 2/n），防止前向激活方差爆炸/消失。
  • 工程诊断：训练中统计某层激活为 0 的神经元占比，若 >10%~20% 可考虑降低学习率、换 Leaky ReLU 或检查 BN 位置。

🔮 追问预测

  • 追问：sigmoid 导数为什么最大只有 1/4？——由 $\sigma'(z)=\sigma(1-\sigma)$，令 $t=\sigma\in(0,1)$，$t(1-t)\le 1/4$（二次函数顶点），且 $|z|\to\infty$ 时趋于 0。
  • 追问：GELU 比 ReLU 好在哪里？——$\text{GELU}(x)=x\Phi(x)$ 在负区保留小负梯度（不硬截断），且在零点光滑可导，训练更稳；Transformer FFN 默认用 GELU。
  • 追问：死亡 ReLU 与初始化/学习率的关系？——若权重初始化过大或学习率过大，ReLU 输入长期为负、神经元失去梯度后无法自行恢复，需要人工调整超参或更换激活函数。
