算法编程 ⭐⭐ 第 1 题

分割数组的最大值（二分答案 + 贪心）

给定非负整数数组 nums 和整数 m，把数组按原顺序切成 m 个非空连续子数组，使这 m 段各自元素之和的最大值尽可能小，返回这个最小的最大段和。

直接枚举切点是组合爆炸，朴素 DP 也要 $O(n^2m)$。本题的钥匙是答案的单调性：「最大段和不超过 $L$ 能否切成不超过 $m$ 段」关于 $L$ 单调。请用二分答案 + 贪心校验做到 $O(n\log \sum nums)$。

⚠️ 三个易错点：① nums 含 0；② m = n 时答案应等于 max(nums)；③ 上界是总和而非 max(nums) * m，下界是 max(nums) 而非 0。
输入
整数数组 nums 与正整数 m
输出
一个整数，表示 m 段连续子数组最大和的最小可能值
示例 1
输入：nums = [7,2,5,10,8], m = 2
输出：18
最优切法 [7,2,5] | [10,8]，两段和分别为 14 与 18，最大值为 18；切成 [7,2,5,10] | [8] 会得到 24，更大。
示例 2
输入：nums = [1,4,4], m = 3
输出：4
必须切成 3 段，只能 [1] | [4] | [4]，最大值是 4，恰好等于 max(nums)。
示例 3
输入：nums = [1,2,3,4,5], m = 2
输出：9
最优为 [1,2,3] | [4,5]，两段和为 6 与 9，最大 9。
约束
1 ≤ n ≤ 10^5；0 ≤ nums[i] ≤ 10^6；1 ≤ m ≤ n；答案最大约 10^11（Python 无溢出压力，C++ 需用 long long）。测试含 n=1、全 0、m=n、m=1、大量相同值、含大数的中等规模与递增序列。

💡 解题思路

一、把「最优化」转成「判定」
定义判定函数 $f(L)$：能否把数组切成不超过 $m$ 段，使每段和都 $\le L$。
若 $f(L)$ 为真，则任何 $L' > L$ 也为真（限制更松）；若为假，则更小的 $L$ 也为假。→ $f$ 关于 $L$ 单调，于是可以二分找最小的可行 $L$。

二、判定 $f(L)$ 用贪心（为什么贪心得到的是最少段数）
从左到右累加，能装就装，一旦 cur + x > L 就切一刀另起一段。因为所有元素非负，「本段尽量长」不会让后面更难切——每多装一个元素，只会让后续可用容量更少而非更多，所以这种做法得到的段数就是最少段数 $g(L)$。
$f(L) = [g(L) \le m]$：段数少于 $m$ 时，随便把某段再切开就能凑够 $m$ 段（元素非负，切开只会让最大值不增）。
⚠️ 若元素允许为负，贪心不再给出最少段数，本方法失效。

三、二分边界
下界 $lo = \max(nums)$：最大元素必须落在某一段里，所以答案不可能更小；
上界 $hi = \sum nums$：全部装进一段一定可行。
在 $[lo, hi]$ 上找最小的可行值，复杂度 $O(n \log(\sum nums - \max nums))$。

四、和 DP 的对比
DP 状态 $dp[k][i]$ 表示前 $i$ 个元素切 $k$ 段的最小最大和，转移 $O(n)$，总 $O(mn^2)$；本题 $n$ 可达 $10^5$ 且 $m$ 可达 $n$，DP 不可行。二分答案把 $m$ 维消掉，只留一个标量判定。

📝 参考代码（python）

def split_array(nums, m):
    """二分答案 + 贪心校验：最小化 m 段连续子数组的最大和"""

    def groups_needed(limit):
        """在每段和不超过 limit 的前提下，最少需要切几段（贪心）"""
        cnt, cur = 1, 0
        for x in nums:
            if cur + x > limit:   # 这一段装不下了，必须另起一段
                cnt += 1
                cur = x
            else:
                cur += x          # 能装就继续装，段数最少
        return cnt

    # 答案的下界：至少能装下最大的单个元素；上界：全部装进一段
    lo, hi = max(nums), sum(nums)
    while lo < hi:                # 二分「可行性」的边界
        mid = (lo + hi) // 2
        if groups_needed(mid) <= m:
            hi = mid              # mid 可行，尝试更小
        else:
            lo = mid + 1          # mid 不可行，答案在右半区
    return lo


if __name__ == "__main__":
    print(split_array([7, 2, 5, 10, 8], 2))   # 18

⚡ 复杂度分析

时间 O(n log(sum(nums) - max(nums))) 空间 O(1)

🎯 考点

① 「最小化最大值 / 最大化最小值」是二分答案的典型信号；② 判定函数必须单调，这是二分的前提；③ 贪心正确性依赖元素非负；④ 边界取 max(nums) 与 sum(nums)，写错会 WA 或死循环；⑤ 循环用 lo < hi 配合 hi = mid，避免 +1/-1 混用导致死循环。

布隆过滤器：为什么没有假阴性、为什么不能删

标准布隆过滤器（Bloom Filter）用 $m$ 位的位数组和 $k$ 个相互独立的哈希函数表示 $n$ 个元素集合，插入时把 $k$ 个哈希位置置 1，查询时检查这 $k$ 位是否全为 1。

💡 解题思路

先明确两个方向的误差：假阳性（不存在却报「可能存在」）允许存在；假阴性（存在却报「不存在」）必须为零。再用「位只置 1、从不清零」这一不变量判断 B、C，用假阳性率公式判断 D。

🎯 考点

假阳性率推导：某一位未被任一哈希命中的概率 $(1-1/m)^{kn}\approx e^{-kn/m}$，被置 1 的概率 $1-e^{-kn/m}$，k 位全 1 的概率即 $p=(1-e^{-kn/m})^k$。记忆口诀：只增不减 → 无假阴性；共享位 → 不能删；k 有最优值。工程延伸：计数布隆过滤器、Cuckoo Filter（支持删除且查询更快）、布谷鸟过滤器的负载因子上限。

🔍 逐项分析

  • ❌ A 错误：返回「可能存在」只说明 k 个位全为 1，但这些位可能是其他元素插入时共同置 1 的，因此可能是假阳性，无法保证真的插入过。这正是布隆过滤器用空间换准确率的代价。
  • ❌ B 错误：插入过的元素，其 k 个位在插入时已全部置 1，而标准布隆过滤器没有任何清零操作，位只会从 0 变 1，所以查询时这 k 位必然全为 1，不会返回「一定不存在」。标准布隆过滤器没有假阴性，只有假阳性。
  • ✅ C 正确：多个元素可能共享同一位。若删除某元素时把它的 k 位清 0，会破坏其他元素「全 1」的判定条件，使它们被误判为不存在，产生本不该有的假阴性。要支持删除需改用计数布隆过滤器（每位换成小计数器，插入 +1、删除 −1）或 Cuckoo Filter。
  • ❌ D 错误：假阳性率 $p(k)=\left(1-e^{-kn/m}\right)^k$，对 k 先降后升：k 太小判别信息不足，k 太大位数组过快饱和（1 的比例趋近 1）。最优值由 $\frac{d}{dk}\ln p=0$ 得 $k^\*=\frac{m}{n}\ln 2\approx 0.693\,m/n$，此时 $p\approx 0.6185^{m/n}$。取 k 远超该值只会更差。
AI公式推导 ⭐⭐⭐ 第 3 题

卷积层反向传播：为什么对输入是「翻转核的全卷积」

先看单通道、无 padding、步长 1 的简化情形。深度学习框架里的「卷积」实际执行的是互相关：
$$Y[i,j]=\sum_{u=0}^{K-1}\sum_{v=0}^{K-1} W[u,v]\,X[i+u,\,j+v]+b,\qquad 0\le i<H_{out},\;0\le j<W_{out}$$
其中 $X\in\mathbb{R}^{H\times W}$，$W\in\mathbb{R}^{K\times K}$，$H_{out}=H-K+1$，$W_{out}=W-K+1$。设损失为 $L$，记输出梯度 $G=\partial L/\partial Y$。

请推导：
(1) $\partial L/\partial b$ 与 $\partial L/\partial W[u,v]$，并说明它在计算上是什么运算；
(2) $\partial L/\partial X[p,q]$，写成对 $G$ 的求和式，并说明它与「翻转核的全卷积 / 转置卷积」的关系；
(3) 解释为什么对 $W$ 的梯度是互相关、对 $X$ 的梯度却要翻转核，两者维度为什么恰好互补；
(4) 推广到多通道 $C_{in}\to C_{out}$，写出 $\partial L/\partial W[o,c,u,v]$；并说明 stride $s>1$、padding $P$ 时索引如何修正；
(5) 给出参数量与前向乘加次数（MACs）公式。
--- 以下为答案与解析 ---

🎯 考点

① 卷积层的反向传播 = 转置卷积，不是卷积的逆；② 对权重是互相关，对输入是翻转核的全卷积；③ stride>1 等价于对输出梯度插零膨胀；padding 由 conv_transpose 的 padding 参数裁剪；④ 参数量与输入尺寸无关，计算量与 $H_{out}W_{out}$ 成正比；⑤ 现代框架用 im2col + GEMM（或 Winograd）实现，所以「卷积」在 GPU 上其实是矩阵乘。

📐 推导过程

### Step 0 · 符号与视角
$Y[i,j]$ 只依赖 $X$ 的一个 $K\times K$ 窗口与整个核 $W$；$b$ 对每个输出位置都加一次。推导只需两件事：谁依赖谁（偏导的非零项）与链式法则（把输出梯度按权重撒回）。

### Step 1 · 对偏置与卷积核的梯度（第 1 问）
因为 $\partial Y[i,j]/\partial b=1$：
$$\frac{\partial L}{\partial b}=\sum_{i,j}\frac{\partial L}{\partial Y[i,j]}\frac{\partial Y[i,j]}{\partial b}=\sum_{i,j}G[i,j]$$
即把 $G$ 的所有元素求和（一个标量）。

$W[u,v]$ 出现在每一个输出位置的求和里，权重是 $X[i+u,j+v]$：
$$\frac{\partial L}{\partial W[u,v]}=\sum_{i=0}^{H_{out}-1}\sum_{j=0}^{W_{out}-1}G[i,j]\,\frac{\partial Y[i,j]}{\partial W[u,v]}=\sum_{i,j}G[i,j]\,X[i+u,j+v]$$
把 $G$ 当作「核」在 $X$ 上滑动、逐位置做加权求和——这正是互相关（与框架的 conv 语义一致，不翻转）。注意输出尺寸为 $(H-H_{out}+1)\times(W-W_{out}+1)=K\times K$，恰好与 $W$ 同形，维度自洽。

### Step 2 · 对输入的梯度（第 2 问）
换个视角：固定输入位置 $(p,q)$，它被哪些输出位置用到？由 $p=i+u,\;q=j+v$ 得 $i=p-u,\;j=q-v$，且需 $0\le i<H_{out},\;0\le j<W_{out}$。于是
$$\frac{\partial L}{\partial X[p,q]}=\sum_{u=0}^{K-1}\sum_{v=0}^{K-1}G[\,p-u,\;q-v\,]\,W[u,v]\quad(\text{仅对满足 }0\le p-u<H_{out},\,0\le q-v<W_{out}\text{ 的项求和})$$
令翻转核 $\tilde W[u,v]=W[K-1-u,\,K-1-v]$，再作变量替换 $u'=K-1-u$，可得
$$\frac{\partial L}{\partial X}=\operatorname{full\_conv}(G,\,\tilde W)$$
即：先用 0 在 $G$ 四周各补 $K-1$ 圈，再与 180° 翻转后的核做互相关。输出尺寸 $H_{out}+K-1=H$，与 $X$ 同形。
这与 conv_transpose2d(G, W, stride=1, padding=K-1) 完全等价（转置卷积的「翻转 + 全卷积」定义）。

### Step 3 · 为什么一个互相关、一个翻转（第 3 问）
前向写成线性映射：$\mathrm{vec}(Y)=\mathcal{A}\,\mathrm{vec}(X)$，$\mathcal{A}$ 是稀疏的「滑动窗口」矩阵（每行有 $K^2$ 个 $W$ 元素）。反向传播的通式是
$$\nabla_X L=\mathcal{A}^{\top}\nabla_Y L,\qquad \nabla_W L=\left(\frac{\partial Y}{\partial W}\right)^{\top}\nabla_Y L$$
对 $W$ 求导时 $X$ 充当系数矩阵，转置后仍是「$G$ 在 $X$ 上滑动」，所以形式是互相关、尺寸为 $K\times K$；对 $X$ 求导需要对 $\mathcal{A}$ 取转置，转置把「输入位置 → 输出位置」的散射关系反过来，空间上表现为核翻转 + 全卷积，尺寸回到 $H\times W$。
一句话：前向是「核扫输入」，反向对核就是「输出梯度扫输入」，反向对输入就是「把梯度按核权重散射回去（转置）」。
⚠️ 常见误解：转置卷积不是卷积的逆运算（$\mathcal{A}^{\top}\neq\mathcal{A}^{-1}$），它只是梯度回传的线性算子；所以它会把 $K\times K$ 的梯度「摊开」并产生重叠相加（overlap-add）。

### Step 4 · 多通道与 stride / padding（第 4 问）
多通道前向：$Y[o,i,j]=\sum_{c=0}^{C_{in}-1}\sum_{u,v}W[o,c,u,v]\,X[c,i+u,j+v]+b[o]$，于是
$$\frac{\partial L}{\partial W[o,c,u,v]}=\sum_{i,j}G[o,i,j]\,X[c,i+u,j+v],\qquad \frac{\partial L}{\partial b[o]}=\sum_{i,j}G[o,i,j]$$
对每个 $o$，这是把 $G[o]$ 与所有输入通道做互相关，得到 $C_{in}\times K\times K$，再在 $o$ 上堆叠；工程实现常写成 conv2d(input=X, weight=G) 后转置通道维（group=1 时相当于一次矩阵乘）。
对输入：
$$\frac{\partial L}{\partial X[c,p,q]}=\sum_{o}\sum_{u,v}G[o,\,p-u,\,q-v\,]\,W[o,c,u,v]$$
即把 $G$ 与翻转后的 $W$ 做全卷积，并在 $o$ 维上求和。

stride $s>1$：前向 $Y[i,j]=\sum W[u,v]X[i\,s+u,\,j\,s+v]$。
- 对 $W$：$\partial L/\partial W[u,v]=\sum_{i,j}G[i,j]X[is+u,js+v]$（采样步长为 $s$ 的互相关）；
- 对 $X$：$\partial L/\partial X[p,q]=\sum G[i,j]W[p-is,\,q-js]$，需 $0\le p-is\le K-1$。
实现上等价于：先在 $G$ 的元素之间插入 $s-1$ 行/列的 0（膨胀），再与翻转核做全卷积，最后裁掉多余边界。
padding $P$：前向索引变为 $X[is+u-P,\,js+v-P]$，只需把越界的 $X$ 项丢弃。反向时，padding 区域对应的 $\partial L/\partial X$ 只收到部分项（边界元素参与的窗口更少），由 conv_transpose(..., padding=P) 自动裁掉。

### Step 5 · 参数量与计算量（第 5 问）
$$\#\text{params}=C_{out}\left(C_{in}K^2+1\right)\quad(\text{含 bias})$$
输出空间尺寸 $H_{out}=\left\lfloor\frac{H+2P-K}{s}\right\rfloor+1$，同理 $W_{out}$。每个输出元素要做 $C_{in}K^2$ 次乘加，故
$$\text{MACs}=C_{out}\,H_{out}\,W_{out}\,C_{in}\,K^2,\qquad \text{FLOPs}\approx 2\times\text{MACs}$$
（有的文献把一次乘加算 1 FLOP，务必说明口径。）特例：$1\times1$ 卷积 MACs $=C_{out}C_{in}HW$，本质是逐像素的通道线性变换；depthwise 卷积 $C_{out}=C_{in}$ 且每组只连一个通道，MACs $=C_{in}H_{out}W_{out}K^2$，是 MobileNet 省算力的核心。

🧠 直觉解释

前向是「核在输入上滑动、把窗口压成一个数」；反向对核，就是把输出梯度当作新的核在输入上滑动，统计每个核权重「贡献了多少」；反向对输入，则是把每个输出位置的梯度按原权重散射回它曾覆盖过的输入位置——重叠处相加，所以需要翻转核并补零成全卷积。
AI面试问答 ⭐⭐⭐ 第 4 题

ALiBi 与 RoPE：都能表达相对位置，为什么主流大模型选 RoPE？

面试官提问：ALiBi 和 RoPE 都能让注意力感知相对位置，但 2023 年以后的开源大模型（LLaMA、Qwen、Mistral 等）几乎清一色用 RoPE。请说明两者的机制差异、各自优缺点；如果业务要求「只用 4K 长度训练、推理时要稳定支持 32K」，你会怎么选型、怎么调参、怎么验证？
--- 以下为答案与解析 ---

📌 回答要点

  • 机制差异：ALiBi 不改 q/k，直接在注意力 logits 上加线性惩罚 $\text{logit}_{ij}=q_i^\top k_j/\sqrt{d}-m_h\,(i-j)$，斜率 $m_h=2^{-8h/H}$ 按头号取几何序列，无任何可学习参数；RoPE 则按位置对 q/k 做旋转，$q_m^\top k_n$ 只依赖 $m-n$，频率 $\theta_i=\text{base}^{-2i/d}$ 决定各维的旋转速度。
  • ALiBi 优点：零参数、实现简单、不增加显存；线性距离惩罚天然带来「越远越弱」的先验，短训长推的零样本外推表现好（BLOOM 系列验证过）。缺点：惩罚形式被写死为线性，每个头的斜率固定，表达能力弱于可学习的相对位置；训练长度内通常不如 RoPE 精细；换头数/维度要重新设计斜率。
  • RoPE 优点：在训练分布内拟合能力更强（相对位置以乘性相位进入注意力），与 KV Cache 天然兼容（缓存旋转后的 k），且有一整套成熟的长上下文扩展方案：位置插值 PI、NTK-aware 放大 base、YaRN 分段插值 + 温度缩放。缺点：原始 RoPE 直接外推会崩——超出训练长度的相位组合从未见过，注意力熵和 logits 幅值失控。
  • 选型：若训练与推理长度一致，选 RoPE（生态、算子、KV Cache、微调工具链都最成熟）；若必须「短训长推」且不想改结构，ALiBi 是低成本选项，但更主流的做法是 RoPE + 轻量继续预训练（PI/NTK/YaRN），长文效果和可控性更好。
  • 落地步骤：先按目标长度扩 base（如 1e4 → 5e5 或用 NTK 动态公式），再用少量长文本做继续预训练/长文 SFT；用 needle-in-a-haystack、长文 PPL、以及分位置桶的检索准确率验证，同时监控 attention 熵与远程注意力占比，避免「能读但不会用」。

⭐ 加分项

  • ALiBi 可视为 T5 相对位置 bias 的「免学习极简版」：T5 用可学习的分桶 bias，ALiBi 用固定线性斜率，参数从 O(头数×桶数) 降到 0。
  • RoPE 的远程衰减来自多频率叠加：低频维提供全局粗定位，高频维提供局部精定位；NTK 理论据此把 base 放大理解为「低频拉伸、高频保留」，比 PI 的均匀压缩更保局部分辨率。
  • 推理侧还要配套：FlashAttention / PagedAttention 的显存、attention sink（首个 token 常吸收大量注意力）、滑动窗口与全局 token 混用；位置外推只是长上下文能力的一环，数据配比与训练课程同样关键。
  • KV Cache 兼容性：ALiBi 只需缓存原始 k，评分时再加 bias；RoPE 缓存旋转后的 k（或缓存原始 k 并在使用时旋转），两者都能增量解码，但 RoPE 扩展方案（YaRN）需要同步调整旋转角。

🔮 追问预测

  • 追问「RoPE 为什么不能直接外推？」→ 训练时只见过 $|m-n|\le L_{train}$ 的相位差，超长位置对应未见过的相位组合，$q^\top k$ 的幅值与分布漂移，softmax 变得极尖锐或极平坦；解决思路是压缩位置（PI）、放大 base（NTK）或分段插值（YaRN）。
  • 追问「PI 和 NTK-aware 的区别？」→ PI 把所有位置线性缩放 $m'=m\cdot L_{train}/L_{target}$，相当于整体降低分辨率，需少量微调恢复；NTK-aware 不改位置而是放大 base，使低频维周期变长、高频维基本不变，训练-free 外推更好。
  • 追问「ALiBi 的斜率为什么取几何序列？」→ 不同头负责不同尺度：小斜率头关注长程、大斜率头关注局部，几何分布让 $H$ 个头在 log 尺度上均匀覆盖距离范围；这是人工先验，不如 RoPE 的频率分解灵活。
  • 追问「长上下文评估怎么做才可信？」→ 除 PPL 外要做位置分桶的检索/多跳问答（needle、RULER 类基准），并检查「中间遗失」（lost in the middle）；同时固定解码参数、区分「能检索」与「能推理」。
