N 皇后 II（回溯法）

n 皇后问题研究的是如何将 $n$ 个皇后放置在 $n \times n$ 的棋盘上，并且使皇后彼此之间不能相互攻击（即任意两个皇后不能处于同一行、同一列或同一对角线）。

给定整数 $n$，返回 n 皇后问题的**不同解法数量**。
输入
一个整数 $n$，表示棋盘大小为 $n \times n$。
输出
一个整数，表示 n 皇后问题的解法总数。
示例 1
输入：n = 4
输出：2
4 皇后问题共有 2 种不同的解法。
示例 2
输入：n = 1
输出：1
1×1 棋盘只有一种放法。
示例 3
输入：n = 8
输出：92
经典的 8 皇后问题共有 92 种解法。
约束
- $1 \le n \le 12$ - 函数签名：`def solve(n: int) -> int`

--- 以下为答案与解析 ---

💡 解题思路

使用**回溯法**逐行放置皇后。对于每一行，尝试将该行的皇后放在每个可能的列上，检查是否与已放置的皇后冲突（同列、同主对角线、同副对角线）。用三个集合分别记录已占用的列、主对角线（row - col）、副对角线（row + col）。若当前位置不冲突则放置并递归到下一行；递归返回后撤销放置（回溯）。当所有 n 行都放置完毕时，计数器加 1。

📝 参考代码（python）

def solve(n: int) -> int:
    if n <= 0:
        return 0
    
    count = 0
    cols = set()    # 已占用的列
    diag1 = set()  # 已占用的主对角线 (row - col)
    diag2 = set()  # 已占用的副对角线 (row + col)
    
    def backtrack(row):
        nonlocal count
        if row == n:
            count += 1
            return
        for col in range(n):
            d1 = row - col
            d2 = row + col
            if col in cols or d1 in diag1 or d2 in diag2:
                continue
            # 放置皇后
            cols.add(col)
            diag1.add(d1)
            diag2.add(d2)
            backtrack(row + 1)
            # 回溯：撤销放置
            cols.remove(col)
            diag1.remove(d1)
            diag2.remove(d2)
    
    backtrack(0)
    return count

⚡ 复杂度分析

时间 O(n!)，第一行有 n 种选择，第二行最多 n-1 种，依此类推 空间 O(n)，递归深度为 n，三个集合各最多存储 n 个元素

🎯 考点

回溯法经典应用；用集合 O(1) 判断列和对角线冲突；主对角线 row-col 相同、副对角线 row+col 相同；回溯时需撤销选择（对称地 remove）
算法概念 ⭐⭐ 第 2 题

贪心算法的性质与适用条件

关于贪心算法（Greedy Algorithm），以下说法**正确**的是？

**选项**：
- A. 贪心算法一定能得到全局最优解，因为它每步都取当前最优
- B. 贪心算法的时间复杂度一定比动态规划低
- C. 贪心算法适用的前提是问题具有贪心选择性质和最优子结构，且贪心选择不会影响子问题的最优解
- D. 贪心算法和动态规划都可以解决所有优化问题，区别仅在于实现方式不同
--- 以下为答案与解析 ---
✅ 正确答案：C

💡 解题思路

逐一分析贪心算法的核心性质和适用条件。

🎯 考点

贪心算法的两个前提：贪心选择性质（局部最优选择不破坏全局最优）和最优子结构（最优解包含子问题最优解）。贪心 vs DP 的核心区别：贪心做出不可撤回的选择，DP 穷举所有子问题取最优。经典贪心问题：活动选择、Huffman 编码、Dijkstra 最短路、Kruskal/Prim 最小生成树。经典反例：01 背包不能用贪心。

🔍 逐项分析

  • **A 错误**：贪心算法每步取局部最优，但**不保证**全局最优。经典反例：01 背包问题中若按价值密度贪心选择，可能无法得到最优解（例如物品 A 价值 6 重量 2、物品 B 价值 10 重量 5、背包容量 5，贪心选 A+A=12，但选 B=10 更优？不，这里贪心选 A+B=16... 更好的反例：A 价值 3 重量 1、B 价值 4 重量 2、C 价值 5 重量 3，容量 3，贪心按密度选 A+A=6 但 B+C=9 更优）。只有当问题具有**贪心选择性质**时才能保证全局最优。
  • **B 错误**：贪心算法通常比动态规划快（因为不做全面搜索），但不是**一定**更快。某些问题的贪心解法可能需要排序预处理 $O(n \log n)$，而该问题的 DP 解法也可能是 $O(n \log n)$。复杂度取决于具体问题和实现方式，不能一概而论。
  • **C 正确**：这是贪心算法适用的两个核心前提：①**贪心选择性质**——可以做出局部最优选择而不影响全局最优解（即当前的选择不会限制后续选择导致整体非最优）；②**最优子结构**——问题的最优解包含子问题的最优解。两者缺一不可，这是贪心算法正确性的理论基础。
  • **D 错误**：贪心和动态规划**并非可以解决所有优化问题**。有些问题两者都无法高效解决（如某些 NP-hard 问题）。且两者有本质区别：贪心是自顶向下的单次选择（不回退），DP 是自底向上（或带记忆化的自顶向下）的穷举所有子问题最优解。贪心不能解决需要考虑所有子问题组合的问题（如 01 背包），DP 也不能高效解决状态空间爆炸的问题。
AI公式推导 ⭐⭐⭐ 第 3 题

RNN 沿时间反向传播（BPTT）梯度推导与梯度消失分析

给定一个简单的循环神经网络（RNN），其前向传播为：

$$h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)$$

$$y_t = W_{hy} h_t + b_y$$

损失函数为 $L = \sum_{t=1}^{T} L_t$，其中 $L_t$ 为时刻 $t$ 的损失。

请推导：
1. 损失 $L$ 对隐藏状态 $h_t$ 的梯度 $\frac{\partial L}{\partial h_t}$ 的完整表达式
2. 损失 $L$ 对权重 $W_{hh}$ 的梯度 $\frac{\partial L}{\partial W_{hh}}$
3. 分析为什么 RNN 在长序列上会出现**梯度消失**问题
--- 以下为答案与解析 ---

🎯 考点

BPTT 本质是沿时间维度展开的链式法则；梯度通过 $\text{diag}(1-h^2) \cdot W_{hh}$ 连乘传播；tanh 导数 $\leq 1$ 导致梯度消失；LSTM 用加法路径和门控机制缓解梯度消失；梯度裁剪（gradient clipping）可缓解梯度爆炸但无法解决消失问题。

📐 推导过程

**符号定义**：
- $W_{hh} \in \mathbb{R}^{d_h \times d_h}$：隐藏状态权重矩阵
- $W_{xh} \in \mathbb{R}^{d_h \times d_x}$：输入权重矩阵
- $W_{hy} \in \mathbb{R}^{d_y \times d_h}$：输出权重矩阵
- $h_t = \tanh(W_{hh} h_{t-1} + W_{xh} x_t + b_h)$，令 $z_t = W_{hh} h_{t-1} + W_{xh} x_t + b_h$，则 $h_t = \tanh(z_t)$
- $L = \sum_{t=1}^{T} L_t$，其中 $L_t$ 依赖于 $h_t$

---

**Part 1：$\frac{\partial L}{\partial h_t}$ 的完整表达式**

$h_t$ 对后续损失有两条路径的影响：
- **直接路径**：$h_t$ 通过 $y_t$ 影响 $L_t$，贡献 $\frac{\partial L_t}{\partial h_t}$
- **间接路径**：$h_t$ 通过 $h_{t+1}, h_{t+2}, \ldots, h_T$ 影响后续所有损失

因此：
$$\frac{\partial L}{\partial h_t} = \frac{\partial L_t}{\partial h_t} + \frac{\partial L}{\partial h_{t+1}} \cdot \frac{\partial h_{t+1}}{\partial h_t}$$

展开 $\frac{\partial h_{t+1}}{\partial h_t}$（链式法则通过 $z_{t+1}$）：
$$\frac{\partial h_{t+1}}{\partial h_t} = \frac{\partial h_{t+1}}{\partial z_{t+1}} \cdot \frac{\partial z_{t+1}}{\partial h_t} = \text{diag}(1 - h_{t+1}^2) \cdot W_{hh}$$

其中 $\text{diag}(1 - h_{t+1}^2)$ 是 $\tanh'$ 的雅可比矩阵（对角矩阵，因为 $\tanh'(z) = 1 - \tanh^2(z) = 1 - h^2$）。

所以完整表达式为：
$$\boxed{\frac{\partial L}{\partial h_t} = \frac{\partial L_t}{\partial h_t} + \left(\frac{\partial L}{\partial h_{t+1}} \odot (1 - h_{t+1}^2)\right)^T W_{hh}}$$

（$\odot$ 表示逐元素乘法，$1 - h_{t+1}^2$ 是 $\tanh$ 导数在 $h_{t+1}$ 处的值）

---

**Part 2：$\frac{\partial L}{\partial W_{hh}}$ 的梯度**

$W_{hh}$ 出现在每个时刻的 $z_t = W_{hh} h_{t-1} + \cdots$ 中，因此需要沿所有时间步累加：
$$\frac{\partial L}{\partial W_{hh}} = \sum_{t=1}^{T} \frac{\partial L}{\partial h_t} \cdot \frac{\partial h_t}{\partial W_{hh}}$$

对每个时刻 $t$，通过 $z_t$ 应用链式法则：
$$\frac{\partial h_t}{\partial W_{hh}} = \frac{\partial h_t}{\partial z_t} \cdot \frac{\partial z_t}{\partial W_{hh}} = \text{diag}(1 - h_t^2) \cdot h_{t-1}$$

因此：
$$\boxed{\frac{\partial L}{\partial W_{hh}} = \sum_{t=1}^{T} \left(\frac{\partial L}{\partial h_t} \odot (1 - h_t^2)\right) h_{t-1}^T}$$

这是一个外积求和：每个时刻贡献一个 $d_h \times d_h$ 的矩阵。

---

**Part 3：梯度消失分析**

将 Part 1 的递推式展开，考虑从时刻 $T$ 反向传播到时刻 $k$ 的梯度：
$$\frac{\partial L}{\partial h_k} \approx \frac{\partial L_T}{\partial h_T} \cdot \prod_{t=k+1}^{T} \frac{\partial h_t}{\partial h_{t-1}}$$

其中每个雅可比矩阵：
$$\frac{\partial h_t}{\partial h_{t-1}} = \text{diag}(1 - h_t^2) \cdot W_{hh}$$

取范数：
$$\left\|\frac{\partial h_t}{\partial h_{t-1}}\right\| \leq \|\text{diag}(1 - h_t^2)\| \cdot \|W_{hh}\| \leq \gamma \cdot \|W_{hh}\|$$

其中 $\gamma = \max_t |1 - h_t^2|$。由于 $\tanh$ 的导数 $\tanh'(z) = 1 - \tanh^2(z)$，其最大值为 1（在 $z = 0$ 时），但实际中 $|h_t| < 1$ 时 $\tanh'(z) < 1$。

当 $T - k$ 很大时：
$$\left\|\frac{\partial L}{\partial h_k}\right\| \leq \left(\gamma \cdot \|W_{hh}\|\right)^{T-k}$$

**梯度消失**：当 $\gamma \cdot \|W_{hh}\| < 1$ 时（即 $W_{hh}$ 的特征值幅度小于 $1/\gamma$），连乘项指数衰减：
$$(\gamma \cdot \|W_{hh}\|)^{T-k} \to 0 \quad \text{当 } T - k \to \infty$$

这意味着早期时刻（$k$ 较小）的梯度趋近于 0，网络无法学习长距离依赖。

**补充：梯度爆炸**：当 $\gamma \cdot \|W_{hh}\| > 1$ 时，连乘项指数增长，梯度爆炸。

**LSTM 的解决方案**：LSTM 引入门控机制（遗忘门 $f_t$、输入门 $i_t$、输出门 $o_t$）和细胞状态 $C_t$。细胞状态的更新为 $C_t = f_t \odot C_{t-1} + i_t \odot \tilde{C}_t$，梯度沿细胞状态传播时 $\frac{\partial C_t}{\partial C_{t-1}} = f_t$，遗忘门可以学习到接近 1 的值，使梯度可以无衰减地长距离传播，从而缓解梯度消失问题。

🧠 直觉解释

RNN 梯度沿时间反向传播时，每经过一个时间步就要乘以一个雅可比矩阵 $\text{diag}(1-h_t^2) \cdot W_{hh}$，连乘多次后若该矩阵的谱半径小于 1 则梯度指数衰减（消失），大于 1 则指数增长（爆炸）。tanh 的导数最大为 1，且实际中通常小于 1，因此梯度消失是 RNN 的主要问题。LSTM 通过加法（而非乘法）的细胞状态更新路径，使梯度可以长距离传播。
AI面试问答 ⭐⭐ 第 4 题

支持向量机（SVM）的原理、对偶问题与核技巧

面试官问："请详细解释支持向量机（SVM）的基本原理，什么是支持向量？为什么要用对偶问题求解？核技巧的本质是什么？SVM 和逻辑回归有什么区别？"
--- 以下为答案与解析 ---

📌 回答要点

  • **SVM 基本原理**：SVM 寻找一个超平面 $w^T x + b = 0$ 将不同类别分开，目标是使**间隔（margin）最大化**。间隔定义为 $\frac{2}{\|w\|}$，因此最大化间隔等价于最小化 $\frac{1}{2}\|w\|^2$。对于线性可分情况，优化问题为：$\min_{w,b} \frac{1}{2}\|w\|^2$，约束 $y_i(w^T x_i + b) \geq 1$。对于软间隔（允许一定误分类），引入松弛变量 $\xi_i \geq 0$，目标变为 $\min \frac{1}{2}\|w\|^2 + C \sum \xi_i$，$C$ 为惩罚参数控制间隔宽度与误分类的权衡。
  • **支持向量**：距离决策边界最近的样本点（满足 $y_i(w^T x_i + b) = 1$，即在间隔边界上）称为支持向量。**只有支持向量决定超平面**，其他样本点不影响（对应的拉格朗日乘子 $\alpha_i = 0$）。这是 SVM 的核心特性——模型仅由少量关键样本决定，具有稀疏性。删除非支持向量不影响解。
  • **对偶问题的必要性**：原始问题通过拉格朗日乘子法转化为对偶问题 $\max_\alpha \sum \alpha_i - \frac{1}{2}\sum_{i,j} \alpha_i \alpha_j y_i y_j x_i^T x_j$，约束 $\sum \alpha_i y_i = 0$，$0 \le \alpha_i \le C$。引入对偶的三个原因：①**自然引入核函数**——对偶问题中 $x_i$ 仅以内积 $x_i^T x_j$ 形式出现，可替换为 $K(x_i, x_j)$ 实现非线性；②**降低计算复杂度**——原始问题优化 $w$ 维度为 $d$（特征数），对偶问题优化 $\alpha$ 维度为 $n$（样本数），当 $d \gg n$ 时对偶更高效；③**KKT 条件**给出支持向量的判定标准（$\alpha_i > 0$ 对应支持向量）。
  • **核技巧的本质**：核技巧将低维空间的非线性问题映射到高维空间变为线性可分，但**不需要显式计算高维映射 $\phi(x)$**，只需定义核函数 $K(x_i, x_j) = \phi(x_i)^T \phi(x_j)$。常用核函数：线性核 $K = x_i^T x_j$；多项式核 $K = (x_i^T x_j + r)^d$；高斯核（RBF）$K = \exp(-\gamma \|x_i - x_j\|^2)$，$\gamma$ 控制核宽度。Mercer 定理保证了核函数的合法性（半正定）。
  • **SVM vs 逻辑回归**：①**损失函数**——SVM 用 hinge loss $\max(0, 1 - y \cdot f(x))$，逻辑回归用对数损失 $\log(1 + e^{-y f(x)})$；②**决策边界**——SVM 只依赖支持向量（稀疏），逻辑回归依赖所有样本（非稀疏）；③**概率输出**——SVM 不直接输出概率（需 Platt scaling 后处理），逻辑回归天然输出概率；④**核化**——SVM 天然支持核技巧，逻辑回归核化后计算量更大（需所有样本参与）。

⭐ 加分项

  • **SVM 的 VC 维**：间隔越大 VC 维越小，SVM 通过最大化间隔实现了结构风险最小化（SRM），这是其泛化能力的理论基础。即使特征维度很高，只要间隔足够大，泛化能力仍有保证。
  • **SMO 算法**：序列最小优化（Sequential Minimal Optimization）是求解 SVM 对偶问题的高效算法，每次只优化两个拉格朗日乘子（因为等式约束 $\sum \alpha_i y_i = 0$ 要求至少同时优化两个），解析求解子问题，避免通用 QP 求解器的高开销。
  • **多分类 SVM**：SVM 本质是二分类器，多分类常用 one-vs-rest（训练 K 个分类器）或 one-vs-one（训练 $K(K-1)/2$ 个分类器，投票决定）。
  • **SVM 在深度学习时代地位**：在中小样本、高维特征（如文本分类 TF-IDF）场景仍有优势；深度学习在大数据场景下端到端学习更强，但 SVM 作为基线方法仍有价值，尤其在需要明确决策边界和稀疏解的场景。

🔮 追问预测

  • **追问：高斯核中 $\gamma$ 参数如何影响模型？** — 回答思路：$\gamma$ 控制单个样本的影响范围。$\gamma$ 大时核函数衰减快，每个支持向量影响范围小，决策边界复杂（容易过拟合）；$\gamma$ 小时影响范围大，决策边界平滑（可能欠拟合）。通常通过交叉验证选择 $\gamma$ 和 $C$。常用网格搜索（grid search）配合交叉验证确定超参数。
  • **追问：SVM 为什么能处理非线性问题？** — 回答思路：通过核技巧将原始空间非线性可分的数据映射到高维特征空间使其线性可分。例如 XOR 问题在 2D 空间线性不可分，但映射到 3D 空间后可分。核技巧避免了显式高维映射的计算开销，通过内积替换实现。高斯核对应无限维特征空间。
  • **追问：软间隔中 C 的作用是什么？** — 回答思路：C 是正则化参数，控制间隔宽度与误分类惩罚的权衡。C 大时对误分类惩罚重，间隔窄，容易过拟合；C 小时间隔宽，容忍更多误分类，容易欠拟合。等价于正则化强度的倒数。
