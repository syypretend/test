算法编程 ⭐⭐ 第 1 题

前缀计数（Trie 字典树）

给定一个单词列表 words 和一个前缀字符串 prefix，请统计 words 中以 prefix 为前缀的单词数量。

例如 words = ["apple", "app", "application"]，prefix = "app"，则以 "app" 为前缀的单词有 3 个（apple、app、application），返回 3。

请使用 **Trie（字典树/前缀树）** 数据结构实现。
输入
第一行为单词列表 `words`（字符串数组），第二行为前缀字符串 `prefix`。
输出
返回一个整数，表示以 `prefix` 为前缀的单词数量。
示例 1
输入：words = ["apple", "app", "application", "apt", "banana"], prefix = "app"
输出：3
apple、app、application 以 "app" 为前缀，apt 以 "a" 开头但第二字符是 p 不是 p... 实际 apt 的前三个字符是 "apt" ≠ "app"，因此只有 apple、app、application 共 3 个。
示例 2
输入：words = ["cat", "car", "card", "care", "careful"], prefix = "car"
输出：4
car、card、care、careful 均以 "car" 为前缀，共 4 个。
约束
- $1 \le words.length \le 10^5$ - $1 \le words[i].length \le 100$ - $1 \le prefix.length \le 100$ - 所有单词和前缀仅由小写英文字母组成 - 函数签名：`def solve(words, prefix) -> int`

--- 以下为答案与解析 ---

💡 解题思路

构建一棵 Trie 字典树。每个节点维护一个 count 字段，记录经过该节点的单词数量。插入时沿字符路径递增每个节点的 count。查询时沿前缀字符走到对应节点，返回该节点的 count 即可。若前缀路径不存在则返回 0。

📝 参考代码（python）

class TrieNode:
    __slots__ = ['children', 'count', 'is_end']
    def __init__(self):
        self.children = {}
        self.count = 0
        self.is_end = False

def solve(words, prefix):
    root = TrieNode()
    for word in words:
        node = root
        for ch in word:
            if ch not in node.children:
                node.children[ch] = TrieNode()
            node = node.children[ch]
            node.count += 1
        node.is_end = True

    node = root
    for ch in prefix:
        if ch not in node.children:
            return 0
        node = node.children[ch]
    return node.count

⚡ 复杂度分析

时间 O(N * L + M)，N 为单词数，L 为平均单词长度，M 为前缀长度 空间 O(N * L * 26)，最坏情况下 Trie 存储所有字符节点

🎯 考点

Trie 字典树的构建与查询；节点 count 字段记录经过该路径的单词数；前缀匹配只需沿路径走到目标节点取 count
算法概念 ⭐⭐ 第 2 题

排序算法的稳定性与复杂度

关于常见排序算法的性质，以下说法**正确**的是？

**选项**：
- A. 快速排序是稳定排序，最坏时间复杂度为 $O(n \log n)$
- B. 归并排序是稳定排序，最坏时间复杂度为 $O(n \log n)$
- C. 堆排序是稳定排序，最坏时间复杂度为 $O(n^2)$
- D. 冒泡排序是不稳定排序，最坏时间复杂度为 $O(n \log n)$
--- 以下为答案与解析 ---
✅ 正确答案：B

💡 解题思路

逐一判断每个排序算法的稳定性和最坏时间复杂度。

🎯 考点

排序稳定性定义：相等元素排序后相对顺序不变则为稳定。常见稳定排序：归并、冒泡、插入、基数。常见不稳定排序：快排、堆排、选择。掌握各排序算法的最好/最坏/平均复杂度是面试基础。

🔍 逐项分析

  • **A 错误**：快速排序是**不稳定**排序（相等元素的相对顺序可能改变），最坏时间复杂度为 $O(n^2)$（当每次 partition 选到最值作为基准时退化）。选项声称稳定且最坏 $O(n \log n)$，两个判断都错。
  • **B 正确**：归并排序是**稳定**排序（合并时相等元素取左侧优先即可保持稳定），最坏/最好/平均时间复杂度均为 $O(n \log n)$，空间复杂度 $O(n)$。两个判断都正确。
  • **C 错误**：堆排序是**不稳定**排序（调整堆时相等元素的相对顺序可能改变），最坏时间复杂度为 $O(n \log n)$ 而非 $O(n^2)$。两个判断都错。
  • **D 错误**：冒泡排序是**稳定**排序（相邻交换时相等元素不交换则保持顺序），最坏时间复杂度为 $O(n^2)$（逆序数组）。选项两个判断都错。
AI公式推导 ⭐⭐ 第 3 题

线性回归正规方程（Normal Equation）闭式解推导

给定训练数据集 $\{(x^{(i)}, y^{(i)})\}_{i=1}^{n}$，其中 $x^{(i)} \in \mathbb{R}^d$（含偏置项 $x_0 = 1$），$y^{(i)} \in \mathbb{R}$。线性回归模型预测 $\hat{y}^{(i)} = \theta^T x^{(i)}$，损失函数为均方误差（MSE）。

请使用矩阵形式推导：**最小化损失函数 $J(\theta) = \frac{1}{2n}\|X\theta - y\|^2$ 关于 $\theta$ 的正规方程，并求出 $\theta$ 的闭式解。**

其中 $X \in \mathbb{R}^{n \times d}$ 为设计矩阵，$y \in \mathbb{R}^n$ 为目标向量，$\theta \in \mathbb{R}^d$ 为参数向量。
--- 以下为答案与解析 ---

🎯 考点

矩阵二次型求导：$\nabla_\theta (\theta^T A \theta) = 2A\theta$（A 对称）；正规方程 $X^TX\theta = X^Ty$ 的推导与闭式解；$X^TX$ 可逆条件（列满秩）；不可逆时用伪逆或加 L2 正则化（岭回归）。

📐 推导过程

**符号定义**：
- 设计矩阵 $X = [x^{(1)T}; x^{(2)T}; \cdots; x^{(n)T}] \in \mathbb{R}^{n \times d}$，每行是一个样本
- 目标向量 $y = [y^{(1)}, y^{(2)}, \cdots, y^{(n)}]^T \in \mathbb{R}^n$
- 参数向量 $\theta \in \mathbb{R}^d$
- 预测向量 $\hat{y} = X\theta \in \mathbb{R}^n$

**损失函数**（省略 $\frac{1}{2n}$ 常数不影响极值点）：
$$J(\theta) = \frac{1}{2}\|X\theta - y\|^2 = \frac{1}{2}(X\theta - y)^T(X\theta - y)$$

**Step 1：展开二次型**
$$J(\theta) = \frac{1}{2}\left[(X\theta)^T(X\theta) - (X\theta)^T y - y^T(X\theta) + y^T y\right]$$
$$= \frac{1}{2}\left[\theta^T X^T X \theta - 2\theta^T X^T y + y^T y\right]$$

（利用 $(X\theta)^T y = \theta^T X^T y$ 是标量，等于其转置 $y^T X \theta$）

**Step 2：对 $\theta$ 求梯度**

利用两个矩阵微积分恒等式：
- $\nabla_\theta (\theta^T A \theta) = (A + A^T)\theta$，当 $A$ 对称时 $= 2A\theta$
- $\nabla_\theta (b^T \theta) = b$

因为 $X^T X$ 是对称矩阵（$(X^T X)^T = X^T X$），令 $A = X^T X$，$b = X^T y$：
$$\nabla_\theta J(\theta) = \frac{1}{2}\left[2 X^T X \theta - 2 X^T y\right] = X^T X \theta - X^T y$$

**Step 3：令梯度为零，得正规方程**
$$X^T X \theta - X^T y = 0$$
$$\boxed{X^T X \, \theta = X^T y}$$

**Step 4：求解闭式解**

当 $X^T X$ 可逆（即 $X$ 列满秩，$n \geq d$ 且特征间无共线性）时：
$$\boxed{\theta = (X^T X)^{-1} X^T y}$$

**Step 5：可逆性讨论**

当 $X^T X$ 不可逆时（特征数 > 样本数，或特征共线性），使用伪逆（Moore-Penrose 伪逆）：
$$\theta = (X^T X)^{+} X^T y = X^{+} y$$

或在损失函数中加入 L2 正则化项 $\frac{\lambda}{2}\|\theta\|^2$（岭回归），此时：
$$\theta = (X^T X + \lambda I)^{-1} X^T y$$

$\lambda > 0$ 时 $X^T X + \lambda I$ 一定可逆（正定矩阵）。

🧠 直觉解释

正规方程 $X^T X \theta = X^T y$ 的几何含义是：残差向量 $X\theta - y$ 与 $X$ 的列空间正交（即残差不能被特征线性表出进一步减小），这正是投影到列空间的最优解。闭式解 $\theta = (X^T X)^{-1} X^T y$ 就是将 $y$ 投影到 $X$ 列空间后在原始坐标系下的系数。
AI面试问答 ⭐⭐ 第 4 题

Batch Normalization 与 Layer Normalization 的区别与应用场景

面试官问："Batch Normalization 和 Layer Normalization 都是深度学习中常用的归一化方法，请详细说明它们的原理区别、计算方式差异，以及为什么 Transformer 用 LayerNorm 而不用 BatchNorm？"
--- 以下为答案与解析 ---

📌 回答要点

  • **计算维度不同**：BatchNorm 沿 **batch 维度** 归一化，对每个特征通道在 batch 内统计均值和方差（$\mu_B, \sigma_B^2$ 计算时 batch 内所有样本同一通道参与）；LayerNorm 沿 **特征维度** 归一化，对每个样本的所有特征独立统计均值和方差（$\mu, \sigma^2$ 在单个样本的所有特征上计算），与 batch 无关。
  • **公式对比**：
    BatchNorm：$\hat{x}_{ij} = \frac{x_{ij} - \mu_B^{(j)}}{\sqrt{\sigma_B^{(j)2} + \epsilon}}$，其中 $\mu_B^{(j)} = \frac{1}{B}\sum_{i=1}^{B} x_{ij}$
    LayerNorm：$\hat{x}_{ij} = \frac{x_{ij} - \mu_i}{\sqrt{\sigma_i^2 + \epsilon}}$，其中 $\mu_i = \frac{1}{d}\sum_{j=1}^{d} x_{ij}$
  • **训练/推理行为差异**：BatchNorm 训练时用 batch 统计量，推理时用训练阶段累积的滑动平均（running mean/var），存在训练-推理不一致问题；LayerNorm 训练和推理行为一致，无需维护 running 统计量。
  • **为什么 Transformer 用 LayerNorm**：① 序列长度可变，BatchNorm 在变长序列中对不同位置的统计量不一致；② batch size 受限（大模型训练常用梯度累积、微调时 batch=1），BatchNorm 在小 batch 下统计量不可靠；③ Transformer 每个位置独立处理，LayerNorm 对单个样本归一化更自然；④ LayerNorm 不依赖 batch 维度，推理时行为与训练一致。
  • **适用场景**：BatchNorm 适合 CNN（固定尺寸输入、大 batch 训练、特征通道有明确语义）；LayerNorm 适合 RNN/Transformer（变长序列、可变 batch、自回归推理）。

⭐ 加分项

  • **RMSNorm**：LayerNorm 的简化变体，去掉均值减法只做方差归一化（$\hat{x}_i = \frac{x_i}{\sqrt{\frac{1}{d}\sum_j x_j^2 + \epsilon}} \cdot \gamma$），计算量减少约 20-30%，LLaMA 等大模型广泛采用，实验证明效果与 LayerNorm 相当。
  • **DeepNorm**：微软提出，通过修改残差连接初始化实现极深 Transformer（1000+层），归一化因子 $\alpha$ 控制梯度规模。
  • **归一化位置**：Pre-LN（归一化在注意力/前馈之前）比 Post-LN（原始 Transformer 位置）训练更稳定，不需要 warmup，现代大模型普遍使用 Pre-LN。
  • **BatchNorm 的泛化性争议**：有研究表明 BatchNorm 的正则化效果部分来自训练时 batch 统计量的随机性，推理时这种随机性消失可能影响泛化。

🔮 追问预测

  • **追问：BatchNorm 中的 $\gamma$ 和 $\beta$ 的作用是什么？** — 回答思路：缩放和平移可学习参数，通过 $y = \gamma \hat{x} + \beta$ 恢复网络表达能力。若归一化后直接使用，激活值分布被强行限制在固定区间，可能降低模型拟合能力；$\gamma$ 和 $\beta$ 让网络自行决定最优的分布范围，极端情况可还原原始分布（$\gamma = \sigma, \beta = \mu$）。
  • **追问：为什么 BatchNorm 能加速训练？** — 回答思路：① 缓解内部协变量偏移（ICS），使每层输入分布更稳定；② 平滑损失景观，允许更大学习率；③ 有轻微正则化效果（batch 统计量引入噪声）。注意：MIT 2018 论文指出 ICS 可能不是 BN 有效的核心原因，平滑损失景观才是。
  • **追问：LayerNorm 中为什么不用 batch 统计量？** — 回答思路：自回归模型推理时 batch=1，batch 统计量无意义；训练时的序列长度变化导致不同位置统计量不一致；LayerNorm 逐样本归一化，无上述问题。
