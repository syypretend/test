算法编程 ⭐⭐ 第 1 题

和为 K 的子数组

给定一个整数数组 nums 和一个整数 k，请你统计并返回该数组中和为 k 的**连续子数组**的个数。

注意：子数组是数组中元素的连续非空序列。数组中可能包含负数。
输入
第一行：整数 n（数组长度）和整数 k
第二行：n 个整数，用空格分隔
输出
一个整数，表示和为 k 的连续子数组的个数
示例 1
输入：nums = [1, 1, 1], k = 2
输出：2
子数组 [1,1]（下标 0-1）和 [1,1]（下标 1-2）的和均为 2
示例 2
输入：nums = [1, 2, 3], k = 3
输出：2
子数组 [1,2]（和=3）和 [3]（和=3）满足条件
示例 3
输入：nums = [1, -1, 0], k = 0
输出：3
子数组 [1,-1]（和=0）、[0]（和=0）、[1,-1,0]（和=0）均满足
约束
1 ≤ n ≤ 2×10^4 -1000 ≤ nums[i] ≤ 1000 -10^7 ≤ k ≤ 10^7

--- 以下为答案与解析 ---

💡 解题思路

**前缀和 + 哈希表**：

设 prefix[i] 为 nums[0..i-1] 的前缀和，则子数组 nums[i..j] 的和 = prefix[j+1] - prefix[i]。

要使 sum(nums[i..j]) = k，即 prefix[j+1] - prefix[i] = k，也就是 prefix[i] = prefix[j+1] - k。

用哈希表记录每个前缀和出现的次数，遍历时查 prefix - k 出现了几次，就找到几个满足条件的子数组。

**关键细节**：初始时哈希表要放入 {0: 1}，表示前缀和为 0 出现过 1 次（空前缀），这样才能统计从下标 0 开始的子数组。

📝 参考代码（python）

def subarray_sum(nums, k):
    count = 0
    prefix_sum = 0
    prefix_count = {0: 1}  # 前缀和为0出现1次
    
    for num in nums:
        prefix_sum += num
        # 查找是否存在前缀和 = prefix_sum - k
        if prefix_sum - k in prefix_count:
            count += prefix_count[prefix_sum - k]
        # 更新哈希表
        prefix_count[prefix_sum] = prefix_count.get(prefix_sum, 0) + 1
    
    return count

⚡ 复杂度分析

时间 O(n) 空间 O(n)

🎯 考点

前缀和 + 哈希表优化；注意初始化 prefix_count = {0: 1} 的作用；理解 prefix[j] - prefix[i] = k 的转化；数组含负数时不能用滑动窗口（窗口和不一定单调）
算法概念 ⭐ 第 2 题

快慢指针检测链表环

在使用快慢指针（Floyd 判圈法）检测链表是否有环时，快指针每次走 2 步，慢指针每次走 1 步。关于该算法，以下哪个说法是**正确的**？
--- 以下为答案与解析 ---
✅ 正确答案：B

💡 解题思路

Floyd 判圈法核心：快指针每次走 2 步，慢指针每次走 1 步。若无环，快指针先到末尾（None），只需遍历 n/2 次，时间 O(n)；若有环，快慢指针一定会在环内相遇。

🎯 考点

Floyd 判圈法的正确性证明（相对速度差为 1 必然相遇）；找环入口的延伸方法（双指针阶段二）；无环时 O(n) 时间复杂度分析

🔍 逐项分析

  • A 错误：相遇时快指针比慢指针多走的步数不一定恰好是 1 圈。快指针每步比慢指针多走 1 步（相对速度差为 1），因此在环内最多需要走「环长度」步即可追上，但这不意味着快指针总共只多走了 1 圈——它可能在进入环之前就已经比慢指针多走了很多步。相遇时快指针总步数是慢指针的 2 倍，多走量取决于环外长度与环长的关系。说「恰好多走 1 圈」过于绝对。
  • B 正确：无环时，快指针每轮前进 2 步，最多 ⌈n/2⌉ 轮到达末尾，时间复杂度 O(n)，这是标准结论。
  • C 错误：Floyd 判圈法不仅能判断有环，还能找到环入口。方法：快慢指针相遇后，将其中一个指针移回链表头，两指针都改为每次走 1 步，再次相遇点即为环入口。原理是从头到环入口的距离 a 与相遇点到环入口的距离满足 a = r - (a mod r) 的数学关系。
  • D 错误：有环时，快慢指针在环内的相对速度为 1（每轮快指针比慢指针多走 1 步），由于环是有限的，快指针一定会追上慢指针并相遇。说「永远不会相遇」完全错误。
AI公式推导 ⭐⭐ 第 3 题

L2 正则化的权重衰减推导

推导 L2 正则化（Ridge / Weight Decay）在梯度下降中的**权重衰减**效果。

设损失函数为 $L(\mathbf{w})$（不含正则化项），模型参数为 $\mathbf{w} \in \mathbb{R}^d$。加入 L2 正则化后的总目标函数为：
$$J(\mathbf{w}) = L(\mathbf{w}) + \frac{\lambda}{2} \|\mathbf{w}\|^2$$

请推导：
1. $J(\mathbf{w})$ 对 $\mathbf{w}$ 的梯度
2. 使用学习率 $\eta$ 的梯度下降更新规则
3. 将更新规则改写为 $\mathbf{w}_{new} = (1 - \eta\lambda)\mathbf{w}_{old} - \eta \nabla L(\mathbf{w})$ 的形式，说明为何 L2 正则化等价于「权重衰减」
4. 与 L1 正则化的梯度行为对比，说明为何 L2 倾向产生小而均匀的权重、而 L1 倾向产生稀疏权重
--- 以下为答案与解析 ---

🎯 考点

L2 正则化梯度推导；权重衰减等价性 $(1-\eta\lambda)$ 因子；L1 vs L2 稀疏性差异的梯度解释（恒定梯度 vs 比例梯度）与几何解释（菱形 vs 圆约束区域）

📐 推导过程

**Step 1：求 $J(\mathbf{w})$ 的梯度**

$$J(\mathbf{w}) = L(\mathbf{w}) + \frac{\lambda}{2} \|\mathbf{w}\|^2 = L(\mathbf{w}) + \frac{\lambda}{2} \sum_{i=1}^{d} w_i^2$$

对 $w_i$ 求偏导：
$$\frac{\partial J}{\partial w_i} = \frac{\partial L}{\partial w_i} + \lambda w_i$$

写成向量形式：
$$\nabla J(\mathbf{w}) = \nabla L(\mathbf{w}) + \lambda \mathbf{w}$$

**Step 2：梯度下降更新规则**

$$\mathbf{w}_{new} = \mathbf{w}_{old} - \eta \nabla J(\mathbf{w}_{old})$$

代入 Step 1 的梯度：
$$\mathbf{w}_{new} = \mathbf{w}_{old} - \eta \left(\nabla L(\mathbf{w}_{old}) + \lambda \mathbf{w}_{old}\right)$$

**Step 3：展开为权重衰减形式**

$$\mathbf{w}_{new} = \mathbf{w}_{old} - \eta \nabla L(\mathbf{w}_{old}) - \eta \lambda \mathbf{w}_{old}$$

$$\mathbf{w}_{new} = (1 - \eta\lambda)\mathbf{w}_{old} - \eta \nabla L(\mathbf{w}_{old})$$

可以看到，在标准梯度下降的基础上，参数 $\mathbf{w}_{old}$ 被乘以了因子 $(1 - \eta\lambda)$。由于 $\eta > 0$ 且 $\lambda > 0$，有 $0 < 1 - \eta\lambda < 1$（假设 $\eta\lambda < 1$），因此每步更新都会先将旧权重**缩小**一个比例，再沿 $L$ 的梯度方向更新。这就是「权重衰减」名称的由来——权重在每步都被衰减（shrink）。

**Step 4：与 L1 正则化对比**

L1 正则化的目标函数：$J_{L1}(\mathbf{w}) = L(\mathbf{w}) + \lambda \|\mathbf{w}\|_1 = L(\mathbf{w}) + \lambda \sum_{i=1}^{d} |w_i|$

L1 的梯度：
$$\frac{\partial J_{L1}}{\partial w_i} = \frac{\partial L}{\partial w_i} + \lambda \cdot \text{sign}(w_i)$$

关键区别：
- **L2** 的正则化梯度为 $\lambda w_i$，当 $w_i$ 接近 0 时，梯度也接近 0，推力逐渐减弱。因此 L2 会把权重压小但不会精确归零，产生**小而均匀的权重分布**。
- **L1** 的正则化梯度为 $\lambda \cdot \text{sign}(w_i)$，无论 $w_i$ 多大或多小，梯度大小始终是 $\lambda$（常数），方向指向 0。当 $w_i$ 接近 0 时，这个恒定的推力仍然存在，能把 $w_i$ 精确推到 0，产生**稀疏权重**（很多 $w_i = 0$）。

从几何角度看：L2 的约束区域是圆（球），等高线与圆相切点一般在坐标轴外的平滑位置；L1 的约束区域是菱形（菱角朝向坐标轴），等高线与菱形相切点更容易落在坐标轴顶点（即某些 $w_i = 0$）。

🧠 直觉解释

L2 正则化让每步梯度下降都先把权重缩小一点再更新，相当于给权重加了一个「向 0 的弹簧」；L1 则给每个权重施加恒定大小的「向 0 的推力」，不因权重大小减弱，因此能把权重精确推到零。
AI面试问答 ⭐⭐ 第 4 题

AUC 指标的原理与适用场景

面试官问：「请解释 AUC 指标的含义、计算方式，以及它在什么场景下适用、什么场景下不适用？」
--- 以下为答案与解析 ---

📌 回答要点

  • AUC（Area Under the ROC Curve）是 ROC 曲线下方的面积，取值范围 [0, 1]，AUC = 0.5 表示随机猜测水平，AUC = 1 表示完美分类。
  • ROC 曲线的横轴是 FPR（假正率 = FP/(FP+TN)），纵轴是 TPR（真正率 = TP/(TP+FN)）。通过遍历所有分类阈值，计算每个阈值下的 (FPR, TPR) 点并连线得到 ROC 曲线。
  • AUC 的概率含义：随机取一个正样本和一个负样本，正样本预测分数高于负样本的概率即为 AUC。这个解释使 AUC 不依赖具体阈值，是一个 rank-based 指标。
  • AUC 的适用场景：类别不平衡的数据集（如正负比 1:100），因为 AUC 只关注正负样本的排序质量，不受类别比例影响；需要评估模型整体排序能力的场景。
  • AUC 的不适用场景：当关注的是某个特定阈值下的精确率/召回率时（如医疗诊断要求高召回），AUC 无法反映单一阈值的表现；当负样本远多于正样本且关注精确率时，AUC 可能高但实际精确率很低。

⭐ 加分项

  • AUC 与 PR-AUC（Precision-Recall AUC）的对比：在极度不平衡数据上，PR-AUC 比ROC-AUC 更敏感地反映正类预测质量，因为 PR 曲线的纵轴是精确率而非 TPR，受 FP 数量影响更大。
  • AUC 的计算优化：朴素方法 O(n²) 逐一比较正负样本对，高效方法 O(n log n) 是先按预测分数排序，然后用公式 $AUC = \frac{\sum_{i \in positive} rank_i - \frac{n_+(n_++1)}{2}}{n_+ \cdot n_-}$，其中 $rank_i$ 是正样本在排序中的秩。
  • AUC 对预测分数的绝对值不敏感，只关心排序（单调变换不影响 AUC），这是优点也是局限——模型整体预测偏高/偏低只要排序对，AUC 就不变。

🔮 追问预测

  • 追问1：「AUC = 0.8 在类别不平衡场景下意味着什么？」→ 回答要点：0.8 表示随机取一对正负样本，有 80% 概率正样本排在负样本前面；但不意味着精确率 80%，精确率还取决于正负比例和阈值选择。
  • 追问2：「ROC-AUC 和 PR-AUC 在什么情况下差异最大？」→ 回答要点：当负样本远多于正样本时差异最大。此时 ROC-AUC 可能仍然很高（因为 TPR 和 FPR 都以各自类别总数归一化，不受比例影响），但 PR-AUC 会显著下降（因为大量 FP 会拉低精确率）。
  • 追问3：「如何用代码实现 AUC 计算？」→ 回答要点：可用 sklearn.metrics.roc_auc_score(y_true, y_score)，或手写排序+秩和公式，注意处理预测分数相同的情况（相同分数取平均秩）。
