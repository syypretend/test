算法编程 ⭐⭐⭐ 第 1 题

二叉树中的最大路径和：『返一条腿，搜一个∩』

某片区域的光缆馈线构成一棵二叉树：每个站点有一个收益值 val（正数代表该站点的增益，负数代表维护损耗）。一条维护路径是沿用馈线连接的站点序列——从某站点出发沿树走到另一站点（或原地不动），同一站点至多经过 1 次。

路径总收益 = 路径上所有站点收益之和。求一条总收益最大的路径。

难点在哪：最优路径不一定经过根，也不必「自上而下」——它可能从左子树某点拐弯穿过一个节点进入右子树（∩ 形），甚至整条路径只含一个负收益站点。这与上一期「打家劫舍 III」同为树形 DP，但递推的返回值和最终答案不再重合：
- 向父节点汇报时，路径只能走「一条腿」；
- 更新全局答案时，却要允许「左右两条腿」同时接上。

把这两层分开，本题就解开了。
输入
一个层序数组，元素为整数或 `null`（Python 中为 `None`），按层序排列表示二叉树，末尾空节点可省略。
输出
一个整数：最大路径和（路径至少含一个站点，因此全负树时答案可为负）。
示例 1
输入：[-10, 9, 20, null, null, 15, 7]
输出：42
最优路径 15 → 20 → 7：15 + 20 + 7 = 42。绕过 -10 的根，两侧子树各取一条腿在 20 处『拐弯』。
示例 2
输入：[2, -1]
输出：2
路径只含根节点 2；把子节点 -1 接上反而更差，负子树剪枝。
约束
节点数 $1\le n\le 10^4$；每个节点 $-1000\le val\le 1000$；树可能退化为深度接近 $n$ 的链（Python 默认递归深度 1000，递归写法需自行评估，判题环境同样如此）。

--- 以下为答案与解析 ---

💡 解题思路

树形 DP（后序自底向上）

1. 定义 $gain(u)$ = 以 u 为最高点、向下（孩子方向）延伸的最大单边链和，允许不延伸（空链 = 0），所以 $gain(u)\ge 0$：
$$gain(u) = \max\bigl(0,\; u.val + \max(gain(l),\; gain(r))\bigr)$$
负腿直接剪掉——max(0, ·) 就是「负贡献不值得延伸」的剪枝。
2. 经过 u 的 ∩ 形路径（u 是路径最高点、左右可以同时接）为
$$u.val + \max(0, gain(l)) + \max(0, gain(r))$$
用它更新全局最优 best。
3. 但 $gain(u)$ 向父节点汇报时只能带一条腿（父节点视角，u 这侧路径不可能既走左孙子又走右孙子，那就不经过父节点了）。这正是「返回值 ≠ 答案」的核心：答案在拐弯处更新，返回值永远单边。
4. 全程用显式栈做后序遍历（先左、右孩子，再处理自己），gain 存在 dict 里，避免深链递归爆栈；与上期打家劫舍 III 的 (take, skip) 二元组合并相比，这里的状态从「节点选不选」换成了「链怎么延伸」，但骨架相同——都是孩子算完往上合并，区别在于答案在哪里被更新：上期的答案就是根的两个状态，而本期的答案在每一个节点的 ∩ 形计算中产生。

📝 参考代码（python）

from collections import deque


class TreeNode:
    def __init__(self, val=0):
        self.val = val
        self.left = None
        self.right = None


def _build(level_order):
    """层序数组 -> 二叉树"""
    if not level_order or level_order[0] is None:
        return None
    root = TreeNode(level_order[0])
    q = deque([root])
    i = 1
    while q and i < len(level_order):
        node = q.popleft()
        if i < len(level_order) and level_order[i] is not None:
            node.left = TreeNode(level_order[i])
            q.append(node.left)
        i += 1
        if i < len(level_order) and level_order[i] is not None:
            node.right = TreeNode(level_order[i])
            q.append(node.right)
        i += 1
    return root


def max_path_sum(level_order):
    root = _build(level_order)
    best = float("-inf")
    gain = {}        # id(节点) -> 以该节点为起点、向下延伸的最大单边链和（可为 0 表示不延伸）

    # 显式栈模拟后序遍历：孩子先算，父节点再合并（防止深链递归爆栈）
    stack = [(root, False)]
    while stack:
        node, done = stack.pop()
        if done:
            # 孩子已算完：查左右单边增益（叶孩子查不到为 0）
            lg = gain.get(id(node.left), 0)
            rg = gain.get(id(node.right), 0)
            # 1) 向上返回：只能选「一条」腿（或都不延伸），负贡献剪为 0
            gain[id(node)] = max(0, node.val + max(lg, rg))
            # 2) 全局答案：经过 node 的 ∩ 形路径 = val + 左腿 + 右腿
            best = max(best, node.val + max(0, lg) + max(0, rg))
        else:
            stack.append((node, True))          # 记"第二次弹出"
            if node.left:
                stack.append((node.left, False))
            if node.right:
                stack.append((node.right, False))
    return best

⚡ 复杂度分析

时间 O(n)：每个节点入栈出栈各两次，孩子增益 O(1) 合并 空间 O(n)：显式栈深 + gain 字典

🎯 考点

① 返回值/答案分离：向上只返单边，全局答案在 ∩ 处更新；② max(0, ·) 负剪枝；③ 全负树答案为负——best 初始化 $-\infty$ 而不是 0；④ 深链场景用显式栈迭代后序；⑤ 与打家劫舍 III 的树形 DP 对比：同为「自底向上合并」，差异在答案位置。
算法概念 ⭐⭐ 第 2 题

拓扑排序：Kahn 算法的入度队列与环检测

工程中有 $n$ 个工单任务，有向边 $u \to v$ 表示「工单 $u$ 必须先于工单 $v$ 完成」。现在要给所有任务排出一个执行顺序（拓扑排序）。关于实现方式，下列说法正确的是？
--- 以下为答案与解析 ---
✅ 正确答案：B

💡 解题思路

Kahn 算法的三件套：入度表 + BFS 队列 + 环判定。统计每个点入度后，所有入度 0（无前置依赖）的点先入队；每次出队输出一个节点，并把它的后继入度减 1，谁降到 0 谁入队。若最终输出节点数少于总节点数，说明剩下的点互相等待、入度永不归零——即存在环，拓扑序不存在。

🎯 考点

Kahn = 入度表 + 队列 + 出队减后继入度；输出数 < n ⇔ 有环；邻接表 $O(V+E)$；拓扑序不唯一（约束不足时）；换优先队列可求字典序最小序，代价是 $O(V\log V)$ 的堆开销。对比方案：DFS 三色标记 + 完成时间逆序同样 $O(V+E)$，适合递归顺手/需要检测回边时；有环时 DFS 遇到灰色（在栈）节点即报环。典型应用：构建依赖解析、课程表（LC 207/210）、工单编排、Spark/Flink 任务 DAG 调度。

🔍 逐项分析

  • A 错误——把 Kahn 和 DFS 法混为一谈。Kahn 是基于入度的 BFS 流程，完全不依赖 DFS。即便谈 DFS 拓扑排序，正确做法也是按节点的「完成时间」（所有后继都搜完被回溯的时刻）逆序输出，而不是首次访问顺序；按首次访问序输出连合法性都不保证（例如 u 出发先访问了远房子孙 v，再访问 u 的直接后继 w，输出里 v 排在 w 前面，但可能存在 w→v 的边）。
  • B 正确——完整概括了 Kahn 的流程、环判定与复杂度：每条边只在后继入度减 1 时被扫一次 O(E)，每个点入队出队各一次 O(V)，配合邻解表总复杂度 $O(V+E)$，且额外空间主要就是入度数组和队列。
  • C 错误——拓扑序一般不唯一。当图中同时存在多个入度 0 的点（约束不足）时，先输出谁都合法。例如三个孤立节点 A、B、C（无边），ABC、ACB、BAC 等 6 种顺序全部合法。两次运行顺序不同通常是队列/遍历顺序问题，不一定是 bug。
  • D 错误——「字典序最小」这半句是对的：换小根堆后每次总取编号最小且当前入度为 0 的点，确实得到字典序最小的拓扑序（依赖安装、课程安排里常用）。但复杂度会变成 $O(V + E + V\log V)$（每个节点一次堆操作），不再是 $O(V+E)$。想拿这半分还得注意：若一开始就要求全字典序最小，初始入度 0 的点也要全先进堆。
AI公式推导 ⭐⭐⭐ 第 3 题

Classifier-Free Guidance：从分类器引导到噪声预测插值的完整推导

上期我们推导了 DDPM 的 $L_{\mathrm{simple}}$，其中模型 $\varepsilon_\theta(x_t,t,c)$ 预测噪声。为了提升生成结果对条件 $c$（如文本提示词）的遵循度，图像生成模型（Stable Diffusion、DiT、Imagen 等）几乎都采用 Classifier-Free Guidance（CFG，无分类器引导）：

采样时并不直接用条件模型 $\varepsilon_c$ 的预测，而改用插值形式
$$\tilde\varepsilon = \varepsilon_u + w\,(\varepsilon_c - \varepsilon_u)$$
其中 $\varepsilon_u = \varepsilon_\theta(x_t,t,\varnothing)$ 是同一模型在空条件 $\varnothing$ 下的预测，$w$ 是引导权重。

任务：(1) 推导模型噪声预测与 score 的关系 $s = -\varepsilon/\sigma_t$；(2) 从贝叶斯分解出发，说明分类器引导如何引入 $\nabla_{x_t}\log p(c\mid x_t)$ 项；(3) 说明 CFG 如何用「条件/无条件模型的 score 差」替代分类器项；(4) 说明 $w=0,1,>1$ 的语义与代价；(5) 给出让同一个模型同时学到 $\varepsilon_c$ 与 $\varepsilon_u$ 的训练目标。
--- 以下为答案与解析 ---

🎯 考点

① $s=-\varepsilon/\sigma_t$ 是噪声预测 ↔ score 的桥；② 分类器引导来自贝叶斯分解出的 $\nabla\log p(c\mid x_t)$，CFG 用 $s_c - s_u$ 学出这一项，免掉分类器；③ $w=1$ 退化为普通条件采样——引导学生最常坑；④ 条件丢弃（10%~20%）让一个网络身兼两职；⑤ CFG 需每步两次前向，且 $w$ 过大越出数据分布产生过饱和。衔接：上期 DDPM 的 $L_{\mathrm{simple}}$ 是「学哪个 score」，这期 CFG 是「采样时怎么改 score」。

📐 推导过程

Step 1：噪声预测就是 score——$s_\theta = -\varepsilon_\theta/\sigma_t$

回顾 DDPM：$x_t = \sqrt{\bar\alpha_t}\,x_0 + \sqrt{1-\bar\alpha_t}\,\epsilon$，记 $\sigma_t = \sqrt{1-\bar\alpha_t}$。固定 $x_t$，对高斯 $p(x_t\mid x_0)=\mathcal{N}(x_t;\sqrt{\bar\alpha_t}x_0,\sigma_t^2 I)$ 求 score：
$$\nabla_{x_t}\log p(x_t\mid x_0) = -\frac{x_t-\sqrt{\bar\alpha_t}x_0}{\sigma_t^2} = -\frac{\epsilon}{\sigma_t}$$
最后一个等号用了 $\epsilon=(x_t-\sqrt{\bar\alpha_t}x_0)/\sigma_t$。对 $x_0$ 取期望后仍成立，故最优噪声预测 $\varepsilon^*(x_t)=\mathbb{E}[\epsilon\mid x_t]$ 对应条件 score
$$s_\theta(x_t,t,\cdot) \;=\; -\,\frac{\varepsilon_\theta(x_t,t,\cdot)}{\sigma_t}$$
所有「引导」技巧本质上都是在修改采样时用的 score。

Step 2：贝叶斯分解，分类器引导登场

条件采样的目标是 $p(x_t\mid c)$。贝叶斯 $p(x_t\mid c) \propto p(x_t)\,p(c\mid x_t)$，取对数再对 $x_t$ 求梯度：
$$\underbrace{\nabla_{x_t}\log p(x_t\mid c)}_{\text{要的 score}} = \underbrace{\nabla_{x_t}\log p(x_t)}_{\text{无条件模型会给}} + \underbrace{\nabla_{x_t}\log p(c\mid x_t)}_{\text{需要额外分类器}}$$
带引导强度 $\gamma$ 时等价于使用 $s_\gamma = s_u + \gamma\,\nabla_{x_t}\log p(c\mid x_t)$（$\gamma>1$ 即外推）。Dhariwal-Nicholson 的分类器引导做法：训练一个噪声鲁棒的分类器 $\hat p(c\mid x_t)$，采样时对其显式求 $\nabla_{x_t}\log \hat p(c\mid x_t)$ 加进去。痛点：要额外训练一个分类器，且它直接见过加噪数据——每个噪声级别都得训。

Step 3：用「两个模型的 score 差」替掉分类器

假设条件模型已充分学到 $\log p(c\mid x_t)$：把 Step 2 的移项反用，
$$\nabla_{x_t}\log p(c\mid x_t) = \nabla_{x_t}\log p(x_t\mid c) - \nabla_{x_t}\log p(x_t) = s_c - s_u$$
代回 $s_\gamma$（取 $\gamma = w$ 一次到位）：
$$\tilde s \;=\; s_u + w\,(s_c - s_u) = (1-w)\,s_u + w\,s_c$$
再由 Step 1 的 $s=-\varepsilon/\sigma_t$ 换回噪声空间（等式两边同乘 $-\sigma_t$）：
$$\boxed{\;\tilde\varepsilon = \varepsilon_u + w\,\bigl(\varepsilon_c - \varepsilon_u\bigr)\;}$$
这就是 CFG：不需要任何分类器，只要同一网络能分别给出条件下与空条件下的两个预测，它们的差就是「知道条件后 score 的修正方向」。

Step 4：$w$ 的语义与代价

- $w = 0$：$\tilde\varepsilon = \varepsilon_u$，纯无条件采样；
- $w = 1$：$\tilde\varepsilon = \varepsilon_c$，退化为标准的条件采样，毫无引导（很多同学的常见误区：以为 CFG 默认就有额外作用）；
- $w > 1$：把「条件引起的修正方向 $\varepsilon_c-\varepsilon_u$」放大过量（外推），相当于在 Step 2 里取 $\gamma>1$——生成明显向 $c$ 偏置，样本更贴合 prompt；

代价：$w$ 过大时 $\tilde s$ 对应的不再是任何真实的概率分布（外推出了训练数据的支撑集），表现为多样性坍缩、色彩过饱和/对比度失真、高频伪影。实践中 SD 类模型常用 CFG $w\in[3,9]$，视频/精细生成有时用 $1.5\sim4$ 的弱引导。

Step 5：一个模型怎么同时学会两个条件？条件丢弃训练

训练时以概率 $p_{\mathrm{uncond}}$（常用 10%~20%）把条件替换为空 token $\varnothing$，其余照常：
记伯努利变量 $b\sim\mathrm{Ber}(1-p_{\mathrm{uncond}})$，实际送入网络的条件为
$$\tilde c = \begin{cases} c, & b=1 \\ \varnothing, & b=0 \end{cases}$$
$$L_{\mathrm{CFG}} \;=\; \mathbb{E}_{x_0,\,\epsilon,\,t,\,c,\,\tilde c} \Bigl\| \varepsilon_\theta\bigl(x_t,\,t,\,\tilde c\bigr) - \epsilon \Bigr\|^2$$
训练目标仍是 DDPM 的噪声预测 MSE，唯一改动是条件被随机置空。这样网络在同一个条件 embedding 空间里同时学到有条件与无条件的噪声预测（$\varnothing$ 通常取空文本的 embedding，作为条件空间里一个被显式学过的「空类别」）。推理时对同一 $x_t$ 调用两次（$c$ 与 $\varnothing$）按 Step 3 插值——代价是每步前向翻倍。注意 DDPM/DiT 系论文里的 $w$ 记号有的是「$1+w$」形式，读论文时先对齐记号再比较数值。

🧠 直觉解释

条件模型比无条件模型「更知道往哪儿去」，两者的预测差就是条件信息带来的导航修正量；CFG 在采样时人为把这个修正量按 $w$ 倍放大/缩回，用少量样本多样性和数值稳定性换取目标遵循度。
AI面试问答 ⭐⭐ 第 4 题

单卡放不下大 batch：梯度累积与真·大 batch 在数学上完全等价吗？

面试官：你手头只有一张 12G 小卡（或 CPU），但实验想要 batch size 256 的更新效果。于是你每个 micro-batch（比如 8）做完 loss.backward() 后不清零梯度，攒满 32 个 micro-batch 才 optimizer.step() + zero_grad()。

问题：(1) 这种梯度累积和真正的 batch 256 一步更新，数学上等价吗？需要什么前提？(2) 哪些常见场景下会失效或明显偏离等价性？(3) 在分布式数据并行（DDP）下使用梯度累积要注意什么？
--- 以下为答案与解析 ---

📌 回答要点

  • 机制：梯度本质是 mini-batch 损失均值的导数，backward() 对 .grad 做累加（+=）。积累 N 个 micro-batch 后一次 optimizer.step()，更新量由「N 段梯度之和」决定，只要每段梯度都是「$(1/N)\times$ 该段批内均值的损失梯度」，总和就等于全批均值损失的梯度。
  • 等价前提：每个 micro-batch 的 loss 必须是『全部样本总和再对总样本数平均』的 $1/N$ 缩放。写法上是 loss = criterion(logits, y) / N（批内默认 mean 之后再除 N）。梯度算子线性：$\sum_k \nabla[\frac{1}{N}L_k] = \nabla[\frac{1}{N}\sum_k L_k] = \nabla L_{\text{全批}}$。剩余差异只有浮点求和顺序（约 1e-7 量级），训练上可忽略。
  • 典型失效 1——BatchNorm：BN 的均值/方差在每个 micro-batch 内统计，micro-batch=4~8 时统计噪声极大，且 N 步累积不会合并这些统计量——与真 batch 256 的 BN 语义完全不同。对策：小显存场景改用 LayerNorm/GroupNorm（与 batch 维无关、天然等价），跨卡场景的 SyncBN 只解决卡间、仍解决不了跨 step。这也是 Stable Diffusion 微调敢用较大梯度累积的原因之一——扩散模型 U-Net 用的是 GroupNorm。
  • 典型失效 2——in-batch 负样本类损失（对比学习/InfoNCE in-batch negatives）：真 batch 256 时负样本池是同批 255 个样本；梯度累积下每个 micro-batch 只有 7 个负样本。梯度虽被累加了，但损失面本身不同——这是『优化目标被改了』而不是『同一目标的分步计算』，严格不等价。需要大负样本池时只能用其他手段（梯度缓存/多步负样本队列，如 GradCache）。
  • 其他易踩坑：① 学习率调度器 scheduler.step() 若在每个 micro-step 都调用，warmup/衰减进度会快 N 倍——应只在真 optimizer.step() 后调用；② AMP 混合精度下 GradScaler 与累积交互要多检查（scale 只在 step 时 unscale）；③ 事件如权重衰减、EMA 更新等挂在 step 上的操作语义不变（只在真更新时执行），这点和等价性相容。
  • DDP 配合：默认 DDP 每次 backward() 都会 all-reduce 梯度（尽管是线性的、反复 reduce 不算错，只是白烧带宽）。标准写法是前 N-1 个 micro-step 包在 with model.no_sync(): 里跳过同步，最后一步正常反传、由 DDP 一次性完成跨卡规约——通信量降为 1/N。

⭐ 加分项

  • 对 Adam 同样成立：一阶/二阶矩是对『这一次实际用于更新的梯度』计算的，梯度累积下这个梯度就是全批均值的梯度，因此 Adam 的 $m_t、v_t$ 与真大 batch 完全一致（与 10-13 那期的 Adam 推导联系起来想：$m$、$v$ 看到的是 step 时的 $g$，与它此前分几段算出无关）。
  • 反例辨析：『每 micro-batch 就 step、学习率除以 N』与『累积 N 步再 step』在 SGD+无动量时数学相同，但在 Adam 上不同——前者的矩每一步都被 micro 梯度刷新（噪声更大、$v_t$ 估计不同），后者矩一次成型。面试里能讲清这一点是大加分。
  • 与梯度检查点正交可叠加：梯度累积是『用时间近似大 batch』，activation checkpointing 是『用重计算时间换激活显存』，两者解决的是显存里不同的账目项（优化器状态/参数 vs 中间激活）。LoRA 减参数量降的是前一项。小显存微调的标配组合拳：GA + checkpointing + LoRA。
  • 大 batch 学习率缩放：梯度累积等效把 batch 拉大 N 倍，若按线性缩放规则想同时放大学习率，要意识到 warmup 与衰减的里程碑都应改按 optimizer step 计数；许多训练崩掉并非数值问题，而是 scheduler 计数错位。

🔮 追问预测

  • 追问 1：BatchNorm 为什么不等价、LayerNorm 为什么等价？ BN 的统计量 $\mu、\sigma$ 依赖 batch 维度上同批样本，micro-batch 改变了统计对象本身；LN 只在单样本内部（特征维）归一化，与 batch 组成无关，逐样本独立计算、逐样本独立梯度，累积后自然还原。
  • 追问 2：显存连一个 micro-batch 都放不下怎么办？ 三条路优先级：① activation checkpointing 用重计算换激活显存；② 更小的 micro-batch（甚至 1）配合 GA；③ LoRA/QLoRA 降低参数与优化器状态。极端场景（对比学习要大 batch）考虑 GradCache 类两阶段梯度缓存。
  • 追问 3：怎么在代码里确认自己的累积写法是对的？ 快速 sanity check：固定种子下，比较『1 次 batch 256 训一步』与『8 次 batch 32 累积训一步』的梯度范数（allclose 到 1e-5 量级）；再把 lr 固定比较一步后的参数差。记得把 dropout 置 eval、数据顺序人工指定，排除随机性干扰。
