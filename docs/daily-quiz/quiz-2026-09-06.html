算法编程 ⭐⭐ 第 1 题

长度最小的子数组

给定一个含有 n 个正整数的数组 nums 和一个正整数 target，找出该数组中满足其元素总和 $\geq target$ 的长度最小的连续子数组，并返回其长度。若不存在符合条件的子数组，返回 0。
输入
nums（正整数数组），target（正整数）
输出
满足条件的最短连续子数组的长度
示例 1
输入：nums = [2, 3, 1, 2, 4, 3], target = 7
输出：2
子数组 [4, 3] 的和为 7，长度为 2，是最短的满足条件的连续子数组。
约束
$1 \le nums.length \le 10^5$，$1 \le nums[i] \le 10^4$，$1 \le target \le 10^9$

--- 以下为答案与解析 ---

💡 解题思路

滑动窗口（双指针）。维护窗口 [left, right]，right 不断右移扩大窗口累加 window_sum；当 window_sum >= target 时尝试右移 left 缩小窗口寻找更短子数组。由于数组元素均为正数，窗口和具有单调性，满足滑动窗口前提。

📝 参考代码（python）

def minSubArrayLen(target, nums):
    left = 0
    window_sum = 0
    min_len = float('inf')
    for right in range(len(nums)):
        window_sum += nums[right]
        while window_sum >= target:
            min_len = min(min_len, right - left + 1)
            window_sum -= nums[left]
            left += 1
    return min_len if min_len != float('inf') else 0

⚡ 复杂度分析

时间 O(n) 空间 O(1)

🎯 考点

滑动窗口 / 双指针；窗口单调性分析；正整数数组→窗口和单调递增是关键条件

小顶堆的数组索引性质

关于小顶堆（Min-Heap）存储在数组中的性质，以下说法**正确的是**？
--- 以下为答案与解析 ---
✅ 正确答案：B

💡 解题思路

逐项分析四个选项的正确性。

🎯 考点

堆的数组表示与索引关系；堆序性质 vs 完全有序的区别；堆的插入与删除调整流程

🔍 逐项分析

  • A 错误：小顶堆中父节点的值 ≤ 子节点的值，即父节点更小而非叶子节点更小。叶子节点的值 ≥ 其父节点的值。
  • B 正确：数组实现堆时，若下标从 1 开始，第 i 个节点的左子节点为 2i，右子节点为 2i+1，父节点为 ⌊i/2⌋。这是堆的数组映射核心公式。
  • C 错误：层序遍历只保证父节点在子节点之前出现，但不保证整体有序。例如堆 [1,3,2,5,4] 的层序遍历为 1,3,2,5,4，显然不是有序序列。
  • D 错误：删除根节点后，通常将最后一个元素移到根位置，然后执行下沉（sift-down）操作恢复堆性质。如果不调整，堆性质会被破坏。
AI公式推导 ⭐⭐ 第 3 题

推导决策树的信息熵与信息增益

决策树 ID3 算法使用信息增益（Information Gain）来选择最优划分特征。请完成以下推导：

1. 给定数据集 D 中包含 K 个类别，第 k 类样本占比为 $p_k$，推导**信息熵** $H(D)$ 的公式。
2. 用特征 A 将 D 划分为若干子集 $D_1, D_2, ..., D_v$（A 有 v 个取值），推导**条件熵** $H(D|A)$。
3. 推导**信息增益** $g(D, A)$ 的定义，并说明其物理含义。
--- 以下为答案与解析 ---

🎯 考点

信息熵定义与边界；条件熵的加权平均思想；信息增益作为特征选择准则；与基尼不纯度的对比（CART 用 Gini = 1 - Σp²，无需对数计算更快）

📐 推导过程

**符号定义**：
- D：当前数据集，共 |D| 个样本
- K：类别总数
- $C_k$：第 k 类的样本集合
- $p_k = |C_k| / |D|$：第 k 类样本占比
- A：离散特征，有 v 个取值 $a_1, ..., a_v$
- $D_v$：特征 A 取值为 $a_v$ 的子集

**第一步：信息熵 H(D)**

从信息论出发，随机变量 X 取值为 k 的概率为 $p_k$，其信息量为 $I(x=k) = -\log_2 p_k$。

对整个分布求期望，得到信息熵：
$$H(D) = -\sum_{k=1}^{K} p_k \log_2 p_k$$

边界情况：
- 全部同类 → $H(D) = 0$（最纯，无不确定性）
- 均匀分布 → $H(D) = \log_2 K$（最大熵，最不确定）

**第二步：条件熵 H(D|A)**

用特征 A 划分后，各子集 $D_v$ 有自己的熵 $H(D_v)$。条件熵是各子集熵的加权平均：
$$H(D|A) = \sum_{v=1}^{V} \frac{|D_v|}{|D|} H(D_v) = -\sum_{v=1}^{V} \frac{|D_v|}{|D|} \sum_{k=1}^{K} p_{kv} \log_2 p_{kv}$$

其中 $p_{kv} = |C_k \cap D_v| / |D_v|$，即子集 $D_v$ 中第 k 类的占比。

**第三步：信息增益 g(D, A)**

$$g(D, A) = H(D) - H(D|A)$$

物理含义：知道了特征 A 的取值后，数据集不确定性减少了多少。信息增益越大，特征 A 对分类贡献越大，ID3 选择信息增益最大的特征划分。

🧠 直觉解释

信息增益 = 划分前的不确定性 - 划分后的平均不确定性，衡量一个特征消除混乱的能力。
AI面试问答 ⭐⭐ 第 4 题

随机森林 vs GBDT vs XGBoost 的核心区别

面试官问：「随机森林、GBDT 和 XGBoost 都是集成学习模型，请详细说明它们的核心区别。」
--- 以下为答案与解析 ---

📌 回答要点

  • **集成策略不同**：随机森林=Bagging（各树并行独立训练，有放回抽样+随机特征，投票/平均输出，树间无依赖）；GBDT/XGBoost=Boosting（树串行训练，每棵新树拟合前轮残差/负梯度，逐步修正错误，树间强依赖）
  • **偏差-方差视角**：随机森林通过 Bagging+随机特征选择**降低方差**（几乎不改变偏差）；GBDT/XGBoost 通过梯度提升**降低偏差**（每轮修正残差逼近真实函数）
  • **优化方式**：GBDT 在函数空间用一阶梯度下降，第 t 轮拟合损失函数对当前预测的负梯度（残差近似）；XGBoost 引入**二阶泰勒展开**（用一阶 g_i 和二阶 h_i 导数），相当于牛顿法 vs 梯度下降，收敛更快精度更高
  • **XGBoost 工程改进**：显式正则项 Ω=γT+½λ‖w‖² 控制复杂度；特征粒度并行（分裂点选择阶段并行计算各特征增益）；内置缺失值自动处理；支持列采样；支持自定义损失函数（提供一二阶导即可）
  • **基模型**：随机森林用深决策树（高方差低偏差→需降方差）；GBDT/XGBoost 用浅回归树（高偏差低方差→需降偏差）

⭐ 加分项

  • LightGBM：直方图算法（Histogram）加速分裂点查找，GOSS 采样减少样本量，EFB 降特征维度，大数据集比 XGBoost 更快
  • CatBoost：对类别特征原生支持，Ordered Boosting 减少预测偏移
  • 工程经验：小数据/快速基线用随机森林；追求精度/大数据/竞赛用 XGBoost 或 LightGBM

🔮 追问预测

  • 追问：为什么 XGBoost 用二阶泰勒展开而非一阶？→ 二阶展开利用曲率信息（海森矩阵），提供步长信息，收敛更快、分裂点选择更精确
  • 追问：随机森林的随机特征选择为什么能降低方差？→ 降低树间相关系数 ρ，Bagging 方差下界为 ρσ²，降 ρ 使方差下界更低，这是 RF 区别于纯 Bagging 的关键
