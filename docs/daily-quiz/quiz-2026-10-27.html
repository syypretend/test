算法编程 ⭐⭐ 第 1 题

二叉树的层序遍历（BFS）

给定一棵二叉树，请实现函数 solve(tree)，返回它的**层序遍历**结果：自顶向下、同一层从左到右，每一层的节点值组成一个子数组，最终返回按层排列的二维数组。

输入 tree 是二叉树的**层序数组表示**（None 表示空节点，例如 [3, 9, 20, None, None, 15, 7] 表示根 3，左子 9，右子 20，20 的左子 15、右子 7）。

**要求**：使用 BFS 队列实现（宽度优先搜索），并把每一层的节点**单独收集为一个子数组**。技巧：每轮出队前先记录当前队列长度 size，只处理 size 个节点——这 size 个节点正好构成完整的一层。
输入
一个列表 `tree`：二叉树的层序数组，元素为整数或 `None`。
输出
`List[List[int]]`：按层分组的结果；空树返回 `[]`。
示例 1
输入：tree = [3, 9, 20, None, None, 15, 7]
输出：[[3], [9, 20], [15, 7]]
第一层只有根 3；第二层是 9、20；第三层是 15、7。
示例 2
输入：tree = [1]
输出：[[1]]
单节点树只有一层。
示例 3
输入：tree = []
输出：[]
空树没有任何层，返回空列表。
约束
- 节点数 $0 \le n \le 2000$ - 节点值：$-1000 \le val \le 1000$ - `None` 只表示占位空节点；层序数组末尾不会出现多余的 `None`。

💡 解题思路

BFS 层序遍历的核心是**用队列 + 固定每轮长度**：队列里永远是「当前层的全部节点」——因为我们是按层把节点入队的，每一轮开始时队列恰好装着下一层的全部节点。

具体做法：
1. 空树直接返回 []；
2. 根节点入队；
3. 循环：记录 size = len(queue)（**必须在出队前记录**，因为出队时队列会变短）→ 弹出 size 个节点组成 level 列表 → 顺手把每个节点的左右子入队（下一层）；
4. 把 level 加入结果。

关键点：**先固定 size 再弹出**，否则把子节点入队后会把下一层的节点也弹进当前层。

📝 参考代码（python）

from collections import deque

class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

def build_tree(arr):
    """层序数组建树：arr[0] 为根，None 表示空节点"""
    if not arr or arr[0] is None:
        return None
    root = TreeNode(arr[0])
    q = deque([root])
    i = 1
    while q and i < len(arr):
        cur = q.popleft()
        if arr[i] is not None:
            cur.left = TreeNode(arr[i])
            q.append(cur.left)
        i += 1
        if i < len(arr) and arr[i] is not None:
            cur.right = TreeNode(arr[i])
            q.append(cur.right)
        i += 1
    return root

def solve_level(tree):
    root = build_tree(tree)
    if root is None:
        return []
    res = []
    q = deque([root])
    while q:
        level = []
        size = len(q)          # 关键：先固定本层节点数
        for _ in range(size):  # 只弹出本层节点
            node = q.popleft()
            level.append(node.val)
            if node.left:
                q.append(node.left)
            if node.right:
                q.append(node.right)
        res.append(level)
    return res

⚡ 复杂度分析

时间 O(n)——每个节点恰好入队出队一次，n 为节点数 空间 O(n)——队列最多同时容纳一层节点（满二叉树最后层约 n/2），结果数组 O(n)

🎯 考点

BFS 层序遍历模板：队列 + 固定 size 分层；与 DFS 递归（深度优先）的差异对比；二叉树层序数组建树（None 占位）；应用：二叉树的锯齿形遍历、每层最大值、最小深度等变体。

✅ 正确答案：A

💡 解题思路

一致性哈希回答的是「增删节点时，多少数据需要搬移」：普通取模哈希 key % n 在 n 变化后**几乎所有 key 的槽位都变**（全量重排）；一致性哈希把变化限制在受影响区间内。四个选项分别考查核心性质（A）、与取模哈希的差异本质（B）、节点数与均匀性的关系（C）、虚拟节点（D）。

🎯 考点

一致性哈希三个记忆点：① 环形空间 + 顺时针后继；② 增删节点只迁移受影响区间（关键优势）；③ 虚拟节点解决节点少时的不均匀 + 支持加权。应用：Memcached/Redis 集群缓存、Cassandra、负载均衡、CDN 边缘缓存；工程上配合「环上二分找后继」可 O(log n) 定位。

🔍 逐项分析

  • **A 正确**。哈希环 + 顺时针查找是经典结构。节点离开时，原落在该节点上的 key 沿顺时针移到**下一个**节点（只搬动这一小段区间）；节点加入时，只把「新节点与前一节点之间」区间的 key 从原后继搬过来。其余区间完全不动——迁移量与**被变动的相邻区间**成正比，而不是与总数据量成正比。
  • **B 错误**。速度不是卖点：取模哈希一次取模也是 O(1)，一致性哈希定位要一次哈希 + 在环上找后继（哈希表/有序表 O(log n)）。真正的优势是**增删节点时数据迁移最小化**（从 O(n) 全量重排降为只迁移受影响区间），以及「映射稳定性」——旧数据的存储位置尽量不因集群规模变化而改变。
  • **C 错误**。恰恰相反：节点很少时（如 2~3 个），每个节点在环上占据的弧长跨度极大，数据极易扎堆到少数节点上，分布非常不均。均匀化靠的是**虚拟节点**：每个物理节点在环上映射多个哈希位置，把大弧段切碎，各物理节点按比例均匀分得 key。
  • **D 错误**。虚拟节点恰恰要**多个**才有效：同一物理节点放置 k 个虚拟点后，它在环上的落点增多，获得 key 的份额趋近均匀；还能通过调节 k 实现「加权」（大容量节点多放虚拟点）。只放一个虚拟节点等于没加虚拟，无法解决小规模不均问题。
AI公式推导 ⭐⭐ 第 3 题

反向传播（BP）四公式：从链式法则到参数梯度

考虑一个 $L$ 层全连接神经网络，逐层定义为：

$$z^l = W^l a^{l-1} + b^l, \qquad a^l = \sigma(z^l), \qquad l = 1, \dots, L$$

其中 $a^0 = x$ 为输入，$W^l, b^l$ 为第 $l$ 层参数，$\sigma$ 为逐元素激活函数，损失为标量 $L$（如均方误差 $L = \tfrac{1}{2}\|a^L - y\|_2^2$）。

定义第 $l$ 层**误差** $\delta^l = \dfrac{\partial L}{\partial z^l}$。请完整推导反向传播四公式（BP1–BP4）：

**(1)** 输出层误差：$\delta^L = \nabla_a L \odot \sigma'(z^L)$；
**(2)** 误差回传：$\delta^l = \big((W^{l+1})^{\mathrm{T}}\delta^{l+1}\big) \odot \sigma'(z^l)$；
**(3)** 权重梯度：$\dfrac{\partial L}{\partial W^l} = \delta^l (a^{l-1})^{\mathrm{T}}$；
**(4)** 偏置梯度：$\dfrac{\partial L}{\partial b^l} = \delta^l$。

要求写出每一步链式法则的中间过程（标量 → 向量），并说明第 (3) 步权重梯度的矩阵形式为什么是**外积**。
--- 以下为答案与解析 ---

🎯 考点

考点：① 链式法则在多层复合函数的展开（先标量后向量化）；② 逐元素激活使交叉项消失；③ $W^{\mathrm{T}}$ 回传与 $\odot\sigma'$ 门控；④ 权重梯度 = 外积 $\delta (a^{l-1})^{\mathrm{T}}$（为什么缓存前向激活）；⑤ 与 Softmax 交叉熵（第 9 期）、RNN BPTT（第 6 期）、LSTM 门控（第 16 期）呼应。

📐 推导过程

**符号约定**：$n_l$ 为第 $l$ 层神经元数；$W^l \in \mathbb{R}^{n_l \times n_{l-1}}$，$b^l \in \mathbb{R}^{n_l}$；$z^l, a^l, \delta^l \in \mathbb{R}^{n_l}$；$\odot$ 为逐元素（Hadamard）乘积；$\sigma'(\cdot)$ 逐元素作用。

---

**第 1 步：输出层误差 (BP1)**

对输出层第 $j$ 个神经元，由链式法则（先看损失对输出 $a^L$ 的依赖，再看输出对加权和的依赖）：

$$\delta^L_j = \frac{\partial L}{\partial z^L_j} = \sum_i \frac{\partial L}{\partial a^L_i} \cdot \frac{\partial a^L_i}{\partial z^L_j}$$

因为 $a^L_i = \sigma(z^L_i)$ 只依赖 $z^L_i$（逐元素激活），$i \neq j$ 的交叉项偏导为 0，只剩 $i = j$：

$$\delta^L_j = \frac{\partial L}{\partial a^L_j} \cdot \sigma'(z^L_j)$$

写成向量：$\delta^L = \nabla_a L \odot \sigma'(z^L)$。

以 MSE 为例验证：$L = \frac{1}{2}\|a^L - y\|_2^2 \Rightarrow \nabla_a L = a^L - y$，故 $\delta^L = (a^L - y) \odot \sigma'(z^L)$。若 $L$ 为交叉熵且输出层为 Softmax，梯度会进一步化简（第 7 期已推导 Softmax 交叉熵梯度，可对照）。

---

**第 2 步：误差逐层回传 (BP2)**

先计算相邻两层加权和的导数关系。由 $z^{l+1} = W^{l+1}\sigma(z^l) + b^{l+1}$：

$$\frac{\partial z^{l+1}_k}{\partial z^l_j} = W^{l+1}_{kj}\,\sigma'(z^l_j)$$

（注意：$z^{l+1}_k = \sum_j W^{l+1}_{kj}\sigma(z^l_j) + b^{l+1}_k$，对 $z^l_j$ 求偏导只留下 $\sigma'(z^l_j)$ 那一项。）

再由链式法则把 $\delta^{l+1}$ 拉回 $l$ 层：

$$\delta^l_j = \sum_k \frac{\partial L}{\partial z^{l+1}_k}\cdot\frac{\partial z^{l+1}_k}{\partial z^l_j} = \sum_k \delta^{l+1}_k\, W^{l+1}_{kj}\,\sigma'(z^l_j)$$

右边 $\sum_k \delta^{l+1}_k W^{l+1}_{kj}$ 正是 $(W^{l+1})^{\mathrm{T}}\delta^{l+1}$ 的第 $j$ 个分量，于是：

$$\delta^l = \big((W^{l+1})^{\mathrm{T}} \delta^{l+1}\big) \odot \sigma'(z^l)$$

直觉：误差沿网络反向传播时，先被 $W^{\mathrm{T}}$「线性混合」到上一层神经元，再被激活导数 $\sigma'(z^l)$ 「逐元素门控」——这就是为什么 $\sigma'$ 总小于 1（sigmoid）时深网误差会指数衰减（梯度消失），呼应 RNN BPTT 与 LSTM 门控直通的主题。

---

**第 3 步：权重梯度 (BP3)**

$W^l$ 的单个元素 $W^l_{jk}$ 只通过 $z^l_j = \sum_k W^l_{jk} a^{l-1}_k + b^l_j$ 影响损失：

$$\frac{\partial z^l_j}{\partial W^l_{jk}} = a^{l-1}_k$$

链式法则：

$$\frac{\partial L}{\partial W^l_{jk}} = \frac{\partial L}{\partial z^l_j}\cdot\frac{\partial z^l_j}{\partial W^l_{jk}} = \delta^l_j\, a^{l-1}_k$$

对所有 $j,k$ 汇总成矩阵：第 $j$ 行第 $k$ 列元素为 $\delta^l_j a^{l-1}_k$——这正是**外积** $\delta^l (a^{l-1})^{\mathrm{T}}$：

$$\frac{\partial L}{\partial W^l} = \delta^l (a^{l-1})^{\mathrm{T}}$$

直觉：梯度矩阵的每个元素是「**本层灵敏度 $\delta$ × 上一层激活值 $a$**」，所以**前向时缓存的 $a^{l-1}$ 和反向算出的 $\delta^l$ 缺一不可**。

---

**第 4 步：偏置梯度 (BP4)**

同理，$\frac{\partial z^l_j}{\partial b^l_j} = 1$：

$$\frac{\partial L}{\partial b^l_j} = \frac{\partial L}{\partial z^l_j}\cdot 1 = \delta^l_j, \qquad \frac{\partial L}{\partial b^l} = \delta^l$$

偏置的梯度**就是误差向量本身**，无需求外积——这也是为什么实现中偏置梯度计算最便宜。

---

**第 5 步：训练循环与复杂度**

一次参数更新的完整流程：
1. **前向**：算 $z^1, a^1, \dots, z^L, a^L$，沿途缓存每个 $z^l$（BP2 需要）与 $a^{l-1}$（BP3 需要），算出 $L$；
2. **反向**：BP1 得 $\delta^L$，BP2 逐层回传得到所有 $\delta^l$；
3. **梯度**：BP3 / BP4 得到 $\frac{\partial L}{\partial W^l}, \frac{\partial L}{\partial b^l}$；
4. **更新**：$W^l \leftarrow W^l - \eta\frac{\partial L}{\partial W^l}$（SGD 等）。

前向与反向各是一轮矩阵连乘，复杂度同阶（都是每层一次矩阵乘法 $O(n_l n_{l-1})$）；相比数值微分（每个参数一次前向，$O(N)$ 倍代价），反向传播是工程可行的关键。

🧠 直觉解释

把 $\delta^l$ 想成「第 $l$ 层每个神经元的**敏感度**」：输出层由「损失对输出导数 × 激活斜率」给出；每往回传一层，误差被 $W^{\mathrm{T}}$ 线性搬回上一位置、再被 $\sigma'$ 逐元素缩放——四公式不过是对敏感度的完整追踪。

大模型合并（Model Merging）：原理、方法与工程要点

「我们微调出了多个大模型——一个擅长客服问答、一个擅长合同审核、一个在数学推理上更优。现在希望在推理时只部署一个模型、一次性拿到这些能力，不想跑多个模型做集成。你会怎么做？」

4. 合并与 LoRA 微调是什么关系？工程落地需要注意哪些坑？

--- 以下为答案与解析 ---

📌 回答要点

  • **定义与本质区别**：模型合并把多个模型的**参数（权重）**按某种规则合成一份，推理时只需一个模型一次前向，额外推理开销 ≈ 0；而 Ensemble 是把多个模型的**输出**（软投票/平均）融合，推理时 N 个模型都要跑，开销 N 倍。所以 merge 是「参数空间融合」，ensemble 是「预测空间融合」——merge 牺牲了集成带来的性能上界，换来部署成本的大幅下降，适合多任务/多模态/持续学习的生产落地。
  • **主要方法（3 类）**：① **权重平均族**——直接或加权平均（如 Fisher 加权按参数重要性给权重）、Model Soup（多个超参/初值的模型平均，常获更好泛化）；② **任务向量族（Task Arithmetic）**——定义任务向量 $\tau_i = M_i - M_{\text{base}}$，合并 $M = M_{\text{base}} + \sum_i \lambda_i \tau_i$（也可用负号 $-$ 实现「消除某能力」，如去毒/去版权）；③ **冲突消解族**——TIES-Merging（先按幅度修剪「小权重」、再对冲突参数做**多数符号投票**、最后只合并符号一致的部分）、DARE（随机丢弃大部分任务向量并 re-scale，常与 LoRA 组合）；另外还有 Layer-wise 嫁接（跨结构拼接）、SLERP（球面线性插值，任务向量短时更稳）。
  • **为什么能工作（直觉）**：核心经验规律是**低维连通性 / 线性模式连通性（LMC）**——大模型从同一基座出发做不同任务微调，其解与基座初始化之间常落在同一个「低损失盆地」中，盆地内部近似平坦连通，因此权重向量的算术组合（平均、插值、相加）仍大概率落在低损失区域，不会像小模型那样「平均两个解 = 一个很差解」。这与损失景观的平坦性、SGD 收敛解共享下界低维子空间有关，也是合并能生效的宏观理由。
  • **与 LoRA 的关系**：① 推理侧，LoRA 训练后可以**合并回基座**（$W' = W + \alpha BA$），实现「零额外延迟」的 LoRA 部署，这正是权重合并的一个特例；② 多个任务 LoRA 可做**插值/合并**成组合（LoRA merge、LoRA soup），各方向参数可加减、可缩放；③ Task Arithmetic 的 delta 如果就是 LoRA 的低秩增量，则合并天然兼容；④ 工程上常「基座 + 多 LoRA 动态路由」与「多 LoRA 合并」是两种互补路线——前者可切换灵活、后者推理更快。
  • **工程落地的坑**：① **同源性要求**——架构、层数、词表、tokenizer、维度必须一致（不同基座如 Llama vs Qwen 不能直接 merge），异构只能考虑层数/嫁接或重训练；② **任务冲突**——目标任务差异大时合并性能衰减明显，需要验：在验证集上扫 λ（或各层/各任务权重）网格，必要时合并后再做少量 SFT 校准；③ **合并 ≠ 集成上界**——别期待合并超过最强单模型太多，它的价值是「单模型能力叠加 + 部署不变」；④ 结合量化/蒸馏/剪枝叠加时注意精度损失叠加效应。

⭐ 加分项

  • **与 MoE 的对比**：MoE 是「稀疏激活、按 token 路由专家」——每个 token 只走部分专家参数，知识分别存储、路由复用；而合并是把多个任务的知识**压缩进同一套稠密参数**，两者在「知识容量 vs 推理成本/能力隔离」上做了不同的取舍，可类比说明 merge 的容量瓶颈。
  • **Fisher 加权平均**：用各任务 Fisher 信息矩阵对角元素作为权重分配 λ——对某个任务「重要」的参数少让别的任务改写，本质是参数空间的贝叶斯「先验」近似，与 EWC 思路同源。
  • **对齐与能力折中**：merge 也被用于「对齐不失智」——将 SFT / RLHF 模型与基座做 Task Arithmetic（如 DPO-offline 系数、orpo），缓解对齐微调导致的灾难性遗忘（capability retention），工业界常用。
  • **与持续学习的关系**：合并天然适合「数据隐私/增量任务」——新任务练成增量权重后 merge 进去，旧任务的数据可以不再保留，规避数据合规问题。

🔮 追问预测

  • **追问 1：两个任务方向冲突怎么办？** 回答思路：符号冲突是合并不稳定的主因——用 TIES 的多数符号投票、或按 Fisher 重要性把「重要参数」保护起来、或对不同任务用不同 λ（甚至逐层 λ）；本质是梯度/参数方向不一致，先检测冲突（如参数符号相反且幅度相近）再消解。
  • **追问 2：合并后的模型需要评估吗？λ 怎么选？** 回答：必须评估——合并后的模型不是「免费午餐」，需要在任务验证集/基准上扫 λ 网格（0~1）与各层权重组合；严重退化时回退为逐层 merge 或转集成。
  • **追问 3：merge 和 MoE 有什么区别？各适合什么场景？** 回答：merge 适合「任务数量少、可压缩进单参数、推理成本敏感」；MoE 适合「任务/专家多、需要能力隔离、显存足够」——后者参数量大但激活稀疏，前者参数小、稠密推理快。
  • **追问 4：为什么 merge 不能保证比集成好？** 回答：merge 是参数空间上的假设性操作，其有效依赖 LMC/低损失盆地，任务差异过大时平均会落在高损失区域；集成在预测空间取期望，风险更小但推理成本线性增长——两者是「性能上限 vs 推理成本」的 trade-off。
