算法编程 ⭐⭐ 第 1 题

数组中的逆序对（归并排序 · 分治）

给定一个整数数组 $nums$，返回数组中**逆序对**的总数量。

**逆序对定义**：满足 $i < j$ 且 $nums[i] > nums[j]$ 的一对下标 $(i, j)$。

例如 $nums = [7, 5, 6, 4]$ 中，逆序对为 $(7,5)、(7,6)、(7,4)、(5,4)、(6,4)$，共 $5$ 对。
输入
整数数组 nums（Python list）
输出
逆序对总数（int）
示例 1
输入：nums = [7, 5, 6, 4]
输出：5
逆序对为 (7,5)、(7,6)、(7,4)、(5,4)、(6,4)，共 5 对
示例 2
输入：nums = [1, 2, 3]
输出：0
数组已升序，不存在逆序对
约束
0 ≤ len(nums) ≤ 10^5；-10^9 ≤ nums[i] ≤ 10^9

def solve(nums): # 返回 nums 中逆序对的数量 # 逆序对：i < j 且 nums[i] > nums[j] pass
--- 以下为答案与解析 ---

💡 解题思路

暴力枚举所有 $(i, j)$ 是 $O(n^2)$，数据规模 $10^5$ 下不可行。**归并排序**天然适合统计逆序对：分治合并两个有序子数组时，若右半指针所指元素 nums[j] 小于左半当前元素 nums[i]，则左半从 i 到 mid 的所有元素都比 nums[j] 大，可一次性累加 mid - i 个逆序对。整个过程在归并排序框架内完成，不会漏计或重复。

📝 参考代码（python）

def solve(nums):
    if not nums:
        return 0

    def merge_sort(arr):
        # 返回 (排序后的数组, 该区间内的逆序对数)
        if len(arr) <= 1:
            return arr, 0
        mid = len(arr) // 2
        left, cnt_l = merge_sort(arr[:mid])
        right, cnt_r = merge_sort(arr[mid:])

        merged = []
        i = j = 0
        cnt = cnt_l + cnt_r
        while i < len(left) and j < len(right):
            if left[i] <= right[j]:
                merged.append(left[i])
                i += 1
            else:
                merged.append(right[j])
                j += 1
                cnt += len(left) - i   # 左半剩余元素均大于 right[j]
        merged.extend(left[i:])
        merged.extend(right[j:])
        return merged, cnt

    _, total = merge_sort(nums)
    return total

⚡ 复杂度分析

时间 O(n log n) 空间 O(n)（归并辅助数组）

🎯 考点

分治思想（归并排序）；合并阶段跨区间逆序对统计；时间复杂度从 O(n^2) 优化到 O(n log n)
算法概念 ⭐ 第 2 题

动态规划与贪心、分治的辨析

关于动态规划（DP）、贪心算法、分治算法三者的性质，下列说法**正确**的是？
--- 以下为答案与解析 ---
✅ 正确答案：A

💡 解题思路

辨析三类算法思想的核心性质：动态规划的两大要素、贪心的局部最优性、分治的独立性。

🎯 考点

DP 最优子结构 + 重叠子问题；贪心局部最优不保证全局最优；分治子问题独立性；DP 的两种实现方式

🔍 逐项分析

  • A 正确：动态规划要求最优子结构 + 重叠子问题（子问题被反复求解，故用表缓存）；分治（如归并排序、快速排序）子问题相互独立、不重叠，因此各自求解后直接合并，无需缓存。
  • B 错误：贪心每一步只做「当前看来最优」的局部选择，并不依赖（也不回溯）子问题最优解；只有满足贪心选择性质 + 最优子结构时才保证全局最优，不是无条件的。
  • C 错误：动态规划有两种等价实现——自底向上（迭代填表）与自顶向下（递归 + 记忆化），后者虽用递归但带缓存去重，本质仍是 DP。
  • D 错误：递归可解的问题（如递归枚举子集、简单递归求阶乘）未必有重叠子问题，DP 只优化「存在大量重叠子问题」的那类问题。
AI公式推导 ⭐⭐⭐ 第 3 题

SVM 对偶问题完整推导

对于线性可分支持向量机，优化目标为：$\min_{w,b} \frac{1}{2}\|w\|^2$，约束为 $y_i(w \cdot x_i + b) \ge 1,\ i=1,...,n$。

请完成以下推导：

1. 写出拉格朗日函数，并通过对 $w$、$b$ 求偏导令为 0，得出 $w$ 的表达式与约束 $\sum_i \alpha_i y_i = 0$；
2. 消去 $w$、$b$ 后写出对偶目标函数（关于 $\alpha$ 的二次规划）；
3. 依据 KKT 条件说明哪些点是支持向量，给出最终决策函数的表达式。
--- 以下为答案与解析 ---

🎯 考点

拉格朗日对偶、KKT 互补条件、支持向量定义、对偶目标函数、核技巧动机

📐 推导过程

#### 符号定义

- 训练集 $\{(x_i, y_i)\}_{i=1}^n$，$x_i \in \mathbb{R}^d$，$y_i \in \{+1, -1\}$
- 分类超平面 $w \cdot x + b = 0$，几何间隔 $= \dfrac{1}{\|w\|}$
- 约束 $y_i(w \cdot x_i + b) \ge 1$ 保证每个样本至少落在间隔边界上

#### 第 1 步：构造拉格朗日函数

对每个约束 $y_i(w \cdot x_i + b) - 1 \ge 0$ 引入拉格朗日乘子 $\alpha_i \ge 0$：

$$L(w, b, \alpha) = \frac{1}{2}\|w\|^2 - \sum_{i=1}^{n} \alpha_i \left[ y_i (w \cdot x_i + b) - 1 \right]$$

#### 第 2 步：对 $w$、$b$ 求偏导并令为 0

$$\frac{\partial L}{\partial w} = w - \sum_{i=1}^{n} \alpha_i y_i x_i = 0 \quad\Longrightarrow\quad w = \sum_{i=1}^{n} \alpha_i y_i x_i$$

$$\frac{\partial L}{\partial b} = -\sum_{i=1}^{n} \alpha_i y_i = 0 \quad\Longrightarrow\quad \sum_{i=1}^{n} \alpha_i y_i = 0$$

#### 第 3 步：代入消元得对偶问题

将 $w = \sum_i \alpha_i y_i x_i$ 代入 $L$，并利用 $\sum_i \alpha_i y_i = 0$ 消去含 $b$ 的项：

$$L_D = \sum_{i=1}^{n} \alpha_i - \frac{1}{2}\sum_{i=1}^{n}\sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j (x_i \cdot x_j)$$

于是对偶问题为：

$$\max_{\alpha} \; \sum_{i=1}^{n} \alpha_i - \frac{1}{2}\sum_{i=1}^{n}\sum_{j=1}^{n} \alpha_i \alpha_j y_i y_j \langle x_i, x_j \rangle \quad s.t.\; \sum_{i=1}^{n} \alpha_i y_i = 0,\ \alpha_i \ge 0$$

#### 第 4 步：KKT 条件与支持向量

KKT 互补松弛条件：$\alpha_i \left[ y_i(w \cdot x_i + b) - 1 \right] = 0$。

- 若 $\alpha_i > 0$，则 $y_i(w \cdot x_i + b) = 1$，样本恰在间隔边界上 → **支持向量**；
- 若样本在间隔边界内侧（$y_i(w \cdot x_i + b) > 1$），则 $\alpha_i = 0$，对决策无贡献。

因此最终 $w$ 只由支持向量累加决定：

$$w = \sum_{i \in SV} \alpha_i y_i x_i$$

$b$ 可由任一支持向量 $x_s$ 求得：$b = y_s - \sum_{i} \alpha_i y_i \langle x_i, x_s \rangle$。

#### 第 5 步：决策函数与核技巧动机

$$f(x) = \text{sign}\left( \sum_{i=1}^{n} \alpha_i y_i \langle x_i, x \rangle + b \right)$$

对偶形式中样本只以内积 $\langle x_i, x_j \rangle$ 出现，可直接用核函数 $K(x_i, x_j) = \langle \phi(x_i), \phi(x_j) \rangle$ 替换，从而在无需显式计算高维映射的情况下实现非线性分类。

🧠 直觉解释

对偶推导把「最小化 w 模长」转化为「最大化关于 α 的二次凹函数」，训练后的模型只与支持向量有关——这既是稀疏性来源，也是引入核技巧的入口。
AI面试问答 ⭐⭐ 第 4 题

Dropout 的原理、训练/推理差异与使用注意事项

面试官：请解释 Dropout 的核心思想、训练与推理阶段的行为差异，并说明使用 Dropout 时的注意事项。
--- 以下为答案与解析 ---

📌 回答要点

  • 核心思想：训练时以概率 p 随机将神经元输出置零（或以概率 1−p 保留），相当于每步训练都在训练一个不同的『瘦身』子网络，多个子网络共享参数，等效于对指数级子网络的集成（Bagging 的近似），从而缓解过拟合、增强泛化。
  • 训练/推理差异：训练时开启随机置零（并做 inverted dropout：保留的神经元输出除以 1−p，使期望输出不变）；推理时必须关闭随机置零，直接用完整网络前向，否则输出随机抖动导致结果不稳定。
  • 数学动机：Dropout 是一种正则化。对线性层，训练期望 $E[X'] = (1-p) \cdot \frac{X}{1-p} = X$（inverted dropout 下期望保持），相当于在每层间注入乘性伯努利噪声，类似于在隐含层加正则约束，可看作 L2 正则的近似/集成思想。
  • 使用位置与注意：一般加在全连接层（激活函数之后）；对 CNN 常在池化后加或使用 SpatialDropout；推理阶段需切换到 eval 模式（PyTorch：model.eval()；Keras：training=False），否则 BN 统计量与 Dropout 行为都会异常。
  • 超参数：dropout rate p 常取 0.5（对全连接）或 0.2~0.3（对卷积）；率过高会欠拟合，过低效果弱；与 BatchNorm 配合使用时通常 dropout 放 BN 之后。

⭐ 加分项

  • 对比：Dropout 训练时随机置零+缩放等价于对激活值做乘性噪声，与数据增广的随机遮挡思想一致；与 L2/Weight Decay 常联合使用。
  • 工程注意：inverted dropout 把缩放并入训练，推理时零成本；若实现为训练不缩放、推理按 1−p 缩放，二者数学等价但工程上更麻烦（易踩坑）。
  • 与 BN 配合：现代大模型（Transformer）里全连接后常不再加 Dropout（注意力与 FFN 已有隐式正则），而 CNN 常使用 Dropout2d（SpatialDropout）按通道置零而非像素置零，以保留空间结构。
  • 训练技巧：dropout 输出会在显存/计算上略有开销；大 batch + dropout 泛化更好；也可配合 scheduler 调整 p（如 Dropout 逐渐增大）。

🔮 追问预测

  • 追问『为什么 inverted dropout 在推理时不做任何操作也能保持一致性？』→ 回答：训练时保留神经元输出乘以 1/(1−p)，使各层输出的期望等于无 dropout 时的期望；推理用完整网络直接输出，即数学期望一致。
  • 追问『Dropout 与 BatchNorm 同时使用为什么有时效果差？』→ BN 本身有正则作用（每 mini-batch 统计噪声），叠加大 dropout 可能正则过强；且两者位置需有序（BN 在激活前，dropout 在激活后），否则方差估计受扰动，BN 的统计量在 train/eval 间不一致。
  • 追问『为什么不建议对 embedding 层直接做像素级 dropout？』→ 高维稀疏 one-hot embedding 中像素间强相关，dropout 像素噪声破坏信息；应使用 embedding dropout（按 token 整体丢弃）或对输出特征做 dropout。
