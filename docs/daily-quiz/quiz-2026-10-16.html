算法编程 ⭐⭐ 第 1 题

无重叠区间（最少移除区间数）

给定一个区间数组 intervals，其中 intervals[i] = [start_i, end_i]（$start_i \le end_i$）。请返回**最少需要移除的区间数量**，使得剩余区间两两互不重叠。

两区间 $[a,b]$ 与 $[c,d]$ 互不重叠，当且仅当 $b \le c$ 或 $d \le a$（即区间**相接**不算重叠，例如 [1,2] 与 [2,3] 视为不重叠）。

> 本题是经典「区间调度（Interval Scheduling）」贪心问题的反向形式：先求最多能保留多少个互不重叠的区间，移除数 = 总数 − 保留数。
输入
第一行一个整数 n（1 ≤ n ≤ 10^5）表示区间个数；接下来 n 行，每行两个整数 start end，表示一个区间 [start, end]。
输出
一个整数，表示最少需要移除的区间数量。
示例 1
输入：4
1 2
2 3
3 4
1 3
输出：1
移除 [1,3] 后剩余 [1,2]、[2,3]、[3,4] 两两不重叠；也可以移除 [1,2]，最少移除 1 个。
示例 2
输入：3
1 2
1 2
1 2
输出：2
三个区间完全相同，最多保留 1 个，需移除 2 个。
示例 3
输入：2
1 2
2 3
输出：0
[1,2] 与 [2,3] 相接不算重叠，无需移除。
约束
$1 \le n \le 10^5$；$-10^9 \le start_i \le end_i \le 10^9$

--- 以下为答案与解析 ---

💡 解题思路

**贪心 + 按右端点排序**：要留下尽可能多的不重叠区间，每次应优先保留「右端点最早」的区间——右端点越早，给后续区间留下的空间越大。

具体做法：
1. 按右端点升序（右端点相同时按左端点）排序；
2. 维护 last_end = 当前已保留区间的最大右端点；
3. 遍历每个区间：若 start < last_end 说明与已保留区间重叠，必须移除（计数 +1）；否则保留，并更新 last_end = end。

正确性：对按右端点排序的区间序列，「保留右端点最小且不冲突的区间」是最优的——任何最优解中的第一个区间都可替换为右端点更早的区间而不影响后面的选择（贪心选择性质）。

📝 参考代码（python）

def solve(intervals):
    # 按右端点升序排序，右端点相同按左端点
    intervals.sort(key=lambda x: (x[1], x[0]))
    removed = 0
    last_end = float('-inf')  # 已保留区间的最右端点
    for start, end in intervals:
        if start < last_end:
            removed += 1      # 与上一个保留区间重叠，移除当前区间
        else:
            last_end = end    # 不重叠，保留并更新右端点
    return removed

⚡ 复杂度分析

时间 O(n log n)（排序主导） 空间 O(1)（原地排序）

🎯 考点

贪心选择性质（右端点越早越优）；重叠判定 start < last_end 的边界（相接不算重叠）；排序稳定性（右端点相同按左端点）。
算法概念 ⭐⭐ 第 2 题

对顶堆与数据流中位数

要求设计一个结构支持「在线流式」插入整数，并能随时查询当前全部数的中位数。常用的高效做法是维护「对顶堆」（两个堆）。关于对顶堆方案的下列理解中，**正确**的是哪一项？
--- 以下为答案与解析 ---
✅ 正确答案：A

💡 解题思路

对顶堆的精髓是「让两个堆顶贴住中位数」：大顶堆（max-heap）存较小的一半，堆顶即较小一半的最大值；小顶堆（min-heap）存较大的一半，堆顶即较大一半的最小值。二者平衡后，中位数要么在大顶堆堆顶（奇数个），要么是两堆顶的平均（偶数个）。

🎯 考点

堆的性质（大顶堆堆顶最大、小顶堆堆顶最小）；对顶堆平衡条件；在线算法；O(log n) 插入 / O(1) 查询。

🔍 逐项分析

  • A 正确：这正是对顶堆的标准形态。约定大顶堆 left、小顶堆 right，插入时新元素先与 left 堆顶比较决定进哪个堆，再调整使 |left| − |right| ∈ {0, 1}（大小最多差 1）。奇数时中位数 = left 堆顶；偶数时 = (left 顶 + right 顶) / 2，均 O(1)。
  • B 错误：若不维持两堆平衡，堆顶不再是中位数。经典实现必须在每次插入后「重平衡」（把多的那堆堆顶移到另一堆），而不是查询时全量排序重建——后者等于退化回离线做法。
  • C 错误：堆顶语义说反了。大顶堆存较小一半，它的堆顶（最大值）才是「较小一半的最大值」；小顶堆存较大一半，堆顶（最小值）才是「较大一半的最小值」。
  • D 错误：插入需要一次 O(log n) 的入堆 + 至多一次 O(log n) 的平衡转移，总复杂度 O(log n)；查询中位数才是 O(1)（直接看堆顶）。
AI公式推导 ⭐⭐⭐ 第 3 题

XGBoost：目标函数与分裂增益的完整推导

推导 XGBoost 的**带正则化的加法模型目标**、**最优叶子权重闭式解**与**分裂增益公式**（论文 Chen & Guestrin 2016 的核心推导）。要求从加法模型出发，完成二阶泰勒展开、叶子分组、求导求最优、分裂前后对比四个步骤。

> 衔接复习：第 14 期推导过 GBDT 用**一阶**负梯度（残差）拟合；XGBoost 的核心升级是使用**二阶**泰勒展开 + 显式正则项，请对比说明二者差异。
--- 以下为答案与解析 ---

🎯 考点

加法模型 + 结构正则；二阶泰勒展开（对 GBDT 一阶梯度的升级）；叶子分组 G_j/H_j；最优叶子权重 w*=−G/(H+λ)；分裂增益与 γ 预剪枝；平方损失退化验证。

📐 推导过程

### 第 1 步：加法模型与带正则的目标函数
设前 $t-1$ 轮已得到模型 $F_{t-1}(x)$，第 $t$ 轮学习一棵回归树 $f_t$，更新为 $F_t(x)=F_{t-1}(x)+f_t(x)$。第 $t$ 轮目标为「经验损失 + 结构正则」：

$$\tilde{\mathcal{L}}^{(t)} = \sum_{i=1}^{n} L\big(y_i,\ \hat{y}_i^{(t-1)} + f_t(x_i)\big) + \Omega(f_t),\qquad \Omega(f) = \gamma T + \tfrac{1}{2}\lambda \sum_{j=1}^{T} w_j^2$$

其中 $T$ 为叶子数、$w_j$ 为第 $j$ 个叶子的输出权重、$\gamma$ 惩罚叶子数（结构复杂度）、$\lambda$ 对叶子权重做 L2 收缩。

### 第 2 步：二阶泰勒展开（XGBoost 的关键升级）
对损失函数在新树 $f_t(x_i)$ 处做二阶展开，$f_t$ 为增量：

$$L(y_i, \hat{y}^{(t-1)} + f_t) \approx L(y_i, \hat{y}^{(t-1)}) + g_i\, f_t(x_i) + \tfrac{1}{2} h_i\, f_t^2(x_i)$$

其中一阶梯度 $g_i$ 与二阶梯度 $h_i$（在 $\hat y = \hat y^{(t-1)}$ 处取值）：

$$g_i = \frac{\partial L(y_i, \hat y)}{\partial \hat y},\qquad h_i = \frac{\partial^2 L(y_i, \hat y)}{\partial \hat y^2}$$

第一项 $L(y_i,\hat y^{(t-1)})$ 与 $f_t$ 无关，可直接删去。于是目标化为：

$$\tilde{\mathcal{L}}^{(t)} \approx \sum_{i=1}^{n} \left[ g_i f_t(x_i) + \tfrac{1}{2} h_i f_t^2(x_i) \right] + \gamma T + \tfrac{1}{2}\lambda\sum_j w_j^2$$

### 第 3 步：按叶子归集，求最优叶子权重
树把样本映射到叶子：$f_t(x_i) = w_{q(x_i)}$，其中 $q$ 为「样本→叶子」的映射。记叶子 $j$ 的样本集合 $I_j = \{i\mid q(x_i)=j\}$，并定义叶子上的梯度统计：

$$G_j = \sum_{i\in I_j} g_i,\qquad H_j = \sum_{i\in I_j} h_i$$

目标变为逐叶子独立的二次函数：

$$\tilde{\mathcal{L}}^{(t)} = \sum_{j=1}^{T}\left[ G_j w_j + \tfrac{1}{2}(H_j + \lambda) w_j^2 \right] + \gamma T$$

对 $w_j$ 求导并置零（二次函数最小值）：$\frac{\partial}{\partial w_j} = G_j + (H_j+\lambda)w_j = 0$，得到**最优叶子权重闭式解**：

$$w_j^{*} = -\frac{G_j}{H_j + \lambda}$$

代回得到「给定树结构 $q$ 时的最小目标值」：

$$\tilde{\mathcal{L}}^{*}(q) = -\frac{1}{2}\sum_{j=1}^{T}\frac{G_j^2}{H_j + \lambda} + \gamma T$$

### 第 4 步：分裂增益公式
树生长时枚举每个候选分裂点：把父叶子（梯度统计 $G, H$）分裂成左右两个新叶子（$G_L,H_L$ / $G_R,H_R$，且 $G=G_L+G_R$、$H=H_L+H_R$）。增益 = 分裂前目标值 − 分裂后目标值（叶子数 $T$ 增加 1，$\gamma$ 相应增加）：

$$\text{Gain} = \frac{1}{2}\left[ \frac{G_L^2}{H_L+\lambda} + \frac{G_R^2}{H_R+\lambda} - \frac{(G_L+G_R)^2}{H_L+H_R+\lambda} \right] - \gamma$$

**只在 $\text{Gain} > 0$ 时保留分裂**：这就是 XGBoost 的分裂准则 + 预剪枝阈值（$\gamma$）。遍历所有特征的所有候选分裂点取最大增益即可建树。

### 直观验证（平方损失退化）
取 $L = \tfrac12(y-\hat y)^2$：$g_i = \hat y^{(t-1)}-y_i$（残差），$h_i = 1$ 常数。此时 $H_j+\lambda$ 退化为 $|I_j|+\lambda$，$G_j$ 为叶内残差和，最优叶子权重 $w_j^* = -G_j/(|I_j|+\lambda)$ 与「叶内均值收缩」一致——说明 XGBoost 是普通最小二乘回归树的自然推广；而 $\lambda$ 就是岭收缩项。

🧠 直觉解释

XGBoost 把「树的结构」当成可优化的参数：分裂增益 = 「左右子树的二阶梯度统计量之和」比父节点提升多少，再扣掉新增叶子的 γ 成本——大于 0 才分裂，既是最优分裂选择也是正则化预剪枝。
AI面试问答 ⭐⭐ 第 4 题

模型量化（GPTQ / AWQ）为什么能省显存并加速大模型推理？

面试官问：LLM 推理前常做「模型量化」，例如 W8A16、GPTQ 4bit、AWQ。请你解释量化为什么能**压缩显存**并**加速推理**，以及后训练量化（PTQ）如何**控制精度损失**。
--- 以下为答案与解析 ---

📌 回答要点

  • 量化本质与显存账本：把权重从 FP16/BF16 降到 INT8/INT4，位宽减半以上。7B 模型 FP16 权重约 14GB，W8A16（权重 8bit、激活 16bit）降到约 7GB，W4 约 3.5GB，直接降低权重存储与访存带宽。
  • 加速机制（decode 是 memory-bound）：自回归 decode 阶段每生成 1 个 token 都要把全部权重从显存读一遍，访存带宽是瓶颈；权重位宽减半 → 读权重时间减半 → 生成速度接近翻倍。prefill 是 compute-bound，INT8 张量核（Tensor Core）算力提升也能获益。
  • 量化数学：线性量化 q = round(w / scale) + zero_point，反量化 w ≈ scale·(q − zero_point)。对称量化 scale = max|w|/127，常按 128 个权重一组（group-wise）定标以保持精度。
  • PTQ 控制精度损失三招：① RTN 直接四舍五入在 4bit 误差大 → GPTQ 用近似二阶 Hessian 矩阵贪心逐层校正量化误差（把被量化权重的误差按 Hessian 补偿到其余权重）；② AWQ 用激活值统计识别显著通道，对重要通道的权重乘保护缩放因子（等价于极细粒度的混合精度）；③ SmoothQuant 把激活的异常值数学迁移到权重侧（等价缩放），实现 W8A8 激活也可量化。
  • 校准数据：PTQ 通常用几百条无标注样本在每层上校准，确定各层 scale/zero_point，使量化误差与真实激活分布对齐。

⭐ 加分项

  • 工程叠加：量化与 KV Cache 量化（INT8 再省约 50%）、PagedAttention、投机解码等正交组合，长上下文场景收益最大；推理端 INT8 通常 <1% 精度损失，4bit 需分组量化保持。
  • 与蒸馏/LoRA 的关系：蒸馏改「结构」、量化改「精度」，可叠加；LoRA 训练时权重保持 FP16，推理时可先合并再量化。
  • 激活量化难：激活分布动态且存在少数异常值通道，整体 min/max 定标会被拉偏 → 所以 W8A8 常见 SmoothQuant，KV 量化也有专门处理（如 KIVI）。

🔮 追问预测

  • 追问 1：为什么 decode 阶段量化收益大而 prefill 阶段不明显？→ decode 每 token 需读全部权重，是带宽瓶颈（memory-bound），位宽减半直接折算减速 2 倍；prefill 是算术密集（compute-bound），收益来自 INT8 张量核算力而非带宽。
  • 追问 2：RTN 与 GPTQ 差别在哪？→ RTN 独立四舍五入每权重、误差不可控；GPTQ 把已量化权重的误差按 Hessian 逆近似补偿到其余未量化权重，逐层贪心最小化输出（如 layer 输出的均方误差），4bit 下显著优于 RTN。
  • 追问 3：为什么激活比权重难量化？→ 权重训练后分布稳定且近似对称，激活随输入动态变化且存在异常值通道，固定 min/max 会被异常值拉偏 → SmoothQuant 把激活缩放迁移到权重实现 W8A8，或用动态 per-token 量化。
