搜索旋转排序数组

一个原本按升序排列的整数数组 nums，在某个未知的下标 k 处进行了旋转（0 <= k < nums.length）。例如 [0,1,2,4,5,6,7] 在下标 3 处旋转后变为 [4,5,6,7,0,1,2]。

给定旋转后的数组 nums 和一个整数 target，如果 target 存在于数组中则返回它的下标，否则返回 -1。

**要求：时间复杂度 $O(\log n)$。**
输入
nums: List[int] —— 旋转后的升序数组
target: int —— 要查找的目标值
输出
int —— target 的下标，不存在则返回 -1
示例 1
输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4
0 出现在下标 4 处
示例 2
输入：nums = [4,5,6,7,0,1,2], target = 3
输出：-1
3 不在数组中，返回 -1
示例 3
输入：nums = [1], target = 0
输出：-1
单元素数组，0 不在其中
约束
1 <= nums.length <= 5000 -10^4 <= nums[i] <= 10^4 nums 中的值互不相同 nums 已按升序排列并进行了旋转

💡 解题思路

核心思路是利用二分查找。尽管数组被旋转了，但二分后必有一半是严格有序的。每次取 mid 后，先判断哪半边有序：
1. 若 nums[left] <= nums[mid]，说明左半边 [left, mid] 有序。此时若 target 在 [nums[left], nums[mid]) 范围内，则搜左半边，否则搜右半边。
2. 否则右半边 [mid, right] 有序。此时若 target 在 (nums[mid], nums[right]] 范围内，则搜右半边，否则搜左半边。

关键点：每次二分后判断有序半边 + 缩小范围，保证 $O(\log n)$。

📝 参考代码（python）

def search(nums, target):
    left, right = 0, len(nums) - 1
    while left <= right:
        mid = (left + right) // 2
        if nums[mid] == target:
            return mid
        # 左半边有序
        if nums[left] <= nums[mid]:
            if nums[left] <= target < nums[mid]:
                right = mid - 1
            else:
                left = mid + 1
        # 右半边有序
        else:
            if nums[mid] < target <= nums[right]:
                left = mid + 1
            else:
                right = mid - 1
    return -1

⚡ 复杂度分析

时间 O(log n) 空间 O(1)

🎯 考点

二分查找变体、旋转数组的有序半边判断、边界条件处理
算法概念 ⭐ 第 2 题

动态规划的最优子结构性质

关于动态规划（Dynamic Programming）的最优子结构性质，以下哪个说法是**正确**的？
--- 以下为答案与解析 ---
✅ 正确答案：B

💡 解题思路

最优子结构是动态规划适用的两大必要条件之一（另一个是重叠子问题）。其含义是：原问题的最优解可以由其子问题的最优解来构造。这意味着我们可以自底向上或自顶向下地通过求解子问题来得到原问题的解。

🎯 考点

最优子结构定义、动态规划两大必要条件（最优子结构+重叠子问题）、与分治/贪心的区别

🔍 逐项分析

  • A 错误：最优子结构并非要求包含**所有**子问题的最优解，而是说存在一条路径——原问题的最优解由某些子问题的最优解构成。例如 01 背包中，dp[i][w] 只依赖 dp[i-1][w] 和 dp[i-1][w-weight[i]] 两个子问题，不是所有子问题。
  • B 正确：这正是最优子结构的定义。原问题的最优解由子问题的最优解组合构造而成。例如 LIS（最长递增子序列）：dp[i] = max(dp[j] + 1) for all j < i where nums[j] < nums[i]，dp[i] 的最优值由子问题 dp[j] 的最优值构造。
  • C 错误：仅有最优子结构不够，还必须有**重叠子问题**。例如归并排序有最优子结构但子问题不重叠（分治即可），不能用 DP。贪心算法也需要某种最优子结构，但不一定适用 DP。
  • D 错误：最优子结构不要求子问题独立。实际上 DP 中子问题往往高度重叠（如斐波那契、最长公共子序列），正是重叠性使得 DP 比朴素递归更高效。子问题独立是贪心算法的某些适用条件，不是 DP 的要求。
AI公式推导 ⭐⭐⭐ 第 3 题

神经网络反向传播四公式完整推导

考虑一个 $L$ 层全连接前馈神经网络，激活函数为 $\sigma$（sigmoid），损失函数采用均方误差 $C = \frac{1}{2n}\sum_{x} \|y(x) - a^L(x)\|^2$（对单个样本简记 $C = \frac{1}{2}\|y - a^L\|^2$）。

记各层加权输入 $z^l = w^l a^{l-1} + b^l$，各层激活 $a^l = \sigma(z^l)$，定义误差 $\delta^l = \frac{\partial C}{\partial z^l}$。

请完整推导反向传播的**四个基本公式**：
1. 输出层误差公式
2. 误差反向传播公式
3. 权重梯度公式
4. 偏置梯度公式
--- 以下为答案与解析 ---

🎯 考点

链式法则、输出层误差公式、误差反向传播、权重梯度 = 前层激活 × 当前层误差、偏置梯度 = 当前层误差

📐 推导过程

**符号约定**：$a^l$ 为第 $l$ 层激活向量，$z^l$ 为加权输入，$w^l$ 为权重矩阵（$w^l_{jk}$ 表示第 $l-1$ 层第 $k$ 个神经元到第 $l$ 层第 $j$ 个神经元的权重），$b^l$ 为偏置向量，$\sigma$ 逐元素作用于向量，$\odot$ 为 Hadamard 积（逐元素乘）。

---

**公式一：输出层误差**

$$\delta^L = \nabla_a C \odot \sigma'(z^L)$$

推导：由链式法则，
$$\delta^L_j = \frac{\partial C}{\partial z^L_j} = \sum_k \frac{\partial C}{\partial a^L_k} \cdot \frac{\partial a^L_k}{\partial z^L_j}$$

由于 $a^L_k = \sigma(z^L_k)$，故 $\frac{\partial a^L_k}{\partial z^L_j} = \sigma'(z^L_j) \cdot \delta_{kj}$（Kronecker delta，仅当 $k=j$ 时为 1）。

代入得：
$$\delta^L_j = \frac{\partial C}{\partial a^L_j} \cdot \sigma'(z^L_j)$$

写成向量形式：
$$\boxed{\delta^L = \nabla_a C \odot \sigma'(z^L)}$$

对于 MSE 损失，$\nabla_a C = (a^L - y)$，故 $\delta^L = (a^L - y) \odot \sigma'(z^L)$。

---

**公式二：误差反向传播**

$$\delta^l = ((w^{l+1})^T \delta^{l+1}) \odot \sigma'(z^l)$$

推导：由链式法则展开 $\delta^l_j = \frac{\partial C}{\partial z^l_j}$，先对下一层的 $z^{l+1}$ 求和：
$$\delta^l_j = \sum_k \frac{\partial C}{\partial z^{l+1}_k} \cdot \frac{\partial z^{l+1}_k}{\partial z^l_j} = \sum_k \delta^{l+1}_k \cdot \frac{\partial z^{l+1}_k}{\partial z^l_j}$$

而 $z^{l+1}_k = \sum_j w^{l+1}_{kj} a^l_j + b^{l+1}_k = \sum_j w^{l+1}_{kj} \sigma(z^l_j) + b^{l+1}_k$，故：
$$\frac{\partial z^{l+1}_k}{\partial z^l_j} = w^{l+1}_{kj} \cdot \sigma'(z^l_j)$$

代回：
$$\delta^l_j = \sum_k \delta^{l+1}_k \cdot w^{l+1}_{kj} \cdot \sigma'(z^l_j) = \sigma'(z^l_j) \sum_k w^{l+1}_{kj} \delta^{l+1}_k$$

注意到 $\sum_k w^{l+1}_{kj} \delta^{l+1}_k = ((w^{l+1})^T \delta^{l+1})_j$（权重矩阵转置乘以误差向量），写成向量形式：
$$\boxed{\delta^l = ((w^{l+1})^T \delta^{l+1}) \odot \sigma'(z^l)}$$

这就是误差从第 $l+1$ 层反向传播到第 $l$ 层的公式。

---

**公式三：权重梯度**

$$\frac{\partial C}{\partial w^l_{jk}} = a^{l-1}_k \cdot \delta^l_j$$

推导：由链式法则，
$$\frac{\partial C}{\partial w^l_{jk}} = \sum_m \frac{\partial C}{\partial z^l_m} \cdot \frac{\partial z^l_m}{\partial w^l_{jk}} = \delta^l_j \cdot \frac{\partial z^l_j}{\partial w^l_{jk}}$$

因为 $z^l_j = \sum_k w^l_{jk} a^{l-1}_k + b^l_j$，故 $\frac{\partial z^l_j}{\partial w^l_{jk}} = a^{l-1}_k$。

代入得：
$$\boxed{\frac{\partial C}{\partial w^l_{jk}} = a^{l-1}_k \cdot \delta^l_j}$$

直觉：**权重梯度 = 上一层激活值 × 当前层误差**。即进入该权重的信号强度（$a^{l-1}_k$）乘以该权重对误差的影响（$\delta^l_j$）。

---

**公式四：偏置梯度**

$$\frac{\partial C}{\partial b^l_j} = \delta^l_j$$

推导：由链式法则，
$$\frac{\partial C}{\partial b^l_j} = \sum_m \frac{\partial C}{\partial z^l_m} \cdot \frac{\partial z^l_m}{\partial b^l_j} = \delta^l_j \cdot \frac{\partial z^l_j}{\partial b^l_j}$$

因为 $z^l_j = \sum_k w^l_{jk} a^{l-1}_k + b^l_j$，故 $\frac{\partial z^l_j}{\partial b^l_j} = 1$。

代入得：
$$\boxed{\frac{\partial C}{\partial b^l_j} = \delta^l_j}$$

偏置梯度恰好等于该层误差，这是反向传播中最简洁的结论。

---

**算法总结**：
1. 前向传播：逐层计算 $z^l = w^l a^{l-1} + b^l$，$a^l = \sigma(z^l)$
2. 输出层误差：$\delta^L = \nabla_a C \odot \sigma'(z^L)$
3. 反向传播：对 $l = L-1, L-2, \ldots, 2$，计算 $\delta^l = ((w^{l+1})^T \delta^{l+1}) \odot \sigma'(z^l)$
4. 梯度：$\frac{\partial C}{\partial w^l} = \delta^l (a^{l-1})^T$，$\frac{\partial C}{\partial b^l} = \delta^l$

🧠 直觉解释

反向传播本质上是用链式法则将损失函数对输出的偏导逐层传回网络，得到每一层每个参数的梯度。四个公式分别解决：①最后一层误差怎么算，②误差怎么往回传一层，③知道了误差和输入怎么更新权重，④偏置更新恰好等于误差。
AI面试问答 ⭐⭐ 第 4 题

Early Stopping 早停策略的原理与实践

面试官问："在模型训练中，Early Stopping（早停）是一种常用的正则化手段。请详细解释早停的原理、实现方式，以及它与其他正则化方法（如 L2、Dropout）相比有什么优劣。"
--- 以下为答案与解析 ---

📌 回答要点

  • **原理**：在训练过程中持续监控验证集损失（validation loss），当验证集损失连续若干个 epoch 不再下降（或开始上升）时停止训练。其直觉来自于训练曲线的三个阶段——欠拟合阶段（训练/验证损失均下降）、最佳拟合点（验证损失最低）、过拟合阶段（训练损失继续下降但验证损失上升）。早停就是在最佳拟合点附近停住。
  • **实现方式**：设定 patience（耐心值）参数，当验证集损失连续 patience 个 epoch 未刷新最低值时触发停止。同时保存验证集损失最低时的模型权重（best checkpoint），训练结束后恢复为最优权重而非最后一步的权重。
  • **关键超参数**：① patience（容忍多少个 epoch 不改善），② min_delta（判定为"改善"的最小变化阈值，避免微小波动误判），③ restore_best_weights（是否恢复最优权重）。
  • **为什么是正则化**：早停在模型开始过拟合之前就停止训练，相当于限制了模型的复杂度——训练时间越短，模型能拟合的函数复杂度越低。这与限制参数范数（L2）或随机丢弃神经元（Dropout）从不同角度达到抑制过拟合的效果。
  • **与 L2/Dropout 对比**：早停无需修改损失函数或网络结构，是"训练策略层面"的正则化，实施简单、计算开销几乎为零（仅需多维护一个验证集和最优权重副本）。可以与 L2、Dropout 组合使用，实践中三者叠加是常见配置。

⭐ 加分项

  • 早停可以与学习率调度器配合使用：如 ReduceLROnPlateau 也在监控验证集指标，可以先降低学习率再触发早停，给模型更多"挣扎"机会，减少因学习率过大导致的假性不收敛。
  • 在深度学习中，早停的 patience 通常设为 5-20（与数据集规模和模型复杂度相关）；min_delta 应设为一个略大于验证集指标噪声水平的值，可用实验估计。
  • 早停的理论基础：它在参数空间中等价于 L2 正则化的效果（在一定假设下，提前停止 SGD 相当于在损失函数中加入 L2 惩罚项，正则化强度与训练步数成反比），称为半正则化（semi-regularization）。
  • 工程实践中的注意事项：验证集不宜太小（否则指标噪声大、容易误触早停）；时间敏感场景下可设置最大 epoch 数作为兜底；分布式训练中需要确保所有节点使用相同的验证集和相同的判断逻辑。

🔮 追问预测

  • 追问1："如果验证集损失在下降过程中有波动， patience 设太小会不会过早停止？" → 回答：是的，可以通过增大 patience、设置 min_delta 阈值、或使用验证集指标的滑动平均来平滑噪声，避免因短期波动误判。
  • 追问2："早停和 L2 正则化的等价关系是什么？" → 回答：在二次损失和梯度下降的设定下，训练 $t$ 步后的参数 $w(t) \approx (I - \eta H)^t w(0)$，而 L2 正则化的解满足 $w_\lambda = (H + \lambda I)^{-1} H w_0$。可以证明存在一个映射 $t \leftrightarrow \lambda$，使得有限步训练的效果等价于某个 $\lambda$ 的 L2 正则化。训练步数越少等价于 $\lambda$ 越大（正则化越强）。
  • 追问3："分布式训练中如何实现早停？" → 回答：需要所有 worker 对验证集做同步评估（通常在某一 rank 上做验证后广播结果），且只有一个进程负责判断和发起停止信号。需注意各 rank 的 random seed 差异和 batch 划分方式对验证指标的影响。
