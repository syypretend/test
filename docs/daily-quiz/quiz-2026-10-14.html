算法编程 ⭐⭐ 第 1 题

数据流的中位数（对顶堆）

设计一个**在线数据流**结构：依次接收一个整数序列中的每个数，每接收一个数后都要返回当前已接收全部元素的中位数。定义：若当前元素个数为奇数，中位数为排序后正中间那个数；若为偶数，为中间两个数的**平均值**（返回浮点数）。

实现函数 solve(nums)：输入完整整数数组，返回一个等长列表，第 i 个元素表示加入 nums[0..i] 后的中位数。要求用**两个堆（对顶堆）**实现，使得每次插入与取中位数都是 O(log n)。
输入
一个整数数组 nums（1 <= len(nums) <= 10^5，元素在 int 范围内，可为负）。
输出
返回一个 float 列表，长度为 len(nums)，每个元素为对应前缀的中位数。
示例 1
输入：[2,1,3,5,4]
输出：[2.0, 1.5, 2.0, 2.5, 3.0]
加入2 -> 中位2；加入1 -> (1,2)中位1.5；加入3 -> (1,2,3)中位2；加入5 -> (1,2,3,5)中位(2+3)/2=2.5；加入4 -> (1,2,3,4,5)中位3。
示例 2
输入：nums=[10,20,30,40,50]
输出：[10.0, 15.0, 20.0, 25.0, 30.0]
奇数个取中间值，偶数个取两中间值平均。
约束
1 <= n <= 10^5；整数数值范围 [-10^6, 10^6]。时间复杂度要求总体 O(n log n)，空间 O(n)。

--- 以下为答案与解析 ---

💡 解题思路

维护两个堆并把数据分成两半：**大顶堆 max_heap** 存较小的一半（元素存负数以便用 Python 最小堆模拟大顶堆），**小顶堆 min_heap** 存较大的一半。核心不变式：① max_heap 中所有元素都 <= min_heap 中所有元素（即 max_heap 堆顶 <= min_heap 堆顶）；② 两堆元素个数相差不超过 1。

**插入流程**：新数先入 max_heap；若 max_heap 堆顶（较小半的最大值）大于 min_heap 堆顶（较大半的最小值），则把前者弹出压入 min_heap，恢复不变式①；再平衡两堆大小（任意一堆多出超过 1 个时，把堆顶移给对方），保证不变式②。

**取中位数**：若 max_heap 多一个，中位数为 max_heap 堆顶；若 min_heap 多一个，中位数为 min_heap 堆顶；两堆相等则取两堆顶平均值。每次插入 O(log n)，取中位数 O(1)。

📝 参考代码（python）

import heapq

def solve(nums):
    # 对顶堆求数据流中位数
    # max_heap: 大顶堆，存"较小的一半"（元素存负数，堆顶是较小一半的最大值）
    # min_heap: 小顶堆，存"较大的一半"，堆顶是较大一半的最小值
    max_heap = []
    min_heap = []
    result = []
    for num in nums:
        # 1) 新元素先放入较小堆（max_heap，存负数）
        heapq.heappush(max_heap, -num)
        # 2) 保证 max_heap 堆顶 <= min_heap 堆顶，否则交换堆顶
        if max_heap and min_heap and -max_heap[0] > min_heap[0]:
            heapq.heappush(min_heap, -heapq.heappop(max_heap))
        # 3) 平衡两堆大小，保证 |len(max)-len(min)| <= 1
        if len(max_heap) > len(min_heap) + 1:
            heapq.heappush(min_heap, -heapq.heappop(max_heap))
        if len(min_heap) > len(max_heap) + 1:
            heapq.heappush(max_heap, -heapq.heappop(min_heap))
        # 4) 取中位数
        if len(max_heap) > len(min_heap):
            result.append(float(-max_heap[0]))
        elif len(min_heap) > len(max_heap):
            result.append(float(min_heap[0]))
        else:
            result.append((-max_heap[0] + min_heap[0]) / 2.0)
    return result

⚡ 复杂度分析

时间 O(n log n)（每次插入 O(log n)） 空间 O(n)（两个堆存储全部元素）

🎯 考点

对顶堆的中位数结构；用负数模拟大顶堆；大小平衡不变式；大顶堆与小顶堆的大小差控制奇偶判断

最小生成树算法辨析（Kruskal vs Prim）

关于求无向连通带权图最小生成树（MST）的两种经典算法 Kruskal 与 Prim，**以下哪个说法正确**？
--- 以下为答案与解析 ---
✅ 正确答案：A

💡 解题思路

判断两个关键点：①Kruskal 判环用**并查集（Union-Find）**而非 DFS；②两种算法的**适用场景**（稀疏 vs 稠密）与复杂度。

🎯 考点

Kruskal=边排序+并查集、适合稀疏图；Prim=点扩展、适合稠密图；两者均基于贪心且有 MST 最优性保证；负权不影响 MST 正确性（只影响最短路）。

🔍 逐项分析

  • A 正确：Kruskal 将 E 条边升序排序（O(E log E)），从小到大逐条尝试，用并查集合并两端顶点、发现两端已在同一连通分量则跳过（O(α(V)) 近似 O(1) 均摊）。E 较小时整体高效，适合稀疏图。
  • B 错误：Prim 从顶点出发「点扩展」式生长，稠密图用邻接矩阵实现达到 O(V²)；稀疏图应优先选 Kruskal。选项把两者的适用场景说反了。
  • C 错误：Kruskal 判环用**并查集**而非 DFS；若每步都用 DFS 判环，总复杂度退化到 O(E·(V+E))。且 Kruskal 适合稀疏而非稠密图。
  • D 错误：MST 完全允许负权边，负权不影响「切割性质/环性质」保证的贪心正确性，Kruskal 与 Prim 对负权图仍能得到最小生成树。负权只会破坏**最短路**的某些假设（如 Dijkstra），与 MST 无关。
AI公式推导 ⭐⭐ 第 3 题

朴素贝叶斯分类器的后验概率推导

请从**贝叶斯定理**出发，逐步推导朴素贝叶斯（Naive Bayes）分类器如何计算后验概率并进行分类决策。要求：明确写出（1）贝叶斯定理公式及为何可忽略分母；（2）**条件独立（朴素）假设**如何把联合概率分解为各特征概率的乘积；（3）为何取对数不改变 argmax 且能避免下溢；（4）给出先验与两类类别条件分布（离散多项式+平滑 / 连续高斯）的极大似然估计式。
--- 以下为答案与解析 ---

🎯 考点

贝叶斯定理 + 分母省略；朴素(条件独立)假设把联合分解成乘积；log 变换保 argmax 且防下溢；MLE+平滑 估计先验与类别条件分布；区分离散多项式/连续高斯两类模型。

📐 推导过程

设样本特征为 $\mathbf{x}=(x_1,x_2,\dots,x_d)$，类别 $C_k,\ k=1,\dots,K$。

**第 1 步：贝叶斯定理（后验）**
$$
P(C_k \mid \mathbf{x}) = \frac{P(\mathbf{x} \mid C_k)\,P(C_k)}{P(\mathbf{x})}
$$
对固定输入 $\mathbf{x}$，分母 $P(\mathbf{x})$ 对所有类别是**相同常数**，不改变各类后验的相对大小，故分类决策可省略分母：
$$
\hat{y}=\arg\max_k P(C_k\mid \mathbf{x}) = \arg\max_k\, P(\mathbf{x}\mid C_k)\,P(C_k)
$$
即「后验 ∝ 似然 × 先验」。

**第 2 步：朴素（条件独立）假设**
直接估计 $P(\mathbf{x}\mid C_k)$ 需要指数级参数（$d$ 维特征联合分布），数据量不足以估计。朴素贝叶斯假设：**给定类别 $C_k$ 时，各特征条件独立**，于是联合似然可分解为单变量乘积：
$$
P(\mathbf{x}\mid C_k) = \prod_{i=1}^{d} P(x_i \mid C_k)
$$

**第 3 步：取对数化简（不改变 argmax，且防下溢）**
当 $d$ 较大时，连乘的多个小于 1 的概率会溢出下界趋近 0（下溢）。$\log$ 严格单调，$\arg\max$ 不变，且把乘积变成求和：
$$
\hat{y} = \arg\max_k\Big[\log P(C_k) + \sum_{i=1}^{d}\log P(x_i \mid C_k)\Big]
$$

**第 4 步：极大似然估计参数（两类特征分布模型）**
- 先验：$\hat{P}(C_k)=N_k/N$（$N_k$ 为 $C_k$ 类样本数，$N$ 为总样本数）。
- **离散特征（多项式模型）+ 拉普拉斯平滑**：设第 $i$ 个特征第 $j$ 个取值在 $C_k$ 类的计数为 $N_{kij}$，该特征共有 $m_i$ 个取值，则
$$
\hat{P}(x_i=a_{ij}\mid C_k) = \frac{N_{kij}+\alpha}{N_k + \alpha\, m_i}
$$
$\alpha=1$ 即拉普拉斯平滑（加 1 平滑），防止某个取值在训练集中未出现导致概率为 0。
- **连续特征（高斯朴素贝叶斯）**：假设 $x_i\mid C_k \sim \mathcal{N}(\mu_{ki},\sigma_{ki}^2)$，用类内样本估计：$\hat{\mu}_{ki}=\tfrac1{N_k}\sum_{x_n\in C_k}x_{ni}$，$\hat{\sigma}_{ki}^2=\tfrac1{N_k}\sum_{x_n\in C_k}(x_{ni}-\hat{\mu}_{ki})^2$。

**第 5 步：决策**
对每个测试样本，代入 $\hat{P}(C_k)$ 与各 $\hat{P}(x_i\mid C_k)$，选对数后验最大者：
$$
\hat{y} = \arg\max_k \Big[\log\hat{P}(C_k) + \sum_{i=1}^{d}\log\hat{P}(x_i\mid C_k)\Big]
$$

🧠 直觉解释

朴素贝叶斯牺牲了「特征间相关性」的建模能力，换取极低的参数复杂度与样本需求——把高维联合分布拆成 d 个一维边缘分布，因此参数少、速度快，在文本分类、垃圾邮件过滤等「特征近似独立」的场景依然表现强健。
AI面试问答 ⭐⭐ 第 4 题

知识蒸馏：为什么小模型能逼近（甚至超越）大模型？

「知识蒸馏（Knowledge Distillation）」是让参数量小得多的学生模型（student）逼近甚至超越大模型（teacher）的经典压缩手段。请从**信息量与训练目标**的角度，解释蒸馏为什么有效，并说出温度 T 与 KL 散度损失的作用。
--- 以下为答案与解析 ---

📌 回答要点

  • 暗知识信息量更大：one-hot 硬标签只告诉「答案是哪个类别」，而 teacher 输出的软概率 logits 还携带「类间相似度」（例如一张狗图 teacher 给猫 0.7、狗 0.3，说明两者特征接近）——这些 soft label 的信息量远大于硬标签，是 student 学不到的暗知识。
  • 温度软化分布：用 softmax(z/T)（T>1）把 teacher 的 logits 摊平，放大类别间的相对差距，让「相似类」的信息能被 student 学走；蒸馏损失即 softmax(z_t/T) 与 softmax(z_s/T) 的 KL 散度。
  • 蒸馏目标 = 软目标 KL 损失 + 硬标签交叉熵损失（加权 α、β），既迁移 teacher 的知识，又保留真实标签的强监督，student 由此学到更平滑的决策边界。
  • 训练流程是「离线教师-学生」：先训练出大网络 teacher，再固定它，用其软输出（离线）监督小网络 student；student 参数少却通过拟合 teacher 的函数映射获得正则化与更优特征，从而逼近甚至反超 teacher。
  • 为什么有效本质上是「函数拟合」：小模型硬学 one-hot 容易过拟合且抓不住类间结构；蒸馏让小模型去拟合 teacher 学到的分布，等价于在更高质量、更平滑的目标上优化，训练更稳、泛化更好。

⭐ 加分项

  • 温度 T 仅在训练时取 1~7 左右软化，推理时回退到 T=1；也可同时混用软、硬目标做多任务损失。
  • 蒸馏可与量化/剪枝互补：蒸馏属于「重训式」压缩，常与 INT8/INT4 量化、结构化剪枝结合，先蒸后压能显著减损。
  • 延伸：特征蒸馏（FitNets 对齐中间层特征）、自蒸馏（student 用 teacher 即大模型自身/同构大网络）、网络蒸馏（GNN）等变体。
  • LLM 场景：教师蒸馏可用 PPO/DPO 或直接用 teacher logits 做监督微调（如 Alpaca/Vicuna 对齐式微调、miniLM 蒸馏），其机制与图像分类的静态 softmax 蒸馏有异同。
  • student 有时反超 teacher 的原因：teacher 在带噪真实标签上训练，student 学其软分布等价于学「去噪平滑后的目标」，正则化更强，或 student 结构更聚焦于任务。

🔮 追问预测

  • 追问：温度 T 增大到底改变了什么？回答思路：L=KL(σ(z_t/T)||σ(z_s/T))，对 T 求导得 ∂L/∂z_s=(σ(z_s/T)-σ(z_t/T))/T；T 越大 softmax 越平坦、梯度中非最高类的权重被放大，student 对「难例」和类间相似度更敏感。
  • 追问：蒸馏与直接在小数据集上训练小模型有何本质区别？回答思路：teacher 的软标签提供了比 one-hot 更丰富的监督（类间几何 + 置信度），相当于一种强正则；在小数据上硬训小模型更易过拟合，蒸馏等价于把 teacher 学到的泛化先验迁移给学生。
  • 追问：LLM 的知识蒸馏与图像分类蒸馏有何不同？回答思路：LLM 是自回归逐 token 生成，teacher 可在每个 token 的 logits 上提供分布（token-level KD），或用生成样本做 pseudo-label；常配合 SFT/RLHF 等对齐，成本更高，需权衡「蒸馏」与「直接用学生生成」。
