算法编程 ⭐⭐ 第 1 题

删除链表的倒数第 N 个节点

给你一个链表的头（以数组 nums 表示），删除链表的倒数第 n 个节点，并返回删除后链表的头（同样以数组表示）。要求**只遍历链表一次**（快慢指针技巧），不能先求长度再删。例如链表 1→2→3→4→5 的倒数第 2 个节点是 4，删除后得到 1→2→3→5。
输入
参数 `nums`：链表元素数组（按链表顺序）；参数 `n`：要删除的倒数第 n 个节点（1 ≤ n ≤ len(nums)，保证合法）。
输出
返回删除后的链表数组。
示例 1
输入：nums = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
倒数第 2 个节点是值为 4 的节点，删除后链表为 1→2→3→5。
示例 2
输入：nums = [1], n = 1
输出：[]
链表中只有一个节点，删除后链表为空。
约束
1 ≤ n ≤ len(nums) ≤ 10^5；-10^4 ≤ nums[i] ≤ 10^4；要求一次遍历完成（空间 O(1)）。

💡 解题思路

**快慢指针 + 哑节点**：在头节点前加一个哑节点（dummy），让快指针 fast 先走 n 步，然后快慢指针同步前进；当 fast 走到链表末尾时，慢指针 slow 恰好停在待删节点的**前一个**节点，执行 slow.next = slow.next.next 即可完成删除。哑节点统一处理“删除头节点”的边界（n = len(nums) 时无需特判）。

📝 参考代码（python）

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

def solve(nums, n):
    # 1. 用数组建链表（哑节点统一处理头节点的删除）
    dummy = ListNode(0)
    tail = dummy
    for v in nums:
        tail.next = ListNode(v)
        tail = tail.next

    # 2. 快指针先走 n 步，与慢指针拉开 n 个节点的差距
    fast = dummy
    slow = dummy
    for _ in range(n):
        fast = fast.next

    # 3. 快指针走到链表末尾时，慢指针恰好停在待删节点的前一个节点
    while fast.next:
        fast = fast.next
        slow = slow.next

    # 4. 跳过待删节点，完成删除
    slow.next = slow.next.next

    # 5. 链表转回数组返回
    res = []
    p = dummy.next
    while p:
        res.append(p.val)
        p = p.next
    return res

⚡ 复杂度分析

时间 O(n)（每个节点最多被访问一次） 空间 O(1)（除返回数组外，只用了哑节点与两个指针）

🎯 考点

链表双指针（快慢指针）、哑节点简化边界、单次遍历；链表与数组的相互转换。

🔍 逐项分析

  • A 错：方向说反。求「下一个更大元素」维护的是从栈顶到栈底单调递减（即栈内元素自顶向下递增）的栈——新元素比栈顶大时，栈顶的「下一个更大元素」就是新元素，因此要先弹出所有比新元素小的栈顶，而不是直接入栈。
  • B 错：复杂度结论错误。单调栈的核心性质是**每个元素最多入栈一次、出栈一次**，均摊下来每次操作 O(1)，总复杂度 O(n)，不是 O(n²)。
  • C 对：这正是单调栈的均摊 O(n) 原理——元素弹栈时，弹出的元素与入栈的新元素构成「下一个更大/更小」关系。
  • D 错：混淆两种结构。滑动窗口最大值时，窗口左端元素滑出后需要**从队首（另一端）移除**，栈只能从一端出入，无法做到；因此必须用**双端队列实现的单调队列**（队首维护窗口移出，队尾维护单调性）。
AI公式推导 ⭐⭐ 第 3 题

缩放点积注意力：为什么除以 √d_k

缩放点积注意力（Scaled Dot-Product Attention）的分数定义为：

$$\text{score}(q, k) = \frac{q \cdot k}{\sqrt{d_k}}$$

请从**概率论**角度推导：为什么点积要除以 $\sqrt{d_k}$？要求完成三件事：

1. 在「$q, k$ 各分量独立、均值为 0、方差为 1」的假设下，推导点积 $q \cdot k$ 的**方差**；
2. 说明不缩放时，大维度 $d_k$ 会给 softmax 带来什么问题（梯度层面）；
3. 给出缩放后的方差，并解释缩放因子为何取 $\sqrt{d_k}$ 而非 $d_k$。
--- 以下为答案与解析 ---

🎯 考点

独立同分布假设下方差的可加性；点积尺度随 √d_k 增长；softmax 饱和区与梯度消失；标准差归一化（除以 √d_k 而非 d_k）。

📐 推导过程

**第 1 步：符号与假设**

设 $q, k \in \mathbb{R}^{d_k}$，各分量 $q_i, k_i$ 之间互相独立，且

$$E[q_i] = E[k_i] = 0, \qquad \mathrm{Var}(q_i) = \mathrm{Var}(k_i) = 1$$

（即每个分量量级为 $O(1)$，与随机初始化后向量各分量量级一致。）

**第 2 步：点积的期望**

$$E[q \cdot k] = E\left[\sum_{i=1}^{d_k} q_i k_i\right] = \sum_{i=1}^{d_k} E[q_i k_i] = \sum_{i=1}^{d_k} E[q_i]E[k_i] = 0$$

其中用到了独立性：$E[q_i k_i] = E[q_i]E[k_i]$。

**第 3 步：点积的方差（关键步骤）**

先看单个乘积项 $q_i k_i$：

$$\mathrm{Var}(q_i k_i) = E[(q_i k_i)^2] - \big(E[q_i k_i]\big)^2 = E[q_i^2 k_i^2] - 0$$

由独立性 $E[q_i^2 k_i^2] = E[q_i^2]E[k_i^2]$；又因为 $E[q_i]=0$、$\mathrm{Var}(q_i)=1$，有

$$E[q_i^2] = \mathrm{Var}(q_i) + E[q_i]^2 = 1 + 0 = 1$$

同理 $E[k_i^2] = 1$。代入得

$$\mathrm{Var}(q_i k_i) = 1 \times 1 = 1$$

由于各分量独立，方差可直接相加：

$$\mathrm{Var}(q \cdot k) = \sum_{i=1}^{d_k} \mathrm{Var}(q_i k_i) = d_k$$

即点积的标准差为 $\sqrt{d_k}$——**点积的量级随维度以 $\sqrt{d_k}$ 增长**。

**第 4 步：不缩放时的梯度问题**

softmax 定义为

$$\mathrm{softmax}(z)_i = \frac{e^{z_i}}{\sum_{j=1}^{n} e^{z_j}}$$

当 $d_k$ 较大（如 64、128）时，点积分布的标准差 $\sqrt{d_k}$ 随之变大，部分 logit 绝对值明显超过 1，各分数差距被放大，softmax 输出趋向尖锐（接近 one-hot）。此时多数位置的预测概率接近 0 或 1，进入 softmax 的饱和区（导数趋近于 0），反向传播时梯度消失，训练变慢甚至不稳定。

**第 5 步：缩放后的方差与结论**

$$\mathrm{Var}\!\left(\frac{q \cdot k}{\sqrt{d_k}}\right) = \frac{1}{d_k}\mathrm{Var}(q \cdot k) = \frac{d_k}{d_k} = 1$$

缩放后点积方差恒为 1，与维度 $d_k$ 无关，softmax 输入始终处于温和量级，梯度稳定。由于我们要归一化的是**标准差**（量级），所以除以 $\sqrt{d_k}$（方差开方）而非 $d_k$：除以 $\sqrt{d_k}$ 恰好使方差归一到 1。

🧠 直觉解释

除以 $\sqrt{d_k}$ 就是把点积的“尺度”钉回 $O(1)$：维度越高、点积方差越大，若不缩放 softmax 会趋于尖锐导致梯度消失；缩放到方差恒为 1 后，注意力分数始终温和，训练稳定。
AI面试问答 ⭐⭐ 第 4 题

分类为什么用交叉熵而不是 MSE

面试官提问：

「分类问题的输出层通常用 softmax + 交叉熵（Cross-Entropy），为什么不用平方误差（MSE）？请从梯度、概率、信息论三个角度解释。」
--- 以下为答案与解析 ---

📌 回答要点

  • **梯度视角（最核心）**：设 $z$ 为 logits，$p=\mathrm{softmax}(z)$，$y$ 为 one-hot 标签。交叉熵 $L_{CE}=-\sum_i y_i \log p_i$ 对 $z_i$ 的梯度是 $p_i - y_i$，量级 $O(1)$，误差越大梯度越大，无饱和问题；而 MSE + softmax 的梯度含 $p_i(1-p_i)$ 因子，当 $p_i \to 0$ 或 $p_i \to 1$ 时梯度消失——恰恰在分错（$p$ 接近 0 的目标类）时几乎学不动。
  • **概率**：交叉熵最小化等价于对 one-hot 标签做**最大似然估计（MLE）**：$L_{CE} = -\log p_y$，最小化它就是最大化真实类别的预测概率；而 MSE 对应高斯噪声假设下的 MLE，适合连续回归目标，对离散的 0/1 类别标签度量并不自然。
  • **信息论**：交叉熵可分解为熵与 KL 散度：$H(p,q)=H(p)+D_{KL}(p \| q)$。真实分布 $p$ 的熵 $H(p)$ 是常数，最小化交叉熵等价于最小化预测分布与真实分布的 KL 散度，目标是指概率分布逼近；MSE 是欧氏距离，度量的是数值误差，与“分布逼近”的目标不匹配。
  • **数值稳定性**：工程实现通常把 softmax 与 log 融合（如 PyTorch 的 CrossEntropyLoss 内置 log-softmax），避免 log(0) 下溢；且 CE 与 softmax 的组合在 logits 线性部分关于类别是凸的，梯度形式干净。

⭐ 加分项

  • 回归任务用 MSE（连续值、高斯噪声 MLE）；多标签分类用 BCE（sigmoid + 二元交叉熵），而不是多类 CE。
  • 知识蒸馏中教师输出为“软标签”时仍用交叉熵（或 KL 散度）而非 MSE：软分布的信息比硬标签更丰富，CE 对分布差异更敏感。
  • 若最后一层不用 softmax（线性输出），MSE 也可用于分类，但会丧失概率解释，且分类问题默认组合仍是 softmax + CE。

🔮 追问预测

  • 追问：请推导 softmax + CE 的梯度？—— 由 $\partial p_j/\partial z_i = p_j(\delta_{ij} - p_i)$，分 $i$ 为真实类与不是两种情况合并，得 $\partial L/\partial z_i = p_i - y_i$，与之前的“梯度干净”呼应。
  • 追问：那回归为什么常用 MSE 而不用 MAE？—— MSE 处处可导、对大误差更敏感，误差服从高斯分布时即 MLE；MAE 对离群点更鲁棒（拉普拉斯分布假设）但零点不可导；实践中可换 Huber 损失结合两者。
  • 追问：标签平滑（Label Smoothing）与交叉熵的关系？—— 把 one-hot 目标软化（如 ε 均分到所有类），等价于在 CE 上加入对均匀分布的 KL 正则，可缓解过拟合、抑制过置信，属于 CE 的改进变体。
