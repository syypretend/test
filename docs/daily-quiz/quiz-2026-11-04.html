算法编程 ⭐⭐ 第 1 题

编辑距离（Levenshtein Distance）

给你两个字符串 word1 和 word2，请返回将 word1 转换成 word2 所使用的最少操作数。

每次操作可以对任意一个字符串执行以下三种动作之一：

1. 插入一个字符；
2. 删除一个字符；
3. 替换一个字符。

这是二维动态规划的经典题：设 $dp[i][j]$ 为 word1 前 $i$ 个字符转成 word2 前 $j$ 个字符的最少操作数，思考末尾字符相同与不同两种情况，写出状态转移方程。
输入
两个字符串 word1、word2，以 Python 函数参数按顺序传入。
输出
返回一个整数，表示最少操作数。
示例 1
输入：word1 = "horse", word2 = "ros"
输出：3
horse → rorse（把 h 替换成 r）→ rose（删除 r）→ ros（删除 e），共 3 步。
示例 2
输入：word1 = "intention", word2 = "execution"
输出：5
intention → inention（删 t）→ enention（i 换 e）→ exention（n 换 x）→ exection（n 换 c）→ execution（插 u），共 5 步。
约束
0 <= word1.length, word2.length <= 500；字符串仅包含小写英文字母。

--- 以下为答案与解析 ---

💡 解题思路

状态定义：$dp[i][j]$ = word1[:i] 变成 word2[:j] 的最少操作数。

边界：$dp[i][0] = i$（全部删除），$dp[0][j] = j$（全部插入）。

转移：
- 若 word1[i-1] == word2[j-1]，末字符已经匹配，不需要操作：$dp[i][j] = dp[i-1][j-1]$；
- 否则在三种操作中取最小再 +1：
$$dp[i][j] = 1 + \min\big(dp[i-1][j],\ dp[i][j-1],\ dp[i-1][j-1]\big)$$
其中 $dp[i-1][j]+1$ 是删除 word1[i-1]，$dp[i][j-1]+1$ 是插入 word2[j-1]，$dp[i-1][j-1]+1$ 是把 word1[i-1] 替换成 word2[j-1]。

空间优化：每一行只依赖上一行与当前行左侧，可用一维数组滚动，但必须用变量 prev_diag 保存左上角的值，否则会被当前行覆盖。

📝 参考代码（python）

def min_distance(word1: str, word2: str) -> int:
    """编辑距离：一维滚动数组实现，时间 O(mn)，空间 O(n)。"""
    m, n = len(word1), len(word2)

    # dp[j] 表示「当前处理到的 word1 前缀」转换到 word2[:j] 的最小操作数
    # 初始为第 0 行：空串 -> word2[:j] 需要 j 次插入
    dp = list(range(n + 1))

    for i in range(1, m + 1):
        prev_diag = dp[0]          # 保存 dp[i-1][j-1]，即左上角
        dp[0] = i                  # 第 i 行第 0 列：word1[:i] -> 空串需 i 次删除

        for j in range(1, n + 1):
            tmp = dp[j]            # 覆盖前先存下 dp[i-1][j]（正上方）
            if word1[i - 1] == word2[j - 1]:
                # 末字符相同，不需要新操作，直接继承左上角
                dp[j] = prev_diag
            else:
                # 三者取最小：删除(左) / 插入(上) / 替换(左上)，再 +1
                dp[j] = 1 + min(dp[j], dp[j - 1], prev_diag)
            prev_diag = tmp        # 供下一列使用

    return dp[n]

⚡ 复杂度分析

时间 O(m·n)，m、n 为两串长度 空间 O(n)（一维滚动数组；未优化时为 O(m·n)）

🎯 考点

二维 DP 的状态定义与边界、三种操作的转移来源、滚动数组的左上角保护
算法概念 ⭐⭐ 第 2 题

跳表（Skip List）：随机化如何带来期望 O(log n)？

跳表是在有序链表上叠加多层索引的结构，Redis 的有序集合（zset）就用它实现。关于它的复杂度与维护方式，下列说法正确的是？
--- 以下为答案与解析 ---
✅ 正确答案：B

💡 解题思路

跳表用「抛硬币」式的随机化代替严格平衡：每个节点以概率 $p$（常取 $1/2$）晋升到上一层，直到失败为止。节点出现在第 $k$ 层的概率是 $p^{k-1}$，因此第 $k$ 层期望节点数为 $n p^{k-1}$，当 $n p^{k-1} \approx 1$ 时得到期望层数 $L \approx \log_{1/p} n$。在每层期望比较常数个节点，故查询期望 $O(\log n)$。

🎯 考点

期望复杂度 vs 最坏复杂度、随机化平衡思想、与平衡树的实现代价对比、Redis zset 的应用

🔍 逐项分析

  • 错误。跳表没有强制「每层减半」，最坏情况（随机数极端不利）仍可能是 $O(n)$；$O(\log n)$ 是期望而非最坏复杂度。
  • 正确。随机晋升使结构以高概率保持近似平衡，且无需旋转；插入只需修改各层前驱指针，删除同理。
  • 错误。跳表完全不做旋转，平衡性来自随机化；这正是它实现比红黑树简单的原因。
  • 错误。删除只需在各层摘除该节点并修改相邻指针，索引自然保持有效，无需重建。
AI公式推导 ⭐⭐⭐ 第 3 题

VAE 的 ELBO：从对数边缘似然到重构项 + KL 项

变分自编码器（VAE）最大化数据对数似然 $\log p_\theta(x)$，但直接计算需要对隐变量积分，通常不可解。请完成：

1. 引入近似后验 $q_\phi(z\mid x)$，推导出证据下界（ELBO），并证明 $\log p_\theta(x) = \text{ELBO} + \mathrm{KL}(q_\phi(z\mid x)\,\|\,p_\theta(z\mid x))$；
2. 把 ELBO 拆成「重构项 − KL 项」；
3. 设 $q_\phi(z\mid x)=\mathcal{N}(\mu,\mathrm{diag}(\sigma^2))$、先验 $p(z)=\mathcal{N}(0,I)$，推导 KL 项的闭式解；
4. 说明重参数化技巧 $z=\mu+\sigma\odot\varepsilon$ 为什么是必要的。
--- 以下为答案与解析 ---

🎯 考点

Jensen/期望形式的变分下界、KL 非负性、对角高斯 KL 闭式解、重参数化的可导性动机

📐 推导过程

第 0 步：符号约定

- $x$：观测数据；$z$：隐变量；$\theta$：解码器（生成网络）参数；$\phi$：编码器（推断网络）参数。
- $p_\theta(x,z)=p(z)p_\theta(x\mid z)$，其中先验 $p(z)=\mathcal{N}(0,I)$。
- $q_\phi(z\mid x)$ 是任意一个关于 $z$ 的概率密度（要求绝对连续）。

第 1 步：把对数似然写成期望形式

对任意 $q_\phi(z\mid x)>0$，有 $\int q_\phi(z\mid x)\,dz=1$，因此

$$\log p_\theta(x)=\log p_\theta(x)\int q_\phi(z\mid x)\,dz=\int q_\phi(z\mid x)\log p_\theta(x)\,dz=\mathbb{E}_{q_\phi(z\mid x)}\big[\log p_\theta(x)\big].$$

第 2 步：乘除 $q_\phi(z\mid x)$ 构造可分解项

由贝叶斯公式 $p_\theta(x)=\dfrac{p_\theta(x,z)}{p_\theta(z\mid x)}$，代入得

$$\log p_\theta(x)=\mathbb{E}_{q}\left[\log\frac{p_\theta(x,z)}{p_\theta(z\mid x)}\right]=\mathbb{E}_{q}\left[\log\frac{p_\theta(x,z)}{q_\phi(z\mid x)}\right]+\mathbb{E}_{q}\left[\log\frac{q_\phi(z\mid x)}{p_\theta(z\mid x)}\right].$$

第二项正是 KL 散度：

$$\mathbb{E}_{q_\phi(z\mid x)}\left[\log\frac{q_\phi(z\mid x)}{p_\theta(z\mid x)}\right]=\mathrm{KL}\big(q_\phi(z\mid x)\,\|\,p_\theta(z\mid x)\big)\ge 0.$$

于是

$$\log p_\theta(x)=\underbrace{\mathbb{E}_{q_\phi(z\mid x)}\left[\log\frac{p_\theta(x,z)}{q_\phi(z\mid x)}\right]}_{\text{ELBO}(\theta,\phi;x)}+\mathrm{KL}\big(q_\phi(z\mid x)\,\|\,p_\theta(z\mid x)\big).$$

因为 KL $\ge 0$，所以 $\text{ELBO}\le \log p_\theta(x)$，最大化 ELBO 即在下界逼近真实似然；当 $q_\phi(z\mid x)=p_\theta(z\mid x)$ 时 KL 为 0，下界取等。

第 3 步：拆成重构项与 KL 项

把联合分布拆开 $p_\theta(x,z)=p(z)p_\theta(x\mid z)$：

$$\text{ELBO}=\mathbb{E}_{q_\phi(z\mid x)}\big[\log p_\theta(x\mid z)\big]-\mathbb{E}_{q_\phi(z\mid x)}\left[\log\frac{q_\phi(z\mid x)}{p(z)}\right]=\underbrace{\mathbb{E}_{q}\big[\log p_\theta(x\mid z)\big]}_{\text{重构项}}-\underbrace{\mathrm{KL}\big(q_\phi(z\mid x)\,\|\,p(z)\big)}_{\text{正则项}}.$$

重构项鼓励隐变量保留能还原 $x$ 的信息；KL 项把近似后验拉向标准正态先验，保证隐空间连续、可采样。

第 4 步：对角高斯下 KL 的闭式解

设维度为 $d$，$q_\phi(z\mid x)=\prod_{j=1}^{d}\mathcal{N}(\mu_j,\sigma_j^2)$，$p(z)=\prod_{j=1}^{d}\mathcal{N}(0,1)$。KL 按维度可加，逐维计算：

$$\mathrm{KL}\big(\mathcal{N}(\mu,\sigma^2)\,\|\,\mathcal{N}(0,1)\big)=\int \mathcal{N}(z;\mu,\sigma^2)\log\frac{\mathcal{N}(z;\mu,\sigma^2)}{\mathcal{N}(z;0,1)}\,dz.$$

代入密度并取对数：

$$\log\frac{\mathcal{N}(z;\mu,\sigma^2)}{\mathcal{N}(z;0,1)}=-\frac{(z-\mu)^2}{2\sigma^2}-\frac{1}{2}\log\sigma^2+\frac{z^2}{2}.$$

利用 $\mathbb{E}[z]=\mu$、$\mathbb{E}[(z-\mu)^2]=\sigma^2$、$\mathbb{E}[z^2]=\mu^2+\sigma^2$，逐项求期望：

$$\mathbb{E}\left[-\frac{(z-\mu)^2}{2\sigma^2}\right]=-\frac{1}{2},\qquad\mathbb{E}\left[\frac{z^2}{2}\right]=\frac{\mu^2+\sigma^2}{2}.$$

合并得单维结果：

$$\mathrm{KL}=\frac{1}{2}\left(\mu^2+\sigma^2-1-\log\sigma^2\right).$$

多维对角情形求和：

$$\mathrm{KL}\big(q_\phi(z\mid x)\,\|\,p(z)\big)=\frac{1}{2}\sum_{j=1}^{d}\left(\mu_j^2+\sigma_j^2-1-\log\sigma_j^2\right).$$

实际实现中网络输出 $\log\sigma^2$ 而非 $\sigma^2$，既保证方差为正，又避免除零与数值下溢。

第 5 步：重构项的高斯形式

若解码器设 $p_\theta(x\mid z)=\mathcal{N}(\hat{x},\tau^2 I)$，则

$$\log p_\theta(x\mid z)=-\frac{\|x-\hat{x}\|^2}{2\tau^2}-\frac{D}{2}\log(2\pi\tau^2),$$

对 $z$ 求期望后，最大化重构项等价于最小化均方误差 $\|x-\hat{x}\|^2$（二值数据则对应伯努利交叉熵）。

第 6 步：重参数化技巧

ELBO 需要对 $\phi$ 求梯度，但采样 $z\sim q_\phi(z\mid x)$ 这一步是随机的，采样结果对 $\phi$ 不可导，无法直接反传。重参数化把随机性外移：

$$\varepsilon\sim\mathcal{N}(0,I),\qquad z=\mu_\phi(x)+\sigma_\phi(x)\odot\varepsilon.$$

此时 $z$ 是 $\phi$ 的确定性函数与独立噪声的组合，$\dfrac{\partial z}{\partial\mu}=\mathbf{1}$、$\dfrac{\partial z}{\partial\sigma}=\varepsilon$，梯度可以正常穿过采样操作回传到编码器。

最终结论

$$\mathcal{L}(\theta,\phi;x)=\mathbb{E}_{\varepsilon\sim\mathcal{N}(0,I)}\big[\log p_\theta(x\mid \mu_\phi(x)+\sigma_\phi(x)\odot\varepsilon)\big]-\frac{1}{2}\sum_{j=1}^{d}\left(\mu_j^2+\sigma_j^2-1-\log\sigma_j^2\right).$$

🧠 直觉解释

ELBO 是「用编码器猜一个隐分布、再用解码器还原数据」的可计算下界：重构项要求还原得准，KL 项要求隐分布别偏离先验太远，二者拉扯出连续可生成的隐空间。
AI面试问答 ⭐⭐ 第 4 题

RAG 为什么要做混合检索（BM25 + 向量）？RRF 如何融合？

面试官问：我们做企业知识库问答，只用向量检索经常漏掉型号、工单号、专有名词；加上 BM25 后又不知道两路结果怎么合并。请说明混合检索的必要性、融合方法和工程要点。
--- 以下为答案与解析 ---

📌 回答要点

  • 两路召回互补：BM25 是稀疏词频匹配，擅长精确命中型号、编号、缩写、人名等低频关键词，对未登录词和领域术语稳定；向量检索是稠密语义匹配，擅长同义改写、口语化提问和跨表述召回。单一路径都有系统性盲区。
  • RRF（Reciprocal Rank Fusion）无需分数归一化：对每篇文档按各路排名计算 $\text{score}(d)=\sum_{i}\dfrac{1}{k+\text{rank}_i(d)}$，常取 $k=60$。它只使用排名而非原始分数，避免 BM25 分数与余弦相似度量纲不同、分布漂移的问题。
  • 两阶段结构：召回阶段并行跑 BM25 与向量检索各取 Top-N（如 50），RRF 融合后取 Top-M（如 20），再用 cross-encoder 重排模型精排取 Top-K 送入 LLM，兼顾召回率与精度。
  • 中文场景的关键细节：BM25 依赖分词，型号/编号需自定义词典或字符级 n-gram 兜底；向量模型要选中文/领域适配版本，并保证建库与查询使用同一模型、同一归一化方式。
  • 用数据驱动参数：以 Recall@K、MRR、nDCG 评估召回质量，分别统计「仅向量命中」「仅 BM25 命中」「两者都命中」的比例，据此决定各路 Top-N、RRF 的 $k$ 以及是否引入权重。

⭐ 加分项

  • 指出 RRF 的局限：它丢弃了分数信息，当某一路置信度差异很大时可能融合出次优结果；可用加权 RRF 或学习型融合（如基于 LambdaMART 的排序融合）改进。
  • 提及查询侧优化：查询改写/扩展（HyDE、同义词、实体抽取）能显著提升稀疏与稠密两路的召回，尤其是多轮对话中的指代消解。
  • 工程上把 BM25 与向量索引放在同一检索服务中并行发起，控制超时与降级；对权限过滤要在召回前或融合前完成，避免越权内容进入上下文。
  • 能说出评估闭环：离线构建「问题-正确文档」标注集，线上用点击/采纳率与答案忠实度（faithfulness）监控。

🔮 追问预测

  • 追问「RRF 的 k 为什么取 60？」——回答：k 起平滑作用，抑制头部排名的绝对优势、让多路共识更稳；60 来自原论文经验值，实际应在验证集上调，k 越小头部越强势。
  • 追问「BM25 和向量分数能不能直接加权求和？」——回答：需先做归一化（min-max/z-score/分位数），但两路分布随查询变化大，归一化不稳定，因此优先 RRF；若要加权，需在固定验证集上学习权重。
  • 追问「混合检索后上下文还是太长怎么办？」——回答：重排后按相关性截断、去重（同文档多段）、按 token 预算动态分配，并保留引用片段以便溯源。
