算法编程 ⭐⭐⭐ 第 1 题

滑动窗口最大值（单调队列）

给你一个整数数组 nums 和一个整数 k，有一个大小为 k 的滑动窗口从数组的最左侧移动到最右侧。窗口每次只向右移动一位，你只能看到窗口内的 k 个数字。

请返回**每一个窗口中的最大值**组成的数组。

要求：整体时间复杂度必须优于 $O(nk)$，即不能对每个窗口都重新扫一遍。
输入
第一行两个整数 n、k；第二行 n 个整数 nums[i]。
输出
输出 n-k+1 个整数，依次为每个窗口的最大值。
示例 1
输入：nums = [1,3,-1,-3,5,3,6,7], k = 3
输出：[3,3,5,5,6,7]
窗口依次为 [1,3,-1]→3、[3,-1,-3]→3、[-1,-3,5]→5、[-3,5,3]→5、[5,3,6]→6、[3,6,7]→7。
示例 2
输入：nums = [1], k = 1
输出：[1]
只有一个元素，窗口即它本身，最大值就是 1。
约束
$1 \le n \le 10^5$；$-10^4 \le nums[i] \le 10^4$；$1 \le k \le n$。要求时间 $O(n)$。

💡 解题思路

**核心：单调队列（递减的双端队列）**。

暴力做法对每个窗口取 max，复杂度 $O(nk)$，在 $n=10^5$、$k=5\times10^4$ 时会超时。观察两个事实：

1. **新元素会“淘汰”所有比它小的旧元素**：如果 $nums[j] \le nums[i]$ 且 $j<i$，那么只要 $i$ 还在窗口里，$j$ 就永远不可能成为最大值（$i$ 比它大、还比它晚过期）。所以 $j$ 可以立即丢弃。
2. **队首是最大值**：队列按值递减维护后，队首天然就是当前窗口最大值。

于是用一个双端队列存**下标**：
- 入队前，从队尾弹出所有 $\le$ 新元素的值（保持递减）；
- 入队后，若队首下标 $\le i-k$ 说明已滑出窗口，从队首弹出；
- 当 $i \ge k-1$（窗口已形成）时，把队首对应的值加入答案。

**为什么存下标而不是值**：需要判断“是否滑出窗口”，只有下标能提供过期信息；同时用下标回查 $nums$ 也避免了值重复时的歧义。

📝 参考代码（python）

from collections import deque

def max_sliding_window(nums, k):
    """
    单调队列（双端队列）解法：
    dq 中存的是下标，对应的 nums 值从队首到队尾严格递减。
    队首永远是当前窗口的最大值下标。
    """
    dq = deque()      # 存下标，值单调递减
    res = []
    for i, x in enumerate(nums):
        # 1) 维护单调性：新元素比队尾大，队尾永远不可能再成为最大值，直接弹出
        while dq and nums[dq[-1]] <= x:
            dq.pop()
        dq.append(i)

        # 2) 维护窗口范围：队首下标若已滑出左边界 i-k，弹出
        if dq[0] <= i - k:
            dq.popleft()

        # 3) 窗口形成之后才记录答案
        if i >= k - 1:
            res.append(nums[dq[0]])
    return res

⚡ 复杂度分析

时间 O(n)（每个下标最多入队一次、出队一次，均摊 O(1)） 空间 O(k)（队列长度不超过窗口大小）

单调队列、双端队列 deque、滑动窗口、均摊复杂度分析、用下标而非值维护窗口边界。

二分查找变体：寻找峰值

💡 解题思路

关键在于理解二分的**方向性判据**：比较 nums[mid] 与 nums[mid+1]，只看这一对相邻元素的升降趋势。

- 若 nums[mid] < nums[mid+1]（上坡），那么从 mid+1 出发向右走，要么一路递增到右边界（此时右边界元素大于其右侧的 -∞，是峰值），要么中途遇到下降（下降前那个元素就是峰值）。两种情况下**右侧必然存在峰值**，所以左侧可以整体丢弃。
- 若 nums[mid] > nums[mid+1]（下坡），同理向左走，要么一路递减到左边界（左边界大于 -∞，是峰值），要么中途遇到上升（上升前那个元素是峰值），**左侧必然存在峰值**。

因此每次都能安全砍掉一半区间，而且该论证只用到“相邻不等 + 边界为负无穷”，与数组是否单峰无关——多峰同样成立。

🎯 考点

二分查找的变体应用、单调性/趋势判据、边界哨兵（-∞）、循环不变式：区间内始终保证至少存在一个峰值。

🔍 逐项分析

  • A 正确：上坡则右侧必有峰值，令 left = mid + 1 是安全丢弃左半（mid 本身不可能是峰值，因为 nums[mid] < nums[mid+1]）；多峰数组也成立，复杂度 O(log n)。
  • B 错误：这是最常见的误解。二分不需要全局单峰，只需要“局部趋势 + 边界条件”保证峰值存在的一侧，多峰数组同样可二分。
  • C 错误：下坡（nums[mid] > nums[mid+1]）说明右侧是下坡方向，峰值应在**左侧**（含 mid），此时应令 right = mid，而不是 left = mid + 1。方向判断反了会把唯一峰值丢掉。
  • D 错误：该二分是确定性收缩，区间长度每次严格减半，不需要任何回溯验证，最坏 O(log n)，不是 O(n log n)。
AI公式推导 ⭐⭐⭐ 第 3 题

PPO-Clip 目标函数与 GAE 优势估计的完整推导

PPO（Proximal Policy Optimization）是大模型 RLHF 中最常用的策略优化算法。请完成两部分推导：

1. 从策略梯度出发，推导 PPO-Clip 的目标函数，并逐段分析为什么 clip 能限制策略更新幅度（给出对 $r$ 的偏导）。
2. 从 TD 残差出发，推导 GAE（Generalized Advantage Estimation）的指数加权形式 $\hat{A}^{\mathrm{GAE}}_t=\sum_{k=0}^{\infty}(\gamma\lambda)^k\delta_{t+k}$，并说明 $\lambda$ 如何控制偏差-方差权衡。

符号约定：$\pi_\theta(a|s)$ 为策略，$\pi_{\theta_{\mathrm{old}}}$ 为采样时的旧策略，$r_t(\theta)=\dfrac{\pi_\theta(a_t|s_t)}{\pi_{\theta_{\mathrm{old}}}(a_t|s_t)}$ 为重要性采样比率，$\hat{A}_t$ 为优势估计，$\gamma$ 为折扣因子，$\epsilon$ 为裁剪系数（常取 0.2）。
--- 以下为答案与解析 ---

🎯 考点

策略梯度定理、重要性采样、TRPO→PPO 的信任域近似、clip 的分段梯度分析、TD 残差望远镜展开、GAE 的几何加权与反向递推、偏差-方差权衡；与 DPO（离线、免奖励模型、闭式解）的对比是面试高频延伸。

📐 推导过程

## 第一部分：策略梯度 → PPO-Clip

### 第 1 步：策略梯度定理

目标是最大化期望回报 $J(\theta)=\mathbb{E}_{\pi_\theta}\left[\sum_t \gamma^t R_t\right]$。策略梯度定理给出

$$\nabla_\theta J(\theta)=\mathbb{E}_{s\sim d^{\pi}, a\sim\pi_\theta}\left[\nabla_\theta \log \pi_\theta(a|s)\, A^{\pi}(s,a)\right]$$

其中 $d^{\pi}$ 是策略诱导的状态分布。注意两个难点：① 采样分布 $d^{\pi}$ 随 $\theta$ 变化；② 期望本身依赖 $\theta$。直接用旧策略采样的数据更新新策略，分布就对不上了。

### 第 2 步：重要性采样修正分布不匹配

对动作分布做重要性采样，把期望换到旧策略下：

$$\nabla_\theta J(\theta)=\mathbb{E}_{s\sim d^{\pi_{\mathrm{old}}}, a\sim\pi_{\theta_{\mathrm{old}}}}\left[\frac{\pi_\theta(a|s)}{\pi_{\theta_{\mathrm{old}}}(a|s)}\nabla_\theta \log \pi_\theta(a|s)\, \hat{A}(s,a)\right]$$

利用恒等式 $\pi_\theta \nabla_\theta \log \pi_\theta = \nabla_\theta \pi_\theta$，可以把它写成一个**可直接求导的目标函数**（这就是 surrogate objective）：

$$L^{\mathrm{IS}}(\theta)=\mathbb{E}_{t}\left[r_t(\theta)\,\hat{A}_t\right],\qquad r_t(\theta)=\frac{\pi_\theta(a_t|s_t)}{\pi_{\theta_{\mathrm{old}}}(a_t|s_t)}$$

对 $L^{\mathrm{IS}}$ 求梯度正好还原上式，因此**最大化 $L^{\mathrm{IS}}$ 就等价于做策略梯度上升**。

### 第 3 步：重要性采样的方差问题 → TRPO 的信任域

$L^{\mathrm{IS}}$ 只有在 $r_t\approx 1$ 时才是可靠估计。$r_t$ 偏离 1 越远，估计方差越大（极端情况下分子分母差几个数量级，梯度的方向完全失真）。TRPO 用 KL 硬约束解决：

$$\max_\theta \mathbb{E}[r_t\hat{A}_t]\quad \text{s.t.}\quad \mathbb{E}\left[D_{\mathrm{KL}}\big(\pi_{\theta_{\mathrm{old}}}\|\pi_\theta\big)\right]\le \delta$$

但 KL 约束需要二阶近似 + 共轭梯度，实现复杂、每步开销大。PPO 的目标是：**用一阶方法近似实现“别走太远”**。

### 第 4 步：PPO-Clip 目标

PPO 直接对比率做截断：

$$L^{\mathrm{CLIP}}(\theta)=\mathbb{E}_{t}\left[\min\Big(r_t(\theta)\hat{A}_t,\;\mathrm{clip}\big(r_t(\theta),1-\epsilon,1+\epsilon\big)\hat{A}_t\Big)\right]$$

为什么是 $\min$？把两种情形拆开看（注意 $\min$ 使得目标始终取“更保守”的那个，防止目标函数被高估）：

**情形一：$\hat{A}_t>0$（该动作比平均好，希望提高其概率）**

$$\frac{\partial L}{\partial r_t}=\begin{cases}\hat{A}_t>0, & r_t<1+\epsilon\\[2pt] 0, & r_t\ge 1+\epsilon\end{cases}$$

当 $r_t$ 已经超过 $1+\epsilon$ 时，继续增大 $r_t$ 不再带来收益（梯度被截断为 0），策略不会为了一个“已经足够好”的动作无限加码。

**情形二：$\hat{A}_t<0$（该动作比平均差，希望降低其概率）**

$$\frac{\partial L}{\partial r_t}=\begin{cases}0, & r_t\le 1-\epsilon\\[2pt] \hat{A}_t<0, & r_t>1-\epsilon\end{cases}$$

当概率已被压到 $1-\epsilon$ 以下时，梯度同样为 0，避免过度惩罚。

**关键观察**：只有当 $r_t$ 落在“该方向还没走够”的区间时梯度非零，一旦走出信任域梯度即被截断。这是一个**单侧、软性的信任域**：允许概率下降方向（对坏动作）和上升方向（对好动作）各自被限制在 $[1-\epsilon,1+\epsilon]$ 内，而反向移动（例如好动作概率变低）不受 clip 保护，梯度仍然存在——这正是 PPO 相对 TRPO 的“廉价近似”。

### 第 5 步：完整损失

实际训练时把三项相加（前两项为负，因为是梯度上升转梯度下降）：

$$L_{\mathrm{total}}=-L^{\mathrm{CLIP}}+c_1 L^{\mathrm{VF}}-c_2\,\mathbb{E}\left[\mathcal{H}(\pi_\theta(\cdot|s_t))\right]$$

其中 $L^{\mathrm{VF}}=\mathbb{E}[(V_\phi(s_t)-R_t^{\mathrm{target}})^2]$ 是价值网络回归损失，熵项 $\mathcal{H}$ 鼓励探索。

## 第二部分：TD 残差 → GAE

### 第 6 步：TD 残差定义

令 $\delta_t=r_t+\gamma V(s_{t+1})-V(s_t)$，其中 $r_t$ 是即时奖励。$\delta_t$ 是“实际一步回报”与“价值函数预测”之差，是优势的单步无偏估计（当 $V=V^{\pi}$ 时 $\mathbb{E}[\delta_t|s_t,a_t]=A^{\pi}(s_t,a_t)$）。

### 第 7 步：n 步优势的望远镜展开

把 $n$ 步回报减去基线：

$$\hat{A}_t^{(n)}=\sum_{l=0}^{n-1}\gamma^l r_{t+l}+\gamma^n V(s_{t+n})-V(s_t)$$

把它展开成 $\delta$ 的求和（望远镜消去）：

$$\hat{A}_t^{(n)}=\sum_{k=0}^{n-1}\gamma^k \delta_{t+k}$$

验证：$\gamma^k\delta_{t+k}=\gamma^k r_{t+k}+\gamma^{k+1}V(s_{t+k+1})-\gamma^{k}V(s_{t+k})$，相邻项的 $\gamma^{k+1}V(s_{t+k+1})$ 与下一项的 $-\gamma^{k+1}V(s_{t+k+1})$ 相消，只剩首项 $-V(s_t)$ 与末项 $\gamma^n V(s_{t+n})$。

- $n=1$：$\hat{A}^{(1)}_t=\delta_t$，单步 TD，偏差大（依赖 $V$ 的准确性）、方差小。
- $n\to\infty$：$\hat{A}^{(\infty)}_t=\sum_{k\ge0}\gamma^k r_{t+k}-V(s_t)$，即蒙特卡洛优势，无偏但方差极大（回报的随机性全部累积）。

### 第 8 步：指数加权得到 GAE

GAE 对所有 $n$ 步优势做几何加权平均（权重 $(1-\lambda)\lambda^{n-1}$，$\sum_{n\ge1}(1-\lambda)\lambda^{n-1}=1$）：

$$\hat{A}^{\mathrm{GAE}}_t=(1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1}\hat{A}_t^{(n)}$$

代入第 7 步结果并交换求和次序：

$$\hat{A}^{\mathrm{GAE}}_t=(1-\lambda)\sum_{n=1}^{\infty}\lambda^{n-1}\sum_{k=0}^{n-1}\gamma^k\delta_{t+k}=(1-\lambda)\sum_{k=0}^{\infty}\gamma^k\delta_{t+k}\sum_{n=k+1}^{\infty}\lambda^{n-1}$$

内层等比级数 $\sum_{n=k+1}^{\infty}\lambda^{n-1}=\dfrac{\lambda^{k}}{1-\lambda}$，于是

$$\boxed{\hat{A}^{\mathrm{GAE}}_t=(1-\lambda)\sum_{k=0}^{\infty}\gamma^k\delta_{t+k}\cdot\frac{\lambda^{k}}{1-\lambda}=\sum_{k=0}^{\infty}(\gamma\lambda)^k\delta_{t+k}}$$

工程实现用反向递推（一条循环搞定，无需算到无穷）：

$$\hat{A}^{\mathrm{GAE}}_t=\delta_t+\gamma\lambda\,\hat{A}^{\mathrm{GAE}}_{t+1}$$

### 第 9 步：λ 的偏差-方差权衡

- $\lambda=0$：$\hat{A}=\delta_t$，完全信任价值函数 → **偏差最大、方差最小**；
- $\lambda=1$：$\hat{A}=\sum_k\gamma^k\delta_{t+k}$，退化为蒙特卡洛 → **无偏、方差最大**；
- $0<\lambda<1$：用 $\gamma\lambda$ 作为有效折扣，越远的 TD 残差权重指数衰减，相当于“在偏差与方差之间连续插值”。

注意 $\gamma\lambda$ 是一个**双重折扣**：$\gamma$ 来自回报定义，$\lambda$ 来自对 $n$ 步估计的信任程度。这也是 GAE 在实践中通常取 $\lambda\approx0.95$、$\gamma\approx0.99$ 的原因。

🧠 直觉解释

PPO-Clip 用“比率截断”把策略更新关在 $[1-\epsilon,1+\epsilon]$ 的软笼子里，避免重要性采样方差爆炸；GAE 则把“一步 TD 的低方差”和“蒙特卡洛的无偏”用 $(\gamma\lambda)^k$ 的权重融合起来，$\lambda$ 就是那只调节偏差与方差的旋钮。
AI面试问答 ⭐⭐ 第 4 题

KNN 的 k 值选择、距离度量与高维失效

面试官问：“KNN 看起来几乎没有‘学习’过程，为什么在工业界仍然被质疑、又仍然被使用？请说明它的核心原理、$k$ 与距离度量如何选，以及在高维场景下为什么会失效，工程上有什么改进手段。”
--- 以下为答案与解析 ---

📌 回答要点

  • **原理：惰性学习（lazy learning）**。KNN 没有显式训练阶段，把全部样本存下来；预测时对查询点计算与所有训练样本的距离，取最近的 $k$ 个做投票（分类）或平均（回归）。所谓“模型”就是训练集本身，因此“训练”是 $O(1)$、“预测”是 $O(nd)$，与常规模型正好相反。
  • **k 值的影响**：$k$ 太小 → 模型复杂、对噪声极敏感（$k=1$ 时一个错标样本就能翻转预测），方差大；$k$ 太大 → 邻域跨越类别边界，预测趋向全局多数类，偏差大。实践用奇数 $k$ 避免平票，通过交叉验证选 $k$，经验起点 $k\approx\sqrt{n}$。
  • **距离度量要与特征语义匹配**：连续特征常用欧氏距离 $L_2$；高维稀疏（文本 TF-IDF）用余弦相似度或 $L_1$；存在量纲差异必须先做标准化/归一化，否则数值大的特征会主导距离。另外闵可夫斯基距离 $L_p$ 是统一框架。
  • **维度灾难是根本瓶颈**：维度升高后，样本间距离趋于集中（相对差异 $\frac{d_{\max}-d_{\min}}{d_{\min}}\to0$），“最近邻”不再比随机点更近；同时 $k$ 个邻居要覆盖固定比例样本，所需体积按 $r^d$ 增长，样本需求指数爆炸。因此 KNN 在高维原始空间基本失效。
  • **工程改进**：① 降维/表征学习（PCA、自编码器、用预训练 embedding 替代原始特征）；② 近似最近邻索引（KD-Tree、Ball-Tree 适合低维，HNSW、IVF-PQ、LSH 适合高维大规模）；③ 特征加权/度量学习（Mahalanobis、学习型距离）；④ 用 KD-Tree 或倒排索引把预测从 $O(nd)$ 降到近似 $O(d\log n)$。

⭐ 加分项

  • **与 K-Means 的区别**：KNN 是监督、有标签、预测时用邻居投票；K-Means 是无监督聚类、优化簇内平方和。二者共享“距离”和“$k$”的符号，但目标完全不同，面试常被故意混淆。
  • **加权 KNN**：按距离倒数 $1/d$ 加权投票，缓解“远邻居与近邻居等权”的不合理；对噪声和不均衡类别更稳健。
  • **类别不平衡**：多数类会在投票中压倒少数类，可改用距离加权或按类先验做阈值调整，而不是单纯增大 $k$。
  • **可解释性与在线更新**：KNN 天然能给出“哪几个样本支持的判断”，可解释性好，且新增样本零成本（直接加入集合），适合冷启动/增量场景；代价是存储与推理成本随数据线性增长。
  • **与深度模型的关系**：检索增强（RAG）、对比学习中的 kNN 分类（如 kNN-LM）本质是“用 embedding + 近邻检索”复活了 KNN 思想，说明它并未过时，只是换了特征空间。

🔮 追问预测

  • **追问：为什么说 KNN 的“训练”是 O(1) 但整体并不便宜？** 答：训练零成本只是把计算推迟到推理，单次预测 $O(nd)$、空间 $O(nd)$；在线服务中 QPS 高时延迟不可接受，必须上 ANN 索引或做向量化/分块计算。
  • **追问：KD-Tree 在多少维以后失效，为什么？** 答：大致 $d>20$ 后退化明显。KD-Tree 依赖轴对齐切分剪枝，高维下超矩形体积占比极小、剪枝率下降，查询退化为近似全扫描；此时应改用 HNSW/IVF-PQ 等基于图或量化的 ANN 结构。
  • **追问：如何证明“距离集中”现象？** 答：对独立同分布特征，$\mathbb{E}[\|x-y\|^2]=2d\sigma^2$，标准差为 $O(\sqrt{d})$，相对波动 $O(1/\sqrt{d})\to0$，即所有点对距离都挤在均值附近，最近邻与最远邻的区分度消失。
  • **追问：k 用交叉验证选，那度量方式也能学吗？** 答：可以，度量学习（如 LMNN、对比学习）直接优化“同类更近、异类更远”的目标，等价于学习一个马氏距离 $d(x,y)=\sqrt{(x-y)^\top M(x-y)}$，$M$ 半正定。
