快速排序 (Quick Sort)

类别：排序算法 | 难度：入门

原理

快速排序采用分治策略：选择一个基准元素（pivot），将数组划分为两部分，小于基准的元素放到基准左边，大于基准的放到右边，然后递归地对左右两部分进行同样操作。平均时间复杂度 O(n log n)，是实际应用中最常用的排序算法之一。

核心要点

  • 基准选择策略直接影响性能（首元素、随机、三数取中）
  • 划分（partition）是核心，Lomuto 与 Hoare 两种划分方式
  • 原地排序，不需要额外数组空间
  • 不稳定排序：相等元素的相对顺序可能改变

技术细节

Hoare 划分使用双指针从两端向中间扫描，交换逆序对，返回最终基准位置；Lomuto 划分使用单指针扫描，遍历过程中将小于基准的元素逐步交换到前面。快速排序在数据规模较小时可切换到插入排序以提升常数因子性能。递归深度最坏为 O(n)（已排序数组 + 首元素基准），可用尾递归或随机化基准规避。

代码示例

def quicksort(arr, low, high):
    if low < high:
        # 使用 Hoare 划分
        pi = partition(arr, low, high)
        quicksort(arr, low, pi - 1)
        quicksort(arr, pi + 1, high)

def partition(arr, low, high):
    pivot = arr[high]
    i = low - 1
    for j in range(low, high):
        if arr[j] <= pivot:
            i += 1
            arr[i], arr[j] = arr[j], arr[i]
    arr[i + 1], arr[high] = arr[high], arr[i + 1]
    return i + 1

复杂度分析

平均 O(n log n)，最坏 O(n²)；空间 O(log n)（递归栈）

应用场景

  • 各类系统排序库（如 C 标准库 qsort、Python sorted）
  • 大数据排序的前置分治
  • 数组第 k 大/小的快速选择算法基础

Transformer 架构

类别：深度学习 | 难度：困难

原理

Transformer 完全基于自注意力机制构建编码器-解码器结构，替代 RNN 的递归结构，可并行训练并能有效建模长距离依赖，是大模型时代的基础架构。

核心要点

  • 编码器：多头自注意力 + 前馈网络 + 残差连接
  • 解码器：掩码自注意力（防止看到未来）+ 交叉注意力
  • 位置编码（正弦 / 可学习 / RoPE）
  • 训练使用 Teacher Forcing 与交叉熵损失

技术细节

每层由 MHA（多头注意力）+ FFN（两层全连接）组成，均有 LayerNorm 与残差连接。解码端对当前序列做因果掩码。推理时以逐步生成方式解码。后续模型如 GPT 仅用解码器栈做自回归生成。

代码示例

import torch
import torch.nn as nn

class TransformerBlock(nn.Module):
    def __init__(self, d_model, n_heads, ff_dim):
        super().__init__()
        self.attn = nn.MultiheadAttention(d_model, n_heads)
        self.norm1 = nn.LayerNorm(d_model)
        self.ff = nn.Sequential(
            nn.Linear(d_model, ff_dim), nn.ReLU(),
            nn.Linear(ff_dim, d_model)
        )
        self.norm2 = nn.LayerNorm(d_model)

    def forward(self, x):
        a, _ = self.attn(x, x, x)
        x = self.norm1(x + a)
        return self.norm2(x + self.ff(x))

复杂度分析

编码 O(n²·d)；解码自回归 O(n²·d)

应用场景

  • GPT、BERT 等预训练模型
  • 机器翻译、文本生成
  • 多模态模型基石

交叉熵损失与 Softmax

类别：损失函数 | 难度：入门

原理

交叉熵衡量两个概率分布间的差异，多分类任务中常用 Softmax 将 logits 归一化为概率，再用交叉熵作为损失，配合梯度下降训练模型。

核心要点

  • Softmax：p_i = eᶻⁱ/Σ eᶻʲ
  • 交叉熵 H(p,q) = -Σ p_i log q_i
  • 数值稳定性：log-softmax 与 LogSumExp
  • 与最大似然估计等价

技术细节

对多分类输出 logits z，Softmax 得概率，损失为 -log p_y（真实标签位置概率的负对数）。数值上使用 log_softmax(z) = z - logsumexp(z) 避免溢出。常用优化器 Adam 结合动量与自适应学习率，加速收敛。

代码示例

import torch
import torch.nn.functional as F

logits = torch.tensor([[2.0, 1.0, 0.1]])
loss = F.cross_entropy(logits, torch.tensor([0]))

复杂度分析

O(类别数)；优化器每步 O(参数数)

应用场景

  • 分类模型训练
  • 多标签分类
  • 语言模型训练
